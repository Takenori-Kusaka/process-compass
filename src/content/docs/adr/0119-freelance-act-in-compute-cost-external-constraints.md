## コンテキスト

ADR-0114 は、発注側の設備を受注側が使う場合の外部の制約として、37号告示・疑義応答集・中小受託取引適正化法を注記に置きました。フリーランス法は本件の外とし、後継の Issue #436 へ送りました。

#436 の審議(重。調査と5委員の会議体)は、次の2点を欠陥と認めました。

- 「本標準が定めないこと」の法令上の当てはめの列挙に、フリーランス法が無い。受注側が個人(従業員を使用しない)の受託は、本標準が対象にする小さい体制で現に起きる。評価しないと決めたのか、書いていないだけなのかを、読み手が区別できない
- 注記の「法令が求める書面や契約に代わりません」の対象に、フリーランス法の3条通知が入っていない。解釈ガイドラインは、費用等の精算の明示が無い場合は、3条通知に記載した報酬の額のみを支払う旨を明示したものとする(第2部 第1 1(3)キ(ウ))。第12項に費用の負担者を書いても、3条通知で精算を明示しなければ、報酬の額のみを支払うものとして扱われる

## 決定

### 1. 外部の制約の注記にフリーランス法の事実を足す

第8章「計算資源の負担を決める」の外部の制約の注記に、次の事実を足します。中身は原文で確かめた事実だけで、規範を足しません。

- 受注側が特定受託事業者である場合はフリーランス法が掛かる。明示(法第3条)は全ての委託する事業者に、禁止行為(法第5条)は従業員を使用するなどの委託する側が1か月以上の期間行う業務委託に掛かる(解釈ガイドライン 第1部 1・4、第2部 第1 1、第2部 第2 2)
- 費用等(名目を問わない)を委託する側が負担する場合は総額が分かるように報酬の額を明示する必要がある。額が確定しない場合の明示の方法として、算定方法の明示と未定事項の扱いが挙げられている。精算の明示が無い場合は3条通知の報酬の額のみを支払う旨を明示したものであることに、特定受託事業者は留意が必要である(同 第2部 第1 1(3)キ(ウ))
- 購入・利用強制(法第5条第1項第5号)は、特定受託事業者に対価を負担させることが要件である(同 第2部 第2 2(2)オ)。中小受託取引適正化法の運用基準と同じ形である
- 両法のいずれにも違反する行為は、原則としてフリーランス法を優先して勧告し、例外がある。例外は、中小受託取引適正化法のみに違反する行為もしている事業者について、行為の全体に同法を適用することが適当であると公取委が考える場合である(適用関係の考え方 3)。両法の適用を受ける取引では、両法の記載事項を一括で示せる(フリーランスのガイドライン 第3 の 1)
- 確かめた範囲(語の検索)では、解釈ガイドライン(全48頁)に、発注側の設備・ソフトウェアの利用権・計算資源の提供や費用の負担を直接扱った記述は無い。計算資源の費用が「費用等」に当たるかを示した公的な整理も、確かめた範囲に無い
- テンプレ8 第12項への記入は、フリーランス法の3条通知にも代わらない

注記の見出しの時点は、法令ごとに確かめた日を示す形へ改めます(37号告示と中小受託取引適正化法は 2026-11-05、フリーランス法は 2026-11-11)。前者を 2026-11-11 に確かめ直してはいないためです。

本文が引くのは、PDF を直接読んだ出典(解釈ガイドライン SRC-0727、適用関係の考え方 SRC-0728、フリーランスのガイドライン SRC-0729)に限ります。法律の条文(SRC-0726)は、法律の名称と条番号を示すためだけに引きます。条文は e-Gov 法令検索の API の XML を直接取得して、条番号を照合しました。

注記には根拠水準のマークを付けません。事実の記述であり、本標準の判断ではないためです。EV-0232(第12項の種類ごとの3つの欄)は対象が変わらないため、据え置きます。

### 2. 「本標準が定めないこと」にフリーランス法を加える

第8章 軸D の「本標準が定めないこと」の項目「計算資源の費用の負担について、法令上の当てはめ(…)を、本標準は評価しない」の括弧に、「特定受託事業者に係る取引の適正化」を加えます。

## 採らなかった案

| 案 | 採らなかった理由 |
| --- | --- |
| 解釈ガイドラインの「費用等の精算の有無や範囲等について十分に協議し決定することが望ましい」を注記に引く | 行政の推奨であり、本標準の注記に置くと本標準の推奨と読まれる |
| 中小受託取引適正化法 5条2項1号(有償支給の原材料等の対価の早期決済)の確認の結果を注記に足す | 根拠の条文の取得が要約モデルを経たもので、照合が済んでいない。役務提供委託に掛からない号であり、論点の外にある |
| 労働基準法上の労働者性の判断を補強する要素(機械・器具の負担関係)を注記に足す | 指揮命令の軸に属する。労働者性の判断を本標準が示すことになり、法的助言の境界を越える |
| テンプレ8 第12項に、3条通知の報酬の額へ含めたかを書く欄を足す | 採用者への新しい義務になる。欄を置く理由が法令にしか無い(ADR-0114 で双務契約の所在の欄を採らなかったのと同じ型) |
| フリーランス法 Q&A と中小受託取引適正化法の条文を本文から引き、出典カードを起こす | どちらも要約モデルを経て読んだもので、原本と照合していない。同じ事実は直接読んだ出典で示せる |
| 計算資源の費用が「費用等」に当たると書く | 原文に例が無く、公的な当てはめも無い。推測を事実として書くことになる |
| 両法を満たす構成(費用を発注側が負い、総額を3条通知に書くなど)を推奨する | 法的助言の境界の外である(ADR-0114 と同じ扱い) |
| 注記に根拠水準のマークを付ける | 事実に暫定のマークを付けると、事実と判断の区別が崩れる |
| ADR を起こさず、調査の記録だけで済ませる | 「本標準が定めないこと」の拡張が、公開の決定から辿れなくなる |

どれも、決めていない事項ではなく、課さないと決めた事項です。
