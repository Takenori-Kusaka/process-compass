## コンテキスト

ADR-0087 は「発注側の設備を受注側が使う場合と、中小受託取引の適正化に関する法令との関係」を決定の外に置き、後継の Issue へ送りました。第8章の外部の制約の注記は、指揮命令の軸だけを扱っていました。設備の負担の軸(37号告示 第二条第二号ハ)と、取引の公正の軸(中小受託取引適正化法)は書かれていませんでした。

テンプレ8 第12項は「費用の負担者=実行環境の所有者」を要求の形で定めていました。この要求には次の欠陥がありました。

- ADR と根拠水準のどちらも無い
- 法令の当てはめの一方の形(発注側の設備を受注側に無償で使わせる形)を既定にする
- 「実行環境」「所有」の語が定まらない。CI の実行環境、AI のサービスの契約者、エージェントが動く端末は、組織が分かれうる。従ったかどうかを判定できない
- 費用の負担の取り決めは、規格が定める事項の外にある(ISO/IEC 専門業務用指針 第2部 箇条4)

準拠テンプレートの様式は、この欄を「実行環境を所有する側」と記入済みで持っていました。欄が埋まって見えるため、決めたかどうかが様式から読めませんでした。

## 決定

### 1. 外部の制約の注記を「計算資源の負担を決める」に置く

第8章 軸D「計算資源の負担を決める」の末尾に、外部の制約の注記を置きます。中身は、原文で確かめた事実だけです。

- 37号告示 第二条第二号ハは、(1) 設備の自己負担、(2) 企画・専門的な技術・経験の「いずれか」を求める
- 疑義応答集 第1集 問13 は、(1) の場合の扱いを示す。業務の処理に直接必要な設備を発注者から借りるときは、請負契約と別の双務契約を要するとする。問14 は双務契約が必要な範囲を扱う
- CI の実行環境・AI のサービスの利用権・エージェントの実行環境に当てはめた公的な整理は、確かめた範囲に無い
- 中小受託取引適正化法の購入・利用強制(法第5条第1項第6号)は、中小受託事業者に対価を負担させることが要件である(運用基準 第4の6(1))。システム利用料の減額の違反行為事例がある(運用基準 3-9)
- テンプレ8 への記入は、法令が求める書面・契約に代わらない
- 本標準は、これらへの当てはめを評価しない

指揮命令の軸の注記(「判定の結果を受け取る者を決める」)には、疑義応答集 第3集 Q6(会議・チャット・プロジェクト管理ツールの共用)を足し、Q8(アジャイル型開発以外のシステム開発にも当てはまる)との関係と、新しい注記への参照を置きます。設備の負担は、判定の置き先と無関係に委託全般に掛かり、指揮命令の注記と適用範囲が違うため、別の注記にしました。

注記には根拠水準のマークを付けません。事実の記述であり、本標準の判断ではないためです。照合の状態は注記の中で開示します。

### 2. テンプレ8 第12項を、実行環境の種類ごとの記録へ改める

「費用の負担者=実行環境の所有者」の要求を廃します。代わりに、実行環境の種類ごとに、次を締結時に決めて記録させます。

| 種類 | 記録する欄 |
| --- | --- |
| CI の実行環境 / AI のサービスの利用権 / エージェントの実行環境 | 利用の契約の当事者、費用の負担者、上限の設定と強制停止の操作を持つ者 |

期間あたりの上限額と到達した場合の措置、上限を超える実行を許可する手続と承認者は、変えません。「所有」の語を第12項で使いません。準拠テンプレートの様式の記入済みの値を消し、雛形へ戻します。

種類ごとの3つの欄で負担の取り決めの抜けを防げるという判断には、実証がありません(EV-0232、見直し 2027-05)。

### 3. 課さないと決めたこと

第8章 軸D の「本標準が定めないこと」に、次の2つを足します。

- 計算資源の費用の負担についての、法令上の当てはめの評価
- 発注側の設備を受注側が使う場合に、別個の双務契約が要るかの判断

費用の負担者と、上限の設定と強制停止の操作を持つ者を一致させることも求めません。

## 採らなかった案

| 案 | 採らなかった理由 |
| --- | --- |
| 指揮命令の注記(既存)に混ぜる | 適用範囲が違う。既存の注記は判定の置き先が分かれる場合の節にある |
| 外部の制約の所在と、本標準が評価しないことだけを書く | 原文で確かめた要件(「いずれか」、対価の負担の要件)を書かないと、読み手が問14 だけを見て双務契約が常に要ると誤る。問14 の本題は双務契約の範囲である |
| 両方を満たす構成(発注側が費用を負い、貸与の契約を別に結ぶ)を推奨する | 法的助言の境界の外である |
| 中小受託取引適正化法 5条2項1号、5条2項2号・運用基準 7-8 を書く | 5条2項1号は条文を確かめていない。5条2項2号と 7-8 は要員に委託外の事務をさせる例で、設備の負担の論点ではない |
| サービスの利用規約の個別の条項と製品名を書く | 版の変わりが早く、本標準が追随できない。席・資格情報の扱いは第12項の記録で捉える |
| 第12項を据え置く・先送りする・削る、負担者を発注側か受注側のどちらかに固定する | 据え置きは根拠が無く、法令の一方の形を既定にする。削ると上限の承認者と強制停止の起点が契約から消える。どちらへの固定も法令の当てはめを本標準が抱える |
| 費用を止められる側が費用を負う形(核)を残す | 費用の負担者と止める者を一致させる理由は、法令にも実証にも無い。止める操作の持ち手は欄として残した |
| 双務契約の所在を書く必須欄 | 欄を置く理由が法令にしか無い。法令上の要求事項を名前を伏せて条項にする形になる(#309 の案 1-D と同じ型) |
| 利用規約の出典カードを起こす | 本文が引かない |

どれも、決めていない事項ではなく、課さないと決めた事項です。
