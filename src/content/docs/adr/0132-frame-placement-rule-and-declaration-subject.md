2026-11-17 に、決定5 が保留した「定める」「課す」への動詞の広げ方は、[ADR-0155](/process-compass/adr/0155-safety-prohibitions-and-statements-decided-per-sentence/) の決定8 で、広げないと決めて閉じました。決定3 の登録簿は仕組みを残し、項目を空にしました。

## コンテキスト

[#440](https://github.com/Takenori-Kusaka/process-compass/issues/440) は、次の2つの食い違いを指摘しました。

- 注意の枠(札に「暫定」を持たない `:::caution` と `:::danger`)の中に、要求・禁止の文末の文が残っていた。第1章 1.7.2 は注記を説明に数えるが、注意の枠は列挙に無い。#342 の裁定は、枠の中の禁止を本文へ移す案を重い審議の対象とした
- 主語を省いた「〜を設けません」が、表明か禁止かが決まらないまま 22 件あった。#298 から X-10 へ至る経緯のとおり、人の注意だけでは再発する

実行で確かめた結果は次のとおりです。

- 1.7.2 の「迷う文は要求として読む」は、読み手の既定である。#342 の先例は、起草者が文の地位を確定するときの審議の重さについてである。2つは別の行為についての定めで、矛盾しない
- 読みの既定は、起草者の確定の代わりになりません。したがって、固有の 7 文を「いまも要求である」として軽い審議で確定できません

## 決定

### 1. 要求事項と禁止を、注意の枠だけに書かない

- 規定として効かせる事項は、枠の外の本文に 1.7.1 の形で書く
- 枠の中で本文の要求事項に触れるときは、要求・禁止の文末を使わず、その所在を示す
- 同じ事項の規定を2か所に置かないためである(1.7)。#342 が `:::caution` について示した向きと同じである

### 2. 注意の枠の種類の地位は、本 ADR で定めない

- 定めるまで、枠の中の文は枠の外と同じ形で読み、迷う文は要求として読む
- 入れ物(枠)が説明か要求かに迷う文も、迷う文に数える。1.7.2 の理由(取りこぼしより、説明が要求として読まれるほうが安全)を入れ物へ及ぼす類推である。文面にはなかったため、1.7.2 に書いて記録する
- 読み手の既定は、起草者の確定の代わりにならない(#342 の先例との関係)
- 今の読みは変わらない。採用者の義務は、増えず、減らない

### 3. 地位が未決の文は、登録簿と第1章 1.7.2 のマークで開示し、一致を機械で確かめる

- 登録簿 `undecidedFrameSentences` に、頁・句・所在・Issue・見直しの月を載せる
- 実物のそばに、効き方を先に書いた1行を置く。枠の文は「決まるまで要求として読む」旨、主語の無い文は「決まるまで禁止として読む」旨を書く
- 検査は、登録の句が本文にあること、実物のそばに表示の文があること、1.7.2 のマークの表に所在の文字列があることを確かめる。審議の結果、文を直したときは、登録が本文から消えて失敗するため、表の行を除く作業を忘れない

### 4. 表明は主語を省かない。表明の主語は本標準またはその部分とする

- 表明の主語を、メタの文の項と同じく、本標準またはその部分(本章・本節・本附属書・本様式)にそろえる
- 採用者を主語に取りえない文で、義務は動かない。`gate-criteria.md` の「本節は新しいゲートを設けない」が表明に入らなかった食い違いが解ける
- 主語を省いた文は、表明の類に入れない

### 5. 検査12 の対象を注意の枠へ広げ、検査17 を足す

- 検査12: 注意の枠の中の要求・禁止の文末(`RE_SHALL`)を検出する。平叙の文末(します・しません)までは広げない
- 検査17: 文末が「設けません」「設けない」で、同じ文に主語の文字列が無い文を検出する。動詞は登録簿 `declarationVerbs` で持ち、自己試験(hit・miss)を付ける。今は「設ける」の1語である
- 「定める」「課す」への広げ方は、主語の無い文の振り分けを読んでから決める。#440 に残す

### 6. 機械で閉じない部分は manual とし、根拠水準マークで開示する

| 閉じない点 | 扱い |
| --- | --- |
| 注意の枠の中の平叙の動詞文が、説明か要求か | manual(起草と査読)。地位は重い審議で決める |
| 枠の中の「所在を示す」文が、正しい条項を指すか | manual |
| 主語のある文が、表明として正しいか | manual。文字列の有無しか見ない |
| 「設ける」のほかの動詞の、主語の無い否定の文 | manual。動詞を広げると正しい禁止を止める |
| 表明か禁止かの振り分けの当否(今回の 20 件) | manual。独立の突合で見る |

開示は 1.7.2 のマーク(EV-0263)と 1.7.4 のマーク(EV-0264)に置く。

## 検討した選択肢

| 案 | 採らなかった理由 |
| --- | --- |
| 説明と書き、未決の文を名指しで除く | 表に載せ損ねた固有の文が、誰も決めないまま説明になる。枠の中の平叙の要求と推奨を落とすことは、軽い審議で決められない |
| 規則を重い審議の結論まで入れない | 枠の中へ新しい禁止が書かれる回帰を止めない。未決であることが標準の中で見えない |
| 形で読むと確定する案、`:::danger` を規範の枠として認める案 | 固有の 7 文を要求として確定する。ADR-0063 の原則の変更で、重い審議に当たる。重い審議の結論がこの案を採れば、本 ADR を置き換える。本 ADR は、この道を閉じていない |
| 注意の枠を説明と確定する案 | 固有の 7 文が規範の力を失う。安全の禁止 2 件が消える |
| 固有の 7 文を「いまも要求である」として本文へ出し、軽い審議で閉じる | 読みの既定は確定の代わりにならない。#342 の先例に反する |
| 未決の文を `provision-ok` で通す | 印は正当な使用の意味で、未決の表示ではない。表と実物の食い違いを機械が見ない |
| 未決の 2 文を表に載せない | 未決であることが読み手に見えない |
| 検査12 を平叙の文末まで広げる | 大半が事実の文である。機械で判定しない部分(1.7.2) |
| 検査17 を、置く・求める・作る・足す まで広げる | 採用者を主語とする正しい禁止を大量に止める見込み |
| 検査17 へ「定める」「課す」を今入れる | 主語の無い文を読んでいない。振り分けの後に入れる(採らないのは時期で、向きではない) |
| 検査を入れず、1.7.2 に書くだけ | 同じ型の再発を人の注意に頼る。#298 から X-10 へ至る経緯のとおり再発した |
| 共通の文末の定義に開き括弧を足す | ほかの検査の検出が動く。検査17 だけの正規表現にする |

## 影響

- 採用組織への新しい義務は無い。固有の 7 文の地位は動かない。読みは今と同じである
- 本標準の文 24 件と編集 1 件を直した。表明 16、禁止の再掲または決定済み 4、注意の枠の中の再掲 2・決定済み 2。実装マーク、ADR の決定、適用範囲は変えない
- 準拠テンプレートの写し 4 件(`04-gate-record.md` の 3 か所と `10-assumption-ledger.md`)は、語が標準と食い違う。検査は落ちない。template を処理する直列の作業で直す
- 重い審議(固有の 7 文の地位、注意の枠の種類の地位、枠の中の平叙の要求と推奨)は #440 に残る。決まるまで、7 文は「決まるまで要求として読みます」の表示つきで残る
- 根拠は E0 のまま、見直しは 2027-05 とする。検査を通ったのに見つかった同じ型の文の件数が1件以上あれば、動詞の登録を広げる向きで見直す
