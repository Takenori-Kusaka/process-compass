## ステータス

採用(2026-08-14)

## コンテキスト

第4章「タスクの分割基準」は、変更規模の上限(既定値 400行)を置き、あわせて**自組織の実測で較正する手続**を定めています。**この2つが両立していませんでした**([#247](https://github.com/Takenori-Kusaka/process-compass/issues/247))。

改訂前の条文です。

> - 上限を超える場合、実装計画へ差し戻す。レビューを分割して対処しない
>
> 2. 四半期ごとに、判定完了時間が SLA を満たした変更の分布を出す
> 3. その分布の上側パーセンタイル(初期は第85を推奨)を新しい上限とする

**手順2の母集団は「レビューを実施した変更」です**。上限超過は差し戻されてレビューへ到達しないため、**母集団の右側が上限で打ち切られます**。

### 帰結は据え置きではなく収縮

第 n 四半期の上限を `L(n)` とすると、母集団は `[0, L(n)]` に収まり、`L(n+1) = P85(母集団) ≤ L(n)` です。等号は、観測の85%以上がちょうど上限値に張り付く場合にしか成立しません。**実際の変更規模は目安100行付近に集中するため、上限は400から急落します**。

手順4(差し戻し率・リバート率の併確認)は下降を止めません。上限を下げると差し戻し率が上がるため悪化を検知しますが、条文は「悪化している場合、上限を戻す」としか書いておらず、**戻し先が前期の上限であれば、同じ計算を翌期に繰り返します**。

### 散文の成果物に、コードの上限が掛かっていた

除外の一覧は「自動生成ファイル・ロックファイル・一括整形」の3つのみでした。**判断記録・機能仕様・設計文書が除外されていません**。

上限400行の根拠は、本文が自ら「2006年当時のC系プロダクトコードとツール支援レビュー」と明記しています。**散文の成果物は原典の適用範囲外です**。

そして本標準は判断記録に「採らなかった選択肢とその理由」を求めます(第6章 テンプレ2)。**行数で分割させると、標準の別条項によって、標準が求めた記録の側が削られます**。

**なお、この除外は準拠テンプレート側にだけ存在していました**。[ADR-0040](/process-compass/adr/0040-template-forms-as-subset-of-standard/)が定めた「テンプレートの様式は標準の部分集合である」に反する逆流であり、本 ADR で解消します。

## 決定

### 1. 上限を、差し戻しの既定とする

上限を超える変更は差し戻しを既定とします。**第7章 7.3 の例外承認を経た場合に限り、超過したままレビューを実施してよい**ものとします。

**打ち切りを解除するのは、超過を通す穴ではありません。超過を通した事実が記録として残る経路です**。

### 2. 超過レビューの記録を、較正の母集団に含める

例外承認を経て実施した超過レビューは、**判定完了時間と変更規模を必ず記録します**。この記録を較正の母集団に含めます。

### 3. 較正の手順を、分位点から充足率へ改める

規模の区間ごとに SLA の充足率を出し、**充足率が8割を下回らない最大の区間の上端を新しい上限とします**。

分位点は母集団の形に依存しますが、充足率は**規模と負荷の関係そのもの**を測ります。上限の定義(レビュアーが判定に耐える負荷で確認できる規模)と、測る量が一致します。

### 4. 観測が無い四半期は、上限を動かさない

**当該四半期に上限を超える観測が1件も無い場合、上限を変更しません。引き下げも行いません**。

観測が無いことは、上限が高すぎることの証拠でも低すぎることの証拠でもありません。**この但し書きが収縮の止め金です**。

### 5. 散文の成果物を、行数の算定から除外する

判断記録・機能仕様・設計文書を除外し、**判定完了時間の SLA で判定します**。

**新しい数値を置きません**。判定完了時間の SLA は既に存在し、超過時の措置は第7章 7.5 が定めています。

## 検討した選択肢

| 案 | 却下の理由 |
| --- | --- |
| 上限を目安のみとし、合否条件から外す | 上限が無い状態は、AI が生成する巨大な変更をそのまま通す経路になる。**打ち切りの解消と、上限の廃止は別である** |
| 較正手続を削り、上限を固定値のままとする | 本文が自ら「2010年代以降に独立して再検証した研究を確認できていない」と書いている。**固定する根拠が無い** |
| 上限超過を、例外承認ではなく判定者の裁量で通す | 通した事実が記録に残らない。母集団の打ち切りが解消しない |
| 母集団に、差し戻した変更の規模も含める | 差し戻した変更には判定完了時間が存在しない。**充足率を計算できない** |

## 帰結

- 上限は残る。既定の帰結も差し戻しのままである
- **第7章 7.3 に、実際の流量が生じる**。[ADR-0046](/process-compass/adr/0046-deferred-with-conditions/)が後置した規定1・2 の採る条件(7.3 の適用が3件を超えたとき)に、初めて到達しうる経路ができる
- 準拠テンプレート側の除外規定が、標準の部分集合になる
- **上限が上がるとはかぎらない**。充足率が8割を下回れば、上限は下がる。本 ADR が止めるのは、**観測に基づかない収縮**だけである
