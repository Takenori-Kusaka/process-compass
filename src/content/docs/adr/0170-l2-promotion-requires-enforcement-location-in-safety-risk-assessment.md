## ステータス

採用(2026-11-17)。[ADR-0158](/process-compass/adr/0158-halt-on-rework-rate-indeterminate-and-record-enforcement-location/) の決定を置き換えない(補足)。ADR-0158 決定8 が「別の重の審議で扱う」と送った論点と、ADR-0158「見直しの契機」の2項目め(L2 への適用の重の審議の結論)に結論を出します。重の審議の結論です(Issue [#340](https://github.com/Takenori-Kusaka/process-compass/issues/340)、`research/340-deliberation/`)。

## コンテキスト

- 3.12.10 要求事項5 は、停止条件を強制できない環境で自律実行を解禁しないと書く。直後の文は「遮断の手段を持たないまま自律水準を上げる構成を認めません」で、限定の語は無い。ADR-0158 決定8 は、L2 を含む読みが自然だと書いた
- L2 は定義の上で「人間および自己修正ループ」をフォールバックに持つ唯一のレベル(5.4.2)であり、人は統合点しか見ない。CL1・CL2 の案件で L1 より上へ上げる手段は L2 しかない
- ADR-0158 は L3 の登録の根拠に4点目を足した。L2 には登録の根拠が無く、L1 から L3 へ直接上がる場合は 5.4.5 の判定を通らないため、別の判定点になる
- 準拠テンプレートは L2 を表せない(ADR-0081 決定6、IMPL-0289)。テンプレ9 は L2 以上で必須(適用条件4)。再評価を 5.4.5 の判定が伴う(IMPL-0861)。危害に財産・データの損害を含むため、費用の暴走も範囲に入る
- 外部の規格・製品で、自律の段階を上げる前提として停止の手段を求めるものは確認できなかった(`research/340-deliberation/research-external.md`)。無いと確かめたのではない

## 決定

1. 要求事項5 は L1 より上への引き上げ全般に掛かる。表の文を L と E の語で書き直す。義務の範囲は広げず縮めない
2. 5.4.5 の条件の表に条件7 を足す。実行の単位ごとに、停止条件を強制する手段の所在(または該当なし(理由))
3. 証跡は、5.4.5 の判定で作成または再評価したテンプレ9 の低減策(手段、実装場所の順)とする。L1 の案件で表が無いときは、L2 への引き上げが適用条件4 に当たるので、判定の時点で作成する。新しい記録は作らない。「時間上の限界」の欄は指名しない。欄は1セルだけで、3種の停止条件のどれにも当たらない。L3 の4点目は変えない。同じ設定を手段にするなら、4点目とテンプレ9 の両方で同じ所在を名指してよい。写しは求めない
4. 統制は manual(B-2 の判定と観点23)。IMPL-1013 は採用者に委ねる(`adopter`)。理由は、準拠テンプレートが L2 を表せないこと(ADR-0081 決定6)。採用者に求めるのは、条件7 の記録を B-2 の判定と観点23 の監査に供すること。機械の検査は足さない。手段が停止を強制するかは確かめない。**課さないと決めたものであり、書かれていないだけではない**
5. 条件7 を足す前に L2 を適用した範囲は止めない。次の 5.4.5 の判定、テンプレ9 の次の更新、次のプロセス内部監査のうち最も早い時点で記録を備える。要求事項1〜3 の強制は免除しない。ADR-0158 が L3 で猶予を採らなかったこととの違いは、機械の門の有無である。L3 には登録の停止という機械の門があり、猶予は期限つきの表示だけになる。L2 には機械の門が無く、即時を書いても誰も検出せず、表示と実態の食い違いを作るだけである。数値の期間は置かない
6. 実行形態 E3 の解禁の時点で照らすかは決めていない。課さないと決めたものではない。E3 の運用の実態を調べていないため、Issue [#444](https://github.com/Takenori-Kusaka/process-compass/issues/444) へ寄せ、実機の確認の知見を入力に別の重の審議で扱う
7. 「自律実行」の語は定義しない。3通りの用例のうち2つが誤用になり、定義の外が抜け道になる。7.11・enablement・compute-strategy の用例は触らない

## 採らなかった案

| 案 | 採らなかった理由 |
| --- | --- |
| L3(と E3)に限ると明記する | 採用済みの「自律水準を上げる構成を認めません」を根拠なしに縮める。CL1・CL2 の案件で唯一の引き上げの手段に、照らしが0になる |
| 5.4.5 に足さず、観点23 の事後の確認で受ける | L2 の開始前に照らす場所は 5.4.5 だけで、事後の確認は暴走の後に見つける。直後の文を縮める点は上と同じ。L2 と L3 の差は統制の強さ(L3 は機械が記入の有無を見て止める。L2 は manual)に残る |
| 条件7 に専用の記録を作る | 同じ範囲の同じ手段を、テンプレ9 の低減策と別の記録の2か所に書かせる。食い違ったとき正本が決まらない |
| 条件の表に行を足さず、後段に1文だけ置く | B-2 が判定に使う表に無く、確かめたかが判定の記録に残らない |
| 「時間上の限界」の欄を証跡に指名する、または欄の見出しを変える | 欄は1セルで3種の停止条件に当たらない。見出しを変えると準拠テンプレートの様式に及ぶ |
| テンプレ9 の上限の実装場所の実在だけを確かめる | 3種のうち時間しか見ず、3.12.10 の単位と3種に届かない |
| 強制の有効性を機械で確かめる | 決定可能でない。準拠テンプレートは L2 を表せない |
| 発火の実績(停止の記録)を条件にする | 連続運用の3か月に停止が起きるとは限らず、演習を新しく課す。L3(記入の有無まで)より L2 を重くする逆転になる |
| 条件7 の記入の有無を機械で検査する | 準拠テンプレートは適用中の L2 を知らない。L1 の案件で誤検出する |
| 第7章の例外承認で強制の欠如を受ける | 7.3 の対象外。受ければ遮断の無い構成を適合の主張に含める |
| 要求事項5 を削る、要求事項1 へ吸収する | 要求事項1 は「強制する」、5 は「解禁の時点で照らす」で役割が違う |
| CL ごとに L2 の照らしを書き分ける | リスク区分は変更ごと、CL は案件ごと(ADR-0039)。案件の CL から適用外を導かない |
| 移行を即時にする | L2 には機械の門が無く、誰も検出しない約束になる。記入だけの後付け(偽の証跡)を促す |
| 移行の猶予を次の 5.4.5 の判定に限る、または数値の期間で置く | 判定の来ない範囲が永久に照らされない。数値は根拠の値が無い |
| 5.4.6 の停止の表に「条件7 の記録が無い」行を足す | 機械で止める経路が L2 に無い。表示と実態が食い違う |
| E3 を本件で決める | E の事実を調べていない。突合の面積が倍になる |
| 外部の規格(EU AI Act 第14条4項(e)、NIST MANAGE 2.4)を条文に引く | 原文を確かめていない。第14条は高リスク AI の提供者・配備者の義務で、開発工程の自律に直接掛からない。背景として書くだけにする |
| 「自律実行」の語を定義する | 決定7 |

## 影響

- **新しい負担**: 技術判断者(申請時に所在を示す)、B-2(判定時に読む)、テンプレ9 の作成者(低減策へ単位ごとに書く)。準拠テンプレートへは降りない(manual・adopter)
- 破られたときの損失は、費用の負担者(ADR-0114。受託では発注側)と、適合の主張の信頼が負う。人の安全へ直接及ばず(安全関連部は L1 固定)、取り消せない損失でもない。したがって条件7 は所在の有無と「該当なし(理由)」に留め、手段の種類・値・発火の実績を求めない
- 降りていない規定: IMPL-1013(5.4.5)、IMPL-1014(テンプレ9。Issue [#448](https://github.com/Takenori-Kusaka/process-compass/issues/448))
- 根拠水準: EV-0313(条件7 と、有効性を確かめない選択。E1)、EV-0314(移行の時点の選択。E0)
- 準拠テンプレートの様式への反映(記入時の注意)は #448 に寄せる。この束では欄を足さない
