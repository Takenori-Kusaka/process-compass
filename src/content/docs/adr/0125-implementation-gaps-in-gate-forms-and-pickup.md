## コンテキスト

[#359](https://github.com/Takenori-Kusaka/process-compass/issues/359) は、判定の様式・スキル・次の一手に欄と注記が欠けていて準拠テンプレートへ降りていない規定(17 件)を扱いました。軽の審議で9件を降ろし、方向の一致した3件を予定のまま残しました。起案と反対の2委員の結論が割れた5件(IMPL-0342・0462・0174・0377・0467)は、CLAUDE.md の規定により重の会議体(起案・現場・品質監査・規格・弁護)へ上げました。

外部の調査(`research/359-deliberation/survey-external.md`)で次のことが分かりました。

- 職務を分離できない小規模の体制について、COSO・PCAOB AS 2201・J-SOX は禁止せず、代わりの統制と開示を求める。一人会社の自己の選任は決議と登記に残るが、個人事業主に当たる公的な記録と、自己の任命の開示を直接定める規範は見つからなかった
- 抜き取りの件数を規範として定める規格は見つからなかった。ISO 19011 と PCAOB AS 2315 は件数を決める要因だけを定め、件数の値はどれも根拠の実証を示さない目安である。5件に問題が0件でも、母集団の中の割合の上限は(信頼90%で)37%までしか言えない
- 受託で価値の判断の責任を発注側に置く点は、IPA のモデル契約とスクラムで一致する。所属を構成の属性にして機械で検出する例は見つからなかった
- 前段の承認の記録の無い着手を止める型は、21 CFR 11.10(f)・(g) と ISO 9001 8.6 にある。事前に承認した類型の一覧を前提にする型は、ITIL の標準変更にある

## 決定

### 1. 1名の体制の自己の任命を、閉じた条件で受け付けて開示する(IMPL-0342)

- 第3章 3.13.3 の「新任の決定者が、自分の任命を自分の記名で確定してはならない」の例外のうち、本人の上に任命の権限を持つ者がいない1名の体制を、準拠テンプレートが受け付ける
- 条件は、すべてを満たす場合に限る。初回の記入でない。前任の決定者がいて、体制から外れている。記名者が変化点の後の決定者である。変化点の後の体制の内がその1名だけである。変化点の前と後の名簿に組織上の任命権者がいない。D-0 の「決裁の権限の出所」が、個人事業主か1名で代表権を持つ法人を挙げている。決定者が当事者になるほかの行を束ねていない(ADR-0122 の行ごとの判定と同じ扱い)
- 自己の任命は変化点の記録に区別して残し、保証の開示の項目7 へ出す。法人で外部の記録(登記・議事録)への言及が無ければ、その旨も出す
- D-0 に新しい行を足さない。既存の「決裁の権限の出所」で同じ記載を運ぶ
- 機械は法的な形態の真偽を確かめない。EV-0248(E0)で開示する

### 2. 記述の内容の四半期の抽出を、本文で定める(IMPL-0174)

- 第5章 5.7.4 の末尾の1文を、要求事項の表に改める。母集団はその四半期の判定記録の人が書く欄とする。抽出は四半期の締めの後に、実行者が選べない値(四半期と母集団の記録の識別子の一覧)から導いた種で機械が無作為に行い、記録は1回だけ残す。件数は5件(母集団が5件以下なら全件。増やしてよく、減らさない)、確かめる者は抽出した記録の判定者以外の人(体制の内が1名なら本人で、その旨を書く)とする。所見は判定者へ届け、判定を自動で取り消さない。所見の次の四半期は件数を倍にする
- 結果を母集団へ一般化しないことを本文に書く。件数は EV-0249(E0)で開示する
- 件数と確かめる者を採用者に委ねない。委ねると件数 0 でも適合になり、満たしたかを照らす先が無い

### 3. 着手の前提とする判断の記録を定める(IMPL-0467)

- 第3章 3.5.5 に要求事項9 を足す。state:needs-po・state:needs-owner を経た state:needs-dev は、価値責任者の判断・事業決裁者の決裁の記録を前提とする。記録は第6章テンプレ4 の判定記録で、ゲートの欄の値を「価値責任者の判断」「事業決裁者の決裁」とし、対象を作業単位とする
- G-6 が省略・未達の構成の state:qm-blocked は、出荷判定者の G-7 の差し戻しの判定記録を前提とする
- 機能へ対応づけない作業単位は、価値責任者が作業の類型ごとに前もって記録した判断(対象「類型 <名>」)を前提にできる。類型の記録が無ければ着手しない。本文は類型を列挙しない
- 「判定できない」で止めた件数を `/pit` に数えて出すことは、結果を残す置き場が要るため、IMPL-0500(降りていない)で追う

### 4. 到達の見込みの費用の実績の入力を、採用者に委ねる(IMPL-0499)

| マーク | 規定 | 採用者に委ねる理由 | 採用者に求めること |
| --- | --- | --- | --- |
| IMPL-0499 | 到達の見込み(第7章 7.7.3 必達基準2)の費用の組の入力のうち、単位期間あたりの費用の実績と、確定済みでまだ発生していない支出 | 入力は、採用組織の会計の基盤(原価の記録・購買の記録)に依存する。準拠テンプレートはこれらを読めない(IMPL-0277 の消費の計測と同じ水準の依存) | 単位期間ごとの費用の実績と確定済みの支出を、見込みの報告の Issue と判定記録の「費用の見込み」へ、記録の所在とともに書く |

- 入力の無い組は、ADR-0099 決定3 の算定できない組とする。新しい値「入力なし」は足さない
- 算定そのもの(IMPL-0377)は、完了スループットの集計(IMPL-0374)の後に降ろす。区分は判定者を拘束するため、集計の無いまま算定を降ろさない。SC-M の母集団は SG で記名した SC-M の一覧を正とし、ラベルと照らす

### 5. 受託の構成の価値責任者の所属は、#357 へ送る(IMPL-0462)

- 機械による検出を本件で降ろさない。`issue=357` へ付け替え、降りていない規定として表示し続ける
- それまでは、受託の構成の CLAUDE.md の注記に、機械で確かめず AI-SLA 合意確認書の締結の時点と G-2 の判定で契約の体制の条項と照らすことを出す

## 影響

- 1名の体制の承継者は、架空の任命権者を名簿へ書かないまま適合できる。法的な形態の記載が事実と異なる場合、機械は止めない。止めるのは内部監査と外部の確認者である。名簿の外に任命権者がいないこと(名簿の完全性)を内部監査の観点6 の所見の例に足すことは、本件の議題の外であり、所有者へ申し送る
- 四半期の抽出は、所見が0件でも母集団の健全さを示さない。広がった形骸化を見つける最低限の網である
- needs-po・needs-owner を経た作業単位は、ゲートの通過に加えて判断の記録を要する。これまで「様式が無く読まない」と注記して着手させていた場面が、「着手しない」になる
