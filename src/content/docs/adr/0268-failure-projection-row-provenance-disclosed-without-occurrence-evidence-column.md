## コンテキスト

- [#465](https://github.com/Takenori-Kusaka/process-compass/issues/465): 所有者の問い。投影の表の困りごとが本質であるという根拠は何に紐づいているか
- ADR-0266(#456 の裁定)は、行を所有者の例示 5 つを起点に作成者が選んだとし、品質保証部門の問いの記録から取っていないと開示していた。しかし、#456 の裁定は、決裁者が尋ねる型に基づくという前提に立っていた。この前提を支える実在の問いの一次記録は、#461 の調査でも得られなかった
- 外部の調査(#282、2026-09 時点)には、失敗の型ごとの発生の実測がある。ただし、知見の原文を読むと、行の困りごとと対象のずれるものが多い。起案の対応表にも誤りがあった
- 軽の審議(起案・反対の2委員)で、起案は「発生の裏づけ」の列を置く案、反対は列を置かず出所を開示する案を示した。議長が裁定した

## 決定

1. 所有者の問いへの答えを開示する。本表の行が本質(頻度と損害が大きい)であることの根拠は無い。発生の実測は、本質であることの根拠にも、止め方が効くことの根拠にもならない。H.3 の前書きと EV-0357 に書く。行の選び方の水準は E0 のまま、見直しは 2027-05 のまま
2. 行の出所を、行ごとに3つのうちちょうど1つで、表の直後に示す: 所有者の例示(2026-11-27)に当たる行、外部の調査の実測から取った行、作成者が足した行
3. 「発生の裏づけ」の列は置かない。附属書の表へ、知見の番号と水準を足さない(2行目の FND-0091 は保つ)。行ごとの発生の実測の対応は、調査メモ(`research/465-deliberation/`)に置く
4. 外部の調査に発生の実測があるが、行にしていない型(検査を形だけ満たす・迂回する、長い作業での監視の見逃し、並行する作業の干渉)を、寄せた先の行とともに表の直後に名指しする。行にしていないことは、止めないことの主張ではなく、止めると主張しないことの表示とする
5. 行を1つ足す(末尾の13行目): AI が、書かれた指示・規則に従わない。止める場所は 3.11.3(違反を許容できない規則を誘導層だけに置かない。強制層へ降ろす)で、区分は `機械が止める` と `人`、最も弱い止め方は `人`。区分の値は増やさず、`開示` の定義を広げない。出所は外部の調査の実測から取った行
6. 行の全体を外部の実測から導き直すことは、実在の問いの記録が得られるまで行わないと決めた。EV-0357 の差し替え条件(実在の問いの記録3件)を保つ
7. 行の採否の規則は置かない。行を採るか否かは作成者の選択のままである
8. 機械の検査(`scripts/check-failure-projection.mjs`)は変えない。出所の箇条は自由な文で、機械で閉じない。manual とし、EV-0357 で開示する

## 採らなかった案(課さないと決めたこと)

| 案 | 採らなかった理由 |
| --- | --- |
| A 実測から導き直して差し替え、裏づけの無い行を外す | 実測の有無は調査の網に依る。行を外すと、既存の統制と未達が決裁者の問いの場所から消える |
| C1 「発生の裏づけ」の列と、知見の実在・水準の機械の検査 | 知見の原文 19 件のうち 9 件が行の困りごとと対象がずれ、1 件は水準の表記が過大だった。揺れる対応に水準(E2・E3)を付けて規範の附属書の表へ載せると、行に根拠の外観を与える。ADR-0266 が退けた「覆って見せる対応表」と同じ構造になる。機械が確かめるのは番号の実在だけで、対応の正しさは閉じない。検査があることが、対応の正しさの外観を足す。知見の多くは見直しの時期が 2026-12 で、表が数か月で揺れる |
| 検査を形だけ満たす(行14)・並行の干渉(行15)の行化 | 前者は既存の行と H.11 に散っていて、行にすると言い換えになる。後者は発生の実測が弱く(実際にマージされた変更で 1/417)、止める場所の条項の適用範囲を確かめていない |
| 行の採否の規則(実測か実在の問いに限る)を前書きに定める | 規則に当たらない既存の行(なぜそう作ったか、秘匿情報)の扱いに例外が要る。細かい定義を足して、表の信頼は上がらない |
| B 行を保ち、何も足さない | 「指示・規則に従わない」は、止める場所が本文にあり、突合も済んでいる。知っていて行にしないのは欠け |
| D 何もしない | 出所の3分類が無く、行にしていない型も示されない |
| EV-0357 の見直しを 2026-12 へ早める | 附属書へ知見の水準を埋めないので、知見の見直しに表を連動させる理由が無い |

## 影響

- 決裁者は、行が本質であることの根拠は無いと表の前で読み、行ごとの出所を表の直後で読める。「検証された困りごとの一覧」と誤って受容することを避ける。出所を偽ると、この誤りを招く(#465 で所有者が問うた形)
- 決裁者は、行ごとの発生の実測の有無を、表からは読めない。調査メモを開いて確かめる
- 表は12行から13行になる。本節は投影で、要求事項を持たない。採用者の義務は変わらない
- 出所の分類が正しいかは機械で検査しない。manual とし、EV-0357 で開示する
- 再検討の契機: 実在の品質保証部門の問いの記録が3件得られたとき。本表に無い困りごとが出たとき

## 根拠水準

- EV-0357: 行の選び方と、各行の止める場所・区分・最も弱い止め方の対応、行の出所の分類(E0)
