## ステータス

採用(2026-11-17)。審議は軽です。記録は `research/354-deliberation/b12-*.md` にあります。採用済みの ADR の決定を置き換えません。[ADR-0068](/process-compass/adr/0068-start-of-application-and-conformance-claim/) と [ADR-0134](/process-compass/adr/0134-exception-approval-is-not-deviation-and-lapses-after-due-date/) が「降りていない」と記録した表明の様式(IMPL-0120)のうち、値の部分が降ります。[ADR-0141](/process-compass/adr/0141-g8-by-record-and-deploy-credential-unlisted-deviation/) の審議が #354 へ寄せた項目(T-1)を採りません。

## コンテキスト

[#354](https://github.com/Takenori-Kusaka/process-compass/issues/354) を閉じた後、3つの実装マークが閉じた Issue を計画として名指していました(IMPL-0120・IMPL-0309・IMPL-0986)。

- IMPL-0120: 第1章 1.10.2 の適用の表明に併記する事項。集約は、版・名・逸脱・例外承認の件数を別々に出していた。未達の件数と記録の欠落の件数を、0 件の場合も含めて併記の形では出していなかった
- IMPL-0309: 第1章 1.10.4 の同じ案件の再開。準拠テンプレートは終了の後の構成の変更を notice のほかは拒む(IMPL-0307)。ADR-0083 決定2 は再開の数え方(件数は最初の開始から数え、空白の期間は記録の欠落とする)を定め、準拠テンプレートが再開の経路を持たないことも記録した。ただし、持たない理由と、採用者に委ねることの記録(ADR-0084 決定4)は無い
- IMPL-0986: 第4章 G-8「配備の統制と資格情報の置き場」。準拠テンプレートは配備のワークフローを持たない(ADR-0090 決定6)。述べられる名(`claimStatus`)は、この離脱を数えない。#329 の審議は、構成に欄を新設して数える案(T-1)を #354 へ寄せた

## 決定

### 1. 併記する事項の値を、集約が1行で出す

出荷の証跡の集約は、適用の表明に併記する事項の値を1行で出します。従う版(作業中の版のときはコミットの識別。読めなければ「識別なし」)、未達のゲートの件数、記録の欠落などの件数、逸脱と列挙に無い離脱の一覧です。0 件と「無し」を省きません。記録の欠落などの件数は、名を下げる判定と同じ欠落の一覧から数えます。種別は分けません(多く数える側)。表明の文は出しません。表明は表明する者が述べるものだからです(第1章 1.10.2)。

### 2. 同じ案件の再開を、採用者に委ねる

準拠テンプレートに再開の経路を足しません。終了の記録を覆せる操作が増え、終了を1つの事象とした定め(ADR-0083 決定2)を弱めるためです。

採用者に求めることは次のとおりです。数え方は ADR-0083 決定2 のとおりで、新しい義務ではありません。同じ案件で再び適用するときは、表明する者が、件数を最初の適用の開始から数え、終了から再開までの期間を記録の欠落として表明に書きます。終了を別の案件の開始に読み替えて数え直しません。同じ案件かどうかは、表明する者が判断して記録します。

### 3. 配備の資格情報の離脱の数え方を、採用者に委ねる。構成に欄を足さない

述べられる名に、配備の資格情報を配備を許す参照に結び付けていない構成を数える仕組みを、準拠テンプレートに足しません。構成に欄を足す案(#329 の T-1)を採りません。欄は記録の正本を2つにし、自己申告の値が実態の離脱を隠しうるためです(ADR-0147 決定1 と同じ理由)。数える材料(配備のワークフロー)は、ADR-0090 決定6 により準拠テンプレートの側にありません。

採用者に求めることは次のとおりです。配備のワークフローを足す採用者は、IMPL-0985 の突き合わせと同じ時点で、配備の資格情報が参照に結び付いているかを確かめます。結び付いていなければ、第7章 7.3 の要求事項のすべてを満たし、効力を失っていない例外承認があるかを確かめます。無ければ列挙に無い離脱で、適合の主張を述べません。例外承認は、技術負債台帳の区分「例外」の行に、対象を配備のワークフローと配備先として残します(件数は集約が数える。IMPL-0573)。

準拠テンプレートは、この離脱を数えていないことを、構成書の注記と品質レポートの併記の行で述べます。

:::caution[暫定 EV-0301 / 見直し 2027-05]
**対象**: 同じ案件の再開が稀であること、構成の欄の自己申告が離脱を隠しうること、配備の資格情報の離脱を採用者の確認に置いても適合の主張の信頼が保てること(決定2・3)。
**根拠の水準**: E0(なし)。
**備考**: 判断であり、採用者の観測は無い。
**差し替え条件**: 採用者の構成の変更の記録で、終了の後に同じ案件を再開した件数。保証の開示と例外承認の台帳で、配備の資格情報の離脱が表明の後に見つかった件数。1件でも見つかれば、決定3 を審議し直す。
:::

## 影響

- IMPL-0120 は降りた規定(`delivered`、`check=machine`)になる。表明の文と、文への書き写しは表明する者が確かめる
- IMPL-0309・IMPL-0986 は `plan=adopter`、`decision=ADR-0165` の降りていない規定として台帳に出し続ける
- 準拠テンプレートの README の、配備の資格情報の語(「未達」)を ADR-0141 決定4・5 の語へ揃える
- 採用者に新しい記入欄は増えない
