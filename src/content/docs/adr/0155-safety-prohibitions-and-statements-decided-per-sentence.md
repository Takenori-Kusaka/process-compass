## ステータス

採用(2026-11-17)。[ADR-0132](/process-compass/adr/0132-frame-placement-rule-and-declaration-subject/) の決定5 が保留した「定める」「課す」への動詞の広げ方を、本 ADR で閉じます(置き換えず、足します)。ADR-0132 の決定4 の主語の定義にそろう編集を足します。注意の枠の種類の地位は [ADR-0156](/process-compass/adr/0156-caution-frames-count-as-explanation/) が決めます。[#440](https://github.com/Takenori-Kusaka/process-compass/issues/440) の重の審議の結論です。

## コンテキスト

ADR-0132 は、注意の枠の中の文と主語の無い文のうち、地位が未決の7文を開示して残しました。7文は「要求として読む」扱いで、本文へ確定しても義務は動きません。新しい義務になるのは、F.7 の挿入した環境と、RRS1・RRS2 の欄の理由の2つだけです。

審議は重です。理由は、7文のうち3文が安全(重-1 は取り消せない操作)であること、重-8 が ADR の原則(ADR-0063)に及ぶこと、採用者への新しい義務を含むことによります。調査(内部・外部)と5委員(起案・現場・品質監査・規格・弁護)の会議体を開きました。記録は `research/440-deliberation/` にあります。

所有者の方針の3問を、論点ごとに当てました。(1) 条文は満たすべき結果と残る証跡まで。手順は手引きへ。(2) 新しい条項を足さずに第7章の例外承認で受けられないか。(3) 破られたとき誰が何を失うか。

## 決定

### 1. 運用に供している安全関連システムへの故障挿入を、本文の禁止にする(重-1)

- 附属書F F.5 の本文に「運用に供している(本番稼働中の)安全関連システムへ、故障を挿入してはなりません」を置く。実行時の挿入とハードウェアによる挿入は、運用から切り離した環境(試験台の実機、または実機を模擬した環境)で行う。分類表の語も同じにそろえる
- この禁止は、第7章 7.3 の例外承認の対象にしない。挿入そのものが危険事象を起こしうるためである
- `:::danger` は所在の枠に縮める
- この2文(禁止と例外承認の対象外)の存在は、登録簿 `confirmedSafetyProhibitions` で検査12 の続きとして確かめる。検査は、句が HTML のコメントを除いた本文で、どの `:::` の囲み(注意の枠・注記・暫定の枠)の外にもあることを確かめる。句を消す・弱める・コメントに残す・囲みへ移すと `lint:provisions` が失敗する。文の意味と、禁止が守られることは確かめない(manual)
- **新しい義務**: F.7 の行「故障挿入の結果」に、実行時の挿入とハードウェアによる挿入をした場合の、挿入した環境を記録する。故障挿入試験は HR のままで、実施は義務づけない
- 根拠は本標準のリスク論である。稼働中への挿入を明文で禁じる規格は、見つかっていない。規格の引用を根拠に書かない。根拠水準マークは EV-0293

### 2. RRS3 を低減後 SR に数えない禁止と、RRS1・RRS2 を適用しない理由の記録を本文にする(重-2・重-3)

- 「低減後 SR の算定に、RRS3(使用上の情報)を数えてはなりません」を第6章の本文に置く。結果の形で書く。規格が「下げてはならない」と書く保証は無く、「RRS3 は無意味」の誤読を招くためである
- **新しい義務**: RRS3 の欄に方策を書く行で、RRS1 または RRS2 の欄に方策を書かないときは、その欄に適用しない理由を書く。新しい列は足さない。理由の当否は機械で閉じない。テンプレ9 の承認者が承認のときに読む(manual)。根拠水準マークは EV-0294
- RRS3 の禁止は F.5 のように例外承認の対象外を本文に書き足さない。低減後 SR はゲートの判定基準の項目ではなく、第7章 7.3 で外れる経路が無い。決定9 が全論点に及ぶ。存在は登録簿 `confirmedSafetyProhibitions` で確かめる
- 「尽くして」は外から確かめられないので使わない。理由の定型を機械で止める案は採らない

### 3. 段階的な開示と対比を、唯一の防御としないことを要求にしない(重-4。緩める)

- 枠を説明の形(可能性の形)に改める
- 本文に「本標準は、判定における対比を入れた判断に、5.6.2 の測定の併用を課しません」を置く。**課さないと決めたこと**である。5.6.2 の欠陥注入の実施は全案件の義務でなく、併用を要求にすると、測定しない体制へ新しい義務を広げる
- 緩む分は、保証の開示の項目6(第4章 G-7)の「未測定」の表示が受ける。IMPL-0821 は規定でなくなったので消す(識別子は再利用しない)。根拠水準マークは EV-0295

### 4. 滞留期間とゲート滞留時間は、定義で分ける(重-5)

- 第4章の指標の表の「ゲート滞留時間」に、定義「各ゲートの提出から判定まで」を括弧で足す。2.10.4 の枠は「両者は始点と終点の異なる別の指標です」の事実の文にする。「集計しない」の禁止は置かない。合算した数はどちらの定義にも当たらず、定義の要求を満たさないためである

### 5. 市場規模の欄は、表明にする(重-6)

- 「本標準は、企画書の様式に市場規模の欄を定めません。適用する者が欄を足すことも禁じません」。[ADR-0031](/process-compass/adr/0031-market-hypothesis-by-structure-not-fields/) 決定6 と矛盾しない。[ADR-0040](/process-compass/adr/0040-template-forms-as-subset-of-standard/) の建付け(必須欄の存在だけを検査する)と一致する

### 6. 応答に対する報奨は定めず、標準が定めた指標の個人評価への使用を禁じる(重-7)

- 「本標準は、応答に対する報奨を定めません」の表明を置く
- 「3.10.8 で記録する応答率と、応答の件数・速さを、個人の評価指標にしてはなりません」を本文の禁止にする。3.10.11 は既に応答率の用途を要求している。この禁止はその裏の向きで、今の読みの確定である。範囲を標準が定めた指標に限る。報奨一般の禁止は採らない(人事に及び、確かめる術と実証が無い)。ロール単位の計測は妨げない。確かめる者は採用組織(manual)。根拠水準マークは EV-0296

### 7. 注意の枠と注記の中の平叙の要求と推奨を、文ごとに直す(重-9)

| 所在 | 扱い |
| --- | --- |
| 第6章 テンプレ8(契約の相手方への指標の定義) | 本文の要求へ。指標ごとの定義(算出方法を含む)を第2項に書いて示し、第15項の合意の記名を得てから条件に用いる。相手方の合意の成否は標準の外で、記名の有無だけを見る |
| 附属書F F.1(規格適合の指示との関係) | 本文の表明へ |
| 附属書F F.4(安全関連部の列は例) | 本文へ出す(本文に支えが無く、IMPL-0924 が規定として扱うため) |
| 第3章 3.7.3(ステージ移行ゲートで差し戻しを用いない) | 本文へ |
| 第4章 G-4 基準4 への委ね、規格の逐語確認が済んでいない旨(3 か所) | 事実の形へ。推奨の文を消す |

推奨を本文の推奨の条項として新設する案は採らない。

### 8. 検査17 の動詞を「定める」「課す」へ広げない

- 40 件のうち表明 39、要求 1(第5章 5.10 の摩擦の配分の設計)。表明 39 の中に偽陽性 3、前の文に主語を持つもの 13 がある。広げると、正しい表明の大半を止め、`provision-ok` の印が押印になる。manual のまま、1.7.4 のマーク(EV-0264)で開示する。見直しの条件は EV-0264 の差し替え条件のままとする
- 要確認の3件(第4章 判定記録の操作、第8章 構成の初期化、第8章 契約の比率)は、主語を足す編集で直した。意味は変えていない

### 9. 第7章の例外承認では、どの論点も受けない

7.3 はゲートの判定基準を満たさないまま進む手続です。行為の禁止・定義・表明には、載せる基準の項目がありません。安全の禁止を載せれば、承認1名の記名で禁止が外れ、SR3 以上の例外を本文で禁じる 7.10.1 と向きが逆になります。

## 影響

- 新しい義務は2つ(決定1 の F.7 の挿入した環境、決定2 の RRS1・RRS2 の欄の理由)。緩めるのは1つ(決定3)。残りは今の読みの確定である
- 根拠水準マーク: EV-0293〜EV-0296 を足した。EV-0264 に振り分けの結果を足した
- 実装マーク: IMPL-0995(RRS1・RRS2 の欄の理由。undelivered)・IMPL-0996(応答率の個人評価への不使用。採用者)・IMPL-0997(ステージ移行ゲートで差し戻しを用いない。undelivered)を足した。IMPL-0821 を消した。IMPL-0925・IMPL-0933・IMPL-0924・IMPL-0871・IMPL-0799・IMPL-0803・IMPL-0825 の注記を改めた
- 準拠テンプレート: 今回は触らない。写しの食い違いと様式の欠けは、`research/440-deliberation/implementation-heavy.md` に項目として残し、#440 を開いたままにする
- 機械の統制は増やさない。新しい禁止・記録は manual で、根拠水準マークか undelivered の表示で開示する
