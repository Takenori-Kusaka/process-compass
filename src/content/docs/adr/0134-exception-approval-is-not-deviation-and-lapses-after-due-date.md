## ステータス

採用(2026-11-15)。[ADR-0083](/process-compass/adr/0083-standard-edition-end-of-application-and-deviation/)の閉じた列挙と記録の欠落の区分を変えません。[ADR-0088](/process-compass/adr/0088-organizational-distance-steps-and-cl1-stage-relaxation/)の決定2 の「例外承認は従来どおり使える」の読みを、本 ADR の決定7 で確認します。[ADR-0133](/process-compass/adr/0133-no-conditions-or-compensating-measures-for-unlisted-deviations/)と同じ理由で、閉じた列挙は D-1 のまま保ちます。

## コンテキスト

[#353](https://github.com/Takenori-Kusaka/process-compass/issues/353) は、第7章 7.3 の例外承認が第1章 1.4 の「逸脱」に当たるか、当たらない場合に適用の表明と適合の主張とあわせて開示させるか、を問いました。例外承認を経て判定基準を満たさないまま進めた変更が範囲にあっても、修飾の無い適合の主張が成り立ちました。現行の条文には、この状態を止める定めがありませんでした。

本件は重い審議として扱いました(適合の主張の開示は採用者の義務の定義で、1.10.2 と附属書H H.8 に及ぶため)。記録は `research/353-deliberation/`(`internal.md`、`external.md`、`council/` の5委員の意見、`decision-draft.md`、`decision.md`、`implementation.md`)にあります。先行の #352(ADR-0133)の裁定を前提にしました。

実物で確かめた事実は次のとおりです。

- 第7章 7.3 は、回収の期限を定めて台帳へ登録することを求めていたが、期限を過ぎた記録を無効にする条文が無かった。既存の定義では、期限を過ぎた未回収の例外承認は落ちなかった
- 附属書H H.6 の保証の開示は、出荷の時点の未回収の例外を項目5 で示す。範囲の件数を、表明と主張の文へ組にして出す定めは無かった

## 決定

1. 第7章の例外承認は、第1章 1.4 の逸脱に当たらない。閉じた列挙は D-1 のままとする。7.3 の回収と報告は、判定基準の不充足を解く手続であり、不充足が続く間の同程度の防御ではないためである(ADR-0133 と同じ理由)
2. 7.3 の要求事項のすべてを満たし、回収の期限を過ぎていない例外承認を経た判定基準の不充足は、満たしていない要求事項として表示しない。判定基準を満たしたことにはしない。ゲートの未達は解かない(第4章 G-6)
3. 適用の表明・適合の主張・逸脱を伴う適合の主張に、範囲の例外承認の件数(うち未回収、うち回収の期限を過ぎた件数、独立した人の確認を経ない出荷の件数、数えた日、技術負債台帳の所在)を併記する。0 件も書く。主張の名は変えない
4. 件数を併記しない表明と主張を、本標準に基づくものとして扱わない。件数の句を省く短い引用には、件数を書いた文書の所在を添える。適合の主張と逸脱を伴う適合の主張は、範囲のすべての変更がゲートの判定基準を満たしたことを述べない
5. 回収の期限を過ぎた例外承認は、期限の翌日から効力を失い、記録の欠落に数える。**採用者への新しい義務である**。回収の記録か、新しい記録による承認のし直しがあるまで続く。期限の書き換えは承認のし直しにならない。新しい行で承認し直された元の行は、未回収と期限超過のどちらにも数えない。突合の日に効力を失っている区分「例外」の行が台帳に1件でもあれば、対象が当該の出荷の範囲に無くても(ゲートの判定を対象とする行を含む)、記録の欠落に数えて以後の出荷判定を差し戻す。効力を失う前に終わった出荷判定と、期限の日までに終わる範囲についての主張は変えない(遡らせない)。所有者の回答(2026-11-15。下記)により、第1版の発行までの定めとする
6. 7.3 の対象は、ゲートの判定基準と、条項が 7.3 を名指しした事項に限る。席の兼務の禁止、文脈の分離、人の名簿、認証情報の分離などの構成の条件は、対象でない。既存の条文の確認であり、新しい義務ではない
7. ADR-0088 決定2 の「例外承認は従来どおり使える」は、同 ADR が例外承認の経路を変えていないという意である。段に届かない未達を例外承認で通せるという意ではない
8. 例外承認の件数、回収の期限の長さ、再承認の回数に、上限を課さない。第7章 7.10 の前提の受容と 7.3.2 の未解決事項は、件数に含めない。附属書H H.6 の保証の開示は変えない

所有者の回答の記録: 回答者は所有者。2026-11-15。問いは、「回収の期限を過ぎた未回収の例外承認の帰結を、第1版の発行までの定めとして受け入れるか」。回答は、受け入れる。期限を過ぎた例外承認は期限の翌日から効力を失い、記録の欠落に数える。未回収が1件でもあれば、回収か再承認まで適合の主張を述べられず、以後の出荷判定(G-7)は差し戻しになる。記録は `research/353-deliberation/decision.md` 1 章にある。

## 検討した選択肢

| 案 | 採らない理由 |
| --- | --- |
| 例外承認を閉じた列挙へ足す | 同程度の防御ではなく、行の中身が閉じない。#352(ADR-0133)と逆になる |
| 開示を課さず、案内の1行だけを足す | 主張の受け手に届く経路が主張の文しかなく、範囲に例外承認が何件あっても修飾の無い主張が成り立つ。本標準は件数の表示を既に採っている。弁護の案のうち「主張が何を述べないかの明示」は決定4 で採る |
| 未回収だけを併記する | 回収済みを落とすと、範囲で外れた量が読めない |
| 主張の名を分ける(例外承認を伴う適合の主張) | 名の識別力が無くなる。閾値に根拠が無い |
| 範囲に例外承認があれば主張を妨げる | 7.2 と ADR-0036 と逆になる。正規の経路を使えなくし、記録を偽る動機を作る |
| 期限超過を、区分を作らず 1.10.2 の述べる条件へ直接足す | ADR-0083 決定3 の4つの表示の外に、主張を妨げる状態ができる。帰結は同じで、既存の区分(記録の欠落)に数えるほうが体系に収まる |
| 期限超過は既存の区分に落ちるとして、何も足さない | 条文にも準拠テンプレートにも、期限と日付を比べる定めが無い |
| 期限超過を件数の内訳で開示させるだけにする | 所有者の回答による。失効の定めが無いと、期限が意味を持たない |
| 失効を未達・列挙に無い離脱にする | 構成の単位の語で、変更の単位の例外承認に合わない |
| 回収済み・取り下げ・失効の内訳、外した基準の一覧、閾値の変更の別掲を文の型へ入れる | 長い句ほど落ちる。別掲の効きを示せない |
| 件数・期限・再承認の回数に上限を置く | 先例に上限を定めたものが見つからず、値に根拠が無い |
| 安全重要度が掛かる判定基準を、7.3 の対象外とする | **採否を決めていない(未決)**。対象の列挙と外部の調査が要る。#327 へ送る |
| 7.4 の後回しの禁止を 7.3 の一般へ及ぼす | 同上(未決) |
| 7.10 の前提の受容を件数に含める | 判定基準の不充足でなく、有効期限を別に持つ |

多数であることは、採否の理由にしていません。5 委員は閉じた列挙の扱いで一致しましたが、理由は ADR-0133 の線引きによります。

## 影響

- 「記録の欠落」の語の意味が、記録は在るが効力が無い場合へ広がった。第1章 1.4 に定義の行は置いていない。語の定義は 1.4 の全体の見直し(#328)で扱う
- 7.3 の要求事項3(影響と対処)と5(継続的な報告)の欠けを確かめる者は、本 ADR で定めていない。内部監査の観点へ新しく割り当てる案は、裁定に無い義務となるので採らなかった。確かめる者の割り当ては #355 へ送る
- 閉じた列挙(`CLOSED_DEVIATIONS`)・主張の名は変わらない。採用者には、件数の併記と、期限の管理(期限を過ぎた例外承認は記録の欠落になる)という新しい義務が加わる
- 併記の検査と、期限の比較は、準拠テンプレートに降りていない。第1章 1.10.2 と第7章 7.3 の実装マーク(IMPL-0573・IMPL-0574)で、降りていない規定として表示する。表明の様式(IMPL-0120)が降りるまで、表明する者が台帳から数えて転記する。準拠テンプレートへ降ろす分は `research/353-deliberation/implementation.md` に一覧した
- 1.10.2 と H.8 の文の型の一致を確かめる機械の検査は無い。一致は人が確かめる
- 短い引用で件数の句が落ちること、台帳に書かれなかった例外を検出できないことは、機械で閉じない。対外の文書は採用者の組織が確かめる(H.8)。件数 0 は、例外承認を使っていないことの証拠にならない
- 実証を欠く点がある。名を変えない開示が受け手の判断を変えること、失効を記録の欠落に数える定めの効き、外部の先例(ISO 9001 8.7、FedRAMP など)が二次情報であること。根拠水準マーク EV-0266(併記)と EV-0267(失効)で開示する
- 安全重要度が掛かる判定基準を 7.3 の対象外とするかは、本 ADR では決めない(#327)

## 再び検討する契機

- EV-0266・EV-0267 の差し替え条件の観測。件数の句を伴わない主張が過半のとき、期限超過の差し戻しが再承認で繰り返し解かれるとき、安全重要度 CL1 以上の案件で例外承認を安全適合性の検証に用いた事例が1件でもあるとき
- #327 の裁定(安全重要度と 7.3 の対象)
