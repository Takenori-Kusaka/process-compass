## コンテキスト

#375 の実装の後に、範囲の外として2つの経路が残りました(`research/375-deliberation/implementation.md`)。内部の調査と実行による確認(`research/434-deliberation/survey-434.md`)で、次のことが分かりました。

- 経路1: 本人以外が確認済みの、AI を示す語を含む氏名の人の記名による確認(氏名・アカウント名)は、記録の時点で受け付けられていた。数え方の関数(`confirmedNames`・`confirmedAccounts`)は、その記録を数えない。契約検査と集約は欠落として止めるが、差分は「確認した」と出し、契約検査の文は原因を言い当てなかった。AR-5 は、同じ型のうち確認待ちの本人だけを列挙していた。名簿に既にある確認の旨は、記名者が誰であれ変化点の記録へ自動で載っていた
- 経路2: 記録の無い旧い確認(#296 より前の、旗だけの確認)の人が、既存の記録(委任の規則の決定と承認、変更種別の登録)の記名者である構成では、本人以外がその氏名を確認する変化点そのものが拒否された。確認の後の構成は同じ記録を通すため、この拒否は統制を守っていなかった。1名から2名へ移る場合に限らず、旧い2名以上の構成でも起きた

経路1 は軽の会議体(起案・反対)で審議しました。経路2 は2委員の結論が割れたため、重へ上げました。重では、外部の調査(`survey-434-2-external.md`。FDA の Part 11 の指針 III.C.3、EU GMP Annex 11、MHRA の GXP Data Integrity Guidance(2018)、PIC/S PI 041-1)と5委員の会議体で審議しました。外部の4文書は、どれも後から付けた確認を元の時点の確認として数えません。後の確認は、確認した日付と確認者で記録する形を取ります。

## 決定

### 1. 後で数えられない確認は、記録の時点で拒否する(経路1)

- この変化点で明示した確認(氏名の確認の旨を書いた確認と、足したアカウント名の確認)が、記録を足した後の構成で数えられなければ、その変化点を拒否する
- 拒否の根拠は、数え方の関数そのものとする。この変化点の記録1件だけを数え方の関数に渡して照らす。拒否の条件を列挙で持たない。列挙は次の経路を見落とす(EV-0229 の開示のとおり)
- ADR-0111 決定6 の確認待ちの本人の記名の拒否(AR-5)は、この規則の特例である。拒否の文は、特例の原因を名指しする文を残す
- 名簿に既にある確認の旨(この変化点で書いたものでない確認)は、数えられない記名者の変化点の記録へ載せない。変化点そのものは拒否せず、確認を記録しない旨を注意として出す。拒否すると、記名者が書いていない確認のために無関係の記録が止まる
- アカウント名の確認も同じ規則に含める。第4章 G-6 は、氏名の確認とアカウント名の確認を同じ文で定めている
- 第4章 G-6 の氏名の確認とアカウント名の確認の規定に、「本人以外の確認が済んでいても、AI を示す語を含む氏名の人の記名は、AI の名義の記名に当たる」と書く。ADR-0079 決定7 と #296 の追加の裁定で既に数えないとされていることの明文化である
- 拒否の文は、原因(記名者の名義が AI を示す語を含むこと)と記名できる人を案内する。記名できるのは、確認される本人以外で AI を示す語を含まず、変化点より前から名簿にいる人である

### 2. 本人以外の確認の変化点に限り、既存の記録の記名者をその確認を数えた後の構成で照らす(経路2)

- 本人以外の確認を記録する変化点に限り、既存の記録の記名者を、その確認を数えた後の構成で照らす。救いの根拠は、記名の無い旗ではなく、本人以外の実在の記名である
- この照合は、その変化点の日付の独立した照合として記録する。既存の記録の時点へ日付を戻さず、遡りの効力を与えない。既存の記録は書き換えない
- 対象は既存の記録に限る。同じ変化点で追加・変更した記録(規則、変更種別の登録、規則の承認)の記名者には使わない。確認する人の資格は、変化点の前の構成で照らす(ADR-0111 決定2)
- 確認の変化点の外(本人以外の確認を含まない変化点)では救わない。そこでの拒否は残す
- 記録の無い確認そのものは、既存の記録の照合に使わない。記録の無い確認が作られた時点で効いていたことは、記録から確かめられない
- 確認の差分の行に、その確認で記名者を照合する既存の記録を列挙する。確認する人が、何を裏づけるかを見てから記名できるようにする
- 照合の結果は、ツールが変化点の記録へ自動で載せる。採用組織に新しい手順を課さない。照合の日付と記名者は、その変化点の記録の日付と記名から読む。同じ事実を2か所に持たない
- 判定の出力(D-0 の変化点の履歴)と保証の開示は、照合した既存の記録を、作られた時点の照合と区別して出す
- 確認の変化点の外の拒否の文は、原因(既存の記録の記名者の氏名の確認に、本人以外の記録が無いこと)と、本人以外が確認すれば通ることを案内する
- 到達する状態は、確認の後の構成で同じ記録が通る今の状態(survey の 2i)と同じである。統制は緩めない。確認待ちと確認の記録が無い間は、契約検査と集約が落ち続ける(ADR-0111 決定5・決定6)

### 3. 根拠水準を開示する

- 決定2 の前提「本人以外の確認は、同じ名義の過去の記名にも及ぶ」は実証が無い。本人以外の確認が保証するのは、氏名の人が実在することであり、旧い記録をその人が記名したこと(作成者の帰属)までは保証しない。外部の根拠は医薬品の GxP からの類推である
- 決定1・決定2 を支えるのは、準拠テンプレートの試作と試験の場面だけである。ほかの経路が無いことは示していない
- 根拠水準を第4章 G-6 の EV-0236 で開示する

| 1-B 列挙を足す(記名者の名義が AI を示す語を含む場合を AR-5 と同じく列挙する) | 拒否の条件と数え方が2か所に分かれる。列挙は次の経路を見落とす |
| 1-C 受け付けて開示する | AR-5 が退けた「効かない確認の記録」を残し、AR-5 と扱いが割れる |
| 1-D を明示した確認にも当てる(数えない確認を載せずに受け付ける) | 記名者は確認したつもりで、記録に何も残らない。表示と記録が食い違う。名簿に既にある確認の旨に限って採った |
| 1-A を自動で載る確認にも当てる(拒否する) | 記名者が書いていない確認のために、無関係の記録が止まる |
| 1-E 確認済みの AI を示す語を含む氏名の人の確認を数える | 数える確認を増やし、緩める向きで #296 の裁定を変える。扱うなら重の審議を要する。本件では議題にしていない |
| 2-A 今のまま(移行で確認待ちにする) | 確認の変化点の拒否(2b・2f)が残る。回避の手段は承認の記録を失う |
| 2-A' 移行の変化点で、記録の無い確認を本人の記名の記録へ書き換える | 記名していない行為を記名として書く後付けである。本人の記名を1名の名簿に限る前提と、確認待ちの印を記録へ書かない決定5 に反する。旧い2名の構成(2f)を救わない |
| 2-B 記録の無い旧い確認を、既存の記録の照合に限って有効とみなす | 帰属の無い旗に遡った効力を与える。作られた時点で2名以上の名簿だった記録(2f)では、G-6 の「作られた時点の構成で照らす」に反する |
| 弱めた 2-B(暫定の許容・証拠・是正の道筋・構成が変われば外れる) | 旗の証拠は記録から得られず、外部の型(FDA の条件)を満たせない。「構成が変われば外れる」は2人目を足す変化点そのもので外れ、何も救わない。暫定の役目は確認待ちが既に担う |
| 2-B を作られた時点の名簿が1名の記録に限る | 連鎖を持たない旧い構成で、記録の時点の名簿の人数を読めることを確かめていない。読めても根拠は記名の無い旗のままである |
| 2-C 移行を拒否して案内する | G-6 と ADR-0111 決定5(記録の無い確認も確認待ちとして受け付ける)に反する。採用組織に手順を足す。旧い2名の構成を救わない |
| 2-D(日付の照合とする条件を付けない形) | 遡りの効力を持つと読まれる余地が残る。日付の照合とする条件と開示を足した決定2 に置き換えた |
| 照合を区別する欄に、照合の日付と確認者を別に持つ | 変化点の記録の日付と記名から読める。同じ事実を2か所に持たない。照合した既存の記録の一覧だけを載せる |

## 影響

- 第4章 G-6: 氏名の確認とアカウント名の確認の規定に、確認済みでも AI を示す語を含む氏名の人の記名は AI の名義の記名に当たることを書いた。後で数えられない確認の規定を足した。既存の記録の照合の規定に、本人以外の確認の変化点の照合を足した。IMPL-0266・IMPL-0446 の注記を改め、IMPL-0472・IMPL-0473 と EV-0236 を付けた
- 準拠テンプレートの `config.mjs`: 数え方の関数そのもので照らす `nameConfirmationCount`・`accountConfirmationCounts`、照合の記録を読む `laterSignerChecks`
- 準拠テンプレートの `generate-profile.mjs`: 明示した確認の拒否と、名簿に既にある確認の旨を記録へ載せないことと注意。本人以外の確認の変化点の既存の規則と変更種別の照合(`clampSeats` を含む)。差分の列挙、変化点の記録の `laterSignerCheck`、D-0 の変化点の履歴への表示、拒否の文の案内
- 準拠テンプレートの `aggregate-evidence.mjs`: 保証の開示の項目1 に、照合した既存の記録を区別して出す
- 試験 `test-name-confirmation-timing.mjs` と回帰の試験 `suite/name-confirmation.mjs` に、経路1・経路2 の場面と否定の場面を固定した
