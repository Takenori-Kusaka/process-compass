## ステータス

採用(2026-11-17)。採用済みの ADR の決定を置き換えません。[ADR-0082](/process-compass/adr/0082-seat-combination-boundaries-and-lane-mapping/) が #328 へ送った「レーンの名とラベルの名の食い違い」に答えます。[ADR-0058](/process-compass/adr/0058-size-over-is-confirmed-not-blocked/)(担保水準)と第5章 5.4 の AI自律レベルの定義は変えません。

## コンテキスト

- [#328](https://github.com/Takenori-Kusaka/process-compass/issues/328): 独立レビュアと出荷判定者を別のレーン(Review・Ship)に置いた後も、開発者への差し戻しのラベルは `state:qm-blocked` の名のままである。ADR-0082 は名を変えずにレーンを足し、語の統一を #328 へ送った
- [#347](https://github.com/Takenori-Kusaka/process-compass/issues/347): 担保水準(L0〜L2)と AI自律レベル(L1〜L3)が同じ L の記号を使う。担保水準 L2 は行数の上限を規範から外し、自律レベル L2 は人が統合点を確かめる協働であり、取り違えると逆向きに効く
- 現行の本文は、担保水準の側に「担保水準 L1」と語を前に付けて書いている。構成の値は欄名(`task.assurance.level`)で分かれている
- 改名は、採用者が保持するラベルと構成の値(`task.assurance.level` など)の書き換えを伴う

## 決定

### 1. `state:qm-blocked` の名を変えない

ラベルの名は、開発者への差し戻しを表す。名の qm は旧い写像の名残であり、ロールを指さない([ADR-0037](/process-compass/adr/0037-label-points-to-lane-not-role/) 決定1)。第3章 3.5.1 の写像の表の下にその旨を書く。

### 2. 担保水準と AI自律レベルの記号を変えない

構成の値も変えない。読み分けは、第1章 1.4 の定義の行と欄名で保つ。どちらの量かが、同じ文、表・節の見出し、欄名から読めない所では、本標準の本文と第6章の様式は記号だけで書かず、「担保水準 L1」「AI自律レベル L1」と書く。採用者が自由に書く文には求めない。

### 3. 読み分けを機械の検査にしない

記号がどちらの量を指すかは、文の意味の判断であり、決定可能な条件ではない。本標準の執筆と査読で確かめる(manual)。

## 検討した選択肢

| 案 | 採否 | 理由 |
| --- | --- | --- |
| `state:qm-blocked` を改名する | 採らない | 採用者のラベルの付け替えを新しい義務として課す。誤読の被害は新しい担当者の読み違いにとどまる |
| ADR-0037 を置き換え、ロール略号をラベル名から除く原則で改名する | 採らない | 同上。原則の変更に見合う被害の記録が無い |
| 担保水準の記号を改める(水準 0〜2 など) | 採らない | 採用者の `task.assurance.level` の移行を要する。旧い値を拒めば構成が止まり(ADR-0028)、受け付ければ二重の語彙を抱える。根拠の無い担保水準 L2 は機械が通さない(第4章「レビュー可能性の担保水準」)ので、取り違えの被害は有界 |
| AI自律レベルの記号を改める | 採らない | 本文・規則データ・知識ベース・準拠テンプレートの全体と、5.4 を前提にした多数の決定に及ぶ |
| 両方を改める | 採らない | 利点が一方の改名に勝らない |
| 注記も記録もしない | 採らない | ADR-0082 が公開の記録で送った論点が閉じない |
| 記号だけの記述を機械で検出する | 採らない | どちらの量かは意味の判断で、文字列の条件では誤検出と見逃しが出る |

:::caution[暫定 EV-0287 / 見直し 2027-05]
**対象**: ラベル `state:qm-blocked` の名と L の記号の衝突は、定義の併記と欄名で取り違えを防げ、改名の移行の負担に見合う被害は無いという判断(決定1・2)。
**根拠の水準**: E0(なし)。
**差し替え条件**: 名または記号の取り違えによる誤った引き渡し・誤った規模の扱いが、採用者または本標準の記録で1件観測されたとき。改名を重の審議で検討し直す。
:::

## 影響

- 本文: 第3章 3.5.1 の箇条に1文、第1章 1.4 に担保水準の行と AI自律レベルの行の書き方を足す
- 準拠テンプレート・規則データ・構成の値: 変更なし
- 旧称の検査(`retiredPhrases`)と異表記の検査: 登録なし(名を変えないため)

## 見直しの契機

- EV-0287 の差し替え条件に当たる取り違えが記録されたとき
- 3つ目の体系が L の記号で始まる記号を持とうとしたとき
