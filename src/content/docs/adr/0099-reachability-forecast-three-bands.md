## コンテキスト

[#415](https://github.com/Takenori-Kusaka/process-compass/issues/415) は、#407 / ADR-0093 の会議体の起案の委員が残した論点です。調査(`research/415-deliberation/survey-415-*.md`)と、起案・現場・品質監査・規格・弁護の 5 委員の会議体(`research/415-deliberation/`)を経ました。

### 見つかったこと

- 比べる値を決める前に、判定の入力が無かった。必達基準2 の「到達に要する見積」を、誰が・いつ・どう作り・どこへ記録するかが決まっておらず、要求として検証できなかった。7.7.9 の見積りは G-1 の時点の案件全体の値で、テンプレ4 にあるのは見積りと実績の差だけだった
- 様式は見積りの幅の両端しか書かせず、中央の値は無かった。7.7.9 の要求事項11(上側を示す)は提示の規定で、判定に及ぶかが書かれていなかった
- 期間は、2.10.6 が実測スループットによる見込みで評価する体系を持っていた。必達基準2 の「見積」とこの見込みの関係は書かれていなかった。7.6 の「超過の見込み」と必達基準2 で、別の値が使われうる。第 3 巡で、これは欠陥ではないと判断した。7.6 は全層の計画からの逸脱を測り、必達基準2 は SC-M の到達を測るためである(決定4)
- 準拠テンプレートの企画書の中止条件に、必達基準を具体化する注記が無かった。SG の補助ファイルに、必達基準ごとの材料の手順が無かった
- 外部: 計画・管理は P50、外部への約束・資金枠は P70〜P90 という二層が一次資料で確立している(英国 IPA の Cost Estimating Guidance 7.4・7.5、NASA の JCL 70%、HM Treasury Green Book)。中止・継続の判定で単一の分位点と比べよと定めた一次資料は無い。英国 IPA 7.8 は幅の全体を負担できる額と比べ、悲観側が超えれば負担不能の公算が大きく、楽観側が下回れば負担可能の公算が大きく、間に入るときは決定者が措置を決める。NASA の法定の引き金はベースラインからの超過率である。サンクコストによる継続の偏りへの処方は、フィードバックの前に判定の値を数で決めておくことである(Simonson & Staw 1992)

## 決定

### 1. 必達基準2 は、ステージの途中の判定で、観測から算定する到達の見込みで判定する

- 判定の契機は、7.7.4 の上程、7.7.6 の棚卸し、7.7.5 の再判定と、SG の後に到達の見込みを初めて算定できた時点(新しいステージの観測の窓に単位期間が 3 つそろった時点)とする。最後の契機は、SG で判定しないことの代わりに、新しいステージの最初の判定を早く置くためである
- 比べる対象は進行中のステージの未完了の SC-M、比べる残りは直近の SG、または必達基準2 の判定(会議体)で記名して確定した期日までの期間と、期間予算・要員予算の配賦の残りとする。それ以外の増額と延長(7.6 の段階2 の決定を含む)では基準を動かさず、次の必達基準2 の判定までは元の基準と比べる(第 4 版の突合 H4-1)。保留の後は、保留で定めた再判定の期限までを残る期間とし、保留で作業を止めた単位期間は窓から除いて記録する
- 判定する者は B-2(置かない体制では事業決裁者。7.7.4 で B-1 へ上がる場合は B-1)とする。SG の後の最初の算定の判定の期限は、算定の記録から B-2 の判定期限とする 7.7.6 の棚卸しでは、点検の実施者の結果を受けて B-2 が判定する。契機の外の判断は、必達基準2 の判定として 7.7.5 に数えない
- 期間の見込みは、比べる対象の作業単位の個数 ÷ 実測スループットとする。スループットは全層の完了で数えるため、SC-M を先に完了させる前提の値である。費用の見込みは、期間の見込み × 単位期間あたりの費用の実績 + 確定済みでまだ発生していない支出とする
- 比べる組は期間・期間予算・要員予算の 3 つ。AI 実行予算と基盤予算は 7.7.4 と必達基準3 による
- 区分の算定は 7.7.2 の期ごとに行い、2.10.6 の見込みの報告の Issue に置く。集計と算定は D-0 表1 の担い手に任せてよい。乙・丙の期の記録は価値責任者へ届ける。観測の窓は SG で区切る。7.7.4 は直近の記録の区分を読む。会議体(B-2 を置かない体制では事業決裁者)が判定するときは、価値責任者が記名した記録を判定記録の節「到達の見込み」に書く
- S0 の初回は「対象外(SC-M なし)」、窓の中の単位期間が 3 つに満たない間は「算定できない」と記録する。どちらも合格・不合格のどちらとしても扱わず、7.7.5 の回数に数えない
- ステージの途中の判定で到達の見込みの記録が無ければ、必達基準2 を満たさない

### 2. SG では必達基準2 を判定しない

- 次ステージの計画の大きさは 2.10.1(SC-M は計画容量の 60% 以下)と 2.10.2(実測スループットに対する件数で合意)が、予算は 7.7.1 と 7.7.9 の要求事項11 が受け持つ。終わるステージの SC-M の完了は SG の判定基準(2.4)が問う
- SG は、未解消の必達基準2 の不合格を消さない。不合格と 7.7.5 の回数を判定記録に書いて引き継ぐ。SG の判定は 7.7.5 の回数に数えない(第 4 版の突合 M4-2。終わったステージの不合格で回数を余計に消費し、上限に達した後の SG で、移行と継続のどちらも選べなくなるため)。再判定の期限は、次のステージで到達の見込みを初めて算定できた時点とする

### 3. 単一の分位点を規定せず、両端と残りを比べる 3 つの区分で判定する

| 区分 | 状態 | 必達基準2 |
| --- | --- | --- |
| 甲 | 遅い側(費用は高い側)の端でも、残りに収まる | 合格 |
| 乙 | 遅い側の端は超えるが、速い側の端は収まる | 不合格 |
| 丙 | 速い側の端でも超える | 不合格 |

- 区分は値から定まる状態であり、判定者は書き換えない。区分の規則は本標準が定め、置き換えを認めない
- 組ごとに区分を記録し、最も悪い区分を案件の区分とする。算定できない組がある場合は、算定できた組に乙・丙があればその区分とし、無ければ「算定できない」とする
- 丙のまま継続と判定する場合は、SC-M・予算・期日のいずれかを同時に変える判定を要する
- 幅の端は、観測の窓の単位期間ごとの完了スループットの最小値と最大値から出す。単位期間の長さは 2.10.2 の要求事項4 の記録による。完了が 0 の単位期間を除かない。最小値が 0 なら遅い側の端は残りを超える。第4章の最小標本数は用いない
- この端の取り方は既定値とし、G-1 か SG で事業決裁者が記名し、中止条件の欄へ記録した場合に限り置き換える。置き換えは次のステージの途中の判定から効く。遅い側の端を観測の中央値より速くしない
- 様式に中央(P50)の欄を足さない
- 区分の判定は EV-0200(E1)、端の既定の取り方は EV-0201(E0)で開示する

### 4. 連動する規定

- 7.6 は ADR-0095 のまま変えない。7.6 は全層の計画からの逸脱を、必達基準2 は SC-M の到達を測るので、2 つの値が違うことは食い違いではない
- 2.10.6: 乙・丙の期の記録は、価値責任者の評価の材料にする。乙・丙をもって 7.6 の起票を決めない(第 3 版の突合 H3-2。区分は SC-M の到達を測り、SC-B・SC-P を削る手順1 で動かないため)
- 7.7.4 の「必達基準に不合格がある」は区分の乙と丙を指す
- 7.7.5 の要求事項4: 案件の中で必達基準の番号ごとに通算し、数え直さない。必達基準2 は、乙・丙のときの継続と保留を 1 回と数える。SC-M の縮小だけで甲に戻した継続は数えない(縮小の累計は 7.6 の SC-M の変動が拾う)。予算の追加か期日の延長を含めて甲に戻した継続は数える(EV-0202、E0)。乙・丙での保留にも要求事項1〜4 を適用する。判定記録に通算の回数、変更の後の区分、延長・増額の累計を書く
- 7.7.9 の要求事項11 は提示の規定であり、判定の入力にしない。両端と残りを比べることは要求事項6 の禁止の対象ではない
- 様式: テンプレ4 の節「到達の見込み」(IMPL-0378)、企画書の中止条件の注記(IMPL-0379)、SG の補助ファイル(IMPL-0380)。期ごとの算定(IMPL-0377)と、ステージの途中の判定記録の検査(IMPL-0381)は降りていない

### 5. 経緯: 第 1 巡・第 2 巡の裁定の撤回

最初の裁定は、SG の時点で「当該ステージ」と「残り」を定めておらず、S0 の初回で必達基準2 が常に甲になることも見落としていました(`crosscheck.md`)。第 2 巡は SG の判定の表と「SG で甲でない計画を確定しない」を置き、7.6 を同じ見込みの遅い側の端で測るとしました。第 2 版の突合(`crosscheck-2.md`)で、これらの組み合わせから 4 つの矛盾が見つかりました。SG-0 の読みが割れること。最小値 0 と甲の要求が重なって行き詰まること。区分を見てから端を選び直せること。7.6 の段階1 の吸収が値に表れず、発火がすべて段階2 へ流れること(ADR-0095 が採らなかった帰結)です。第 3 巡で、必達基準2 をステージの途中の判定に限り、SG と 7.6 から外しました。

| SG で不合格を持ったまま継続・移行する判定を 7.7.5 の回数に数える | 第 3 版の突合の後の訂正 | 第 4 版の突合(M4-2)で撤回。上限に達した後の SG で選べる判定が無くなる |
| 7.6 の判定で確定した期日と配賦でも比べる残りの基準を動かす | 第 3 版の突合の後の訂正 | 第 4 版の突合(H4-1)で撤回。事業決裁者の単独の決定で B-2 の判定の基準が動き、延長が 7.7.5 に数えられない |
| 端を、残る期間と同じ長さの連続区間の完了件数の最小・最大で取る | 規格(第 2 巡) | 採らない。計算が重く、記録から人が再計算しにくい |
| 7.7.5 の要求事項4 を改訂前に戻す | 弁護(第 2 巡) | 採らない。乙と丙を合わせて数えることと、算定のやり直しで数え直さないことを失う |
| 甲に戻ったら、1 期以上の観測の後に数え直す | 規格(第 2・3 巡) | 採らない。甲と乙を往復する計画で上限に届かない |
| SC-M を削り、確定した値を超えない残りで甲になったときだけ数え直す | 品質監査(第 2・3 巡) | 採らない。数え直しを置かない通算で足りる |
| SG で、終わるステージの到達の実績を必達基準2 の区分で記録する | 品質監査(第 2 巡) | 採らない。終わるステージの完了は SG の判定基準(2.4)が問い、未完了の個数は「見積りと実績の差」に書く |
| S0 の初回に、期間と予算を打ち切りの枠として SG-0 の判定を求める | 現場(第 2 巡) | 採らない。7.7.4 の消化進捗比と 7.6 が受け持つ |
| 予算の増額や期日の延長を禁じる | 検討 | 採らない。延長と増額は正当な判定であり、7.7.5 の回数で上限を掛ける |
| ADR-0093 への追記で済ませる | 検討 | 採らない(品質監査)。採用済みの ADR は書き換えない |

### 本件で決めないこと

- 7.6 の見込みの端の取り方
- 計画容量の算定に使う実測値の取り方を、SG の前に固定すること(品質監査)
- 終わるステージの未完了の SC-M の扱い(未完了の個数は「見積りと実績の差」に書く)
- 必達基準1・3〜5 の判定の材料の様式
- 10 名以上の体制で、チームごとに作業単位の定義が違う場合の見込みの合算
- 委託が主の案件の見込み(#414)

## 影響

- 第7章 7.7.3(必達基準2 と到達の見込みの規則、IMPL-0377〜0381、EV-0200・EV-0201)、7.7.4(不合格の意味)、7.7.5 の要求事項4(回数の数え方、EV-0202)、7.7.9 の要求事項11。7.6 は変えない
- 第2章 2.10.6(到達の見込みの記録を評価の材料にする)
- 第6章 テンプレ4(節「到達の見込み」)、テンプレ6(中止条件の注記)
- 準拠テンプレート: 判定記録の様式、企画書の様式(本体と 3 つのプロファイル)、SG の補助ファイル
- 遅い側の端で判定するため、到達できたはずの案件を不合格にすること(偽の不合格)が増えうる。乙は 7.7.5 の継続で受け、件数を EV-0200 の差し替え条件で観測する
- SG では必達基準2 の検査が消える。SG で 60% 以内に確定した計画が最初の算定で乙・丙になる件数と、必達基準2 が乙・丙なのに 7.6 が発火しなかった期の件数を、EV-0200 の差し替え条件で観測する
