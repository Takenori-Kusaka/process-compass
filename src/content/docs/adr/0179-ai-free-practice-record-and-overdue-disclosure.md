## ステータス

採用(2026-11-17)。[ADR-0178](/process-compass/adr/0178-scope-procedure-records-backlog-review-and-ai-free-practice-frequency/) の未決の節を解く。重の審議の結論です(Issue [#447](https://github.com/Takenori-Kusaka/process-compass/issues/447)、`research/447-deliberation/decision.md`)。所有者の決定(2026-11-17。案 イ)による。準拠テンプレートの変更は本件に含めない。

## コンテキスト

- 5.4.7 は登録した変更種別にも掛かる。しかし実施記録を照らす時点は 5.4.5 の条件5 だけで、準拠テンプレートの採用者が通る登録の経路に証跡が無かった([ADR-0178](/process-compass/adr/0178-scope-procedure-records-backlog-review-and-ai-free-practice-frequency/))
- 所有者は、案件側に常時の実施の記録を課し、層1 の頻度を過ぎたら保証の開示の項目7 に表示する案(案 イ)を選んだ。止めない
- 第3章 3.4.3 の「研究が無い」は日付の無い断定だった。時点つきの「確認できていない」に改めた(編集の扱い)。[ADR-0057](/process-compass/adr/0057-organizational-quality-assurance/) の同じ文は採用済みの本文なので触らない

## 決定

1. L2 以上を適用する範囲で AI を用いずに対象領域を実装または調査したときは、実施した日・対象領域・実施者を D-0 の「AI を用いない実施の記録」(表7 の下の「AI自律レベルの適用」の直下)へ人が追記する。必須はこの3点だけ。追記は変化点に数えず、構成から生成しない(3.13.2)。5.4.5 の条件5 の「実施記録」はこの記録を指す
2. 保証の開示を作る日に、範囲ごとに記録と層1 の頻度を照らし、頻度を定めていない(空欄・1回あたりの期間の長さとして読めない値)、記録が無い(猶予なし)、頻度を過ぎている、を項目7 に表示する。止めない。組織継続の側の状態に含めず、受容を求めない
3. 経路(5.4.5 の引き上げ・5.5.4 の登録)を問わず同じ記録と表示で照らす。本節(5.4.7)は登録の判定者に務めを足さない。5.4.5 の「兼ねる」は、所有者の回答(2026-11-17。議長の裁定として扱う)で条件2〜7(条件5 の実施記録を含む)に及ぶと読みを固定した。登録の判定の時点で条件5 の実施記録を照らす務めは、5.4.5 の条件5 が持つ。5.4.7 の常時の記録と表示は、それと並んで続く(#340 の登録の経路の分を閉じる)
4. 機械が確かめるのは行の形式・範囲の名と人の名簿との一致・日付の比較まで。実施の中身と実施の事実は確かめない(manual。確かめる者はいない。EV-0322)

## 課さないと決めたこと

- 頻度の値、頻度の書式の指定
- 記録の所在・中身・確かめた者、本人以外の確認
- 頻度切れ・記録なしでの出荷・登録した変更種別・引き上げた範囲の停止
- 頻度を満たせない期間の第7章 7.3 の例外承認
- 5.4.7 が新たに、登録の判定(B-4)へ実施の記録を照らす務めを足すこと(登録の判定の時点の照らしは、読みを固定した 5.4.5 の条件5 が持つ。本節が足したものではない)

## 検討した選択肢(採らない)

| 案 | 採らない理由 |
| --- | --- |
| D-0 の外の新しい様式(品質監査) | 3.4.3 冒頭の立場と食い違う。変化点の懸念は 3.13.2 の行で閉じる |
| 表5 の下の力量の確認の表へ欄を足す、または隣に置く(現場) | 単位と目的が違う。片方で他方を満たしたと読まれる |
| 置き場を降ろし先に任せる(規格) | 対象領域の一致を照らす相手が定まらず、決定可能にならない |
| 記録の所在を必須または任意の欄にする(現場・品質監査) | 所有者の3点を超える新しい義務。中身を確かめられないまま閉じたように見せる。限界は EV-0322 で開示 |
| 記名の申告(「AI を用いずに行った」)の固定文 | 真偽を確かめられない申告を増やすだけ。記録は申告であると条文に書く |
| 確かめた者(本人以外)を課す | 機会の確保は確認ではない(3.4.3 要求事項2 とは水準が違う)。1〜2名の体制で満たせない。全委員が一致 |
| 実施の時間・件数・内容・成果物の水準 | 件数は能力の代理指標にならない。手順の混入 |
| 人ごとに頻度を照らす | 5.4.7 は「対象領域について」で、個人の義務を課していない |
| 適用の開始から1期間の猶予(現場・弁護) | 3.4.3 の先例と食い違い、2つ目の日付が要る |
| 頻度の内も値・最終実施日・実施者数を出す(品質監査) | 所有者の決定を超える新しい表示。人数の基準が無いので判定の材料にならない。代わりに「表示が出ないことも技能の維持を示さない」を条文に書く |
| 実施者が本人だけの注記(現場) | 新しい表示。1名の体制は別の表示で既に開示している |
| 遡及の追記を「遡及」と併記する(品質監査) | 追加の日を履歴から取る新しい判定。閉じない |
| 「読めない」を独立の状態にする(品質監査) | 値の併記で足りる。状態を増やさない |
| 頻度を「数+単位」「Nか月」に限る(現場・品質監査・弁護) | 層1 の表の中で規則が割れる。例を変える必要が無い |
| 頻度の値・既定値を本標準が定める | 3.4.3 の決定を維持。**課さないと決めた**(全委員一致) |
| 頻度切れ・記録なしで出荷・登録した種別・引き上げた範囲を止める | 止める規定を持つ領域(航空の規則・原子力)は数値の根拠と許認可の拘束力を併せ持つ。ADR-0081 の停止の列挙を変えない。**課さないと決めた** |
| 表示を組織継続の側の状態に入れる | 受容の期限切れが記載の欠落(G-7 基準9)となり、差し戻しを通じて実質的に止める。「止めない」と食い違う |
| 頻度を満たせない期間を 7.3 の例外承認で受ける | 表示を消す手続になる。表示は事実の開示。**課さないと決めた**(ADR-0178 から維持) |
| 登録の判定者(B-4)に実施の記録を照らさせる務めを、5.4.7 が新たに足す(案 ウ) | 所有者が選んでいない。登録の判定の時点の照らしは、読みの固定(5.4.5)による別の根拠で在る |
| 5.4.5 の条件5 に「最後の実施が頻度の内」を足す(品質監査が挙げて退けた案) | 引き上げの判定に新しい条件を足す |
| 5.4.5 の「兼ねる」の読みを固定しない(重の審議の初めの結論。品質監査・弁護。#340 へ返す) | 所有者の回答(2026-11-17)で固定した。採らない |
| 「兼ねる」を兼ねないと固定する(起案・現場)、条件1・6・7 に限ると固定する(規格) | 所有者の回答で、条件2〜7 に及ぶと固定した。採らない |
| L1 を含む全範囲に記録を課す | 5.4.7・3.4.3 の適用範囲を変える |
| 演習・力量の確認の記録を自動で数える | 対象領域と AI の不使用が記録から読めない。表に行として書いたものだけを数える |
| 成果の指標(欠陥率・口頭弁護)で代える | 実施の有無を照らせない。G-6 の挙動要約と 3.4.3 の力量の確認が別に持つ |
| 3.4.3 に「AI 支援が技能の形成を下げうる研究は在る」の句を足す | 原典を全文で読んでおらず、出典台帳に無い。登録してから書く |
| 項目7 の出所の列(assurance-case 581 行・gate-criteria 1727 行)に D-0 の実施の記録を足す | 項目7 の出所の列には、既にある 3.4.3 の「未確認・失効」と層1 の「演習の頻度を定めていない」の表示も載っていない。5.4.7 だけを足すと、列挙の一部に見えて残りが漏れていると読まれる。列を網羅にするかは別の編集の指摘 |
| `ai-free-practice-record`(予定の降ろし先 `docs/capability-maintenance/`)を残す | 置き場を D-0 に決めたので、指す先が無くなる。消す |

## 影響

- 変えるもの: human-ai-boundary(5.4.5・5.4.7)、roles-responsibilities(3.4.3・3.13.2)、deliverable-templates(D-0 の説明と様式・テンプレ11 の行)。IMPL-0978・0777・1020・1021 の note、IMPL-1022・1023、EV-0322・0322 も変える。impl-targets.yaml、impl-inventory.yaml、implementation-marking.md も合わせる
- 準拠テンプレート(template)の D-0 の表・テンプレ11 の行・集約の表示は本件で触らない。IMPL は降りていない規定として台帳に表示し続ける
- 機械で閉じない点: 実施の中身・実施の事実(manual)。機械にできるのは IMPL-1022・1021 の存在・一致・日付の比較(決定可能)
- 本件の採用の日に既に登録した変更種別がある採用者には、最初の保証の開示から「AI を用いない実施の記録が無い」が出る(猶予なし。EV-0323)
