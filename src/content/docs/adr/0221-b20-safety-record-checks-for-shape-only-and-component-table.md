## ステータス

採用(2026-11-18)。束 B20 の重の件のうち、IMPL-1007・IMPL-0925・IMPL-0927・IMPL-0934・IMPL-0759 の決定です。

## コンテキスト

- G-7 基準7 の機械の部分は「確かめていない」でした。F.7 の記録は様式 09 に置き場があるだけで、空欄のまま出荷できました
- 安全の件であるため、検査を通ったことを「安全を検証した」と読ませない。機械で閉じるのは記入の形までである
- 有償規格の本文は読んでいない。規格に先例が無い点は「本標準が足す」と書く。SRC-0763 は改訂案で、制定版との一致は未確認である

## 決定

1. **項目数は 6**。F.7 の表が6行である。様式 09 の条件つきの4行(安全関連ソフトウェアの区分・実行時の不変条件の確認・監視の実装・生成された行の検証)は機械で見ない
2. **検査の置き場**は `scripts/gate/check-safety-record.mjs`。適用は、D-0 表10 の Q1 が「はい」の案件と、CL2・CL3 の案件(記録の区分と構成の回答の高いほう)。D-0 が無いとき、Q1 を読めないときは、適用として扱う。適用外のときは「適用外(Q1 いいえ・CL0/CL1)」と出す。空欄に数える値は、セル全体が一致するときだけである。理由を添えた「なし(…)」は通る。G-3 の検査と違い、「不明」「TBD」を通さない
3. **基準7 の出力**は「記載の欠落の検査のみ。内容の妥当性は確かめていない」と同じ行に書く。通ったことは、安全の検証が妥当であることを示さない
4. **故障挿入の環境(IMPL-0925)**は「試験台の実機」「模擬環境」「専門部門の設備」の識別つき(例: 模擬環境(HIL-2))か「実行前の挿入」に限る。語彙は新設せず、F.7 の3種に F.5 の分類の語を足すだけである。種別だけ・3種でない語・種別の併記・空欄・括弧を2組持つ形は欠落。前方一致で通さない。識別の欄の語の意味は見ず、「模擬環境: 本番と併用」のように識別の欄へ書かれた併用は機械では落ちない(確かめる者: 独立した評価者と G-7 の判定者)。禁止語の一覧は採らない(重の裁定 9 節)。例外承認の ID は環境の欄で受けない(F.5 が 7.3 の対象にしないため)。本番でないことは機械で閉じない
5. **結果の欄(IMPL-0927)**は試験項目の7行すべてで「一致」「不一致」で始める。省く場合は `例外承認: <行の ID>`(技術負債台帳の区分「例外」の失効していない行)。**その行の対象の欄は、語「基準7」(「基準 7」を含む)か「安全関連部の検証の記録」を含むこと。含まなければ記載の欠落に数える。語の有無だけを機械が見る。対象の文が当該の項目を正しく指すか、省く理由が妥当かは機械で閉じず、独立した評価者と G-7 の判定者が確かめる**。「該当なし(時間窓なし)」は通さない。F.5 は項目2 を省いてはならないと定める。時間窓を持たない単純な監視は「不一致(時間窓なし。早い応答を通す)」と書く。新しい免除は作らない
6. **手法の表(IMPL-0934)**を様式 09 に足す(手法・推奨度・出典・適用・しない理由)。表が無い、0件、推奨度・出典・適用の空欄、適用の値の誤りを欠落に数える。HR で始まる推奨度の行は、適用が「しない」で理由が空欄でも欠落に数える。**規格の表は転載しない**(標準と様式のどちらにも置かない)。推奨度は記入者の申告である。HR を R へ書き換えること、HR の行を表から外すことは機械で閉じない。出典の表との突き合わせは独立した評価者が行う(manual)
7. **構成要素ごとの判定(IMPL-0759)**を全 CL に求める(1行で足りる)。区分は低減の後の区分を書く。判定が表の最大より低ければ記録の不備(G-1 の前は D-0 の検査が失敗し、以後は出荷の記載の欠落)、高ければ注意。表が無い・0件・区分を読めないも不備。既存の案件の D-0 に表が無いと、次の検査で不備になる(移行の注意)。列挙の十分さは機械で閉じない(確かめる者: 判定の確認者)
8. **機械で閉じない点の開示**: 内容の妥当性、環境が本番でないこと、試験の実施、推奨度の正しさ、構成要素の列挙の十分さ。いずれも manual とし、確かめる者をマークに書く

## 課さないと決めたこと

- 様式の10行を必須とすること(条件に当たらない案件を落とす)
- 内容の妥当性・記入量の閾値を見ること(第5章 5.7.4 に反する)
- 規格の HR の総数を書かせて行数と比べること(総数も自己申告で閉じない)
- 推奨度の値域を規格ごとに検査すること(規格の表を持つことになる)
- 本番・稼働中の語を禁止語にすること(「本番と同型の試験台」を落とし、言い換えで抜けられる)
- 構成要素の表を CL1 以上か Q1「はい」に限ること(低く判定した案件ほど検査を受けなくなる)
- 判定と表の最大の等号の一致(安全側の判定を落とす)

## 検討した選択肢(採らない)

| 案 | 採らなかった理由 |
| --- | --- |
| 様式の版を記録に持たせ、旧版は警告にする(現場) | 様式の文が変わると旧い記録は初期の文と一致せず、欠落に数えられない。懸念の場面が起きない |
| 「稼働中のシステムではない」の記名の1行を足す(現場) | 新しい欄の義務になる。確かめる者は既存の独立した評価者で足りる |
| 本番でないことを機械で確かめたと表示する | 機械で閉じるのは形までである |
| 監視タイマを持たない構成の免除(現場) | 条文に無い免除の新設になる。第7章の例外承認で受ける |
| 項目2 だけを検査する(弁護) | 他の項目で「省略」が通る |
| 対象の照合を足さず、IMPL-0927 の note と EV-0334 の開示だけにする(議長の初案。案 A) | 別のゲート・別の対象の例外承認の行を流用して、故障挿入の全項目を省ける穴が残る。破られたとき失うのは安全関連部の適合の主張の信頼であり、所有者の方針(2026-11-16)の (3) に当たる。所有者が採らないと決めた |
| 対象に試験項目の番号まで求める | 語の組み合わせの検査は細かい定義を増やし、番号の対応の正しさは結局人が見る。語の有無までを機械にする |
| 黒名簿を広げる | 語の一覧が閉じない |
| 1行の表に根拠を要求する(監査) | 文の意味の判定になる |

## 根拠水準

- EV-0296 を更新(E0): 検査が見るのは記入の形だけで、本番でないことを保証しない
- EV-0334(E0、IMPL-0927): 項目を名指しして省略を禁じる判断。規格に先例は確かめられていない
- EV-0335(E1、IMPL-0934): 推奨度と行の網羅が記入者の申告に依る
- EV-0336(E0、IMPL-0759): 構成要素の列挙の十分さが機械で閉じない
- 見直しはいずれも 2027-05
