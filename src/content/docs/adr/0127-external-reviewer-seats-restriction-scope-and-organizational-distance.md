## コンテキスト

[#357](https://github.com/Takenori-Kusaka/process-compass/issues/357) は、外部の確認者の席の限定、確認者の力量の記録、2名必須の制限、段2 以上の照合、受託の価値責任者と任免の決定者、観点6 の所見、名簿の未知の欄の扱いを扱いました。新しい義務と ADR の原則の変更を含むため、重の審議(5 委員)で決めました(`research/357-deliberation/decision.md`)。

内部の調査と外部の調査(`survey.md`・`survey-external.md`)で、次のことが分かりました。

- 3.5 は(イ)の外部の確認者を独立レビュアの席に限るが、準拠テンプレートは他の席の責任者に外部の確認者を置く構成を拒まなかった
- (イ)の3条件の適用が「3名未満」に限られていた。このため、3名以上の体制の条件が3名未満より緩い逆転が生じていた
- 3.4.1 の力量の確認と書面の合意を置く欄が構成に無く、3.4.3 の `competence` は別の要求を満たす記録であった
- 7.9 の制限は範囲を持つが、準拠テンプレートは発動の記録から範囲を捨てていた
- 外部の規格・実務に、人の属性(上長・部門・法人)の自己申告から独立を「満たす」と判定する例は無い。構成から導ける反証だけが決定的に判定できる
- 疑義応答集は、発注者が特定の者を指名・就業を拒否することを、配置の決定への関与とされる例として挙げている

## 決定

### 1. 外部の確認者を責任者に置ける席の限定を降ろす

- 独立レビュア以外の席の責任者に `external: true` の人を置く構成を、`namingProblems` で拒む。変化点の入口・契約の検査・出荷の証跡の集約(記録の欠落)の3か所で効く。任命権者を席に置かない既存の拒否と同じ層である(IMPL-0463)
- D-0 表1 の決定者は席(`governance.structureDecider`)で表されるため、外部の確認者が表1 の決定者になる経路も同じ拒否で塞がる。表1 に席を介さない氏名を書く経路は、準拠テンプレートに無い
- 区分を「体制の内」へ改める変化点は、既存の記名の規則による。当人の記名の扱いは、特別に緩めず、締めもしない。区分の訂正と回答 `q-team-size` の訂正は、1つの変化点で行える。猶予の期間は置かない
- 拒否の文言は「受託で発注側に置く席の人も、体制の内(`external: false`)として載せる」を名指す
- 新しい義務: 無し(3.5 の採用済みの条項を降ろす)

### 2. 3名以上の体制でも(イ)を認め、3条件を人数によらず掛ける

- 3.5 は、(イ)の3条件の対象を、「外部の確認者が独立レビュアの席の責任者である体制(規模によらない)」と明記する。(ア)(イ)の表と「既定は(ア)」の適用は、「3名未満の体制」のまま残す
- 3名以上の体制で(イ)を採ると、その体制の G-6 は外部の確認者が担う。外部の確認者は体制の人数に数えないため、3名の境界の判定は変わらない
- 新しい義務: あり(3名以上で(イ)を採る採用者に3条件)。EV-0253 を新設する

### 3. (イ)の条件の記録を、3.4.3 の competence と別の欄で降ろす

- 力量の確認(3.4.1)は、名簿の人の行の `reviewCompetence: { confirmedAt, confirmedBy, record }` に置く。`seats[].competence` へは流用しない
- 書面の合意は、独立レビュアの席の `agreement: { at, record }` に所在だけを置く。本文は構成へ写さない
- 外部の確認者を独立レビュアの席の責任者に置く変化点は、両方の記録が無いと拒む
- 既存の構成で記録の無いものは、出荷の証跡の集約で記録の欠落とする。3条件は ADR-0060 から条項であり、新しい要求ではない。G-6 の状態(`required`)は変えない
- (イ)に暫定任命の経路を開かない。暫定任命は確認済みの者による併記を要し、(イ)を要する体制には併記できる者がいない
- 機械が確かめるのは記録の有無、確認した者が本人でも AI の名義でもないこと、確認日の形まで。力量と合意の中身は確かめない(IMPL-0116)

### 4. 席の責任者でない確認者の力量と、件数・区別の出力を降ろす

- 独立した人の確認として数えた承認ごとに、承認者の名簿の行から `reviewCompetence` を引く
- 出荷の証跡の集約は、保証の開示の項目1 に2つの件数を出す。「力量の確認の記録が無い確認者による確認」と「依頼した本人による確認」。出荷は止めない(3.4.1)
- 「依頼した本人による確認」は、承認した者の `reviewCompetence.confirmedBy` が、その変更の作成を指示した者と同じ人である確認と定義する。3.4.1 に「確認を依頼した本人(その変更の作成を指示した者)」と明記する。作成を指示した者を依頼した本人とする等式を、条項に書く。確認者に申告の印を書かせない(IMPL-0117)
- 新しい義務: 無し(3.4.1 は採用済み)

### 5. 2名必須の制限を記録し、集約で確かめる

- 種別 notice の `event: "restriction"` に `restriction: { id, person, paths, basis, recordedBy }` を必須にする。解除は `event: "restriction-release"`。`recordedBy` は名簿の自然人(7.9.6 の品質保証の機能)。期限の欄は置かない(7.9.3)
- 出荷の証跡の集約は、解除されていない制限の範囲に触れる変更で、独立した人の確認に数えた承認が2名に満たないものを、独立した人の確認に数えない。数え方は 7.9.2 の字義(範囲の変更はだれが承認しても独立レビュア2名)を正とする。これは ADR-0067 決定2 の目的(対象の人の承認を単独で数えない)を含み、より厳しい
- 強制する承認の数(`reviewersRequiredOf`・ブランチ保護)には入れない。ADR-0088 決定6 を保ち、範囲の限定を全 PR へ広げない
- 7.9.6 に「発動と解除は人が記録する。記録された制限を出荷の証跡の集約が照らすことは、機械による発動に当たらない」を足す
- 範囲の無い旧い発動の記録は、集約が「範囲を判定できない制限」として保証の開示の項目1 に出し、範囲を記録し直す変化点を案内する。欠落にはしない。範囲を捨てたのは準拠テンプレートであり、採用者の記録の欠けではない
- 帰結: 準拠テンプレートの集約は、G-6 を適用する体制(G-6 が required か simplified で、未達でない体制)でだけ制限の範囲を照らす。範囲に触れたか(変更のパスが範囲に当たるか)は決定可能な条件なので、G-6 の適用に依らず数え、保証の開示の項目1 に「範囲に触れた変更 N 件」と出す。G-6 が未達の体制では、2名を要する扱い(数えない扱い)にせず、数えなかった変更の件数は出さないと表示する(0 件とは出さない。第2巡の高の直し)。G-6 を適用する体制のうち、1〜2名の体制は2人目の独立レビュアを置けないことが多く、範囲の変更は記録の欠落になる。この場合の扱いは、既存の例外承認(7.3)に委ねる。条項は変えない(IMPL-0118)

### 6. 段2 以上は名簿から導かず、記録の段を比べ、構成から導ける反証だけを機械で拾う

- 名簿に直属の上長・部門・法人・リリースの権限の欄を足さない。値は自己申告で異動のたびにずれ、属性から独立を「満たす」と判定する規格の例が無い
- 段の判定は、記録に書いた段と根拠を、求める段と比べる。段2 以上の距離そのものは機械では確かめていない。距離を確かめるのは人(出荷判定者・内部監査)である
- 構成から導ける反証だけを機械で拾い、段を引き下げて数える。満たす向きには使わない
  - 確認者・評価者が出荷判定者または事業決裁者の席の責任者のとき、段2 以上に数えない
  - 確認者・評価者と、開発者の席の責任者・作成を指示した者・判定者のいずれかが、名簿の `team` で同じ値のとき、段3 以上に数えない
- 第1章 1.4 の段2 の「リリースの権限」に定義を足す。出荷判定者・事業決裁者の席の責任者、および出荷を確定させる操作の権限(保護の迂回を含む)を持つ者である
- O-5 を直す。安全性の評価者の段の欄を集約が読み、CL2 は段2、CL3 は段3 と比べる。届かなければ記録の欠落とする。段階「最強」の検証の担当者の行も、氏名が書かれていれば同じく比べる
- ADR-0069 決定2 の対象は字義どおり「席と受信箱」であり、名簿はその外と読む。IMPL-0462 の note の「席と名簿」は誤記として直した
- IMPL-0344・0452・0184 は、記録の段の比較と反証の検出を delivered にする。距離そのものの照合は「課さないと決めた」(`plan=adopter`)と書いて表示し続ける(IMPL-0514)
- 根拠水準: 反証の2つの規則は類推(EV-0254)

### 7. 受託の価値責任者は、様式 08 の行と席の責任者を照らす

- 様式 08(AI-SLA 合意確認書)の「判定の置き先と結果の受け渡し」の節に「価値責任者(発注側が選任した者)」の行を置く
- 準拠テンプレートは、受託・委託の構成で、行が空欄なら注記を出し、席の責任者の氏名と食い違えば出荷の証跡の集約で記録の欠落とする。一致は「発注側の人であることは機械では確かめていない」と出す
- 空欄を欠落にしない。行は本件で足し、次の締結(改訂)から記入する。空欄の間は注記で案内する(IMPL-0462)
- 新しい義務: あり(受託・委託の採用者に1行の記入)

### 8. 受託の構成では、席の責任者の任免を、その人が属する側の組織が決め、相手へ通知する

- 外部の制約の注記に、疑義応答集 第3集 A7・第2集 問13(発注者が特定の者を指名し、または就業を拒否することは、配置の決定への関与とされる)を足す。時点を書き「〜とされています」の形にする
- D-0 表1 の既定のままでは、受注側の席の任免に発注側の人の記名が残り、A7 の例示と同じ形の記録になることを本文に書く
- 受託・委託の構成では、席の責任者の任免を、その人が属する側の組織で任命の権限を持つ者が決定する。相手の組織への通知として、氏名と交替の理由を記録する。D-0 表1「体制と運用形態」の行は、任免に限って組織ごとに決定者を置く
- 理由は法令への適合ではなく、決裁の権限の出所である。発注側の人は受注側の要員を任命する権限を持たず、その記名は権限の無い任免の記録になる。受注側の人が発注側の価値責任者を任命する逆向きも同じ。法令の評価を含まない
- 原則の変更: 表1 の「決定者を1人に定める」は、単一の組織を前提にしていた。組織をまたぐ構成では、1名の決定者が相手の組織の任命の権限を持たない。そのため受託・委託の任免に限って組織ごとに分ける
- 準拠テンプレートは名簿に所属を持たず、どちらの側の任免かを判定できない。機械は確かめず、受託・委託の構成で任免の変化点を記録するときに、通知の記録の所在を案内する1行を出すにとどめる(IMPL-0513。`plan=adopter`。確かめる者は G-2 の判定者と AI-SLA の締結者)。入口の緩和は、変化点の前後の構成がともに受託・委託のときに限り、任命権者でない外部の確認者の記名には当てはめない(第2巡の中①②)。名簿へ人を足す行は緩和の対象にせず、今も表1 の決定者の記名を要する。これは新しい義務を課さない現状の開示であり、足す行まで緩めるかは別の裁定に委ねる
- 根拠水準: EV-0255(E0。組織をまたぐ任免の記録の誤りを観測した資料は無い)
- 新しい義務: あり(受託・委託の採用者)。委員の結論は3対2 に割れ、規格は通知の形を原則の変更として指摘した。議長が上のとおり裁定した

### 9. 内部監査の観点6 に所見の例を3つ足す

- 附属書H H.3 の観点6 に、載せるべき人の欠け、区分の誤り、例外の条件の偽りの3つを足す。プロセス内部監査の手引きの観点6 の「機械で検出できないもの」にも同じ3つを足す
- 「組織上の任命権者を名簿に載せていない」こと自体は所見にしない(ADR-0122 決定2)
- `deliverable-templates.md` が要求の所在として手引きの頁を引いていた食い違いを、附属書H H.3 を引く形へ直す(ADR-0086 決定1)
- 新しい義務: あり(確かめる事項が3つ増える)。根拠水準 EV-0256(E0)。監査は人の作業で実行主体の挙動を制約しないため、実装マークは置かない(降ろし先が無い。番号 IMPL-0515 は使わず空ける)

### 10. 名簿・notice の未知の欄を拒否へ改める。形式の版は上げない

- 名簿の要素と種別 notice の未知の欄を、変化点の入口で拒む。保存された構成の未知の欄は、契約の検査で注意にとどめる
- 旧い構成の表示は欄ごとに決めた。決定1・3 は欠落、決定4 は件数、決定5 は判定できない、決定6 は欠落・未達、決定7 は注記とする
- 形式の版(`formatVersion`)は上げない。新しい欄はすべて省略できる欄で、旧い版の構成の意味を変えない。旧い版の準拠テンプレートが新しい欄を捨てる経路は残るが、版を戻す操作であり、取り込みの記録(ADR-0085 決定6)で追える。並行する #358 も名簿を触るため、版を上げるなら取り込みの時に一度で上げる

| 形式の版を上げる | 新しい欄は省略できる欄で意味を変えない。#358 との取り込みの時に判断する |

## 見直しの契機

- EV-0253〜0256 の見直し時期の到来
- 名簿の所属の欄を採る根拠(独立を属性から判定する規格の例)が現れたとき
- 1〜2名の体制で、例外承認の記名(B-2)を置けない事例を観測したとき(本件では審議していない)

## 影響

- 準拠テンプレートの構成、変化点の入口、出荷の証跡の集約、様式 08 が変わる。受託・委託の採用者に、様式 08 の1行の記入と任免の通知の記録が新しく要る
- 降りていない規定(IMPL-0513・0514 の `plan=adopter`。IMPL-0513 は記名が名簿の自然人であることだけを機械が確かめ、決定者の正しさと通知は人が確かめる)は、消さずに表示し続ける
- 機械が確かめるのは記録の有無と形までで、力量・合意・距離・所属の中身は確かめない
