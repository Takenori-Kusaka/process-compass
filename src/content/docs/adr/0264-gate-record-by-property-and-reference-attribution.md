## コンテキスト

- [#459](https://github.com/Takenori-Kusaka/process-compass/issues/459): 語「記名」を本標準が定義していない。「記名者」「記名の自然人」などの派生語が定義なしに多用され、媒体や氏名欄の要否が読み手によって分かれる
- [#460](https://github.com/Takenori-Kusaka/process-compass/issues/460): 組織が既に運用する決裁の仕組み(ワークフロー・電子決裁)の記録を、判定記録の媒体にする条件が無い。G-1 などで、決裁の記録と様式の判定記録が二重になる。トップマネジメントや事業決裁者はホスティングのアカウントを持たない場合がある
- 所有者の決定(2026-11-27): 資料や様式に、承認者の氏名・記名・押印・日付の人が記入する欄を求めない。決裁の証跡は会社の既存の仕組みに残ればよい。仕組みが無い場合に限り様式を使う
- 議長は、この決定を人が記入する欄を指すと解した。機械が操作の記録から出す判定者・判定日時と、基底ブランチへ入った時刻は残す。Part 11 §11.50 の先例と ADR-0036 決定1 の成立要件に沿う

## 決定

1. 語「記名」を定義する(第1章 1.4)。語は置き換えない。定義は1文とし、媒体を問わないこと・署名押印や人が書く氏名日付の欄を求めないこと・本文の氏名だけでは帰属を裏づけないことは注記に置く。「組織の決裁の仕組み」も1行で定義する。読み手向けの言い換え「本人の承認の記録」は、附属書の説明の文に限る
2. 判定記録を性質で定める。判定記録の欄を運ぶこと・判定者本人の認証・申請の種別の意味の事前の定義・対象の固定と失効・改変の履歴と保管の5つを、すべて満たす記録に限る。各行は既存の成立要件と保全の条件の言い換えであり、新しい要求を足さない。承認レビュー・組織の決裁の仕組みの記録・様式は例とし、受け皿の数を数えない。順序は、対象が PR の判定は承認レビュー、それ以外で性質を満たす決裁の仕組みがあればその記録、無ければ様式とする。PR 本文と Issue のコメントは受け皿にしない。メールは名指しで除外せず、性質で判定する
3. 確認した項目を承認の意味の事前の定義で満たしてよいのは、判定が決裁の権限の行使であるものに限る(G-1・G-8・SG・層1・D-0 の決定・例外承認・停止の解除)。G-7 の確認した項目と確認していない事項、G-8 の決断の記録と出荷判定者の異議、差し戻し理由は、判定者本人が書く。定義の表は D-0 の決定として版を持ち、改めた定義は改めた後の承認にだけ効く
4. 基底ブランチへ入れるのは、写しでなく所在の参照(外部の記録の識別子・申請の種別・対象の版)とする。決裁した者・日時の欄を置かない。正本は決裁の仕組みの側にある。判定者は D-0 の名簿の当該の席の責任者として機械が出す欄で導き、効力の日は参照が基底ブランチへ入った時刻とする
5. 帰属の確認の定義を拡張する(1.4)。記名者が作成した変更の承認に加えて、外部の記録を確かめる承認を含める。後者の承認者は、所在の参照を入れる変更を承認し、自分の閲覧で確かめる。確認者は名簿の人に限り、AI の名義でも名義を共有する者でもない。記名者・変更の作成者・作成を指示した者のいずれとも別で、D-0 の申告で閲覧できる者に限る。確認者は事前に定めた宣言行を書く。ADR-0106 の経路に、これを3つ目として足す。上位の原則の語「記名者本人のアカウントの操作」も、「記名者本人の操作(ホスティングのアカウントの操作、または組織の決裁の仕組みでの本人の認証を経た操作)」へ一部置き換える(ADR-0106 決定3 の語の範囲)。効力を持つ記録の列挙にも、同じ3つ目の項目を置く(判定記録と効力を持つ記録の両方に、本決定を掛ける)
6. 外部の記録を閲覧できない場合と確認者を置けない場合は、「照合なし」として受け付け、成立条件1・4 に数えない。保証の開示の項目1 に、機械の裏づけ・組織の決裁の仕組みの記録による裏づけ・照合なし・自己申告を別の件数で出し、合算しない。プロセス内部監査が抜き取りで外部の記録との一致を確かめる。不一致と引き出せない記録は欠落へ戻す。最初の使用の後の最初の内部監査で抜き取らなかった場合、その期間の記録を照合なしへ戻す
7. 統制の閉じ方: 参照の存在・形、確認者の別、宣言行の存在、効力の日は機械で確かめる。外部の記録の一致の真偽は manual(確認者と内部監査の抜き取り)、外部の仕組みが性質を満たすことは adopter(D-0 の申告)とし、根拠水準マーク EV-0351〜EV-0353 で開示する。外部の仕組みの API で機械が照らすことは義務にしない

## 検討した選択肢(採らない)

| 案 | 採らなかった理由 |
| --- | --- |
| 語「記名」の全量の置き換え、手引きでの説明だけ | 定義の欠けを直さない。置き換えは参照の食い違いを広げる |
| 媒体の名指し、様式へ戻る現状維持、受け皿を「3つ」と数える形 | 新しい仕組みのたびに媒体の列挙へ戻る。ツールに成立要件を依存させないという ADR-0036 の却下理由と逆向きになる。現状維持は決裁の記録との二重が残る |
| 性質を3条件へ縮める形 | 保全の条件はホスティングの語で書かれており、外部の仕組みに当てると何を満たせばよいかが読めない。内部監査の基準にならない |
| 添付資料で確認した項目を代える、確認した項目を求めない | 承認の操作と判断の区別が消える |
| 技術判定(G-7)に事前の定義を使う形、G-8・SG を技術判定として様式に留める形 | G-7 の中身は基準ごとの確認で、押下を確認と読ませられない。G-8 の基準2 は事業リスクの受容、SG は投資判断であり、いずれも決裁である |
| 差し戻し理由を項目番号なしで受ける形 | 項目番号は再提出の突合の鍵である |
| 所在の参照に決裁した者・日時を必須の欄として持たせる形 | 所有者の決定と向きが食い違い、外部の記録と同じ事実の第二の正本になる |
| 所在の記載だけで裏づける、照合なしを自己申告と同じ区分にする、外部の記録を自己申告として開示する | 認証を経て決裁された記録と、名前を書いただけの記録を同じ表示にすると、開示が実態と食い違う |
| 外部の仕組みの API の照合を義務にする | 採用者の仕組みに依存する新しい義務になる |
| 第7章の例外承認で受ける形 | 7.3 の対象は判定基準と名指しの事項に限り、構成の条件を含まない。恒常の運用を期限付きの例外で回すと、ADR-0036 決定3 の素通しの正規経路になる |
| 確認者の報告の上下関係を条件にする | 機械で閉じず、小規模の体制で満たせない。手引きと内部監査の観点で扱う |
| 抜き取りの率を標準で定める | 根拠が無い。EV-0353 で開示する |
| 承認者の氏名・記名・押印・日付の欄、電子署名を求める | 所有者の決定による。電子署名が要るかは所管部門が決める |
| 規制業・CL2 以上で受け皿を禁じる | 根拠が無い。監査対応書式は維持する(ADR-0070 決定9) |

## 影響

- 第4章の判定記録は性質で定まり、組織の決裁の仕組みの記録が媒体になりうる。G-1 の決裁の記録に様式を重ねない
- 外部の記録による帰属は人の照合に依る。ADR-0106 が避けた自己申告に近いと反論されうるが、確認者の独立と閲覧の権限、抜き取り、不一致の取り消し、区別開示により、自己申告と違う統制として開示する
- 破られたとき: 不一致が見つかれば、確認者の承認がホスティングに残る。記録は欠落へ戻り、その出荷の保証の主張は開示で改められる。失うのは採用者の保証の主張であり、標準は罰しない。外部の記録が存在しなかった場合は、権限の無い決裁が効力を持った期間が生じうる。抜き取りで見つける残余のリスクとして EV-0351 に書く
- 準拠テンプレートは変えていない。D-0 の申告の表・テンプレ4・11・12・集約・PR の時点の検査・/gate の手引きは、IMPL-1037〜IMPL-1044 が降りていない規定として台帳に出し続ける。欄名の変更と template-fields.yaml の template 側の欄名の変更は、準拠テンプレートと同時に行う(束 D1)。standard 側は第6章の改めに合わせて改めた(t7・t9)
- 第4章の欄名(判定者・判定日・承認した者・記名(技術判断者)など)は、この変更で変えていない。両方向の検査(ADR-0040)は落ちない
- 後続の試行の承認(#458)は、この性質を満たす既存の決裁の記録で足りる
- 第6章の様式のうち、人が記入する承認者・決裁者・日付の欄は、承認の記録の所在へ改めた(D-0・企画書・テンプレ7・8・9・11・12)。準拠テンプレートに同じ欄があるものは、IMPL-1038〜IMPL-1040・IMPL-1047〜IMPL-1049 が降りていない規定として表示する。機械が残す判定者・判定日時は保つ
- 降りるまでの間、IMPL-1041〜IMPL-1043 は check=manual で表示する(機械の検査へ降ろす予定。試験の無い machine を置かない規則による)

## 根拠水準

- EV-0351: 外部の決裁の記録による帰属の確認を成立条件1・4 に数える(E0)
- EV-0352: 性質1〜5 の充足を採用者の申告で受け付ける(E0)
- EV-0353: 抜き取りの率を定めず、最初の内部監査での未実施を照合なしへ戻す(E0)
- 本決定は、既存の差し替え条件(gate-criteria の「裏づけの経路を足す向きの見直し」。名前の一致へ戻さない向き)に当たる、経路を足す向きの見直しである。名前の一致を裏づけに数えない原則は保つ
- 既存の EV-0109(判定の成立の媒体別の欠落)は、番号を再利用せず文を改訂した。媒体に組織の決裁の仕組みの記録を加え、媒体の追加後の分布が未測定であることを書き足した
- 先例: 米国 21 CFR Part 11 §11.50(署名の意味の記録)と日本の電子帳簿の法令は、条文の根拠にしていない。ISO 9001 7.5.3 は、二次の転載で読んだだけの参照(未確認の転載)であり、条項の根拠に引いていない
