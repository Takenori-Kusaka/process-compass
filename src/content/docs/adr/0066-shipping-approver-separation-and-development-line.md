## ステータス

採用(2026-10-13)。[ADR-0029](/process-compass/adr/0029-shipping-approver-merge-exception/)を置き換えません。同 ADR が定めなかった兼務禁止の範囲を足します。[ADR-0057](/process-compass/adr/0057-organizational-quality-assurance/)の成立条件4 は書き換えず、出荷ごとの条件を足します。[ADR-0056](/process-compass/adr/0056-assurance-argument/)の決定8(使わない表現)が前提にした「第三者レビュー」の語を定義します。

影響の節が後継へ送った2つの論点(価値責任者と技術判断者の兼務の境界、第3章 3.5.1 の既定の写像)は、[ADR-0082](/process-compass/adr/0082-seat-combination-boundaries-and-lane-mapping/)が決めました(2026-10-23)。本 ADR の決定は維持されます。

## コンテキスト

[#304](https://github.com/Takenori-Kusaka/process-compass/issues/304) は、「開発ライン」の語に定義が無いこと、出荷判定者が兼ねてはならない席の範囲が本文と機械で食い違うことを指摘しました。指摘をそのまま条項にせず、調査・会議体・突合の順で扱いました。記録は `research/302-310-deliberation/`(`survey-304.md`、`council-A-01`〜`05`、`decision.md` の A-4〜A-7)にあります。

### 本文と機械が、別の範囲を指していた

本文は4か所で、独立レビュアと出荷判定者を別の人として書いていました。

- 第3章 3.5 の「最小体制は3名(作成指示者・独立レビュア・出荷判定者の兼務禁止を満たす下限)」
- 第8章 軸A の、2名体制で成立するのは G-6 だけであるという記述
- 附属書A A.5 と ADR-0057 決定2 の組(G-6 は開発ラインの中の確認、G-7 は開発ラインの外の突合)
- 附属書I I.5 の3名の割り当ての例(独立レビュアと出荷判定者が別の人)

規則データの兼務禁止は、開発者の席と出荷判定者の席の組だけでした。独立レビュアと出荷判定者を同一人物にする3名以上の構成は、通っていました。規則データの組からは、最小の人数は2名と導かれました(調査が総当たりで確認)。独立レビュア × 出荷判定者の組を足すと、3名になります。

兼務を認めると決めた記録は、どちらの向きにもありませんでした。回帰の fixture は独立レビュアと出荷判定者を同じ人に割り当てていましたが、fixture が確かめていたのは任免の記名です。fixture はリポジトリの履歴の外にあり、決定の記録ではありません。

### 席の禁止だけでは、行為で迂回できた

会議体の品質保証の委員が、実行して確かめました。出荷判定者の席の責任者が、席の責任者でない担い手として PR を承認すると、出荷の証跡の集約は、その承認を G-6 の確認に数えました。成立条件4 は、判定記録があれば G-7 と G-8 の記名が別人かだけを見ており、2名体制で開発者本人が G-7 を記名した構成を成立と出しました。保証の主張は「出荷ごとに開発ラインの外の記名の自然人が突合し」と対外に述べています。主張の文が、条件より強くなっていました。

### 「開発ライン」は3つの意味で使われていた

語は、標準と準拠テンプレートで約100行に現れ、定義がありませんでした。意味は3つありました。同一案件で出荷判定者と兼ねてはならない側(席の集合)、案件と並ぶ組織の単位、案件の開発に関わる人の全体です。採用済みの ADR-0029 と ADR-0057 は、1つ目の意味でこの語を使っています。

### 「第三者レビュー」の定義は、附属書にだけあった

定義の文は、附属書D の「提案書で使わない表現」の中にだけありました。同じ語を、附属書A、附属書H、規則データが使っていました。定義は「開発ラインの外の組織による検証」で、同じ会社の品質保証部門を含むかどうかが読み取れませんでした。フェーズ1・2 の文書は、品質保証部門の判定を「第三者判定」と呼んでいました。適合性評価の用語では、同じ組織の中の検証を第三者とは呼びません。

## 決定

### 1. 3名以上の体制で、出荷判定者の席は、開発者の席とも独立レビュアの席とも兼ねない

規則データに、独立レビュア × 出荷判定者の組を足します。3名以上の体制では、同じ人をこの2つの席の責任者にする構成を拒否します。3名未満の体制では、開発者 × 出荷判定者と同じく、第3章 3.5.2 の例外(代償措置つきの逸脱)として記録します。

出荷判定(G-7)は、独立レビュー(G-6)の通過記録と、独立の成立状況を突合します。独立レビュアが出荷判定者を兼ねると、自分の記録を自分で突合することになります。

**出荷判定者の席と、価値責任者・技術判断者・文脈オーナー・AI維持管理者・AI運用担当者の席との兼務は、禁じません**。意図的な決定です。禁じる範囲を広げる根拠になる記録と測定は、確認できていません。

### 2. 出荷ごとに、出荷判定を記名した人を確かめる

保証の主張の成立条件4 に、次を足します。出荷判定(G-7)を記名した人が、範囲内の変更の作成を指示した者でも、G-6 の承認者でもないこと。

席の兼務禁止は構成の条件であり、席の責任者でない担い手としての指示と承認を止めません。独立を、構成の条件と行為の条件の2層で定める原則([ADR-0060](/process-compass/adr/0060-drafting-context-and-two-layer-independence/) 決定3)を、G-7 に当てます。

### 3. 「開発ライン」を、1つの意味に限って定義する

開発ラインは、同一の案件の、開発者の席と独立レビュアの席を指します。出荷判定者の席と事業決裁者の席を含みません。定義は第1章 1.4 に置きます。

ほかの意味には、この語を使いません。複数の案件にまたがる開発の単位は「開発組織」、案件に関わる人の全体は「案件に関与する者」と書きます。第3章 3.5 の兼務禁止の表は、席の名前で書きます。

会議体の多数(3名)は、語を廃して読み替えの1行を置く案を採りました。議長は、多数に従いませんでした。採用済みの ADR-0029・ADR-0057 と第1章 1.9 がこの語を使っており、ADR は書き換えません。語を廃して読み替えを置く形と、1つの意味で定義する形は、読み手にとって同じ効果になります。定義を置くほうが、過去の記録を読み替えなしで読めます。

採用済みの ADR に残る用例は、次のとおり読みます。

| ADR | 用例 | 読み方 |
| --- | --- | --- |
| ADR-0029 | 「開発ライン × 出荷判定者」「価値責任者が同時に開発ラインでもある」 | 本決定の定義のとおり。価値責任者が開発者の席を兼ねる場面を述べている |
| ADR-0057 決定2 | 「開発ラインの外の記名の自然人が…突合する」 | 本決定の定義のとおり |
| ADR-0057 決定12 ほか | 「案件または開発ラインの単位で…評価する」 | 「開発組織」と読む |

### 4. 本文を正とし、「最小体制は3名」を規則データから導いて保つ

本文と fixture の食い違いは、本文を正とします。規則データ・本文・回帰の fixture を同時に直します。

最小体制の3名は、兼務禁止の組から総当たりで導き、`npm run check`(エンジンの試験)で保ちます。開発者・独立レビュア・出荷判定者の3つの席は、どの2つも責任者を同一人物にできません。3つの席に別の人を置ける最小の人数が3名です。

### 5. 「第三者レビュー」を、別の組織で利害を持たない者による検証に限る

定義を、附属書D から第1章 1.4 へ移します。第三者レビューは、本標準を適用する組織と別の組織にあり、案件に利害を持たない者による検証を指します。本標準のゲートには無い活動です。

同じ組織の別部門(品質保証部門など)による検証は、「組織上独立した検証」と呼びます。独立レビュー(G-6)とプロセス内部監査も、第三者レビューと呼びません。第7章 7.7.6 の題、第2章 H-3、フェーズ1・2 の文書の「第三者」のうち、社内の者を指す用法は言い換えます。

規格の文は引きません。定義は本標準の言葉で書きます。

## 影響

- 規則データに `sep-reviewer-shipping` を足した。**独立レビュアと出荷判定者が同一人物である3名以上の構成は、構成の変更と契約検査で拒否される**。規則より前の版で受理された構成も、契約検査が失敗する。独立レビュアの席を、別の人(事業決裁者・価値責任者・技術判断者の席の人でよい)へ移すと解ける。3名のまま組める(総当たりで確認)
- 保証の主張の成立条件4 が、厳しくなった。**2名体制で、2人がそれぞれ作成の指示と G-6 の承認に当たると、条件4 を満たす出荷判定の記名者が体制の内にいない**。1名体制も同じである。出荷判定を、範囲内の変更の指示と確認のどちらにも当たっていない人が記名する場合に限り、条件4 を満たす。附属書H H.1 の体制別の道筋を改めた
- 準拠テンプレートの出荷の証跡の集約は、出荷判定を記名した人を、記録に現れた指示者と G-6 の承認者に照らす(IMPL-0113)。記録に現れない関与は確かめない
- 根拠水準マーク(EV-0103。E1。見直し 2027-04)を、第3章 3.5 に付けた。兼務した場合としない場合の欠陥の流出を比べた測定は無い
- 回帰の fixture(履歴の外)の3名の土台は、独立レビュアを別の人へ移した。固定していた決定(任免の記名、3名の全検査)は変わらない
- 「開発ライン」の語は、標準と準拠テンプレートの約50行で「開発組織」「案件に関与する者」などへ言い換えた。採用済みの ADR は書き換えていない
- 価値責任者と技術判断者の兼務の境界、第3章 3.5.1 の既定の写像(独立レビュアと出荷判定者を同じレーンに置く)は、今回の決定の外である。会議体が見つけた論点として、後継の Issue へ送る
