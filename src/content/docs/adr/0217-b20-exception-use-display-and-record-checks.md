## ステータス

採用(2026-11-18)。束 B20 の軽の件のうち、台帳の行(#355 の U1)、開示の表示(U2)、第7章の行使(U3)の決定です。判定記録の回数・点検・併記の欄・判断記録の再検査(U4)の決定は、同じ ADR の決定 9 以降に後の段で足す。

[ADR-0200](/process-compass/adr/0200-b18-first-group-adopter-record-conventions/) の決定2・決定5(a) と [ADR-0153](/process-compass/adr/0153-assign-0996-gate-exception-targets/) 決定2 を前提とする。審議の記録は `research/448-deliberation/b20-decision-light.md`(1 節から 4 節)にある。

## コンテキスト

- #355 は3つの未達を挙げた。第7章の例外の行使を集約が見ていないこと。期限の延長と類似検知の超過が欠落にならないこと。開示の表示が試験で固定されていないこと
- 起票者の提案をそのまま条項にしない。既存の印・欄・欠落の経路で足りるものは新しい語や欄を作らず、新しい義務に当たるものは外した
- 実行で確かめた事実がある。印を太字やバッククォートで書くと印として読まれず、G-4・G-5 を名指す行の拒否を素通りする。未回収の行を台帳から消すと、既に未回収に数えられる

## 決定

1. ファストトラック(7.4)の指標(発生率・回収完了率・適用後の欠陥)は、既存の印(ADR-0200 決定2)を数えて項目7 に表示する。新しい語・区分は作らない。印の読みは `exception-expiry.mjs` の `fastTrackMarkOf` に移し、強調の `*`・バッククォート・括弧の前の空白・全角を許す。`check-pr.mjs` の拒否(IMPL-0567・IMPL-0610)と集約は同じ関数を使う。欠陥は、原因の変更を印の行の対象と結べた件数と、原因の変更が空欄の件数を併記する
2. 制限された状態での例外決裁(7.9.4)の行は、条件で見分ける。区分「例外」の行のうち、対象の変更が承認権限の一時制限の範囲に触れ、数えた承認が2名に満たないものとする。印は求めない。承認した者が D-0 の会議体の表の B-2 の決定者でない(B-2 が該当なしなら事業決裁者の席の責任者と比べる)こと、返却の目安に日付か回収責任者が無いことを記録の欠落にする。読めないときは未確認と表示し、欠落にしない。印の無い行は件数を表示する
3. 7.9.5 の枠と行使は、企画書の「例外の枠」と、直前のステージ移行ゲートの通過のコミットの台帳との差で数え、項目7 に「枠・行使・残り」を出す。超過は表示し、止めない(拒否は IMPL-0630)。累計は範囲の中で 7.9.4 の条件に当たる行だけで、範囲の外で足された行は再判定できないため下限の値である。読めないときは確認できないと出す
4. 判定記録の写し(`docs/records/reviews/`)を含む PR が、技術負債台帳・閾値のファイルと構成の `ci`・`task`・`guard`・停止の解除の様式も変えるときは、G-5 の `pr-rules` で失敗にする。段(ステージ)で緩めない。出荷の PR は写しと `docs/gates/` の様式を複製するため(`ship-evidence.yml`)、記録用ブランチ `records/gates/` に同名・同内容の停止の解除の様式が在るものは複製として除く。記録用ブランチを読めないときは、その様式についてだけ注意にとどめる
5. 返却の目安を延ばす書き換えは、記録の欠落にする。区分「例外」「類似検知」の行を範囲の始点と終点の台帳で比べ、終点の期限が後の日付、または始点が日付で終点が日付として読めないものを数える。期限を早める向き、状態だけの変更、始点の台帳が読めない場合は欠落にしない。延長は新しい行で承認し直す(7.3)
6. 区分「類似検知」の行は、返却の目安が突合の日より前で未返却のもの、目安が日付として読めないものを記録の欠落にする(G-7 基準8)。次の条件を満たす区分「例外」の延長の行があれば、その行は数えない。対象に当該の行の ID を書いていること。有効で期限内であること。承認した者が名簿の人で、AI の名義でないこと。理由と期限が記入されていること。範囲の例外承認の件数は類似検知の行の有無で変えない
7. 開示の表示を固定する。(a) G-6 未達のまま入った R2 の変更の件数を項目3 に表示する(止めない)。(b) D-0 の不在と構成の変更記録の不在を、項目を導けない記載の欠落にする。実行時に自分の見出しを確かめる検査は置かない。(c) 保証の開示に載った未達への出荷判定者の見解は、G-8 の異議で扱い、停止の保留に数えない(既存の実装を試験で固定する)。(d) 発注側が価値責任者を置かない委託は、様式 08 の値「置かない」(NFKC で正規化した完全一致)だけを明示の値とし、G-2 を未達として表示する。空欄は注記のままとする(ADR-0127 決定7)
8. 類似の検知の実施記録の4事項(IMPL-1009)は manual とする。置き場が2択なので、機械の読む所を定められない。機械は実施の有無を見ない。確かめる者は出荷判定者とする

## 課さないと決めたこと

- 7.9.4 の行に印を求めること。ADR-0200 決定5(a) が「印の付け忘れを機械で検出すること」を課さないと決めており、矛盾する。印の無い行は件数の表示にとどめる
- 7.9.4 専用の区分・様式。条文が「別の手続を新設しません」と定める
- 未回収の行の消去を欠落にすること。消した行は既に未回収に数えられる。短くする向きの書き換えを欠落にすること(条文が禁じるのは延ばす書き換えだけ)
- 範囲の外の履歴の書き換えの検出(決定できない)。類似の検知の実施記録の置き場の固定(新しい義務)
- 値「置かない」のとき、例外承認で受ける道を手引きに書くこと。例外承認はゲートの未達を解かない
- 実行時に自分の見出しを確かめる検査。固定の見出しを同じ処理で確かめるので、恒真になる
- 印の付け忘れの検出と、会議体へ報告するふるまいの検出(会議の議事にしか現れない)

## 検討した選択肢(採らない)

| 案 | 採らなかった理由 |
| --- | --- |
| ファストトラックの新しい語・区分を作る(0612) | 既存の印で数えられる。語を増やすと採用者の既存の台帳が読めなくなる |
| 7.9.4 の行に印を求める(0628) | ADR-0200 決定5(a) と矛盾する |
| 0554 を S0 で注意に緩める | 条文に段の限定が無い。S0 で G-7 を適用するのは Q1「はい」の案件で、緩めると安全に関わる案件ほど弱くなる |
| 0554 を `verify` へ移す | 必須の検査でない |
| 未回収の行の消去を検査する(0787) | 既に未回収の件数に数える。条文が禁じるのは期限の書き換えである |
| 類似の検知の延長を IMPL-0786 の全条件で判定する(1008) | 検知した変更の作成を指示した者との照合は、類似検知の行の対象(検知した変更)から導くと誤りやすい。成立判定から外し、note に開示した |
| 空欄の価値責任者を未達にする(0755) | ADR-0127 決定7 の「空欄を欠落にしない」を覆す |

## 影響

- 採用者は、ファストトラックの印を太字やバッククォートで書いても、読まれる。G-4・G-5 を名指す行は、書き方を変えても拒まれる
- 採用者の台帳で、期限を延ばす書き換えをすると記録の欠落になる。延長は新しい行で承認し直す
- 区分「類似検知」の行は、期限を過ぎたまま残ると出荷の記録の欠落になる。延長は区分「例外」の行で書く
- 判定記録の写しを含む PR は、台帳・閾値・停止の解除の様式を同じ PR で変えられない。出荷の PR の複製は、記録用ブランチと内容が同じなら通る
- 項目7 に、ファストトラックの指標、7.9.4 の行の件数、枠・行使・残りが出る。止めるのは、7.9.4 の行の欠落(決定2)だけである
- 項目の根拠は実証されていない。発生率や欠陥の結び付けは、印の付け忘れと原因の変更の記入に依る

:::caution[暫定 EV-0327 / 見直し 2027-05]
**対象**: ファストトラックの指標(発生率・回収完了率・適用後の欠陥の結べた件数)が、乱用の兆候を示すという前提。
**根拠の水準**: E0(なし)。
**差し替え条件**: 採用者の台帳で、印の付け忘れの件数と、原因の変更の欄が空欄の欠陥の割合。

印の付け忘れは機械で数えられず、原因の変更の欄が空欄の欠陥は結べません。結べた件数は下限であり、楽観へ偏ります。
:::
