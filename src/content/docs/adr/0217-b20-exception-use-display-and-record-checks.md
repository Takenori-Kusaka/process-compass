## ステータス

採用(2026-11-18)。束 B20 の軽の件のうち、台帳の行(#355 の U1)、開示の表示(U2)、第7章の行使(U3)の決定です。判定記録の回数・点検・併記の欄・判断記録の再検査(U4)と、手引きの追記・採用者の確認に委ねる件(U5〜U6)の決定は、同じ ADR の決定 9 以降に足す。

[ADR-0200](/process-compass/adr/0200-b18-first-group-adopter-record-conventions/) の決定2・決定5(a) と [ADR-0153](/process-compass/adr/0153-assign-0996-gate-exception-targets/) 決定2 を前提とする。審議の記録は `research/448-deliberation/b20-decision-light.md`(1 節から 4 節)にある。

## コンテキスト

- #355 は3つの未達を挙げた。第7章の例外の行使を集約が見ていないこと。期限の延長と類似検知の超過が欠落にならないこと。開示の表示が試験で固定されていないこと
- 起票者の提案をそのまま条項にしない。既存の印・欄・欠落の経路で足りるものは新しい語や欄を作らず、新しい義務に当たるものは外した
- 実行で確かめた事実がある。印を太字やバッククォートで書くと印として読まれず、G-4・G-5 を名指す行の拒否を素通りする。未回収の行を台帳から消すと、既に未回収に数えられる

## 決定

1. ファストトラック(7.4)の指標(発生率・回収完了率・適用後の欠陥)は、既存の印(ADR-0200 決定2)を数えて項目7 に表示する。新しい語・区分は作らない。印の読みは `exception-expiry.mjs` の `fastTrackMarkOf` に移し、強調の `*`・バッククォート・括弧の前の空白・全角を許す。`check-pr.mjs` の拒否(IMPL-0567・IMPL-0610)と集約は同じ関数を使う。欠陥は、原因の変更を印の行の対象と結べた件数と、原因の変更が空欄の件数を併記する
2. 制限された状態での例外決裁(7.9.4)の行は、条件で見分ける。区分「例外」の行のうち、対象の変更が承認権限の一時制限の範囲に触れ、数えた承認が2名に満たないものとする。印は求めない。承認した者が D-0 の会議体の表の B-2 の決定者でない(B-2 が該当なしなら事業決裁者の席の責任者と比べる)こと、返却の目安に日付か回収責任者が無いことを記録の欠落にする。読めないときは未確認と表示し、欠落にしない。印の無い行は件数を表示する
3. 7.9.5 の枠と行使は、企画書の「例外の枠」と、直前のステージ移行ゲートの通過のコミットの台帳との差で数え、項目7 に「枠・行使・残り」を出す。超過は表示し、止めない(拒否は IMPL-0630)。累計は範囲の中で 7.9.4 の条件に当たる行だけで、範囲の外で足された行は再判定できないため下限の値である。読めないときは確認できないと出す
4. 判定記録の写し(`docs/records/reviews/`)を含む PR が、技術負債台帳・閾値のファイルと構成の `ci`・`task`・`guard`・停止の解除の様式も変えるときは、G-5 の `pr-rules` で失敗にする。段(ステージ)で緩めない。出荷の PR は写しと `docs/gates/` の様式を複製するため(`ship-evidence.yml`)、記録用ブランチ `records/gates/` に同名・同内容の停止の解除の様式が在るものは複製として除く。記録用ブランチを読めないときは、その様式についてだけ注意にとどめる
5. 返却の目安を延ばす書き換えは、記録の欠落にする。区分「例外」「類似検知」の行を範囲の始点と終点の台帳で比べ、終点の期限が後の日付、または始点が日付で終点が日付として読めないものを数える。期限を早める向き、状態だけの変更、始点の台帳が読めない場合は欠落にしない。延長は新しい行で承認し直す(7.3)
6. 区分「類似検知」の行は、返却の目安が突合の日より前で未返却のもの、目安が日付として読めないものを記録の欠落にする(G-7 基準8)。次の条件を満たす区分「例外」の延長の行があれば、その行は数えない。対象に当該の行の ID を書いていること。有効で期限内であること。承認した者が名簿の人で、AI の名義でないこと。理由と期限が記入されていること。承認した者が、対象の変更の作成を指示した者本人でないこと(IMPL-0786 と同じ条件。対象を変更へ解決できない延長は成立に数え、件数を項目7 に「指示者と照合できない延長 N 件」と出す)。範囲の例外承認の件数は類似検知の行の有無で変えない
7. 開示の表示を固定する。(a) G-6 未達のまま入った R2 の変更の件数を項目3 に表示する(止めない)。(b) D-0 の不在と構成の変更記録の不在を、項目を導けない記載の欠落にする。実行時に自分の見出しを確かめる検査は置かない。(c) 保証の開示に載った未達への出荷判定者の見解は、G-8 の異議で扱い、停止の保留に数えない(既存の実装を試験で固定する)。(d) 発注側が価値責任者を置かない委託は、様式 08 の値「置かない」(NFKC で正規化した完全一致)だけを明示の値とし、G-2 を未達として表示する。空欄は注記のままとする(ADR-0127 決定7)
8. 類似の検知の実施記録の4事項(IMPL-1009)は manual とする。置き場が2択なので、機械の読む所を定められない。機械は実施の有無を見ない。確かめる者は出荷判定者とする
9. 必達基準2 の継続・保留の通算の回数(IMPL-0667)は、記録から数える。必達基準の判定記録を判定日時の順に見て、案件の区分が乙・丙で判定が継続・保留のものを数え、範囲の中の記録が4回目以降なら欠落にする。欄「7.7.5 の回数」の先頭の「通算 N 回」は、数えた回数より小さければ欠落、大きければ N から続けて数える。人が書いた回数を下げる向きには使えない。新しい欄は足さず、全必達基準へ欄を広げない(新しい義務に当たる)。必達基準 1・3・4・5 は機械で数える材料が無いので、IMPL-1026(manual)に分ける。確かめる者は当該の判定の決定者とする
10. 案件に関与していない者による点検(IMPL-0622)は、S1 以降、棚卸しの判定記録の最終の判定日と経過日数を項目7 に出し、記録なしか 365 日超は注意とする。止めない。実施者の限定と項目ごとの合否は文の意味なので、IMPL-1027(manual)へ分ける。内部監査の席の無い体制があるので、確かめる者は出荷判定者とする
11. 暫定任命の期間中の併記(IMPL-0638)は、様式 04 と標準のテンプレ4 に任意の欄「確認済みの者の併記」を足して(`template-fields.yaml` に両方向で登録)、D-0 節9 の期間の表で期間内の判定を対象にする。対象が責任者なら席の責任者、代理者なら同じ節の代行者の欄の者の判定とする。併記が無い・名簿の人でない・AI の名義・判定者本人は未達として項目1 に出す。CL0 で規制業でない案件は止めない。CL1 以上と規制業は、出荷の範囲の中の判定の未達を [ADR-0218](/process-compass/adr/0218-b20-ship-block-on-human-confirmation-unmet-and-stacked-layer-approval/) により欠落に数える(範囲の外は表示だけ)。G-6 は対象にしない。期間が日付として読めない行は「確認できない」と表示し、欠落にしない。併記は 3.4.1 が既に求めており、欄は書く場所である。CL0 で規制業でない案件は、無くても止めず未達と表示する
12. 判断記録の再検査(IMPL-0523)は、所見に留めない。出荷の範囲で変わった `context/decisions/` と `context/_archive/decisions/` のファイルだけを、G-3 で判定した版と先端で、状態の行を除いた文字列の一致(改行・行末の空白・端の空行を揃える)で比べ、不一致を欠落にする。3値(一致・不一致・未確認)は ADR-0136 決定1 に揃え、未確認は欠落にしない。「置き換える決定」を持つのに G-3 の通過の記録が無い判断記録も欠落にする。欠落の文に、解く道(置き換える判断記録を起こす、採用の前なら変更後の版で G-3 を受け直す)を書く。履歴の全部は比べない(既存の採用者が一斉に止まるため)。誤字の修正も不一致になる(様式 02「書き換えてよいのは、状態の行だけ」の字義のとおり)
13. 基準集合の正解を確定した者と導入を承認した者の同一(IMPL-0710)は、単一障害点の項目(受容の対象「基準集合の確定者と導入承認者が同一人物」)として項目5・7 に出す。受容は D-0 節15 の期限つきの受容で受け、受容者は層1 の「品質の残存リスク」の受容者の行で照らす(層1 の受容の権限の段階に専用の行は無い)。期限切れは記載の欠落。同一の判定は名簿の識別の一致までで、別名義の同一人物は閉じない
14. 手引きの追記と採用者の確認に委ねる件は manual とする。次の5件は、自由な文の意味か会議の議事にしか現れない事実なので、機械で閉じない。
   - 0717: 学習利用の有無を構成の依存先の `data` に書く手引きを足す。新しいキーは足さない
   - 0719: 依存先の一覧を再生成する契機を、SG・/process-change・handoff に書く
   - 0655: 委譲先の記名を判定者の欄へ書かない旨を、G-4 の補助ファイルに書く
   - 0853: 手段に従った事実を適合の根拠に数えない旨を、G-7 の署名の意味に書く
   - 0626: エスカレーションの全件突合の手順を、G-7 と handoff に書く。専用のラベルは足さない
15. 単一障害点の B-2 への報告と受容(IMPL-0720)は、ファイルを変えない。受容の書き場所は D-0 節15 に既にある。保管の期間と 0963・0837・0584 は、ADR-0216 が採用者へ委ねる

## 課さないと決めたこと

- 7.9.4 の行に印を求めること。ADR-0200 決定5(a) が「印の付け忘れを機械で検出すること」を課さないと決めており、矛盾する。印の無い行は件数の表示にとどめる
- 7.9.4 専用の区分・様式。条文が「別の手続を新設しません」と定める
- 未回収の行の消去を欠落にすること。消した行は既に未回収に数えられる。短くする向きの書き換えを欠落にすること(条文が禁じるのは延ばす書き換えだけ)
- 範囲の外の履歴の書き換えの検出(決定できない)。類似の検知の実施記録の置き場の固定(新しい義務)
- 値「置かない」のとき、例外承認で受ける道を手引きに書くこと。例外承認はゲートの未達を解かない
- 実行時に自分の見出しを確かめる検査。固定の見出しを同じ処理で確かめるので、恒真になる
- 印の付け忘れの検出と、会議体へ報告するふるまいの検出(会議の議事にしか現れない)
- 全必達基準への回数の欄の追加(新しい義務)。欄の値だけを信じる検査
- 力量の記録が無い席をすべて暫定に数えること(初期の案件の全判定が未達になる)。点検の未実施で出荷を止めること(出荷の基準でない)
- 判断記録の履歴の全部を比べること(既存の採用者が一斉に止まる)。意味を変える差だけを選ぶ定義(機械で閉じない)
- 学習利用の新しいキー。専用のエスカレーションのラベル(7.6 と食い違う)

## 検討した選択肢(採らない)

| 案 | 採らなかった理由 |
| --- | --- |
| ファストトラックの新しい語・区分を作る(0612) | 既存の印で数えられる。語を増やすと採用者の既存の台帳が読めなくなる |
| 7.9.4 の行に印を求める(0628) | ADR-0200 決定5(a) と矛盾する |
| 0554 を S0 で注意に緩める | 条文に段の限定が無い。S0 で G-7 を適用するのは Q1「はい」の案件で、緩めると安全に関わる案件ほど弱くなる |
| 0554 を `verify` へ移す | 必須の検査でない |
| 未回収の行の消去を検査する(0787) | 既に未回収の件数に数える。条文が禁じるのは期限の書き換えである |
| 類似検知の延長の照合を成立判定から外す(1008) | 軽の裁定が「IMPL-0786 と同じ条件」と定めた条件を、裁定なしに外すことになる(独立の突合 F-09)。指示者へ解決できない場合だけ、成立に数えて件数を出す |
| 空欄の価値責任者を未達にする(0755) | ADR-0127 決定7 の「空欄を欠落にしない」を覆す |
| 回数の欄を全必達基準へ広げる(0667) | 様式の必須欄が増え、新しい義務に当たる。記録から数える |
| 判断記録の不一致を所見に留める(0523) | 読まれない表示は統制にならない。ADR-0136 決定1 は文字列の一致で合否にする先例である |
| 判断記録の履歴の全部を比べる(0523) | 過去の書き換えで既存の採用者が一斉に止まる。出荷の範囲で変わったファイルに限る |
| 力量の記録が無い席をすべて暫定に数える(0638) | 初期の案件の全判定が未達になる |

## 影響

- 採用者は、ファストトラックの印を太字やバッククォートで書いても、読まれる。G-4・G-5 を名指す行は、書き方を変えても拒まれる
- 採用者の台帳で、期限を延ばす書き換えをすると記録の欠落になる。延長は新しい行で承認し直す
- 区分「類似検知」の行は、期限を過ぎたまま残ると出荷の記録の欠落になる。延長は区分「例外」の行で書く
- 判定記録の写しを含む PR は、台帳・閾値・停止の解除の様式を同じ PR で変えられない。出荷の PR の複製は、記録用ブランチと内容が同じなら通る
- 項目7 に、ファストトラックの指標、7.9.4 の行の件数、枠・行使・残りが出る。止めるのは、7.9.4 の行の欠落(決定2)だけである
- 項目7 に、必達基準2 の通算の回数と点検の経過、判断記録の再検査の件数が出る。項目1 に、暫定任命の期間中の未達が出る。止めるのは、通算4回目以降と回数の欄の下げ、判断記録の不一致、G-3 の通過の無い置き換え、受容の期限切れである
- 判定記録の様式に任意の欄「確認済みの者の併記」が増え、欄「7.7.5 の回数」の書き方が「通算 N 回」から始まる
- 採用者は、手引きに足した手順(学習利用の有無・依存先の一覧の再生成・委譲先の記名・エスカレーションの突合)を自分の運用で行う。機械は見ない
- 項目の根拠は実証されていない。発生率や欠陥の結び付けは、印の付け忘れと原因の変更の記入に依る

:::caution[暫定 EV-0327 / 見直し 2027-05]
**対象**: ファストトラックの指標(発生率・回収完了率・適用後の欠陥の結べた件数)が、乱用の兆候を示すという前提。
**根拠の水準**: E0(なし)。
**差し替え条件**: 採用者の台帳で、印の付け忘れの件数と、原因の変更の欄が空欄の欠陥の割合。

印の付け忘れは機械で数えられず、原因の変更の欄が空欄の欠陥は結べません。結べた件数は下限であり、楽観へ偏ります。
:::

:::caution[暫定 EV-0328 / 見直し 2027-05]
**対象**: 必達基準2 の乙・丙の継続・保留を数えれば、7.7.5 の回数の上限を守らせられるという前提。
**根拠の水準**: E0(なし)。
**差し替え条件**: 採用者の判定記録で、甲へ戻した継続と他の必達基準の継続の件数と、機械の数えた回数との食い違い。

機械が数えるのは必達基準2 の乙・丙だけです。甲へ戻した継続と必達基準 1・3・4・5 は数えません。欄の値は、数えた回数を下げる向きには使えません。
:::

:::caution[暫定 EV-0329 / 見直し 2027-02]
**対象**: 状態の行を除いた文字列の一致が、判断記録の書き換えを過不足なく拾うという前提。
**根拠の水準**: E0(なし)。
**差し替え条件**: 採用者の出荷の範囲での不一致の件数と、そのうち意味を変える書き換えだった割合。

誤字の修正も不一致になります。履歴の全部は比べず、出荷の範囲で変わったファイルに限ります。履歴の全部を比べた参考値では、決定の節に差のある判断記録が 162 件中 66 件ありました(最初のコミットとの比較なので上限の値です)。
:::
