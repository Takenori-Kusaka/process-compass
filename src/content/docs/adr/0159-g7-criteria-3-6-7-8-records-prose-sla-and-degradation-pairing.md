## ステータス

採用(2026-11-17)。[ADR-0084](/process-compass/adr/0084-check-strength-plans-and-resident-rules/)・[ADR-0137](/process-compass/adr/0137-period-disclosure-approval-pace-and-degradation-metrics/)・[ADR-0138](/process-compass/adr/0138-handover-items-and-decision-fields-checks/)・[ADR-0153](/process-compass/adr/0153-safety-judgment-and-ship-prohibitions-outside-exception-approval/) は置き換えません。本 ADR は、これらの決定の適用です。重の審議の結論です(Issue [#355](https://github.com/Takenori-Kusaka/process-compass/issues/355) 束2、`research/355-deliberation/b2-decision.md`)。

## コンテキスト

G-7 の判定基準の表は、基準3・6・7・8 に「記録漏れ 0 件」「欠落がない」「欠落 0 件」を求めます。機械(出荷の証跡の集約)が見るのは、記録の有無と非空までです。表の値と機械の範囲が食い違うまま、表示だけが完備を主張する状態にありました。基準6・7・8 は、実装マークが集約に降ろす計画のまま、降ろし先の手順(`gates/G-7.md`)も無い状態でした。

あわせて、散文のファイルの変更が「SLA で判定する」と読める文、3.11.7 の「個人の指標と保守性の指標は必ず対で確認します」(「個人の指標」は本標準に定義が無い)、類似の検知の未処理を置く台帳の区分の欠落が、それぞれ未決でした。

## 決定

1. **基準3・6・7・8 は出荷判定者が判定する。** 機械が見る範囲を基準ごとに書く(第4章 G-7「基準3・6・7・8 の記録」)。「記入が在ることは、完備を意味しません」を置く。基準の文は揃えない。基準9 との非対称は、2つの要求の違い(記録の存在と、状態の開示の完備)であり、根拠水準マークで開示しない
2. **基準3 の結合キーは課さない。** 負債・未解決の行の「対象」へ PR を書く義務を足さない。台帳に無く、チェック項目も付けずに受け入れた妥協は、機械と判定者のどちらからも見えない。この穴を EV-0304 で開示する
3. **基準6 は、G-1 の閾値の記録と、比率を合否に用いていないことを確かめる。** 判定記録(テンプレ4)の基準6 の行に書く。新しい記録は足さない。機械は欠落を数えない。値の良否は判定しない。adopter にしない
4. **基準7 の適用は、D-0 表10 の「附属書F F.2 の回答」と、安全重要度 CL2・CL3 の記録で決める。** どちらも人が判定した記録で、機械は読むだけにする。CL から F.2 の判断を導かない(ADR-0039 と同じく、別の軸の判定で置き換えない)。食い違う案件は安全関連として扱い、判定者が備考に書く。CL0・CL1 の案件でも F.2 の Q1 が「はい」なら基準7 が掛かる。これは新しい義務ではない。Q1 が「はい」の案件は附属書F の対象で、F.7 の記録を附属書F が既に求めている。第8章 軸E の表(CL0・CL1 は「不要」)と附属書F F.2 の「適用外」には、この限定を書き足した。基準7 の例外承認は第7章 7.3 と ADR-0153 のとおりで、新しい条項を足さない。adopter にしない
5. **類似の検知の実施記録は4事項を持つ。** 用いた手段・対象の範囲・実施日・結果。道具の水準は定めない。台帳の区分に「類似検知」を足し、返却目安の期限を過ぎた未返却の行が残る出荷を止める。期限の延長と、実施しなかった出荷の先送りは、7.3 の例外承認で受ける。延長は区分「例外」の新しい行に書き、「対象」へ元の行の ID を書く。元の行の返却目安は書き換えない。機械は、有効な例外の行が対象とする行を欠落に数えない。adopter にしない
6. **散文のファイルの変更に、固有の判定を置かない。** 行数の算定から除外した変更にも、全ての変更と同じ判定完了時間の SLA と滞留の措置が掛かる。措置(催促・通知・代理の指名)は #445 の IMPL-0681・IMPL-0979 へ一本化する
7. **3.11.7 を改める。** 個人の指標との対を必ず確認する旨の文を、4指標を単独で提示せず、採用者が用いる生産性・速度の指標と並べて確認する旨の文に改める。並べる相手と手段は採用者が定める。これは意味の変更である。IMPL-0981 は `plan=adopter` にする
8. **課さないと決めたこと**を次に挙げる。**書かれていないだけではない**

   - **「個人の指標」を本標準で定義すること**(所有者の決定 2026-11-17)。理由は2つある。(a) 細かい定義を増やして、プロセスの柔軟性を失わない(所有者の方針 2026-11-16)。(b) 個人の単位の指標を標準が定義すると、個人の評価へ転用される危険がある([運用メトリクス](/process-compass/phase6-operation/metrics/)の設計の原則2・4と同じ向き)。本標準は、個人の単位の指標の収集も求めない
   - 基準3 の結合キー(負債・未解決の行の「対象」への PR の記入)
   - 基準6 の新しい記録(傾向の確認の実施の記録、並べた指標の名前を記録する欄)
   - 基準7 の例外承認への追加の要件(ADR-0153 決定3 を維持する)
   - 営業日の暦を必須の入力にすること(散文の SLA について)
   - 類似の検知の道具の水準
   - 類似の検知の結果による合否

## 採らなかった案

| 案 | 採らなかった理由 |
| --- | --- |
| 基準7 を adopter にする | 規格に根拠が無く、安全の統制が採用者の実装の有無で消える |
| 基準7 の機械の部分を別マーク(delivered presence)で持つ | 基準7 は1つの判定基準(ADR-0084 R-6)。機械の部分は新しい「基準7 の記録」の文に置く |
| 判定記録に「附属書F の適用」の欄を足す | D-0 表10 の F.2 の回答が既にあり、機械が検査している。同じ判断を2か所に書かせると食い違う |
| `q-criticality` が cl1〜cl3 なら基準7 の対象とする | CL1 は規則 r-e-cl2 の対象外。CL で F.2 の判断を置き換える(ADR-0039) |
| 基準7 の例外承認の可否を先送りする | 7.3・ADR-0153 決定3・EV-0295 に答えがある |
| 手引きに「基準7 の例外承認は独立した評価の記名を残す」と書く | ADR-0153 決定3 が課さないと決めた追加の要件を、手引きの形で足すことになる |
| 基準7 の例外承認を禁止する | ADR-0153 を覆す事例が無い。安全の最終判断は 5.8.3 が持つ |
| #448 の様式(IMPL-0933)を本束へ引き取る、または基準7 の全てを #448 へ寄せる | 前者は様式の二重決定、後者は判定と適用の出所が決まらない |
| 基準7 を「F.7 の記録が添付されている」に縮める | 統制が変わらない |
| 基準6 を adopter にする | 判定者の確認で、置き場はテンプレ4 に既にある。手順の欠けが未達の表示から消える |
| 基準6 を今すぐ delivered にする | 手順の置き場(`gates/G-7.md`)に手順が無い |
| 傾向の確認の実施の記録を新設する | テンプレ4 の行が既に記録。算出していない採用者に書けない義務を課す |
| 基準6 を基準から外す | 「合否に用いていない」を確かめる場が消える。基準番号は附属書H・D が引く |
| 機械が基準6 の欠落を失敗にする | 標準が合否にしないと決めている |
| 類似の検知を既存の区分(未解決)と「対象」の値で識別する | 区分の表で「通過を妨げない」区分の行が出荷を止める。テンプレ3 の「由来を混ぜない」に反する |
| 実施記録の偽の一致を開示だけで済ませる | 偽の一致が実行で確かめられており、開示では残る。知財は取り消せない損害 |
| 「使用せず、理由」を欄の値として通す | 承認なしに基準8 を外す経路になる |
| 基準8 を adopter にする、検知の結果で止める、道具の水準を指定する | 利用者側に責任が残り、推認への防御は記録だけである。検知の結果で止める先例は無い |
| 基準3 の結合キーを課す | 検出の範囲が判定者の突合と同じで、核心の穴(付けなかった妥協)は閉じない。完備を機械が確かめたように読ませる |
| 散文の変更の SLA を合否にする | ADR-0072・ADR-0058 の趣旨と当たる。暦が無いと偽の超過が出る |
| 散文の SLA の文を「管理する」「観測し、超過は 7.5 につなぐ」と書く | 前者は何を確かめるか読めない。後者は SLA の節の措置(3段)と食い違う |
| 営業日の暦を必須の入力にする | 固有の判定を置かないので要らない |
| 3.11.7 の文を削る、チームの生産性の指標との対に限る、推奨に弱める | 削ると4指標と原則1 の結び付きが消える。限ると相手を標準が持ち込み、定義が増える。弱めると誰が何を確かめるか決まらない |
| 「個人の指標」を定義する | 決定8 のとおり、課さないと決めた |
| IMPL-0136 の note に、読まれずに通る散文の検知の未達を戻す | 措置の SLA と検知の未達という別の主題が1つのマークに同居する。IMPL-1007 に分けた |
| 期限の延長を、区分「類似検知」の行の返却目安の書き換えで受ける | 承認なしの書き換えでも機械が通る。延長の承認と期限の記録が結ばれない |

## 影響

- **新しい負担**: 台帳の区分「類似検知」と実施記録の4事項(1行で書ける)だけである。小さいチームは、未処理の検知が出たときだけ区分を使う。独立の確認者は、本 ADR のどの決定も求めない
- 降りていない規定は次のとおり。IMPL-0044・IMPL-0045・IMPL-0046 は `gates/G-7.md` に手順が無い。IMPL-1004 は F.7 の未記入で、#448 が追う。IMPL-0548・IMPL-1005・IMPL-1006 は類似の検知。IMPL-0136 は措置で、#445 が追う。IMPL-1007 は読まれずに通る散文の検知(ADR-0092 決定7。IMPL-0136 から分けた)。IMPL-0981 は adopter。
- 期限内の未処理の区分「類似検知」の行は、保証の開示の項目5 に出ない(項目5 は基準1〜3 の記録から導き、集約は負債・例外・未解決だけを数える)。出荷判定者が基準8 の判定で台帳を読む。項目5 に含めるかは、新しい義務に当たるため、EV-0305 の見直しで審議する。課さないと決めたのではなく、未決である
- 降ろしたら、IMPL-1004・IMPL-1005 は違反と適合の対の試験を添えて machine にする。準拠テンプレートへの変更の一覧は `research/355-deliberation/b2-implementation.md` に置いた
- 機械で閉じる条件: F.7 の項目の置き場の有無と空欄、区分「類似検知」の行の期限超過(区分・日付・状態の比較)。機械で閉じない条件: 基準3・6・7・8 の判定の意味、実施記録の手段が実際に走ったか、チェック項目を付けない妥協(閉じない。EV-0304 で開示)
- 破られたとき失うもの: 基準3 は返却の追跡。基準6 は劣化の検証の材料。基準7 は事故時の検証の記録(採用組織・最終利用者)。基準8 は侵害の主張への防御(採用組織)。基準7・8 は取り消しにくい損害の側のため、項目まで条文に残した
- 根拠水準: EV-0304(基準3。E0)、EV-0305(実施記録と区分。E1)、EV-0306(3.11.7。E1)。EV-0277 は差し替え条件(#355 の重の審議で文の直し方を決める)を満たしたため外した
