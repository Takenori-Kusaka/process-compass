## 決定

### 1. 定めの無い事項の作業上の選択は、6 段の順に依り、成り立つ最初の段で止める

仕様 → 採用者の登録 → コードベースの流儀と既存の実装 → 基盤の機能と導入済みの部品 → 世の中の標準と既製の部品・マネージドサービス → 動く最小限の自作。順は、同じ事項で複数の段が成り立つときの決め方であり、上位の義務(削らないもの・人へ戻す3つ・判断記録・依存の確認)を免除しない。

### 2. 段5 の調べは、手元(段1〜4)に依る先が無い事項で、自分で作る前に毎回行う

これは問い1 の C の「いつも調べる」への議長の読みである(コンテキストの「議長の読み」)。手元で足りた事項では調べないので、世の中の標準との食い違いに気付く機会を失う。

規模・採用者の登録の有無を理由に省かない。深さ・範囲・手段は定めない。調べる手段が使えなければ止めず、調べられなかった旨を示す。手元で足りる事項は調べない(足す先が無い)。人の確認が増えすぎる主因である「手元で足りるのに調べて足す」形を、止まり方で塞ぐ。

### 3. 段5 は、標準に合わせることを先にし、部品・サービスを足すのは標準に合わせるだけでは足りない場合に限る

足す選択は、依存の追加であり設計上の選択です。判断記録(自作の案と並べる)・依存の一覧・G-6 基準5、判断記録の要否の規則に当たれば G-3 の、既にある経路へ載せます。新しい経路は作りません。1 つの機能のために足す複数の依存は、1 つの判断記録にまとめてよい。

### 4. 段1〜5 に依った選択は、外部の制約に従った選択として所在を記録する

標準は番号と版か公開された頁で示す。担い手が自ら開いて確かめていない所在には、推測の旨を添える。調べた範囲と該当なしは記録しない。比べて退けた部品は、退けた案として名と理由を記録する。依った先の記録は作成側の主張で、判定の根拠に数えない。

### 5. 調べた標準・部品が、仕様に無い法令・契約・安全の要求に当たるなら、自ら決めず人へ戻す

### 6. 削ってはならないもの(入力の検証・データの損失を防ぐエラー処理・セキュリティ・頼まれたこと)を、順より上に置く

採用者の登録でも外せない。段3・段4 に依るとこれらを損なうときは、倣って広げず、食い違いを示す。既存の箇所は直さない。

### 7. 標準は、確定の場で読む範囲を変えない。採用者は、パスと変更種別の規則で、記録された作業上の選択と理由を読む対象から外せる

外れるのは、それだけです。G-6 の判定・人へ戻す3つの場合・判断記録と G-3・G-6 基準5・コア機能の理解の確認は残ります。規則が無い構成は警告しません(所有者の決定「定めが無ければ今のまま」)。

### 8. 規則の条件に、記録の中身と担い手の申告を使わない。規則は基底ブランチの構成から読み、機械で当たりを判定する

AI の「倣った」「段に沿った」という記載を条件にすると、附属書H 原則2・H.4 条件4・ADR-0274 決定7・ADR-0267 決定3 に反する。所有者の決定は「種類を各社が定める」で、種類の書き方は決めていない。決定可能な条件(パス・変更種別)に限っても、各社は外す範囲を自由に選べる。

### 9. 規則は、R1 の変更と、安全重要度 CL1 以上・規制業の案件の変更に当てない

回答 2 の原文と、指揮役の読み・議長の読み(コンテキスト)による(決定12)。規則を置いても外さず、当てていない旨を示す。

### 10. 規則を置く・広げるのは統制を緩める向きの変更とし、D-0 の決定者の記名と理由を要する。規則を変える変更の下限は R2、製品のコードとは別の変更にする

置き場は、判断記録の要否の規則と区分の下限の規則と同じ形(パスと変更種別の規則の並び)に寄せ、照合の部品と検査を使い回す。委任の登録(標準変更カタログ)へは寄せない。

### 11. 外した件数を、規則ごとに、範囲の変更の件数と並べて、出荷の証跡の集約と保証の開示の項目2 に出す。止めない

件数は、合否に数えず、記載の欠落としても扱いません。外した範囲では、確定の場で記録された選択の誤りを見つける機会を失います。件数は、外した範囲を読み手へ示すために出します(EV-0395)。

### 12. 安全重要度 CL1 以上の案件・規制業の案件の変更と R1 の変更では、決め事を担い手が決めて進めない。案をまとめて既存の経路へ載せ、人が決める

決め事の範囲は議長の読みである(コンテキスト)。3 つ: 設計上の選択(2.6)、段5 の世の中の標準・既製の部品・サービスを使うかの選択(足さずに標準へ合わせる選択を含む)、仕様が定めていない、利用者・外部から見える振る舞い。決め事に依る実装は、人が決めた後に行う。決め事に依らない作業は止めない。載せる先は、設計と段5 に依るかは判断記録の案と G-3、仕様に無い振る舞いは機能仕様の未確定事項と G-2・G-4(着手の後は価値責任者への引き渡し)。新しい様式・欄・ゲート・ラベルを足さない。G-3 と G-4 の判定の時点も変えない。

### 13. 選択のたびに人を呼ばない

着手の前にまとめ、途中で当たったものは変更ごとにまとめる。R1 の変更では案に推しを付けない(5.5.5 項目1・5.7.3。どの案を採るかの理由は人が書く)。段階1 を要する変更では、人の方針の後に案を出す。区分の下限の規則が R1 を導く変更と、担い手が R1 と読んだ変更は、着手の時点から範囲に入れる。後から R1 と分かった変更では、決め事を案としてまとめ直して上げ、人が決めるまで取り込まない。

### 14. 人確定の変更でも、決め事に当たらない作業上の選択は、担い手が決めて記録する

5.5.1 は協働の席だけを書いていたため、人確定の読みを本文に明示する(5.5.1 の段落の文を足す)。

| 段5 の調べの深さ・件数・時間の下限 | 一律の値 | 所有者の指示 |

| 段5 を段3・段4 より上に置く | 標準を流儀より先にすること | 流儀との食い違いを直しにいく変更が、範囲の外の変更を生み、人へ戻す件数が増える。流儀が削らないものを損なう場合は、既に倣わない |
| 段5 で部品を足すことを第一の手にする(標準に合わせるより先) | 部品の先行 | 人の確認が依存の件数だけ増え、存在しない部品・供給網の露出が最大になる |
| 依存の追加の確認・判断記録を、段5 に沿った追加では軽くする | 確認の軽減 | ADR-0044 が退けた危険がそのまま当たる。所有者の決定にも無い |
| 「そもそも要るか」の段 | 段の追加 | スコープの定めが既に受ける |
| 外部の実例の「強さの 3 段」 | 段の追加 | 採用者の登録(段の上書き)で足りる |
| 削らないものへのアクセシビリティ・ハードウェアの校正の追加 | 項目の追加 | 本文にこの 2 つを要求する条項があるかを確かめていない。採用者は原則の登録で足せる |
| 段の順に従ったか・調べたかの機械の判定、AI による採点 | 機械の判定 | 決定可能でない |
| 決め事を上げたかの機械の検査 | 範囲の判定と上げたかの検査 | 上げたかは決定可能でない。範囲の表示だけ足しても統制は閉じない |
| 「本文の規範にしない(手引きと AI への指示まで)」(反対の委員) | 規範でない指示 | 所有者が既定に入れると決めた。規範でない指示は監査の基準にならない |

## 検討した選択肢

### 会議体の結論と、採られなかったこと

会議体の 4 委員は、新しい依存の段を既定に置かない結論でした。議長は、問い1・問い2 のどちらも A を勧めました。所有者は、どちらも採りませんでした(回答 1)。そのため、これらの結論は採られていません。標準は、所有者の決定を前提とします。反対の委員の 7 場面は、条件で塞ぐか、開示して残すことで受けます。

### 反対の委員の 7 場面への答え

| 場面 | 答え | どこで |
| --- | --- | --- |
| 1 既製へ倒して依存が増える | 条件で塞ぐ。残りは開示 | 段5 は手元で足りない事項に限る。標準に合わせて足りるなら足さない。足すのは設計上の選択で、判断記録・依存の一覧・G-6 基準5 に載る(規則でも外れない)。足す件数の増加は所有者が承知で選んだ。EV-0394(d)(f) で数える |
| 2 古い流儀へ倣い欠陥が広がる | 一部防ぐ。残りは開示 | 削らないものが順より上。倣って広げない。食い違いを示す。段3 が段5 より上なので、悪い流儀が良い標準に勝つ場面が残る。規則で外した範囲では誰も読まない(EV-0394(b)・EV-0395) |
| 3 拠り所の記載が定型文になる | 開示して残す | EV-0358(a) と EV-0394(a) |
| 4 警告の常態化 | 防げる | 登録が無いこと・規則が無いことを警告しない。外した件数は表示だけ |
| 5 AI が調べた「業界標準」が誤り | 条件で塞ぐ。残りは開示 | 所在(番号と版か公開された頁)を求め、自ら確かめていなければ推測と書く。法令・契約・安全の要求に当たれば人へ戻す。記録は主張で、判定の根拠に数えない。AI が確かめたと偽って書くことは止められない(EV-0394(e)) |
| 6 存在しないパッケージ | 既存の統制で防ぐ範囲。残りは開示 | 足す選択は依存の一覧(初出の名前)と G-6 基準5 に載る。依存の解決が走る構成では、未登録の名前は G-5 で落ちる。標準に合わせるを先にして足す件数を抑える。降りていないスタックは既存の開示のまま |
| 7 削らないものが削られる | 開示して残す | 条文に明示し、登録でも外せない。実効は独立に測られていない(EV-0394(c)) |

### 人の確認が増えすぎる場面と、塞ぎ方

| 場面 | 塞ぎ方 |
| --- | --- |
| O-1 小さな処理ごとに部品を足す | 段1〜4 で成り立つ事項には足さない。標準に合わせて足りるなら足さない |
| O-2 調べた結果の記録で確定の場の読みが膨らむ | 調べた範囲と該当なしを書かない。退けた部品は名と理由を 1 行。終わりの開示は 1〜2 行 |
| O-3 1 つの機能で部品を複数足す | 1 つの判断記録にまとめてよい(2.6) |
| O-4 調べた標準と流儀が食い違い、既存の箇所を直しにいく | 流儀が勝つ。食い違いは 1 行で示し、既存の箇所は直さない |
| O-5 調べる手段が使えない | 止めない。調べられなかった旨を書いて段6 へ |
| O-6 法令・契約・安全の要求が見つかる | 塞がない(人が決めるべき判断。既存の経路) |
| O-7 マネージドサービスが外部の契約・個人データに当たる | 塞がない(R1 で人確定。既存の 3.8.1) |

規則で新たに生じる場面は、次のとおりです。外した範囲での誤りの素通りは、開示して残します(件数を出す)。規則を広く書いて実質全件を外す場面は、置く・広げるに決定者の記名と理由を要し、件数を範囲の件数と並べて出すことで見えるようにします。R1 や安全の案件の変更が規則に当たる場面は、当てないことで防ぎます。

## 影響

- 実装は準拠テンプレートの次の所にある
  - `CLAUDE.md` と `scripts/gate/claude-md-resident.json`: 常駐の指示(決定1〜6・12・13)
  - `.claude/skills/implement/SKILL.md`・`.claude/skills/task-breakdown/SKILL.md`: 段の順・段5 の分け方・決め事を上げること
  - `scripts/init/generate-profile.mjs`・`scripts/gate/check-pr.mjs`・`scripts/gate/aggregate-evidence.mjs`: 規則の形・置く変更の記名・下限・件数の出力(決定7〜11)
  - `.claude/skills/gate/gates/G-6.md`: 外れるのは選択の記録を読むことだけであること
- 準拠テンプレートの文には、条項(章・節)だけを引き、ADR 番号・Issue 番号を足していない
- 依存の追加と自前実装の非対称は、一部だけ縮む。調べて退けた部品は、退けた案として記録に現れる。調べずに自作した事実は、今と同じく記録に現れない
- 部品・サービスの追加が増えると、判断記録・依存の確認・G-3 の人の確認が増える。所有者は問い1 の C で、この増加を承知で選んだ
- 採用者が規則で外した範囲では、記録された選択の誤りが確定の場で見つかる機会が無くなる。件数で開示する
- 安全重要度 CL1 以上・規制業の案件と R1 の変更では、決め事を人が決めるまで、その決め事に依る実装が待つ。待ちと人の負荷は実測が無い(EV-0396)
- 残る不確かさ: 段5 の調べの実効(準拠テンプレートの実行環境で調べる道具が使えるか)は確かめていない。「手元で成り立つ」「標準に合わせるだけでは足りない」「決め事に当たる」の判定は担い手がする(manual)。AI が開いて確かめたと書いた所在が、実際に開いたものかは確かめられない。仕様に定めの無いデータ形式を段5 の標準に合わせて決める選択が、5.5.1 の「データ形式を変える選択」に当たるかは確かめていない(新しく決める形式は「変える」に当たらないと読む)。実装の途中で当たった仕様の振る舞いを仕様へ書き戻すと、確定した版の変更として G-4 を受け直すことになり、待ちが重くなりうる
- ADR-0044 が退けた理由への答えの**残り**
  - 存在しない部品: 足す選択は依存の一覧と G-6 基準5 の人の確認に載る。足す頻度が上がれば、露出は増える。依存の解決が走らない構成では、存在しない名前は解決の失敗で落ちない(既存の開示のまま)
  - 供給網: 手元で足りるなら足さず、標準に合わせて足りるなら足さないことで、足さずに済むかを先に問う。人の確認を通る悪性の部品は防げない。採用者の供給網上の義務は免除しない
  - 規制: マネージドサービスの追加は判断記録の対象で、外部の契約・個人データに当たれば R1 として人が決める。データの所在の規制とマネージドサービスの関係は、外部の調査で出典を得られていない
  - 粒度: 作業上の選択の単位で調べる先例は無い(所有者の決定による。EV-0394)。「手元で成り立つ」の判定は担い手がする(manual)
- ADR-0273 との差は、保つ表の行のとおり。規定 B は、規則が無いことを警告しない
- 突合で見つけ、本件では直していないこと: 既にある判断記録の要否の規則(decisionRules)を、PR を経ないコミットで変えたときの下限 R2 を、集約が照らさない。今回足した規則(choiceReviewExclusions)では集約が照らす。過去の決定を固定した試験の場面に触れるため、本件の範囲の外とし、既存の Issue へ記録する
- 範囲の途中で安全重要度を CL1 以上から下げた構成では、集約は全規則を「当てていない」と表示し、外した件数を出さない。外した範囲を多く見せない側に倒れる
- 暫定の根拠水準: EV-0394(段の順と段5)、EV-0395(規則で外すこと)、EV-0396(決め事を先に人へ上げること)
