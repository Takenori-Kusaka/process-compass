## 決定

### 1. サンドボックスは本標準の要求事項を免除しない

第8章「社会実装の段階の調整」に、サンドボックスは既存規程の条項の手続を免除するものであり、本標準の要求事項を免除しないことを書きます。附属書H H.3 の内部監査も免除されません。既存の規定から導ける読みですが、明文が無かったため、本文に置きます。

### 2. 免除の期限を記録し、期限は自動では延びない

免除の期限を、試行前チェックリストに記録します。チェックリストの行を「サンドボックス申請が承認され、免除の期限が記録されている」へ改めます。期限は自動では延びません。延長は、新しい期限を記録した決定とします。期限の到来で自動的に延びる免除では、観点5 が判定の働きを持たないためです。

### 3. 観点5 の照合先を本文へ戻す

附属書H H.3 の観点5 の照合する規定を、第8章のサンドボックスの期限と延長、試行前チェックリストに記録した免除の期限とします。手引きは「〜参照」の形で引きます。所見の例に、延長の決定が記録されないまま期限を過ぎた運用を足します。観点の番号は振り直しません。

### 4. 承認者と申請の様式は採用組織が決める

申請の様式、承認者、期限と延長を決める手続は、採用組織が既存規程に基づいて決めます。本標準は定めません。手引きの3者(品質マネジメント所管・法務・予算責任者)の記名は、例として残します。

### 5. 内部監査の抽出の対象を、監査される当事者に選ばせない

附属書H H.3 の手続の段落に、「監査の抽出の対象を、監査される当事者に選ばせてはならない」を置きます。当事者は、監査の対象となる案件へ関与した者です(第3章の監査担当の要件1 と同じ語)。禁じるのは、どれを抽出するかの選定です。母集団の一覧を当事者が示すことは禁じません。1〜2名の体制で外部の監査担当が母集団を受け取る形を、成立させるためです。

第8章「事後監査の手続」の禁止は、H.3 の規則を事後監査へ当てはめたものと書き直します。当事者の範囲(切替を適用した変更の作成を指示した者)は、第8章の側に残します。

### 6. 実装の印を付けない

足した規範に実装の印(IMPL)を付けません。サンドボックスは採用組織の既存規程の免除の制度であり、準拠テンプレートに試行前チェックリストもサンドボックスの置き場もありません。内部監査の抽出は、監査する者(人)の手続であり、準拠テンプレートに内部監査の記録の様式がありません。どちらも、実装マークの規約が対象にしない「組織の制度設計に関する規定」に当たります。棚卸しの登録簿の附属書H「内部監査で確かめる観点」の区分(`org-design`)と同じ判断です。

## 採らなかった案

| 案 | 採らなかった理由 |
| --- | --- |
| 手引きのサンドボックスの申請の要求事項(条項の番号での列挙、置換先の対応づけ、置換先を示せない条項の免除の禁止、法令・契約・安全に由来する条項の免除の禁止、承認者の記名による成立)を本文へ上げる(起案の委員) | 新しい義務であり、重へ上げる要がある。品質マネジメントの特別採用・逸脱許可や、規制のサンドボックスの期限と延長の実務を調べていない。ADR-0085 決定1 の分け方(判定の対象は本文、手順は手引き)にも反する。法令・契約は第1章が外枠としており、免除されないことは既存の規定から導ける |
| 承認者を品質マネジメント所管・法務・予算責任者の3者に固定する | 組織の職制に依る顔ぶれである。法務の部門を持たず、決裁権限規程だけを持つ組織がある。承認者は採用組織が決める |
| 全社の監査部門の監査対象から外さないことを本文に置く | 全社の監査部門の監査範囲は、本標準の外の事項である。本標準の内部監査が免除されないこと(決定1)だけを置き、手引きの推奨に残す |
| 期限と延長の規則のすべてを採用組織に委ねる | 自動延長を定めた組織も適合し、観点5 の働きが外れる経路が残る |
| 観点5 を附属書H から外し、サンドボックスを全体として手引きの事項にする | ADR-0085 が却下した「標準には何も置かない」と同じ形になる。チェックリストの行が手引きの語を引いたまま残る |
| 今のまま(C-1・C-2 とも) | 観点5 が本文に無い期限を前提にし、事後監査が元の手続より厳しい食い違いが残る |
| 抽出の禁止を第3章の監査担当の要件の表へ置く | 表は実施者の要件であり、抽出は手続である。要件を満たせないときの代替(他チーム・外部・相互の監査)が抽出の禁止にも掛かるように読める |
| 第3章の要件1(関与していない実施者)で足りると本文に書く | 要件1 は誰が監査するかの要件で、誰が対象を選ぶかを扱わない。関与していない実施者が、当事者の選んだ抽出を監査する形が残る |
| 母集団の取り方、抽出の方法の記録、監査記録の様式の必須欄を本文へ上げる | 新しい義務であり、重へ上げる要がある(反対の委員)。記録の所在を規定する条項になり、体制ごとの負担の調査を要する |
| RC-11 の値(監査の周期と抽出数。EV-0010)を本件で改める | 本件で扱わない。起案の委員は抽出の規則と一緒に決めるとしたが、2委員の結論が重ならない |

どれも、決めていない事項ではなく、課さないと決めた事項です。ただし、重へ上げる要があるとした案(申請の要求事項、母集団の取り方と抽出の方法の記録、RC-11 の値の所在)は、調査と重の会議体を経れば採りうる案です。本件で新しい Issue は起こしていません。

## 影響

- 第8章「社会実装の段階の調整」: サンドボックスが本標準の要求事項を免除しないこと、期限の記録、自動では延びないこと、延長は記録された決定であること、採用組織が決める事項を足した。試行前チェックリストに免除の期限の記録を足した
- 第8章「事後監査の手続」: 抽出の禁止を、附属書H H.3 の規則の当てはめと書き直した
- 附属書H H.3「内部監査で確かめる観点」: 抽出の禁止を置き、手続の例を「〜参照」の形で引く形にした。観点5 の照合する規定を第8章へ戻し、所見の例を足した
- 手引き: 社会実装計画のサンドボックスの節の要求に見える表現(「申請の要求事項」「1名でも欠けた申請を成立させません」「自動延長を設けないことを勧めます」)を、例と本文の所在を引く文へ改めた。試行前チェックリストの写しを第8章とそろえた。プロセス内部監査の推奨の文を、附属書H を引く文へ改めた
- 範囲の外の気づき(`review.md` 6 節)のうち、フェーズ5・6 の頁の `description` に残っていた「規定」の語(qms-document-control・enablement・process-audit・incident-drill)を改めた。第4章「継続計測します」の書き方(食い違い D-1)は扱っていない
- 根拠水準: EV-0174 の差し替え条件の前者を満たしたと記録した(第1章 1.8)。条件の向きは事項を本文へ上げることであり、1.8 の定めは改めないため、マークは残す。EV-0163 は区分を保つ
- 実装マーク: 足していない(決定6)
- 記録: `research/367-review/`(`review.md` に 42 件の振り分け、`decision.md` に議長の裁定、`implementation.md` に実装の記録)
