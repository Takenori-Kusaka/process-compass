## コンテキスト

- [#456](https://github.com/Takenori-Kusaka/process-compass/issues/456): 第三者の意見(レビュー報告 2026-11-27)。決裁者は困りごと(失敗の型)で尋ねる。H.3 は主張起点、H.9 は問い起点で、個々の困りごとの止め方の区分と、降りていない規定(未達)の結線を持たない
- 外部の分類(OWASP の LLM アプリ向けと Agentic アプリ向けの Top 10、NIST AI 600-1)は、開発工程の失敗の型を構成原理に持たない(出典は下の「出典」)。MITRE ATLAS は出典台帳に無く、読んでいないため、本 ADR は根拠にしない
- 軽の審議(起案・反対の2委員)で割れた点を、議長が裁定した

## 決定

1. 附属書H の H.3 に、投影の節「困りごとから、止める場所と証跡へ引く」を置く。要求事項を持たない。各章を優先し、案件に記入を求めない
2. 行は外部の分類から取らない。構成原理と拾えない性質を表の前に併記する(ADR-0041)
3. 止め方の区分は6値(`機械が止める` / `機械が示し人が止める` / `人` / `未達` / `審議中` / `開示`)を手で書く。「最も弱い止め方」を行に示し、止まらない部分を事実の文で書く
4. 審議中は、Issue 番号と日付(`YYYY-MM-DD 時点`)を専用の列に表示する。審議中は本標準の本文の欠け、予定(実装台帳の plan=scheduled)は準拠テンプレートへの降ろしの欠けで、別に扱う
5. 機械の検査は、決定可能な表記の整合だけにする: 見出しの列、IMPL の実在、区分の語彙、未達と state=undelivered の一致、機械が止める升の必要条件(delivered かつ check=machine)、最も弱い止め方の導出、審議中の番号と日付。困りごとと条項の対応の正しさは検査せず、根拠水準のマーク(EV-0357、E0)で開示する
6. 新しい検査(`scripts/check-failure-projection.mjs`)は、本標準の文書どうしの整合の検査で、本リポジトリの `npm run lint:refs` だけで動く。準拠テンプレートと案件に掛からないため、H.3 末尾の「論証のために、新しいゲート・検査・様式を足さない」に当たらない
7. H.9 に問25 を足し、附属書D・I は問25 と H.3 から引く。EV-0272・EV-0058 の対象は問1〜24 に限る

| 台帳に「合否に使わない」の列を足す | 実装マークの書式の変更で範囲を超える。「止めるか」は note の自由な文の意味に依り、決定可能にならない |
| 外部の分類との対応の列、外部の型のうち表に無いものを表に並べること | H.10 が退けた、確かめていない範囲まで覆って見せる対応表になる |
| 列「担う主張」 | 主張と条項の対応は H.3 の表が正本。担わない欠けを投影で評価することになる(ADR-0056 決定9) |
| 行を区分ごとに分ける | 1つの困りごとが複数の行に散り、困りごと起点の目的を損なう |
| 審議中の Issue 番号を本文に書かない | 審議中を消すと、決裁者は今の範囲を確定した範囲と読む。「決めていない」と「課さないと決めた」の区別が失われる。附属書H と実装台帳に Issue 番号の表示の前例がある |
| 審議中の Issue が open かの検査 | ネットワークに依る。決定可能でない |
| 困りごとと条項の対応の機械の検査、表の自動生成 | 対応は意味の判断で、機械で閉じない統制は manual と根拠水準で開示する |
| 未達を H.11・I.9 の一般論へ送ること | 個々の困りごとの止まらない部分が、決裁者の問いの場所から見えなくなる |
| 管理された品質状態の新しい様式・指標・推移の表示、崩れの兆しの閾値の記載 | 採用者への新しい義務になる。必要な値は H.6・H.7・附属書I にある。H.5・H.7(値の良否で差し戻さない)に反する。証拠の列は既存の値の名だけを書く |
| 検査を足さず、`lint:refs` の節番号の検査の拡張に留める | 節番号の検査は「実在」だけを見る。IMPL の state と区分の一致、未達の結線は、表の列の意味を読む検査が要る |
| 列「止まらないこと」を独立の列にする | 最も弱い止め方の列が止まらない部分を示す。列を分けると、区分と食い違う記述を増やす |
| 行4(ブラックボックス化)の止める場所を空にする | 記録として残す場所は実在する。空にすると、止める場所が無いと読まれる |
| 行の出所を EV-0058 に相乗りさせる | EV-0058 の差し替え条件(問いの記録3件)が、困りごとの行の妥当性まで証すると読める。EV-0357 に独自の条件を持たせる |

## 影響

- 決裁者は、困りごとを起点に、止める場所・止め方・止まらない部分・証跡・引く条項を1つの表で読める。降りていない規定と審議中の欠けが、同じ行に出る
- 審議中の行は、結論の日にまたがって古くなりうる。日付を必須にし、当該の Issue の実装の段で行を改める(#454・#455・#457)
- 検査は表記の整合だけで、対応の誤りは検出しない。区分の誤りは、根拠水準の見直しと実装台帳の読み直しで直す
- 破られたとき: 表の区分を実装より強く書くと、決裁者が止まると誤って受容する。最も弱い止め方の列と未達の機械の検査は、その表示と実態の食い違いの一部だけを塞ぐ
- 再検討の契機: 実在の品質保証部門の問いで、本表に無い困りごとが出たとき。区分が実態と食い違う行が出たとき
