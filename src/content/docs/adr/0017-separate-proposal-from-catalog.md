## ステータス

採用(2026-08-06)

## コンテキスト

オーナーから次の指摘を受けていた。

> 統合プロセス参照モデル(AI協調型)は内容としてはそんなに問題ないと思いますが、**プロセス体系として新設が混じっていることに違和感がある**のと、**ここへの参照がフェーズ4からされることも違和感があります**。

この指摘は 2 つの内容を含んでいたが、質問管理表へ落とす段階で前半が欠落し、後半も ADR-0010 で「データとドキュメントの正本分担」という別の問題へ読み替えられた。**情報設計の問題としては一度も扱われていなかった**。

分離前の構成は次のとおりであった。

```
フェーズ1: 現状調査
  └ プロセス体系(データ駆動)
      ├ 一覧 / 横断比較表
      ├ ★ 統合プロセス(提案)   ← 本プロジェクトの提案
      ├ ウォーターフォール       ← 以下すべて既存手法の調査結果
      └ ...
```

既存手法のカタログに自作の提案が 1 件だけ混じり、**フェーズ1(現状調査)配下に置かれていた**。横断比較表でも、提案が既存手法と同じ表の**先頭**に並んでいた。

あわせて、階層レベルの表示名にも衝突が見つかった。ADR-0006 が定めた 3 ズームレベルの表示名 L1 / L2 / L3 が、第5章の AI自律レベル L1〜L3 と同じ記号になっていた。

## 決定

1. **統合プロセス参照モデルを独立したセクションへ移す**。サイドバーの配置はフェーズ3の後、フェーズ4の前とする。ギャップ分析の出力であり、標準の入力にあたるためである
2. **URL は変更しない**(`/processes/integrated/`)。フェーズ4の本文から多数の参照があり、外部リンクも壊さないためである
3. **カタログのセクション名を「既存プロセスの体系」へ改める**。何が載っているページかを名前で示す
4. **一覧ページで、提案を分類の外へ出す**。ページ末尾に「参考: 本プロジェクトの提案」として置き、調査対象ではない旨を明記する
5. **横断比較表から提案を外し、別表とする**。調査対象と同じ表に並べると比較の公平性が問われる。ただし情報は落とさず、同じ軸の別表として末尾に置き、優劣を示すものではない旨を明記する
6. **階層レベルの表示名を L1 / L2 / L3 から第1階層 / 第2階層 / 第3階層へ改める**。AI自律レベルとの記号の衝突を避ける

## 検討した選択肢

- **フェーズ4の配下へ移し、URL も変更する** — 位置づけは最も明確になるが、`/processes/` 配下はスキーマ駆動のカスタムページであり Starlight の自動生成から除外されている。移設には生成の仕組みごと変更が要る。またフェーズ4本文の多数の参照と外部リンクが壊れる
- **カタログの中に残し、視覚的にのみ区別する** — 変更量は最小だが、フェーズ1(現状調査)配下に提案が置かれている状態は変わらない。指摘の中心はこの点にある
- **横断比較表から完全に削除する** — 混在は解消するが、参照モデルが既存手法と比べてどういう構成なのかという情報が失われる
- **横断比較表にそのまま残す** — 情報は保たれるが、自作の提案を調査対象と同じ表の先頭に置くことが指摘された違和感そのものである
- **階層レベルの表示名を維持する** — 変更量は減るが、AI自律レベル L1〜L3 との衝突が残る。本プロジェクトは記号の衝突で 2 度改称を強いられており、同じ失敗を繰り返さない

## 影響

- `astro.config.mjs` のサイドバー構成を変更した。「プロセス体系(データ駆動)」を「既存プロセスの体系(データ駆動)」へ改称し、統合プロセスを独立セクションへ移した
- `src/pages/processes/index.astro` で、提案をカタログの分類から外し末尾へ移した
- `src/pages/processes/comparison.astro` で、比較表を既存プロセスと提案の 2 表に分けた
- 階層レベルの表示名を 3 ファイルで変更した。**ADR-0006 の本文は書き換えていない**。同 ADR が定めた 3 段階のドリルダウンという決定自体は有効であり、変更したのは表示名のみである
- URL とページの識別子は変更していないため、既存のリンクはすべて有効である
- ADR-0007(スキーマ駆動)および ADR-0010(正本分担)と矛盾しない。`integrated.yaml` は引き続き構造の正本である
- 提案が複数になった場合も、`category: proposal` を持つ要素は自動的に分離される構成にした
- 記号の索引([トレーサビリティと記号の索引](/process-compass/vision/04-traceability/))に階層レベルの記載はない。表示名の変更により、追加も不要である
