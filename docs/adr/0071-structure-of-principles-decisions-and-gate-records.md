## ステータス

採用(2026-10-23)。置き換える決定はありません。[ADR-0025](/process-compass/adr/0025-context-forgetting-over-detection/)の保管の手続と、[ADR-0018](/process-compass/adr/0018-assumption-ledger/)の決定8 の理由(書き換えない記録と変化する状態を統合しない)を、判断記録へ及ぼします。両 ADR の本文は書き換えません。[ADR-0034](/process-compass/adr/0034-stack-is-output-of-exploration/)の「検討した選択肢」の理由の1つが前提を失ったことを、本 ADR の決定9 に記録します。

## コンテキスト

[#289](https://github.com/Takenori-Kusaka/process-compass/issues/289) は、成果物の構造についての5つの Issue(#251・#252・#253・#272・#275 の原則4・9)を束ねました。指摘をそのまま条項にせず、調査・会議体・突合の順で扱いました。記録は `research/289-deliberation/`(調査 `survey-289-1`〜`4`、意見書 `council-01`〜`05`、`decision.md` の D-1〜D-6・D-15)にあります。本 ADR は、そのうち成果物の構造(D-1〜D-6)を記録します。文書の量は [ADR-0072](/process-compass/adr/0072-document-volume-is-not-a-metric/)、是正の起動と統制の設定は [ADR-0073](/process-compass/adr/0073-corrective-action-by-impact-and-control-effectiveness/)に分けました。1本の ADR が1つの問いへ答える形にして、部分の置き換えの連鎖を増やさないためです。

### 分けた先の様式が無かった

第2章 2.6 は、規約・用語を恒久層へ、設計上の選択を判断記録へ分けています。恒久層の側には様式がありませんでした。G-3 の基準2 の確認方法は「恒久層(設計標準)との突合」で、様式の無い置き場を指していました。実案件(#251)は、立ち戻る先として判断記録を読み、決まったことと採らなかった案が同じ文書に並ぶことを問題にしました。準拠テンプレートの `/adr-write` は「方針、原則」を判断記録の対象に挙げ、本文の 2.6 と逆を向いていました。

### 判定の対象・材料・証跡の語が無かった

第6章の成果物の一覧は、判断記録を「G-3 の判定対象」と書いていました。第4章の G-3 は「判断記録の書式が整っていても、選択が誤っていれば差し戻す」と読める規定を持ち、第7章 7.4 と [ADR-0036](/process-compass/adr/0036-gate-closure-by-record/)は判定の証跡を判定記録としていました。3通りの読みが並んでいました。G-3 の基準1 は様式の無い「設計案の非機能欄」を、基準3 はテンプレ2 に無い「『戻せない選択』欄」を確認方法にしていました。

### 状態の語彙が足りず、旧い側から辿れなかった

本プロジェクト自身の ADR で、置き換え 9 件のうち 6 件は、置き換えられた側の状態が「採用」のままでした(E2)。一部だけを置き換える語彙が、運用ルールに無かったためです。準拠テンプレートの保管領域の README は「参照対象に残したまま注記する方式は採らない。注記は読まれない」と書きながら、判断記録を保管の対象に挙げていませんでした。

## 決定

### 1. プロダクトの原則の様式(テンプレ12)を置き、義務にはしない

第6章にテンプレ12「プロダクトの原則」を置きます。置き場は恒久層(`context/standards/principles.md`)です。各原則は「名前・文・理由・含意(反する選択の例)」の4欄で書き、採らなかった案を書きません。置いた場合は技術判断者が記名し、原則の改廃は判断記録で記録します。原則はゲートの判定の対象にしません。事業の軸は企画書(テンプレ6)と品質保証の方針(層1)が持ち、原則へ再掲しません。

**置くことは義務にしません**。原則の層を置いた効果の測定がありません(E1)。置かない場合も、G-3 の基準2 は「突合先なし」の記録として判定記録に現れ、判定者が欠落を見られます。根拠水準は EV-0121 で開示します。

### 2. G-3 の基準2 の突合先を、存在する恒久層と、置き場に残る判断記録とする

基準2 の確認方法を「恒久層(用語集・設計標準・プロダクトの原則)のうち存在するものと、判断記録の置き場に残る判断記録(状態が採用または一部置き換え)との突合。いずれも無い場合は、突合先が無いことを判定記録へ書く」へ改めます。判断記録は恒久層に含めません。恒久層は書き換えて保つもの(原則・用語集・設計標準)であり、判断記録は書き換えない経緯の記録だからです(決定1・決定5)。一部置き換えの判断記録は、置き換えられていない決定が効いているため、突合先に含めます(決定7)。「突合先なし」の記録は、[ADR-0033](/process-compass/adr/0033-no-target-as-recorded-state/)の「対象なし」と同じ型です。

### 3. 判定の対象・材料・証跡を第1章で定義し、G-3 に当てる

第1章 1.4 に「判定の対象」「判定の材料」「判定の証跡」を定義します。判定の証跡は判定記録(テンプレ4)に限ります。G-3 は、対象を技術上の選択、材料を判断記録、証跡を判定記録とします。第6章の一覧の語を改め、ほかのゲートは成果物そのものが対象であることを確かめて残します。G-7 の運用引き継ぎ文書は材料と改めます。

[ADR-0036](/process-compass/adr/0036-gate-closure-by-record/)の決定2 が決めたのは判定の語彙(通過 / 差し戻し)であり、判定の対象の定義ではありません。本決定はこれと両立します。

### 4. G-3 の判定記録に判断記録の番号と版を書き、基準1・3 の確認方法を欄の名で書く

G-3 の判定記録に、判定した判断記録の番号と、判定した版のコミットを書かせます。判定記録は判断記録の内容を再掲しません。基準1 の確認方法を判断記録の「非機能への影響」欄へ、基準3 を「可逆性」欄へ改めます。「G-3 の判定対象」「設計案の非機能欄」「『戻せない選択』欄」の言い回しは廃し、廃した言い回しの登録簿に載せます。

### 5. 判断記録は独立の文書として `context/decisions/` に置く

判断記録を、実装計画・機能仕様・判定記録・PR の本文へ統合しません。書き換えない記録と書き換わる成果物を同居させない理由は、ADR-0018 決定8 と同じです。出荷の証跡の集約、G-6 の基準3 の添付確認など、機械と規定の読みは所在の固定を要します。

### 6. 判断記録の範囲を第2章 2.6 に定め、可逆性で要否を分けない

範囲は第2章 2.6 の1か所に定めます。設計上の選択を例示で示します(依存の追加・変更、外部インタフェース、データ形式、構成単位の境界、非機能への影響)。例示は網羅ではありません([ADR-0041](/process-compass/adr/0041-scope-is-not-exhaustive/))。原則と規約は恒久層に置き、判断記録に置きません。プロセスの構造の変更、安全重要度の引き下げ、実装スタックの変更は、既存の規定のとおり判断記録の対象です。

**選択が可逆であることを理由に、判断記録を省いてはなりません**。可逆性の評価は G-3 の基準3 の中身です。要否の判定へ前置すると、評価が判定の前に起案者の申告で済みます([ADR-0044](/process-compass/adr/0044-no-search-obligation-for-existing-parts/)決定4 と同じ論法)。準拠テンプレートの「方針、原則」と「作り直しに近ければ」の目安は本文に根拠が無いため、テンプレートの側を改めます。

### 7. 索引は課さず、全部を置き換えた判断記録と廃止した判断記録を保管領域へ移す

判断記録の索引の作成を課しません。状態と保管により、置き場そのものが現に効いている判断記録の集合になり、索引はその複製になります。状態から機械で導く一覧は禁じませんが、手で保守してはなりません。根拠水準は EV-0122 で開示します。

全部を置き換えた判断記録と廃止した判断記録は、その状態にした変更で、保管領域(`context/_archive/decisions/`)へ移し、読み込みから外します。一部を置き換えた判断記録は移しません。削除はしません。第3章 3.11.4 要求事項7 と ADR-0025 の保管の手続を、判断記録へ及ぼします。移す契機は状態だけであり、期間の経過では移しません。準拠テンプレートは、権限設定で保管領域の読み込みを拒否します。

判断記録の移動は、置き換える判断記録(または廃止)を判定した G-3(人が判定する)の帰結の事務です。ADR-0025 の決定8・10・11(読み込み実績を第一の基準とする、外す判断を AI に行わせず AI維持管理者が担う、四半期の棚卸しで判定する)が扱う、読み込み実績に基づく忘却の判断ではありません。ADR-0025 の決定9(削除せず保管する、読み込みから明示的に除外する、記録する)は、判断記録に及ぼします。ADR-0025 の決定は置き換えません。3.11.4 要求事項7 の記録の4項目は、次のとおり満たします。

- 外した日: 状態を改めた日(状態の行)
- 外した理由: 置き換え、または廃止(状態の行)
- 外した者: その G-3 の判定者(判定記録)
- 復帰の条件: 置き換えた判断記録が廃止されたとき

### 8. 状態の語彙に一部置き換えを加え、両側の参照を機械で検査する

状態の語彙を「採用 / 一部置き換え(→ ADR-MMM の決定 n) / 置き換え(→ ADR-MMM) / 廃止」の4つにします。置き換える側に「置き換える決定」の欄を必須にします。両側の一致と、状態と置き場の一致を機械で検査します(準拠テンプレートの `check-decisions`)。採用後に書き換えてよいのは状態の行だけであり、状態の行は本文に含めません。本プロジェクトの ADR のうち旧い側の状態が採用のままだった 6 件(ADR-0009・0017・0032・0035・0040・0054)は、状態の行だけをこの語彙で改めます。

### 9. 範囲の外の論点と、前提を失った理由を記録する

- #275 の原則6(設計書を単一の情報源に)は、本 ADR で閉じる。設計書という単一の成果物を課さない。情報源は機能仕様の受入基準と実装計画、選択は判断記録、立ち戻る軸はプロダクトの原則である
- #275 の原則5(基準が言い訳に転用されるパターン)は、#290 へ送る
- ADR-0034 は「スタックの確定を G-3 の要件とする」案を、「G-3 は S0 では主要な選択のみに簡略化されている」ことを理由の1つとして退けた。[ADR-0063](/process-compass/adr/0063-normative-informative-and-verbal-forms/)で S0 の G-3 は「適用」となり、この理由は前提を失った。案の再評価はしない。当時退けた案を採る材料は、今回出ていない
- 規則データの判定の語彙(`integrated.yaml`)が全工程ゲートで ADR-0036 の2値と異なっていたため、全ゲートを「通過 / 差し戻し」へ直す。新しい判断を要しない

## 影響

- 第1章 1.4 に、判定の対象・材料・証跡の語が加わる
- 第2章 2.6 に「判断記録の範囲」が加わる
- 第4章 G-3 の前文・判定基準の表・記載の検査の表が改まる。両側の参照の検査は実装マーク IMPL-0131(降りている)、欄の形式の検査は IMPL-0132(降りていない)で示す
- 第6章に、テンプレ12、原則・判断記録・判定記録の関係の図、テンプレ2 の「置き換えと廃止」と「判断記録の索引」の節が加わる
- 準拠テンプレートに `templates/12-product-principles.md` と `scripts/gate/check-decisions.mjs` が加わり、権限設定が保管領域の読み込みを拒否する
- 本プロジェクトの ADR の運用ルール(`adr/index.md`)の状態の語彙を、本決定の4つへ改める
- 判断記録の範囲の例示は網羅ではない。例示に当たらない選択を判断記録へ残すかは、技術判断者が決める
