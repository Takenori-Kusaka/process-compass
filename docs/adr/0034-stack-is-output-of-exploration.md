## ステータス

採用(2026-08-12)

## コンテキスト

実案件の立ち上げで、**実装スタックをいつ確定すべきかが本標準に規定されていない**ことが判明しました。

本標準の記述は、S0 の開始時にスタックが決まっていることを要求していません。むしろ逆を示しています。

| 箇所 | 記述 |
| --- | --- |
| [第2章 2.3](/process-compass/phase4-process-design/lifecycle/) | S0 のゴールは「事業仮説と**技術的実現性を検証し**、投資継続の可否を判断できる状態にする」 |
| 同 2.4 | SG-0 の判定基準に「**技術的実現性が確認されている**」 |
| 同 2.5 | G-3 技術設計判断は S0 では「**主要な選択のみ**」 |

つまり**実装スタックは S0 の出力であり、S0 の入力ではありません**。ところがこの理解が本文のどこにも明文化されていないため、構成を決める道具が付随項目としてスタックの確定を前倒しで求めても、標準と照らして誤りだと判定できませんでした。

実案件では、構想メモの記述を根拠に選んだスタックと、S0 の実測で有望と判明した構成が食い違いました。**構成を決めた時点では原理的に決められない事柄でした**。

放置した場合の帰結は3点です。

- 技術判断者の判断記録(ADR)を伴わずに、構成の付随項目としてスタックが無自覚に確定する
- S0 の実測結果と食い違ったとき、確定済みの構成が既成事実として働く
- 構成を訂正する手続(いつ・誰が・何を根拠に変えてよいか)が定義されていない

## 決定

1. **実装スタックの確定時期を SG-0 とする**。S0 の期間中は未確定でよい
2. **SG-0 の判定基準を増やさない**。実装スタックの確定は、既存の基準「技術的実現性が確認されている」に含まれるものとして扱う。基準を増やすと、判定の項目が実装の詳細へ寄る
3. **S0 期間中の「未確定」を、構成として表現できる正規の状態と定める**。未確定は未達ではない。**未達は目的を達成する構成を示せていない状態であり、未確定は時期が来ていない状態である**
4. **SG-0 を通過した後に未確定が残る場合、未達として扱う**。この時点以降、未確定は「決められない」状態を意味する
5. **構成へ記録済みのスタックを S0 の結果に基づいて変更する場合、技術判断者の判断とし、判断記録(ADR)を必須とする**。**G-1 の再判定は要しない**。企画承認の判定基準4項目は実装スタックを含まないため
6. **スタックが未確定であっても、プロセス構成の初期化を実行してよい**ことをテーラリングへ明記する

## 検討した選択肢

- **SG-0 の判定基準に独立の項目として加える** — 確定の要求が明示される。しかし SG-0 は投資の継続を判断するステージ移行ゲートであり、判定の項目に実装の詳細が入ると、**会議体が技術選定の是非を審議する構成になる**。技術設計の良否はステアリングコミッティの決定事項ではない
- **スタックの確定を G-3 の要件とする** — 技術判断者の判断として扱う点は筋が通る。しかし G-3 は S0 では「主要な選択のみ」に簡略化されており、**簡略化された G-3 に確定を要求すると、簡略化の意味が失われる**
- **構成の初期化より前に S0 の探索を先に回す** — 順序としては自然に見える。しかし探索がプロセス構成のない状態で行われる作業になり、統制の外で技術選定が進む。**構成の側が未確定を表現できるようにするほうが筋である**
- **未確定を未達として扱う** — 既存の枠に収まる。しかし未達は調達先の記入と代償措置を要求する状態であり、**S0 の全期間にわたって未達の宣言が立ち続ける**。ADR-0028 が区別した未達の意味が薄れる
- **スタックの変更に G-1 の再判定を求める** — 変更が決裁の目に触れる。しかし G-1 の判定基準4項目は実装スタックを含まず、**判定の対象でないものを理由に再判定を求めることになる**。判定の滞留だけが増える

## 影響

- 第2章に、実装スタックが S0 の出力であることの明記が加わる
- 第8章に、スタック未確定でも構成を初期化してよい旨が加わる
- 決定4 により、SG-0 の通過後は未確定が未達として現れる。**時期による状態の切り替わりを、構成を決める道具が表現できなければならない**
- 決定5 により、S0 の結果に基づくスタックの変更は判断記録を伴う。**記録のない変更は、判断を経ていない変更として扱う**
- 本 ADR は、S0 の実測とスタックの事前選択が食い違った単一の事例に基づく。ただし決定の根拠は事例ではなく、**S0 のゴールと SG-0 の判定基準から導かれる論理である**
