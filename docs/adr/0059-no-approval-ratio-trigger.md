## ステータス

採用(2026-10-13)。一部置き換え(→ ADR-0081 の決定1・決定6): 決定3 の「残る3つの比率」を2つ(差し戻し率、手戻り率)へ、決定5 の `basis.detection` の3つの欄を2つへ、[ADR-0081](/process-compass/adr/0081-autonomy-downgrade-delivered-as-registration-stop/)の決定1 が置き換えました。決定4(準拠テンプレートは比率を算出せず、IMPL-0104 を降りていないと表示する)は、同 ADR の決定6 が置き換えました。影響の節の「4行目の措置の語」は、現在の3行目(手戻り率の行)を指すと同 ADR の決定8 が読み替えました(2026-10-23)。

本 ADR は、[ADR-0054](/process-compass/adr/0054-seat-accountable-performer/)の決定4 のうち、次の2点を置き換えます。「5.4.6 の検知条件」として4つの比率を数える部分を、3つ(差し戻し率、重複率、手戻り率)へ置き換えます。登録の根拠の1点目(「5.4.6 の検知条件を何で計測するか」)を、検知条件ごとの算出の所在へ置き換えます。決定4 のそれ以外(登録の根拠を連続運用の期間に置かない。機械が確かめるのは記入の有無まで)は維持します。

## コンテキスト

[#303](https://github.com/Takenori-Kusaka/process-compass/issues/303) は、第5章 5.4.6 の検知条件「自動承認の比率が急上昇した(初期値: 前月比2倍)」に、量の定義(分子・分母・単位)が無いことを指摘しました。根拠水準マーク EV-0090 は、差し替え条件を「定義と、その定義で集計した3か月分の実測」としていました。指摘をそのまま条項にせず、調査・会議体・突合の順で扱いました。記録は `research/302-310-deliberation/`(`survey-303.md`、`council-C-01`〜`05`、`decision.md` の C-1〜C-3)にあります。

### 定義が書けなかった

5.4.6 がこの量に求める条件は、本文から3つ読めます。

| # | 条件 | 本文の根拠 |
| --- | --- | --- |
| a | 人の点検を経ずに、記録から算出できる | 「人間の点検を挟むと、引き下げは判定になります」 |
| b | L2 の前提なので、L1 の時点で値を持つ | 「第2区分の計測ができない範囲へ、L2 以上を適用しません」 |
| c | 上昇が、監督の劣化を示す | 節の趣旨 |

調査が挙げた定義の候補は、どれも3つを同時に満たしませんでした。

| 候補 | 満たさない点 |
| --- | --- |
| 挙動要約を伴わない承認の比率 | 形の検査は、意味の無い8文字を挙動要約に数える(調査と委員が実行して確認)。分子から外れる最短の経路が「8文字書く」になる。G-6 を適用する体制では、要約を欠く承認は記録の欠落として差し戻されるので、分子が0へ寄る |
| 人の確認なしに実行された操作の比率 | 2026-10 時点で、確認を省く実行は実行基盤の既定の設定になった。値は基盤の版と設定で動き、利用者の監督を測らない |
| 人の事前確認を経ない変更の比率 | L1・L2 では定義上0になり、条件 b を満たさない。委任の側の引き下げ(5.5.7)と重なる |

出所の報告自身は、この比率の上昇を、信頼の蓄積として解釈しています。劣化の指標として使っていません。

### 同じ語が、禁止の対象と計測の対象を指していた

「自動承認」は、判定期限の超過を承認とみなすことの禁止(第4章 共通ルール 2 ほか5か所)にも使われています。こちらは揺れがありません。

### 残る比率にも、窓と実装の欠落があった

- 5.4.6 の「2か月継続」は月の窓で数える。第4章「閾値の設定と較正」は、母数の下限を満たさない期間の値を判定に用いることを禁じている。5.4.6 はこの節を引いていなかった
- 準拠テンプレートは、差し戻し率・重複率・手戻り率のどれも算出しない。AI自律レベルを構成に持たない。5.4.6 は「検知した時点で自動的に発火します」と書くが、降りていないことの表示が無かった
- 登録の根拠の欄 `basis.detection` は自由記述で、「計測していない」と書いても受け付けた(委員が実行して確認)。準拠テンプレートの記入例は、比率の計測ではなく欠陥の検知手段を書いており、条項と読みが違っていた

## 決定

### 1. 行を廃し、課さないと明記する

5.4.6 の表から「自動承認の比率が急上昇した」の行を外します。本標準は、人の確認を経ずに進んだ操作や変更の比率にも、承認に占める特定の形の比率にも、検知条件と判断基準を課しません。その旨を 5.4.6 に明記します。

形骸化の検知は、欠陥注入による検出能力の測定(第5章 5.6.2)と承認権限の一時制限(第7章 7.9)、および運用メトリクスの既存の2指標(レビュー所要時間の分布、挙動要約の品質)が担います。2指標を、引き下げの検知条件にも、合否条件にもしません。

EV-0090 は、差し替えではなく、対象の規定の廃止によって閉じます。番号は再利用しません。

### 2. 量の名前としての語を廃する

計測する量の名前としての「自動承認の比率」を廃します。判定期限の超過を「自動承認」としてはならないという禁止は、変えません。廃した語は、廃した言い回しの登録簿に載せ、再び現れたら検査で落とします([ADR-0063](/process-compass/adr/0063-normative-informative-and-verbal-forms/))。

### 3. 残る3つの比率を、母数の下限に従わせる

5.4.6 の第2区分の検知条件(差し戻し率、重複率、手戻り率)の集計は、第4章「閾値の設定と較正」の要求事項3(母数の下限)によります。下限を満たさない期間の値で、引き下げを発火させません。

### 4. 自動の発火が降りていないことを表示する

5.4.6 に、実装マーク IMPL-0104(降りていない)を付けます。準拠テンプレートは3つの比率を算出しません。採用者が集計の手段を備えるまで、引き下げは発火しません。5.4.6 が定めるとおり、備えるまでは L1 で運用します。

### 5. 登録の根拠は、検知条件ごとに算出の所在を書く

第5章 5.5.4 の「登録の根拠の記録」の1点目を、「5.4.6 の第2区分の検知条件のそれぞれについての、算出の所在」へ改めます。検知条件の名前だけの記入と、計測している旨だけの記入を、算出の所在として扱いません。準拠テンプレートの `basis.detection` は、3つの検知条件ごとの欄を持つ形にします。記入例は条項に合わせます。

機械が確かめるのは、検知条件ごとの記入の有無までです。内容は登録する者が判定します。この線は ADR-0054 決定4 から変えません。

:::caution[暫定 EV-0098 / 見直し 2027-04]
**対象**: 承認の比率は監督の劣化だけを映さないという判断と、形骸化の検知を検出能力の測定と承認権限の一時制限に委ねれば足りるという前提。
**根拠の水準**: E1(間接)。
**差し替え条件**: 採用組織での第7章 7.9 の発動の件数。差し戻し率が0%でないまま、検出率の低下した範囲の件数。

承認の比率は、対象の品質と提示の設計で動きます。この判断は、隣接する領域の報告に依ります。医療の警告、ブラウザの警告、AI の実行基盤の提供者の自己報告です。本標準の文脈での測定はありません。検出能力が未測定の体制では、7.9 は発動しません。その体制で人の承認の形骸化を検知する条件は、差し戻し率0%の継続だけです。
:::

## 検討した選択肢

| 案 | 採らなかった理由 |
| --- | --- |
| 挙動要約を伴わない承認の比率に定める | #300 でこの案を推した委員が、今回の実行結果を受けて撤回した。形の検査は意味の無い文字列を通す |
| 量の定義を組織に定めさせる | 標準が何を測る量かを言えないまま、その量を L2 の前提と自動の引き下げに使い続けることになる。定義の無い量を発火条件に残す点は変わらない |
| 傾向の確認へ格下げし、指標を1つ足す | 近い指標が運用メトリクスに既に2つある。足す理由が無い |
| 検出率の低下を検知条件に置き換える | ADR-0054 決定4 は、判定の履歴の集計と検出能力の測定を別の量として分けている。検出率の低下による制限は第7章 7.9 が既に定めており、同じ低下に2つの措置が付く |
| 倍率を別の値へ改める、絶対の水準を置く | 量の定義が無いので、値を置く対象が無い |
| 1時間あたりの行数の線(200行/時)を足す | 出典が1系統であり、今回の論点の外である |
| 決めない | EV-0090 の差し替え条件は、定義と実測である。定義が無ければ実測は始まらない。待っても材料は増えない |

## 影響

- 5.4.6 の検知条件は4行になる。継続的な集計を要する検知条件は3つになる。第5章 5.5.4、第8章、附属書H の列挙を合わせた
- 人が確認を省き始めることを、承認の比率からは検知しない。検知は、差し戻し率0%の継続と、欠陥注入による検出能力の測定に依る
- 準拠テンプレートの構成の `basis.detection` の形が変わる。1つの文で書いた既存の記入は、記入なしとして拒否される。採用者は、3つの検知条件ごとに書き直す
- 「計測していない」と3つの欄に書けば、機械は受け付ける。変わるのは、検知条件ごとの記入が記録に残る点である。記入の内容は、登録する者と内部監査が確かめる
- 5.4.6 の表のほかの値(「1件」「2か月継続」)の根拠水準と、4行目の措置の語(「検討する」)は、今回決めていない
