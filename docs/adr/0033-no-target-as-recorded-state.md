## ステータス

採用(2026-08-12)

## コンテキスト

本標準は次の順序を要求します。

```
プロセス構成 → G-1 企画承認 → G-2 要件合意 → G-3 技術設計判断 → G-4 機能仕様承認 → 実装
```

**したがって案件の最初の数件の変更は、標準に従う限り必ず文書のみになります**。ところが[G-5 の判定基準](/process-compass/phase4-process-design/gate-criteria/)8項目のうち、テスト・静的解析・カバレッジ・ライセンス検査は、**検査の対象そのものが存在しません**。

これは特定の案件の事情ではありません。**標準が要求する順序に対して、G-5 の規定が実装の存在を暗黙の前提に置いていた**ことによります。

一方で、本標準には「実施しなかったことを記録して通す」という思想が既にあります。

| 箇所 | 記述 |
| --- | --- |
| 第4章 G-5 基準8 | 判定するのは「検出されなかったこと」ではなく「**定めた検査を実施し記録したこと**」 |
| [ADR-0021](/process-compass/adr/0021-ip-clearance-evidence-not-guarantee/) | 知財の潔白性は保証ではなく証跡である |
| [ADR-0028](/process-compass/adr/0028-unmet-gate-distinct-from-omitted/) | 未達と省略を区別する |

規定されていなかったのは、**この思想を「検査対象が存在しない」場合へ適用してよいか**でした。

## 決定

1. **G-5 の判定基準は8つのまま変えない**。ステージや段階によって基準の数を変えない
2. **検査対象が存在しない基準は、「対象なし」として証跡へ記録したうえで通過させる**。通過の根拠は「検査の結果が0件であったこと」ではなく、**対象が存在しない事実を記録したこと**とする
3. **基準7(秘匿情報の混入検査)を免除しない**。リポジトリ全体が常に検査の対象であり、実装が存在しない段階でも対象は存在する。第4章の「台帳への記録による通過を認めない」を、この局面でも動かさない
4. **基準6(文脈ファイルの形式検査)も免除しない**。文書のみの変更では、むしろ文脈ファイルが主たる変更対象になる
5. **「対象なし」の記録に、どの基準か・対象が存在しない理由・判定の時刻を含める**
6. **実装が存在する段階でこの扱いを用いてはならない**。テストコードが存在するにもかかわらず0件で通過する経路を作らない
7. **「対象なし」を、未達および省略のいずれとも区別する**。未達は目的を達成する構成を示せていない状態、省略は適用しないと決めた状態を指す。対象なしは**適用しているが、いま対象が存在しない状態**である。ADR-0028 の2区分へ third state として加えず、G-5 の証跡の属性として扱う
8. **出荷判定(G-7)の突合で、「対象なし」の記録を記録の欠落と区別する**

## 検討した選択肢

- **段階に応じて G-5 の基準数を変える** — 文書のみの段階では基準を4つに減らす案。判定は単純になる。しかし基準の数が段階で変わると、**どの段階のどの基準で通過したのかを後から追えなくなる**。G-7 の突合も段階ごとの分岐を持つことになる
- **文書のみの変更を G-5 の対象外とする** — 最も簡単である。しかし基準6・7 は文書のみの変更でも対象を持ち、とくに秘匿情報は文書へ混入する。**対象外にすると、混入の検査が最も必要な段階で検査が外れる**
- **実装が存在するまでゲートを開始しない** — 順序としては筋が通る。しかし本標準は G-4 の前に実装を始めないことを要求しており、**実装の開始前に必ず文書の変更が発生する**。ゲートを開始しない期間は、統制の外で変更が進む期間になる
- **0件を合格として扱う** — 実装が容易である。しかし「検査したが0件だった」と「検査対象がなかった」が同じ記録になる。**後者を前者として残すと、検査を実施した記録が偽になる**
- **未達(unmet)として扱う** — ADR-0028 の既存の枠に収まる。しかし未達は調達先の記入と代償措置を要求する状態であり、**時間の経過だけで解消する状態へ適用すると、未達の宣言が形骸化する**

## 影響

- 第4章 G-5 に「検査対象が存在しない場合の扱い」の節が加わる
- 基準7・基準6 は、実装が存在しない段階でも実施しなければならない。**この2つを通す構成を持たないテンプレートは、標準に反する**
- 決定6 により、実装の開始後に「対象なし」を用いた記録が現れた場合、それは検査の不備を示す
- G-7 基準5 の突合に、「対象なし」と欠落を区別する手続が加わる
- 本 ADR は、案件の初期に文書のみの変更が発生するという観測に基づく。**この観測は本標準の要求する順序から導かれるものであり、単一の案件に固有ではない**
