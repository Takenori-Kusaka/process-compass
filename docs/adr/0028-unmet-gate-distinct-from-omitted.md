## ステータス

採用(2026-08-08)

## コンテキスト

[ピットイン方式 準拠テンプレート](https://github.com/Takenori-Kusaka/pit-in-template)は、軸A〜E の回答からゲートの構成を導出します。ここで、1人の開発者が AI エージェントへ実行を委ねる構成をどう扱うかが問題になりました。

[第8章 軸A](/process-compass/phase4-process-design/tailoring-guide/)は、1〜2名の体制で独立レビュー(G-6)を外部へ依頼すると定めています。外部の依頼先がいない場合、テーラリングの規則は G-6 を省略へ倒します。

しかしこの省略は、他の省略と性質が異なります。第8章の調整は3つの要求を同時に満たすことを条件としており、要求3は「調整後の構成で当該ゲートの目的が達成されることを示す」ことです。1人と AI で G-6 の目的が達成される構成は示せません。

[G-6 の判定基準](/process-compass/phase4-process-design/gate-criteria/)5項目のうち、4項目は開発者(検証)として自分で実行できます。埋まらないのは「作成を指示した本人でない」の1項目だけです。作成時に抱えた思い込みを、抱えていない人が見ること。1人ではこれが成立しません。

AI で埋めることもできません。第8章は「AI を独立レビュアの代替に置きません」と規定し、[第5章 5.8.4](/process-compass/phase4-process-design/human-ai-boundary/)は「エージェントを分けたことをもって独立性を確保したとみなしてはならない」と規定しています。

## 決定

ゲートの状態に **`unmet`(未達)** を設け、`omitted`(省略)と型として区別します。

| 値 | 意味 |
| --- | --- |
| `required` | 適用する |
| `simplified` | 簡略化して適用する |
| `merged-into-gN` | 他のゲートへ統合する |
| `omitted` | 標準の規則により省略する。調整として成立している |
| **`unmet`** | **目的を達成する構成を示せていない** |

7つの決定を含みます。

1. 1〜2名かつ外部のレビュアが不在の構成では、G-6 を `omitted` ではなく `unmet` にする
2. `unmet` はプロセス構成書の**冒頭**に表示する。下位の節へ送らない
3. 出荷判定の証跡と品質レポートにも必ず載せる。隠す経路を設けない
4. 未達を埋める調達先の欄を設け、**未記入は未記入として表示する**
5. 契約検査は、`unmet` の記録がない状態への書き換えを失敗させる
6. 代償措置(CI 基準の厳格化、事後の抜き取り監査)は記録するが、**未達の解消として扱わない**
7. AI レビューは G-5 の拡張として置き、承認させず、合否条件にもしない

## 検討した選択肢

| 案 | 採らなかった理由 |
| --- | --- |
| 省略として扱い、テーラリング宣言に理由を書く | 宣言は差分の追跡手段であって、目的達成の代替ではない。要求3を満たさない調整は、本標準に基づく調整として扱われない |
| モデルや文脈を分けた AI を独立レビュアとして認める | 同一のモデルでは事前学習の知識という共通の原因が残る。生成物の確認を生成器へ委ねる構成は、自動化バイアスによって見落としを増やす |
| G-6 を初期状態で外し、CI の厳格化だけで代替する | 何が欠けているかが構成から読み取れなくなる。「独立レビューのない構成」が既定の姿として定着する |
| 1〜2名の利用を想定から外す | 個人開発は最も導入しやすい入口であり、ここを閉じると標準そのものが試されない |
| 未達を警告として出し、一定期間で消す | 期間で消える表示は、期間の経過を待つ動機を生む。未達は解消されるまで残るべきもの |

## 影響

- テンプレートは、1人の利用者へ「このプロセスは完全には成立していない」と表示し続ける。心地よい表示ではない
- 未達を消す操作は存在しない。埋めるか、体制を変えるかのいずれかによる
- 代償措置を実施しても未達は残る。**時点を動かす調整と、判定そのものの不在は別の問題**
- 安全重要度 CL1 以上および規制業では、1〜2名の構成そのものを拒否する。危害の深刻度は体制の都合で下がらない

**未達の表示は、品質の保証にも不足の証明にもなりません**。示しているのは、標準の要求のうちどれを満たせていないかだけです。満たしている項目の妥当性は、ゲート判定の記録によります。
