## ステータス

採用(2026-11-18)。[ADR-0175](/process-compass/adr/0175-assign-445-450-undelivered-to-adopter-or-template/) の型(決定1・2)に従い、同じ区分を 3 件へ広げる。置き換えない。軽の審議の結論です(束 B15、`research/b15-template-items/intake.md`)。

## コンテキスト

- IMPL-0303(出荷を起動する取り込みの前の G-7 の判定記録)、IMPL-0715(廃止予定の棚卸し・通知・着手の期限)、IMPL-0718(全社の統制の警告→猶予→必須の反映)は、plan=scheduled のまま、降ろし先の置き場が準拠テンプレートに無い
- 0303 は、配備のワークフローをテンプレートが持たない(ADR-0090 決定6)。0715 の棚卸しと通知は AI 実行基盤の側の活動である。0718 の統制の更新と予定日は全社の側で決める

## 決定

1. IMPL-0303・0715・0718 を plan=adopter・check=manual・decision=ADR-0184 とする。規定は課したままである
2. IMPL-0718 は組織の側の文へ絞る。受け手の側(新しい検査を警告として先に入れる書き方)は新しい IMPL-1024(target=handoff-reference、plan=scheduled)で追う
3. 3 件に確かめる者を置く: 0303 は採用者の出荷判定者、0715 と 0718 は採用者の AI運用担当者

## 課さないと決めたこと

なし。3 件の規定は課したままで、採用者への新しい義務は生じない。

## 検討した選択肢(採らない)

| 案 | 採らなかった理由 |
| --- | --- |
| 0715 の着手の期限を依存先の欄(IMPL-0065)へ日付の欄として足す | 自己申告の欄を増やすことになる(ADR-0165 決定3 と同じ懸念)。破られたときの損失が、安全・取り消せない操作・適合の主張の信頼のどれにも当たらない。445〜450 の突合 1巡目が戻した点を、問い3 で裁定し直した |
| 0718 の昇格の予定日を構成に持たせ、gate-g5 の阻止を日付で切り替える | 理由は同じ。組織の側の決定を案件のリポジトリへ写すだけで、機構が大きい |
| 0303 を配備のワークフローの雛形として降ろす | テンプレートは配備のワークフローを持たない(ADR-0090 決定6) |

:::caution[暫定 EV-0324 / 見直し 2027-11]
**対象**: 3 件を採用者の実装とする線引き。採用者の実装の欠けを生まないことは測られていない。
**根拠の水準**: E0(なし)。
**差し替え条件**: 3 件について、採用者から「テンプレートが持つべきだった」との申し立てが出た件数。
:::

## 見直しの契機

- EV-0324 の見直し時期(2027-11)の到来
- 準拠テンプレートが配備のワークフローまたは全社の統制の配布を扱うようになったとき
