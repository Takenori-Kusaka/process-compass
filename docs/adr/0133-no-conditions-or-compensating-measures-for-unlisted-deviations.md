## ステータス

採用(2026-11-15)。一部置き換え(→ 本 ADR の決定3): [ADR-0035](/process-compass/adr/0035-separation-by-execution-context/)の決定2 の「代償措置つきの逸脱として記録します。ADR-0029 の出荷判定者の例外と同じ扱い」を置き換えます。一部置き換え(→ 本 ADR の決定2): [ADR-0083](/process-compass/adr/0083-standard-edition-end-of-application-and-deviation/)の決定7 の「次の4つの規定が常に当たる」を置き換えます。同決定7 と決定8 が別の Issue へ送った2つの問い(1名・2名の体制のための代償措置を閉じた列挙へ加えるか、認証情報の分離が許可に当たるか)を、本 ADR が閉じます。[ADR-0029](/process-compass/adr/0029-shipping-approver-merge-exception/)は変えません。

追記(2026-11-17): 決定5 が #356 へ寄せた運用中の未測定の問いは、[ADR-0161](/process-compass/adr/0161-seeded-error-blinding-by-separating-surfaces-and-counting-misses-by-scope/) 決定1 が閉じました。決定5 は変えていません。

一部置き換え(→ [ADR-0225](/process-compass/adr/0225-credential-departure-split-seats-and-natural-persons/)の決定1・決定7): 決定1 の表の行「認証情報を席ごとに分けられない構成」の定めない理由と、決定3 の第1箇条の「席ごと」を置き換えます(2026-11-19)。認証情報の離脱は、兼務を禁止した組の席どうしと、別の自然人どうしの2つに分けます。条件と代償措置を定めない点は変えません。

## コンテキスト

[#352](https://github.com/Takenori-Kusaka/process-compass/issues/352) は、第1章 1.10.2 の「列挙に無い離脱」のうち、条件と代償措置を定めて閉じた列挙へ入れるべきものがあるかを問いました。体制の内の人が1人の体制は、現行の条項では適合の主張と逸脱を伴う適合の主張をどちらも述べられず、述べられるのは適用の表明までです。この帰結の重さが、問いの背景にあります。

本件は重い審議として扱いました(ADR-0083 の閉じた列挙と、適合の主張の定義に触れるため)。記録は `research/352-deliberation/`(`internal.md`、`external.md`、`council/` の5委員の意見、`decision-draft.md`、`decision.md`)にあります。

実物で確かめた事実は次のとおりです。

- Issue が引く「#313(ADR-0082)」の ADR は ADR-0083 である。ADR-0082 は #312(兼務の境界)の決定である
- 「1名の体制は主張できない」は、新しい原則ではない。ADR-0083 の決定7 と「影響」が既に書いている。同じ段落は「所有者の確認を経ているところです」と書くが、その確認の記録は `research/` に無かった(#313 の突合 X-9)
- 判定記録の置き場の履歴を規則で止めていない構成について、第4章は走査・先頭の固定・署名の要求を省かないと既に定めている。そのうえで、この構成を列挙に無い離脱と呼んでいる
- 席の兼務の2組は、第3章 3.5 が「発生」と「決定」の語で既に区別している([ADR-0122](/process-compass/adr/0122-self-related-decisions-and-arising-separations/))

## 決定

### 1. 閉じた列挙は D-1 だけのまま保つ

第1章 1.10.2 の列挙に無い離脱の8つのどれにも、条件と代償措置を定めません。8つには、Issue の一覧に無かった2つ(AI の担い手の名義の共有・未申告、判定記録の置き場の履歴を規則で止めていない構成)を含みます。「書かれていない」のではなく、「定めないと決めた」ことを、第1章 1.10.2 の本文に明記します。離脱ごとの理由は次のとおりです。

| 離脱 | 定めない理由 |
| --- | --- |
| コア機能の理解の保持者が1名以下(第3章 3.4.3 要求事項6・7) | 欠けるのは規定の目的(判断できる人が2名以上いること)そのものである。ADR-0029 の線引きで、目的が欠ける側(G-6 の側)に当たる。登録・受容・表示は、保持者が1名であることの害を検出しない |
| 出荷判定者 × 事業決裁者の兼務 | 体制の内の人が2人以上なら席を分けられる。1人なら、書く者と受容する者が別の自然人であるという前提が欠ける |
| AI維持管理者 × AI運用担当者の兼務 | 2人以上なら席を分けられる。1人なら、全社の統制を保つ者と案件の都合を持つ者が別の人であるという前提が欠ける |
| 欠陥注入の時期と箇所の秘匿の不成立 | 兼務の規定ではない。秘匿は測定が成り立つための条件であり、兼務を許す代わりに置ける同程度の防御が無い。措置を足すと、測れたと読まれる。附属書I 要件③は、導入前の検証でこの層を検出率に数えないことを勧めるが、これは推奨であり、本標準は課さない |
| 層1 の記名者 × 事業決裁者(テンプレ11 要求事項5) | 1名の組織では、受容の基準を定める者と受容する者が必ず同じ人である。組織の中の体制では、上位の者の記名で解ける |
| 認証情報を席ごとに分けられない構成 | 規模を問わず、採用者が分けられる。ADR-0035 決定2 は名だけで、条件も措置も書いていない |
| AI の担い手の名義の共有・未申告 | 専用の名義の申告と照合で解ける |
| 判定記録の置き場の履歴を規則で止めていない構成 | 検出型の統制(走査・先頭の固定・署名)が既に必須で、第4章はそれでも離脱と定めている。足す措置の要が機械で閉じない。プランに依る統制の扱いは #329 の裁定を待つ |

### 2. 1名の体制は、2つの主張をどちらも述べない

- 体制の内の人が1人の体制は、適用組織に含まれる(ADR-0068 の決定6)。述べられるのは適用の表明までである
- 字義どおり常に当たる離脱は、兼務の2組(出荷判定者 × 事業決裁者、AI維持管理者 × AI運用担当者)だけである。外部の確認者を責任者に置ける席が、独立レビュアの席に限られるためである(ADR-0127 の決定1)。本標準は、この2組に条件と代償措置を定めない
- ADR-0083 決定7 の「次の4つの規定が常に当たる」は、2組が常に当たり、ほかは第1章 1.10.2 の表の「当たる条件」による、と補う。表には「当たる条件」の列を足し、限定を行の中に書く
- 「恒久的に」とは書かない。体制の内の人が2人以上になり、2名の体制の条件がそろうまでと書く
- 2名の体制の6条件は変えない
- 所有者の確認(#313 の突合 X-9)の記録: 回答者は所有者。2026-11-15。問いは、「1名の体制が適合を主張できない帰結を、第1版の発行までの定めとして受け入れるか」。回答は、受け入れる。1名の体制は適用の表明までとし、適合を主張できないことを第1版の発行までの定めとする。見直しは、EV-0160 の観測で行う。本 ADR は、観測に EV-0265 を足す。回答の記録は、審議の記録(`research/352-deliberation/decision.md` 1 章)にある。この回答を、ADR-0083 決定7 が「確認を経ているところ」と書いた確認の記録とする

### 3. ADR-0035 決定2 の「代償措置つきの逸脱」を置き換える

- 認証情報を席ごとに分けていない構成は、列挙に無い離脱である。許可ではなく、措置を持たない
- 記録と表示は ADR-0035 のとおり続ける。ADR-0083 決定8 の「許可に当たるかは決定7 の別の Issue で審議する」を、本決定で閉じる

### 4. 保持者の規定の登録と受容は、条件でも措置でもない

- 第3章 3.4.3 要求事項6 の登録と期限つきの受容は、離脱を解くまでの扱いである。受容しても離脱は消えない。受容している間も、適合の主張と逸脱を伴う適合の主張を妨げる
- 委任の停止([ADR-0081](/process-compass/adr/0081-autonomy-downgrade-delivered-as-registration-stop/)の決定6)は、第5章 5.4.6 が独立に定めた帰結で、列挙と無関係に効く。措置に数えない

### 5. 欠陥注入の秘匿の不成立は、列挙に無い離脱の表に残す

- 附属書I 要件③は、導入前の検証で注入者と見つける者が同じ層を検出率に数えないことを勧める推奨で、本標準は課さない。本 ADR は、これを本文の要求にしない。運用中の欠陥注入にこの層を未測定として扱う要求を置くかは、本 ADR では決めない(#356 へ寄せる)

### 6. 離脱を「構造的」と「選べる」に分ける表示を設けない

- 機械が出す分類は設けない。分類は離脱の種類では決まらず、離脱と体制の組に付くためである。席の兼務の由来は、3.5 の発生と決定による(ADR-0122)
- 現場の指摘の中身は、第1章 1.10.2 の表の「当たる条件」で採る。読み手は表から、どの離脱が体制の内の人数で決まり、どの離脱が構成で解けるかを読める
- 主張の名を足さない。離脱の表示に新しい分類の語を足さない

### 7. 代償措置つきで認める線引きは、ADR-0029 の表による

- 代償措置つきで認めるのは、規定の目的を1人で達成でき、欠けるのが判定者の独立性だけの場合である
- 審議で委員が使った4つの観点は、検討の記録として残す。条項にしない。観点は、制約の正当性、既存の統制を措置に数えないこと、本人以外の確認、限界の明記である。外部の先例を移したもので、採用者の実績に基づかないためである
- D-1 がこれらの観点のすべてを満たすとは確かめていない。根拠水準マーク EV-0265 で開示する

### 8. 再び検討する契機

- EV-0160 と EV-0265 の観測。列挙に無い離脱のために主張をできなかった採用者の件数を、離脱の種類と体制の内の人数で分けて数える
- #329 の裁定(判定記録の置き場の扱い)
- 外部の確認者の席の限定(ADR-0127 の決定1)を見直す決定

## 検討した選択肢

| 案 | 採らない理由 |
| --- | --- |
| 保持者を D-2 として列挙へ入れる(後継候補の記録・期限つきの受容・委任の停止・表示を措置とする形と、保持者がちょうど1名で受容する者が本人でない形) | 欠けるのは規定の目的そのものである。受容と台帳登録は是正の手順であり、同程度の防御ではない。体制の内の人が1人の体制では、措置を本人以外は確かめられない。期限の上限の値に実証が無い。委任の停止は既に独立に効いており、代償に数えられない。再検討の出発点は、受容する者が保持者本人でない形とする |
| 判定記録の置き場を D-3 として列挙へ入れる | 検出型の統制を課したうえで離脱と定めた既存の条文と二重になる。措置の要(2つの置き場の権限者が異なること)が機械で閉じず、1名の体制では成り立たない。文案は #329 へ送る |
| 出荷判定者 × 事業決裁者に、体制の外の者の異議の記録または追認(共署)を措置として置く | 外の者の異議は出荷判定者の異議ではなく、拘束しない。追認する者が実質の受容者になり、それは分離であって代償ではない。外部の確認者の席を独立レビュアに限った定めを、措置の名で広げる。等価に近い唯一の候補である点は記録する |
| AI維持管理者 × AI運用担当者に、変更ごとの確認の記名を措置として置く | 2人いるなら席を分ければ足りる。1人なら確かめる者がいない |
| 停止条件・予算の下限を層1 が固定し、下回る変更を機械が拒否する | 兼務の有無に依らず課せる独立の統制で、代償ではない。新しい義務になる |
| 認証情報に、操作の記録へ文脈の印を付ける措置を置く | 印が自己申告である限り、分離の代わりにならない。機械に付けさせるなら、認証情報を分けるのと同じ作業になる |
| 体制の規模でプロファイル(別の要求の組)を分ける | 規模は本標準のテーラリングの軸に無い。「適合」の意味が規模ごとに増える。分ければ、分離が守る危険を小さい体制でだけ受け入れる形になり、その根拠となる実証が無い。小さい体制は、適用と主張を分けた設計(ADR-0068 決定6)で既に適用の内にある |
| 1名の体制のための主張の名(第3の主張)を足す | ADR-0083 が2つに分けた直後で、名の意味を薄める。観測(EV-0160)が無いまま名を増やす。離脱は適用の表明の併記で既に示される |
| 要求を「実行可能であれば」の条件つきにする | 条件が開き、適合と列挙に無い離脱の線が決定可能でなくなる |
| 離脱を「構造的」と「選べる」に分けて機械が出す | 決定6 のとおり |
| 欠陥注入の秘匿を列挙に無い離脱の表から外す | 主張の条件を緩める向きの変更で、本件の問いの外。#356 へ寄せる |
| 是正計画つきの不適合を表す第3の区分を足す | 逸脱と列挙に無い離脱の二分(ADR-0083 決定3)に語を足す。観測が無い |
| 発行の前に、1名の体制が主張に至る道を作る | 所有者の回答(第1版の発行までの定めとして受け入れる)による |
| 委員の観点を、列挙へ加える基準として条項にする | 決定7 のとおり |

多数であることは、採否の理由にしていません。保持者の規定を退けた理由は、条文の目的と、代償統制の先例の条件(元の要求の意図と同程度の防御、措置の独立の確認)に照らしたものです。

## 影響

- 閉じた列挙は D-1 の1件のまま変わらない。準拠テンプレートの列挙(`CLOSED_DEVIATIONS`)・区分・試験は動かない。採用者の義務は増えず、減らない
- 1名の体制の帰結は変わらない。変わるのは、理由が条文に書かれ、「課さないと決めた」ことが読み手に区別できる点である
- 準拠テンプレートに及ぶ文の直しが2点ある。構成に欄の無い離脱の注記へ欠陥注入の秘匿を足すこと、D-0 の兼務の節の語を「条件と代償措置を定めない」へ揃えること。どちらも検査を落とさず、#354 の順で行う
- 構成に欄の無い4つの離脱を、述べられる名が数えない点は、第1章 1.10.2 の実装マークで未達として表示する。準拠テンプレートの注記は人が確かめる旨を出すが、機械の検査には置き換えていない
- 実証を欠く点がある。1名の体制の排除に実証が無いこと、外部の出典の多くが二次情報であること、ADR-0081 との整合を条文の読みで確かめ実行では確かめていないこと、D-1 自体が委員の観点に照らして弱いこと。根拠水準マーク EV-0265 で開示する
- 1名の体制を主張から外すことで失う採用者の数は、分かっていない。EV-0160 の観測で見直す
- 育成の途中の3名以上の組織が主張を失う点が過剰かどうかを測った資料は無い。EV-0071(保持者の最低数 2。E2)は変えない
- 保持者の規定での期限つきの受容の読みが例外承認(第7章。#353)にそのまま当たるかは、本 ADR では決めない
