## ステータス

採用(2026-09-30)。一部を置き換え(2026-10-03): 決定2、決定3 の一部(本標準は品質を保証すると主張しない、に当たる部分)、決定8、帰結の一部(本標準は「品質を保証する」と主張しない)を[ADR-0057](/process-compass/adr/0057-organizational-quality-assurance/)で置き換えました。その他の決定は維持します。

## コンテキスト

品質保証部門は、AI を介した開発成果物をどう担保するかという問いを抱えています。本標準は個々の統制(独立レビュー、ゲート、AI 生成物の統制、形骸化の検出)を規定していますが、「本標準に従えば何が言えるのか」を1か所で示していませんでした。

### 部品は揃っており、束ねる主張が無かった

弁護役の意見書(`research/phase4-standard/284-council-05-defender.md`)は、論証の部品(主張・根拠・証跡・限界)が本文 11 ページと ADR 8 件に散らばっていることを示しました。無いのは、それらを束ねる最上位の主張と、主張から証跡へ辿る道筋です。

### 品質保証部門の立場から見た欠落

品質保証部門の立場の意見書(`284-council-03-qa-audit.md`)は、品質保証部門が尋ねる 17 の問いを現行の標準へ当てました。結果は、明確 6、曖昧 9、答えなし 2 でした。曖昧の主因は、条項の欠落ではなく、**証跡が出荷判定の突合の対象へ入っていない**ことです。

最大の欠落は、署名の意味でした。

- G-7 は、出荷判定者に内容の十分性を判定させない
- G-8 は、技術品質を蒸し返さない
- したがって、独立レビューの未達や検出能力の未測定といった残存リスクを**誰が受容したのか**が、どの記録にも残らない

同じ意見書は、条項どうしの食い違いを5件挙げました。附属書D の想定問答は「承認した人間が品質を保証する」と答えますが、G-7 は出荷判定者に十分性を判定させません。

### 「品質を保証する」とは書けない

5つの立場はいずれも、「本標準を回せば品質が保証される」という文言を退けました。

- 本標準の運用が欠陥の流出を減らしたという測定は、外部の資料と実証案件のどちらにも無い
- 形式の機械強制が、中身を伴わない充足を生んだ事例がある(FND-0097、E2)
- 本標準は既に、レビューパッケージを品質の保証として扱わず([ADR-0023](/process-compass/adr/0023-review-package-cues-not-conclusions/))、検査の実施を潔白の証明として扱わない([ADR-0021](/process-compass/adr/0021-ip-clearance-evidence-not-guarantee/))

言えるのは、**何をどの独立性で確かめ、何を確かめていないかを示せる**ことまでです。品質マネジメントの規格がプロセスの適合を扱い、製品に欠陥が無いことを扱わないのと同じ立ち位置です。

## 決定

### 1. 品質保証の論証を、附属書H として置く

論証は、主張・それを支える条項・受け取る証跡・主張の崩れを示す観測、の対応表です。**附属書H は既存の条項からの投影であり、第2の正本にしません**。要求事項の正本は各章です。案件には論証を書かせません。

### 2. 最上位の主張

> 本標準に従って出荷した変更は、事前に人が合意した受入基準への適合を、作成の指示者から切り離された検証によって確かめている。検証の独立性が成立しなかった範囲、実施しなかった検証、検証の検出能力の実測値(または未測定である事実)は、出荷の時点で一覧として開示され、記名の自然人がそれを見たうえで出荷を決めている。

この主張は工程についての主張です。製品に欠陥が無いことの主張ではありません。

### 3. 主張しないことを明記する

欠陥が無いこと、受入基準と試験計画が十分であること、AI による確認が独立した人の確認と同等であること、人のレビューが全行を読んだこと、抜き取られなかった範囲に逸脱が無いこと、既存規格への適合、契約上の責任の帰結、を主張しません。

### 4. AI による確認の数え方

| 種別 | 例 | 扱い |
| --- | --- | --- |
| 決定論的な検査 | AI が書いたテストの実行、静的解析、変異試験 | 検証に数える。期待値が人の承認した受入基準に由来することが条件。テストの生成へ実装を渡してよいかと、変異試験の要否は、変更のリスク区分による(第5章 5.8.4、フェーズ5「AI生成テストの検出力検証」) |
| AI の推定による判定 | AI レビュー、AI による受入基準の充足判定 | **判定に数えない**。検出の層としてのみ数える |
| 人の判定 | G-6、G-7 | 判定に数える |

AI の推定による判定を検出の層として数える条件は、次の5つです。

1. 欠陥注入による検出率を測り、値を開示する。未測定は「未測定」と開示する。担い手の識別が変わったら測り直す
2. 検証側へ、生成側の文脈と作成者の主張を渡さない
3. 検証側の指示を、検証の対象となる変更から書き換えられない
4. 通過を理由に人の確認を減らさない。合否条件に入れない
5. 記録には「AI レビュー通過」ではなく、指摘の内容と採否を残す

条件4 に、委任の範囲という除外を置きません。G-6 の判定を事後へ移した委任([ADR-0054](/process-compass/adr/0054-seat-accountable-performer/))の変更で人の事前確認が無いのは、AI の確認の通過によるものではなく、第5章 5.5.4 の7条件によるものです。

### 5. 署名の意味を定める

> 出荷判定者の署名は、成果物の正しさの承認ではない。事前に定めた出荷基準を満たしていることと、定めた検証の記録および成立しなかった統制の一覧が揃っていることの確認である。一覧に載った残存リスクの受容は、リリース決裁(G-8)の決断の記録に事業決裁者が記名する。

署名が意味するのは、次の2点です。成果物の正しさと、数値の十分性は意味しません。

- 事前に定めた出荷基準を満たしていること。出荷基準とは、欠陥トリアージ基準、安定性の閾値など、G-7 の基準を指す
- 定めた検証の記録と、保証の開示が揃っていること

G-7 へ十分性の判定を戻しません。事業決裁者が受容するのは設計の良否ではなく、開示された未達という事実です。

**出荷判定者は、開示された未達・未測定についての異議の有無を、G-8 の決断の記録へ必ず記載します**。事業決裁者は、この記載を読んだうえで受容を記名します。G-7 は値の良否で差し戻さないため(決定6)、異議の経路が無いと、品質保証部門は未達の多さに意見を述べる場を失います。異議は出荷を止める権限ではありません。止めるかどうかを決めるのは事業決裁者で、異議とその扱いは記録に残ります。

- 異議が無い場合も、「異議なし」と記載する
- 空欄は、記載の欠落として扱う。空欄のままでは、事業決裁者は受容を記名しない
- 新しい様式を足さない。既存の決断の記録の欄として書く

**異議の仕組みは、異議を書く者と、読んで受容する者が別の自然人であることを前提にします**。同じ人が兼ねると、受容が自己完結します。

- 3名以上の体制では、出荷判定者の席の責任者と、事業決裁者の席の責任者を、同一人物にする構成を認めない
- 1〜2名の体制では、兼務を逸脱として記録する。保証の開示の項目1 へ「異議を書く者と、残存リスクを受容する者が同一である」と表示する
- 1〜2名の体制でも、異議の欄の記載と受容の記名は省かない。同一人物が書いた事実を、表示で読めるようにする

保証の開示が次のいずれかに当たる場合、出荷判定者は、異議の有無とあわせて理由を書きます。「異議なし」とする場合も同じです。

1. 独立した人の確認を経ていない R1 の変更がある
2. 検出能力が、前回の出荷に続いて未測定である
3. 独立した人の確認を経ていない変更の件数、または構成上の未達のゲートと逸脱の数が、前回の出荷より増えた
4. 事後の抜き取りを、作成を指示した本人が行っている

事項3 は、2つの量のどちらか一方が増えれば当たります。変更の件数と、構成上の未達・逸脱の数を、合算して比べません。

これは、異議を書かせる基準ではありません。当たる場合に理由を残させ、開示を読まないままの「異議なし」を、記録の上で判別できるようにします。当たるのに理由が無い記載は、空欄と同じく記載の欠落として扱います。4つの事項の選定に実証はありません。根拠の水準と差し替え条件は、第4章 G-8 の暫定マーク EV-0063 によります。

委任で先へ進めた変更は、G-8 を個別の変更ごとには行いません。ただし、期間ごとの保証の開示にも、事業決裁者の受容の記名と、出荷判定者の異議の記載を要します。期間の開示への受容と異議は、判定記録の「対象」へ期間の起点と終点を書いて記録します。期間のための様式を足しません。

「異議なし」と「書かなかった」を監査で区別できないと、異議の経路が働いているかを確かめられません。内部監査は、G-8 の決断の記録に、開示された未達・未測定への受容と、出荷判定者の異議の扱いが記載されているかを確かめます。

### 6. 出荷ごとに「保証の開示」を示す

出荷ごとに、次の項目を1枚で示します。**既存の記録からの投影とし、人に新しい記述を書かせません**。

| # | 項目 |
| --- | --- |
| 1 | 体制と独立性の成立状況(G-6・G-7 それぞれ、成立 / 外部依頼 / 事後の抜き取り / 未達 / 兼務と代償措置) |
| 2 | テーラリングの宣言(外した項目と理由) |
| 3 | リスク区分ごとの変更の件数と、確定の形態(人確定・協働・委任)の内訳 |
| 4 | 機械検査の結果。未実施と通過を区別する |
| 5 | 残存リスク、既知の不具合、未回収の例外 |
| 6 | 検出能力の測定値と測定時点(人の層・AI の層)。未測定は「未測定」とし、未測定が続いている期間(最初の出荷からの経過)を併記する |
| 7 | 生成の条件(モデルの版・指示資産の版)と、期間中の体制の変化点。AI が使えなかった期間と、その間の扱いを含む([ADR-0055](/process-compass/adr/0055-team-change-points/)) |

- 未達・未測定は正当な値として受け入れる。**差し戻すのは記載の欠落だけとする**。値の良否で落とすと、形式を満たすための記入が起きる
- 記載の欠落とは、次のいずれかを指す。項目が開示に無い。作成を求める記録が無く、項目を導けない。当該の出荷の範囲の判定記録が無い。「未測定」「記録なし」と記載された項目は、欠落ではない
- 未測定は正当な値だが、続いていることを見えるようにする。項目6 の期間の併記は、このために置く
- 項目1・3・6 には、前回の出荷の値を併記する。悪化しているかを読めるようにするためである
- リスク区分を確定した者を、判定記録へ記名する(第3章 3.8.1)。項目3 の区分が作成者の自己記載だけに依る場合は、その旨を表示する
- 対外文書へ添える保証の開示では、項目6 を検出率の値で示さない。測定している事実・測定時点・推移の向きで示す(決定7)
- 受託では、納品ごとに保証の開示を受け渡す。委任を適用するかどうかは、契約で合意する
- 委任で先へ進めた変更は、期間ごとの保証の開示へ件数を計上する。出荷判定者は、その開示を突合して記名する([ADR-0054](/process-compass/adr/0054-seat-accountable-performer/) 決定4)
- G-7 の突合の対象へ、保証の開示の完備を加える
- 保証の水準を等級で表さない。等級は「満たした」という主張として読まれる
- 独立した人の確認を経ていない成果物には、その旨を定型の文で書く

### 7. 形骸化していないことは、作動の記録と実測で示す

承認の件数や署名では示しません。検出能力の実測、統制が作動した記録(差し戻し、権限の一時制限の発動、自動の引き下げ)、内部監査の所見、欠陥の検出工程の分布で示します。検出率を対外へ出すときは、値ではなく、測定している事実・測定時点・推移の向きに限ります。

### 8. 対外的に使う表現を定める

実施した事実と、記録から確かめられる状態までを書きます。「品質を保証する」「欠陥が無いことを保証する」「承認した人間が品質を保証する」「独立検証済み」「第三者レビュー済み」「規格に適合」とは書きません。対外文書の文言は、各組織の法務部門が確認します。

### 9. 附属書D の想定問答は、附属書H からの投影に改める

問答を単独で増やしません。品質保証部門の問いへの回答は附属書H に置き、附属書D はそこから引きます。

### 10. 論証を支えない検査と記録は、廃止の候補にする

論証のどの主張も支えない検査・記録は、改善サイクル(フェーズ6)で廃止の候補に挙げます。統制を外すときは理由を記録します。論証のために新しいゲートと検査を足しません。

## 検討した選択肢

| 案 | 却下の理由 |
| --- | --- |
| 想定問答を増やすだけにする | 問答は主張と証跡の対応を持たない。現に附属書D の回答が G-7 と食い違っている |
| 既存規格への対応表で示す | 規格への対応は品質の証拠ではない。1.3 が適合性を主張しないと定めている。未読の条文が残る |
| 保証の水準を等級で示す | 等級の境界に実証が無い。等級が目標になる |
| G-7 へ内容の十分性の判定を戻す | 読解力を前提としない判定という設計を壊す |
| AI レビューの通過を G-6 の判定へ算入する | 文脈を切り離した再レビューでも、注入欠陥の約 73% を見逃した測定がある |
| 承認ごとに「何を確かめたか」の署名様式を足す | 検出能力を示さない書類が1枚増える |
| 案件ごとに論証を書かせる | 文書が製品を上回る状態の再現になる |
| 欠陥密度・テスト密度を出荷の合否に使う | AI は分母も分子も増やせる。網羅率は検出力の代理として弱い(FND-0099、E3) |
| 出荷判定者と事業決裁者の兼務を、1〜2名の体制でも禁止する | 1名体制を宣言できなくなる。未達と逸脱を隠さずに表示するという [ADR-0028](/process-compass/adr/0028-unmet-gate-distinct-from-omitted/) の方針に合わない。逸脱として記録し、同一人物である旨を表示する |
| 出荷判定者と事業決裁者の兼務を、3名以上の体制でも逸脱の表示で済ませる | 別の人を置けるのに、受容が自己完結する構成を認めることになる。異議の経路が働かない |

## 帰結

- 附属書H を新設する。第1章に、本標準が主張することと主張しないことを書く
- G-7 の突合の対象へ保証の開示を加え、署名の意味を第4章へ書く。G-8 の決断の記録へ、残存リスクの受容と、出荷判定者の異議の扱いを含める
- **出荷判定の規程の改定を要する**。出荷判定者の署名の意味を定め、残存リスクの受容を事業決裁者の記名へ置くためである。附属書D の「既存制度への変更点」へ、この点を加える
- 内部監査の観点へ、G-8 の決断の記録における受容と異議の扱いの記載を加える
- 附属書D の5節と想定問答を改める。テンプレ4 の「条件付き承認」を第4章の2値へ合わせる
- **本標準は「品質を保証する」と主張しない**。主張するのは、確かめたことと確かめていないことを示せることである
- 開示は免罪符になりうる。歯止めは、G-8 の受容を記名にすることと、未達の件数を内部監査の抽出条件へ加えることである
- 論証そのものも形骸化しうる。論証の各行が指す条項の実在は機械で検査する
