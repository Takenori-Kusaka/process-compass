## ステータス

採用(2026-11-18)。束 B20 の軽の件のうち、U7(0963・0837・0584)と、0626 から分けた保管の期間(IMPL-1028)の決定です。

[ADR-0084](/process-compass/adr/0084-check-strength-plans-and-resident-rules/) 決定4(no-adopter の登録簿)と [ADR-0159](/process-compass/adr/0159-g7-criteria-3-6-7-8-records-prose-sla-and-degradation-pairing/) 決定5 を前提とする。審議の記録は `research/448-deliberation/b20-decision-light.md`(6 節)

## コンテキスト

- #355 は、4つの規定について準拠テンプレートに降りていないと挙げた
- 起票者の提案(機械の検査や出力の追加)をそのまま条項にしない。4つとも、機械で閉じるかを調べた
- 判断軸は信頼性である。閉じない統制を機械の検査と名乗ると、検査の通過が規定を守った根拠に見える。閉じないものは、採用者に委ねると明記して開示する

## 決定

1. 対外の文書の表現(IMPL-0963)は、採用者に委ねる。「保証する」「独立検証済み」などが当たるかは、自由な文の意味であり、機械で閉じない。標準は禁止の表現を示すにとどめ、準拠テンプレートは文面の検査を置かない
2. 規制業の規制当局向けエビデンスと AI 関与範囲の明記(IMPL-0837)は、採用者に委ねる。求める形が業法と当局ごとに違うので、準拠テンプレートは出力しない。注記として構成の why と PROCESS-PROFILE.md に出ることは変えない
3. レビュア間の偏りの集計(IMPL-0584)は、条文を保ったまま、準拠テンプレートが個人単位の集計を出さない。所有者の決定(2026-11-18)による。個人の評価に使われる危険が、集計を出す利点を上回る。採用者が必要な範囲で計測する
4. エスカレーション記録を案件の完了後に保管する期間(IMPL-1028。IMPL-0626 から分ける)は、採用者に委ねる。標準は期間の長さを定めない。採用者の組織の記録管理に依る。[ADR-0135](/process-compass/adr/0135-ship-evidence-copied-to-base-branch-retention-left-to-adopter/) の先例に揃える
5. 4件は、`state=undelivered`・`plan=adopter`・`decision=ADR-0216` の実装マークで表示し続ける。消さない。「書かれていない」と「採用者に委ねると決めた」を読み手が区別できるようにする

## 課さないと決めたこと

- 対外の文書の文面を機械で検査すること(自由な文の意味は機械で閉じない)
- 規制当局向けの共通の様式を準拠テンプレートが持つこと(当局ごとに違う形を、1つの様式へ押し込まない)
- 個人単位の集計を準拠テンプレートに同梱すること
- 保管の期間の長さを標準が定めること

## 検討した選択肢(採らない)

| 案 | 採らなかった理由 |
| --- | --- |
| 対外の文書の文面を禁止語の一覧で検査する(0963) | 語の一覧で意味は閉じない。通過が「守った」の根拠に見える |
| 規制当局向けの共通の様式を同梱する(0837) | 業法と当局ごとに求める形が違う |
| 個人単位の分布を集約に出す(0584) | 偏りを見るためという目的が、個人の評価に転用される。所有者の決定で採らない |
| 保管の期間を標準が年数で定める(1028) | 組織の記録管理と法令に依る。ADR-0135 の先例と食い違う |
| エスカレーション専用のラベルを足す(0626) | 7.6 と食い違う |

## 影響

- 採用者は、4つの規定を自分の運用で満たす。準拠テンプレートの検査が通っても、4つを満たした根拠にならない
- 実装マークは `undelivered` のまま台帳に出続ける。見直しの時期は、根拠水準マークの見直し期限に従う

:::caution[暫定 EV-0330 / 見直し 2027-05]
**対象**: 対外文書の表現・規制当局向けエビデンス・レビュア間の偏りの集計・保管の期間を、採用者の運用に委ねても足りるという前提。
**根拠の水準**: E0(なし)。
**差し替え条件**: 採用者の運用の記録で、4つの規定が実際に満たされているかの確認(内部監査の観点、出荷判定者の抜き取り)。

委ねると決めたことは、満たされたことを意味しません。満たされているかは、採用者の記録で確かめます。
:::
