## ステータス

採用(2026-08-12)

## コンテキスト

本標準の内部に、正面から衝突する2つの規定がありました。

| 規定 | 内容 |
| --- | --- |
| [第3章 3.5](/process-compass/phase4-process-design/roles-responsibilities/) | 開発ライン × 出荷判定者(同一案件)の兼務を**禁止**する |
| [第8章 軸A](/process-compass/phase4-process-design/tailoring-guide/) | 1〜2名の体制では、出荷判定を**価値責任者が兼ねる** |

1〜2名の体制では価値責任者が同時に開発ラインでもあるため、テーラリングが導出する構成は必ず 3.5 の禁止へ抵触します。準拠テンプレートでこの構成を生成すると、D-0 体制図の兼務表を埋める段で行き止まりになります。

利用者が取りうる行動は3つで、いずれも望ましくないものでした。

- 兼務表を無視して埋める(規則を破った記録が残らない)
- 出荷判定者の欄を空欄・未定にする(テンプレートが明示的に禁止している)
- 生成物を手で書き換える(導出の記録と実態が乖離する)

同じ構造の衝突は「作成指示者 × 独立レビュア」にもありますが、こちらは [ADR-0028](/process-compass/adr/0028-unmet-gate-distinct-from-omitted/)により G-6 が未達として表示されるため、利用者は状況を正しく理解できます。**G-7 は `required` のまま残るため、衝突が可視化されませんでした**。

## 決定

**3名未満の体制に限り、開発ライン × 出荷判定者の兼務を、代償措置つきの逸脱として認めます**。

条件は4つです。すべてを満たす場合に限ります。

1. 体制が3名未満であること。3名以上になった時点で例外は失効する
2. G-7 の判定記録を必須とし、基準の各項目との突合を記録に残すこと
3. リリース後の抜き取り確認を定常作業として置くこと
4. 兼務の事実と代償措置を D-0 体制図へ明記すること

あわせて、**逸脱を構成から読み取れる形で出力します**。準拠テンプレートは、未達(`unmet`)とは別の区分として代償措置つきの逸脱を持ち、プロセス構成書の冒頭へ表示します。ゲートの状態は `required` のままとします。判定そのものは実施するためです。

## G-6 と G-7 を分けて扱う理由

両者は「1人では満たせない」点で同じに見えますが、**満たせないものの性質が異なります**。

| | 作成指示者 × 独立レビュア(G-6) | 開発ライン × 出荷判定者(G-7) |
| --- | --- | --- |
| ゲートの目的 | 作成時の思い込みを、抱えていない人が見る | 品質の記録と基準を突き合わせ、出荷の可否を判定する |
| 1人での達成 | 不可能。目的の定義そのものが第三者を要求する | 可能。突合と判定は単独で実行できる |
| 欠けるもの | 目的そのもの | 判定者の独立性 |
| 扱い | 未達(`unmet`) | 代償措置つきの逸脱 |

**代償措置を独立性の回復として扱いません**。この点は ADR-0028 の決定6(代償措置は未達の解消として扱わない)と同じ立場です。記録と抜き取りが行うのは、判定の甘さを後から検出できる状態にすることだけです。

## 検討した選択肢

| 案 | 採らなかった理由 |
| --- | --- |
| G-7 も未達として扱い、G-6 と揃える | 「出荷判定を実施していない」と読める。実際には判定は行われ、独立性だけが欠ける。未達の語を広げると、ADR-0028 が作った区別が薄まる |
| 3.5 の禁止を緩め、兼務を一般に許可する | 3名以上の体制でも兼務が既定になる。禁止の対象を狭めるのではなく、成立しない規模に限った例外として置くほうが範囲を制御できる |
| 1〜2名では G-7 を省略する | 出荷の可否を誰も判定しない構成になる。省略できないゲートを増やす方向とも矛盾する |
| 衝突を文書上の注記だけで解消する | 生成される構成に現れないため、利用者は毎回同じ行き止まりに当たる。可視化を伴わない解消は、問題の記述にとどまる |
| テーラリングの導出を優先し、D-0 の兼務表から当該行を削る | 禁止の事実が消える。例外である状態と、禁止がそもそも存在しない状態を区別できなくなる |

## 影響

- 準拠テンプレートは、1〜2名の構成に対して**未達(G-6)と代償措置つきの逸脱(G-7)を同時に表示する**
- 逸脱は体制が3名以上になるまで残る。消す操作は設けない
- D-0 体制図の兼務表に例外の行が加わる。**例外に当たらない場合の可否は変わらない**
- 判定の独立性が欠けた状態は残る。本 ADR が変えるのは、その状態が記録に現れるかどうかだけである
