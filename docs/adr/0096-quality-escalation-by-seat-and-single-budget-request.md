## コンテキスト

[#419](https://github.com/Takenori-Kusaka/process-compass/issues/419) は、#418 の会議体が範囲の外とした論点です。調査(`research/419-deliberation/survey-419-*.md`)と、起案・現場・品質監査・規格・弁護の 5 委員の会議体(`research/419-deliberation/`)を経ました。

### 見つかったこと

- 品質側の表の宛先「判定者の上位者」「品質保証部門」は、どちらも定義が無かった。品質保証部門は、H.12・3.13.6・ADR-0055 決定7 が設置を要求しない部門で、部門の無い組織では 2 行の宛先が欠けた。報告を受けた者が何を決めるかも書かれていなかった
- 「上位」を宛先に使う箇所が 9 か所あった(7.5 の図、第4章 共通ルール 2 と滞留の措置、3.9.3、3.10.5、3.10.11 の 2 行、テンプレートの /gate、フェーズ5 の事前レビューの自動化の図)。判定者が組織の最上位のとき宛先が消え、B-1 には本標準の中で上位が無い。第5章では同じ語が、承認者・判別者から「外す」側に使われている
- 同じ費用の先行から、7.6 の段階3 と 7.7.4 の上程の 2 本の判定要求が B-2 へ届きえた。起票する者・期限・様式が違い、7.7.4 で 2 つ以上が同時に成立すると B-1 へ上がるが、B-2 の裁定との先後が無かった。7.7.4 の上程は B-2 の「決定する事項」に無く、3.7.5 の列挙外の禁止と当たった
- 7.7.4 には、実装マークと根拠水準マークのどちらも無かった。準拠テンプレートに機械の上程は無い
- 外部: 既存の枠組みは報告先を職位や部門名で書かない。「指名された受け手」(CMMI PPQA)、「責任の割当て・兼務可」(ISO 9001:2015 5.3)、「委任の1つ上」(GovS 002)、「プロジェクト外の主体」(ISO/IEC 29110)のどれかで書く。自動のアラートは判断を起動する入力として扱われ、判断の権限は人の委任の構造に置かれる(FinOps、ITIL、GovS 002)

## 決定

### 1. 品質側の表を、起票する者・判定する者・写しの宛先で書く

7.6 の品質側の表を、基準の所在・起票する者・判定する者(席・会議体)・写しの宛先の 4 列に改めます。

| 事象 | 起票する者 | 判定する者 |
| --- | --- | --- |
| ゲート判定の期限超過率が基準を超えた | 価値責任者 | D-0 表1「体制と運用形態」の決定者 |
| 差し戻し率が基準の範囲より高い | 出荷判定者の席の責任者 | 技術判断者 |
| 差し戻し率が 0% のまま推移した | 判定を要しない(5.4.6 の引き下げ) | 判定を要しない |
| 同一箇所の修正が収束しない | 独立レビュアの席の責任者 | 技術判断者 |
| 事業ステージの基準を満たさない未解決欠陥 | 出荷判定者の席の責任者 | 事業決裁者 |
| 事業性の前提が崩れた | 価値責任者 | B-2。B-2 を置かない体制では事業決裁者 |

- 品質保証部門は、D-0 に「品質保証部門の通知先」を定めた組織に限る写しの宛先とする。必須の宛先にしない
- 起票した者は自分の起票を判定しない。兼務で同一人物になる体制は、ADR-0095 決定4 と同じく開示する
- 期限超過率の基準は、3.9.4 の会議体の警戒サインと同じ 10% を既定値とする(EV-0196、E0)。差し戻し率の 0% 側は 5.4.6 の検知を引き、別の値を 7.6 に置かない
- 判定する者が決めることを行ごとに書く。D-0 表3 と準拠テンプレートの D-0 の節6 に品質側の 4 行を足し、判定する者の列を予め書く(IMPL-0369)

### 2. 「上位」を定義せず、宛先を D-0 の記名で書く

- 宛先は、D-0 表3 の行「ゲート判定・会議体の決定が期限を超過」の判定する者とする。務めは代理の判定者・決定者の指名である
- 様式は、この行に D-0 表1「体制と運用形態」の決定者を予め書く。席の任免の権限が、この決定者にあるためである(3.13)
- 決定者を決裁権限規程が定める会議体(B-1 など)では、代理は規程の代決の定めによる。定めが無い場合、または規程を持たない体制では、組織上の任命権者が指名する。D-0 の席の任免の権限は、規程が権限を与えた決定者の代理に及ばないためである
- 期限を超えた者がこの決定者と同じ人のときは、D-0 の「組織上の任命権者」とする(3.13.3 と同じ受け皿)。任命権者もいない体制では「指名できる者なし」と書き、期限の超過を未達として表示し続ける。自動承認にしない
- 宛先でない用法(第5章の「開発組織の上位者ではない」、層1 の上申の「上位の権限者」)は変えない
- 「判定者の上位」「決定者の上位」「上位へ通知」「上位への通知」を廃した言い回しへ登録する

### 3. 予算の判定要求を 1 本にまとめる

- 7.7.4 の上程は、検知の時点で判定要求として成立する。価値責任者のレポートを待たない
- 同じ案件で予算に関する判定要求が判定待ちの間に別の発火が立ったら、新しい要求を立てずに材料として綴じる
- 判定する者は、綴じた発火の判定する者(席・会議体)のうち最も上の者とする。B-1 が判定する者になった時点で、B-2 に係属中の要求を B-1 へ移す。移した側は判定を出さず、移送は 3.7.3 の保留に当たらない。3.7.4 の B-1 の「決定する事項」に、7.7.4 の上程の判定(移した要求と綴じた 7.6 の発火を含む)を加える
- 期限は早いほうとし、最初の上程の受理日から起算する。様式は 7.6 の 5 項目とし、項目5 は価値責任者が書く
- B-2 を置かない体制の 7.7.4 の上程先は事業決裁者とする。B-1 の行の上程先は、3.7.4 の B-1 の決定者(第8章で兼ねる者を含む)とする
- 3.7.4 の B-2 の「決定する事項」に、7.7.4 の上程の判定(中止を含む)と、品質側の「事業性の前提が崩れた状態」の判定を加える
- 機械の上程は降りていない規定として表示する(IMPL-0370。予算の消化がリポジトリの外の記録に依るため、採用者が実装する)。それまでは D-0 表1「フローの観測と見込みの報告」の担い手が裁量なく起票する
- 7.7.4 の値と 7.7.3 の「3 期連続」の根拠水準を開示する(EV-0197、E0)

| 選択肢 | 出した者 | 採否と理由 |

| 品質保証部門の設置を要求する | 検討 | 採らない。H.12・3.13.6・ADR-0055 決定7 が要求しないと決めている。部門の無い組織が不適合になる |
| 5.4.6 の検知と別の値を 7.6 に置く | 現行 | 採らない(品質監査)。同じ事項の規定が 2 か所に分かれる(第1章 1.7) |

| D-0 に品質保証の機能の担い手の記名欄を新設する | 品質監査 | 採らない。H.12 の「担う部門を定めない」を記名の要求で覆す。宛先は出荷判定者の席と任意の部門の通知先で足りる |
| 品質側の全行に判定する者を一律に課す | 検討 | 採らない(弁護)。差し戻し率の 0% 側は 5.4.6 の自動の引き下げで足りる |
| 期限超過率の起票を文脈オーナー・出荷判定者にする | 規格・品質監査 | 採らない。期限超過は流れの観測の材料であり、ADR-0094 が見込みの評価を価値責任者に置いた |
| 未解決欠陥の判定を出荷判定者にする | 現場 | 採らない。出荷判定者の停止権は基準の未充足に限られ(5.5.5)、受容は事業決裁者の記名による(G-8)。起票した者が自分で判定することにもなる |
| 第1章 1.4 で「上位」を定義する | 検討 | 採らない(5 委員一致)。組織図に依存し、記録で検証できない。第5章の外す側の用法と衝突する |
| 会議体ごとに宛先を分ける(B-2 → B-1 の決定者など) | 品質監査 | 採らない。代理の指名は席の任免であり、権限は 3.13 の決定者に一つしかない。任免の権限が 2 か所に分かれる |
| 行の空欄を既定の宛先で埋める | 起案・規格 | 様式の記入として採る。空欄の既定にすると、黙って効く既定が増える |
| 7.6 と 7.7.4 の判定要求を別々に走らせる | 検討 | 採らない。同じ事実に別の期限・別の判定が出る |
| 併合した要求の期限を遅いほうへ揃える | 検討 | 採らない。併合が判定を遅らせる経路になる |
| 7.7.4 を 7.6 へ吸収して消す | 弁護の懸念 | 採らない。人の起票に吸収され、機械の発火が消える。7.7.4 の上程は単独でも判定要求として成立する |
| 7.7.4 の機械の上程を判定(承認)として扱う | 検討 | 採らない。判断の権限は人の委任の構造に置く |

- 第6章 D-0 表3(品質側の 4 行と期限超過の行の判定する者)
