## ステータス

採用(2026-08-14)

## コンテキスト

[ADR-0026](/process-compass/adr/0026-evidence-level-marking/)の根拠水準マークは、実証に基づかない記述へ**差し替え条件**を付けることを求めます。会議体で EV-0021 の差し替え条件を検査したところ、**条件として機能していませんでした**([#242](https://github.com/Takenori-Kusaka/process-compass/issues/242))。

旧条件は次のとおりでした。

> 3案件分のゲート判定記録と、7.3 の例外承認の適用件数。**適用が過小であれば、手続の重さが回避を招いている**ことになる。

| 検査項目 | 結果 |
| --- | --- |
| 「過小」の判定基準が定義されているか | **されていない** |
| 比較する期待値または分母があるか | **無い**。例外承認が本来何件発生するはずかを与えるものが標準内に存在しない |
| 対立仮説を分離できるか | **できない**。適用0件は「手続が重すぎて回避された」とも「逸脱が実際に発生しなかった」とも読める |
| 案件数を増やせば分離できるか | **ならない**。判定基準が無いという欠落は、標本数では埋まらない |

案件 P-001 の実績は**適用0件**でした。当事者は「この2つを自分では区別できない」と述べています。**同じ観測が両方の仮説と整合する状態が、現に起きていました**。

### 待機は中立な選択ではない

ADR-0026 は「満たされていなければ期限を延ばし、記録を続けます。**期限の延長を記録なしで行わないこと**が、この仕組みが形骸化しない条件です」と定めます。

**判別できない条件の期限を延長し続けることは、まさにこの形骸化です**。記録付きで延長しても、延長の理由が「まだ3案件に達していない」であり続ける限り、**判定不能であるという事実が記録されません**。

### 台帳が同一事例の重複計上を検出しない

根拠水準の台帳は EV-0020 / EV-0021 / EV-0024 を独立の3行として並べ、いずれも「E2(単一事例)」と表示します。**読み手は「3つの単一事例がある」と読みます。実際には同じ案件 P-001 の1件です**。

**同じ事例を複数の決定の根拠に用いること自体は誤りではありません**。誤りは、台帳がそれを区別せず、根拠が独立に3つあるかのように見せることです。

## 決定

### 1. 差し替え条件は、対立仮説を分離できる形で書く

差し替え条件には次を含めます。

- **観測する量**(数えられるもの)
- **どの観測が得られたらどちらへ判定するか**

**「Nか月分の記録」「N案件分の実績」だけを書いた条件を認めません**。標本数は、判定基準の欠落を埋めません。

### 2. 分離できる条件を書けない場合、マークを置かない

条件を書けない記述は、**マークではなく削除または書き直しの対象です**。ADR-0026 が「差し替え条件を『継続して検討する』のような文で埋めないでください」と定めた規則を、**判別可能性まで拡張します**。

### 3. 既存の観測機構の出力を優先して使う

新しい観測のための欄や判定を作りません。**既存の検査の出力を数える形を先に検討します**。

EV-0021 の書き直しは、この形を採りました。本標準は「記録を書かないまま次工程へ進んだ場合は逸脱として扱い、出荷判定(G-7)基準5 で検出する」機構を既に持っています。**その出力を数えるだけで、回避と不発生を分離できます**。

### 4. 台帳へ、根拠となった事例の識別子を書く

根拠水準の台帳に**事例の識別子の列**を加えます。同じ事例から出たマークが並ぶ場合、読み手がそれを識別できるようにします。

**マークの件数を、独立した根拠の件数として読ませません**。

### 5. 本 ADR の適用は、以後に書くマークからとする

台帳の既存25件へ遡って検査しません。**見直し期限の到来時に、あわせて判別可能性を確認します**。

遡及しない理由は、一斉の書き直しが**条件の質ではなく体裁を揃える作業になるため**です。期限の到来時であれば、当該の記述を書いた文脈とともに検査できます。

## 検討した選択肢

| 案 | 却下の理由 |
| --- | --- |
| 既存25件を直ちに全件検査する | 一斉の書き直しは体裁を揃える作業になる。条件の質は上がらない |
| 差し替え条件の様式を定型化する | 対象ごとに観測できる量が異なる。定型は埋められない欄を生み、「継続して検討する」と同じ形になる |
| EV-0021 を削除する | 決定3(条件付き通過を設けない)は実証を持たない。マークを外すと、その事実が読み手に見えなくなる |
| 台帳に事例の識別子を書かない | マークの件数が、独立した根拠の件数として読まれ続ける |

## 帰結

- EV-0021 の差し替え条件を書き直した。**ADR-0036 の決定は変更していない**
- 以後に書くマークは、対立仮説を分離できる形の条件を要する
- **台帳へ事例の識別子の列が増える**。`scripts/check-evidence.mjs` の出力を変更する
- **既存25件の判別可能性は、見直し期限まで検査されない**。この間、判別不能な条件が残りうる

:::caution[暫定 EV-0031 / 見直し 2027-02]
**対象**: 決定5(期限の到来時に検査すれば足りるという判断)。

**根拠の水準**: E0(なし)。

**一斉検査と期限到来時の検査を比べた実績を持ちません**。

**差し替え条件**: 見直し期限が到来したマークのうち、判別不能と判定された件数。**期限到来分の半数を超えて判別不能であった場合、期限を待つ方式では遅すぎることになります**。
:::
