## ステータス

採用(2026-11-18)。束 B20 の重の件(IMPL-0990)と軽の件(IMPL-1010。所有者の決定)の決定です。

[ADR-0138](/process-compass/adr/0138-handover-items-and-decision-fields-checks/) の決定3(前の記録との一致は降ろさない)と、[ADR-0092](/process-compass/adr/0092-quality-uplift-shown-within-ai-evaluation/) の決定7 のうち「AI が生成した大量の散文が読まれずに通ることの検知(IMPL-0136・IMPL-0159)は、未達の表示を続ける」の文を置き換えます。**採用済みの本文は書き換えません**。ADR-0092 決定7 の他の文と、IMPL-0136・IMPL-0159 の扱いは変えません。審議の記録は `research/448-deliberation/b20-decision-heavy.md`(4 節)と `b20-decision-light.md` です。

## コンテキスト

- 標準の G-3 の表は、前の判断記録との記述の一致の「機械の列」を「検査する」と書いていた。同じ節の本文、第5章 5.7.4、IMPL-0132 の note、`gates/G-3.md` は、機械で見ないと書いていた。誤りは表の4行目だけだった
- 全部を置き換える判断記録は、正当に同じ影響を書く。一致を失敗にする定義は置けない
- IMPL-1010 は、散文の変更を人が読み切ったかを確かめる仕組みを求めていた。確かめる材料が機械の側に無い

## 決定

**人に残す(IMPL-0990)**

1. 前の判断記録との記述の一致は、機械では見ない。G-3 の判定者が判定のときに読んで確かめる。表は「機械の列: しない」「人の列: 判定する」へ改める。マークは `delivered` / `manual` とし、確かめる者は G-3 の判定者とする
2. これは判定者の新しい務めではない。`gates/G-3.md` は既に判定者が読むと定めていた。表を実態へ合わせる

**課さない(IMPL-1010)**

3. 読まれずに通る散文の検知は、**課さないと決めた**。マークを外し、番号 IMPL-1010 は再利用しない。人に残す(決定1)のとは別で、確かめる担い手を置かない
4. 残る手段は、G-6 の人の確認と、散文の変更の判定完了時間と規模の観測(IMPL-0136 の降りた部分)である。観測は、読まれたことの検知ではない。そう書いて開示する

## 課さないと決めたこと

- 前の判断記録との一致を失敗にすること(案A)。5.7.4 と衝突し、閾値に根拠が無い
- 一致を所見として出力すること(案B)。読む者が決まらない出力を足すことになる
- 判定記録に「前の記録との突合: 実施」の行を足すこと。実施の語が書かれるだけで読んだ証拠にならず、新しい記入の義務を生む
- 読まれたかの検知の plan=adopter への移し。求める内容を書けない。issue=445 への付け替えも、降ろす手段の無い計画が残るので採らない

## 検討した選択肢(採らない)

| 案 | 採らなかった理由 |
| --- | --- |
| 案A: 一致を失敗にする | 5.7.4 と衝突し、閾値に根拠が無い |
| 案B: 所見にする | 読む者が決まらない出力を足す |
| 判定記録に突合の行を足す(監査) | 実施の語が書かれるだけで、読んだ証拠にならない |
| 1010 を plan=adopter にする | 求める内容を書けない |
| 1010 を issue=445 に付け替える | 降ろす手段の無い計画が残る |
| 1010 を未達のまま表示し続ける(ADR-0092 決定7 の文) | 降ろす手段が無いまま残り、読み手が「課さない」と「未達」を区別できない |

## 影響

- G-3 の判定者は、これまでどおり前の判断記録を読む。機械は見ない
- 台帳から IMPL-1010 が消える。降りていない規定の一覧から、読まれずに通る散文の検知は外れる。外れたのは降りたからではなく、課さないと決めたからである
- 判断記録の整合の質が破られても失うのは記録の質で、安全や取り消せない操作には響かない
