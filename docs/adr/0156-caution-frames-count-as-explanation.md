## ステータス

採用(2026-11-17)。[ADR-0132](/process-compass/adr/0132-frame-placement-rule-and-declaration-subject/) の決定2(注意の枠の種類の地位を定めない)と、決定6 の表の1行(注意の枠の中の平叙の動詞文が、説明と要求のどちらか)を置き換えます。[ADR-0063](/process-compass/adr/0063-normative-informative-and-verbal-forms/) の決定2 と [ADR-0086](/process-compass/adr/0086-guide-pages-and-remaining-verbal-forms/) の決定3 は置き換えず、説明の類に1項を足します。[#440](https://github.com/Takenori-Kusaka/process-compass/issues/440) の重-8 の結論で、[ADR-0155](/process-compass/adr/0155-safety-prohibitions-and-statements-decided-per-sentence/) と一続きの審議です。

## コンテキスト

ADR-0132 は、注意の枠(札に「暫定」を持たない `:::caution` と `:::danger`)の中の文が説明か要求かを定めず、重の審議の結論へ残しました。そのため、読み手は枠ごとに地位を判断し続ける状態にありました。ADR-0155 の審議の結果、枠の中にあった要求と禁止は、すべて本文へ出るか、説明へ改まりました。

## 決定

### 1. 注意の枠は、説明の類に数える

- 第1章 1.7.2 の説明の類に「注意の枠(札に「暫定」を持たない `:::caution` と `:::danger`)。枠の種類は目立たせ方の違いで、地位の違いではない」を足す
- 要求は本文にある。枠は理由・限界・所在を担う。第7章 7.10.1 の型(本文に禁止、`:::danger` は所在)と、ADR-0132 の決定1 にそろう
- 規格の作法(注記に要求を書かない)にも近い

### 2. 枠の中の誤配置の文は、直すまで要求として読む

- 枠の中に、本文に所在の無い要求・禁止の形の文が見つかったときは、起草の誤りとして扱い、直すまで要求として読む
- 「要求・禁止の形の文」の範囲は、述語が本標準を適用する者の行為であり、文末が第1章 1.7.1 の表の要求・禁止・推奨の形(である調の対を含む)の文とする。形は列挙せず、表の行を引く。適用する者の行為を述語としない事実と因果の文は対象の外である。新しい義務は足さない
- これは地位の未決ではなく、起草の誤りの扱いである。1.7.2 の「迷う文は要求として読む」と同じ、安全側の向きである
- 検査12 は強い文末だけを見る。平叙の文の誤配置の発見は manual(人の査読と突合)で、EV-0300 に開示する

### 3. 登録簿の項目を空にし、EV-0263 を閉じる

- 登録簿 `undecidedFrameSentences` の全項目を除く。仕組みは残す。重の審議に掛かる文の開示に使う
- 第1章 1.7.2 の表と EV-0263 のマークを除く。差し替え条件(表が空になり、枠の種類の地位を定める)が満ちた。識別子は再利用しない
- ADR-0132 決定6 の表の該当行は、「枠の中に要求の形の文が残っていないか(manual)」に置き換える
- 枠の下の「審議中です」の表示 6 か所を除く

## 検討した選択肢

| 案 | 採らなかった理由 |
| --- | --- |
| `:::danger` を規範の枠と認める | 規範の置き場が2種になり、ADR-0063 の原則の変更になる。前例が見つかっていない。signal word は製品の標識の様式で、文書の規範の地位とは別である |
| 地位を定めず、形で読み、迷えば要求とすることを恒久にする | 読み手の判断を恒久にし、監査で被監査側が枠は説明だと争える余地を残す。誤配置への懸念は、決定2 の1文で受けた |
| `:::danger` を廃止する | 安全の所在の目立ち方を落とす |

## 影響

- 義務は動かない。7文と P の文は、すべて本文へ出たか説明へ改まった
- 根拠水準マーク: EV-0263 を閉じ、EV-0300 を足した
- 検査12 のコードは変えない。検査17 の動詞は、ADR-0155 の決定8 のとおり変えない
