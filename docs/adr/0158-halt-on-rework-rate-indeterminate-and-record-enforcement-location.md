## ステータス

採用(2026-11-17)。[ADR-0129](/process-compass/adr/0129-second-category-window-baseline-and-rework-rate-derivation/) 決定3 のうち、「基準値が未設定、または母数が最小標本数に満たないときは、止めずに『発火しない』と表示する」の**1項だけ**を置き換えます。決定3 の残り(母数・分子・基準値の欄・表示)と、ADR-0129 の他の決定は維持します。決定3 の「履歴を読めないときは『読めない』と表示する」は表示として維持し、読めないときに止めない扱いだけを置き換えます(決定1)。あわせて、ADR-0129「採用者に委ねる規定」の表の IMPL-0519 の行のうち、手段の所在を書く場所(D-0)を、5.5.4 の登録の根拠(4点目)へ移します(決定5)。ADR-0129 の「重の審議へ送ったこと」は、1項目(手戻り率の判定不能・基準値の未設定で止めるか)に結論を出します。2項目(強制の手段の所在の記録を求めるか)は、L3 の登録に限って結論を出します。L2 への引き上げは決めていません(決定8)。決定8 の論点には [ADR-0170](/process-compass/adr/0170-l2-promotion-requires-enforcement-location-in-safety-risk-assessment/) が結論を出しました。[ADR-0081](/process-compass/adr/0081-autonomy-downgrade-delivered-as-registration-stop/) 決定5 は維持し、手戻り率にも当てます。重の審議の結論です(Issue [#348](https://github.com/Takenori-Kusaka/process-compass/issues/348)・[#340](https://github.com/Takenori-Kusaka/process-compass/issues/340)、`research/348-340-q-deliberation/`)。

## コンテキスト

ADR-0081 決定5 は、登録した変更種別で判定不能となったときは、判定可能な窓が得られるまで委任を止めると決めました。比率を差し戻し率に限っていません。「何もしない(表示だけ)」は採らなかった案に挙がっています。ADR-0129 は、ステータスの表で決定5 の維持を宣言しながら、決定3 で手戻り率の判定不能・基準値の未設定を止めないとしました。同じ ADR が、止めるかを重の審議へ送っています。この決定3 の1項は、手戻り率の算出だけを先に降ろした時点の実装の状態であり、停止についての決定ではありません。

5.4.6 は「判定不能が続く範囲は、第2区分を計測できない範囲として扱う」「計測ができない範囲へ L2 以上を適用しない」と書きます。5.5.4 は「計測できない種別は登録しない」と書きます。入口は手戻り率の計測を要件にしています。ところが運用では、計測できない場合も L3 が続いていました。

3.12.10 要求事項5 は、停止条件を強制できない環境で自律実行を解禁しないと書きます。登録の時点でそれを照らす場所と記録は、ありませんでした(IMPL-0834 は登録の時点で照らさない旨の未達)。

## 決定

### 1. 第2区分の比率のいずれかの窓が判定不能のとき、登録した変更種別を止める

- 5.4.6 の停止の表の「差し戻し率の窓が判定不能」の行を、「第2区分の比率(差し戻し率、手戻り率)のいずれかの窓が判定不能」へ改める。性質は適用の条件の欠落。戻る条件は、両方の窓が判定可能になった時点
- 手戻り率の記録を読めないときも、判定できないものとして止める。差し戻し率の履歴を読めないとき(IMPL-0286)と同じ扱いである。「判定不能」の語(窓の件数)は広げない。ADR-0129 決定3 の「読めないときは『読めない』と表示する」は表示として維持し、止めない扱いだけを置き換える
- 採らなかった案(表示だけ)を手戻り率に当てていた ADR-0129 決定3 の1項を、ADR-0081 決定5 の側に合わせて置き換える。採用済みの原則と、原則を決めないまま置いた実装の状態が食い違うときは、前者を正とする

### 2. 手戻り率の基準値の未設定でも止める。「判定不能」の語は広げない

- 停止の表に別の行を立てる。「手戻り率の基準値が未設定」、適用の条件の欠落、戻る条件は基準値を記録した日より後の評価の日。基準値の無い手戻り率は、算出できても「基準を超えた」という検知条件が成立しない(5.4.6、5.5.4)
- 「判定不能」の定義(窓の件数)は広げない。既存の ADR・実装マーク・試験の語が揺れるためである
- 第4章 要求事項1 の値の決め方に、既定値を持たない閾値の選択肢として「実測前の組織の値 / 実測から」を加える。実測前の値は、既定値と同じく暫定で、要求事項2 の置き換え(2四半期の実測)の対象とする。実測前の値で解いた停止は、保証の開示と次の一手に決め方を出す(降ろしは IMPL-1006)
- 基準値の既定値は置かない(ADR-0129 の課さないと決めたことを維持する)。実測前の組織の値は既定値ではない。組織が記名と理由を添えて置く値である

止めない構成では、基準値を書かないことが最も得になります。書かなければ手戻り率は永久に発火せず、L3 が続きます。緩い値を書いた場合は、値・日・決定した者・理由・決め方が構成に残り、保証の開示と内部監査(観点23)から読めます。ゲーミングの跡が残るのは止める側だけです。

### 3. 止めている間も手戻り率を算出し、母数に数える

- 5.4.6 の停止の段落の「止めている間に協働で扱った変更も、差し戻し率の窓の母数に数えます」を、第2区分の窓へ広げる(差し戻し率は変更、手戻り率はタスク)
- 母数が溜まらない構成では、止まった種別は判定可能な窓に届かず止まり続ける。止めている間に実測から基準値を置く道を、母数の計上で開く
- 準拠テンプレートの `scripts/gate/autonomy.mjs` の母数の算出(`reworkCount`)は、委任の可否を参照せず、窓の中の取り込みのトレーラと種別の範囲だけで数える読みである。実行での確認は、降ろす束が行う

### 4. 戻り方と、解く手段

止まった種別は、次の4つの手段で解きます(登録の取り下げは L3 へ戻る経路ではありません)。

| 手段 | 内容 |
| --- | --- |
| 判定可能な窓 | 窓の中のタスクが最小標本数に届く。届かなければ観測の窓を長くする(記名と理由。最小標本数は下げない。ADR-0129 決定2) |
| 基準値の記録 | 第4章 要求事項1 の事項を記録する。値は記録した日より後の評価から当てる |
| 登録の根拠の4点目の記録 | 決定5 により止めた種別に限る。4点目(実行の単位ごとの手段の所在、または該当なし(理由))を記録した時点で戻る |
| 登録の取り下げ | 種別を登録から外し、L1(協働)で扱う |

[ADR-0081](/process-compass/adr/0081-autonomy-downgrade-delivered-as-registration-stop/) の突合の表は、ADR-0030 に対して「判定を経ずに戻る経路」を2つ数えています(判定不能の窓から判定可能な窓への回復、原因を特定できない事象の原因の特定)。基準値の記録と、決定5 の4点目の記録は、その数え上げに**3つ目と4つ目として加えます**。ADR-0081 が数えた2つに無い経路であることを、ここに明記します。どれも、止めた理由である記録の欠落が解けたことを記録から確かめる回復で、[ADR-0030](/process-compass/adr/0030-criticality-reduction-by-design/) の「自動的に緩む経路」(判定と記録を経ずに統制を緩める経路)に当たりません。後から記録した4点目の内容は、登録の判定を経ません。内容の確かめは内部監査(観点23。manual)に限り、戻る時点では、記入の有無だけを機械が確かめます。記録の書き直しで、発火した引き下げは戻りません。引き下げとしての停止を戻すのは、従来どおり 5.5.4 の登録の判定だけです。

### 5. 強制の手段の所在を、登録の根拠の4点目にする

- 5.5.4 の「登録の根拠の記録」を3点から4点にする。4点目は、3.12.10 の実行の単位(自己修正のループ、AI の確認側と作成側の往復)ごとの、停止条件を強制する手段の所在。その単位を使わない種別は「該当なし(理由)」と書く
- 4点の記録が無い種別は登録しない。既に登録した種別で4点目が欠けたものは、登録が完了していないものとして止める(ADR-0081 の「登録日の無い種別は止める」と同じ型)。5.4.6 の停止の表に、適用の条件の欠落の行として「登録の根拠の4点目が無い」を立て、戻る条件を4点目を記録した時点とする(判定を待たずに戻る。決定4 の4つ目の経路)
- 機械が確かめるのは、実行の単位ごとの記入の有無まで。手段が実際に停止を強制するかは確かめない。**課さないと決めたものであり、書かれていないだけではない**(ADR-0059 決定5、ADR-0054 決定4、ADR-0081)。準拠テンプレートの「内容は機械で確かめていない」旨の表示(IMPL-0983)に、4点目を含める
- 条項は新設しない。3.12.10 要求事項5 は既に「してはならない」と書いている。足すのは、確かめる場所(登録)と記録の場所(登録の根拠)である。要求事項5 の直後の段落に、L3 の登録についての1文を足す
- 置き場所を 3.12.10 要求事項4(G-1 の記録)にしない。G-1 は案件の開始時の記録で、L3 を解禁する時点(登録)と一致しない。IMPL-0519 の note が求めていた「D-0 へ書く」は、D-0 節12 を構成から出す形で満たす(正本を構成の1か所にする)

ADR-0129 が採らなかった「解禁の記録に、強制の範囲の理解の確認を足す」とは別物です。あちらは自由な文の記名で、機械で閉じません。こちらは場所と手段の名で、記入の有無が決定可能です。ADR-0129 の不採用は維持します。

### 6. 準拠テンプレートの強制の範囲の開示

- 「準拠テンプレートの上では L3 を解禁できない」とは書かない。実態と食い違う(`start` を呼んだ単位には強制が届く。IMPL-0272)
- 附属書H の 3.12.10 の行と IMPL-0834 の note へ、次を書く。準拠テンプレートが強制するのは `start` を呼んだ自己修正の単位だけである。ロックの外の反復と AI の往復を使う種別を登録できるのは、採用者が手段を備え、所在を登録の根拠に書いた場合だけである

### 7. 第8章の切替への帰結

第8章「極小規模での事後監査への切替」は、5.5.4 の委任を1〜2名の体制へ適用したもの、つまり L3 の登録そのものです。本 ADR の停止と記録は、切替を使える範囲に直接効きます。第8章に、登録できる種別の条件と、届かない間は協働で扱うこと、1名の体制ではコア機能の理解保持者数が常に1名以下であるためコア機能に関わる種別が止まり続けることを、帰結の説明として1段落書く。新しい義務の語は使わない。

### 8. L2 について何も決めていない

3.12.10 要求事項5 の直後の文は「遮断の手段を持たないまま自律水準を上げる構成を認めません」で、L1 からの引き上げ全般(L2 を含む)に掛かる読みが自然です。会議体は L3 の登録だけを論じました。**L2 への引き上げ(5.4.5 の判定)に、強制の手段の所在の記録を求めるかについて、本 ADR は何も決めていません**。L3 に限るとも、L2 へ広げるとも決めていません。本文に入れたのは L3 の登録についての文だけです。L2 は、採用者の義務の範囲を決める点で、別の重の審議で扱います(#340 を開いたまま受け皿にします)。

## 採らなかった案

| 案 | 採らなかった理由 |
| --- | --- |
| 4点目を後から記録した時点で、登録する者の内容の判定を要して戻す型 | 採らなかった。裁定 Q2 は、4点目の欠けを適用の条件の欠落とし、記録の欠落が解けたことで戻ると決めた。判定を要する型は、戻る経路を登録の判定に寄せ、新しい義務の読みになる。内容の確かめが無い点は、課さないと決めたものとして開示する(EV-0303) |
| 手戻り率の判定不能・基準値の未設定で止めない(ADR-0129 決定3 の1項) | 本 ADR で置き換えた。ADR-0081 決定5 が退けた「表示だけ」と同じ形であり、基準値を書かないことが最も得になる |
| 「判定不能」の定義を広げて基準値の未設定を含める | 既存の ADR・実装マーク・試験の語が揺れる。別の状態として1行を立てる |
| 「使わない」と記名して手戻り率の検知の無い L3 を続ける欄 | 5.5.4「計測できない種別は登録しない」に反する種別を、記名で登録に残す形になる。使わない自由は、登録しない(L1)ことで既に表せる |
| 手戻り率の基準値の既定値 | 根拠が無い(ADR-0129 を維持)。置けば根拠のない値が全採用者の既定になる |
| 移行の猶予(一定期間は止めない) | 期限つきの「表示だけ」であり、ADR-0081 が退けた案の期限つきの形である。基準値の記録は1件で済む |
| 第7章の例外承認で停止を解く経路 | 7.3 の対象はゲートの判定基準と 7.3 が名指した事項に限り、構成の条件は対象にしない。停止は「自動」(ADR-0081 決定3)であり、承認で見送れば裁量を戻す。文は足さない |
| CL ごとに停止・記録を分ける | L3 の登録は CL0 の案件に限る(第8章 軸E)。分ける対象が無い。リスク区分は変更ごと、CL は案件ごと(ADR-0039)で、案件の CL から適用外を導かない |
| 3.12.10 要求事項5 の新しい条項 | 既にある。二重になる |
| 強制の手段の所在を記入させない(IMPL-0519 の note を adopter のまま残す) | 記録の場所も検査も無いまま残り、「課さないと決めた」と「書かれていない」の区別がつかない |
| 強制の有効性を機械で確かめて登録を拒む | 決定可能でない。検査が保証した体になる |
| 強制の範囲の理解の確認の記名 | 自由な文の記名で、機械で閉じない(ADR-0129 を維持) |
| 「準拠テンプレートの上では L3 を解禁できない」と書く | 実態と食い違う。決定6 |
| 手段の所在を 3.12.10 要求事項4(G-1 の記録)に置く | 時点が解禁(登録)と合わない |

## 影響

- **新しい負担**: 準拠テンプレートの採用者で、基準値を置かずに L3 を使っている構成は、準拠テンプレートの更新の時点で登録した種別が止まる(協働へ落ちる)。採用者が先に失う負担である。負担の重さ(1件の記録、または L1 への取り下げ)と、負わない場合に失う信頼を比べて、負わせる側を採った。破られると、出荷の相手が、手戻りの増加の検知の無い L3 の成果物を受ける。L3 は CL0 の案件に限るため、人の安全には直接及ばない。響くのは適合の主張の信頼である
- 準拠テンプレートが4点目を確かめるようになった時点(IMPL-0834 が降りたとき)で、4点目を書いていない登録済みの種別は、すべて止まる。登録の根拠に4点目の欄が無い現在の登録は、移行の猶予なく止まる。使わない実行の単位は「該当なし(理由)」の1行で戻る
- 1〜2名の体制では、止まった種別の G-6 を事前に判定する。置けなければ未達になる。移行の猶予は置かない
- 1名の体制では、第8章の切替を使える範囲がこの停止の分だけ狭まる。実測は無い(EV-0302)
- 降りていない規定: IMPL-0291(停止)、IMPL-1006(基準値の決め方)、IMPL-0834(4点目の記入の有無)。準拠テンプレートは現在、手戻り率の判定不能・基準値の未設定を「発火しない」と表示し、止めない。それまで、本文の規定は降りていない規定として台帳に出る
- 機械で閉じる条件: 窓の件数、基準値の有無、決め方の値と日付の比較、4点目の記入の有無。機械で閉じない条件: 基準値の妥当性(manual。EV-0302)、手段が停止を強制するか(adopter・manual。EV-0303)、「該当なし(理由)」の理由の妥当性(manual)
- 根拠水準: EV-0302(止める判断。E0)、EV-0303(記入の有無だけを確かめる判断。E0)
