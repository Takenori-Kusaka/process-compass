## ステータス

採用(2026-10-13)。[ADR-0028](/process-compass/adr/0028-unmet-gate-distinct-from-omitted/)を置き換えません。同 ADR の決定1(未達にする構成)の読み方と、決定4・5(未記入の表示、未達の記録を消す書き換えの拒否)の実装を補います。

## コンテキスト

[#302](https://github.com/Takenori-Kusaka/process-compass/issues/302) は、S0 で独立レビューを省略することを決めた記録が無いこと、確認者の有無で省略と未達に型が分かれること、設問への回答だけで未達の表示が消えることを指摘しました。指摘をそのまま条項にせず、調査・会議体・突合の順で扱いました。記録は `research/302-310-deliberation/`(`survey-302.md`、`council-A-01`〜`05`、`decision.md` の A-1〜A-3)にあります。

### 省略を決めた記録が無かった

S0 の省略は、第8章 軸B の表、第2章 2.5、規則データ、エンジンの試験の4か所が同じ向きで固定していました。決定の記録だけがありませんでした。ADR-0028 は、省略の状態を「標準の規則により省略する。調整として成立している」と書きますが、何によって成立するかを書いていません。第8章「調整は宣言を伴う」の要求事項3 は、調整後の構成で当該ゲートの目的が達成されることを示すよう求めます。

成立の前提は、本文に散らばって既にありました。軸B の「コア指定の範囲: なし」、第4章「事業ステージ別のトリアージマトリクス」の「S0 探索: 社内・実験参加者」、軸B の「PoC から MVP への切り替え時に、省略したゲートを適用へ戻す」です。束ねる記録が無いだけでした。

### 省略は、保証の主張を崩していなかった

会議体の品質保証の委員が、S0 の構成で出荷の証跡を集約して確かめました。G-6 と G-7 を省略した構成の出荷は、保証の主張の成立条件3・4 を満たさず、「品質保証の対象外として出荷しました」と出ます。独立した人の確認を経ていない変更の件数は、ゲートの状態によらず出ます。S1 へ移すと、G-6 と G-7 は厳しくする向きの変更として自動で適用に戻ります。S0 の期間に確認を経なかった変更は、S1 以降の出荷の範囲に入ると、記録の欠落になります。

### CL1 だけ、規定どうしが矛盾していた

ADR-0028 の「影響」は、安全重要度 CL1 以上では危害の深刻度が体制の都合で下がらないと書きます。ところが、3名以上・CL1・S0 の構成では、G-6 が丸ごと省略されていました。CL2 以上の規則が持つ省略の取り消しを、CL1 の規則が持っていなかったためです。軸E の表は、CL1 の独立レビューの人数を1名と書いています。

### 回答だけで、未達の表示が消えた

調査が実行して再現しました。S0 では、設問に「確認者がいる」と答えれば、未達は出ませんでした。人の名簿が空の場合も、名簿が本人だけの場合も、独立レビュアの席が本人の場合も同じでした。S1 以降でも、「いる」と答えて名簿が空なら、未達は出ませんでした。名簿と席による検出は、G-6 を適用する状態でしか働いていませんでした。正直に「いない」と答えた体制のほうが、表示も CI の下限も重くなっていました。

## 決定

### 1. S0・標準品質・CL0 の G-6 と G-7 の省略を、前提つきで維持する

省略は、次の3つの前提のもとで成立します。

| # | 前提 | 所在 |
| --- | --- | --- |
| 1 | コア機能の指定が無い | 第8章 軸B「コア指定の範囲」 |
| 2 | 露出する利用者が、社内と実験参加者に限られる | 第4章「事業ステージ別のトリアージマトリクス」 |
| 3 | S1 へ移ると G-6 は適用に戻る。S0 の期間に独立した人の確認を経なかった変更は、S1 以降の出荷の範囲に入ると、記録の欠落になる | 第4章 G-6・G-7 |

露出が前提2 を超える前に、S1 へ移します。前提1・2 が成立しているかを、機械では確かめません。

表の升の語は「省略」とします。「省略可」は使いません([ADR-0063](/process-compass/adr/0063-normative-informative-and-verbal-forms/))。升は規則が定める結果であり、組織が選ぶ余地を示しません。

### 2. 省略と未達の型の分岐を残す

未達は、体制が独立レビューの目的を達成する構成を示せていないことの表示です。事業ステージで変わりません。作成を指示した本人以外の確認者を置けない体制は、S0 でも未達です。確認者を置ける体制の S0 は、省略です。

会議体の多数(4名)は、S0 では確認者の有無を問わず省略へ統一する案を採りました。議長は、多数に従いませんでした。S0 は設問への回答だけで決まり、期限と判定がありません。統一すると、確認者を置けない体制が、ステージの回答だけで未達の表示と代償措置を消せます。ADR-0028 の決定1 にステージの条件は無く、決定5 は、未達の記録が無い状態への書き換えを失敗させると定めています。多数が挙げた「正直な回答だけが重くなる」は、決定5 で回答を根拠から外せば、体制の実態の差になります。

### 3. CL1 以上は、S0 でも G-6 を適用する

危害の深刻度は、体制の都合でも、事業ステージの都合でも下がりません。規則データの CL1 の規則に、事業ステージによる G-6 の省略を取り消す設定を足します。規則の漏れの訂正です。

### 4. S0 でも G-6 を適用する形と、組織の選択にする形は採らない

S0・標準品質・CL0 の構成で G-6 を適用する形は、採りません。適用するかどうかを組織が選ぶ形も、採りません。決めないと明記する形も、採りません。理由は「検討した選択肢」に書きます。

### 5. 確認者を置けるかどうかは、人の名簿と席から導く

- 確認者を置けるかどうかは、D-0 体制図の表5(人の名簿と席)の記載で判定する。設問への回答は、判定の根拠にしない
- 開発者の席または独立レビュアの席の責任者が未記入である間は、未達の側へ倒す。2つの席の責任者が同一人物である場合も、未達である
- 回答と名簿の食い違いは、どちらの向きも検出する
- S0 にも、S1 以降にも掛ける

ADR-0028 の決定4(未記入は未記入として表示する)と決定5 の、実装の残りです。名簿に実在しない人を書く形は、機械では止まりません。プロセス内部監査の観点6 で確かめます。

## 検討した選択肢

| 案 | 採らなかった理由 |
| --- | --- |
| S0 でも G-6 を適用する | 省略で起きた害を示す材料が無い。[#300](https://github.com/Takenori-Kusaka/process-compass/issues/300) の会議体が全員一致で退けた読みの蒸し返しになる。省略は、保証の主張を崩していない |
| 適用するかどうかを、組織の選択にする | ADR-0028 の状態の語彙に「選べる」が無い。テーラリングの表は、同じ入力から同じ構成を導くための規定である。升の語を閉じた語彙にする決定(ADR-0063)と衝突する |
| 決めないと明記する | 4か所が同じ向きで固定しており、決定の記録だけが無い状態を残す理由が無い |
| S0 では、確認者の有無によらず省略に統一する | 決定2 のとおり |
| 新しい成立条件と、条件を機械で確かめる検査を足す | 前提は本文に既にある。S0 の成果物が外へ出たかを機械で確かめる手段が無く、S0 でもリリース決裁(G-8)を適用することと衝突する |
| 回答を正とし、名簿との食い違いを内部監査に委ねる | 未達が表示されず記録も無い構成は、監査の抽出の対象に上がらない。回答は「いる」の1語で、確かめる対象が無い |
| 「確認者がいる」と答えて名簿から確かめられない構成を、変更として拒否する | 人の離脱で確認者がいなくなった構成を、回答の書き換えを待たずに未達へ反映するという規定(第3章 3.13.3)と両立しない。未達として表示し、食い違いを理由と注記へ出す形にとどめた |

## 影響

- 第8章 軸B に「S0 の省略が成立する前提」の節を置き、根拠水準マーク(EV-0101。E1。見直し 2027-04)を付けた。省略で害が生じないことの実証は無い
- 第8章 軸B「本軸が動かすもの、動かさないもの」に、本軸が未達の表示を動かさないことを書いた
- 規則データ `r-e-cl1` に、G-6 の省略を取り消す設定を足した。3名以上・CL1・S0 の構成は、G-6 が省略から適用へ変わる。既存の構成にとっては、厳しくする向きの変更である
- 準拠テンプレートは、1〜2名の体制で、開発者の席・独立レビュアの席の責任者が未記入か同一人物なら、回答と事業ステージによらず G-6 を未達にする(IMPL-0111)。**初期化の直後は、人の名簿が空であるため、1〜2名の体制はすべて未達から始まる**。席を記入し、別の人が確認者であることを名簿と席で示すと、未達が解ける
- 未達の代償措置として、カバレッジの下限の導出値が 80% から 90% へ上がる。準拠テンプレートは、導出値が下がっても下限を自動では下げない(下げるのは緩める向きの決定)。初期化の直後の下限 90% は、席を記入して未達が解けた後も残る。下げるには、記名と理由を伴う変更を要する
- S0 で、席を記入して G-6 が未達から省略へ変わる変化点は、未達の表示が消える変更であり、準拠テンプレートは緩める向きとして決定者の記名と理由を求める
- 規則より前の版で生成した構成のうち、1〜2名で、回答が「いる」、席が未記入または同一人物のものは、契約検査が失敗する。構成を再生成すると、未達として反映される
- 「確認者がいる」と答えて名簿から確かめられない構成は、拒否しない。未達の理由と契約検査の注記に、食い違いを出す。「いない」と答えて席へ別の人を記入する変更は、従来どおり拒否する
- 前提1・2 の成立を、機械は確かめない(IMPL-0108)。S0 を名乗る条件・期限・判定は、設けていない
