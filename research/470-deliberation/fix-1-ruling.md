# #470 独立の突合 1 巡目の所見への議長の裁定(2026-11-28)

所見は review-1-main.md(F-1〜F-15)と review-1-template.md(R1-1〜R1-5 と低 3 件)。

| 所見 | 裁定 | 担当 |
| --- | --- | --- |
| F-1(高) 規則の当たりが確定の場で示されない | 直す。PR の検査が、基底の規則に当たる変更に「記録された作業上の選択と理由は読む対象から外れる(規則 id)」を、R1・安全重要度 CL1 以上・規制業では「規則はあるが当てていない」を、**知らせとして**出す。合否を変えない。規則が無ければ何も出さない。G-6 の手引きはこの知らせを見るよう直す。実装できなければ、手引きの文を実態へ合わせ、本体で undelivered として表示する | template → 本体(note) |
| F-2(高) 「いつも調べる」が「手元の 4 段で足りなければ毎回」になった | 条文は変えない。指揮役の指示(人の確認が増えすぎる場面だけを条件で塞ぐ。例: 既にあるもので足りるなら足さない)に沿った議長の読みである。ADR-0276 に「議長の読み」と明記し、失うもの(手元の流儀で足りた事項では、世の中の標準との食い違いに気付く機会が無い)を書く。最後の報告で所有者に知らせる | 本体 |
| F-3(高) IMPL-1051 の note と PR 様式の例の食い違い | 表示と実態を合わせる。PR 様式の例を note のとおり(受入基準の項目を AC-N で引く形)に直せるなら直す。様式の検査で直せないなら、本体の note を実態に合わせる | template → 本体 |
| F-4(中) ADR が議長・指揮役の読みを所有者の決定として書く | 直す。所有者の原文、指揮役の読み(所有者が Issue で確かめたもの・確かめていないもの)、議長の読みを分けて書く | 本体 |
| F-5(中) CLAUDE.md が決め事を「(a) 人が確定する判断」に入れる | 直す。その句を消す(標準の 5.5.5 の 6 判断に決め事は無い)。「人へ戻す」とだけ書く | template |
| F-6(中) 常駐の指示に「毎回・規模で省かない」が無い | 直す。常駐の行に足す(核にも) | template |
| F-7(中) EV-0394 が出典の限定を落とす・訳が違う | 直す。sources-register.md の「引いてよい数値」に合わせる。作者の値は「独立の試験は反証していない(does not refute)」と書く | 本体 |
| F-8・F-9(中) ADR に、0044 が退けた理由の残りと 0273 との差が無い | 直す(ruling.md 2 章・3 章のとおり) | 本体 |
| F-10(中) submodule の参照 | push の段で進める(議長) | 議長 |
| F-11(中)・R1-5(中) 試験が確かめていない判定 | 直す。id の重複の拒否、基底から読むこと、CL1 以上の不適用、PR の経路の集約に場面を足す。場面は、判定を無効にすると落ちることを確かめる | template |
| F-12(低) 安全重要度を途中で下げた構成の表示 | 本体の担当が所見を読み、厳しい側(当てない)に倒れているなら実態を条文か note に 1 文で書く | 本体 |
| F-13〜F-15(低) 「上表」の指す先、0044 と 0276 の範囲のずれ、文言 | 直す | 本体 |
| R1-1(高) PR を経ないコミットで規則を変えたときの下限 R2 を照らしていない | choiceReviewExclusions については直す(集約が、規則を変えたコミットの下限 R2 の欠落を出す)。既にある decisionRules の同じ穴は、過去の決定を固定した場面に触れるので本件では変えず、議長が既存の Issue へ記録する。直せなければ、本体の IMPL の note を実態へ直し、undelivered で表示する | template → 本体 |
| R1-2(中) 規則の変更そのものが外した件数に入る | 直す。プロセス構成のファイルに触れる変更は、規則に当てない(外した件数に数えない) | template → 本体(条文に 1 文) |
| R1-3(中) 規則の why が組織の外へ渡す開示に出る | 直す。外側の開示は規則の id と件数だけ。why は内側だけ | template |
| R1-4(中) PROCESS-PROFILE.md に規則が出ない | 直す(表示する)。直せなければ undelivered | template → 本体 |
| 低(template) G-6 の手引きに 5.4.7 が無い、スキルの括弧書き | 直す | template |
| 低 IMPL-1080 の「初期化でも検査」 | 実態に合わせて note を直す(初期化の対話は規則を書かない。規則を書けるのは変化点だけ)。初期化の入口と変化点のスキル本文の案内が無い点は、条文が約束していないので undelivered にはしないが、note に 1 文で書く | 本体 |

採らない案: R1-1 を decisionRules まで広げて直すこと(本件の範囲の外。記録して別件にする)。F-2 で条文を「手元で足りても毎回調べる」に変えること(些細な選択のたびに調べることになり、指揮役の指示の「増えすぎる場面を塞ぐ」に反する。所有者に知らせて判断を仰ぐ)。
