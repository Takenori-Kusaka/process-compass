### PR の検査(check-pr.mjs)の知らせ(合否を変えない。`result.notices`)
- 読む規則: **基底ブランチの構成**(`baseConfig.choiceReviewExclusions.rules`)。基底の構成が未設定、または規則が 0 件なら、何も出さない
- 当てる変更: PR の変更のうち、**プロセス構成のファイル(`process.config.json`)に触れる変更(名前の変更の元を含む)を除いたもの**に、規則のパスと変更の種類で当てる
- 「当てていない」の条件(1 つでも当たれば): 記載の区分が R1、または区分の下限の規則が出した下限が R1 / 基底か head の構成の安全重要度が CL1 以上 / 基底か head の構成が規制業
- 文言(当てていない): `作業上の選択を読む対象から外す規則(<規則の id を , 区切り>)は、この変更に当てていない(<R1 の変更・安全重要度 CL1 以上・規制業を・で並べる>)。記録された作業上の選択と理由も、確定の場で読む対象である(第5章 5.5.1)`
- 文言(当たった): `作業上の選択を読む対象から外す規則に当たる変更である(当たった規則: <id を , 区切り>)。記録された作業上の選択と理由は、確定の場で読む対象から外れる。独立レビューの基準・依存の確認・判断記録は外れない。この知らせは合否を変えない(第5章 5.5.1)`
- 「当てていない」の知らせが先で、出たときは「当たった」は出さない。規則はあるが当たらず、当てない条件にも当たらない変更には何も出さない
- 既存の規則の変更の PR の下限 R2 と、規則と製品のコードの同時変更の失敗は変えていない
