# 束 B22 — 附属書H と附属書F F.4 の食い違いの裁定(軽。2026-11-19)

出どころ: 群B の独立の突合 1巡目 R-1(`50-review-B-1.md`)。2委員の意見: `80-light-H-proposer.md`・`80-light-H-opponent.md`。

## 1. 経緯(所有者の指示により記録する)

1. 突合の R-1 が、附属書H の表「R1 の変更では変異試験が必須」と、附属書F F.4 の R1 の列「R(推奨)」の食い違いを挙げた
2. 議長は「附属書H の列はフェーズ5 の手引きの投影で、全採用者に必須を課す根拠の ADR が無い」と要約し、子(附属書H を F.4 に揃える)を推して指揮役へ上げた。所有者は子を選んだ(triage §4 の 38)
3. 軽の2委員が一次の条文を調べ、「R1 の変異試験は必須」が附属書H の表だけでなく、保証の主張の側(`assurance-case.md` の H.3 の検証に数える条件、主張 C4 の証拠、想定問答4)、`adoption-guide.md`、フェーズ5 の手引き、`gate-criteria.md`・`roles-responsibilities.md`(変異試験を R1・R2 の統制に数える)に組み込まれていることを示した。議長の先の要約は不十分だった
4. 議長は前提を訂正し、子-a(推奨に下げて6か所を改める)と寅(附属書H を保ち F.4 を直す)を上げ直した。推奨は寅に改めた
5. 所有者は回答 38 を取り消し、寅を選んだ(triage §4 の 39)

## 2. 裁定(寅)

- 附属書H H.1 の表の規定(R1 は必須・変更のたび、R2 は週次で合否条件にしない、R3 は任意)を保つ。保証の主張の側の文は変えない
- 誤りは附属書F F.4 の表の側にあると定める。F.4 のミューテーション試験の行の R1 の欄を「附属書H H.1 による」に直す
- **R2 の欄も同じに直す**(議長の判断。所有者の回答は R1 の列を名指す。R2 も、附属書H は「週次の定期実行」、F.4 は「R」で、同じ食い違いである。主張 C4 の証拠は「R2 は週次」を数える。同じ原則(附属書H を保つ)の帰結として直し、指揮役への報告に明記する)。R3 の欄(—)は附属書H の「任意」と食い違わないので変えない
- F.4 の安全関連部の列(HR)と、本束で足した F.4 の注(ADR-0224 の条件の案件では理由つきの省略を用いない)は変えない
- IMPL-1026 は `state=undelivered` の表示を続ける。note から「F.4 と食い違う。未裁定」を外し、「附属書F F.4 の R1・R2 の欄は附属書H H.1 を指す(2026-11-19 の裁定)。道具の無い言語の扱いは #445 に残る」と書く。`impl-inventory.yaml` の節は `marked` のまま
- ADR-0224 の決定13 を、この裁定に改める。全採用者の R1 の変更の変異試験は、附属書H に既に在る規定であり、本 ADR が新しく課すものではない。本 ADR が足すのは、案件ごとの段(CL3・Q1「はい」)だけである。採らなかった案と §1 の経緯を ADR-0224 に記録する
- 審議の重さ: 軽(食い違いの解消。規定の強さは変えず、誤っていた表の欄を正本へ向ける)。独立の突合は、本束の 2巡目に含める

## 3. 採らない案

- **子-a**(R1 を推奨に下げ、保証の主張の6か所を「実行した変更に限り検出力を測っていると主張する」に改める): 保証の主張 C4 と H.3 の検証に数える条件を弱める。適合の主張の信頼に響く変更で、軽に収まらず、弱める根拠の実証も無い
- **子**(附属書H の表の1欄だけを推奨に替える): 保証の主張の側の6か所と食い違い、実質の必須が H.3 に残る
- **丑**(F.4 を附属書H に揃えたうえで、全採用者への必須を新しい義務として重の審議にかける): 規定は既に附属書H に在る。新しく課すのではなく、既存の規定を確認するだけで足りる
- F.4 のミューテーション試験の行を表から削る案: 安全関連部の列(HR)が要る
- 道具の無い言語の扱いを本束で定める案: template へ降ろすときの設計に依る。#445 に残す

## 4. 残る点(#445 へ)

- IMPL-1026 を template へ降ろすとき、R1 の変更ごとの変異試験を案件ごとの段(mutation)と同じ段で拾うか、道具の無い言語をどう受けるか
