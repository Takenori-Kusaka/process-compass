# 起案委員の意見(#459・#460。2026-11-27)

総評: 裁定の案の骨(A1 定義・性質で受ける・帰属の確認で裏づける・例外承認は不可・template は D1 へ)に賛成。ただし**定義を増やしすぎ**、**二重の記録を否定しながら写しを要する**矛盾がある。次のとおり組み直す。

## 論点ごと

- **A 定義を足す(A1)**: 賛成。A2・A3 の却下も妥当。定義は短くし、裏づけの細目は第4章への参照だけにする。「求めない」の列挙(署名・押印・手書き)は定義に入れず、1.4 の注に置く。
- **B 性質で受ける**: 賛成。ただし P1〜P6 は多すぎる。P2・P4・P5・P6 は「判定の成立」と保全の条件が既に課している(欠けは新義務でなく再掲)。新しいのは P1(本人の認証を経た操作)と P3(承認の意味の事前の定義)だけ。→ 性質は「既存の成立要件と保全の条件を満たす」「本人の操作として記録される」「承認の意味が事前に定義されている」の3つに縮める。
- **C 確認した項目**: C1 賛成、C2・C3 の却下に賛成。ただし事前の定義は新設せず、既存の「宣言行の事前の定義」(gate-criteria.md L118 付近)を外部の仕組みの申請の種別にも使う、と書く。
- **D 帰属**: D1 賛成、D2〜D4 の却下に賛成。閉じ方の割り当て(存在・形=machine、照合の真偽=manual、仕組みの充足=adopter)は、コアポリシーの「機械で閉じない統制は開示する」に合う。
- **E・F**: template は D1 の束へ、undelivered 表示で賛成。

## 裁定の案の欠陥

1. **二重の記録の矛盾**。B3 は「外部の決裁の後に様式を作る」を二重として退けるが、D1 は基底ブランチへ写し(所在・決裁者・日時・結果・版)を要する。実質は外部の正本+索引。**写しは二重の記録でなく、機械が読む索引である**と正面から書く。決裁の内容と証跡は外部に1つだけ。写しに記名者の書き込みを求めない(写しは事務担当が作る)。これなら所有者の決定(欄を求めない)と矛盾しない。
2. **「帰属の確認」の定義の変更を明示していない**。現行(overview.md L113)は「記名者が作成した変更で効力を持つ記録を入れるとき」の統制。D1 では記名者は作成者でなく、確認者は写しと外部の記録の一致を見る。定義の拡張であり、「延ばすだけ」ではない。1.4 の改訂に載せる。
3. **確認者の独立が未記載**。写しの作成者と確認者が同じ人だと自己確認になる。確認者は写しの作成者・記名者のいずれとも別人、と条件に入れる(機械で閉じる決定可能な条件)。
4. **ADR 番号**。docs の ADR は 0250 が最新。0264 は他の束の予約でなければ根拠が要る。採番を台帳で確かめる。
5. 現行は L63 で「媒体を様式のファイルに限定しない」と既に書く。受け皿の限定は L118 の「人が書く欄の受け皿は2つ」にあり、変えるのはそこと ADR-0070 決定3・8。変更の所在をこの2点に絞る(gate-criteria.md の広い書き換えを避け、信頼性の根拠を局所化する)。

## 未決の点への答え

1. 成立条件1・4 で数える: **数える**。ただし区分(外部の記録の照合は人)を開示し、EV マークの差し替え条件は「抜き取りで見つかった不一致の件数」。
2. 確認者を置けない小体制: 数えない。「外部の記録の所在あり・照合者なし」と開示し、成立条件1 は不成立のまま。無理に自己確認で満たさせない。
3. 欄名の変更: D1 と同じ束(賛成)。
4. 規制業・CL2 以上: 受け皿にしてよい。新しい制限は課さない(根拠が無い)。監査対応書式は維持。

## 破られたとき誰が何を失うか(条文に1文)

不一致が見つかれば、確認者の承認がホスティングに残り、その記録は欠落に戻り、該当出荷の保証の主張は開示で取り消される。失うのは採用者の保証の主張であり、標準は罰しない。

## 条文の案

1.4 用語の定義:

> **記名**: 承認・決定・確定を行った者が誰であるかを、後から確かめられる形で記録に残すこと。媒体は問わない。**帰属の確認**: 記録が記名者本人のものであることを確かめる統制。記名者が作成した変更の承認、または、組織の決裁の仕組みの記録と基底ブランチの写しの一致の確認(確認者は写しの作成者・記名者と別の名簿の人)をいう。記録の中身の妥当性を判定しない。

gate-criteria.md「機械が出す欄と人が書く欄」の受け皿:

> 人が書く欄の受け皿は、レビューの本文、判定記録(様式)、組織の決裁の仕組みの記録の3つとする。決裁の仕組みの記録は、既存の成立要件と保全の条件を満たし、本人の操作として記録され、承認の種別とゲートの対応を事前に定めたものに限る。基底ブランチには、記録の所在・決裁した者・日時・結果・対象の版を写しとして置く。
