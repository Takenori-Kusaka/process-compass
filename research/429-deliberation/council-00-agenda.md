# 会議体の議題(#429 AI の担い手の認証情報の共有と、名簿の数値の識別子による照合)

入力: Issue #429、`survey-429-1-internal.md`(内部)、`survey-429-2-external.md`(外部)。前段の審議 `research/380-deliberation/`(H-7)と ADR-0106。

## 前提として確かめた事実(要旨)

- 本標準は、席どうしの認証情報の分離(3.5.1・3.5.3・1.10.2、ADR-0035/0082/0083)を求めるが、席の責任者(人)とその席の AI の担い手が1つの認証情報を共有する構成には、禁止も推奨も開示も無い
- G-6 の「AI・bot の名義の承認は数えない」(gate-criteria.md:933・938-949)は名義で AI を見分けられる前提に立つ。担い手が人のアカウントで出した承認は人の承認として数えられ、この穴は G-6 の節に書かれていない。共有を想定する記述は #380 で足した EV-0220・観点28・ADR-0106 だけ
- 担い手のアカウントを書く欄が無い(3.4.2 の識別はモデル・指示資産・権限の組。D-0・構成・/process-init・保証の開示・第8章にも無い)。テンプレートの中でも recording.md(共有を想定内とする)と performer.md(担い手ごとに別のトークン)で前提が割れる
- 権限設定で止まるのは `gh pr review` だけ。`gh api` で直接レビューや承認を作る経路は止まらない。常駐の規則も宣言行のレビューに限る
- 名簿の照合はログイン名の文字列一致だけ(findPersonByAccount)。数値の識別子は写し・PR の検査の入力・ホスティングの照会で取れているが、照合に使っていない。契約検査は名簿に数値を書くと失敗させる。第4章 :84(数値の識別子の対応表、リポジトリの外側)には実装マークが無い
- 外部: Copilot cloud agent はコミットの作者を Copilot にし、依頼した人を共同作者とし、依頼した人の承認を数えない。Claude Code Action は既定で App として動き、公式文書は PAT を使わないよう書く。ローカルの Claude Code は利用者の認証情報で動く。Cursor の対話起動・Devin の User 設定は人の名義で PR を開く
- NIST SP 800-53 Rev.5: IA-2 は利用者の一意の識別と代理のプロセスへの結び付けを求め、AC-2(9) は共有アカウントを説明責任の欠けとして扱い、IA-4 d. は識別子の再利用を禁じる。OWASP Agentic Top 10 ASI03 は「attribution gap」と「Identity Sharing」を挙げる。CISA ほかの指針は「各エージェントを別個の主体として構成する」。人の認証情報の共有を禁じる明文の条文は見つかっていない
- GitHub: ログイン名は改名で直ちに、削除後 90 日で他人が取れる。数値の id は REST・GraphQL で取れる。ルールセットは数値の actor_id、CODEOWNERS と監査ログの検索はログイン名で照合する。Co-authored-by と署名は、人の名義の操作を人の操作と区別する証拠にならない

## R-1 共有の構成への要求の向き

- 問い: 人の認証情報を AI の担い手と共有する構成を、禁止するか、推奨と開示にとどめるか、構成の入力として問うか、黙るか。1〜2名の採用者への影響。1.10.2(席ごとの認証情報)との関係

## R-2 共有の構成で崩れる統制の扱い

- 問い: G-6 の独立した人の確認、作成を指示した者の照合、効力を持つ記録の帰属、PR の作成者の別、の何が崩れるか。崩れる統制ごとに、数えない・開示する・人の確認で補う、のどれにするか。保証の開示の項目のどこに出すか

## R-3 担い手の識別にアカウントを含めるか

- 問い: 3.4.2 の担い手の識別(モデル・指示資産・権限)に、動かすアカウント(または「人の認証情報で動く」の別)を足すか。D-0・構成の欄。変化点の扱い

## R-4 名簿の数値の識別子による照合

- 問い: 第4章 :84 の要求(数値の識別子、リポジトリの外側)を維持するか、改めるか。準拠テンプレートの移行の形(内部調査の M1〜M6)。ログイン名でしか照合できなかった照合の開示。PR 本文の `@アカウント` の扱い

## R-5 テンプレートの手段と記録

- 問い: `gh api` による承認・レビューの作成の止め方(権限設定の deny の範囲、常駐の規則)。新しい ADR、EV・IMPL、採らない案
