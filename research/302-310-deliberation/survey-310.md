`src/content/docs/phase4-process-design/overview.md` 「## 1.7 記述の原則」(179〜186 行)。

- 「推奨事項と区別する」と書くが、推奨事項の文末は定めていない。許容(してよい)、可能(できる)、外部の制約(法令による)の文末も無い

- プロジェクトの執筆規約(`CLAUDE.md`「日本語校正」)は「箇条書きは『である調 / 体言止め』、本文は『ですます調』」。1.7 の 3 形は「である調」の形で書かれており、本文では「〜しなければなりません」「〜してはなりません」になる。**1.7 は文体の違い(である/ですます)に触れていない**
- 文末の形を検査する仕組みは無い。`scripts/` の全ファイルと `.textlintrc.json` を「望ましい・しなければ・文末」で検索して該当なし。`scripts/check-tone.mjs` が見るのは内部資料への言及・主観的な強調・口語・未完成の痕跡の 4 種

対応表から読み取れる事実。

- JIS は、**平叙の「…する。」を要求の表現形式の筆頭に置く**。本標準の「〜します。」をこれに当たると読めば、本文の規範の大半は JIS の作法に合う。ただし JIS は「説明の文」と「…する。」の要求を、置き場所(規定要素か、注記・例・参考の附属書か)で分ける。本標準の本文は、根拠の説明と規範が同じ段落に並ぶので、**文末が同じ「します」の文のうち、どれが要求かを置き場所で分けられない**
- JIS は「…できる」を許容にも可能性にも使わないと定める。本標準は多用している
- 「省略可」「任意」に 1 対 1 で当たる JIS の形は「…(し)なくてもよい」(不必要)である。指針 第2部 第9版は、否定の許容を曖昧として廃した(「Negative permissions are ambiguous and should not be used. Rather than using negative permissions, either rewrite the sentence to state what is permitted, or rewrite as a requirement/recommendation not to do something.」)

- **B6 表の中の語の閉じた語彙**。表の升に入る語(適用・標準・簡略・省略可・任意・必須・禁止・許容・避けたい・どちらでもよい・不要)が、どの種類(要求・推奨・許容)に当たるかの対応表。ADR-0028 のゲートの状態の語彙(5 値)と ADR-0049(適用範囲の単位と閉じた語彙)が先例。「省略可」を (a) 規定(S0 では省略する)へ改める、(b) 許容(省略しても適用してもよい)とし、エンジンに選択を持たせる、(c) 語を廃して状態の語彙の日本語(省略・未達・簡略・統合・適用)だけを使う、のどれかを決めると 1.6 の差の扱いが決まる
- **「できる」の扱い**。JIS は許容にも可能性にも使わないと定める。本標準は「AI は草案を生成できます」を、能力と許容の両方に使っている。第5章 5.5 の「協働で AI が起案できるもの」の表は許容の表である
- **推奨の効力**。推奨に従わなかったとき、理由の記録を求めるか(附属書F の「HR: 適用しない場合は、しない理由を記録する」は、推奨に記録の要求を重ねた例。RFC 2119 の SHOULD の読みに近い)、何も求めないか(指針 第2部・JIS の推奨)
- **検査**。どの案でも、文末の検査を `npm run check` に足すか、足さないと決めるか

## 4. 会議体への問い

1. **本標準の「〜します。」は要求か**。JIS Z 8301 は平叙の「…する。」を要求の筆頭に置く。そう読むなら 1.7 を広げ、本文から説明を出す作業(「本文は要求事項のみ」の実行)が要る。読まないなら、規範の大半を書き換える。どちらの作業を引き受けるのか。第 3 の道(構造で示す)は、表の外の規範をどうするのか
2. **手引きを自称する附属書の中の「してはならない」は、適合に効くのか**。JIS は「参考要素とみなす」。ADR-0040 決定5 は「その規範だけを降ろす」。E.9 の禁止事項 5 つ、H.4・H.8、G.5 を、規定の附属書に入れるのか、本文へ移すのか、参考として効力を持たせないのか
3. **第8章は規定か、手引きか**。ADR-0009 決定5(誤読を防ぐために本文へ置いた)と、ADR-0057 S42(「第8章の表は手引き」)のどちらを正とするのか。表が手引きなら、エンジンが出す `omitted` は「標準の規則により省略する」(ADR-0028)と言えるのか
4. **「省略可」「任意」は、組織が選べるという意味か、標準が省略を定めるという意味か**。選べるなら、選んだ記録はどこに残り、選ばなかった組織の既定は何か。定めるなら、なぜ「可」と書くのか。G-7 と G-8 で同じ語が逆の結果になっている状態を、どちらへ揃えるのか
5. **受入基準の内容について、標準は何も課さないのか、確定の行為の記録までは課すのか**。ADR-0051 決定2 を維持したまま課せるのは記録までである。記録を課して、形だけの記録を防ぐ手段が無いなら、課さないと明記するほうが信頼できるのか
6. **スキルの文は標準の一部か、実装の一例か**。一部なら、標準に無い 17 件と、標準を落とす・強める 34 件を検査で止める仕組みが要る。一例なら、「現場が従うのはスキルの文」という事実に対して、標準の要求が届いたことを何で確かめるのか。フェーズ5・6 の文にも同じ問いが立つ
