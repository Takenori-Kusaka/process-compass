# #334 受付

- 日付: 2026-11-15
- 審議の重さ(案): **軽**
- 論点: (1) 判定記録の整合の検査を PR の時点で走らせるか(#254 の残り)。(2) G-4 で確定した版から受入基準・前提・スコープ外が変わったのに、変更後の版の判定記録が無い状態を PR の時点で検出するか(#294 K-1 の機械の確認の前倒し)

## 重さ「軽」とする理由

- 新しい義務を採用者へ課さない見込み。標準は G-2/G-4 の受け直し(第4章「確定した版を変える場合」、ADR-0078)を既に義務としている。#334 が決めるのは、その確認を**どこで機械にするか**(出荷の集約 / PR の検査 / 置かない)である。検査の置き場の選択に当たる
- ADR の原則を変えない見込み。ADR-0036(判定記録の作成をもって成立)、ADR-0106(判定記録の帰属は出荷の集約で事後でよい)の区分を前提にできる
- 安全・法令に当たらない
- 外部調査は不要(新しい義務を課さず、規格の引用も要さない)。内部の調査と実行での確認だけを行った

## 重へ上げる条件(議長への注意)

- 会議体が「PR の時点で判定記録の存在を必須にする」「PR の時点で集約を必須チェックにする」を採る場合は、採用者の新しい義務であり、ADR-0106 の区分(判定記録は事後でよい)と ADR-0078 の 2.10.8(受け直しのために止めない)にも触れるため、重へ上げる(research.md の案 1-C・2-C)
- 軽のまま閉じられるのは、(a) 出荷の集約に置く現状を維持して「PR の時点では課さない」を明記する、(b) PR の時点では決定可能な部分検査(構文、または spec の節の差分の表示のみ)だけを足す、のいずれか
