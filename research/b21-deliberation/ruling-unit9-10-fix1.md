# 束 B21 単位9・10 — 突合 1巡目の所見への議長の裁定(2026-11-18)

対象の所見: `review-unit9-10-1.md`(高2・中6・低9)。

| 所見 | 裁定 | 理由 |
| --- | --- | --- |
| H1(0682 の note とコメントの文が、まだ無い手引きを有るものとして示す) | **採る**。note は「差し戻しの手引きの一文は未記載(B20 の push の後に足す)」に改める。PR へのコメントの文からは、手引きへの参照を外す(一文を足した単位で戻す) | 表示と実態の食い違い |
| H2(6項目の note に、実装の前の文が残る) | **採る**(編集の指摘)。旧い文を削るか、日付つきの経緯へ移す。0136 の「降りた部分」に review-queue の検出を足す | 同上 |
| M1(依頼の付け直しで催促と同時保有数から外れる) | **採る**。応答は「依頼の時刻より後のレビュー」に限る。付け直しの場面を試験へ足す | 日時の比較で決定可能。催促が黙って消えるのは統制の抜け |
| M2(判定完了時間の起点と終点が条文とずれる) | **採る**。起点は最初のレビュー依頼(無ければ ready の時点)、終点は条文の定義に寄せる。条文が二つあって読みが割れる場合は、どちらに寄せたかを note に書き、割れている事実を `fix-unit9-10-1.md` に残す(議長が #445 へコメントで寄せる)。条項は足さない | 標準の定義が正本。テンプレートが別の定義を作らない |
| M3(機械が付けた risk のラベルが、後の push で下限が上がっても更新されない) | **採る**。機械(github-actions)が付けたラベルだけを、下限へ引き上げる。下げない。人が付けたラベルには触れない | 引き上げは安全側。人の操作を覆さない(§5)を保つ |
| M4(着手の時点の近似が、作業単位より前を起点にしうる) | **採る**。起点を「PR の作成と Issue の作成の遅い方」で下から抑え、同じリポジトリの PR に限る。近似が残る点は note に書く | 日時の比較で決定可能。残る近似は開示する |
| M5(観測の窓 90 日・最小標本 10 件が新しい定義として入っている) | **採る**。窓と完了の判定は、単位8(`next.mjs`)の読み方を共用する。共用しても残る値があれば、テンプレートの既定値として note に値を書き、根拠の無い暫定の値である旨を開示する。標準の本文へ新しい値は足さない | 所有者の方針: 細かい定義を増やさない。正本を2つにしない |
| M6(0212 の降ろし先が実装の所在と違う) | **採る**。降ろし先を実装の所在に合わせる。結線の担当への申し送りに書く | 台帳の検査が実在を確かめるため |
| L1(ページ送りの連結) | **採る**。`--slurp` を使う | 本文の中の文字列を壊す |
| L2(重複を防ぐ印をだれのコメントでも受け付ける) | **採る**。印は機械(github-actions)のコメントに限る | 印を書けば通知を止められる |
| L3(日本時間の固定) | **採る**。差を変数で渡せるようにし、note へ書く。夏時間には対応しない旨を開示する | 細かい定義は増やさず、開示で閉じる |
| L4(祝日を数えていない旨がコメントに出ない) | **採る**。催促の文に一言足す | §2.4 |
| L5(0680 の判定が事象から組んだ値を見る) | **採る**。`requested_reviewers` が空であることで判定する | 決定可能な正本の値を読む |
| 残りの低 | 直しの案のとおりに直せるものは直す。直さないものは理由を記録する | — |

## 採らない案

- M3 に対し、人が付けたラベルも機械が下限へ引き上げる案: 人の操作を機械が覆す(§5)
- M5 に対し、窓と最小標本を標準の本文へ値として足す案: 実証を欠く値を規範にすることになり、細かい定義が増える
- H1 に対し、いま `/gate` の SKILL.md へ一文を足す案: 並行の束 B20 が触るファイルであり、B20 の push の後に行う
