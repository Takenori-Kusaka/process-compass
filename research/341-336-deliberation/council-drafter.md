## 1. 論点 A: 逐語の文案

検証した事実: 1.3 の表は `lint:citations` が「行の版の呼び名」と「行のカードの題名の最初の呼び名」の一致を求める。SRC-0491 の題は `ISO/IEC/IEEE 12207:2026 …` で、新しい行 `ISO/IEC/IEEE 12207:2026(第2版)` は通る。「(第2版)」は呼び名の外で、ガイドラインの「第N版」の検査(4)は規格の呼び名を持たない行にだけ掛かる。実装は `npm run test:citations` で確かめる。

**1.3 の行(66 行の置き換え)**

`| ライフサイクル | ISO/IEC/IEEE 12207:2026(第2版) | プロセスを「成果(Outcomes)」で定義する構成の根拠 | 出版社の公開のプレビュー(まえがき・序論・適用範囲・目次・参考文献)。箇条4(適合)の本文は読んでいない | SRC-0491 |`

**78 行の注記(置き換え。「追従を決めていない」を消す)**

「表の文書は、2017 年版(ISO/IEC/IEEE 12207:2017)から第2版(ISO/IEC/IEEE 12207:2026。SRC-0491)へ改めました(#341、2026-11)。第2版は 2026-04 に第1版を置き換えました。出版社の公開のプレビューにより確かめた事実であり、発行日は iso.org では確かめていません。用途は変わりません。成果で定義する構成と4プロセス群は、第2版の序論と目次でも同じです。2017 年版の附属書H(Application of Agile、参考)は、第2版の附属書の一覧にありません。アジャイルの適用は、第2版では適用範囲の記述に移りました。本標準の本文は、2017 年版の附属書H を引いていません。なお、本標準の附属書H(保証の論証)とは別の文書の別の附属書です。規格の附属書を書くときは、番号と版を前に置きます」

## 3. 論点 D: 先送りの防止(依頼 (1))

draft の「2026 年版の目次を一次の資料で確かめた時点」は、確かめる者・時期・場所が無く、実質は無期限の先送りになりうる。検査も働かない(`lint:citations` は H.10 の版を見ない)。次を加えて確定する。

1. **担当と契機**: 確かめるのは本標準の保守者(版の発行の棚卸しを行う者)。契機は2つで、早い方に当たる。(a) 本標準の次の版の発行(standard-editions.md「引用規格の棚卸し」手順1・2)、(b) 下の EV の見直し期日。確かめる場所は ISO の公開の目次かプレビュー、または JIS Q 9001:2026 の公開の目次。見つからなければ、見つからなかったことを記録して期日を延ばす(延長も EV の改版で記録する)
2. **棚卸しの手順へ固定する**: standard-editions.md の手順1 の「記録」の欄に「対応表を持つ文書(H.10 の ISO 9001)は、一次の目次を確かめたか、確かめていないならその旨と次の見直しの期日」を足す。棚卸しを省けば `citationReview` が欠けるので、既存の仕組みで追える
3. **根拠水準のマーク**を H.10 の版の扱い(assurance-case.md 109 行付近、または H.10 の導入の 910〜912 行の箇所)に置く。書式は次のとおり(識別子は実装が `evidence-ledger.md` の最大値の次にする。本日時点の台帳の最大は EV-0256)

```
:::caution[暫定 EV-NNNN / 見直し 2027-04]
**対象**: H.10 の ISO 9001 の対応を、2015 年版の目次のまま保つこと(2026 年版の本文と目次を一次の資料で確かめていない)。
**根拠の水準**: E1(間接)。
**差し替え条件**: ISO 9001:2026 の箇条の番号と題を、ISO または JIS の公開の目次で確かめた結果。2015 年版の認証の移行期間の終了日を、ISO または認定機関の一次の発表で確かめた結果。

H.10 は 2015 年版の箇条の番号と題を、公開の目次で確かめて書いています。2026 年版は 2026-09-16 に発行されたと、二次資料が伝えています(SRC-0736)。2015 年版の認証は 2029-09-30 まで有効と、同じ二次資料が伝えますが、終了日は認定機関の最終の決定によります。箇条1〜10 の構成が保たれる見込みは、解説による期待であり、確かめていません。
:::
```

見直し期日の根拠: JIS Q 9001:2026 の公開の時期が不明(survey 2.2)で、ISO の目次の公開が先に起きる見込みがある。本標準の保守の周期(EV-0106 の 2027-04 と同じ周期)に合わせて 2027-04 とした。この値の根拠は E1 の水準のままで、マークの対象に含める。

**旧版の列を外す時期**: 本文に 2029-09-30 を規則の値として書かない。「2015 年版の認証の移行期間が終わった後の、最初の版の発行の棚卸し」と書き、終了日は EV の中だけに、二次情報として置く。理由は、外部の二次の日付を本標準の規則の条件にすると、日付が動いたときに規則が意味を変えるため。

**(3) 外部事実の根拠水準マーク**: 判断を左右する外部の事実(2029-09-30。旧版の列を外す時期の根拠)で、かつ単一の二次情報にだけ支えられるものは、マークが要る(E1)。判断を左右しない記述的な事実(発行日。出版社のプレビューで確かめた 12207:2026 の目次)は、行の中の読んだ範囲の開示で足りる(ADR-0083 の形。1.3 の既存の書き方)。draft の 4.4「マークは要らない」は、後者の基準を前者にまで広げており、**修正する**。

D2 のその他(追補の読んだ範囲、版の無い4件への `:2015`、`lint:citations` を足さない判断)は draft どおり。追補は1.3 の ISO 9001 行の「読んだ範囲」に、「追補(ISO 9001:2015/Amd 1:2024、JIS Q 9001:2015/AMENDMENT 1:2025)は読んでいない」と書く。追補は SRC-0737 が abstract 水準であり、「読んでいない」と書くのが正しい。

## 4. 論点 C: 新しい義務になっていないか(依頼 (2))

draft の2文目「…は、それだけでは、…検査を外す変更の記録に当たりません」は、二様に読める。

- 意図した読み: 道具の上の操作は、本標準の記録の代わりにならない
- 危険な読み: 道具の上の却下は検査を外す変更でない。だから G-5 の記録は要らない(X-1 を先に決めてしまう)

後者は、必須の検査の警告を却下しても記録を求められない、という免罪に読まれる。これは X-1(未決)を、C2 の文で黙って「求めない」側へ決めることになる。逆に「求める」と書けば新しい義務で、**重に当たる**。どちらも本件で決められない。

確定する文案(置き場は draft どおり G-5「検査を外す変更の記録」の節の末尾):

「本標準は、外部の道具が持つ却下の理由の値(静的解析の結果の交換形式の抑止、コードスキャンや依存関係の警告の却下の理由など)を、本標準の記録の語と対応づけません。値の組が道具ごとに異なり、本標準で権限を要する判断(リスクの受容)と、事実の判断(誤検出)が、同じ欄に混ざるためです。道具の上で警告を却下・抑止・解決にしたことは、それだけでは、本標準の受容、例外承認、指摘の不採用、検査を外す変更の記録として数えません。これらの判断をしたのであれば、本標準の記録を別に残します。道具の上の却下そのものが、検査を外す変更に当たるかは、本標準は定めていません」

- 2文目の「数えません」は、記録の**代替にならない**ことだけを言う。「別に残します」の前提は「これらの判断をしたのであれば」で、既存の義務(受容は層1・G-8・7.3、検査を外すのは AI維持管理者の受け入れ)の言い換えに限る。道具の却下を写す義務は課さない。却下したが受容も例外承認もしていない、という操作は、記録を求めない
- 最後の1文が「書かれていない」と「課さないと決めた」の区別を満たす。**課さないと決めたのではなく、決めていない**ことを開示する。これを X-1 の行き先に結ぶ EV を添える
- EV(識別子は実装が割り当て、見直し 2027-04): 対象「外部の道具の上の却下・抑止が、検査を外す変更に当たるか定めていないこと(G-5)」。水準 E0。差し替え条件「採用者の運用で、道具の上の却下により必須の検査を実質的に外した事例の有無と件数」。X-1 を寄せた既存 Issue の番号を本文に添える
- 重の判定: **文案は新しい義務を課さないので軽のまま**。ただし、議長が X-1 を「当たる」と決めれば、それは採用者への新しい義務で**重**。その場合は本件に混ぜず、別の審議にする。この線引きを decision.md に書く

実装マーク: テンプレートが `dismissed_reason` を読むかは、実装の担当が確かめる。読むなら、挙動を変える文ではないので `<!-- impl -->` は付けない(降ろす対象が無い)。読んで何かを止めているなら、その挙動は本文と食い違うので、止めて議長へ送る。
