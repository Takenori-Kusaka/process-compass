# #432 論点1 会議体(軽) 委員1: 起案

- 対象: 発生で入った兼務が、誰の決定にも掛からずに続く(survey-432-1-internal.md §3.2 L1a〜L1f、§4.1 1-A〜1-G)
- 前提: 論点2 の裁定(decision.md R-1〜R-3)。決定者は、自分が当事者になる兼務を自分の記名で決めない。2名以上では本人以外の記名を事前に要する

## 1. 推す案: 1-A + 1-E(印) + 1-D(期限) + 1-G(前者)

1. **1-A**: 照合の鍵を「席の組 + 当事者」にする。当事者が替われば「解消」と「生じる」の行を出す。旧い構成の当事者は、記録の `reason` からではなく変更前の構成の席の割り当てから導く(記録の移行は要らない)
2. **1-E**: 兼務の記録に由来(発生 / 決定)の印を持たせる。発生で入り、内側の人が2人以上になった兼務を「決定待ち」と表示する。印が無い旧い記録で内側が2人以上なら、決定待ちとして扱う(厳しくする向きに倒す)
3. **1-D**: 決定待ちの兼務は、次のゲート判定より前に、解くか、記名で決める。記名者は R-1・R-2 による(当事者が決定者なら本人以外)。決めないまま判定すると、判定記録の検査が記載の欠落として扱う。名簿へ人を足す事実の反映は止めない
4. **1-G(前者)**: 3.5 の 387 行(出荷判定者 × 事業決裁者、3名未満)を、445 行と同じく「別の人を置けない場合は記録する。置ける体制で兼ねるのは緩める決定である」へそろえる

## 2. 理由(所在つき)

- 経路で扱いが分かれる。同じ最終の状態でも、初回の記入では緩める行(L1c)、1人から2人目を足す経路では記名なしの通過(L1f)になる。同じ状態に違う統制が掛かるプロセスは、信頼できない
- ADR-0055 決定5(136〜152 行)と 3.13.2(1955 行)は、発生を「人が実際に減った場合」に限る。人が増えた後も発生の扱いが続くことは、この限定と食い違う
- 3.5 の 445 行は、離脱の記録を「成立しない場合は」に限る。2人目が入れば、その条件はもう満たされない
- 3.13.1 変化点1(1933 行)は「兼務の変更」を変化点に数える。3.13.4 記録2(2048 行)は再判定の結果を記録として求める。当事者の差し替え(L1d)で行が出ないのは、この2つに反する。1-A はこの食い違いを解く
- 1-D の時点は、3.13.3 の「最初のゲート判定より前に」と同じ型である。判定が兼務に頼る前に決まっていれば、ゲートの信頼性は保たれる
- 1-E の印が無いと、修正の前から2名の体制で続いている兼務(L1a 段4・5 の状態)を拾えない。1人から2人への移り目だけを見る 1-B の検出では、移り目を過ぎた構成が漏れる

## 3. 他の案を落とす理由

- **1-B**(人を足す変化点で記名を求める): 事実の反映が記名を待って止まる。2人目を名簿へ載せない誘因が生まれ、宣言と実態のずれ(3.13.5)を招く。ADR-0055 決定5 の「旧い構成のまま止めない」は離脱についての規定だが、事実を早く正しく載せるという趣旨は人の追加にも及ぶ。さらに R-1 により、記名者は入ったばかりの2人目になりうる。加入の手続と兼務の決定を同じ1手に束ねる理由は無い。検出の漏れは 2. の最後の項のとおり
- **1-C 単独**: 表示を強めるだけで、決定に掛からずに続くことは直らない。Issue の問題を解かない
- **1-F**(今の挙動を明記): L1c と L1f で扱いが分かれる状態を規定として固定する。分けて出せば決定を避けられる経路を認めることになる
- **1-G(後者)**(2名の兼務を決定に掛けない): 緩める向きである。ADR-0110 決定4 と R-1 に反する
- **1-A 単独**: 同じ人のまま続く経路(L1a・L1b・L1f)が直らない

## 4. 新しい義務を課すか

課す。次の2つは今は無い義務です。

- 1-D: 発生で入った兼務を、選択の余地が生じた後、次のゲート判定より前に決める義務
- 1-D × R-1: 出荷判定者 × 事業決裁者の兼務は、既定の構成では必ず決定者を当事者に含む(survey §2.5)。そのため2名の体制では、もう1人の記名が要る

1-A と 1-G(前者)だけなら、既存の規定(3.13.1・3.13.4・ADR-0110 決定4)の帰結にとどまり、新しい義務は課しません。

## 5. 1-B・1-D・1-E は ADR-0110 決定4 の帰結か: 言えない。**重へ上げるべき**

- 決定4(0110 の 63 行)が維持したのは「**新しく生じる**兼務の行」の分類だけである。続いている兼務を、人が増えた時点で決定へ移すことは定めていない。人の追加は「人の確認を減らす変更」(ADR-0055 決定5)にも当たらない。記名の時点は、既存の規定のどこからも一意に導けない(1976 行の自動の失効も、3名の境界しか定めていない)
- R-1・R-2 で改まったのは「誰が記名するか」であり、「いつ記名するか」ではない。時点を新しく置けば、記名の要件を採用者の2人目へ新たに課すことになる
- したがって 1-B・1-D・1-E は新しい義務であり、「重」(採用者への新しい義務)に当たる。外部の調査(§5 の3点目、例外の再評価の契機)で 1-D の時点の妥当性を確かめるべきである。2名の体制でもう1人が記名する牽制がどこまで効くかは実証が無いので、EV で開示する
- 1-A と 1-G(前者)は軽のまま先に実装してよい。ただし 1-G を本文へ入れると 2名の兼務が決定に掛かることになり、時点の規定が無いと 1-F と同じ穴が残る。そのため、1-G は 1-D と同じ裁定で入れることを推す
