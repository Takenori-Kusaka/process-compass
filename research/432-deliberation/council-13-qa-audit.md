# 会議体 委員の意見: 品質監査(#432 論点2・#433 の重の部分)

- 日付: 2026-11-11
- 立場: 監査。自己承認の抜け道、迂回、記録と開示の正直さ、事後のレビューの実効性を重視する
- 読んだもの: `council-00-agenda.md`、`survey-432-1-internal.md`、`survey-432-2-external.md`、`../433-deliberation/survey-433.md`・`decision.md`、roles-responsibilities.md:1993-2005、template-repository.md:604・645、ADR-0110:46-53・76-78
- 表記: 「未実証」= 実行でも外部の出典でも確かめていない前提

## 監査の前提として置く観察

1. 自己に関わる変更が問題になるのは、実際には **2名の体制**が中心である。出荷判定者 × 事業決裁者 は 3名以上で禁止され(roles-responsibilities.md:327・380-390)、テンプレートは抵触を拒否する(template-repository.md:634)。1名の体制の兼務は発生(`soleInsider`)で、決定に掛からない(survey-432-1 §4.2 の 2-F)。ただし 3名以上の非推奨の組(事業決裁者 × 価値責任者、:328)で決定者が当事者になる経路が緩める行として出るかは、**未確認**である
2. #433 の要件(決定者本人の行に本人以外の記名)は、今は**名目**である。同じアカウントの付け替えが「決定者その人を替える」任免として、本人の記名だけで通る(survey-433 U1・T2)。機械は同じ人かを判別しない(template-repository.md:915)。経路の申告(表記の変更か、新しい行か)で統制が変わる設計は、監査では正直な申告者だけを止める統制と評価する
3. 外部のどの枠組みも、小規模を理由に分離を免除して終わりにしない。共通するのは「特定する、代わりの統制を置く、記録・開示する」である(survey-432-2 S1 p.4、S5 事例3-10・5-1)。事例3-10 は、経営者の直接の関与を認める前提に、経営者自身による無効化への対応を置く。決定者の自己の決定はこの無効化そのものに当たる

## R-1 原則 — 推す案: 既定で禁止し、本人以外の確認が得られない体制に限って、記録と開示を条件に許す

- 理由
  - 既存の本文は、同じ形の自己承認をすでに禁じている。根拠は、新任の決定者が自分の任命を確定してはならないという規定(:2001)と、任免に記名を求める理由(:1998。替わった者の名義で緩める決定が通る)である。自分が当事者の兼務と、自分の行の表記の変更だけを許す理由は、本文に無い
  - 例外の形は :2001 と EV-0179 の前例(1名の体制、自己の任命として記録し、保証の開示の項目7 へ表示)にそろえる。釣り合いのとれない例外(#433 の1名の行き止まり、survey-433 S9・T1)を残さない
- 落とす案
  - 2-G(今の挙動を明記)は採らない。:2001 の禁止と同じ形の自己承認を、理由なしに認めることになる
  - 2-E(開示だけ)を単独では採らない。2名の体制には確認できる者がいるのに、確認を求めないことになるからである。開示は、下の R-2 の各段で**併せて必ず**行う
  - 2-A(変更前の決定者の記名)は採らない。観測した場面では当事者その人が記名者で、効かない(L2a-1)
  - #433 の c-1(課さないと明記する)は採らない。迂回を理由に要件を外すのは、穴を塞ぐ代わりに穴を規定にすることである。名目の要件を残す今の形(b)も同じ理由で採らない
- 留保: 「自己」の判定は、氏名ではなく名簿の数値の識別子(ADR-0108)で行う。氏名の一致に頼ると、表記の変更そのものが判定を外す

## R-2 体制の規模ごとの扱い — 推す案: 本人以外の確認を必須とし、事前にできなければ事後の確認で閉じる。1名の体制では開示で閉じる

| 体制 | 扱い |
| --- | --- |
| 3名以上 | 本人以外(本人以外の席の責任者か任命権者)の記名を**事前**に要する。表記の変更の行は今のテンプレートどおり。任免と同時になるため事前に記名できない行は、2名と同じ事後の確認による |
| 2名 | 決定者の記名で受け付ける。そのうえで、もう1名(当事者でない側)の**確認の記録**を要する。確認が付くまでは「本人以外の確認待ちの自己の決定」として保証の開示の項目7 へ表示する |
| 1名(任命権者なし) | 自己の決定として変化点の記録へ残し、保証の開示の項目7 へ表示する(:2001 と同じ形)。表記の変更の行き止まり(S9・T1)は解く。外部の確認者は任意とし、置いた場合はその記録を開示へ添える |

- 事後の確認を実効のあるものにする条件(監査として、どれか1つでも欠ければ名目の確認と評価する)
  1. **期限**: 次のゲート判定より前とする。確認の無いまま次のゲート判定を記録できない。変化点の後、最初のゲート判定より前に構成を改める規定(ADR-0055 決定3 の節)と同じ時点に置く
  2. **緩める決定の保留**: 確認が付くまで、自己の決定で決定者の席に結び付いたアカウントの記名による緩める向きの行を受け付けない。:1998 の懸念(替わった名義で緩める決定が通る)を、事後の確認の間に開けないためである
  3. **確認の材料**: 確認者は旧い値と新しい値(`rosterEdits`)、兼務の組と当事者を見て記名する。確認欄へのチェックだけでは認めない。AI の名義は受け付けない(:2003 付近の既存規定と同じ)
  4. **不同意の扱い**: 確認者が同意しない場合は、その記録を残す。次のゲート判定を止め、解くには新しい変化点を要する。解き方の詳細は実装で確かめる(**未実証**)
- 落とす案: 2-F(全面禁止)は採らない。1名の体制では :2001 と釣り合わない行き止まりを作る(#433 S9・T1)。また、迂回(U1)があるため統制は強まらず、手順だけが増える
- 留保(**未実証**): 2名の体制で、もう1名が決定者の部下・家族などで、事実上は拒めない場合の実効性。外部にも1〜2名の体制での実証は無い(survey-432-2 §3 末尾)。根拠水準マーク(ADR-0026)で開示し、見直し期限を置く

## R-3 ADR-0110 決定2 との関係 — 推す案: 記名者1人の原則を保ち、本人以外の確認を「別の記録の1人の記名」として置く

- 理由
  - 確認を別の記録(後の変化点、または変化点に結び付く確認の記録)にすれば、各記録の記名者は1人のままである。ADR-0110 が「2名の記名」を採らなかった理由(:76。記録5 は決定した自然人を単数で定める)に触れない
  - 兼務の行は任命そのものから生じるため、変化点を分けて事前に別の人へ記名させることはできない(survey-432-1 §3.3)。事後の確認は、分けられない変化点に本人以外の目を入れる唯一の形である
- 落とす案
  - 要件の和(どちらか一方で足りる)は採らない。ADR-0110:78 が指摘する抜け道そのものである
  - 2-B の (ii)(任免の行を任命権者でもよいとする)は採らない。ADR-0110:77 が採らなかった「任命権者に緩める権限を渡す」に当たる
  - 「2名の記名(連名)」を限定して認める案は、確認の記録で同じ効果が得られるため採らない
- 条件: 確認の記録は「決定」ではなく「確認」と区別して記録する。確認者が決定者の権限を得たように読める記録にしない

## R-4 #433 本人の行・迂回・差し替え、記録・ADR

- a-3(本人の行の要件)は、**c-2(迂回を塞ぐ)と組でだけ**本文へ置く。決定者の席に結び付くアカウントか氏名が替わる変更は、経路によらず R-2 の確認を要する。表記の変更か、「決定者その人を替える」任免(ADR-0055 決定3、:1995)かを問わない。申告で統制が変わらないので、「同じ人である」という申告の真偽に統制を依存させずに済む
  - これは ADR-0055 決定3(前任の決定者の記名だけで交代)を改める。正当な交代も確認の対象になるが、交代は権限の移転そのものである。本人以外の確認を求めるのは監査として妥当と考える
  - a-3 だけを置き c-2 を置かない案は採らない(名目の要件。survey-433 §4.3 の2)
- a-1(差し替えの禁止)は本文へ上げる。差し替えは、任免の記録を残さずに人を替える経路である。K67 には理由が書かれていない(survey-433 §3.4)ので、新しい ADR で理由を書く。置き場は 3.13.3 の手続とし、第4章 gate-criteria.md:84 の名簿の変更の記名から引く
- 第5章 :645 の案内は、決定者本人の行を対象から外す(軽の裁定 4、作業中の版に反映済み)。c-2 を採れば、本人の行の訂正の正規の経路を本文の確認つきの形で示す
- 記録・ADR
  - 新しい ADR を1つ(#432・#433 共通)とする。ADR-0055 決定3 を一部置き換える。ADR-0110 決定2 は維持する旨と、R-3 の理由を書く
  - :2004 の「未決の論点」の文は、決定に置き換える。決定まで残した未決の表示を、黙って消さない
  - EV: 2名の体制での事後の確認の実効性(R-2 の留保)、1名の体制の開示だけで足りるとする判断。いずれも E0 相当
  - IMPL: 自己の決定の印(`selfDecided`)、確認の記録、確認待ちの間のゲート判定の停止、緩める行の保留。降ろし先は config-change-log・gate-records など登録済みのものを使う。実装までは `state=undelivered` で表示し続ける
  - 採らない案(上の各 R の「落とす案」)は、ADR の「採らなかった案」へ全件書く
