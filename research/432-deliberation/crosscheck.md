### X-3 追加の行と決定者が当事者になる行を同じ変化点に含むと、1回では誰も記名できない。2名の初回の記入で、裁定 3 の「本人以外の記名」の経路が1回では成り立たない(中)

- 所在: `template/scripts/init/generate-profile.mjs:2675`(`deciderRowProblems` の `addItems` の照合。`soloFirst` か変更前の決定者しか通さず、`selfMode` の `selfOk` を見ない)。ADR-0122 `:75`(影響「2名の体制で、初回の記入から全席を1人に置く構成は、もう1人の記名を要する」)。IMPL-0480 の注記(「初回の記入は決定者の席に記入する人」)
- 事実(実行、E5): 2名の名簿で、初回の記入に全席を A(決定者)へ置く変化点は、次のとおり誰の記名でも通らなかった
  - A の記名: 決定者が当事者になる行として拒否
  - B の記名: 「人の名簿: 追加 山田 太郎」「人の名簿: 追加 佐藤 花子」の行で拒否(「記名できるのは…決定者の席に記入する人(初回の記入)です」)
  - 記名なし: 任免の行で拒否
  - 先に2人を記名なしで名簿へ足し(席はすべて空)、次の変化点で B の記名で記入すると通った(E5b)
  - 初回でなくても、人を足す行と決定者が当事者になる行を同じ変化点に含めば同じ形になる(E8 で、追加の行が B の記名を拒んだ)
- 根拠: R-3 は「1人の記名者がすべての行の要件を満たせるようにする」ために、決定者が当事者になる行を含む変化点では任免の行の記名者を本人以外へ移した。追加の行は移されておらず、本人以外へ移した記名者を追加の行が拒む。裁定 3 は「2名以上の初回の記入は、R-2 のとおり本人以外の記名を要する」とし、その記名で通ることを前提にしている。ADR-0122 の影響の第2箇条もそう読める。実装の記録(読み方 9)とテンプレートの skill は「1回の変化点では通らない」と書いており、本文・ADR と食い違う
- 直し方の案: `addItems` の照合に、任免の行と同じ `if (selfMode) { if (selfOk) continue; … }` を入れる。追加の行は記名を要しない行なので、本人以外の記名者が記名したことで拒む理由は無い。直さない場合は、ADR-0122 の影響の第2箇条と本文に「名簿へ人を足す変化点と分けて出す」を書き、拒否の文にも分け方を出す(ADR-0110 決定2 の案内と同じ形)

### X-4 EV-0243 が開示する残る迂回は1つだが、同じ型の迂回が少なくとももう2つある(中)

- 所在: `roles-responsibilities.md:2071`(EV-0243)、ADR-0122 `:77`(影響の第4箇条)、`template/scripts/init/generate-profile.mjs:2593`(`selfDecisionContext` の `signers`)、同 2652 行の案内文
- 事実(実行)
  - **任命権者の経路(E3)**: 1名の決定者 A が、自分の別のアカウントを組織上の任命権者(`external: true`・`appointer: true`)として、A の記名で名簿へ置けた。次の変化点で、その行の記名で A の行のアカウントの変更が通った。`selfDecided` は残らず、項目7 に自己の決定と出ない。拒否の文自身が「組織上の任命権者を名簿へ置く変化点を先に出します(決定者が体制に残っている間は、決定者の記名で置けます)」と案内している
  - **兼務の決定の経路(E2b)**: 1名の決定者 A が、席を持たない別のアカウントの行を記名なしで足すと、A が当事者の2組の兼務が決定待ちになる。その行の記名で `keepSeparations` を出すと通り、兼務は「当事者以外の記名で決めた」(decided)になった
  - EV-0243 の開示した経路(席を持たない行の記名で本人の行の表記の変更が通る。E2)も再現した。足す行の記名は不要だった(実装の記録は「本人の記名」で足しているが、記名なしでも足せる)
- 根拠: EV-0243 の対象は「決定者の席のアカウントか氏名を変える変更」の封鎖の網羅性で、本文は残る迂回を1つだけ挙げる。任命権者の経路は、1名の体制では開示つきの自己の決定を、開示の無い本人以外の決定へ変える。兼務の経路は、R-1 の対象の1つめ(自分が当事者になる兼務)の封鎖の網羅性であり、EV-0243 の対象にも、ほかの EV にも入っていない。どちらも「同じ人かを機械が判別しない」ことから生じる同じ型で、審議の条件「2手に分けた迂回が残るかを実行で確かめ、残るなら EV で開示する」の範囲に入る
- 直し方の案: EV-0243 の対象を「決定者に関わる変更(兼務・表記・席)の封鎖の網羅性」へ広げ、確かめた経路と残る経路を3つとも書く。観測の源に、任命権者の行の追加と、その記名で通った決定者に関わる変更の件数を加える。あわせて、拒否の文(2652 行)が任命権者を置く経路を案内するなら、任命権者を置いた変化点の記名者(決定者本人)を項目7 に出す案を議長へ戻す(新しい義務になるため、本件の突合では決めない)

### X-5 決定待ちのまま記録したゲート判定は、後で決定すると欠落として出なくなる。この読み方は議長へ戻されていない(中)

- 所在: `template/scripts/init/generate-profile.mjs:1354-1357`(`pendingSeparationProblems` は、今 `pending` の兼務だけを見る)。本文 `roles-responsibilities.md:459`、ADR-0122 `:67`
- 事実(実行、E4): 決定待ちの間に判定記録を置くと、契約検査は記載の欠落で落ちた。その後、B の記名で兼務を続ける決定を出すと、同じ判定記録の欠落は契約検査から消えた。出荷の証跡の集約も同じ関数を使うため、G-7 の時点では、決定待ちのまま判定したことがどこにも出ない
- 根拠: 裁定(論点1「期限を過ぎたとき」)・本文の表・ADR-0122 決定5 は、決定待ちのまま記録したゲート判定を「記載の欠落として扱う。判定記録の検査と、G-7 の集約の両方で扱う」とし、後の決定で欠落が消えるとは書いていない。実装の記録は、読み方 5 で「決定した後は、決定より前の判定記録を欠落として残し続けない(成立済みの判定記録は書き換えられず、解く手段が無くなるため)」と決めたが、「議長へ戻す点」に入れていない。この読み方では、期限を過ぎても G-7 の前に決めれば痕跡が残らず、期限が G-7 まで待つ案(裁定が採らなかった案)と同じ効き目になる
- 直し方の案: 議長へ戻す。案は2つある。(1) 決定の後も、決定待ちの間の判定記録を、保証の開示に「決定待ちのまま記録した判定」として件数と所在を出し続ける(欠落ではなく表示とし、落とさない)。(2) 欠落のまま残し、例外承認(技術負債台帳)で受け入れる経路を置く。どちらにしても、本文の表の「期限を過ぎたとき」の行に、決定の後の扱いを書く

### X-6 移行で起点の記録が無いと、規定より前の判定記録まで欠落に数える(低)

- 所在: `template/scripts/init/generate-profile.mjs:1362`(`if (!sinceKey) return true;`)
- 事実(読解): 旧い構成からの移行で決定待ちになった件は、`intake`・`edition`・`migrate` の記録が無いと起点が null になり、すべての判定記録を数える。本件の規定ができる前の判定も含まれる。日付だけの判定日時は、同じ日の変化点より前の判定も後と数える
- 根拠: 裁定は「移行で決定待ちになった件の期限の起点は、版を切り替えた変化点とする」とした。起点の記録が無い場合の扱いは、裁定にも本文にも無い。IMPL-0482 の注記には書かれている(「記録が無ければ、すべての判定記録を数える」)
- 直し方の案: 起点の記録が無い場合は、移行を検出した最初の変化点(当事者を書いた行を最初に持つ記録)を起点とする。または、本文の表の「旧い記録からの移行」の行に、起点の記録が無い場合の扱いを書く

### X-7 1名の例外の条件のうち「本人の上に任命の権限を持つ者がいない」を、機械も記録も確かめない(低)

- 所在: `roles-responsibilities.md:2047`、ADR-0122 `:42`、`template/scripts/init/generate-profile.mjs:2615`(`!appointerIn` だけを見る)
- 事実: 本文は例外を「本人の上に任命の権限を持つ者がおらず、組織上の任命権者を置いていない」場合とする。テンプレートは、名簿に任命権者の行が無いことだけで例外を認める。より大きな組織の中の1名の体制が任命権者を名簿へ書かなければ、自己の決定として通る
- 根拠: 同じ節の自己の任命の例外(2001 行の次の箇条)は、「根拠は D-0 の『決裁の権限の出所』へ書く」とし、「より大きな組織の中の1名の体制は…当たらない」と明記する。R-1 は自己の任命の禁止を広げたものであり、例外の条件の確かめ方もそろえるのが自然である
- 直し方の案: 自分に関わる変更の1名の例外にも、自己の任命の例外と同じ「根拠は D-0 の『決裁の権限の出所』へ書く」を引く。新しい義務を足すのではなく、2001 行の次の箇条の条件を引く形にする。機械で確かめられない旨は、EV-0241 の本文に書く
