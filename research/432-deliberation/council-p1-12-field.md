# #432 論点1 会議体(重) 委員: 現場

- 立場: 1名から2名・3名へ育つ小さい体制の採用者。人を足す反映が止まらないこと、期限の現実性、旧い構成の移行を重視する
- 入力: `survey-432-1-internal.md`(以下 調査)、`survey-432-2-external.md`(以下 外部)、`decision.md`(以下 裁定)、`council-p1-01`・`02`、本文 `roles-responsibilities.md`(以下 3章)

## 1. 推す案: 1-D + 1-E を採る。期限は 3.13.3 の時点に相乗りさせ、状態で判定する

1. **印(1-E)**: 席の兼務の記録に `origin` を持たせる。値は `arising`(発生)・`pending`(決定待ち)・`decided`(決定済み)の3つ。内側の人が2人以上になった変化点で、`arising` を `pending` へ移す。この変化点は名簿へ人を足すだけで受け付ける。記名は求めない(1-B を採らない)
2. **期限(1-D)**: `pending` の兼務は、**その変化点の後の最初のゲート判定より前に**、解くか、R-1・R-2 の記名者の記名で決める。この時点は、3.13.3(3章 1959 行)が D-0 と構成を改める期限として既に置いている時点と同じである。新しい時点を足すのではなく、既存の移行の段階(1959〜1975 行の表)に「決定待ちの兼務を片づける」を1項足す
3. **過ぎたときの扱い**: 欠落として扱う。判定の時点で `pending` が残っていれば、そのゲートの判定記録の検査が記載の欠落として落とす。比べるのは日時ではなく、判定の時点の状態である(変更の記録の日時とゲート記録の日時の前後を比べる実装は、時計と記録の順序に依存して誤りやすい。MEMORY の回帰スイートの時計依存の教訓)。止まるのはゲートの判定だけで、名簿の更新や開発の作業は止めない
4. **内側が1人へ戻った場合**: 決める前に2人目が離脱したら、`pending` を `arising` へ戻す。選択の余地が消えたためである(3.5 の 445 行「成立しない場合は」と同じ条件)。`decided` は、1-A の鍵(席の組 + 当事者)が変わらない限り `decided` のまま保つ
5. **旧い構成の移行**: 印が無く、内側が2人以上の兼務はすべて `pending` とする(02 の案と同じ厳しい向き)。期限は、本標準の版を切り替える変化点(process-change が扱う)の後の最初のゲート判定より前とする。変更の記録から決定済みかどうかを復元する案は採らない(3. を参照)

## 2. 理由(所在つき)

- 現実性: 2名の体制では、本人以外の記名者(裁定 R-2 のもう1人)が必ずいる。期限までに打てる手は2つある。席を2人目へ移して解くか、2人目が記名するかである。どちらも1回の変化点で済む。期限の時点で、打てる手が無い状態は生じない
- 3章 1959 行は「期限を日数で定めません。値の根拠が無いためです」と書く。日数を足すのはこの判断に反する。ゲートの判定に揃えれば、兼務に頼る判定(とくに出荷判定)の前に必ず決まる
- 人を足す反映を止めると、2人目を名簿へ載せない誘因になる(01・02 の 1-B の却下と同じ)。1-D は記名をゲートの前へ回すので、事実は即日に構成へ入る
- 移行で全件を `pending` にするのは、裁定 R-1 の帰結である。旧い構成で決定済みの出荷判定者 × 事業決裁者の兼務は、既定の構成では決定者が当事者なので(調査 §2.5)、その決定は自己の記名だった。R-1 の下では決め直す必要がある。記録の `reason` の文から決定を読む方法は、表記の変更で誤る(02 の 1-A の注意と同じ)

## 3. 他の案を落とす理由(採らない)

- **期限を日数で置く案**: 3章 1959 行のとおり、値の根拠が無い。採らない
- **組ごとに期限を変える案**(出荷判定者 × 事業決裁者は G-7 まで、AI の組は次のゲートまで): G-7 まで猶予すると、その前のゲートは決まっていない体制の上で判定される。D-0 は 3.13.3 で改めたことになっているのに、兼務だけが未決のまま残り、宣言と実態がずれる(3.13.5)。採らない
- **期限の超過を表示だけにする案**: 1-C と同じで、誰の決定にも掛からずに続く。Issue の問題を解かない。採らない
- **期限の超過で作業全体を止める案**: 名簿の更新や開発の作業まで止めると、1-B と同じ誘因を生む。ゲートの判定記録に限る。採らない
- **移行で変更の記録から `decided` を復元する案**: 2. の最後の項のとおり、自己の記名で決めた兼務を通してしまう。自由記述の解析は表記の変更で誤る。採らない
- **1-B**(人を足す変化点で記名を求める): 01・02 の理由に加える。2人目が加わったその変化点で、上長の兼務の承認を求めることになる。2人目が体制に慣れる前に記名させる形であり、牽制として効く見込みが最も低い。採らない
