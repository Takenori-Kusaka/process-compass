## 3. 使う条件の決め方(新しい記入・欄を足していない)

- 使うかは **構成の既存の値だけ**から決まる: G-6 必須・範囲 all・`review.requiredApprovals` 0・S2・CL0 と記入・品質 standard と記入・承認者 1 名・委任の規則が空。判定は `approvalByPreRead` の 1 か所。generate-profile は同じ関数を build の時点で当て、ルールセット `team-core`・承認数 0 を決める。**未記入は使わない**(両方向を試験)

- **ルールセット**: 新しいものを作らず、まとまり 1 の `team-core`(承認数 0・必須チェック gate-g5 と gate-g5-base・最後の push の後の承認)を S2 にも使う。判定が同一の中身なので足りる。名前に「core」が残るが、本文の側の呼び名は段 E2 で決める(§6 点 2)。`material-attribution` の承認数 0 の検査の例外(gate-g5-base が必須チェックにあるとき)はそのまま当たる
