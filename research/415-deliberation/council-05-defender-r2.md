## 問い1(H-1)判定の時点ごとの「比べる対象」と「残り」

### 結論

判定の時点を、ステージの途中と SG に分けて定義します。どの時点も、比べる対象は SC-M です。

| 判定の時点 | 比べる対象(ゴール) | 残り(期間・予算) |
| --- | --- | --- |
| ステージの途中: 7.7.4 の検知、7.7.6 の棚卸し、7.6 の段階2 以上、7.7.5 要求事項3 の再判定 | 進行中のステージの SC-M のうち、完了していない作業単位 | 直前の SG(S0 の初回は G-1)で確定した次回判定日までの期間と、そのステージに配賦した期間予算・要員予算から消化を引いた残り |
| SG で「継続」(2.4 の移行)を判定するとき | 同じ判定で確定する次ステージの SC-M の全体 | 同じ判定で確定しようとする次ステージの期間・予算(配賦の案) |
| SG で「保留」(2.4 の継続検証)を判定するとき | 現ステージの SC-M のうち、完了していない作業単位 | 保留に付ける再判定の期限までの期間と、延長に配賦する予算 |
| SG で「中止」を判定するとき | 判定しない | — |

- 終わろうとするステージの到達そのものは、必達基準2 で判定しない。ステージの成果は SG の判定基準と「見積りと実績の差」(7.7.9 要求事項4)が受け持つ
- SG の「継続」では、区分は**確定しようとする配賦の案**に対して定まる。乙・丙のときは、同じ判定の中で SC-M を削るか配賦の案を改めて甲にするか、乙・丙のまま 7.7.5 の要件を満たして継続とするかを選ぶ。どちらを選んだかと区分を判定記録に書く
- ステージの途中の記録は、D-0 表1 の担い手が 7.7.2 の期ごとに作り直す(H-2 の直し方と同じ)。7.7.4 の検知と 7.6 の発火は、検知の時点で最新の期の記録を読む

### 理由

- **SG の判定と矛盾しない**。3.7.3 は「継続」の判定に次段階の資源配分・スコープ・次回判定日を同時に確定することを求め(`roles-responsibilities.md:822`)、2.10 は SC-M を SG の「継続」と同時に確定させます(`lifecycle.md:500`)。確定しようとする配賦の案と次ステージの SC-M を比べることは、この確定に検査を一つ足すだけです。確定の手続そのものは変えません
- **SG の「継続」での判定は、突合の言う「ほぼ常に甲」になるとは限らない**。SC-M ≤ 計画容量の 60%(`lifecycle.md:460`)は、計画容量に対する個数の上限です。遅い側の端(観測の窓の最小スループット)で割った期間が、配賦の案の期間に収まることまでは保証しません。仮にほぼ常に甲になるとしても、それは配賦の案が観測と整合していることの確認です。空振りする判定であって、壊れた判定ではありません。乙・丙が出るのは、配賦の案が観測より楽観的なときに限られます。この場合に判定を求めるのは、7.7.9 要求事項11 の「楽観の端を出さない」(EE:600 前後の段落)の趣旨と同じ向きです
- **終わろうとするステージを必達基準2 で見ないのは、問いの意味からの帰結である**。残る期間がほぼ 0 の比較は、到達の可否ではなく到達の事実を問います。到達の事実は SG の判定基準そのものです。二重に判定させると、同じ未達が SG の判定基準の不合格と必達基準2 の不合格として二度数えられ、7.7.5 の回数を余計に消費させます
- **ステージの途中が必達基準2 の本来の場である**。7.7.4 の上程(EE:446)と 7.7.5 要求事項3 の再判定の期限(最長1ステージ)は、ステージの途中で判定が行われることを前提にしています。途中の記録を 7.7.2 の期ごとに作り直すと、7.7.4 の担い手が「裁量なく起票」(EE の 7.7.4 の箇条)できる材料がそろいます。期の頻度は 7.7.4 の「2期連続」「3期連続」と同じ単位なので、新しい周期を作りません
- **保留の残りを延長分に限るのは、3.7.3 の保留の要件と同じ形である**。保留には解除条件と再判定の期限が要ります(`roles-responsibilities.md:819,824`)。延長の期間と予算で到達できない保留は、期限のない保留と同じく「記録上は生存しているが誰も進めない案件」(同 `:824`)になります

## 問い2(H-3)S0 の初回

### 結論

- **S0 の初回は、必達基準2 の判定の対象外とする**。判定記録の「到達の見込み」の節には「S0 の初回: SC-M なし(第2章 2.10.2 要求事項2)」と書き、区分を書かない。**甲と書いてはならない**
- 対象外の判定は、7.7.5 の回数に数えない。7.7.4 の「必達基準に不合格がある」にも当たらない
- 裁定の「実測が無い間は 7.7.9 の見積りの幅で代える」は削る。S0 の初回の予算の保護は、7.6 の予算の行を**消化の実績と配賦の比**で測ることと、7.7.4 の消化進捗比(EE:445)で行う。この区間は、到達の見込みの記録から測ると決めた 7.6 の箇条(EE:221)の例外として書く
- S0 の初回に計画範囲の一部を SC-M の代わりに数える案(突合の直し方の一つ目)は採らない

### 理由

- **SC-M の代用品を作ると、2.10.2 要求事項2 を裏口から崩す**。2.10.2 は、実測の無い段階で確約範囲を置かないと定めています(`lifecycle.md:487`)。7.7.9 要求事項8 も、S0 の初回の範囲の案を SC-M と呼ばせません(EE:598)。「SG-0 の判定基準の材料に当たる作業単位」を必達基準2 のゴールにすれば、名前を変えた確約範囲を実測なしで置くことになります。SG-0 の判定基準を増やしてはならないという規定(`lifecycle.md:80`)とも当たります
- **7.7.9 の幅で代える案は、比べる量が合わない**。突合の指摘どおり、7.7.9 の見積りは G-1 の時点の案件全体の値です(EE:392 の文自身がそう書く)。ステージの残りと比べる単位がありません。残せば、記入者がステージ分を任意に切り出すことになります。「区分は機械的に定まる」(裁定 R-2)が成り立ちません
- **「対象外」と「甲」を書き分けるのは、「書かれていない」と「課さないと決めた」の区別と同じ理由である**。甲と書くと、S0 の初回の案件が到達の見込みを確かめられたかのように読めます
- **裁定の「実測が無ければ不合格としない」の理由は、この整理で消える**。裁定は「S0 の初回の SG が常に不合格になる」ことを理由に挙げましたが、S0 の初回を対象外にすれば、この理由は当たりません。実測が不足する場合の扱いは、S0 の初回とは別に問い4(M-2)で決めます
- **S0 の初回の予算の超過は、実績で十分に測れる**。S0 は探索のステージで、ゴールは事業仮説と技術的実現性の検証です(`lifecycle.md:57`)。SG-0 の判定の中心は必達基準1(観測データ)です。予算の暴走は、配賦に対する消化の実績(7.6)と消化進捗比(7.7.4)が捉えます。見込みの算定ができないことを理由に、予算の保護を外すことにはなりません

## 問い3(H-4)7.7.5 要求事項4 の数え直し

### 結論

- **数え直しの条件を削る**。「SC-M・予算・期日を変える判定が記録されたときに限り数え直す」は採らない。その意味で、要求事項4 の数え方は改訂前に戻す
- ただし改訂で足した次の明確化は残す。回数は案件の中で必達基準の番号ごとに数える。必達基準2 は乙と丙を合わせて数える。見込みの算定のやり直しでは数え直さない
- 数え直しの経路は、**新たな企画承認(G-1)を経て、中止条件を定め直した場合**だけとする。この場合は別の案件として数える
- 丙の継続に要する変更(EE:410)は、回数を数え直す理由にならないと明記する

### 理由

- **数え直しの条件は、要求事項4 を無効にする**。突合の指摘(H-4)は正しく、弁護できません。丙の継続は、SC-M・予算・期日を変える判定を必ず伴います(EE:410)。そのため、丙の継続は判定のたびに回数を 0 に戻し、上限に一度も届きません。乙の継続も、SC-M を1件動かせば同じになります。条件が括弧の外にあるため、必達基準1・3〜5 にも掛かります。7.7.5 が「最も強い歯止め」と書く要求事項4(EE:487)を、最も弱い箇所にしてしまいます
- **突合の改案「変えた後の見込みで甲になったときに数え直す」も採らない**。範囲を十分に削れば、変えた直後の算定は同じ観測から必ず甲になります。数え直しの条件が、範囲を削る判定と同じ意味になります。範囲を削った後に SC-M を足し戻す経路(SG・7.6 の判定)と組み合わせれば、回数を持ち越さずに元の範囲へ戻れます
- **継続の偏りへの処方は、事前に決めた規則を後から緩めないことである**(Simonson & Staw 1992。`survey-415-2-external.md` §1.13)。判定者が自分の判定で回数を戻せる規則は、この処方と逆向きです
- **G-1 を経た定め直しを数え直しの経路にすると、外部の作法と合う**。NASA は 30% 超過の後、議会の承認と新しいベースラインの報告を経て初めて継続できます(外部 §1.5)。本標準で同じ位置にあるのは、事業決裁者が新しい中止条件を承認する G-1 です。7.7.3 の「始めた後に止める条件を定めると…交渉の対象になります」(EE:432 前後)にも沿います。中止条件を交渉で動かすのではなく、企画を承認し直します
- **厳しすぎるという反論に答える**。上限に達した後も、保留と中止は選べます。範囲の縮小を伴う継続も、要求事項4 の「継続」に当たるので選べません。それが要求事項4 の設計です。3回の継続で到達の見込みが立たない案件に、さらに継続を認める理由を示した実績はありません。実績が出れば EV-0200 の差し替え条件(7.7.5 の上限に達した件数)で見直します

## 問い4(M-1〜M-3)

### M-1 比べる組ごとの区分の組み合わせ

**結論**: 組ごとに区分を出し、**最も悪い区分を案件の区分とする**(甲 < 乙 < 丙)。判定記録には組ごとの区分も書く。組は、期間の見込みと残る期間、費用の見込みと、配賦した予算の区分(期間予算・要員予算)ごとの残りとする。区分をまたいで予算を合算しない。

**理由**: 改訂前の不合格の文言は「残る予算**または**期間を上回る」でした。どれか一つでも届かなければ不合格という論理は、最も悪い区分を取ることと同じです。改訂前の論理を保つだけです。合算しないのは、期間予算(要員の稼働期間)と要員予算(人数と役割の構成)が別の区分として配賦されるためです(EE:335-336)。区分の間で融通するには配賦の判定が要ります。合算すると、判定を経ていない融通を前提に甲を出すことになります。組ごとの区分を書かせるのは、記入者が組を選べないようにするためです。

### M-2 スループットの最小値が 0 のとき、最小標本数に満たないとき

**結論**:

- 完了 0 の単位期間を窓から除いてはならない。最小値が 0 なら、遅い側の端は「到達の期日が定まらない」とし、残りを超えるものとして扱う。最大値も 0 なら丙、そうでなければ乙
- 窓の中の完了の件数が、第4章「閾値の設定と較正」要求事項3 の最小標本数に満たない場合は「実測不足」と書く。S0 の初回(問い2)と違い、SC-M が置かれているので対象外にはしない。区分は乙とする(不合格。丙にはしない)
- どちらも、直し方は規則の側ではなく組織の値の側に置く。単位期間の長さ(2.10.2 要求事項4 で記録する)、観測の窓、最小標本数は、G-1 で組織が記録して置き換えられる(第4章 要求事項1・2)
- EV-0201 の差し替え条件に、0 の単位期間を含む窓の件数と「実測不足」の件数を足す

**理由**: 0 の単位期間を除くのは、都合の悪い観測を捨てて遅い側の端を速く見せる操作です。裁定が置き換えの下限として定めた「遅い側の端を中央値より速くしてはならない」(EE:397)と同じ理由で禁じます。完了 0 の期間がある窓は、ステージの残りの期間に完了が止まる可能性を観測から否定できない状態です。「到達できる」と判定する根拠がありません。

最小標本数に満たない値を判断に用いてはならない、と第4章は定めています。この禁止を必達基準2 だけ外す理由はありません。一方で、実測不足を「対象外」にすると、確約範囲を置いた案件が到達の見込みを示さないまま合格を続けられます。S0 の初回と違い、この案件は既に確約しています。乙として 7.7.5 の記名・期限・回数の歯止めに載せるのが、信頼できる扱いです。

1〜2 名の体制で常に 0 や実測不足になる、という反論が考えられます。その場合は、単位期間を長くするか、最小標本数を組織の値として置き換えます。どちらも既存の手続で、記録が残ります。規則の側を緩めると、体制の大小に関わらず全員に穴が開きます。

### M-3 2.10.6 との整合

**結論**:

- 2.10.6 の「期日に間に合わない見込み」に、**到達の見込みの記録で期間の区分が乙または丙になったとき**を十分条件として足す。2.10.4 の2指標による価値責任者の評価は残す(置き換えない)
- 2.10.6 の選択の順序(SC-B → SC-P を削る → 期日 → 基準。`lifecycle.md` 2.10.6 の図)は変えない
- 7.7.3 の「2.10.6 の見込みと同じ材料による」は「2.10.6 が集計する材料(残る作業単位の個数、実測スループット、残る期間)と同じ材料による」に改める。評価の指標まで同じとは書かない

**理由**: 2.10.6 は、価値責任者が自分の権限(SC-B・SC-P を削る)で早く手を打つための入口です(`lifecycle.md:550`)。入口の条件は、7.6 や必達基準2 より早く開くほうが正しい向きです。区分の乙・丙を十分条件として足せば、7.6 の発火(遅い側の端で測る)より 2.10.6 の入口が遅れることはなくなります。突合が指摘した食い違い(M-3)の、危ない向きが閉じます。2.10.4 の指標を残しても、早く開く向きの食い違いしか残りません。

2.10.4 の指標を到達の見込みで置き換える案は採りません。2.10.4 の滞留期間は個々の作業単位の停滞を捉える指標です。到達の見込みには代わりません。材料の文言を改めるのは、2.10.4 の進捗率が受入基準の数で数え、到達の見込みが作業単位の個数で数えるためです(ADR-0098)。「同じ材料」と書くと、読み手は数える単位まで同じだと読みます。

## 問いごとの結論(1行)

1. H-1: 途中の判定は進行中のステージの SC-M の未完了分と配賦の残りで判定し、記録は 7.7.2 の期ごとに作り直します。SG の継続は次ステージの SC-M と配賦の案、保留は延長分で判定し、中止と終わるステージの到達は判定しません。SG の判定、7.7.5、2.10.6 は壊しません
2. H-3: S0 の初回は対象外とし、「SC-M なし」と記録して甲とは書きません。7.7.5 の回数に数えず、7.7.9 の幅で代える定めは削ります。予算の保護は 7.6(実績)と 7.7.4 の消化進捗比で行います
3. H-4: 数え直しの条件を削り、改訂前に戻します。番号ごと・乙丙の合算・算定のやり直しで数え直さないの3点は残します。数え直しは新たな G-1 で中止条件を定め直した場合だけとします
4. M-1〜M-3: 組ごとの区分の最も悪いものを案件の区分とし、予算の区分は合算しません。0 の期間は除かず、最小値 0 は乙、最大値も 0 なら丙、実測不足は乙とし、直すのは組織の値の側です。2.10.6 には乙・丙を十分条件として足し、材料の文言は集計の材料に限って揃えます
