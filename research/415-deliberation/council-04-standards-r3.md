# #415 第3巡 委員「規格(standards)」の意見

- 作成: 2026-11-04
- 入力: `council-00-agenda-r3.md`(N 案)、`crosscheck-2.md`(H2-1〜H2-4、M2-1〜M2-9)
- 立場は第1巡・第2巡と同じ。判断軸は信頼性で、検証できる書き方かを問う
- 第2巡の自己批判: 本委員は第2巡で、SG の判定を「配賦の案の検査」として残すよう推した(`council-04-standards-r2.md` 問い1)。最小値 0 の扱い・甲の要求・置き換えの時点との組み合わせを検討しないまま推した。H2-2・H2-3 は、その組み合わせから出た矛盾である

## Q1 N 案に賛成か

### 結論

**賛成します。ただし、次の 5 つを条件とします**。条件を欠くと、N 案は矛盾の代わりに穴を残します。

1. **7.7.3 に判定の時点を書く**。必達基準の表の前に、次の 2 文を置く(#226 の作法で、限定を行の中へ書く)
   - 必達基準1・3・4・5: SG と、ステージの途中の判定(7.7.4 の上程・7.7.6 の棚卸し・7.7.5 の再判定)で判定する
   - 必達基準2 の行: 「(適用: ステージの途中の判定。SG では判定しない。S0 の初回は SC-M を置かないため適用外)」
   - 現行の本文は、必達基準を「いつ」判定するかを一度も書いていない。必達基準2 だけを限ると、他の基準の時点がかえって曖昧になる
2. **SG と 7.7.5 の再判定の期限が重なる場合を書く**。7.7.5 要求事項3 の再判定の期限は最長 1 ステージなので、期限が SG に落ちることがある。SG で必達基準2 を判定しないと、不合格のまま継続した記録の行き場が無い。次のとおり定める
   - 終わるステージの SC-M の完了が SG の判定基準で確かめられたときは、当該の不合格は解消したものとする(到達は観測された事実で、見込みより強い)
   - 完了していないときは、SG の判定(継続検証 = 保留、または中止)で受ける。7.7.5 の回数は引き継ぎ、ステージの移行で数え直さない
3. **期ごとの算定は残す**(7.7.2 の期ごと、D-0 表1 の担い手)。判定は途中の判定の時点に限っても、7.7.4 の第2行は検知の時点に区分を要する。算定の記録が無いと、上程の条件が判定できない。記録の置き場は N 案 6 のとおり B-2 の判定記録の節とする。期ごとの算定はその節の版として残す
4. **SG で計画が予算に見合うかの検査が消えることを、ADR に書く**。N 案 2 の「2.10.1・2.10.2 が受け持つ」は、件数(SC-M と計画容量)についてだけ正しい。予算の配賦が期間に見合うか(目標からの逆算で削った予算)を観測と突き合わせる場は、SG から消える。この不一致は、ステージの途中の最初の算定で乙・丙として現れる。ただし 7.7.4 の第2行は「残20%未満」まで発火しない。そのため、**最初の期の算定で費用の組が乙・丙になった場合は、2.10.6 の見込みと同じく 7.6 の起票の十分条件とする**。こう書かないと、配賦の不足がステージの終わり近くまで判定に上がらない
5. **必達基準2 の判定者を一つに書く**(M2-5)。ステージの途中の判定は B-2(置かない体制では事業決裁者)。7.7.6 の棚卸しの判定者が別に定まっている場合は、棚卸しは合否の記録までとし、継続・中止の判定は B-2 へ渡すと書く

### 理由

- **検証できる書き方になる**: N 案では、必達基準2 の比べる対象が一つになります。進行中のステージの未完了の SC-M を、直近の SG で確定した期日までの期間と配賦の残りと比べます。第2巡の表は時点ごとに 4 行の定義を持ち、行ごとに例外(甲の要求、置き換えの時点、0 の扱い)が重なりました。定義が一つなら、同じ記録から同じ区分が出ます
- **確定の場で計画を検査すると、判定者が選んだ値を判定者が検査する形になる**。H2-3 は、その構造上の帰結です。SG の計画は判定者が確定する値です。確定する値で算定する検査は、Simonson & Staw 1992 の「フィードバックの前に決めた規則」になりえません〔一次〕。外部の作法でも、確定の時点の信頼水準(NASA の JCL)と、途中の引き金(超過率)は別の物差しです〔一次〕。確定の時点の検査を必達基準2 から外し、計画の作法(2.10.1・2.10.2)へ任せるのは、この分離に合います
- **7.6 を ADR-0095 に戻すのは、段階1 の設計を守るため**。SC-M だけで数える値は、SC-B・SC-P を削っても動きません。この値で 7.6 を測ると、段階1 の吸収が構造上働きません(H2-4)。これは ADR-0095 が却下した帰結と同じであり、補う関係の ADR が採用済みの決定を事実上覆すことになります
- 条件4 の十分条件は、7.6 の段階の判定者を変えません。起票の契機を一つ足すだけなので、段階1 の吸収とも当たりません

### 採らない案

| 案 | 採らない理由 |
| --- | --- |
| 第2巡の範囲を保ち、H2-2 を (a) 単位期間を束ねた最小値、H2-3 を「置き換えは次の判定から」で閉じる | 個々の矛盾は閉じても、確定する値で算定する構造(判定者が選んだ値の検査)が残る。時点ごとの例外が増え、検証の手順が行ごとに分かれる |
| 7.6 の予算・日程を全層(SC-M+SC-P+SC-B)の見込みで測る(突合 H2-4 の (b)) | 必達基準2 と 7.6 で同じ記録の別の行を使うことになり、「同じ値を使う」の利点が名目だけになる。2.10.6 の見込みで足り、新しい物差しを足す理由が無い |
| N 案 2 だけを採り、条件4 を置かない | 逆算で削った予算が、ステージの終わり近くまで判定に上がらない |

## Q2 M2-6 期日・予算の延長で甲に戻す継続

### 結論

1. **数える**。不合格を受けて期日または予算を延ばし、その判定の中で区分を甲に戻した継続も、7.7.5 要求事項4 の 1 回に数える。数え直すのは、第2巡の本委員の案どおり、変更の後に少なくとも 1 期の観測を経て同じ基準が合格したときに限る
2. **延長の累計を、ステージの途中では SG で確定した当初の値で測る**。7.6 の予算の閾値を、直近の SG で確定した配賦に対して測る。ステージの途中で配賦を増やしても、基準は動かさない。日程も同じく、SG で確定した期日に対して測る
3. **数え方を根拠水準のマークの対象に入れる**。EV-0200 の対象に「7.7.5 要求事項4 の数え方(案件の通算、延長による甲への復帰も数える、観測を経た合格でだけ数え直す)」を加える。E0 とし、差し替え条件に「延長して継続した件数と、その後に到達しなかった件数」「観測を経た合格で数え直した件数と、その後に再び不合格になった件数」を加える

### 理由

- 要求事項4 が止めようとしているのは、同じ不合格を理由に継続を重ねることです。延長して甲に戻すのは、不合格を受けて資源を追加する判定であり、継続の偏りが最も典型的に現れる形です(Keil ら〔二次〕)。これを数えないと、上限は SC-M を削らない継続にしか掛かりません
- 51 U.S.C. §30104 は、ベースラインを引き直すことを引き金の解除として扱いません。30% 超の事業の継続には、上位の承認を求めます〔一次〕。基準を当初の確定値に固定する条件2 は、同じ作法です
- 延長の判定の中で算定した甲は、判定者が選んだ値の算定です。Q1 で SG の確定の検査を外した理由と同じ理由で、数え直しには使えません

### 採らない案

| 案 | 採らない理由 |
| --- | --- |
| 甲へ戻した継続は数えない(現行の裁定) | 期日・予算を延ばし続ける経路に上限が無い |
| 延長を禁じる | 延長は 2.10.6 の手順2・7.6 の段階2・3 の正当な選択肢である。禁じるのではなく、回数で縛る |
| 7.6 の閾値を、延長後の配賦で測る | 配賦を増やすたびに基準が動き、累計の超過がどの段階にも現れない |

## Q3 採らない第2巡の定めの ADR への書き方

### 結論

ADR-0099 は、まだコミットしていません(2026-11-04 の作業ツリーで未追跡の差分)。公開前なので、本文を第3巡の決定へ書き改めてよいと考えます。ただし、第2巡で採った定めを消すだけにしてはなりません。「検討した選択肢」に次の形で残します。

| 選択肢 | 出した者・巡 | 判断 | 理由 |
| --- | --- | --- | --- |
| SG で必達基準2 を判定する(時点ごとの表。SG の継続では次ステージの SC-M と確定する値で算定) | 規格(第2巡)、裁定(第2巡) | 採らない | 確定する値で算定すると、判定者が選んだ値を判定者が検査する。置き換えの時点(H2-3)・最小値 0(H2-2)・甲の要求と組み合わさり、継続を出せないか、区分を選び直せるかのどちらかになる。計画の大きさは 2.10.1・2.10.2 が件数で受け持つ。予算の見合いは、途中の最初の期の算定で受ける(決定に書く) |
| SG で甲でない計画を確定しない | 起案(第2巡) | 採らない | 2.10.1 の SC-M の上限 60% を、事実上より強い値で置き換える(M2-12)。最小値 0 の窓では、SC-M を 0 件にしても甲にならない |
| 7.6 の予算・日程を到達の見込みの遅い側の端で測る | 規格(第1巡)、裁定(第1・2巡) | 採らない | SC-M だけで数える値は段階1 の吸収で動かず、ADR-0095 が却下した帰結(段階1 の全件が事業決裁者へ流れる)になる。7.6 は ADR-0095 のまま 2.10.6 の見込みで発火する。期間の区分が乙・丙になることを、2.10.6 の見込みが立った十分条件として残す |
| 7.6 を全層の見込みで測る | 突合(第2版 H2-4 (b)) | 採らない | Q1 の採らない案のとおり |
| 甲へ戻した継続を 7.7.5 に数えない | 裁定(第2巡) | 採らない(Q2 の結論を採る場合) | 期日・予算の延長に上限が無い |

- 各行に、**どの巡で採り、どの突合の所見で覆したか**を書きます。後の読者が同じ案を再提案したとき、組み合わせの矛盾まで辿れるようにするためです
- 「影響」の節に、**SG から消える検査**(予算の配賦が期間に見合うか)と、その代わりに受ける場所(途中の最初の期の算定、Q1 条件4)を書きます。却下は成果ですが、却下によって外れた統制を書かないと、「課さないと決めた」と「受け持つ場所がある」の区別がつきません
- ADR-0095 との関係の欄は、「補う」を保ちます(N 案で 7.6 を変えないため)。第2巡の版で「補う」と書きながら段階1 を消していたことは、却下の行の理由に書きます
- ADR-0099 を既にコミット・公開していた場合は、採用済みの本文を書き換えず、新しい ADR で置き換える(CLAUDE.md の規約)。本件は公開前なので、書き改めで足ります

### 採らない案

- 第2巡の定めを ADR から消し、第3巡の決定だけを書く: 一度採った案の矛盾の記録が失われ、同じ組み合わせが再提案される
- 第3巡の決定を新しい ADR(ADR-0100)にし、ADR-0099 を第2巡の版で残す: 公開前の ADR を、矛盾を含んだまま採用済みとして公開することになる
