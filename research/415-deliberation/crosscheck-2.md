### H2-1(高)SG-0 が「S0 の初回」に入るかが割れており、準拠テンプレートは SG-0 を「算定できない」と読ませている

- 所在: `EE:397`(ステージ移行ゲートの継続・移行は、同じ判定で確定する次ステージの SC-M と比べる)、`EE:409`(S0 の初回は「算定できない」)、`DT:794` と `T/templates/04-gate-record.md:211`(実測スループットの端の欄「S0 の初回は「算定できない」」)、`T/.claude/skills/gate/gates/SG.md:22`(「S0 の初回と…は「算定できない」と書く」)、`T/scripts/gate/test-brief-estimates.mjs:48`(判定の時点「継続・移行」・比べる対象「SC-M なし」・区分「算定できない」を記入として受け付ける)、`LC:489`(2.10.2 要求事項4: SG では実測値を根拠に規模を合意する)
- 問題:
  - 判定記録の様式と SG の補助ファイルは、ステージ移行ゲートの判定記録に書くものです。「S0 の初回」の間に作るステージ移行ゲートの判定記録は SG-0 だけです。そのため、様式と補助ファイルは「SG-0 は算定できない」と読ませます。試験もこの読みを固定しています。
  - 一方、`EE:397` によれば、SG-0 の継続(S1 への移行)で比べる対象は S1 の SC-M です。S1 の SC-M は、2.10.2 要求事項4 のとおり S0 の実測スループットから合意します。対象もスループットもあるので、算定できます。
  - 第2巡の意見も割れています。起案(`council-01-drafter-r2.md:81`)は、SG-0 で S1 の計画を確定するときは表が効く、と読みます。品質監査(`council-03-qa-audit-r2.md:54-55`)は、SG-0 を判定不能とし、S1 の最初の期の終わりを最初の判定の期限とします。裁定(decision 第2巡 H-3)はどちらとも書いていません。
  - SG-0 を算定できないと読むと、最初の SC-M を確定する判定が「甲でない計画を確定しない」(`EE:421`)を免れます。案件で最も不確かな確約に、必達基準2 が掛からなくなります。S1 の途中の判定まで区分が出ません。

### H2-2(高)最小値 0 と「甲でない計画を確定しない」が重なると、ステージ移行ゲートで継続を出せない

- 所在: `EE:405`(完了が 0 の単位期間を除かない。最小値が 0 なら遅い側の端は残りを超える)、`EE:421`(継続・移行では甲でない計画を確定しない。甲になるまで案を改める)、`RR:813-819`(3.7.3。判定は 4 値のいずれかで出す。持ち越しを認めない)
- 問題:
  - 窓の中に完了 0 の単位期間が 1 つでもあると、遅い側の端は、比べる対象の個数によらず「残りを超える」と定まります。SC-M を減らしても、0 件にしても甲になりません(0 件 ÷ 0 も「超える」と書かれている)。
  - その結果、ステージ移行ゲートで継続(移行)を確定する案が、1 つも作れません。選べるのは保留か中止だけになります。1〜2 名の体制では、休暇や障害で完了 0 の週は珍しくありません。EV-0201 の補足(`EE:445`)が守ろうとした小さな体制ほど、ゲートで止まります。
  - 抜け道は、同じゲートで端の取り方か単位期間の長さを置き換えることです(H2-3)。抜け道を使わせる構造になっています。
  - 第2巡の多数(decision 第2巡 M-2)は「最小値 0 なら遅い側の端は残りを超える」を採りましたが、「甲でない計画を確定しない」(起案)と組み合わせた結果を検討した記録はありません(`council-0*-r2.md` を確かめた範囲)。
- 直し方: 次のどちらかを会議体で決めます。(a) ステージ移行ゲートの継続・移行では、最小値 0 の扱いを「残りを超える」でなく、0 を含めた窓で別の端(たとえば 0 を除かずに単位期間を 2 つずつ束ねた最小値)とする。(b) 最小値 0 の場合は、区分を乙とし、ゲートでは「甲でない計画を確定しない」の例外として、判定者の記名で確定し、7.7.5 の回数に数える。どちらを採っても、EV-0201 の差し替え条件に「最小値 0 のために継続を確定できなかったゲートの件数」を足します。

- 所在: `EE:405`(置き換えは G-1 またはステージ移行ゲートで、事業決裁者の記名で中止条件の欄へ記録)、`DT:1033`、`T/templates/06-project-brief.md:142` と 3 つのプロファイル、decision R-2(Simonson & Staw 1992 の、フィードバックの前に判定の値を決めておく処方)、ADR99:62・85
