## Q1 N 案に賛成か

### 結論

**条件付きで賛成します**。SG と 7.6 から到達の見込みを外す点に賛成します。ただし N 案のままでは、ステージの前半に必達基準2 が働く時点がありません。そこで次の4つを条件とします。

1. **期ごとの記録の置き場を、2.10.6 の「見込みの報告の Issue」に置く**。担い手が 7.7.2 の期ごとに到達の見込み(期間の組)を作り直し、その Issue に書きます。区分が乙・丙になった時点で `state:needs-po` を付け、2.10.6 の手続を始めさせます(N 案3 の十分条件)。判定記録(テンプレ4 の節)は、B-2 が判定する時点(7.7.4・7.7.6・7.7.5 の再判定)だけに書きます
2. **S0 の初回の 7.7.4**: 「期間予算の残20%未満、かつ必達基準に不合格」の行で、S0 の初回は「算定できない」を不合格と同じく上程の条件に読みます。上程の先は SG-0 の判定です。上程の条件にするだけで、7.7.5 の回数には数えません
3. **新しいステージの最初の判定の時点を決める**。SG で判定しない代わりに、移行した後の最初の期の終わりに、担い手が最初の記録を作ります(品質監査の第2巡の案と同旨)。区分が乙・丙なら、1 の経路で価値責任者へ渡します
4. **最小値 0 の扱いは第2巡のまま(遅い側の端は残りを超え、乙)とする**。SG のゲートを外せば、行き詰まり(H2-2)は消えます。単位期間の長さは 2.10.2 の記録に一本化します(N 案7)。1〜2 名の体制では単位期間を長く取ることで 0 を避ける、と解説に書きます

### 理由

- **N 案のままでは前半が空く**: N 案1 で挙がる途中の判定のうち、7.7.4 が発火するのは期間予算の残りが20%を切ってからです〔確: `exception-escalation.md` 7.7.4 の表〕。7.7.6 の棚卸しは定期の点検で、7.7.5 の再判定は一度不合格が出た後にしか来ません。そのため、ステージの最初の 8 割で乙を拾う経路は 2.10.6 だけになります。その 2.10.6 の入力となる期ごとの記録の置き場が、N 案には書かれていません(M2-1 の残り)
- **見込みの報告の Issue にする理由**: この Issue は 2.10.6 と ADR-0094 が既に定めた経路です。担い手が起票し、`state:needs-po` で価値責任者へ渡します〔確: `lifecycle.md` 2.10.6〕。判定ではない記録を判定記録に書かせるより、1〜2 名の体制でも負担は小さく済みます。それでも、期ごとの区分は記録として残ります
- **S0 の初回の上程**: N 案4 は「消化進捗比が歯止め」としています。しかし消化進捗比が測るのは消化と進捗の比です。予算が尽きかけていても、進捗と釣り合っていれば発火しません。「算定できない」を上程の条件に読まなければ、残20%の行は S0 の初回に一度も働きません。第2巡の本委員の「打ち切りの枠」を、既存の行の読み方で実現します
- **SG のゲートを外してよい理由**: 次の計画の大きさは、2.10.1 と 2.10.2 が実測から合意させています〔確〕。SG で遅い期への耐性を確かめないことで失うものはあります。しかしそれは、新ステージの最初の期の終わりの記録(条件3)で、1 期遅れで拾えます。ゲートに残すと、最小値 0、SG-0 の読みの割れ、置き換えによる選び直しの3つの矛盾が同時に残ります(H2-1〜H2-3)

### 譲れない点

- 期ごとの記録とその置き場を必ず定める。判定の時点だけの記録にしない
- S0 の初回に、予算・期間が尽きても上程されない区間を残さない
- 完了 0 の期を窓から除かない

### 採らない案

| 案 | 採らない理由 |
| --- | --- |
| N 案をそのまま採る | ステージの前半に必達基準2 が働かない。S0 の初回は残20%の行も働かない |
| 第2巡の範囲を保ち、最小値 0 を束ねた期で救う(突合 H2-2 の (a)) | 端の取り方が二通りになり、どちらを使ったかを記録で確かめる手間が増える。SG-0 の読みの割れ(H2-1)と H2-4 は残る |
| 第2巡の範囲を保ち、最小値 0 のときだけ SG で乙の確定を認める(突合 H2-2 の (b)) | 「甲でない計画を確定しない」の例外が定型になる〔経〕 |
| 期ごとの記録を判定記録(テンプレ4)に書かせる | 判定の無い記録に判定記録の様式を使うことになる。集約の偽の欠落(M2-9 と同型)を生む |

## Q2 M2-6 期日・予算の延長で甲に戻す継続を、7.7.5 に数えるか

### 結論

- **期日または予算を延ばして甲に戻す継続は、7.7.5 の要求事項4 の回数に数えます**
- **SC-M を減らして甲に戻す継続は、数えません**。削りすぎは 7.6 の SC-M の変動率で拾います
- 同じ判定で両方を変えた場合は、数えます
- 数え方を EV で開示します。差し替え条件の案は、延長で甲に戻した継続の件数、その後に到達しなかった件数、3回の上限に達した案件の件数です

### 理由

- **延長は継続の偏りそのもの**: 資源を足して続けることは、意思決定の研究が拡大(escalation)と呼ぶ形です(外部調査 §1.13)。7.6 の予算の閾値は配賦に対する超過で測るため、配賦を増やすたびに基準が動きます〔確: `exception-escalation.md` 7.6「配賦した予算に対する超過」〕。延長の累計を拾う仕組みは、ほかにありません
- **SC-M の削減を数えない理由**: 削ればゴールが小さくなります。これは中止の手前の正当な選択で、2.10.6 の順序の先頭(範囲を削る)と同じ向きです。7.6 の SC-M の変動率が累計を測っています〔確〕
- **1〜2 名の体制でも行き詰まらない**: 延長を3回使い切っても、SC-M を減らす経路は回数に掛からずに残ります。上限が強いるのは「延ばし続けること」の停止だけで、案件を止めることではありません〔推〕
- 受託では、期日の延長は顧客との契約変更になり、外の歯止めが掛かります〔確: 7.6 の兼務の箇条「確約範囲の変更が契約変更の起点」〕。それでも数えます。契約変更の合意は、到達するかどうかを確かめるものではないからです

### 譲れない点

- 予算・期日の延長で甲に戻した継続を、上限の外に置かない

### 採らない案

| 案 | 採らない理由 |
| --- | --- |
| 甲へ戻す継続はすべて数えない(現行) | 延長を無限に繰り返せる(M2-6) |
| 甲へ戻す継続をすべて数える | SC-M を削る正当な選択まで上限を消費し、削るより止める・延ばす方へ誘う |
| 7.6 の予算を当初の配賦で測って累計を拾う | 7.6 の閾値の意味を変え、ADR-0095・EV-0195 の前提をさらに動かす。N 案3 で 7.6 を切り離した趣旨と逆向き |

## Q3 N 案で採らない第2巡の定めを、ADR にどう書くか

### 結論

ADR-0099 の「検討した選択肢」の表に、次の3行を**採らない**として書きます。各行には、第2巡で一度採ってから外した経緯と、外した結果に失うものも書きます。ADR-0099 は未採用(未追跡)なので、新しい ADR は起こさず、ADR-0099 の本文で扱います。

| 案 | 判断 | 理由 | 失うもの(開示) |
| --- | --- | --- | --- |
| SG で必達基準2 を判定し、判定の時点ごとの表(SG の継続・移行、保留の行)で比べる | 採らない | SG-0 の読みが割れる(H2-1)。保留の延長に上限が掛からない(M2-2)。SG-1 の「継続」の語と当たる(M2-3)。中止と定常運用への移行の記録で偽の欠落が出る(M2-9)。次の計画の大きさは 2.10.1・2.10.2 が受け持つ | SG では、次の計画が遅い期に耐えるかを確かめない。新ステージの最初の期の終わりの記録で拾う |
| SG で、区分が甲でない計画を確定しない | 採らない | 最小値 0 と重なると継続を出せない(H2-2)。同じゲートの置き換えが選び直しの経路になる(H2-3) | 同上 |
| 7.6 の予算・日程の見込みを、到達の見込みの遅い側の端で測る | 採らない | SC-M だけの見込みでは、段階1 の吸収が値に表れない。ADR-0095 が採らなかった「段階1 を事業決裁者の判定にする」と同じ帰結になる(H2-4) | 7.6 と必達基準2 が別の値を使いうる(裁定 §0 の欠陥)。2.10.6 の十分条件(期間の区分が乙・丙)で両者をつなぐ |

- 「失うもの」の列には、根拠水準のマークを付けます。差し替え条件は、新ステージの最初の期の終わりで乙・丙となった件数と、7.6 が発火せずに必達基準2 が不合格となった件数です。これらが多ければ、SG と 7.6 への結び付けを見直します
- 第2巡の裁定(`decision.md`)は研究の記録として残し、書き換えません。ADR に「第2巡で採り、第3巡で外した」と書いて辿れるようにします

### 理由

- 却下は成果です(コアポリシー)。とくに第2巡で一度採った定めは、外したことを書かなければ、読み手には「書き漏れ」と区別できません
- 失うものを書くのは、範囲を狭めたことで確かめなくなる事項を、「課さないと決めた」として読み手に示すためです

### 譲れない点

- 3行とも「失うもの」を書き、根拠水準のマークと差し替え条件で見直しの道を残す

### 採らない案

| 案 | 採らない理由 |
| --- | --- |
| 本文から消すだけで ADR に書かない | 書かれていないことと、課さないと決めたことの区別がつかない |
| 外した定めごとに別の ADR を起こす | ADR-0099 は未採用で、同じ決定の範囲の調整にすぎない |
