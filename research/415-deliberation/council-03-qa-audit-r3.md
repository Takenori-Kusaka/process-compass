# #415 第3巡 委員「品質監査(qa-audit)」の意見

- 作成: 2026-11-04 / 入力: `council-00-agenda-r3.md`(N 案)、`crosscheck-2.md`、`lifecycle.md` 2.10.1・2.10.2(`LC:455-496`)
- 立場は前巡と同じ。判定が記録で再演できるか、値を後から選べないか、入力の出所はどこかを問う

## Q1 N 案に賛成か

### 結論

**条件付きで賛成する。** H2-1〜H2-4 は、SG の計画の確定と 7.6 にまで判定を広げたことから出ている。範囲を狭めれば構造ごと消える。第2巡で当委員が出した SG の表(r2 問い(1))は取り下げる。

ただし、**SG で必達基準2 を判定しないことは、そのままでは「洗浄の場」になる**。ステージの途中で乙・丙が出ても、SG まで待てば新しい計画の下で何も問われずに次ステージへ進める。2.10.1・2.10.2 は次ステージの**大きさ**を縛るが、**持ち越される不合格**と**計画容量の出所**は縛らない。次の4つを N 案に足すことを賛成の条件とする。

1. **SG は、未解消の必達基準2 の不合格を消さない**。ステージの途中で乙・丙と判定され、7.7.5 の再判定の期限が来ていない不合格があれば、SG の判定記録にその旨と継続の回数を書く。再判定の期限は次ステージの最初の途中の判定へ引き継ぐ。7.7.5 の回数は SG で戻さない(第2巡の裁定を保つ)
2. **SG の後の最初の途中の判定を、次ステージの最初の 7.7.2 の期の終わりに置く**。新しい計画が到達の見込みに触れずに走る期間を1期に限る
3. **計画容量の算定に使う実測値の取り方(窓、統計の種類)を事前に固定する**。2.10.2 要求事項4 は「根拠とした実測値」を記録させるが、どの値を取るか(平均・最大・直近の良い期)を選ぶ時点を定めていない〔確認範囲: `LC:486-490`〕。取り方は G-1(または前の SG)で記録し、その取り方を適用する SG の場で置き換えない(H2-3 と同じ原理)
4. **終わるステージの未完了の SC-M は、次ステージの SC-M へ移すか、記録した判定で外す**(r2 問い(1)結論1 を保つ)。記録なしに消すと、到達しなかった事実が次の判定の入力から消える。SG の判定基準(2.4)が終わるステージの完了を問う、という N 案2 の前提は、この追跡が様式にあるかを起案で確かめる

その他の項目への意見は次のとおり。

- N 案3(7.6 を結び付けない): 賛成。残る食い違いとして、必達基準2 が乙でも 7.6 が発火しない期間がありうる。これは 7.7.4(残20%未満かつ乙・丙)と、2.10.6 の十分条件(乙・丙で見込みが立つ)が拾う。食い違いの存在は ADR に書く
- N 案4(S0 の初回は算定できない): 賛成(r2 問い(2)と同じ)。「算定できない」を合格として扱わない、と本文に書く
- N 案6(置き場): 賛成。B-2 を置かない体制では事業決裁者の判定記録に置く、と明記する
- N 案7(単位期間): 賛成。条件3 の取り方の固定と同じ記録(2.10.2 要求事項4)へ一本化する

### 理由

- 継続の偏りが最も強く働くのは、資源を足す決定の場である(Simonson & Staw 1992。外部 1.13)。SG は次ステージの資源を確定する場なので、そこで不合格が消えると、偏りの処方(事前の固定、動かさない目標)が SG の手前で途切れる。条件1・4 は不合格と未完了を SG の向こうへ運ぶ
- 2.10.1 の 60% の上限は、計画容量が正しく出ていれば緩衝として働く。しかし計画容量の出所の値を SG の場で選べるなら、60% は選んだ値の 60% にすぎない。条件3 は、第1巡の端の取り方の固定と同じ型を計画容量に当てる
- 第2巡の SG の判定は、「甲でない計画を確定しない」と組み合わさって行き詰まり(H2-2)を生み、その抜け道として選び直しの経路(H2-3)を開いた。判定を外して記録の引き継ぎに置き換えれば、行き詰まりも抜け道も生じない

### 監査で確かめられること

- SG の判定記録に、未解消の必達基準2 の不合格の有無、継続の回数、引き継いだ再判定の期限があるか
- 次ステージの最初の期の終わりに、区分の付いた途中の判定記録があるか
- 計画容量の根拠の実測値の取り方が、適用する SG より前の記録と一致するか
- 終わるステージの未完了の SC-M が、一件ずつ次の SC-M または外した判定へたどれるか

### 採らない案

- **第2巡の範囲を保ったまま、H2-2 の (a)(b) で閉じる**: 採らない。(a) は束ねる単位という新しい選択の余地を作り、(b) は記名による例外を常態化させる。どちらも SG で判定するための補修であり、判定を外せば要らない
- **SG で到達の見込みを参考として記録だけさせる(判定に使わない)**: 採らない。使われない数値の欄は判定として読まれ、H2-1 の読み違いを再び生む。後から EV を検証する材料は、条件2 の最初の途中の判定で取れる
- **N 案をそのまま採る(条件なし)**: 採らない。SG が不合格の洗浄の場になる

## Q2 M2-6 期日・予算の延長で甲に戻す継続

### 結論

1. **期日の延長か予算の増額で甲に戻した継続は、7.7.5 要求事項4 の回数に数える。数え直しの理由にもしない**(r2 問い(3)と同じ)。数え直せるのは、SC-M を削り、直近の SG で確定した期日・配賦を超えない残りで甲になった場合に限る
2. 途中の判定記録に、**直近の SG で確定した期日・配賦からの延長・増額の累計**を書く
3. 7.6 の予算の超過を測る基準は、ステージの途中で増額した配賦ではなく、**直近の SG で確定した配賦**とする(突合 M2-6 の直し方を支持する)。増額で基準が動くと、7.6 の段階も増額のたびに戻る
4. 数え方(通算、数え直さない、延長で戻した継続も数える)を EV で開示する(E0)。差し替え条件は次のとおり
   - 延長・増額で甲へ戻した継続の件数と、その後に到達しなかった件数
   - SC-M を削って数え直した件数と、その後の到達

### 理由

- 期日と予算を足して甲に戻すのは、資源を追加して目標の側を動かすことにあたる。継続の偏り(escalation of commitment)の典型である。これを回数に数えないと、7.7.5 の「最も強い歯止め」は、資源を足し続ける案件にだけ働かなくなる
- 範囲を削る方向は撤退の方向である。偏りに逆らう行動の結果は数え直してよい。この非対称は、偏りの向きに合わせて置いている
- 7.6 の予算の基準を SG の確定値に固定しないと、条件2 の累計が記録にあっても発火に効かない

### 監査で確かめられること

- 延長・増額の判定の後に甲となった継続が、回数に入っているか
- 累計の欄の値が、延長・増額の判定記録の合計と一致するか
- 7.6 の予算の段階が、直近の SG で確定した配賦に対して測られているか

### 採らない案

- **甲に戻った継続は数えない(現行)**: 採らない。資源を足し続ける経路が上限の外に残る
- **延長・増額そのものに上限を置く**: 採らない。上限の値に根拠が無い。回数に数えれば 7.7.5 の3回の上限が働くので足りる

## Q3 ADR に却下としてどう書くか

### 結論

ADR-0099 は未採用(下書き)なので、本文は N 案で書き直してよい。そのうえで、第2巡で一度採ってから外した定めを、**「検討した選択肢」の表に、一度採ってから外した経緯と理由とともに残す**。「書かれていない」と「課さないと決めた」を区別するためである。

| 選択肢 | 判断 | 書く理由 |
| --- | --- | --- |
| SG で判定の時点ごとの表(継続・保留・中止)で必達基準2 を判定する | 第2巡で採り、第3巡で外す | 「甲でない計画を確定しない」と組み合わさると、完了 0 の単位期間があるだけで継続が作れない(H2-2)。抜け道として、同じゲートで値を選び直す経路が開く(H2-3)。SG-0 の読みも割れる(H2-1) |
| SG で甲でない計画を確定しない | 第2巡で採り、第3巡で外す | 同上。次ステージの大きさは 2.10.1・2.10.2 が縛る。持ち越しの不合格と計画容量の出所は、決定の追加(Q1 条件1〜4)で縛る |
| 7.6 の予算・日程を到達の見込みで測る | 第2巡で採り、第3巡で外す | SC-B・SC-P による段階1 の吸収が働かず、ADR-0095 の段階の設計が崩れる(H2-4)。7.6 は 2.10.6 の見込みで発火し、乙・丙は 2.10.6 の十分条件として結ぶ |
| SG で到達の見込みを参考として記録だけさせる | 採らない | 判定として読まれる。検証の材料は SG の後の最初の途中の判定で取る |
| H2-2 の (a) 単位期間を束ねる・(b) 記名の例外 | 採らない | SG で判定するための補修で、判定を外せば要らない。(a) は選択の余地を増やす |

あわせて次を ADR に書く。

- **「SG では必達基準2 を判定しない」を決定として書く**。省いたのではないことを示す。SG を何が受け持つかも書く(2.10.1・2.10.2、2.4、Q1 の条件1〜4)
- **残るリスクを書く**: 次ステージの計画が到達の見込みに触れずに確定し、最初の期の終わりまで走ること。根拠水準は E0。差し替え条件は、SG の後の最初の途中の判定で乙・丙となった件数の割合
- 第2巡の当委員の SG の表の案が、外した定めの出所であることを書く(会議体の意見の変遷を追えるようにするため)

### 理由

- 一度採った定めを黙って消すと、次の会議体が同じ案を出し、同じ組み合わせの矛盾を再び踏む。外した理由が組み合わせの矛盾(単独では正しく見える)であるため、記録の価値が特に高い

### 監査で確かめられること

- ADR-0099 の検討した選択肢の表に上の5行があり、本文の 7.7.3・7.6・2.10.6 の記述と一致するか
- 「SG では判定しない」の決定と、残るリスクの EV マークが本文と台帳にあるか

### 採らない案

- **第2巡の定めを ADR から消し、N 案だけを書く**: 採らない。却下の記録が残らない
- **第2巡の版を採用済みとして残し、別の ADR で置き換える**: 採らない。ADR-0099 は未採用で、採用済み ADR の書き換え禁止に当たらない。ADR を2本にすると読み手の追跡が増えるだけである
