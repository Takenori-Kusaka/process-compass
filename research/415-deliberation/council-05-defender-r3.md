# #415 会議体 第3巡 委員「弁護(defender)」の意見

- 作成: 2026-11-04
- 入力: `council-00-agenda-r3.md`(N 案)、`crosscheck-2.md`。既存の規定は HEAD(352f4ad)の 7.6(`exception-escalation.md` の 7.6 の表と箇条)、ADR-0095、`lifecycle.md` 2.10.1・2.10.2・2.10.6、`roles-responsibilities.md` 3.7.3 で確かめた
- **認めること**: 第1巡(R-3)と第2巡で、私は「7.6 と必達基準2 は同じ記録から取り、出所を一本にする」と主張しました。H2-4 が示すとおり、これは ADR-0095 の段階1(SC-B・SC-P による吸収)を構造上働かなくします。7.6 は全層の計画を、必達基準2 は SC-M を測るのが正しい分担です。対象が違うことは食い違いではありませんでした。私の誤りです

## Q1 N 案に賛成か

### 結論

**賛成する**。ただし次の欠け4点を同時に埋めることを条件とする。

1. **7.7.4 の検知の材料が無くなる**。7.7.4 の「残20%未満、かつ必達基準に不合格がある」は、判定の前に区分が分かっていることを前提にする。N 案 6 のように記録を B-2 の判定記録だけに置くと、判定が無い限り区分が無く、上程が発火しない(循環)。D-0 表1 の担い手が 7.7.2 の期ごとに区分を**算定**し、2.10.6 の見込みの報告の Issue(ADR-0094 の既存の置き場)に書く。これは判定ではなく検知の材料とする。判定記録の節は、その材料を判定で引き写す場所とする
2. **SG で必達基準2 を「判定しない」ことを、SG の必達基準の記録に明記する**。7.7.3 の「到達の見込みの記録が無い判定は必達基準2 を満たさない」は、ステージの途中の判定に限る。限らないと、SG の判定記録が常に必達基準2 を満たさなくなる(前回 H-2 と同じ型)
3. **2.10.6 の十分条件は、手順の順序を保つ書き方にする**。「乙・丙になったら見込みが立った。手順1(SC-B → SC-P)では SC-M の到達の見込みは改まらないため、手順1 の不足として 7.6 を起票する」と書く。「手順1 を待たずに」は使わない(`lifecycle.md` の「順序を入れ替えてはならない」と当たる。crosscheck-2 H2-4)
4. **7.6 の見込みの端の取り方が、ADR-0095 のまま未定であることを開示する**。7.6 を到達の見込みから切り離すと、#415 が最初に見つけた穴(内部調査 H-7「7.6 の見込みの値の取り方が無い」)の 7.6 の側が残る。今回は決めないと ADR-0099 の「本件で決めないこと」に書き、Issue を起こす

### 理由

- **7.6 を ADR-0095 のままに戻すことは、既存の規定と整合する**。ADR-0095 決定1 の表は、予算・日程の段階1 を「価値責任者が SC-B・SC-P を削って吸収し、判定を要しない」としています。この設計は、7.6 の見込みが全層の計画(SC-M + SC-P + SC-B)の見込みであって初めて働きます。削れば見込みが改まり、吸収が値に表れるからです。ADR-0095 が却下した「予算・日程の段階1 も事業決裁者が判定する」(受信箱が日常の報告で埋まる)に、第2巡の結び付けは実質的に戻っていました。戻すことは ADR-0095 を守ることです
- **戻しても、7.6 と必達基準2 の食い違いは危ない向きには残らない**。SC-M は全層の一部です。到達の見込みの遅い側で SC-M が届かないなら、同じ材料で測る全層の見込みも届きません。したがって「必達基準2 は乙なのに 7.6 は発火しない」は、同じ端で測る限り起きません。逆の「7.6 は発火、必達基準2 は甲」は、SC-P・SC-B を削れば足りる状態です。2.10.6 の手順1 の通りに流れます。欠け4 の開示が要るのは、7.6 の端が定まらない間はこの議論が成り立つ保証が無いためです
- **2.10.1・2.10.2 が SG の計画の確定を受け持つことは、既存の規定と整合する**。SG の「継続」は次段階の資源配分・スコープ・次回判定日を同時に確定します(3.7.3、`roles-responsibilities.md:822`)。スコープの側は 2.10.1(SC-M ≤ 計画容量の 60%)と 2.10.2(実測に対する件数で合意する。見積りの精度で上限を引き上げない)が確定させます(`lifecycle.md:460,482-489,500`)。予算の側は 7.7.1(SG で次ステージ分を確定)と 7.7.9 要求事項11(上側を示す)が受け持ちます。SG に第二の上限(甲の条件)を重ねる必要はありません。重ねると、crosscheck-2 M2-12 のとおり 60% の規則を事実上置き換え、EV-0150 の観測も乱します
- **SG で判定しないことは、SG で到達を問わないことではない**。終わるステージの到達は 2.4 の判定基準が問い、次ステージの計画の大きさは上記の規定が問います。必達基準2 が問うのは、確約した後の途中の崩れです。ステージの途中に限ることで、問いが本来の場所に収まります
- **残る副作用を一つ挙げる**。SG で SC-M を平均の 60% で確定すると、ステージの最初の期の算定で、最小値に基づく遅い側の端が乙になることがありえます。これは確約が観測の悪い側の期間に耐えないことの開示であり、誤りではありません。ただし発生の頻度を EV-0200 の差し替え条件に足します(SG の後の最初の期の算定で乙・丙になった件数)
- **S0 の初回(N 案 4)には賛成する**。語は「算定できない」より「対象外(SC-M なし)」がよい。実測不足(SC-M はあるが窓の件数が足りない)と区別できるからです。S0 の初回の 7.6 の見込みの穴は ADR-0099 より前からあるもので、本件が作ったものではありません。欠け4 と同じく開示します

## Q2 M2-6(期日・予算の延長で甲に戻す継続を 7.7.5 に数えるか)

### 結論

- **数える**。7.7.5 の回数は、**判定の時点の区分が乙・丙であった継続の判定**を数える。同時に行った変更(期日・予算・SC-M)の後の区分によらない。「区分を甲に戻した継続は数えない」の定めは削る
- 議長が範囲の縮小(SC-M を削って甲に戻す)を数えないと決める場合でも、**期日と予算の延長で甲に戻す継続は必ず数える**。これは譲れない最低線とする
- 数え方を EV で開示する(crosscheck-2 M2-6 の後段の指摘を認める)。差し替え条件は、甲へ戻した継続の件数と、その後に到達しなかった件数

### 理由

- **期日と予算の延長は、投資の拡大そのものである**。継続の偏りの研究(Staw、Simonson & Staw 1992、Keil ら。`survey-415-2-external.md` §1.13)が問題にするのは、届かない見込みを前に資源を追加し続けることです。延長で甲に戻すことを数えなければ、要求事項4 の上限は、最も典型的な拡大の経路に掛かりません。NASA の法定の引き金も、30% 超の後の継続には上位(議会)の承認と新しいベースラインを要します(外部 §1.5)。本標準で同じ位置にあるのが要求事項4 の上限と、上限に達した後の新たな G-1 です
- **延長は 7.6 も拾えない**。7.6 の予算の閾値は配賦に対する超過で測ります。配賦を増やすたびに基準が動くため、延長の累計は 7.6 に現れません(crosscheck-2 M2-6)。拾う規定が他に無い以上、7.7.5 で数えるしかありません
- **範囲の縮小も数えるのが一貫する**。範囲の縮小は確約を減らす健全な対応ですが、判定の時点で乙・丙だった事実は変わりません。数え方を「判定の時点の区分」に揃えれば、記入者が変更の種類を選んで回数を避ける経路も消えます。上限に達した後も保留と中止は選べ、企画を承認し直す道(新たな G-1)も残ります。3 回の範囲の縮小で到達の見込みが立たない案件に、それ以上の継続を認める理由を示す実績はありません

## Q3 N 案で採らない第2巡の定めを、ADR にどう書くか

### 結論

ADR-0099 は未採用であり、第2巡の定めは公開していません。そのため、採用済みの決定を置き換える形にはしません。検討した選択肢の表に、**「第2巡で一度採り、組み合わせの矛盾で撤回」と分かる行**として置きます。

| 選択肢 | 出した者 | 採否と理由 |
| --- | --- | --- |
| SG で必達基準2 を判定し、判定の時点(継続・保留)ごとに比べる対象と残りを定める | 第2巡(弁護・起案) | 採らない(第2巡で採り、撤回)。次ステージの計画の大きさは 2.10.1・2.10.2 と 7.7.1 が受け持つ。SG で判定すると二重の上限になり(60% の規則の事実上の置き換え)、保留の延長に上限が無い経路と、SG-0・SG-1・SG-2 の語の衝突を生んだ |
| SG で区分が甲でない計画を確定しない | 第2巡(起案) | 採らない(同)。完了 0 の単位期間を含む窓では、SC-M を 0 件にしても甲にならず、継続を確定できない。同じゲートで端の取り方を選び直す経路だけが逃げ道になる |
| 7.6 の予算・日程の見込みを、必達基準2 と同じ到達の見込みの記録から遅い側の端で測る | 第1巡・第2巡(弁護が提起、5 委員一致) | 採らない(同)。SC-M だけを数える見込みは SC-B・SC-P を削っても改まらず、ADR-0095 の段階1 の吸収が働かない。ADR-0095 が却下した「予算・日程の段階1 も事業決裁者が判定する」と同じ帰結になる。7.6 は全層の計画、必達基準2 は SC-M を測る |
| S0 の初回は 7.7.9 の見積りの幅で代える | 第1巡(起案・規格・弁護) | 採らない。案件全体の値で、ステージの残りと比べる単位が合わない |

あわせて、次を書く。

- **影響**に「ADR-0095 を変えない。7.6 は 2.10.6 の見込みで発火する」と書く。「補う」とだけ書かない
- **本件で決めないこと**に「7.6 の見込みの端の取り方」「S0 の初回の 7.6 の見込みの材料」を足す。前者は内部調査 H-7 の残りであり、後継の Issue の番号を書く
- 却下の理由の主語は、組み合わせの矛盾を見つけた独立の突合(`crosscheck-2.md` の H2-1〜H2-4)とする

### 理由

- 却下は成果であり、採らないと決めたことは明記する(コアポリシー)。第2巡の定めは本文に一度書かれ、突合の対象にもなりました。表に残さないと、後の読み手は「SG で必達基準2 を判定しない」を見落としと読みます。2.10.1・2.10.2 が受け持つから判定しない、という判断が伝わりません
- 7.6 の結び付けは、私自身が第1巡から推した案です。出した者を正しく書くことは、同じ誤りを繰り返させないための記録です
- 7.6 の端の取り方を「決めない」と書くのは、「書かれていない」と「課さないと決めた」を区別するためです。H-7 は #415 の出発点の一つでした。範囲を狭めた結果として残る穴を、黙って残すことはできません

## Q ごとの結論(1行)

- Q1: 賛成します。7.6 を ADR-0095 に戻すことも、SG の計画の確定を 2.10.1・2.10.2(と 7.7.1)に任せることも、既存の規定と整合します。条件は4つです。期ごとの区分の算定を 7.7.4 の検知の材料として見込みの報告の Issue に置くこと。「記録が無い判定は満たさない」を途中の判定に限ること。2.10.6 の十分条件を手順の順序を保つ書き方にすること。7.6 の端の取り方が未定であることを開示すること
- Q2: 数えます。判定の時点で乙・丙だった継続を、変更の後の区分によらず数えます。最低でも、期日・予算の延長で甲に戻す継続は必ず数えます。数え方は EV で開示します
- Q3: 検討した選択肢の表に「第2巡で採り、組み合わせの矛盾で撤回」の行を4つ置きます。7.6 の結び付けは、出した者を弁護と書きます。影響に「ADR-0095 を変えない」、本件で決めないことに「7.6 の見込みの端の取り方」を書きます
