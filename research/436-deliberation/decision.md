# 議長の裁定(#436 フリーランス法と、発注側の設備・計算資源の負担の注記の関係)

- 審議の重さ: **重**(法令)
- 入力: `survey-436.md`(S-1〜S-6)と、5 委員(起案・現場・品質監査・規格・弁護)の意見 `council-01`〜`05`
- 既存の決定: ADR-0069 決定3(注記は情報であり、規範を足さない)、ADR-0114(#372 の注記)

## 0. 骨格

5 委員とも、次の2点を欠陥と認めた。
- 「本標準が定めないこと」(640 行)の列挙に、フリーランス法が無い
- 注記 879 行の「法令が求める書面や契約に代わりません」の対象に、フリーランス法の 3条通知が入っていない

最も重い論点は候補 C である(現場・規格)。第12項に費用の負担者を書いても、3条通知で精算を明示しなければ「報酬の額のみを支払う」ものとして扱われる(S-2 10〜11頁)。

## 出典の扱い(論点2) — 裁定

- 本文から引くのは、PDF を直接読んだものに限る。S-2(解釈ガイドライン)、S-3(適用関係の考え方)、S-6(フリーランスガイドライン)が当たる(5 委員)
- S-1(法律の条文)は、法律の名称と条番号を示すためだけに引く。e-Gov の XML を直接取得して照合する。照合できなければ、照合の状態を partial とする(規格・現場・弁護)
- S-4(Q&A)・S-5(取適法の条文)は、要約モデルを経て読んだもの。本文から引かず、出典カードも起こさない(品質監査・弁護)

## 候補ごとの裁定(論点1)

| 候補 | 裁定 | 理由 |
| --- | --- | --- |
| A 適用の入口 | 採る | 3条は全ての業務委託事業者に、5条は特定業務委託事業者の1か月以上の委託に掛かる(S-2 7頁・26頁) |
| B 購入・利用強制の要件 | 採る | 「その対価を負担させること」で、取適法と同じ形(S-2 36頁) |
| C 費用等の明示 | 採る。ただし「協議し決定することが望ましい」の部分は除く | 精算の明示が無いと「報酬の額のみ」とされる事実は、第12項の記録と 3条通知の違いを示すのに要る(S-2 10〜11頁)。「望ましい」は行政の推奨であり、本標準の推奨と読まれる(弁護) |
| D 重なりの扱い | 採る。S-3 と S-6 8頁の範囲に限る | 原則としてフリーランス法を優先し、例外がある(S-3)。明示は両法の記載事項を一括で示せる(S-6 8頁)。Q&A(S-4)は引かない |
| E 公的な整理の所在 | 採る。範囲は S-2 に限る | 発注側の設備・利用権・計算資源の提供や費用の負担を直接扱った記述は、確かめた範囲に無い。「計算資源の費用が『費用等』に当たるかを示した公的な整理は、確かめた範囲に無い」と開示を添える(品質監査) |
| F 取適法 5条2項1号 | 採らない(注記へは足さない) | 根拠の S-5 が要約を経たもので、照合が済んでいない。役務提供委託に掛からない号であり、論点の外 |
| G 労働者性の補強要素 | 採らない | 指揮命令の軸に属する。労働者性の判断を標準が示すことになり、法的助言の境界を越える |
| 640 行への追記 | 採る | 列挙の括弧に、フリーランス法(特定受託事業者に係る取引の適正化)を加える |
| 879 行の対象の拡張 | 採る | 「代わりません」の対象に、フリーランス法の 3条通知を加える |

- 採らない(論点1): 第12項に 3条通知の欄を足す案(新しい義務になる。#372 で双務契約の所在の欄を採らなかったのと同じ型)
- 注記の見出しにある時点「2026-11-05」は、確かめた日に合わせて直す(品質監査)

## 記録(論点3) — 裁定
