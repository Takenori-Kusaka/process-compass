# 委員の意見(#436 現場: 個人の事業者へ発注する受託開発)

- 立場: フリーランスへ発注する受託開発の現場。発注の手数、書面の作り方、席・計算資源の貸与の実務を重視する
- 入力: `survey-436.md`(§3・§4)、`research/372-deliberation/decision.md`、第8章 `tailoring-guide.md`「計算資源の負担を決める」(843〜880 行)と「本標準が定めないこと」(640 行)
- 前提: 注記は情報で、規範を足さない(ADR-0069 決定3、372 decision R-1)。判断軸は信頼性

## 現場から見た骨格

個人の受注者との取引では、AI のサービスの席や CI を、発注側が貸す場合と受注者が自前で契約する場合が混在します。現場で最も起きやすい誤りは、テンプレ8 第12項に「費用の負担者」を書いた時点で、取り決めが済んだと思うことです。フリーランス法の解釈ガイドラインは、精算の明示が無ければ3条通知の報酬の額のみを支払う旨を明示したものとされる、と書いています(S-2 10〜11頁、PDF を直接読んだもの)。第12項に「発注側が負担」と書いても、3条通知で明示しなければ、その費用は受注者の持ち出しと読まれえます。この食い違いを読み手に知らせることが、本件の信頼性の中心です。

## 論点1 候補 A〜G と「本標準が定めないこと」

| 候補 | 推す判断 | 理由(所在) |
| --- | --- | --- |
| A 適用の入口 | 採る | 3条は全ての業務委託事業者に、5条は特定業務委託事業者の1か月以上の委託に掛かる(S-2 7頁・26頁)。従業員のいない発注者・短期の委託にも3条が掛かることを、現場はよく見落とす |
| B 購入・利用強制の要件 | 採る | 取適法の文(注記 875 行)と同じ形で並べられる(S-2 36頁)。無償の貸与に取適法だけを当てて読む誤りを防ぐ |
| C 費用等の明示 | 採る(最重要) | 上の骨格。S-2 10〜11頁 |
| D 重なりの扱い | 一部を採る | 一括明示(S-6 8頁)は書面を1通にできるため、発注の手数に直結する。勧告の優先(S-3)は執行の話で、書面の作り方に影響しないため採らない |
| E 公的な整理の所在 | 採る | 877 行の「確認した範囲にありません」へフリーランス法を加える。書かないと、調べていないのか、無かったのかを読み手が区別できない |
| F 取適法 5条2項1号 | 注記には採らない | 役務提供委託に掛からない(S-5 柱書の括弧書き)。ソフトウェアの受託は情報成果物の作成委託であり、原材料の有償支給は現場の論点にならない。確認の結果は ADR の採らない案に残す |
| G 労働者性の補強要素 | 本注記には採らない。693 行の注記に1文で採る | 個人へ PC・アカウントを貸す現場では、設備の負担は37号の区分より労働者性の補強要素として現れる(S-6 30〜31頁)。ただし主たる基準は指揮監督であり、指揮命令の軸に属する(372 decision 骨格「適用範囲が違うものを混ぜない」) |
| 定めないことへの追記 | 採る | 640 行の括弧に「特定受託事業者に係る取引の適正化」を加える |

文の形(案。事実の記述だけにする):

- A: 「受注側が特定受託事業者(従業員を使用しない個人・一人法人)である場合は、フリーランス法が掛かるとされています。給付の内容・報酬の額などの明示(第3条)は全ての業務委託事業者に、禁止行為(第5条)は特定業務委託事業者が1か月以上の業務委託をする場合に掛かるとされています。」
- C: 「同法の解釈ガイドラインは、業務委託事業者が業務の遂行に要する費用等(名目を問わない)を負担する場合は、総額が把握できるように報酬の額を明示する必要があるとしています。精算について明示が無い場合は、3条通知に記載した報酬の額のみを支払う旨を明示したものとされます。」
- C の続き(既存 879 行の拡張): 「テンプレ8 第12項への記入は、同法の3条通知にも代わりません。」
- D: 「両法が適用される取引では、両法の記載事項を一括で示すことができるとされています(S-6)。」
- G(693 行側): 「受注側が個人の場合、労働基準法上の労働者性は指揮監督等で判断され、機械・器具の負担関係は判断を補強する要素とされています。」
- 定めないこと: 「…(労働者派遣事業と請負の区分、中小受託取引の適正化、特定受託事業者に係る取引の適正化)を、本標準は評価しない」

採らない案:

- 計算資源の費用が「費用等」に当たると書くこと。原文に例が無い(survey §4)。現場は書いてほしいが、推測を事実として書けば信頼性を損なう
- 「AI の席の費用は3条通知で明示する」と勧めること。法的助言で、規範の追加になる
- 第12項に3条通知の参照欄を足すこと。理由が法令にしか無い(372 R-2 の双務契約の欄と同じ型)

## 論点2 要約モデル経由の出典(S-1・S-4・S-5)

- 推す案: 本文が引く文は、PDF を直接読んだ出典(S-2・S-3・S-6)から取る。S-1 は、S-2・S-6 と一致した2条・5条の文言に限って補助に使う。3条の後半(要約での取得)は引かない
- S-4(Q&A)は本文で引かない。D の一括明示は S-6 8頁で足りる。Q39(諸経費を「別途協議」とできる条件)は現場に最も役立つが、要約経由のため、flpa.pdf を直接読んで照合できた場合に限って引く。照合できなければ ADR の未確認の一覧に残す
- S-5 は F を注記に採らないため、本文で引かない。確認の経緯は ADR に「要約モデル経由」と書いて残す
- 実装の前に、e-Gov 法令 API の XML を要約モデルを通さずに取得して S-1 を照合することを求める。372 で運用基準(SRC-0724)の照合が「部分」のまま本文に入った前例を繰り返さないため(880 行付近)
- 落とす案: 要約経由の引用に「照合は部分」と添えて本文へ入れる案。読み手は添え書きより引用の文を信じる

## 論点3 新しい ADR と EV

- ADR: 新設を推す。ADR-0114 は採用済みで書き換えられない。「本標準が定めないこと」へフリーランス法を加えるのは「課さないと決めた」決定であり、記録が要る。F・G の扱い、要約経由の出典を引かない判断、見直しの契機(解釈ガイドラインの改正。令和8年10月1日改正の差分は未確認)を書く
- EV: 付けない。足すのは事実の記述で、新しい規範も値も無い(372 R-3 と同じ扱い)。EV-0232 の差し替え条件に「3条通知と第12項の食い違いの件数」を足す案は、条件の変更が既存の EV の判断に関わるため、議長の判断に委ねる
- 落とす案: ADR-0114 の改訂として扱う案(採用済み ADR の本文は書き換えない)
