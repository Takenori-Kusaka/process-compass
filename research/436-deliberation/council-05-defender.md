# 弁護の委員の意見(#436 フリーランス法と、計算資源の負担の注記)

立場: 今の注記(第8章 `tailoring-guide.md` 867〜880 行。37号告示・取適法だけ)の側に立つ。広げる案の弱点を突き、欠陥と認めるものは認める。判断軸は信頼性。規範は足さない(ADR-0069 決定3)。

## 0. 認める欠陥

- 640 行「本標準が定めないこと」は、法令を2つ(派遣と請負の区分・中小受託取引の適正化)だけ挙げる。読み手は、これを当てはめの要る法令の全部と読みうる。受注側が個人(従業員を使用しない)の受託は、本標準が対象にする小さい体制で現に起きる。フリーランス法が載っていないのは、「書かれていない」と「課さないと決めた」を区別できない状態である(CLAUDE.md コアポリシー)。欠陥と認める
- 879 行「法令が求める書面や契約に代わりません」の「これらの法令」は、37号告示と取適法を指す。フリーランス法の 3条通知(報酬の額の明示)は、この文の対象から外れている。第12項の「費用の負担者」の記入を 3条通知の代わりと読む誤りを、今の文は防げない(survey §6、S-2 10〜11頁)。欠陥と認める

## 1. 広げる案の弱点(全候補に掛かる)

- 解釈の危険: 適用の閾値の言い換えは、それ自体が法令の解釈になる。例: フリーランス法の「従業員を使用」は週20時間以上かつ31日以上の雇用見込みに限られる(S-2 3頁)。日常の語の「従業員」で読むと誤る。注記に書くなら条文の文言の引用に限り、要約しない
- 改正への追随: 解釈ガイドライン(S-2)は令和6年5月の後に令和7年10月・令和8年10月と改正された。S-3・S-6 も令和8年1月に改正された。2年で4回。注記の時点の表示と、ADR の見直しの契機に、これらの改正を載せない限り、注記は黙って古くなる
- 隣接の誤読: 計算資源の費用の隣に法令の費用の記述を置くと、「計算資源の費用は解釈ガイドラインの費用等に当たる」と読まれる。これは survey §4 で推測(未確認)とした点である。広げるなら、公的な当てはめが無いという文(候補 E)を必ず同じ注記に置く

## 2. 論点1 候補ごとの採否

- **A 採る(条文の引用に限る)**。文の形: 「受注側が特定受託事業者(従業員を使用しない個人、または一の代表者以外に役員がなく従業員を使用しない法人。同法 2条1項)である場合、特定受託事業者に係る取引の適正化等に関する法律が掛かります。明示(3条)は全ての業務委託事業者に、禁止行為(5条)は特定業務委託事業者の1か月以上の業務委託に掛かるとされています(解釈ガイドライン 7頁・26頁)。」「従業員」の範囲は言い換えず、解釈ガイドライン 3頁を参照させる。理由: 0 の欠陥を直すには、どの取引に掛かるかが要る
- **B 採る**。取適法の文(875 行)と同じ形で、「その対価を負担させること」の要件を解釈ガイドライン 36頁から引く。理由: #372 R-1 が、要件を書かないと読み手が誤ると裁定した(弁護の「所在だけ」案を落とした理由)。同じ理由がこちらにも当てはまる
- **C 一部を採る**。採る文: 費用等(名目を問わない)を業務委託事業者が負担する場合は総額が分かるように報酬の額を明示する必要があり、精算の明示が無ければ報酬の額のみを支払う旨を明示したものとされる(S-2 10〜11頁)。879 行の「代わりません」の対象に 3条通知を名指しで加える。採らない文: 「協議し決定することが望ましい」。標準の注記に置くと、本標準の推奨と読まれる。#372 R-1 で「両方を満たす構成の推奨」を法的助言の境界の外として落としたのと同じ型である
- **D 採らない**。S-3 の定めは公正取引委員会の勧告の優先の扱いであり、採用者の義務を減らさない(S-3 の示唆)。「優先して適用」と書くと、取適法の義務が外れると誤読される。明示の一括(S-4 Q33)は要約モデル経由である
- **E 採る(必須)**。877 行の「確認した範囲にありません」の範囲に、フリーランス法の解釈ガイドライン(令和8年10月1日改正版)を加える。理由: 1 の隣接の誤読を防ぐ唯一の文である。Q&A(S-4)は全問を目視していないため、範囲に含めない
- **F 採らない(本文へ)**。取適法 5条2項1号の文言は S-5(要約モデル経由)だけに依る。「役務提供委託に掛からない」「計算資源は原材料等に当たらない」は当てはめであり、本標準は評価しない(880 行)。確認の結果は ADR の未確認の一覧を更新する形で残す
- **G 採らない(本注記にも 693 行にも、本件では)**。労働者性は指揮命令の軸であり、#372 の骨格(適用範囲が違うものを混ぜない)に反する。判断基準の原典(昭和60年 労働基準法研究会報告)を読んでいない。693 行へ置くかは別の審議の論点として記録する
- **640 行への追記 採る**。文の形: 「計算資源の費用の負担について、法令上の当てはめ(労働者派遣事業と請負の区分、中小受託取引の適正化、特定受託事業者に係る取引の適正化)を、本標準は評価しない」。加えて「テンプレ8 第12項への記入が、特定受託事業者に係る取引の適正化等に関する法律の 3条の明示に当たるかを、本標準は判断しない」を置く

## 3. 論点2 要約モデル経由の出典(S-1・S-4・S-5)

- 推す案: 本文は、PDF を直接読んだ S-2(と、採るなら S-3・S-6)だけを引く。S-1・S-4・S-5 を単独の根拠にする文は書かない
- S-1(法の条文)は本文が法の名と 2条・3条・5条を引くので、出典カードが要る。実装の前に e-Gov 法令 API の XML を要約モデルを通さずに直接取得し(curl 等)、引用と文字単位で照合する。照合できなければカードの照合を「部分」とし、条文の内容は S-2 の引用の側で示す
- S-4・S-5 はカードを起こさない(本文が引かない。#372 R-3 の「本文が引く資料にだけ claim を立てる」)。survey の未確認の一覧に残す
- 落とす案: 「S-2・S-6 と一致したから S-1 は確かめた事実」とする扱い。一致は 2条・5条の範囲だけで、3条の後半は要約での取得である(S-1 の照合の水準)。一部の一致で全体を確かめたことにしない
- 採らない案: 要約モデル経由の出典を、照合「部分」の表示つきで本文から引く。照合の表示は読み手に届かず、F のような当てはめが本文に入る経路になる

## 4. 論点3 ADR と EV

- 新しい ADR: 要る。ADR-0114 の決定1は注記の中身を 37号告示・取適法に定め、見直しの契機をその法令・告示・運用基準の改正とした。法令を加えることと見直しの契機を広げることは、この決定の範囲の変更であり、採用済み ADR の本文は書き換えられない。新しい ADR は ADR-0114 を置き換えず補う。決定、採らない案(D・F・G、「望ましい」の文)、見直しの契機(解釈ガイドライン・Q&A・施行令・公正取引委員会規則の改正)を書く
- EV: 新しい EV は要らない。注記は事実の記述であり、#372 R-3 も注記に EV を付けなかった。3条通知に「代わらない」の文は本標準自身についての記述で、実証を要する判断ではない。EV-0232 は対象(第12項の3欄)が変わらないので据え置く
- 採らない案: ADR を立てず注記と 640 行だけを直す。改正への追随(1)の手当てが、どこにも記録されない
