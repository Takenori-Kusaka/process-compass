# 会議体 意見(#436 規格の委員)

- 立場: 法令と行政の文書(フリーランス法・取適法・解釈ガイドライン・適用関係の考え方・Q&A)との整合を重視する。法的助言を標準に書かない境界を守る
- 入力: `survey-436.md`(§0〜§6)、`research/372-deliberation/decision.md`、第8章 `tailoring-guide.md` 843〜881 行の注記と 640 行付近の「本標準が定めないこと」
- 前提: 注記は情報であり規範を足さない(ADR-0069 決定3、#372 R-1)。判断軸は信頼性。読み手が取適法の注記だけを見て「個人の受注者にも同じ扱いで足りる」と誤らないことを目的とする

## 論点1 候補 A〜G と「本標準が定めないこと」

推す案: A・B・C・D・E を事実の文として注記へ足す。F・G は注記へ足さない。「定めないこと」は既存の箇条の括弧へフリーランス法を足し、3条通知の項目を1つ足す。

- A(適用の入口) — 採る。文の形: 「受注側が特定受託事業者(従業員を使用しない個人、または代表者のほかに役員がなく従業員を使用しない法人)である場合、特定受託事業者に係る取引の適正化等に関する法律(フリーランス・事業者間取引適正化等法)が掛かるとされています。明示(第3条)は全ての業務委託事業者に、禁止行為(第5条)は特定業務委託事業者が1か月以上の業務委託をする場合に掛かるとされています(解釈ガイドライン 7頁・26頁)」
  - 理由: 3条と5条で義務を負う者・期間が違う(S-2 7頁「全ての業務委託事業者に適用」、26頁「１か月」)。入口を書かないと、従業員のいない発注者や短期の委託の読み手が自分には掛からないと誤る
  - 「従業員を使用」の定義(週20時間以上かつ31日以上。S-2 3頁)は本文に書かない。要件の再記述は当てはめの手引きになり、法的助言の境界へ寄るため。出典の所在を示すにとどめる
- B(購入・利用強制の要件) — 採る。現行 876 行の取適法の文と同じ形で、「フリーランス・事業者間取引適正化等法の解釈ガイドラインも、購入・利用強制(法第5条第1項第5号)を、…特定受託事業者に**その対価を負担させること**としています(第2部 第2 2(2)オ、36頁)」
  - 理由: 両法で要件の形が同じことは、PDF を直接読んで確かめた(S-2)。片方だけを書くと、無償貸与の扱いが法ごとに違うと読まれる
- C(費用等の明示) — 採る。最も重い。文の形: 「業務委託事業者が業務の遂行に要する費用等(名目を問わない)を負担する場合は、総額が把握できるように報酬の額を明示する必要があるとされています。精算について明示が無い場合は、3条通知に記載した報酬の額のみを支払う旨を明示したものとされています。精算の有無と範囲は、委託に先立って協議し決定することが望ましいとされています(解釈ガイドライン 第2部 第1 1(3)キ(ウ)、10〜11頁)」。続けて、現行 880 行の「書面や契約に代わりません」の対象に3条通知を明記する
  - 理由: 設備・計算資源の費用が法の側で最初に現れる場所は5条でなく3条である(survey §6)。第12項の「費用の負担者」の記録だけで3条の明示を済ませたと読み手が誤ることが、本件で最も起きやすい誤りである
  - 条件: 「望ましい」は行政文書の語として「とされています」で受ける。本標準の推奨に格上げしない。「計算資源の費用が費用等に当たる」とは書かない(§4 の推測。公的な当てはめが無い)
- D(重なりの扱い) — 採る。ただし「原則としてフリーランス法を優先して**適用**し、重ねて取適法で勧告しない。例外がある」を、執行(勧告)の優先として書く(S-3 3)。明示の一括は S-6 8頁を出典にする
  - 理由: 「優先」を「片方の義務が免除される」と読む誤りを防ぐ(S-3 の原文は「勧告することはない」で、義務の免除を書いていない)。Q33(S-4)は要約モデル経由のため、同旨の S-6 8頁(PDF 直読)で代える
- E(公的な整理の所在) — 採る。現行 878 行の「確認した範囲にありません」の範囲へ、解釈ガイドライン(令和8年10月1日改正版、全48頁)を加える
  - 条件: Q&A は本体 PDF(flpa.pdf)を全問目視するまで範囲に入れない。HTML の要約モデルの「無い」は、無いことの根拠として弱い(不存在の主張は取得漏れに最も弱い)
- F(取適法 5条2項1号) — 注記へ足さない。理由: 条文の文言(半製品・部品・附属品・原材料)と柱書の括弧書きから、役務提供委託に掛からないとされ、本注記の論点(設備・利用権)の外にある。#372 R-1 が 5条2項2号・運用基準 7-8 を「論点の外」として外した型と同じ。条文の取得が要約モデル経由(S-5)でもある。確認の結果は新しい ADR の「確かめた事実・採らない案」に残し、ADR-0114 の未確認の一覧からの解消を記録する
- G(労働者性の補強要素) — 本注記にも 693 行の注記にも足さない。理由: (1) 労働者性は指揮命令(使用従属性)の軸で、#372 の骨格(適用範囲が違うものを混ぜない)に反する。(2) 判断基準の原典(労働基準法研究会報告 昭和60年)を読んでいない(§5)。(3) 補強要素の列挙は、受注側が「機材を自分で持てば労働者性が弱まる」という当てはめの手引きとして読まれ、法的助言の境界を越える。後継の Issue へ送る(既存の open Issue があればそこへ寄せる)
- 「本標準が定めないこと」 — 採る。文の形: 既存の箇条の括弧を「(労働者派遣事業と請負の区分、中小受託取引の適正化、特定受託事業者に係る取引の適正化)」にする。さらに1項「フリーランス・事業者間取引適正化等法の3条通知の明示事項(報酬の額と費用等の精算の扱い)を、本標準は定めない。テンプレ8 第12項はその明示に代わらない」を足す
  - 理由: 「書かれていない」と「課さないと決めた」を区別する(コアポリシー)。#372 の時点ではフリーランス法は列挙に無く、読み手は未検討か不採用かを区別できない
- 注記の見出しの時点は 2026-11-11 へ進める。法令の名は初出で正式名称、以後は解釈ガイドラインが使う通称に揃える

採らない案: 両法を満たす構成(費用を発注側が負担し、総額を3条通知へ書く等)の推奨。#372 R-1 で外した「両方を満たす構成の推奨」と同じく法的助言の境界の外。

## 論点2 要約モデル経由の出典(S-1・S-4・S-5)

推す案: 本文の引用(「」で括る文言)は、PDF を直接読んだ S-2・S-3・S-6 からだけ取る。S-1・S-5 は条番号の所在の参照にとどめ、引用しない。S-4 は本文から引かない。

- 理由: 法令の文言は1字の違いで要件が変わる(「いずれか」で #372 が示した)。S-1 の 2条・5条は S-2・S-6 の引用と一致するが、一致は解釈ガイドライン側の引用で足り、要約モデル経由の条文を重ねる必要が無い。S-5 の 5条2項1号は F を採らないため本文に出ない
- 出典カード: S-2・S-3・S-6 に新しいカードを起こし、本文が引く頁にだけ claim を立てる(#372 R-3 の型)。S-1 は条番号の所在だけを claim にし、照合は「部分」と記録する。S-4 はカードを起こさない(本文が引かない)
- 実装の前に、e-Gov 法令 API の XML を要約モデルを通さず取得して 2条・3条・5条を文字単位で照合することを勧める。照合できれば S-1 を「照合した」に上げてよい。できなければ上の扱いのまま
- 採らない案: (a) SRC-0724 と同じく「要約モデル経由。照合は部分」の開示つきで S-1・S-4 を本文に引く案。代わりの直読の出典があるのに弱い出典を引く理由が無い。(b) 要約モデル経由の出典を一律に捨てる案。所在の手がかり(Q39 の「別途協議」など)は調査の記録として残す価値がある

## 論点3 新しい ADR と EV

- ADR — 新設を推す(ADR-0114 を置き換えず補う)。理由: ADR-0114 は「本標準が定めないこと」の範囲を2法で決めた。採用済みの本文は書き換えられない。範囲へフリーランス法と3条通知を足すこと、F・G を採らないこと、ADR-0114 の未確認の一覧(5条2項1号)の解消は、後から変えにくい方針の決定である。見直しの契機に、解釈ガイドライン・施行令・公正取引委員会規則の改正と、計算資源の費用を費用等に当てはめた公的な整理の公表を書く
- EV — 付けない。理由: 足すものは原文で確かめた事実と、評価しない旨の宣言だけで、規範も実証に依る値も無い(#372 R-3「EV は改めた規定にだけ付ける。注記には付けない」)。既存の EV-0232 の対象(第12項の3つの欄)は変えないため、更新も要らない
- 採らない案: ADR-0114 の改訂(採用済み ADR の本文は書き換えない規則に反する)。EV を注記に付ける案(事実の記述に根拠水準のマークを付けると、事実と暫定の判断の区別が崩れる)
