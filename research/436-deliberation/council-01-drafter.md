# 起案の委員の意見(#436 フリーランス法と計算資源の負担の注記)

- 立場: 注記の文案を起草する。ADR-0069 決定3(注記は情報で、規範を足さない)と ADR-0114 決定1 の既存の注記(第8章 tailoring-guide.md 867〜880 行)との整合を重視する
- 入力: `survey-436.md`、`research/372-deliberation/decision.md`、ADR-0114、第8章の当該の節と 640 行

## 論点1 候補 A〜G と「本標準が定めないこと」

推す案: A・B・C・E を、既存の注記の取適法の段落の後ろに1段落にまとめて足す。「定めないこと」は既存の項目の括弧へ足す。D・F・G は注記へ入れない。

文案(注記の見出しは「外部の制約(2026-11-11 時点)」へ改める。段落ごとの照合の日付は残す):

> 受注側が特定受託事業者(従業員を使用しない個人、または代表者のほかに役員と従業員のいない法人)である場合は、「特定受託事業者に係る取引の適正化等に関する法律」(フリーランス法)が掛かります。取引条件の明示(法第3条)は、全ての業務委託事業者に掛かるとされています。禁止行為(法第5条)は、特定業務委託事業者が1か月以上の業務委託をする場合に掛かるとされています。同法の解釈ガイドラインは、業務委託事業者が業務の遂行に要する費用等(名目を問わない)を負担する場合は、その金額を含めた総額が分かるように報酬の額を明示する必要があるとしています。費用等の精算について明示が無い場合は、明示した報酬の額のみを支払う旨を明示したものとされています。購入・利用強制(法第5条第1項第5号)は、特定受託事業者に**その対価を負担させること**とされています(解釈ガイドライン 第2部 第1 1(3)キ(ウ)、第2部 第2 2(2)オ)。引用は令和8年10月1日に改正された版の PDF のテキストから取りました。同ガイドラインの例示に、ソフトウェアの利用権や計算資源は含まれていません。

- 既存の「公的な整理は、確認した範囲にありません」(877 行)の「これらの法令」にフリーランス法が入る形にする(候補 E)。新しい文を立てない
- 既存の「第12項への記入は、これらの法令が求める書面や契約に代わりません」(879 行)の「これらの法令」が、3条の明示を含むことになる(候補 C の副項)。文を変えずに範囲が届く
- 「定めないこと」(640 行): 括弧を「(労働者派遣事業と請負の区分、中小受託取引の適正化、特定受託事業者に係る取引の適正化)」へ改める

理由:
- A は B・C を読む入口である。A が無いと、発注者に従業員がいない短期の委託でも3条が掛かること(S-2 7頁)を読み手が落とす
- C が本件で最も信頼性に効く。第12項は「費用の負担者」を記録させる(第8章 851 行の表)。記録に負担者を書いても、3条通知の報酬の額に費用等を含めていなければ、精算の明示の無い通知として扱われる(S-2 10〜11頁)。第12項を記入したことで足りると読み手が誤る道を、事実で塞ぐ
- B は既存の取適法の段落(875 行)と同じ型であり、無償の貸与が購入・利用強制に当たると誤る道を塞ぐ。#372 R-1 が「要件を書かないと誤る」として所在だけの案を落とした理由と同じ
- 「例示に含まれていない」は確かめた事実(S-2 全48頁)で書く。「費用等に当たる/当たらない」は推測(survey §4)のため書かない
- 規範を足さない(ADR-0069 決定3)。「協議し決定することが望ましい」(S-2 11頁)は、注記に引くと本標準の推奨に読めるため引かない

他の案を落とす理由:
- D(重なりの優先と一括の明示): 勧告の優先は執行の定めで、計算資源の負担の論点の外である。「原則フリーランス法を優先」は、取適法の段落が掛からないと誤読される危険がある(S-3 は免除を定めない)。一括の明示は書面の様式の話で、第12項と関係しない
- F(取適法 5条2項1号の確認結果): 役務提供委託に掛からず(S-5 柱書の括弧書き)、論点の外。S-5 は要約モデル経由で照合が部分。新 ADR の「未確認の一次資料」の更新として記録だけ残す
- G(労働者性の補強要素): 指揮命令の軸に属する。#372 の骨格(適用範囲が違うものを混ぜない)により本注記には置かない。693 行の注記へ置くかは別 Issue へ送る(既存の open Issue へ寄せる)

採らない案: 第12項に「3条通知の報酬の額に含めたか」の欄を足す案(理由が法令にしか無い。ADR-0114 の双務契約の欄を落とした理由と同じ型)。

## 論点2 要約モデル経由の出典(S-1・S-4・S-5)

推す案: 本文の引用は、PDF を直接読んだ S-2 だけから取る。S-1 は条番号の所在としてだけ使い、文言は引かない。S-4・S-5 は本文から引かない。

- S-1: 2条・5条の文言は S-2・S-6 の引用と一致するが、文字単位の照合は未了。条文の要件(従業員の有無・1か月)は S-2 3頁・26頁の記述で足りる
- S-4 Q39(諸費用の「別途協議」): C を補う有用な情報だが、HTML の要約経由で PDF(flpa.pdf)と照合していない。実装の前に PDF のテキストで照合できたときに限り、C の後ろに1文足す。照合できなければ新 ADR の未確認の一次資料へ残す
- S-5: F を採らないため本文で使わない
- 出典カード: S-2 に新しいカードを起こし、版(令和8年10月1日改正)を名指す。S-1 は所在のカードとし照合を partial と書く(SRC-0724 の先例)

落とす理由: 要約モデル経由の文言を「原文で確かめた事実」として注記に書くと、ADR-0114 決定1 の前提(原文で確かめた事実だけ)が崩れる。照合の状態を注記で開示して載せる案(875 行の先例)は、S-2 という直接の出典が同じ事実を支えるため不要。

## 論点3 新しい ADR と EV

推す案: 新しい ADR を起こす(ADR-0114 を補う。置き換えない)。EV は付けない。

- ADR: 「定めないこと」の範囲を広げることは、課さないと決めた事項の追加であり、あとから変えにくい決定である。ADR-0114 は採用済みで本文を書き換えられない。ADR-0114 の見直しの契機にフリーランス法と解釈ガイドラインが無く、新 ADR が契機を持つ必要がある。D・F・G・欄の案の不採用と、F の確認結果もここへ記録する
- EV: 注記は事実の記述で、本標準の判断ではない(ADR-0114 決定1 末尾の先例)。規範を足さないため、根拠水準を付ける対象が無い

採らない案: ADR を起こさず research の記録だけで済ます案(「定めないこと」の拡張が公開の決定から辿れなくなる)。注記に EV を付ける案(事実に暫定のマークを付けると、事実と判断の区別が崩れる)。
