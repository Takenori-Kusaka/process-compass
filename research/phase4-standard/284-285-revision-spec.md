## 4. 書き方の規則(検査で落ちるもの)

- 本文はですます調。**箇条書きと表のセルは、である調か体言止め**(textlint が落とす)
- 1文に読点は3つまで。同じ助詞(「が」「にも」など)を1文に2回使わない
- 節全体に掛かる適用範囲は見出しへ併記する(`### 5.5.4 委任の条件(適用: CL0・R3 の変更)`)。限定を規範と別の段落へ置かない。リスク区分(R)は変更ごと、安全重要度(CL)は案件ごと(`community/scope-marking.md`)
- 実証を欠く値・判断には根拠水準マーク `:::caution[暫定 EV-NNNN / 見直し 2027-03]`(`community/evidence-marking.md`)。番号の割当: A = EV-0046〜0049、B = EV-0050〜0053、C = EV-0054〜0057、D = EV-0058〜0062。**ADR に付けた EV-0040〜0045 と同じ判断を本文で繰り返すときは、新しい番号を振らず ADR へリンクする**
- 実行主体の挙動を制約する新しい規定には実装マーク `<!-- impl IMPL-NNNN target=... state=undelivered note="..." -->`。target は既存の登録済みのもの(`claude-md`、`d0-template`、`config-roles`、`config-gates`、`gate-record-template`、`gate-record-skill`)だけを使う。番号の割当: A = IMPL-0020〜0023、B = IMPL-0024〜0027、C = IMPL-0028〜0030、D = IMPL-0031〜0032。state は `undelivered` にする(テンプレート担当が後で改める)
- 内部リンクは `/process-compass/...` の base パスつき。ADR のスラッグは `src/content/docs/adr/` の実ファイル名を確かめる
- 外部調査の知見を引くときは、本文に `FND-NNNN` を書かず、内容と時点(2026-09 時点)と根拠水準を文で書く。出典の所在は「`research/282-survey-2026-09/`」で示す(公開ページから research/ の個別 ID へは辿れないため)
- 新しいゲート・判定値・会議体・台帳・様式を足さない。足してよいのは ADR が挙げたものだけ
- 既存の ADR の本文は書き換えない
