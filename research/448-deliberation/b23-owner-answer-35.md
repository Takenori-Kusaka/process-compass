# 束 B23 所有者の回答 35(IMPL-0927 の例外承認の行の対象)と議長の裁定

## 所有者の回答(triage の 35。指揮役を通じて受けた)

IMPL-0927(#448)は、故障挿入の試験項目を省く例外承認の行の**対象**に、「基準7」または「安全関連部の検証の記録」を指す語を必須とし、機械で照合する。

束 B20 の1巡目の裁定 7 節(`b20-round1-ruling.md`)で議長が推した案 A(対象の照合は足さず、IMPL-0927 の note と EV-0334 の開示にとどめる)は**採らない**。

## 議長の裁定(2026-11-19)

1. `check-safety-record.mjs` の結果の欄の検査(`resultProblem`)へ、例外承認の行の対象の照合を足す。条件は決定可能なものに限る: 技術負債台帳の当該の行の、対象を書く欄(様式 03 の実際の列名に従う)が、語「基準7」(「基準 7」の表記揺れを含む)または語「安全関連部の検証の記録」を含むこと。含まなければ、その試験項目は記載の欠落に数える(理由の文に行の ID と欠けている語を出す)
2. 機械が見るのは語の有無だけである。対象の文が当該の試験項目を正しく指すか(項目の番号・省く理由の妥当性)は機械で閉じない。確かめる者は独立した評価者と G-7 の判定者のまま。この限界は IMPL-0927 の note と EV-0334 に残す
3. これまで note と EV-0334 にあった「例外承認の行の対象が基準7 を指すことは機械では確かめません」の開示は、上の 1・2 に合わせて改める(語の有無は機械、意味は人)
4. ADR-0221 の決定 5 へ対象の語の条件を足し、「採らなかった案」に案 A(開示だけ)を、採らなかった理由とともに記す。理由: 別のゲート・別の対象の例外承認の行を流用して、故障挿入の全項目を省ける穴が残る。破られたとき失うのは安全関連部の適合の主張の信頼であり、所有者の方針(2026-11-16)の (3) に当たる
5. 様式 03(技術負債台帳)の手引きに、故障挿入の試験項目を省く例外承認の行は対象に上の語を書くことを1行足す。様式の必須欄(`template-fields.yaml`)は増やさない(欄は既にある)
6. 試験: `test-safety-record.mjs` に、対象の語を欠く行(ng)・「基準7」を持つ行(ok)・「安全関連部の検証の記録」を持つ行(ok)の場面を足す。`test-aggregate-wiring.mjs` の 0927 の場面の台帳の行が新しい条件を満たすよう直す。条件を常に真へ変異させると試験が落ちることを確かめる

## 採らなかった案

- 案 A(開示だけ): 上のとおり。所有者が採らないと決めた
- 対象に試験項目の番号まで求める案: 採らない。語の組み合わせの検査は細かい定義を増やし、番号の対応の正しさは結局人が見る。語の有無までを機械にする
