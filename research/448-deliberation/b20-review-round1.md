#### R1-01 環境の欄で「併用」が通る(IMPL-0925)

- **所在**: `template/scripts/gate/check-safety-record.mjs` 95 行の `envProblem`、IMPL-0925 の note、ADR-0221 決定4
- **事実**: `envProblem` を直接呼び、さらに Q1「はい」の案件で様式を埋めて `aggregate-evidence.mjs` を通した。基準7 の欠落は 0 件だった

  | 環境の欄の値 | 結果 |
  | --- | --- |
  | `模擬環境(HIL-2)と本番機(B-1)` | 通過 |
  | `模擬環境(HIL-2)・本番(稼働中)` | 通過 |
  | `模擬環境: 本番と併用` | 通過 |
  | `模擬環境と本番の併用`(試験にある形) | 欠落 |

- **原因**: 正規表現 `(.+?)` が括弧を含む文字列まで識別として受ける。コロンの形は後ろを何でも受ける
- **影響**: note と ADR は「併用は欠落に数える」と書くが、実態は括弧かコロンを使うと通る。本番への故障の挿入を禁じる検査の表示と実態が食い違う
- **直し方の案**: 識別から括弧と区切りの語を除く(例: 括弧の形は `[^()]+` に限り、セル全体で括弧を1組に限る)。コロンの形も同じ文字の制限を掛ける。語の意味までは閉じないので、note を「形の検査で、識別の語の意味は見ない」と改める。試験へ上の3行を足す

## 5. IMPL-0506 の議長の裁定についての判断

**条件つきで妥当とする**。

- **妥当な点**: 軽の裁定の止める条件は、満たさないときに議長が裁定すると定める。軽の裁定の文言は「動くことを確かめる」で、「3 つとも終了コード 0」は I5 の指示の文言である。生の記録で、隔離の有無の両方が終了コード 1、出力の差分 0 行、記録の欠落 17 件、拒否の語 0 件を確かめた。失敗の原因が隔離でないという主張は支えられている
- **開示**: 結果の後に条件を改めたことは、裁定、README、note の 3 か所に書かれており、十分である
- **足りない点 1**: 確かめた使い捨てのリポジトリには `origin` も PR も無いので、集約の `git fetch origin refs/pull/<N>/head` など通信を伴う経路を通っていない。「隔離が手順を妨げない」と言えるのは、通った経路までである。note の開示は「記録のそろった案件」とだけ書き、通信の経路が未確認であることを読み取れない。note へ足す
- **足りない点 2**: ADR-0222 決定17 と矛盾する(R1-09)
