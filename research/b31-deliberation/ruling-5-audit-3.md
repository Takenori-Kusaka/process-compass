# 束 B33 議長の裁定 その5 — U6c・U8 の突合 1巡目(audit-3.md)と実装の返し(impl-u6c-u8.md)への裁定

裁定 2026-11-26。段は軽のまま。

| 所見・返し | 裁定 |
| --- | --- |
| 中1 / 返し② 集約が (A) を満たさない閾値割れの行を (B) で数える | 採る。`ruling-1.md` §0 の一致「帰属は (A) に限る」に揃える。集約は、閾値割れの印を持つ `G-5 PR-<番号>` の行について、対象の PR の写しが範囲にあるときは (A) だけで帰属を数える。(A) を満たさなければ欠落。抜け道ではない(audit-3 観点1)が、表示(ADR-0243 決定5・note・README 項23・手引き)より弱い挙動を残さない。写しは record-copy.yml が `edited_by` つきで作るので、通常の運用で経路は使える |
| 返し① 写しが無い PR は (B) だけで読み、止める側に倒れる | 採らない向きを確かめた。閾値割れの行で写しが範囲に無いときは欠落(止める側)とする。印の無い行・ほかの G-5 の行の扱いは変えない |
| 低1 (B) へ落ちる分岐が試験で固定されていない | 採る。閾値割れの行で「写しが範囲にあり (A) を満たさない → 欠落」「写しが範囲にあり (A) を満たす → 成立」「写しが無い → 欠落」の3場面を足し、陰性の確認をする |
| 低2 U8 の陰性の確認で既存の2場面も落ちる | 直さない。記録に書く |

この直しの差分を2巡目の突合で見て、U6c・U8 の突合を閉じる。
