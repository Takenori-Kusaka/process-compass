# 束 B33 議長の裁定 その4 — 独立の突合 2巡目(audit-2.md)への裁定

裁定 2026-11-26。2巡目は高0・中0・低3。U6a・U6b・U7 とその直しの突合はここで閉じる(CLAUDE.md の2巡まで)。

| 所見 | 裁定 |
| --- | --- |
| 低1 台帳の「無い/読めない」を `cat-file -e` だけで分け、「読めない」の分岐を外しても試験が落ちない | 直さずに開示する。読めないときに「無い」側へ倒れても、全行が PR の中で足した行として (A) が要り、受ける側への抜け道にならない(audit-2 も同じ見立て)。U6c の実装の記録と ADR-0243 の注に1文で書く |
| 低2 ADR-0243 の ADR-0115 との突合の項が、PR の側から偽れる材料を狭く書く | 編集の指摘として直す(U6c の担当が、偽れる材料を audit-2 の列挙に揃える) |
| 低3 README と手引きの「受けないもの」に、基底の構成・台帳を取り出せない場合が抜けている | 編集の指摘として直す(U6c の担当) |

U6c・U8 は新しい実装なので、その全体を1巡目として突合し、その直しの差分を2巡目とする。
