# 束 B33 議長の裁定 その3 — 独立の突合 1巡目(audit-1.md)への裁定

裁定 2026-11-26。材料: `audit-1.md`。段は軽のまま(どの所見も新しい義務・ADR の原則の変更・安全に当たらない)。

| 所見 | 裁定 | 直し |
| --- | --- | --- |
| 高1 効かない回避の手順 | 採る。誤りは議長の `ruling-2-u6a-returns.md` の2 の後段(基底の台帳に先に入れても、`@` の指示者は行に依らず退けられる) | 手引き・README から「7.3 の例外承認を既定ブランチの台帳に先に入れる」を削る。「作成を指示した者を名簿の記載の名で書き直し、失敗したジョブを再実行する」だけを案内する。基底の行で受ける新しい道は採らない(`@` を確かめずに受けると指示者の排除の抜け道になる) |
| 高2 ADR-0243 決定2 の状態の値 | 採る(編集の指摘) | 「状態が有効を指す値(未返却・未回収・有効)のどれかと完全一致する」 |
| 中1 IMPL-0996 の note の現在形 | 採る | 予定の形へ書き換え、理由づけは `ruling-1.md` §1.5 の文だけを残す。ADR-0243 決定2 の「同じ関数で読む」も「段が読む。集約は U6c で同じ関数へ寄せる」へ(U6c の実装で現在形へ戻す) |
| 中2 基底から読む入力が取れないときに作業ツリー側へ倒れる | 採る | `PIT_IN_BASE_CONFIG` が無い・読めない、`PIT_IN_POLICY_BASE` が無い、基底の台帳の `git show` が「読めない」(基底に台帳が無いのとは区別する。無いときは全行が PR の中で足した行で (A) が要るので受けてよい)のときは受けない。ng の試験を足す: PR 側の構成に名簿の人を足した場面、基底の行の期限を書き換えて `PIT_IN_POLICY_BASE` を渡さない場面、基底の構成が無い場面 |
| 中3 「GH_TOKEN を渡さない」の強さ | 文の直しを採る。`persist-credentials: false` は採らない(非公開の採用者の後続の取得を壊しうる。実行で確かめていない) | gate-g5.yml のコメントと README を「環境変数としては段のコマンドへ渡さない。checkout が残す資格情報は段のコマンドからも読める」へ。ADR-0243 に ADR-0115 決定1 との突合を1項足す: 段の出力の行と受否の材料(PR の記録の一時ファイル)は PR の側のコードから偽れる。これは EV-0339 の manual と同じ水準で、新しい抜け道ではない。G-6・承認した者が段の出力と宣言行を読む(manual) |
| 低1 LF の写しの作り方 | 採る | 記録に `git -c core.autocrlf=false archive` を書く |
| 低2 返却済みの行に期限の理由 | 採る | 期限の文は `overdue` のときだけ出す |
| 低3 起動の経路の単独の試験 | 採る | `PIT_IN_EVENT=workflow_dispatch` と整った記録の組の ng を1件足す |

2巡目の突合は、この直しの差分と U6c・U8 だけを見る(CLAUDE.md の2巡まで)。
