## 所見

### X-1(中)guard-write は、NTFS の短い名前と既定のストリームの名前を通す

- 所在: `template/.claude/hooks/guard-write.mjs` の照合(`rel` の算出と `globToRegExp`)、IMPL-0198 の注記
- 事実: ネイティブの Windows(NTFS)の一時の置き場で、フックを Write の入力で起動し、同じパスへ Node の `fs.writeFileSync` で書いた。`.claude/SETTIN~1.JSO`(8.3 の短い名前)と `.claude/settings.json::$DATA`(既定のデータストリーム)は、フックが終了コード 0 で通し、実際に `.claude/settings.json` の中身を書き換えた。大文字と小文字を変えた形は直っている(終了コード 2)。H-2 は「NTFS・APFS は区別しないため強制層の遮断を通りうる」を理由に大文字と小文字を直したが、同じ「別の綴りが同じファイルを指す」類の経路が残る。IMPL-0198 の注記は「照合は大文字と小文字を区別しない(NTFS・APFS で同じファイルを指すため)」とだけ書き、残る経路を開示していない
- 直し方の案: 照合の前にパスを正規化する。`::$DATA` など `:` 以降のストリームの指定を落とす(または `:` を含むパスを拒否する)。対象が既にあれば `fs.realpathSync.native` で長い名前へ解決し、無ければ親のディレクトリを解決してから照合する。`~` と数字を含む成分を拒否する形でもよい。試験に両方の場面を足す。直さない場合は、IMPL-0198 の注記にこの2つの経路を開示する

### X-2(中)第4章 G-5 基準6 の本文と IMPL-0222・IMPL-0312 が、分量の検査は降りていないと書いたまま

- 所在: `src/content/docs/phase4-process-design/gate-criteria.md` 672 行(「分量の上限は…準拠テンプレートへ降ろしていません。上限の規定(IMPL-0222)も、それを検査するジョブ(IMPL-0312)も降りていません。採用者が検査を足すまで、これらは機械では止まりません」)、同 676 行の IMPL-0312、`roles-responsibilities.md` 1409 行の IMPL-0222(「準拠テンプレートに上限の規則も検査も無い」)
- 事実: 本件の IMPL-0501 で、pr-rules が既定ブランチの `instructionAssetLimit.maxLinesPerFile` を超える指示資産を失敗させる検査が降りた。上の3か所はそれと食い違う。また IMPL-0501 は「変えた指示資産だけ」を数え、基準6 の「上限超過 0 件」はリポジトリの全体の文脈ファイルを指すと読めるため、IMPL-0501 で基準6 の何が満たされ何が残るかの整理が無い。ADR-0084 の adopter の表(IMPL-0312「値を定め、検査を足して集約の needs へ入れる」)の求めとの関係も書かれていない
- 直し方の案: 672 行の段落と IMPL-0222・IMPL-0312 の注記を、IMPL-0501 を名指して改める。値は採用者が定める(adopter のまま)、検査は変えたファイルについて降りた、変えていないファイルの超過は拾わない、を書き分ける。基準6 の「0 件」を全体で確かめる部分が残るなら、それを降りていない残りとして表示する

### X-3(中)`.mcp.json` を統制の設定に入れたため、外部ツールの追加に陰性の確認の記録が求められる

- 所在: `template/scripts/gate/check-pr.mjs` の `CONTROL_FILES` への `.mcp.json` の追加、ADR-0126「落ちうる検査と直し方」の「統制の設定の陰性の確認: `.mcp.json` を変えた PR に陰性の確認の節が無い」
- 事実: 陰性の確認(ADR-0073)は、止める仕組みに違反を通して止まるかを確かめる記録である。`.mcp.json` はエージェントに道具を足す一覧で、止める仕組みではない。サーバーを足す PR で「通した違反の場面・結果」に書ける中身が定まらない。裁定 L-4 は指示資産について「誘導層は止める仕組みでなく、陰性の確認の対象にならない」として陰性の確認を課さないとした。L-5 は `.mcp.json` を「統制の設定…へ足す」としたが、陰性の確認を課すかは裁定に書かれていない。結果として、裁定に明示の無い記録の義務が採用者に足されている
- 直し方の案: `.mcp.json` を、陰性の確認を課さない承認の一覧(`INSTRUCTION_ASSET_FILES` と同じ扱いの別の一覧)へ移す。陰性の確認を課すと決めるなら、外部ツールの追加で何を「違反の場面」とするかを ADR-0126 に書き、議長の裁定へ戻す

### X-4(中)常駐の規則 CR-103 の核の文言が途中で切れ、3.11.3 の要の句を照合していない

- 所在: `template/scripts/gate/claude-md-resident.json` の CR-103(核が「…手段が無ければ、止まらないことを行に書き(」で終わる)、`claude-md-resident.mjs` の `extractRules`(行を `` `[機械]` `` で切る)、IMPL-0221 の注記(「check-process-rules が核の文言を照合する」)

### X-8(低)個人用のファイルと指示資産の照合が、大文字と小文字の違いと下位の `.claude/` を拾わない
