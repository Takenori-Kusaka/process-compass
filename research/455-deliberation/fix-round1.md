## 高

- **H-1 直した**。`parseAuditSignatures` は、終了コードが 0 以外で失敗の節(invalid / missing registry signature、invalid attestation)が出力に無いとき `not-run` にする。一覧は「検証: 未実施(検証を実行できなかった(終了コード N。…))」になり、「実施」「検証の失敗」を出さない。実 npm 11.20.0 の依存 0 件の出力で未実施になることを確かめた。鍵の取得の不達の出力も同じ(試験)
- **H-2 直した**(実装を条文に合わせた)。名前ごとに種類(署名の不正・署名の欠落・来歴の証明の不正)を持つ。行の印は「検証の失敗(署名の不正)」の形、行に「検証の結果」の欄、一覧の頭に「種類別: 署名=…・来歴の証明=…・完全性=未実施(node では検証しない。go mod verify は来歴と数えない)」。失敗の節の無い種類は「失敗の報告なし」とし、成功とは書かない。完全性は node では検証しないので常に未実施。CRLF の出力を試験に足した
