## 2. 所見

### 中

#### M2-1 出どころを比べなかった行を、比べて一致した行と区別して表示しない(M-2 の直し)

- 所在: `template/scripts/gate/dependency-provenance.mjs`(`attestedRepoOf`・`provenanceRepo` が、証明の取得の失敗・本文が読めない・SLSA v0.2 の形をすべて null にする。`missing` の対象に出どころが無い)、`dependency-diff.mjs`(公開者の欄は出どころが null なら名前だけ)
- 実態: trusted publishing の版どうし(公開者の名前が双方 `GitHub Actions`)で、証明の取得が時間切れか失敗すると、出どころは null で比べず、印は付かない。行は「来歴の証明あり」「公開者 GitHub Actions」「照会: 取得」となり、比べて一致した行と見分けられない。E-7 のとおり、2023 年の SLSA v0.2 の証明でも同じになる
- 食い違い: M-2 の直しの意図は「trusted publishing の版では名前の比較が識別にならないので出どころで比べる」で、比べなかったときに印が無いのは、比べて変化が無いと読ませる。`fix-round1.md` は「証明の取得に失敗した行(比べない)は拾わない」を「条文・IMPL-1037 の note・ADR-0261 影響で同じに開示した」と書くが、3か所とも「同じリポジトリの中の変更と、証明が無い版の出どころ」だけで、**取得の失敗と読めない形は開示されていない**(記録と実態の食い違い)
- 直し方の案(どちらかで閉じる):
  1. 実装: `attestation === true` で出どころが null の版があるとき、`missing` に「証明の出どころ」を足す(行の照会の欄が「取得(欠け: 証明の出どころ)」になる)。試験を1件足す
  2. 開示: 条文の「来歴の欄」の箇条、IMPL-1037 の note、ADR-0261 影響に「証明の取得に失敗した版と、出どころを読めない形の証明(SLSA v0.2)は比べず、行にその旨を出さない」を足す
- 1. を推す。値の取得の失敗を空欄にせず「取得できず」と出す、という条文(R-8)の型に揃うため

### 低

- **M2-2 印「解決元の変更」と公開者の出どころの比較は、裁定に記録が無い**。1巡目は M-1 で「印の一覧に足すかは議長の裁定」とした。`decision.md` R-6 の印の対象にも追記が無い。G-6 基準5 が読む行の集合を広げるが、「印の付いた行を読む」という義務は変わらず、R-11(解決元を対象外として表示)・R-3(公開者の変更)の範囲の具体化で、裁定と逆ではない。直し方: `decision.md` か `fix-round1.md` に、議長がこの2点を R-3・R-6・R-11 の範囲として採ったと1行残す
- **M2-3 README が「表示の省略は、行の印になります」のまま**(`template/README.md` の依存の一覧の段落)。L-4 の直しで条文は「行に付けられないので一覧の頭に件数で出す」と言い分けたが、README は直っていない。編集の指摘。直し方: 「…対象外は行の印になり、表示の省略は一覧の頭に件数で出ます」。G-6.md の印の列挙に表示の省略が入るのは R-6 の語のままで、食い違いではない
- **M2-4 頭の失敗の件数が、一覧の行に無い名前も数える。種類の無い入力では印が付かない**。`buildReport` の「N 件の名前に「検証の失敗」」の N は `npm audit signatures` が報告した全名前で、差分に無い既存の依存の名前はどの行にも JSON にも出ない(E-4 で 3 件と出て行は 2 件)。1巡目より前からの挙動。また `marksOf` は Map の値が空配列のとき印を付けない(E-8)が、`parseAuditSignatures` は必ず種類を返すので、実際の経路では起きない。直し方: 頭に「うち一覧の行に無い名前: …」を出し、JSON に `failures` を残す。空配列でも印「検証の失敗」を付ける。直さないなら IMPL-1038 の note に「差分に無い依存の失敗は件数だけ」と開示する
- **M2-5 終了コード 0 のとき、来歴の証明を「合格(証明のある版だけ)」と書く**。証明のある版が 0 件でも「合格」になる。限定の句があり、行の「署名・来歴の証明」の欄が証明の有無を出すので食い違いとまでは言えない。直さずに閉じてよい
- **M2-6 ADR-0261 決定2 の句点の欠け**: 「…種類別(署名・来歴の証明・完全性)の結果を頭に出す解析と照会の入力は、…」の「出す」の後に「。」が無い。`test-dependency-diff.mjs` 8 行目の印の列挙の注に「解決元の変更」が無い。編集の指摘
