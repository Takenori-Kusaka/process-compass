# 議長の裁定(#366 文末の肯定の「できます」の、許容と能力の振り分け)

- 審議の重さ: **軽**。2委員(起案・反対)の結論が重なる範囲で決める。表(1.7.1)を変える案は、2委員とも重へ上げる要があるとしたので、本件では採らない
- 入力: `survey-366.md`・`classification-366.json`(75 件、2つの読み手の一致 75/75、文脈の確認で 22 件のうち1件の区分を変更)、`council-01-drafter.md`、`council-02-opponent.md`
- Issue の参照の訂正: #316 の決定は ADR-0086(Issue 本文の ADR-0085 ではない)

## 裁定

1. **許容の 15 件を、1.7.1 のとおりに直す**(2委員)。既存の規定(「できますを許容に使わない」)への回帰の修正であり、新しい決定ではない
   - 型どおりに機械で置き換えない。K-018・K-021・K-054・K-073 は、型どおりに当てると意味か強さが変わる(反対)。1件ずつ、意味と強さを保つ文にする
   - 起案の委員が挙げた R-A の2件(overview.md:310「可能性と能力に限る」に反する)も、同じ扱いで直す
2. **主張の成立の3件**は、1.9(overview.md:474)と同じ「〜に限ります」の形にする(反対)。本文に先例のある形で、要求事項として読まれない。起案の委員の (a) 許容の形は、主張の成立を「してよい」と読ませるので採らない
3. **K-026** の文案は新しい禁止を足すので採らない(反対)。既存の意味を保つ書き換えにとどめる
4. **能力・可能性と条件の項目の 59 件を JIS の形へ寄せること(層2)は採らない**(2委員)。1.7.1 の表を変えることは ADR-0086 決定2 の置き換えにあたり、重へ上げる要がある
5. **機械の検査**: 既知の全件を区分つきで登録簿に置く。新しく現れた文末の「できます/できる」、つまり登録簿に無い出現で検査を落とす(2委員)。主語と述語で警告する形は、取りこぼしと誤検出が多いので採らない(反対)。1.7.4 を、この検査の所在に合わせて改める(起案)
   - 登録簿の区分は AI の2つの読み手と裁定役による振り分けであり、文脈で確かめたのは 22 件だけ。残る 53 件は人が読んでいない。この旨を根拠水準のマークで開示する(起案は人の読みを前提としたが、人の作業を本件の前提にはしない。開示で足りる)
6. **「〜られる」**: 機械の抽出へは広げない。誤検出が多い(反対)。7.11 の要求事項1 と K-073 は表に無い形(overview.md:295 に反する)なので、許容の形へそろえる(2委員)。7.11 を要求の形へ改めることは採らない(重へ上げる要がある)
7. **一致率の記録**: 目隠しでの一致 75/75 と、文脈の確認で 22 件のうち1件を変えたことを対にして、EV-0172 へ記録する(起案)。読み手の作業記録が空で、目隠しは指示と出力の違いからしか裏づけられないことも開示する
8. ADR-0117 を新設し、登録簿の検査と採らない案を書く

## 採らない案

| 案 | 理由 |
| --- | --- |
| 型どおりの機械の置き換え | 4件で意味か強さが変わる |
| 主張の成立を許容の形で書く | 主張の成立を「してよい」と読ませる |
| 59 件を JIS の形へ寄せる | 1.7.1 の表の変更で、重へ上げる要がある |
| 主語と述語で警告する検査 | 取りこぼしと誤検出が多い |
| 「〜られる」を機械の抽出へ広げる | 誤検出が多い |
| 7.11 を要求の形へ改める | 新しい義務で、重へ上げる要がある |
| K-026 の新しい禁止 | 裁定の範囲の外 |

## 独立の突合への裁定(2026-11-11、`crosscheck.md`)

- **高(K-058、tailoring-guide.md:943)**: 戻す。裁定は K-058 の書き換えを定めていない。書き換えの結果は、採用済みの ADR-0113 決定2(CL0 で規制業でない案件は G-8 の受容で出荷できる)を変え、準拠テンプレートとも食い違う。裁定の外の変更が原因なので、重へ上げるのではなく、変更を取り消して高の原因を除く。K-058 は、もとの文のまま登録簿へ区分つきで載せる
- **中**: K-018 は、新しい禁止の形と範囲の拡大を取り消し、もとの意味と強さを保つ形にする。K-061 は、主張の中身に足した限定を取り消す。K-015 は、1.7.2 の因果の文の規定に合う形にする
- **低の6件**: 実装の担当が直す。同じ頁に同じ文が2度出ると検査を通る点は、出現の回数まで照らす。EV-0172 には、作業記録が空であることを開示する
