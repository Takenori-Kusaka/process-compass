## 2. 項目ごとの降ろし方

### 441-a 一発承認率 : template の機械の検査(template の項目として残す)

- 理由: 分母・分子は PR のレビューの状態から決定できる(差し戻し率 IMPL-0516 と同じ材料で、集約は承認レビューの写しを既に読む)。決定可能な条件なので機械の検査にできる。`adopter` は不可: 理由を書けない(ADR-0084 決定4)。降ろさない(manual のまま)も不可: 決定可能なものを人に委ねる根拠が無い
- 3問の(3)が軽い(合否に波及しない)ので、重要度は低い。だが「安さを理由にしない」。降ろせるものは降ろす
- template の項目(本束で触らない):
  1. 集約に一発承認率を足す。窓は構成の `observationWindow`、最小標本数は IMPL-0516 と同じ定数。窓の中の件数が最小標本数に満たなければ「判断に用いない(N件)」と出し、値を出さない
  2. 試験の対: 違反(29件の窓で値を出す)/適合(30件以上で値を出し、29件で「用いない」と出る)
  3. 合否に使わないので、判定・欠落には数えない(IMPL-0159 と同じ扱い)
- 既定の窓の食い違い: 第4章の既定は四半期、template の共通の窓は既定2か月(IMPL-0516 の note が既に開示)。一発承認率も同じ窓に従い、その旨を note に引き継ぐ。新しい義務ではない

### 441-b AI 生成行の短期書き換え率 : `plan=adopter`(案A)

- 理由(新 ADR に書く): (i) template に行単位の帰属が無い(帰属は `Co-Authored-By` のコミット単位だけで、スカッシュ取り込みでは人の行と AI の行が1コミットに混ざる)。算出は推定の積み重ねで、機械が決定できる条件ではない。(ii) 合否に使わず傾向の確認だけ(gate-criteria.md「合否条件にしてよい指標」)。(iii) 案B(コミットのトレーラ単位でみなす)は、混在を EV で開示しても値の意味が弱く、「機械が出した値」として権威を帯びる害の方が大きい。ADR-0079 決定4 の「帰属は推定」とも合う
- 採用者に求めること(新 ADR に書く): 集計の手段に窓と最小標本数を備え、満たない値を用いない。行の帰属の取り方(推定)と14日を、採用者が記録に残す
- 規定は課したまま。降ろさないのは template の実装だけ
- 採らない案: 案B。理由は上記(iii)と、ADR-0137 の置き換えを要するのに得られる信頼が増えないこと。短期書き換え率を指標から外す案も採らない(ADR-0079 の決定の変更。議論の対象になれば重へ上げる)
- 案Aの弱点(反対の委員が問う点): 採用者が窓の無い値を出しても照らす先が無い。応答: 要求事項3 は採用者にも直接課され、確かめる者は G-1 の閾値の記録(IMPL-0977)の席。機械で閉じない統制は manual/adopter で開示するという所有者の方針に沿う。照らす先の欠落は、マークの note に「機械は検出しない」と明記して開示する
- 根拠水準マーク: 新たに足す必要は無い(EV-0144 が14日、EV-0145 が窓と30件を既に開示)。ただし「推定の帰属で採用者が出した値の確度」は未検証なので、新 ADR の本文で E0 と書き、EV は増やさない(値や閾値を新設していないため)

### 441-c トレーラの読み方 : template の機械の検査(template の項目として残す)

- どちらへ揃えるか: 末尾の段落へ(`doneTasks` を `lastParagraph` に揃える)。根拠は `git-strategy.md:125`・`ci-gates.md:168` の規範が末尾の段落だと定めており、next.mjs が規範から外れているため。本文を変える必要は無い(規範は既にある)
- template の項目:
  1. `next.mjs` の `doneTasks` を autonomy.mjs の `specTrailersOf` と同じ読み方にする(同じ関数を共有するのが望ましい。2通りの実装を残さない)
  2. 試験の対: 違反(本文の途中の `Spec:` 行を済みと数えない)/適合(末尾の段落の `Spec:` を数える)
  3. 既存の履歴に本文の途中のトレーラだけを持つコミットがあれば、次の一手が「未済」に戻る。移行の注意を template の手引きに1行書く
- 補足: 規範はあり、食い違いは実装側の欠陥。これは規定の新設ではなく編集の指摘に近いが、実装の挙動が変わるので議長が独立の突合へ回すか判断する
