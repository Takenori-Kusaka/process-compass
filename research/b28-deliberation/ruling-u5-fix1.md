| 所見 | 裁定 | 直しの中身 |

| H-1 変更の一覧の一致の固定が `measureCommitSize` に及ばない | **採る** | `measureCommitSize` の変更の一覧を別の作り方にすると落ちる試験を足す。足した後、IMPL-1029 の note が実態と合うことを確かめる(合わなければ note を直す) |

| M-2 同じ PR が企画書の枠の行を消す・読めない値にすると拒否が外れる | **採る(機械で閉じる)** | 枠の数は**基底の企画書**から読む。基底で読めないとき(初めて枠を置く PR)だけ head から読む。基底で読めた枠を head で読めなくする PR が 7.9.4 の行を足しても、基底の枠で数える試験を足す。「読めない枠は注意で通す」は、基底でも head でも読めないときに限る |
| L-1 この PR の行は `PR #<番号>` で見分ける | 採る(note) | IMPL-0630 の note に開示する。新しい義務は課さない |
| L-2 コミットを名指す過去の行の単位が集約と違う | 採る(note) | note に、check-pr が集約より多く数えうる場面(拒む向き)を開示する。単位の作り方は変えない |
| L-3 | 直さない | 回帰の全量で捕まる。マークの test= は増やさない |
| L-4 見出しの番号 | 採る(編集) | 付け直す |
