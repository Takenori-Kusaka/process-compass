# 束 B28 U5 の「議長へ返す点」への裁定

裁定 2026-11-20。対象は `impl-u5.md` の「議長へ返す点」1〜7。U5 は軽(B21・B22・B26 で裁定済みの実装)。

1. **IMPL-0836 の表示**: delivered・machine を保つ。機械が数えるのは段のコマンド(アダプタ)・閾値(構成の `ci`)・採用者が `thresholdFiles` へ登録したファイルで、**登録の有無は機械が確かめない**ことを note に書く(実装のとおり)。採らない: (a) 規則集の登録だけを別のマーク(adopter)へ分ける(マークを増やす。登録は既存の `thresholdFiles` の仕組みで、新しい統制ではない)。(b) undelivered へ戻す(段のコマンドと閾値は機械が数えており、実態より弱く書くことになる)。独立の突合で、表示が実態より強く読めないかを見てもらう
2. **過去の PR の承認の数え方**: note の開示で受ける。check-pr は承認を多く数える向き(行使を少なく数える)で、拒否が弱く働く。出荷の集約は独立した人の確認の規則で数え直すので、G-7 の材料では漏れない。集約と同じ数え方に揃える案は採らない(過去の PR の全コミットの情報を PR ごとに引く。決定可能だが、G-5 の検査の時間と API の呼び出しが PR の数に比例して増える)
3. **移行の注意の置き場**: README の「テンプレート更新時の既存案件への影響と運用ルール」へ1項を足す(`answers-1.md` §3 の指揮役の決定と同じ扱い。CHANGELOG.md は新設しない)。「枠を超える 7.9.4 の決裁は G-5 で止まる」と書く。直しの段で足す
4. **ADR-0217 の影響の節**: 採用済みの ADR は書き換えない。U6 で新設する ADR-0243 に、「ADR-0217 の影響の節の『止めるのは 7.9.4 の行の欠落だけ』を、枠の超過の拒否(IMPL-0630)について置き換える」と記す
5. **要求事項4(事後レビュー)**: manual のまま(裁定どおり)
6. **集約の表示の文**: 変えない。拒否の所在は IMPL-0630 の note と README の項で足りる。採らない: 表示に拒否の所在を足す(suite の固定の期待を改める理由が弱い)
7. 直しは要らない
