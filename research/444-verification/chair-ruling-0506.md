# IMPL-0506 の確認の条件についての議長の裁定

日付: 2026-11-18

## 事実

隔離のもとの自身の手順で、`aggregate-evidence.mjs` は終了コード 1 を返した。手順の条件の文言は「3 つとも 0」であり、**文言のままでは満たしていない**。隔離なしの対照の実行も同じ終了コードで、出力の差分は 0 行だった。失敗の原因は、確認に使った使い捨てのリポジトリの記録の欠落 17 件である。

## 裁定

条件の目的は「隔離が手順を妨げないこと」である。終了コード 0 は、記録のそろった案件を前提にした代理の指標だった。そこで、この項目の条件を「隔離のもとの終了コードと出力が、隔離なしの対照と一致する」へ改め、IMPL-0506 を delivered へ移す。

## 開示

- 条件は結果を見た後に改めた。元の文言と、改めた理由を、この記録と IMPL-0506 の note に残す
- 記録のそろった案件で集約が終了コード 0 になることは、隔離のもとでは確かめていない
- 独立の突合で、この裁定を確かめる対象に含める

## 採らない案

- undelivered のまま残す案: 隔離による拒否が無いことを対照で確かめており、未達の理由が隔離の性質と無関係である
- 元の文言を満たしたと書く案: 事実に反する
