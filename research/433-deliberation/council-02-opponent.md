# #433 会議体(軽) 委員2 反対の委員

- 日付: 2026-11-11
- 立場: 起案されそうな案の弱点を突く。欠陥と認めるものは認める
- 読んだ所在: survey-433.md 全体、roles-responsibilities.md:1993-2003・2052、gate-criteria.md:84、template-repository.md:604・645-646、phase4-process-design/overview.md:440-442、ADR-0055(0055-team-change-points.md:93-105)、ADR-0110(0110-mixed-change-point-direction-and-signer.md:48)、Issue #432 の本文

## 論点1 案(c-1)を採るか

- **推す案**: c-1 の前半(基本の要件 a-2 を本文で閉じる)だけを採る。後半(決定者本人の行の要件を「課さない」と明記する)は採らない
- 前半を採る理由: 2003 行は記名者に「すべての行の要件」を求めながら、表記の変更の行の要件を第5章の表へ預けている。これは 1.8 の第2項(overview.md:441「要求事項の内容を…委ねない」)に反する欠陥であり、認める。基本の要件は gate-criteria.md:84「名簿の変更は、効力を持つ記録(D-0 の決定の記名)として…」が既に課しているため、新しい義務ではない(survey §5 a-2)
- 置き場: 2003 行は第4章 84 行を引く形にする(c-3 の考え)。3.13.3 へ同じ文を書き写すと、1.7 の「同じ事項は1か所」に反し、将来の食い違いの種になる。ただし 84 行は「D-0 の決定の記名」とだけ書き、**だれの記名か**(表1 の決定者か)を言っていない。引く前に、84 行の主語の欠けを直す必要がある。これを直さずに引くと、空の参照を本文の中で循環させるだけになる
- 後半を落とす理由
  1. **自己承認の穴を規格として認める**。S3・S4(survey §4.2)は、決定者が自分の行へ名簿外のアカウントを足し、またはアカウントを置き換える変更である。課さないと明記すれば、決定者は1人の記名で、自分の承認・判定として数えられるアカウントを替えられる。G-6 の独立した確認と G-7 の判定の帰属を、本人の一存で結び付け直せる(survey §6.1)。これは 2001 行「新任の決定者が、自分の任命を自分の記名で確定してはならない」と同じ構図の穴を、本文で合法にすることになる
  2. **「迂回があるから名目」という推論が逆**。迂回(U1・T2)が見つかったなら、塞ぐか開示するのが筋である。錠を外す理由にはならない。しかも迂回の経路は記録上「決定者の変更」として改訂履歴に出る(survey §6.3)。表記の変更として黙って通す c-1 の後半より、まだ痕跡が残る
  3. **テンプレートの採用者の保護を後退させる**。本文が「課さない」と書けば、テンプレートの照合は 1.8 の第1項(overview.md:440「要求事項を加えない」)と緊張する。照合を外せば、今 S2〜S4 で止まっている変更が通るようになる。判断軸は信頼性であり、この後退は採れない
  4. **「課さない」は軽の範囲を超える決定である**。新しい義務ではなくても、自己承認を許すかどうかは 2001 行の原則の射程を決める。軽で「課さない」を確定させるのは、重で決めるべき原則の先取りである
- 新しい義務か: 前半は否。後半は義務ではないが、原則に関わるため軽で確定させない

## 論点2 本人の行(a-3)・差し替えの禁止(a-1)・迂回の封鎖(c-2)

- **推す案**: a-1・a-3・c-2 は**重へ上げるべき**。a-1・a-3 は本文に無い拒否・記名を課す新しい義務(survey §5)。c-2 は ADR-0055 決定3(0055:93-105「前任の決定者の記名と理由を要する」)の変更に及ぶ。どれも CLAUDE.md の重の条件に当たる
- 重で決めるまでの間: a-3 を「課さない」とも「課す」とも本文に書かない。第5章 604 行の「要る」は 1.8 の第3項(overview.md:442)が禁じる形なので、テンプレートの挙動の説明(平叙)へ改め、本文の根拠が審議中であることを暫定の根拠水準マーク(ADR-0026)で開示する。照合そのものは外さない
- **#432 へ寄せることには反対**。理由
  1. 論点の機構が違う。#432 は兼務の照合の鍵(席の組だけで人を含まない)と、発生で入った兼務の扱いである。#433 は人とアカウント・氏名の結び付けである。外部の規準も別筋になる(役割の分離か、アカウントの管理か。survey §6.3 は候補を挙げただけで原典は未確認)
  2. #432 の「決めること」は2つあり、どちらも #433 の a-1(差し替えの禁止)を含まない。寄せると a-1 が議題から落ちる
  3. #432 は範囲が広く、結論が遅れる。その間、645 行の迂回の案内と S3・S4 の穴の議論が止まる
- ただし、原則の食い違いは防ぐ。「決定者が自分に関わる変更を自分で決めない。1名の体制は 2001 行の自己の任命の例外に揃えて記録・開示する」という原則の部分だけは、1つの ADR で一度に決め、#432・#433 の重の会議体がそれぞれ引く。各 Issue の個別の論点(兼務の鍵、差し替え、迂回)は分けて審議する
- c-2 の弱点(重へ渡す): 「決定者その人を替える」正当な引き継ぎ(前任が新任へ渡す)と、U1 の自己の付け替えは、機械では区別できない。c-2 を文字どおりに課すと、2名の体制の正当な交代まで第三者の記名を要することになる。新任の側の確認(副署)で足りるか、を重で比べる必要がある
- 第5章 645-646 行は、今の時点で欠陥と認める。氏名の訂正の手段として、本人の行の要件を避ける経路を案内している。重の結論を待たずに、少なくとも「この経路は表記の変更の記名の要件を経ない」旨と、記録の理由に同じ人である旨を書く要件の所在を明らかにすべきである(案内の撤去か、開示か、の選択は重で決める)

## 論点4 3.13.4 記録7 の「名簿への追加」の欠け

- **欠陥と認める**。2052 行は区分しない行の記名の要件を「各行の規定による(3.13.3)」とするが、3.13.3 に名簿への追加の要件は無い。#433 と同じ形の欠けである
- **推す案**: 後継の Issue へ回さず、#433 の中で扱う。名簿への追加は U1 の迂回の第一歩(名簿外のアカウントの新しい行を足す)であり、論点2 と切り離せない。別の Issue に回すと、迂回の議論が片側だけで閉じる
- 直し方: 引き先を 3.13.3 から第4章 84 行へ改める(軽)。ただし 84 行は論点1 のとおり記名者を特定していない。追加の記名者を「表1 の決定者」と特定するのが今の第4章の読みの範囲に収まるなら軽、決定者本人以外の記名を求めるなら新しい義務であり重
- 新しい義務か: 引き先の直しは否。追加の記名者に本人以外を求めるなら重へ上げるべき
