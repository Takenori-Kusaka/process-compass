# #434 経路2 会議体(重) 委員: 現場

- 立場: #296 より前の旧い構成から版を上げる採用者。移行で詰まらないこと、手数、案内の分かりやすさを重視する
- 判断軸: 信頼性。変更量の少なさは理由にしない
- 読んだもの: `survey-434.md`(3.2 の 2a〜2i、5 節)、`survey-434-2-external.md`(S1〜S4・横断の整理)、`decision.md`、`council-01-drafter.md`、`council-02-opponent.md`

## 現場から見た経路2 の実態

- 採用者が自然に取る手は「2人目の高橋に Dupont を確認してもらう」の1つである。2b・2f では、その確認の変化点が「AI の名義の記名を受け付けない」の文で拒否される(survey 3.2)。採用者は、何を直せばよいかをこの文から読めない
  - 拒否の文は、旧い旗が原因であることを言わない
  - 今の回避は2つある。2d は2人目を足す前にしか使えない。2h は委任の規則と承認の記録を失う(survey 3.2 の「分かったこと」)。どちらを選んでも、現場では詰まるか、記録を失う
- したがって、経路2 で問うべきは次の2点である。1つ目は、採用者の自然な一手を通すこと。2つ目は、通したことが記録の上で後から説明できること

## 推す案: 2-D(外部の示唆による限定つき)

- 中身: 本人以外の確認を含む変化点では、既存の記録の記名者を、その確認を足した後の構成で照らす。この確認は、**その日付に行った独立の照合**として扱う。旧い記録の時点へ日付を戻して数えない
- 理由
  1. 現場の手数が増えない。採用者の自然な一手(本人以外の確認)が、そのまま救いの条件になる。2b・2f の両方が救われる(反対委員の論点3)。2i が示すとおり、到達する最終の状態は今と同じである(survey 3.2 の 2i)
  2. 救いの根拠が、実在する本人以外の記名にある。記名者と日時は、確認の変化点の記録に既に残る。旧い旗は、誰がいつ立てたかを記録から確かめられない(survey 5 節 2-B の欄、反対委員の論点3 の理由1)。外部の示唆でも、旗は「署名を示すだけの表示」と同じ性格を持ち、それだけでは確認として成立しない(外部 S3 の 6.14 の示唆)
  3. 後の確認を、その時点の独立した照合として記録する形は、外部の4文書と整合する(外部「横断の整理」の後付けの項、S3 の 6.15、S4 の 8.8)。日付を戻さないので、Contemporaneous と衝突しない
  4. 旧い記録を書き換えない。2-A' のように、2名の名簿の記録へ本人の記名を書き込まない。訂正では元の記録を見えるまま残すという外部の原則(S3 の 6.15)にも合う

## 2-D に付ける条件

- C1 確認の変化点の差分に、この確認によって照合が通る既存の記録を列挙して表示する(例: 規則 DR-001・変更種別「表示文言」・委任の席)。確認する人が、自分が何を裏付けるかを見てから記名できるようにする。数えるだけで見せない形は、外部 S3 の 6.15 にある「確認の結果の肯定的な記述」を欠く
- C2 拒否の文を直す。旧い記録の無い確認が原因のときは、その旨と「本人以外の名簿の人が確認すれば通る」ことを案内する。案内の分かりにくさは、現場の詰まりそのものである
- C3 確認の変化点の外で拒否が起きないかを、実行で確かめる。たとえば確認待ちの間に、高橋が記名する無関係の変化点を出す場面である。survey 5 節は、2-D の弱点を「確認の変化点の外を救わない」とした。起きるなら C2 の案内で「先に確認する」へ導く。導けない場面が出たら、重大度「高」として扱う
- C4 1名の注記(「記録してください」。2d)は残す。2人目を迎える前の推奨の手順として、移行の案内に書く。ただし、これを義務にはしない(2-C を採らない理由と同じ)
- C5 ADR-0111 決定6 の「作られた変化点の前の構成で照らす」との関係は、新しい ADR で補う。照らし直しは、本人以外の確認があったときに限る。資格を得るのは既存の記録の記名者だけで、確認する人は前の名簿で照らす(反対委員の論点3)。採用済みの本文は書き換えない

## 他の案を落とす理由

- 2-B(旧い旗を既存の記録の照合に限って有効とみなす): 救いの根拠が、記名の無い旗にある。2f では、作られた時点で効いていなかった確認を、効いていたとみなすことになる(反対委員の論点3 の理由2)。外部の4文書も、旧い記録を無条件で有効とみなす立場を取らない(外部「横断の整理」)
- 2-B を弱める案(暫定の許容+証拠+是正の道筋+構成が変われば外れる): 採らない。理由は3つある
  - 現場に、作れない証拠を求めることになる。旗の時点で正当に立てられたことを示す記録は、そもそも存在しない(survey 3.2 の模擬の前提)。証拠の書面を作れば、採用者に新しい義務を課すことになる
  - 「是正の道筋」は、本人以外の確認そのものである。弱めた 2-B は、行き着くと 2-D と同じ確認を要する。そのうえ、暫定の間の扱いと失効の条件を、別の規則として持つことになる
  - 暫定の許容の役目は、既に確認待ちが担っている。確認待ちの間は、契約検査と集約が落ち続ける(ADR-0111 決定6)。その上へ暫定の効力を重ねても、取り込みも出荷もできない。それでいて、委任の席を旗で保つ前例だけが残る(反対委員の論点3 の理由3)
- 2-A(今のまま): 2b・2f の詰まりが残る。現場は 2h へ追い込まれ、承認の記録を失う
- 2-A'(移行時に本人の記名の記録へ書き換える): 2名の名簿の記録に本人の記名を書くことになり、AR-4 の不変条件が崩れる。そのうえ 2f を救わない(survey 5 節)
- 2-C(移行を拒否して案内する): 採用者に手順を1つ足す。G-6 と ADR-0111 決定5(記録の無い確認も確認待ちとして受け付ける)に反する。2f を救わない

## 根拠水準

- 2b・2f・2i は、旧い構成を模したもので確かめた場面である(survey 3.2)。実在の旧い構成では確かめていない。外部の根拠は医薬品 GxP からの類推である(外部の冒頭の限定)。EV-0229 の見直しか新しい EV で開示する
