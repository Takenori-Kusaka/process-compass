## 3. 割れた点と裁定

### 3.1 一般原理「遮断は害を直接止める条件に限る」を新 ADR で立てるか

**裁定: 立てない。ADR-0152 は起こさない。** 重へ上げない。

根拠:

1. **原理は既存の遮断を不適格にする**(反対委員の反例は成立する)。RC-05 の停止は費用と暴走の抑止、RC-06 の合否は網羅の代理指標で、どちらも「害を直接止める」に収まらない。起案は「適合の主張の信頼に響く条件」を足して救ったが、この語は範囲を決められず、どの定数も入れられる。原理として働かないか、働けば既存の遮断の再審査(ADR の原則の変更=重)を呼ぶ。どちらに転んでも、この Issue の軽の範囲では価値を生まない
2. **所有者の方針**(細かい定義を増やさない。条文は結果と証跡まで)。受け入れ条件1「定数ごとに遮断・観測のどちらで使うかの基準と理由を決める」は、**定数ごとの理由**を登録簿の行に書けば満たせる。横断の原理は要らない。新しい定数を足す者は、登録簿の行を書く時点でその列を埋めるので、参照の置き場は登録簿で足りる(起案の「事例に埋もれる」懸念への答え)
3. **破られたとき誰が何を失うか**で見ても、定数ごとに違う。規模・所要(RC-01・02)を遮断にすれば採用者が較正の母集団を失う(ADR-0047)。カバレッジ(RC-06)を外せば、適合の主張の受け手が、独立レビューを欠く体制の補償を失う。失うものが定数ごとに違う以上、1つの原理で裁かず、行ごとに書くのが正確
4. **例外承認で受けられるか**: 採用者が使い方を変えたい場合、値は組織が定める値(1.7.7)であり、強める向きは自由、緩める向きは記名(IMPL-0274・IMPL-0346)で受けられる。新しい条項は要らない

ADR-0047 の害(打ち切られた分布から上限を導くと毎期縮む)は、RC-01・02 についての記述として残す。他の定数に一般化しない。

### 3.2 登録簿に列を足すか、行の文言を補うか

**裁定: 列を足す(「超過・未達のときの扱い」)。閉じた語彙は置かない。自由記述で、正本の条項を引く。**

- 反対委員の代案(「担っている保証と、移った先」のセルへ補う)は採らない。理由: 3.12.12 要求事項5 は、このセルを「定数を外しても失わない保証」と「移った先」として使う。使い方を混ぜると、外すときに何を移すのかが読めなくなる
- 反対委員が挙げた「様式の変更(ADR-0040 の両方向の検査)を起こす」は、事実として当たらない(F6)
- 起案の閉じた6語は採らない。新しい定義が増え(所有者の方針)、語彙に収めること自体が意味の分類を強いる。語に収まっても実装と一致する保証にならない(反対委員の論点2-3)
- 反対委員の懸念「表示と実態の食い違いを生む装置」への手当て: 列は**要約**であり、正本は各セルが引く条項と実装マークであると表の注に書く。各セルは条項か IMPL を必ず引く
- 機械の検査: 能力に依る行(RC-01〜08)の新しい列が空でないこと(存在だけ。決定可能)。意味の一致は人が読む(機械で閉じない統制。§5 に開示)

### 3.3 起案の弱い点の裁定

**(a) 基準6 の「未設定は判定しない」と 1.7.7 の「記録が無いとき=基準を満たさない」**

- **起案の (a) 案(基準6 を「組織が定める値」型にせず「未設定は判定しない」と書く)は採らない**。1.7.7 の例外を作り、3.11.4 要求事項1(上限を設ける)を条文の上で空にする。統制を緩める向きの文言の変更になる
- 起案の (b) 案(未設定を失敗にする)も採らない。ADR-0126 が既に採らない案にしている(F2)。覆す材料は無い
- **食い違いは、実は無い**。1.7.7 の「当該の基準を満たさない」は、**満たしたと記録しない**ことであって、機械が失敗にすることではない。3.11.5 の要求(`roles-responsibilities.md:1617`「上限内とは記録しない」)とテンプレートの表示(「上限未設定。上限内とは記録しない」)はこの読み方で一致する。残るのは、**満たさないまま G-5 の集約が通る**という機械で閉じない部分で、これは IMPL-0222 が undelivered として表示し続けている。足りないのは、その帰結を G-5 の側に一文で書くことだけ(§4.1)

**(b) カバレッジの合否と較正の母集団の説明の実証の欠け**

- 起案の「カバレッジの合否は母集団を打ち切らない」は、**標準に書かない**(3.1 で原理を立てないため、この説明を条文の根拠に使わない)。よって新しい根拠水準マークも要らない
- ただし審議の中で、別の形の打ち切りが見つかった。EV-0143 の差し替え条件は「採用組織が記録した基準値と、出荷後の欠陥の流出の関係」である。下限を満たさない変更は出荷されないので、この観測は**下限を満たして出荷された変更に限られる**。下限を下げてよいという根拠は、この観測からは得にくい(ADR-0047 の「毎期縮む」ではなく、下げる向きの根拠が出にくい偏り)。EV-0143 の本文へ、この限界を一文補う(§4.4)

| --- | --- |
| 登録簿の新しい列が能力に依る行で空でない | 機械(存在) |
| 列の記述が実装の挙動と一致する | manual。列の注で「正本は引いた条項」と開示 |
| 指示資産の上限の未設定で G-5 が通る | 機械で閉じない(ADR-0126)。IMPL-0222 の undelivered と §4.1 の3の文で開示 |
| 企画書の基準値と構成の下限の一致 | 現状は閉じない。IMPL-TMP-337-1 の undelivered で開示。降ろすときは machine |

## 6. 採らない案

| 案 | 出した者 | 理由 |
| --- | --- | --- |
| 一般原理「遮断は害を直接止める条件に限る」を新 ADR(ADR-0152)で立てる | 起案 | RC-05・RC-06 が原理に収まらず、働けば既存の遮断の再審査(重)を呼ぶ。定数ごとの理由で受け入れ条件を満たせる(§3.1) |
| 登録簿の閉じた6語の語彙と、その機械の検査 | 起案 | 新しい定義が増える。語に収まっても実装との一致を保証しない(§3.2) |
| 使い方を「担っている保証と、移った先」のセルへ補う | 反対 | 要求事項5 のセルの意味(外しても失わない保証)と混ざる(§3.2) |
| 基準6 に「未設定は判定しない」と書く | 起案 (a) | 1.7.7 の例外を作り、3.11.4 要求事項1 を条文の上で空にする。緩める向き(§3.3) |
| 指示資産の上限の未設定を G-5 の失敗にする | 起案 (b) の検討 | ADR-0126 が採らない案にした。覆す材料が無い |
| 「カバレッジの合否は較正の母集団を打ち切らない」を条文の説明に置き、EV を付ける | 起案 | 原理を立てないので根拠に使わない。別の偏り(下げる向きの根拠が出にくい)は EV-0143 へ補う(§3.3) |
| RC-06(90% を含む)を観測へ下げる | Issue の含意 | 適合の主張の受け手が、独立レビューを欠く体制の補償を失う。ADR-0028 決定6 と食い違う |
| 90% を引き上げる・義務にする | (両委員が予防的に却下) | E0(EV-0143)の値を義務にする |
| 全定数を観測に統一/遮断に統一 | 受付の候補 | 前者は統制を緩め、後者は ADR-0047・0058 の収縮を再発させる |
| 使い方を採用者が選ぶ欄 | 受付の候補 | 自己申告で外せる(ADR-0044 決定4 と同型) |
| ADR-0065 の読み替えの新 ADR | 受付・起案 | ADR-0088 決定5 と `gate-criteria.md:1028-1036` が既に定める。決定の重複 |
| 代償措置を別の機構(事後の抜き取りなど)へ置き換える | 受付の候補 | 効果を測った資料が無い |
| IMPL-0312(変えていない指示資産の超過を拾わない)を強める | 反対の見落とし | 本 Issue の範囲外。plan=adopter で開示済み。変えない |
| 論点4: チームの数で境界を引く | 所有者のコメント(#338 から) | 人数で足りない事象の記載が無い。チームの定義を置けば採用者への新しい義務になる(重)。材料なしに重を開かない。新しい事象が出たら別 Issue で重として受け付ける |
| 論点5: 価値責任者×技術判断者の兼務の 10名以上の禁止を問い直す | 所有者のコメント(#338 から) | 撤廃は統制を緩める向きで、撤廃を支える観測も新しい材料も無い。ADR-0082 決定1 を維持し、見直しは EV-0156 の時期(2027-10)に委ねる。能力依存の定数ではなく組織構造の定数で、本 Issue の基準では裁かない |

## 7. 既存の ADR・条項・語彙との突合

| 相手 | 結果 |
| --- | --- |
| 1.7.7(ADR-0097)値の3つの型 | 整合。基準6 の上限を「組織が定める値」と明記し、未設定=満たしたと記録しない、とした。起案 (a) を採らないことで例外を作らない |

| ADR-0084(テンプレートは上限の値を定めない) | 整合 |
| ADR-0047・ADR-0058 | 整合。RC-01・02 の記述として残し、一般化しない。§4.1 の4は 2128 の段落の範囲を明記するだけ |
| ADR-0058 決定6(登録簿の補い) | 整合。列の追加はその範囲 |

| ADR-0082 決定1・EV-0156 | 維持(論点5) |
