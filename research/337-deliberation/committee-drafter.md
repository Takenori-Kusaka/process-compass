# #337 起案委員の意見(論点1〜3)

日付: 2026-11-17。担当: 起案委員(軽の会議体)。反対委員のファイルは読んでいない。読んだ実物: `intake.md`、RC 登録簿(`roles-responsibilities.md` 3.12.12)、`gate-criteria.md` の G-5 基準3・6 とその注、ADR-0058 決定1・ADR-0065 ステータス、`evidence-ledger.md` の EV-0143。template/ は未初期化で、実行での確認はしていない。

## 0. 結論(先に)

- **統制を緩める向きではない**。どの定数の現在の使い方も変えない。RC-06(カバレッジの合否)を観測へ下げる案は採らない。議長の重への再判定を要する条件(採用者への新しい義務・ADR の原則の変更・緩和)には当たらない、というのが起案の見立て
- 案は3点。(A) 登録簿 3.12.12 に「使い方」の列を足す。(B) G-5 基準6 の文言を、値の所在(組織が定める)と合わせて直す。(C) 新 ADR 1本(ADR-015x)で、遮断の基準を一般化して記録し、ADR-0047 決定1 の一般化と ADR-0065 の読み替えを同時に記す
- 論点3 は ADR-0065 を無効にしない。新しい条項も足さない

## 1. 論点1・2 使い方の基準

### 1.1 基準(ADR-015x の決定1の案)

> 遮断(合否)に使う定数は、超過が害を直接起こす条件、または適合の主張の信頼に響く条件に限る。母集団を観測して較正する定数(規模・所要・見積・帯域)は、遮断に使わない。

- 根拠: ADR-0047 の「較正の母集団が上限で打ち切られ、毎期縮む」(`gate-criteria.md:2128`)と、ADR-0058 決定1。両 ADR は規模(RC-01)の個別の決定で、基準としては書かれていない。一般化して記録するだけで、RC-01 の扱いは変えない
- カバレッジ(RC-06)は比率の合否で、母集団を観測して較正する定数ではない。ADR-0047 の害の形(打ち切られた分布から導く)に当たらない。よって合否のまま残す。この説明は反対委員に突き合わせてもらう点(カバレッジの未達は PR を止めるので、実際に母集団を打ち切らないか)
- 採用者が RC-03・RC-04 などに自ら合否を置くことは、標準は禁じない(基準値は組織が定める。1.7.7)。標準が書くのは、標準の既定として遮断に使わないこと

### 1.3 G-5 基準6 の文言(B)

- 変える文の所在: `gate-criteria.md:737`(基準6 の値の欄)「1ファイルの分量の上限超過 0 件」
- 新しい文の案: 「変えた指示資産の分量が、組織が定めた上限を超える件数 0 件(上限を定めていない場合は判定しない。参考の値は置かない)」
- 理由: 現行は「標準が遮断として上限を課す」とも読める。実装の事実(IMPL-0501・0222・0312)は、値を採用者が置いたときだけ変えた指示資産で失敗、である。条文を実装の事実へ合わせる。これは**緩和ではなく、実装との食い違いの解消**(編集の指摘に近い)。ただし「値が未設定のとき基準6 を満たすか」は文言上の新しい帰結になるので、1.7.7 の「組織が定める値」の行(記録が無いとき=基準を満たさない)との整合を確かめる必要がある。1.7.7 の通りなら「未設定=満たさない」になり、実装(判定しない、undelivered 表示)と食い違う。ここは起案委員にも未解決で、(a)基準6 の後半を「組織が定める値」型にせず「既定値なし・未設定は判定せず未達の表示」と書く、(b)実装を未設定で失敗にする、の二択が残る。起案は(a)を採る。(b)は、準拠テンプレートが値を定めない決定(ADR-0084)と、採用の初日に全員が値を置かされる義務の新設に当たるため採らない

### 1.5 採らない案と理由

1. 全定数を観測に統一: RC-05 の停止・RC-06 の合否は害や信頼を直接止める。統制を緩める向き
2. 全定数を遮断に統一: ADR-0047・0058 の収縮が再発する
3. 使い方を採用者が選ぶ欄: 自己申告で外せる(ADR-0044 決定4 と同型)
4. 使い方を定数ごとに自動で切り替える仕組み: 決定可能な条件に収まらず、実証も無い
5. 使い方の変更を再評価の「残す・外す・移す」へ加える: 3.12.12 は能力の前提の変化への対応の手続で、使い方の変更はそれと別の軸。手続を足すと条項が増える
6. 値の列(カバレッジを「観測」に下げる、RC-07 を標準の既定で遮断にする)も採らない

## 2. 論点3 ADR-0065 の代償措置

### 2.1 事実の整理

- ADR-0065 は無効ではない。影響5つ目は ADR-0088 決定5 が置き換え済み。決定1〜5 は維持される
- Issue の「不揃いを前提にしたまま」の核は、**代償措置の手段が能力依存の RC-06(EV-0143: E0)であるのに、90% が遮断として働く**点。ただし `gate-criteria.md:1030` は 90% を参考の値とし、基準値は組織が定めると書く。遮断になるのは、構成(`ci-strict`)が導いた値を採用者が置いた場合である。この導出が参考の値を既定値として置くのか、は未確認(intake §5 の実行での確認(b))
- 90% の根拠水準は EV-0143 で既にマーク済み(E0、見直し 2027-10)。新しい EV は要らない

### 2.2 案

- 条文: 代償措置が担う結果は「独立の欠落を補う、機械の検査の強化」までとし、手段の値(90%)は参考の値のままとする。**ADR-0065 の本文は変えない**。ADR-015x の決定2として「ADR-0065 の代償措置の手段である下限 90% は、遮断のときも参考の値であり、採用者が較正する。較正しても未達の解消に数えない(ADR-0028 決定6)」と記す。これは現行の `gate-criteria.md:1028-1033` の書き方を ADR にも明記する、実質は読み替え
- 90% が合否として働く点は変えない。観測へ下げない。理由: 代償措置は、確認者を置けない体制の G-6 未達を補う唯一の機械の強化で、下げれば、適合の主張を受け取る側が失うものが生じる。効果を測った資料は無い(`gate-criteria.md:1475`)ので、強化を緩める根拠も、強める根拠もない。開示(EV-0143)で足りる
- 値が不適切だと考える採用者は、基準値の較正(1.7.7)と記名で受ける。新しい条項は要らない

### 2.3 採らない案

1. 代償措置の下限を観測へ下げる: 統制を緩める。実証が無いときは強化を維持する側へ倒す(ADR-0082 の原則と同じ向き)
2. 代償措置を別の機構(事後の抜き取りなど)へ置き換える: 効果を測った資料が無い
3. ADR-0065 を新 ADR で全面的に置き換える: 無効でない決定を置き換えると、決定3(CL1 以上は S0 でも G-6 を適用)の連鎖の確認が増える
