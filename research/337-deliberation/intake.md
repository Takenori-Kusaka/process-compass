## 1. 論点ごとの現状(実物の所在)

### 論点1 「200 行の上限は遮断し、PR の規模は遮断しない」

前提が部分的に古い。

- 指示資産の 200 行は **参考の値**(RC-07、EV-0088。`phase4-process-design/roles-responsibilities.md:2033`、同:1556 以降)。ADR-0084 は「分量の上限の既定値(200 行)を置いて降ろす」案を採らず(`adr/0084-check-strength-plans-and-resident-rules.md:145`)、準拠テンプレートは **値を定めない**(IMPL-0222・IMPL-0312、`community/implementation-ledger.md:132,149`)
- 遮断は、採用者が `.claude/guard.json` の `instructionAssetLimit.maxLinesPerFile` に自ら置いた値だけで起きる。しかも **変えた指示資産だけ**(IMPL-0501、`gate-criteria.md:743`)。値が未設定なら「上限未設定」と出して判定しない。変えていない超過は拾わず、undelivered で表示し続けている(IMPL-0312)
- 標準側の G-5 基準6 は「1ファイルの分量の上限超過 0 件」と書く(`gate-criteria.md:737`)。**条文は遮断の語を持つが、値は組織が定める**。「標準が 200 を遮断に使う」のではなく「採用者が値を置けば基準6 が遮断する」。一方、PR 規模の側は ADR-0047「上限を遮断として運用してはなりません」(`gate-criteria.md:2128`)。2つの条文の向きが逆に読める余地は **残る食い違い**
- PR の規模(RC-01)は、ADR-0058 決定1 で遮断から確認と区分 R2 へ移した(`adr/0058-size-over-is-confirmed-not-blocked.md:44`、IMPL-0880)。委任の規模条件(IMPL-0741)は、超過を委任の対象外にする。これは遮断ではなく **適用範囲の外**。使い方は観測・確認・適用範囲・遮断・停止の複数あり、2値(遮断/観測)に切れていない

### 論点2 能力依存の定数ごとの使い方の実態(受け入れ条件1)

登録簿は RC-01〜RC-12(`roles-responsibilities.md:2027-2038`)。列は「定数・前提・担っている保証と移った先・能力に依るか」で、**使い方(遮断/観測)の列は無い**。実態(文書上):

| ID | 定数 | 現在の使い方 | 所在 |
| --- | --- | --- | --- |
| RC-01 | 規模 400行・15ファイル | 確認+区分 R2(遮断しない)。委任は範囲外 | ADR-0058、IMPL-0049・0880・0741 |
| RC-02 | レビュー30分 | 規模の確認の自己申告 | 同 |
| RC-03 | 見積 8時間 | 理由の記録(目安)。見積の列の無い様式では適用なし | ADR-0098 |
| RC-04 | 帯域 3〜4件/日 | 観測(判定完了時間・SLA) | `roles-responsibilities.md:2030` |
| RC-05 | 自己修正 3回・2回 | 停止(保留へ)。値は構成で変えられ、緩める向きは記名(IMPL-0274) | IMPL-0275・0276 |
| RC-06 | カバレッジ 80%/90% | 基準3 の合否(遮断)。値は組織が定める基準値で、標準のは参考の値 | `gate-criteria.md:1028-1033`、IMPL-0346 |
| RC-07 | 指示資産 200行 | 値は採用者が置く。置けば変えたファイルで失敗 | 上記 |
| RC-08 | 層数 3 | 観測(検出能力の測定) | `roles-responsibilities.md:2034` |
| RC-09〜12 | 窓・周期 | 能力に依らない。引き上げ・引き下げの条件 | ADR-0081 ほか |

見立て: 「揃っていない」のは事実だが、揃えるべきかは別。ADR-0047・0058 が示した害(遮断は較正の母集団を打ち切り、上限が毎期縮む)は、母集団を観測して較正する定数(規模・所要)で起きる。比率の合否(カバレッジ)には同じ形では当たらない。この説明が成立するかは、会議体の検証事項。

### 論点3 ADR-0065 の代償措置の妥当性

- 内容: 確認者を置けない体制の G-6 は未達。代償措置として CI を強める(カバレッジの下限の参考の値 80%→90%。`gate-criteria.md:1028-1030`)。下限は未達の記録に属し、基準値と分ける(IMPL-0346・IMPL-0736)。**代償措置の終了は ADR-0088 決定5 が置き換え済み**(ADR-0065 ステータス欄)。「初期化の直後の下限 90% が残る」(影響5つ目)は既に置き換わっている
- 能力依存との関係: 代償措置の手段は RC-06(能力依存。EV-0143 は E0、`evidence-ledger.md:232`)。**根拠の無い 90% を遮断として使う**ことが、Issue の言う「不揃いを前提にしたまま」の核。ただし 90% は参考の値で、基準値は組織が定める(`gate-criteria.md:1028`)。遮断になるのは組織が置いた値で、標準が値を課すのではない
- 代償措置の効果を測った資料は、2026-09 時点で見つかっていない(`gate-criteria.md:1475`)。開示は既にある
- 見立て: 論点は「ADR-0065 が無効」ではなく「代償措置に使う定数の使い方の基準」。ADR の本文は書き換えず、必要なら新 ADR で置き換える

### 論点4(コメントa) チームの数で境界を引く案

- 現状: 境界は人数(3名、10名)。#296 の L-6 で「組織が境界を定める形は課さない」「チームの数を軸にする案は別 Issue」(`research/296-deliberation/decision.md:18,73`)。ADR-0082 も #338 に残した(同 ADR:54)。#338 は経路を持たないと決めて閉じられた(コメント)
- 数えるのは表5 の人(AI と外部の確認者を数えない)。チームの定義が標準に無い。定義を置けば **採用者への新しい義務**になりうる
- 本 Issue には人数で足りない事象の記載が無い

### 論点5(コメントb) 価値責任者×技術判断者の 10名以上の禁止

- 現状: ADR-0082 決定1。3.5 の X1〜X4 のどれにも当たらず、G-3 と G-2・G-4 が互いを確認しない、人数で独立の意味が変わる根拠も外部の閾値も無い、と自認している(同:56)。撤廃は統制を緩める向きで、撤廃を支える観測が無いため残した。エンジンの `mustSplitFrom` は変えていない(同:148)
- 本 Issue の定数の枠組みでは **組織構造の定数**で、能力依存ではない。#296 L-6 が登録簿に載せないと決めた(`adr/0079-coverage-scope-approval-binding-self-heal.md:71`)。コメントの「能力依存の定数を扱う本 Issue と合わせて」は、手続の都合であって、同じ基準で裁けるという意味ではない
- 禁止の種別は、遮断ではなく **構成の拒否**(規則データ)

## 2. 審議の重さの案

| 論点 | 案 | 理由 |

| 1・2・3 | **軽**(起案と反対の2委員) | 新しい義務を課さず、既存の使い方の整理と開示。安全・法令に当たらない。ただし RC-06 を遮断から観測へ下げる結論に傾けば、統制を緩める向きで、重の条件(採用者への義務・ADR の原則)に当たりうる。そのときは議長が再判定する |

## 3. 3つの問いへの案(条項を足さずに受けられるか)

方針: 条文は満たすべき結果と残る証跡まで。手順は手引き。珍しい構成は第7章の例外承認。安全・取り消せない操作・適合の主張の信頼に響くものだけを細かく書く。

### 論点1〜2 使い方の基準

- 問1(結果と証跡): 結果は「遮断は、害を直接止める条件に限る。較正の母集団を観測する定数を遮断に使わない」(ADR-0047 の原理の一般化)。証跡は登録簿の行。登録簿に「使い方」の列を足すのは、条項の新設でなく ADR-0058 決定6 の登録簿の補い(様式の欄)
- 問2(例外承認): 採用者が値を置いて遮断にしたい場合は、置けばよい(基準値は組織が定める。1.7.7)。標準が直すべきは、参考の値を遮断として読ませる書き方だけ。G-5 基準6 の文言を、値の所在(組織が定める)と合わせて読めるよう直す(編集に近い)で受けられる見込み
- 問3(破られたとき誰が何を失うか): 規模・所要を遮断にして破られると、採用者が較正の母集団を失い、上限が毎期縮む(ADR-0047)。カバレッジの比率を観測へ下げて破られると、適合の主張を受け取る側が、独立レビューを欠く体制の補償を失う。前者は手引きでよく、後者は条文に残す
- 降ろし先の候補: 機械の検査=登録簿の各行に使い方の値があること・語彙に収まること(存在・構文だけ)。様式の欄=登録簿の列。手引き=遮断/観測の選び方。使い方が妥当かの意味判断は機械にせず、manual か adopter で開示する
- 採らない候補: ①全定数を観測に統一(RC-05 の停止・RC-06 の合否は害を直接止める。統制を緩める) ②全定数を遮断に統一(ADR-0047・0058 の収縮が再発) ③使い方を組織が選ぶ欄(自己申告で外せる。ADR-0044 決定4 と同型) ④定数ごとに自動で切り替える仕組み(決定可能な条件に収まらず、実証も無い)

### 論点3 ADR-0065 の代償措置

- 問1: 条文は「独立の欠落を補う機械の検査の強化」まで。手段(90%)は参考の値。証跡は未達の記録と下限の由来(IMPL-0346)で既に残る
- 問2: 値が不適切と考える採用者は、基準値の較正(1.7.7)と記名で受ける。新しい条項は不要
- 問3: 代償措置が効かないとき失うのは、適合の主張を受け取る側の信頼。ここは細かく書く側に残す
- 見立て: **条項を足さずに受けられる**。必要なら読み替えの新 ADR 1本
- 採らない候補: 代償措置を別の機構(事後の抜き取りなど)へ置き換える(効果を測った資料が無い。EV の開示で足りる)

### 論点4 チームの数

- 問1: 条文に書く結果が無い(事象が未確認)。問2: 複数チームの小規模組織は、境界を越えた規則の適用を例外承認で受けられる見込み。問3: 破られたとき失うのは、10名以上の列の規則(別チームのレビュー等)が担う独立。失うのは利用者・出荷先
- 見立て: **条項を足さずに受けられる見込みが高い**。ただし事象の確認が先
- 採らない候補: チームの数の定義を標準へ置く(定義の増加。テンプレートが標準を体現するため連動して増える)、組織が境界を定める形(自己申告で外せる。#296 L-6)

### 論点5 10名以上の禁止

- 問1: 条文は「禁止」という結果。証跡は D-0 の記録。問2: 特殊な構成(小さなチームが複数ある 10名以上)は、禁止を残したまま例外承認で受けられる。問3: 破られたとき失うのは G-3 の独立。ただし X1〜X4 に当たらず根拠も無いので、重い安全上の損失とは主張できない
- 見立て: 新材料が無ければ **維持**(ADR-0082 の裁定を覆す材料が無い)。緩める場合も新しい義務は課さないが、統制を緩める向きなので、2027-10 の見直しを待たずに外す根拠が要る
- 採らない候補: 禁止を非推奨へ下げる(撤廃を支える観測が無い)、全規模で禁止する(根拠が無い)

## 4. 外部の調査の要否

- 論点1〜3: **不要**。新しい義務を課さず、規格の引用も要さない。遮断と観測の一般論は ADR-0047・0058 の外部調査と 282 の調査(`research/282-survey-2026-09/README.md`)で足りる
- 論点4・5: 重として開く場合は **要る**。調べるのは、組織の規模・チーム数で職務分掌の独立を変える規格や実務があるか(ISO/IEC/IEEE 12207、ISO 9001、SOC 2 の職務分掌、DORA など)。無いこと自体が「境界を人数で引く根拠が外に無い」という結論になりうる(ADR-0082 は「外部の人数の閾値も見つかっていない」と書く)。ただし新材料が示されないまま取り上げるなら、外部の調査も省く
