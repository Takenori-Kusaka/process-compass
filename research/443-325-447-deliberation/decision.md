## 1. #443 2.10.6 の記録と IMPL-0899 の確かめる者

### 1.1 原文で確かめた事実

- 2.10.6 の順序の3項は主語を持たない。手順1(SC-B から先に削る、SC-M に手を付けない)を実行し、手順1 の不足で 7.6 を起票するのは価値責任者である(2.10.6 第3段落、7.6 段階の表の「起票する者: 価値責任者」)

- 7.6 の報告の項目1 は「何が基準を満たさないか。数値で示す」、項目4 は「3案」。手順1 で何を削ったかは項目に無い
- 実装マークの「確かめる者」は、実行のときに確かめる者を書く(IMPL-0851「価値責任者(SC-P へ項目を追加する調整を記録するとき)」、IMPL-0220「当該ゲートの判定者(判定記録を書くとき)」)。規定を負う行為者の自己の確認の形が先例である
- ADR-0173 結果:「IMPL-0899 の順序の違反を誰が確かめるか(他の席に置くと新しい義務になる)」。同 採らなかった案:「IMPL-0954・IMPL-0899 を adopter にする — 束 C の裁定の前提を取り違えている」
- ADR-0175 決定2:「テンプレートが欄・手引き・検査のどれかで届けられるものは (d) にしない」

### 1.2 割れた点の裁定: 確かめる者

**採る: 価値責任者(手続を開始し、手順を選ぶとき)**。

- IMPL-0899 が追う規定の行為者は、価値責任者だけである(評価・手続の開始・手順1 の順序・不足の起票)。手順2・3 の権限の割当は、note 自身が「第7章 7.3・7.6 のマークが追う」としている。0899 の確かめる者を 7.6・7.3 の判定者へ置くと、0899 の範囲の外の席に確かめる行為を割り当てることになり、ADR-0173 の「他の席に置くと新しい義務になる」と両立しない
- 起案の「確かめは決定する者の決定に含まれる」は、手順2・3 の判定者が**自らの判定**の正しさを確かめる限りで正しい。しかしそれは 7.6・7.3 のマークの範囲であり、0899 で名指す理由にならない。しかも手順1 だけで吸収した経路には後段の判定者が現れず、確かめる者が空になる
- 自己の確認は弱い。弱さは EV-NEW1 で開示する(1.4)。破られたときの損失は期日の延伸・範囲の縮小で、取り消せる(所有者の方針の問い3 で、細かく書く対象に当たらない)。SC-M を黙って縮める経路は、2.10.5 の表の行4 と契約の段落が既に経路を定めている

**採らない**:
- 後段の判定者(7.6 の判定者・7.3 の権限を持つ者)を確かめる者にする(起案・受付の案 A)。上の理由
- plan=adopter にする(起案)。ADR-0173 の採らなかった案と真っ向から食い違う。ADR-0175 決定2 にも反する(手引きで届く部分がある)
- 案 C(後段の判定者が前段の不足を確かめて決める、の1文)。両委員とも不採用。判定者に確かめる行為を課し、手順1 だけの経路には届かない
- 案 D(見込みの評価の記録)。両委員とも不採用。EV-0193 の差し替え条件(通知から手続の開始までの時間・通知の無い期日超え)は、既存の記録(調整の記録・7.6 の起票の時刻・見込みの報告の Issue の起票と閉じの時刻)で観測できる
- 案 E(別の席に置く)。ADR-0094 に反する
- SC-M の削減と順序の関係を添える編集(受付 1.5)。起案は「SC-M を順序の外で自由に選べると読める」として不採用、反対は議長に委ねた。**添えない**。意味を変えうる文は編集の指摘に当たらない。迷いは手引き(7 節)で解く

## 2. #325 2.10.5「3.10 の事前レビュー期間の仕組みへ載せる」

### 2.1 原文で確かめた事実

- 2.10.5 の原文で載せる対象は「滞留した項目の一覧と、スコープ3層の現状」であり、**調整ではない**。IMPL-0954 の note の「調整を非同期に確認し、3.10 の…へ載せること」は原文の言い換えの誤り(反対の委員の指摘どおり)
- 3.10.2 は判定日 T と決定者を前提にする(T−5営業日の公開・記名のレビュアの指名・T の判定は決定者)。一覧と現状の確認は、判定日も決定者も持たない
- 7.6 の段階の表で、SC-M を判定する者は段階1・2 が「事業決裁者の記名の決定」、段階3 が B-2。段階2 は「非同期の持ち回りでよい」。事業決裁者の決定は B-1〜B-4 の上程ではなく、3.10.1 の適用範囲に入らない。**受付・起案の文案「SC-M の増減は、その上程に 3.10 が掛かる」は段階1・2 で偽**
- SG は B-2 の「判定する事項」(SG-0 / SG-1 / SG-2)で、B-2 の上程として 3.10.1 の内(両委員が一致。原文で確認)
- ADR-0019 決定5:「棚卸しのための会議体を設けない。滞留の一覧を非同期に確認し、既存の事前レビュー期間の仕組みへ載せる」。対象は「滞留の一覧」で、2.10.5 と同じく調整ではない

### 2.2 割れた点の裁定

**(a) 3.10 を掛けない理由**: 採るのは反対の案「判定日と決定者を持たないため」。起案・受付の理由「ADR-0019 決定7(単独判定)と衝突するため」は採らない。その理由は「調整を載せる」という原文に無い読みから出たもので、ADR に書くと、後に 2.10.5 と決定7 の関係を誤らせる

**(b) ADR-0019 決定5 の後半の扱い**: 起案は「読みの確定」、反対は「主眼を保つ撤回」。採るのは**撤回**。原文の後半は滞留の一覧に 3.10 を掛ける指示で、どう読んでも実行できる読みが無い。読みの確定と呼ぶと、決定5 の後半が今も生きていると読まれる。前半(会議体を設けない)は主眼として維持するので、ADR の原則の変更に当たらない。ADR-0019 の検討した選択肢(B-2 に棚卸しの議題を足す案を 3.7.5 により退けた)と同じ向きの判断である

**(c) 文案**: 反対の案の書き方を採る。SC-M を一律に 3.10 へ結び付けず、上程になる場合だけを書き、段階1・2 は掛からないと明記する。起案の文案は (2.1) のとおり偽を含むので採らない

**採らない**(両委員の一致を含む):
- 案 B(3.10.1 に調整を足す): 調整のたびに5営業日と記名のレビュアを課す。新しい義務。2.10.4 の「定例の開催まで待たせない」と ADR-0019 決定7 に反する
- 案 C(文を削るだけ): 「掛けないと決めた」ことと、上程になる調整に 3.10 が掛かることが読めなくなる
- 案 D(note の開示を続ける): 実行できない手順を条文が指したまま残る
- 段階1・2 の事業決裁者の決定に事前レビュー期間を設ける: 本件の範囲外で新しい義務になる。SC-M の縮小が持ち回りで決まる経路の信頼は、7.6 の記名の決定と判定記録が受ける。反対の委員の気付きとして 6 節に残す

- 5.4.5 条件5「5.4.7 の能力維持措置が実施済みである | 実施記録がある」は、上表の引き上げの判定の時点にだけ掛かる。登録した変更種別は「上表の手続に代えて」5.5.4 の登録の判定で L3 になり、条件5 を経ない。同じ段は「5.4.7 の能力維持措置は、登録した変更種別にも適用する」と書く。**義務は掛かるが、照らす時点と証跡が無い**(反対の委員の指摘どおり。起案の「5.4.5 条件5 が既に前提とする」は登録の経路では成り立たない)
- テンプレ11「確認の周期と後継」には同型の行(演習の頻度・力量の確認の周期など)があり、注記「値は組織が定める値であり、本標準は値を定めない(第1章 1.7.7)」と、様式の読み方の注記7(空欄は層1 を無効にしない)を持つ。既存の行は適用の限定を持たない
- ADR-0175 影響:「IMPL-0978(5.4.7)は本件で決めない。採用者への新しい義務に当たるため、重の審議へ送る」。IMPL-0978 の note:「頻度の値と記録の欄を足すことは採用者への新しい義務になる」

### 3.2 割れた点の裁定

**(a) 層1 の行の表示の条件**: 起案「L2 以上を適用する範囲がある場合」、反対「登録した変更種別がある場合だけ」。採るのは**起案の条件**(常時の表示は両委員とも採らない)。

- 標準の側では、L2 以上は 5.4.5 の上表の引き上げでも適用される。反対の条件は準拠テンプレートの構成(登録した変更種別が L3、他は L1)に限れば正しいが、標準の様式に書くと 5.4.5 で L2 に上げた採用者を落とす
- 準拠テンプレートでは「L2 以上を適用する範囲」は「登録した変更種別」と一致する。両案はテンプレートの上では同じ結果になる。反対の案は template の項目の実装の条件として採る(7 節)
- 常時の表示は採らない。L1 だけの採用者に、掛からない義務の不履行を表示する(偽の否定的な開示)。5.4.7 と 3.4.3 の適用範囲を変えることになる
- 限定は行の中に書く(適用範囲の書き方 #226)

**(b) 案 C(常時の実施の記録と頻度切れの表示)**: 採らない(反対の案)。

- 5.4.7 に記録の語は無く、条件5 は登録の経路で来ない。常時の記録の置き場を定めることは、登録の経路の採用者に証跡を作る務めを新たに課す。**新しい義務である**。起案の「無い」は採らない
- 新しい義務を課すか否かは所有者の方針の事項なので、議長は裁定しない(4 節の問い)

**(c) 登録の経路で照らす時点が無いこと**: 起案は C で閉じる、反対は未決として所有者に委ねる。採るのは**未決として開示し、所有者へ問う**。「課さないと決めた」とは書かない。5.4.7 の本文に「未決」を書く(3.10.2 の「短縮の下限は…まだ定めていません(未決)」と同じ形)。IMPL-0978 は undelivered のまま表示する

**(d) ADR-0175 の分類の誤りの範囲**: 採るのは反対の案「一部だけ誤り」。

- 誤り: 「頻度の値の欄を足すこと」を新しい義務と数えた点。頻度を組織が定める義務は 5.4.7・3.4.3 に既に在り、層1 の行は置き場の定めである
- 誤りでない: 「実施の記録の欄」と、登録の経路で実施を照らす時点を足すことは新しい義務である。ADR-0175 の分類はこの点で正しい
- ADR-0175 の本文は書き換えない。ADR-0178 決定3 で一部を置き換え、ADR-0175 のステータスの節に後継を書く(adr/index.md 規則3・5)

**(e) 層1 の行は新しい義務か**: 両委員とも「置き場の定めで、新しい義務ではない」で一致。採る。ただし反対の委員の区別を記録する: 既に記名済みの層1 に新しい行が空欄で現れ、保証の開示が変わる。これは義務の増加ではなく**開示の増加**である。空欄は層1 を無効にしない

**採らない**(両委員の一致を含む):
- 案 A(何もしない): 頻度の置き場すら無いまま残る
- 案 D(登録の判定で照らす): 新しい義務。所有者への問いの選択肢として残す
- 案 E(数値の頻度): 3.4.3 の決定と理由に反する。**課さないと決めた**(3.4.3 の決定を維持)
- 案 F(adopter): ADR-0175 決定2 に反する。層1 の様式はテンプレートが持つ
- 案 G(頻度切れで登録した種別を止める): 止める根拠が無い。ADR-0081 の停止の列挙を変える。**課さないと決めた**
- 頻度を満たせない期間を 7.3 の例外承認で受ける: 5.4.7 は 7.3 を名指していない。足すと新しい条項になる(ADR-0175 の 0766 と同じ理由)
- 類型E の演習を 5.4.7 の機会に数えてよい条件を手引きで示す(起案): 実施の記録を課すかが未決のまま、数え方だけを先に示すと、照らす時点の無い機会の数え方が独り歩きする。所有者の回答の後に決める。それまでは受付 3.2 のとおり同一視しない

## 4. 所有者へ問う点

**問い(#447)**: 登録した変更種別(L3)の経路で、5.4.7 の「AI を用いずに実装または調査する機会」を確保したことを、本標準は照らすか。

## 7. ADR-0178(新設)の要旨

- 番号: 0178。題: 「期日に間に合わない見込みの評価と順序の記録を課さず、棚卸しの確認を事前レビュー期間へ載せず、AI を用いない実施の頻度の置き場を層1 に置く」
- ステータス: 採用(2026-11-17)。ADR-0019 決定5 の後半、ADR-0173 決定3 の一部、ADR-0175 の影響の IMPL-0978 の分類を一部置き換える。軽の審議の結論(Issue #443・#325・#447、`research/443-325-447-deliberation/decision.md`)
- 決定:
  1. 2.10.6 の見込みの評価そのものと順序を記録する義務は課さない。選んだ手順は既存の3記録に残る。順序を守ったかを確かめる者は、手続を開始し手順を選ぶ価値責任者とし、後段の判定者・別の席に確かめる務めを課さない(EV-NEW1)。IMPL-0899 は手引き(handoff-reference)へ降ろす
  2. ADR-0019 決定5 の後半「既存の事前レビュー期間の仕組みへ載せる」を撤回する。滞留の一覧とスコープ3層の現状の確認は判定日と決定者を持たず、3.10 が前提を欠くためである。前半(会議体を設けない)は維持する。B-1〜B-4 へ上程する調整には 3.10.1 のとおり 3.10 が掛かり、7.6 の段階1・2 の事業決裁者の決定には掛からない
  3. 5.4.7 の頻度の置き場をテンプレ11 の層1 の行とする(適用: L2 以上を適用する範囲がある場合。空欄は保証の開示の項目7 に表示し、止めない)。ADR-0175 が IMPL-0978 を新しい義務とした分類のうち、頻度の置き場の部分は誤りだったので改める。常時の実施の記録と登録の経路で照らす時点は新しい義務で、ADR-0175 の分類はこの部分で正しい。これは未決とし、所有者へ問う
- 課さないと決めたこと: 見込みの評価の記録、順序の記録、後段の判定者・別の席による順序の確認、滞留の一覧への 3.10 の適用、3.10.1 への調整の追加、5.4.7 の頻度の値、頻度切れでの停止、頻度を満たせない期間の 7.3 の例外承認
- 未決: 登録の経路で 5.4.7 の実施を照らす時点と常時の実施の記録(所有者へ問う)
- 採らなかった案: 1〜3 節の「採らない」を表にする(後段の判定者を確かめる者にする案、plan=adopter、案 C・D・E、SC-M の編集の1文、決定7 を理由にする案、「読みの確定」と呼ぶ案、起案の 2.10.5 の文案、3.10.1 の拡張、文を削るだけの案、常時の表示、登録した変更種別だけを条件にする案(標準の側)、案 C(#447)、案 A・D・E・F・G(#447)、類型E の数え方の手引き)
- 影響: 本文3頁(lifecycle・human-ai-boundary・deliverable-templates)、IMPL-0899・0954・0978・0070・0071 の note、IMPL-NEW1・NEW2、EV-NEW1、impl-targets.yaml の3項目、impl-inventory.yaml の3項目。template の項目は8 節
- 機械で閉じない点: 順序の遵守(manual)、実施の中身(manual)。機械にできるのは IMPL-NEW2 の空欄と範囲の有無だけ(決定可能)
