## 1. #443

### 争点への答え

1. 案 C(後段の判定者が前段の不足を確かめて決める、の1文)は採らない。理由は、既存の禁止(「順序を入れ替えてはならない」)の主語を明示するだけとは読めないため。「確かめて決める」は確かめる行為を課す。しかも確かめの材料(7.6 の報告の項目1 状態・項目4 3案)は、判定者が判定のために元々読むものである。禁止が後段の判定者を既に縛っている(手順2 は事業決裁者または B-2、手順3 は 7.3 の権限者が決める。2.10.6 の第3段落)ので、足しても得るものが無く、義務かどうかの解釈の争いだけが残る。新しい義務かどうかが割れる文を、効果が無いのに足さない
2. EV-0193 の観測は欠けない。差し替え条件は「滞留の通知が出てから価値責任者が手続を始めるまでの時間」と「通知の無い期日超えの件数」であり(lifecycle.md の EV-0193 を確認)、手続の開始の終点は最初の調整の記録かエスカレーションレポートの起票の時刻で取れる。「見込みなし」と評価した事実は、観測の入力ではない。「見込みなしと評価したのに期日を越えた」は、通知の無い期日超えまたは 7.6 段階1 の報告の遅れとして、既に現れる。評価の記録は課さない(案 D 不採用)。D の損失は、価値責任者が評価のたびに記録を書くことで、得るものは観測の終点の別の取り方にとどまる
3. 両立する。ADR-0173 の「他の席に置くと新しい義務になる」は、決定する者でない席(内部監査・SG の判定者・計画の担当者)に確かめを課す場合を指す。後段の判定者は、順序の違反が起きる決定そのものを下す者である。自分の決定が順序に反しないことを確かめるのは、決定の責任の一部で、確かめを別に課すのではない。ただし「確かめる者」の名指しは note への書き込みであって、条文の義務を増やさない形でなければならない(下の note)

## 2. #325

### 争点への答え

1. 「後半の読みの確定」である。ADR-0019 の決定5 は前半「棚卸しのための会議体を設けない」が主眼で、後半「既存の事前レビュー期間の仕組みへ載せる」は、その前半の実現手段(会議体を開かずに非同期で意見を集める)である。同じ ADR の決定7(SC-P・SC-B の増減は価値責任者の単独判定で、逸脱として扱わない)と、後半を単独判定の調整全部に掛ける読みとは、両立しない(3.10.2 は T−5営業日の公開と記名のレビュアの指名を要する)。両立する読みを定めるのは原則の維持であって変更ではない。前半と決定7 は変わらない。割れたら議長が裁定し、採らない案を記録する
2. SG は 3.10.1 の内にある。原文で確かめた: roles-responsibilities.md の会議体の表で B-2 の「判定する事項」は「SG-0 / SG-1 / SG-2」(行952)、決定する事項に「SG-0〜SG-2 の判定」(行1007)。したがって SG は B-2 の上程で、3.10.1 の「B-1〜B-4 の全ての上程」に入る。7.6 の経路のうち、段階3 に達して B-2 へ上がるものも同じ。段階2 の事業決裁者の持ち回りは B-2 の上程ではないので 3.10 は掛からない。書き方は、会議体の判定に上がることで限定する。SG・B-2 と書き分けずに「会議体の判定に上がる調整」と書けば足りる

## 3. #447

### 争点への答え

1. 層1 に行を足すこと(案 B)は新しい義務ではない。頻度を組織が定めることは 5.4.7(「定められた頻度」)と 3.4.3(「本標準は定めない…組織が定める」。定めない理由「頻度と技能の維持の関係を測った研究が無い」つき)に既にある。行は置き場である。テンプレ11 の表は、本標準は値を定めない旨を明記し(「値は組織が定める値であり、本標準は値を定めない(第1章 1.7.7)」)、空欄の扱いを行ごとに持つ。同型の行が既に6行ある。ADR-0175 の分類(「頻度の値と記録の欄を足すことは採用者への新しい義務」)は広すぎ、本件の「欄を足す」を一律に新しいと数えた。誤りは ADR-0175 の側と裁定する。ADR-0175 は本文を書き換えず、本束の ADR で「IMPL-0978 を重へ送った前提を改める」と書く。ただし、新たに生じるものを3つに分けて認める: (i) 置き場の定め、(ii) 空欄の表示、(iii) 実施の日の比較の表示。(i)(ii) は他の行と同型で義務を増やさない。(iii) は2に述べる
2. 登録した変更種別の経路は、案 C を表示だけに限って採ることで閉じる。案 D(登録の判定で照らす)は採らない。D は登録の条件を増やし、B-4 等の判定者に新しい義務を課す。登録の経路は 5.4.5 の表を経ないが、5.4.5 の登録の段が 5.4.7 を適用すると定めている(human-ai-boundary.md の「5.4.6 の引き下げと 5.4.7 の能力維持措置は、登録した変更種別にも適用する」)。適用されるものを、守られているかを判定の時点でなく常時の表示で見せる。席の責任者の力量の確認(3.4.3)が、周期を過ぎたら「失効」と表示して出荷は止めない形と同型である。表示は止めない

- note の「頻度の値と記録の欄を足すことは採用者への新しい義務になるため、棚卸しでは決めず、降ろす段階で審議する」を、次に置き換える: 「頻度は組織が定め(層1。テンプレ11 の行)、実施の記録は案件側に置く。数値の頻度と頻度切れでの停止は課さないと決めた(ADR-NNNN)。表示は止めない」

根拠水準マーク: 表示を不利な側に倒す設計は、席の責任者の力量の確認の行(IMPL-0082 等)と同じ構造で、新しい未検証の値を足さない。数値を課さないので値の暫定マークも要らない。EV の新設は不要。ただし 3.4.3 の「研究が無い」(2026 年時点で更新が要るか)は外部の調査を要する。本束は軽のため行わない。更新が要れば別に審議する

### 採らない案と理由

- A(何もしない): 登録の経路(準拠テンプレートの採用者の主な経路)に、5.4.7 の実施を照らす時点が標準のどこにも無いまま残る。破られたとき失うのは、人が監督する力量そのもの、つまり「決められた場所では必ず人間が触る」という主張の実効である。適合の主張の信頼に響く。取り消せない損失は直接は無いが、気づかれない劣化である
- D(登録の判定で照らす): 判定者に新しい義務。登録の条件を増やす。常時の表示で足りる
- E(数値を課す): 3.4.3 の決定と根拠(測った研究が無い)に反する。課さないと決めたことに戻す
- F(adopter): ADR-0175 決定2 の線引き(テンプレートの単位の外にあるものだけ)に反する。層1 の様式は準拠テンプレートが持つ
- G(頻度切れで止める): 新しい停止の条件。止める根拠が無い(上と同じ)。ADR-0081 の停止の列挙を変える。重の条件に当たる

### 新しい義務の判定

- B: 無い
- B+C(採る案): 無いと判定する。理由は、実施の記録は 5.4.5 条件5 が既に前提とし、「確保する」は確保したことの証跡を前提とするため。表示は止めず、周期の失効の表示と同型。割れる点は C の表示が「登録の経路の採用者に記録の手間を新たに生む」かどうか。そう判断されたら、C を外して B だけを採る(その場合、登録の経路の穴は開示に留める。IMPL-0978 の note と保証の開示の項目7 へ「実施の記録の頻度の確認は課さない」と明記)。この退避を採る場合も、重に上げるほどではない。上げる条件は、数値・停止・登録の判定への追加(D・E・G)へ割れた場合だけ
