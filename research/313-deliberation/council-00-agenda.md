# 会議体の議題(#313 標準の版・適用の終了・逸脱と適合の主張)

入力: `issues-context.md`、`survey-313-1-internal.md`(内部)、`survey-313-2-external.md`(外部)。本文は `phase4-process-design/overview.md` 1.3・1.7.1・1.10、`assurance-case.md` H.8、ADR-0029・0052・0068・0077、`phase5-implementation/ci-gates.md` L313・`template-repository.md` L33、テンプレート `scripts/gate/aggregate-evidence.mjs` の `findInitCommit`、`scripts/build-template-kb.mjs`、`qms-document-control.md:90`。

## Q-1 標準の版の付番と改訂時の扱い
- 現状: 版の識別は `dist/standard` の VERSION.md(コミット・run 番号)と KB の `source.commit` だけ。人が読める版が無い。`qms-document-control.md:90` は「ハッシュは監査の場で版の識別子として通用しない」と自ら書く。テンプレートは従う標準の版を記録しない。`check-template-drift.mjs` は `source.commit` を乖離の検査から外す
- 外部: 規格は「新版は旧版を取り消し置き換える」が既定。移行期間は認証制度の側(IAF MD 26 の 36 か月など)。FAA AC 20-115C は「旧版のまま続けてよいが新版への適合を宣言してはならない」。SLSA・ASVS は主張に版を含める書式を定め、意味を変えない改訂の範囲を先に決める
- 問い: 付番の形(日付・連番・意味つきの版)、どの変更で版が上がるか(規範の変更と編集上の修正の区別)、改訂のときに既存の適用の表明・適合の主張がどうなるか、移行期間を置くか、テンプレートが従う版をどこに記録するか

## Q-2 適用の終了
- 現状: 語は ADR-0068 の 1 か所だけ。案件の中止(`roles-responsibilities.md:699`)・ステージ移行と 1.10 が繋がっていない。`changeLog` に終了の種別が無い
- 外部: 終了は期日の失効・能動的な取り消し(一時停止)・範囲の縮小の 3 事象。終了後の表示の撤去が明文(17065)
- 問い: 適用の終了を定義するか。定義するなら事象・記録・終了後の表明の扱い

## Q-3 逸脱がある場合の適合の主張
- 現状: 1.10.2・H.8 の適合の主張の条件は「未達と記録の欠落が無い範囲」で逸脱に触れない。1.7.1 は「適合を主張するには逸脱を認めない」。「逸脱」が 2 義(要求からの逸脱 / 代償措置つきの逸脱 = 構成の区分、ADR-0029)。H.8 は逸脱の併記を求める
- 適用の表明の必須の記載が 1.10.2(件数だけ)と H.8(版・調整・逸脱・署名)で 2 通り。同じ事項の規定は 1 か所(`overview.md:214`)に反する
- 外部: 12207 系(完全適合 / 修整適合)と MISRA Compliance(Compliant / Deviations / Violations / Disapplied、逸脱記録の要件、逸脱不可の層)が、独立に「適合」と「逸脱つき適合」を別の語で呼ぶ
- 問い: 逸脱つきの構成が主張できるのは何か(適合 / 別の語の主張 / 主張できない)。語の 2 義をどう解くか。正本を 1.10 と H.8 のどちらに置くか

## Q-4 引用規格の版の書き方
- 現状: 1.3 は一部だけ版つき(ISO 9001・90003・12100 は版なし)。出典台帳に 2017 年版のカードが無い。本文から SRC への参照は 0 件
- 外部: ISO/IEC Directives Part 2 は、版つき引用は引いた版だけが適用、版なしは文書全体と全改訂を取り込む場合だけ、部分を引くときは必ず版つき。改訂時の引用の見直しの義務
- 問い: 引用の版の規則と、改訂時の棚卸しを作業として定めるか。12207:2026 への個別の更新は #341
