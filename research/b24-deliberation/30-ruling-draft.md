# 束 B24 — 議長の裁定の案(2026-11-19)

受付は `00-intake.md`。触るファイルは `05-files.md`。各項目の「方針」は所有者の方針(2026-11-16)の3問の答えで、(1) 条文は結果と証跡までか、(2) 第7章の例外承認で受けられないか、(3) 破られたとき誰が何を失うか、を示す。既にある裁定(ADR-0220・0223・0225、B22 の 30・81、B21 の ruling-deferred、B18 の ruling-a1)は覆さない。

## 0. 共通

- 降ろし方は4つから選ぶ: (M) 機械の検査(決定可能な条件だけ)/(F) 様式の欄/(G) 手引き/(A) 採用者の実装(adopter)。本束に (A) と (F) の新設は無い
- 構成へ欄を足すのは、B21 案 §2.2 の線(条文が「構成に持つ」「記録する」「組織で定める」と名指す値)に限る。本束で足す欄は `delegation.sampling.perMonth`(0597)・`seats[].qualification.record`(0640)・`CHANGE_TYPE_BASIS` の4点目(0834)の3つで、既存の裁定どおり。`delegation.introducesPaths`(0840)は足さない案を推す(§1 の 0840)。欠けたときの扱いを項目ごとに書き、CHANGELOG と移行の注意に載せる
- 新しい試験のファイルは作らない見込み(既存の結線済みの試験に場面を足す)。新しいファイルを作るなら `gate-g5.yml` の run の行を同じ単位に含める
- **新しい ADR は要らない**。0594 は ADR-0220、0830・0214・0217 は ADR-0223、1030 は ADR-0225 が決定の所在で、本束は降ろし方だけを決める。0237〜0242 は使わない
- 新しい根拠水準マークは要らない見込み。実装で実証の無い値を置くなら付す(0597 の既定 min(n,5) は既存の tailoring-guide.md の暫定のマークが受けている)
- マークを変えたら `npm run impl:write`。0709・0900 の target の変更は `lint:impl` で降ろし先の実在を確かめる
