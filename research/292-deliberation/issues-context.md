## #292(本 Issue)

背景: 実装台帳の「降りていない規定」が 0 件であることは、降りていない規定が無いことを示さない。マークを足すべき条項を特定する手続が無い。

引き継ぐ論点:
- 実行主体の挙動を制約する条項を網羅的に洗い出す手続(どの章のどの文型を対象にするか)
- 0 件を異常として扱う判定
- 5.6.2・5.8 系の条項の実装マーク

受入条件:
- マークを足すべき条項を特定する手続が `community/implementation-marking.md` に書かれている
- 手続で見つかった未マークの条項にマークが付き、台帳に反映されている

## #259(閉)のコメント

### 2026-09-23 起票者のコメント(ganbari-quest の型)

対象の一覧と理由付きの明示除外リストを対にして、どちらにも載っていない対象をテストで落とす(no-silent-gap guard)。網羅性そのものは保証できないが、まだ分類していない対象がある状態は機械で検出できる。案: (1) 規範を含む段落(「してはならない」「しなければならない」等)を機械で列挙する (2) マーク済み・明示除外(理由必須)・未分類の 3 者に仕分ける (3) 未分類が 0 でなければ落とす。
