### V3-1(高) SRC-0916#c1 が、書籍の沈黙を「書いた」として表示する

- 所在: `research/sources/SRC-0916.yaml` の summary と c1 の text、`personas.md` の C-Q1 の根拠の欄(「権限を品質保証部門の長でなく、任命された責任者と独立の監査者に置くと書く」)
- 事実: 抜き書き B1 の論点の表は「品質保証部門長の権限としては書かれていない」とする。書籍が書くのは、品質管理責任者を任命して権限を与えることと、監査者をプロジェクトから独立した部門から選ぶことである。その独立した部門が品質保証部門である可能性を、書籍は否定していない。カードと C-Q1 は、「部門長ではなく」を書籍の主張として表示している
- 影響: C-Q1 の段(G3)は SRC-0913#c2 と SRC-0917#c1 で保たれるため、段は動かない。表示の誤りだけである。P-A の演者への注意(「部門長の権限とは書かず」)は正しい書き方で、これと食い違う
- 直し方の案: c1 の text と summary を「権限は任命された品質管理責任者と、独立した部門から選ぶ監査者に置く。品質保証部門の長の権限としては書かれない」へ改める。C-Q1 の欄も「部門長の権限とは書かず、任命された責任者と独立の監査者に置く」へ揃える。research-05 の B1 の表(L1)の同じ言い回しも直す
