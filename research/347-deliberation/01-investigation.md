# #347 受付と内部の調査(2026-11-17。標準の本文は未変更)

## 議長への提案: 段(ed/軽/重)と理由
- **段は「軽」**。記号の衝突は語の整理であり、新しい義務・安全・法令には当たらない。ただし **担保水準の記号を改める案は、構成の値(`task.assurance.level`: "L0"|"L1"|"L2")を採用者が書き換える移行を伴う**。これが「採用者への新しい義務」に当たるなら重へ上げる(議長の裁定)。
- 本文だけで閉じる案(読み分けの規則と ADR への記録。改名なし)は軽のまま。両方の記号を残す場合は、ADR-0058・ADR-0081 の決定を置き換えない補足の ADR で足りる。
- 外部の調査は、改名する案を採る場合だけ要る(ISO/IEC/IEEE 15288・12207 等の段階の記号の用例)。内部の調査は本書で足りる。

### 1.2 衝突の実害の見え方
- 記録に「L1」とだけ書かれた場合に読み分けられない。例: PR の本文・宣言・D-0 の「AI自律レベルの適用の表」(`tailoring-guide.md:249`)・`task.assurance`。
- 現行の本文は、担保水準の側が常に「担保水準 L1」と接頭語を付けて書く(`gate-criteria.md:2109,2112,2127`、PULL_REQUEST_TEMPLATE:71、G-5.md:30)。自律レベルの側は「L3」「自律レベル」「AI自律レベル」と書く。**接頭語は守られているが、規則としては定めていない**。
- 取り違えると結果が逆向きに効く。担保水準 L2 は「規模の上限なし」を許し、自律レベル L2 は「協働・人が統合点を確認」。「L2 だから上限なし」と読み違える余地がある。
- 近い記号との衝突はほかに無い。安全重要度は CL0〜CL3、リスク区分は R1〜R3。担保水準が `L` で始まる別の体系を持つのは、この2つだけである。

## 3. 選択肢
- **(A) 改めず、読み分けを ADR に記録する**。「担保水準 L0〜L2」「自律レベル L1〜L3」と、常に接頭語を付けて書く規則を第1章 1.4 の用語の表と書き方の節に置く。記録の欄(`task.assurance`)の値は「L1」のままだが、欄の名で読み分けられる。変更は本文だけ。
- **(B) 担保水準を改める**(例: 水準 0〜2、または「逐行読解 / 観点絞込 / リスク判定」の名)。本文の面積は小さい。構成の値の移行(採用者の `task.assurance.level`)が要る。ADR-0058 の決定は置き換えず、新 ADR で記号の部分だけを置き換える(ADR-0047→0058 のような一部置き換え)。
- **(C) 自律レベルを改める**(例: 段 1〜3、または「主導・並行・自己修復」)。面積が最大。ADR-0081 など第5章 5.4 を前提にした多数の決定の語を読み替える。
- **(D) 両方を改める**。面積が最大で、利点は (B) か (C) の一方に勝らない。

## 5. 所有者の方針(2026-11-16)の3つの問い
1. **満たすべき結果と証跡まで、手順は手引きへ**: 結果は「記録の読み手が、どちらの量かを取り違えない」こと。証跡は、欄の名・接頭語・値の形が分かれていること。記号の改名は結果を達する唯一の手順ではない。接頭語の規則 (A) でも達する。ただし接頭語の規則は機械が確かめにくい(自由な文の意味)ので、**manual と根拠水準マーク**で開示する。欄の値の形で分ける (B) は機械で確かめられる(値の構文)。
2. **新条項を足さず例外承認で受けられないか**: 条項の新設ではなく、1.4 の用語と書き方の節の一行。新しい義務は課さない。例外承認(第7章)は使わない。
3. **破られたとき誰が何を失うか**: 読み違えた採用者の編集者・レビュアが、規模の上限の扱いを誤る。担保水準 L2 の宣言を自律レベルと取り違えて規模の確認を省くと、レビュー可能性の担保を欠いた大きな変更が通りうる(根拠の実在は機械が確かめる〔`gate-criteria.md:2127`〕ので、根拠なしの L2 は通らない)。被害は有界。

## 6. 所見(調査の担当としての整理)
- 実害は「記録に記号だけが書かれる」場面に限られ、現行の本文は接頭語を保っている。(A) の費用は最小だが、コアポリシーにより安さは採否の理由にしない。信頼性の判断軸では、**記号そのものが衝突している限り、将来の記述者が接頭語を落とす余地が残る**。構成の値の形(`"L1"`)で衝突が残るのは (A) の弱点。
- (B) は面積が小さい割に、採用者の構成の値の移行を伴うため、移行期間の扱い(旧値を受け付けて警告するか、拒否するか)の決定を要する。拒否すれば採用者の構成が止まる(ADR-0028 の未達と省略の区別に関わる)。
- (C) は規則データと知識ベースまで及び、`template:kb` の再生成と乖離検査(`npm run check`)の通過を要する。

## 7. 本文側だけで閉じる範囲 / template 側の範囲
- 本文側だけで閉じる: (A)(接頭語の規則と ADR の記録)。(B) の本文・ADR・台帳。
- template 側(本束では触らない): (B) の `task.assurance.level` の値と移行、(C) の自律レベルの全箇所。知識ベース(`src/data/tailoring/` → `template:kb`)は (C) のときだけ。
- 旧称の検査: 句単位の登録(記号単独は誤検出するため不可)。
