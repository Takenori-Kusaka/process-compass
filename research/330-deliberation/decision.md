## 3. 裁定

1. アダプタのコマンドが空の任意の検査(静的解析・依存監査・ライセンス検査・依存の導入)は、実装の開始後も G-5 を失敗にしない。**構成で選んだ未実施**として、保証の開示 項目4 に検査ごとの理由で出す。これは、実行環境が入力を欠いて実施できなかった検査(gate-criteria.md L1020。失敗に数える)とは区別する。前者は構成に書かれた選択で、構成の変更の記録を経る。後者は意図しない欠落である
2. 項目4 が「未実施」の検査は、**未実施が続いている期間(未実施のまま出荷した最初の出荷からの経過と、連続した出荷の回数)**を併記する。理由が「検査対象が存在しない」の未実施にも当てる(実装の開始後に続く対象なしが、出荷ごとに見えるようになる。IMPL-0239 の機械で閉じない部分への手当て)
3. 継続の長さで差し戻さず、閾値を課さない。例外承認(7.3)の対象にしない。G-8 の異議の対象を広げない。いずれも「課さないと決めた」と ADR に明記する
4. カバレッジは任意の検査から外す(編集。1章 b)
5. ADR-0151 を起こす(あとから変えにくい「失敗にしない」の決定と、その理由・採らない案を残すため。Issue が求める「当てないなら項目4 で足りる理由」の置き場)

所有者の方針への答え:
- (1) 条文は結果(未実施を通過と区別し、続いていることを開示する)と証跡(項目4 の検査名・理由・起点・回数)まで。コマンドの選び方は手引き
- (2) 新しい条項は足さない。第7章の例外承認でも受けない(入口が無い)。既存の項目4 の行と H.6 の併記の表の拡張で受ける
- (3) 破られたとき(未実施が通過と読まれたとき)失うのは、出荷判定者と事業決裁者の判断の質と、採用者の適合の主張の信頼。安全に直結するテスト・秘匿情報は既に空を許さない。よって統制は「見える化」までとし、根拠水準マークで開示する
- 降ろし方: 機械の検査(項目4 の未実施と継続期間の出力。値の存在と日付で決定可能)。合否には使わない。理由の妥当性(自由な文)は機械にしない

### 4.3 ADR-0151

題: 「アダプタのコマンドが空の任意の検査は失敗にせず、未実施の継続を開示する」。決定:
1. 構成で選んだ未実施(空のコマンド)は、実装の開始後も G-5 を失敗にしない。入力の欠落による未実施(ADR-0077 の範囲)と区別する
2. 項目4 に、検査ごとの理由と継続期間を併記する。起点は未実施のまま出荷した最初の出荷(項目6 と同じ)
3. 継続の長さで差し戻さず、閾値を課さない。例外承認の対象にしない。G-8 の異議の対象を広げない
4. ADR-0033 決定6 を未実施へ広げない(採用済みの ADR を書き換えない)。ADR-0056 の項目4 の行を、項目6 と同じ型で補う

「採らなかった案」は本書 5章を写す。「見直しの契機」: 未実施が通過と取り違えられた事例の報告、内部監査の観点16 で継続した未実施が見つかった報告、EV-TMP-330-1・2 の見直し期限(2027-05)。ADR の index も更新する。

## 5. 採らない案

| 案 | 理由 |
| --- | --- |
| 実装の開始後は空のコマンドを G-5 の失敗にする | 採用者への新しい義務(重)。道具の無い言語・社内の閉じた道具の採用者を、空のままの抜け道か例外承認の連続へ追い込む。「実装の開始」の判定は目印を持たないコードで機械に閉じない |
| audit だけを必須にする(S4) | 新しい義務。同梱のアダプタは既に audit を持ち、手引きで足りる |
| 未実施が N 出荷続いたら失敗にする | N の根拠が無い。値で落とすと形式的な記入を招く(gate-criteria.md L1692 の既存の理由) |
| 例外承認(7.3)で未実施の継続を受ける(受付の見立て) | 7.3 の入口が無い。作れば新しい義務。7.3 の期限の効力も IMPL-0574・0575 が undelivered |
| 省略(第8章)で基準2・5 を外して受ける | 本件の結論は省略を要しない。外せるかは第8章の範囲で、本件では決めない |
| 基準2 の文に「未実施を0件に数えない」を足す | 基準の読みの変更(重)。項目4 が検査ごとに区別して出すことを実行で確かめたので、重複でもある |
| G-8 の異議の対象・観点14 に未実施を足す(S2) | 出荷判定者への新しい義務(重)。死文にしない目的は観点16 で受ける |
| 継続期間の起点を G-4 の時刻・SG-0 にする(S1) | G-4 は単一の時刻にならない。SG-0 の記録は機械の入力として定まっていない |
| 継続期間を出さず、未実施の名の列挙だけにする(反対委員の代案) | 起点の争いは S1 で解けた。列挙だけでは続いていることが読めず、項目6 との釣り合いを欠く |
| ADR-0033 決定6 を遡って未実施へ広げる | 採用済み ADR を書き換えない。ADR-0151 で扱う |
| 新しい観点を内部監査に立てる | 観点16 の文言が既に未実施を含む。重複 |
| 空の理由の妥当性を機械で判定する | 自由な文の意味で、機械で閉じない |
| #360 を再開して L862 を返す(S3) | #360 は CLOSED。名指している open の #330 で直す |
