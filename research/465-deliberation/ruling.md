# #465 裁定(議長 2026-11-27)

- 重さ: 軽(`weight-decision.md`)。2委員の結論は割れた(起案 = 案 C、反対 = 対案 E)。議長が裁定する
- 割れた点は、新しい義務・ADR の原則の変更・安全のどれにも当たらない。重へは上げない

## 1. 裁定

### 1.1 所有者の問いへの答えを、開示として書く

所有者の問いは「この困りごとが本質であるという根拠は何に紐づいているか」である。答えは「紐づいていない」である。

- 発生の実測がある型でも、採用者にとって本質(頻度と損害が大きい)であることは、実測から導けない
- 実在の品質保証部門の問いの一次記録は、#461 の調査でも見つからなかった
- この2点を、H.3 の前書きと EV-0357 に書く。行の選び方の水準は E0 のまま

### 1.2 「発生の裏づけ」の列は置かない(案 C1 を採らない)

- 反対委員が知見の原文 19 件を読み、9 件が行の困りごとと対象がずれ、1 件は水準の表記が過大だった。起案委員も受付の対応表に誤り3点を見つけた。2つの独立の読みで対応が揺れた
- 揺れる対応を、水準(E2・E3)つきで規範の附属書の表へ載せると、行に根拠の外観を与える。ADR-0266 が退けた「覆って見せる対応表」と同じ構造になる
- 知見の多くは見直しの時期が 2026-12 で、表が数か月で揺れる
- 発生の実測は、止め方が効くことの実測でも、本質であることの根拠でもない。列にすると混同を招く

### 1.3 行の出所を、行ごとに3つに分けて表の直後に示す(対案 E を採る)

- 所有者の例示(2026-11-27)に当たる行、外部の調査の実測から取った行、作成者が足した行、の3つに分ける
- 行ごとの発生の実測の対応(揺れを含む)は、調査メモ `research/465-deliberation/` に置く。附属書には、FND の番号と水準を足さない(既にある2行目の FND-0091 は保つ)

### 1.4 行を1つ足す: 「AI が指示・規則に従わない」

- 起案委員が、止める場所(3.11.3「違反を許容できない規則を誘導層だけに置いてはならない」、強制層への降ろし)を本文と実装台帳で突き合わせた。既存の行のどれとも止め方が違う
- 本標準の中心の主張(指示に頼らず、強制層で止める)の投影で、決裁者が最初に尋ねる型である。表に無いのは欠け
- 出所は「外部の調査の実測から取った行」とする(FND-0034 ほか)。ただし実装の段で FND の原文を読み、対象がずれるなら出所を「作成者が足した行」とする
- 区分は、起案委員の案(1)(`人` と、強制層へ降りた規則の `機械が止める`)による。`開示` の定義は広げない。誘導層だけに置いた規則は守られない場合がある、という実態は「最も弱い止め方」の欄に書く。**実装の段で、引く条項と IMPL の状態を本文と台帳で確かめてから書く**。確かめられない区分は書かない
- 行は末尾へ足す。並びを変える理由が無い

### 1.5 行にしない型を、前書きに名指しする

- 検査を形だけ満たす・迂回する: 既存の行(何も確かめない単体テスト、許していない操作、読んでいない作業を完了と報告する)と H.11「論証そのものの形骸化」に散っている。行にすると言い換えになる
- 長い作業で AI の監視が危険な操作を見逃す: 止め方は「AI が、許していない操作をする」「AI の確認を過信する」の行と同じ
- 並行エージェントの作業の干渉: 発生の実測が弱く(実マージで 1/417)、止める場所の条項の適用範囲が未確認
- 前書きの「拾えない性質」とは別に、「外部の調査に発生の実測があるが、行にしていない型」として挙げ、寄せた先の行を示す

### 1.6 導き直しは、実在の問いの記録が得られたときに行う

- 行の全体を外部の実測から導き直すことは、今は行わない。EV-0357 の差し替え条件(実在の問いの記録3件)を保つ
- 「行わない」と決めたことを EV-0357 に明記する。「まだ行っていない」と読まれないようにする

### 1.7 ADR-0268 を起こす

- ADR-0266 は置き換えない。決定2 を補う
- 記録すること: #456 の裁定が誤った前提(品質保証部門の問い)に立っていたこと、行の出所を行ごとに開示すること、発生の実測の水準を表へ載せないこと、行の採否は作成者の選択のままで規則にしないこと、採らない案
- 機械の検査は変えない。出所の箇条は自由な文で、機械で閉じない。manual とし、EV-0357 で開示する

## 2. 採らない案

| 案 | 理由 |
| --- | --- |
| A 実測から導き直して差し替え、裏づけの無い行を外す | 実測の有無は調査の網に依る。行を外すと、既存の統制と未達が決裁者の問いの場所から消える |
| C1 「発生の裏づけ」の列と、FND の実在・水準の機械の検査 | 1.2 のとおり。機械が確かめるのは番号の実在だけで、対応の正しさは閉じない。検査があることが、対応の正しさの外観を足す |
| C の行14(検査を形だけ満たす)・行15(並行の干渉) | 1.5 のとおり |
| 行の採否の規則(実測か実在の問いに限る)を前書きに定める | 規則にすると、規則に当たらない既存の行(なぜそう作ったか、秘匿情報)の扱いに例外が要る。細かい定義を足して、表の信頼は上がらない |
| B 行を保ち、何も足さない | 「指示・規則に従わない」は止める場所が本文にあり、突合も済んでいる。知っていて行にしないのは欠け |
| D 何もしない | 出所の3分類が無く、行にしていない型も示されない |
| EV-0357 の見直しを 2026-12 へ早める | 附属書に FND の水準を埋めないので、知見の見直しに表を連動させる理由が無い。2027-05 のまま |

## 3. 所有者の3つの問い

| 問い | 答え |
| --- | --- |
| 細かい定義を増やさないか | 新しい語・列・検査を足さない。足すのは行1つと、出所の箇条 |
| 条文は結果と証跡までか | 本節は投影で、要求事項を持たない。採用者の義務は変わらない |
| 破られたとき誰が何を失うか | 出所を偽ると、決裁者が「検証された困りごとの一覧」と誤って受容する。#465 で所有者が問うた形そのもの |
