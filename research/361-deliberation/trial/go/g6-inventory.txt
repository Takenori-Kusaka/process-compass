# 強制層の検査の棚卸しの入力(2026Q4。2026-10-01 〜 2026-12-31、UTC の暦)

入力の一覧です。解釈と、廃止の候補の選定は、AI維持管理者が四半期の棚卸しで行います。機械は候補を選ばず、合否に使いません(標準 3.11.4 要求事項4)。

## 1. 欠陥の台帳の「是正の記録」のうち、検査装置を対象とする行

読めない: docs/defect-ledger.md がありません。

## 2. GitHub Actions の実行の失敗(ワークフロー・ジョブごと)

読めない: 実行の記録を読み出せませんでした(リポジトリ(--repo か GITHUB_REPOSITORY)が未指定)。権限(Actions の読み取り)などの可能性があります。失敗が 0 件という意味ではありません。

- ジョブの失敗は、失敗した実行のジョブの記録から数えます。ジョブの記録を読めなかった実行は、ワークフローの失敗にだけ数えます。
- 実行の一覧は各実行の最新の試行の結論だけを持ちます。再実行で成功した失敗(run_attempt が 2 以上)は数えません。
- 是正の行との対応は、対象の欄にワークフローのパス、またはジョブの名が書かれているかの文字列の一致です。意味は読んでいません。
- 失敗が多い・少ないことは、検査の要否を示しません。働いていない検査(失敗が一度も無い)かどうかは、人が判断します。
