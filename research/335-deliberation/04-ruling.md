# #335 議長の裁定(軽、2026-11-15)

前の段: `01-investigation.md`(調査)、`02-opinion-drafter.md`(起案)、`03-opinion-opposition.md`(反対)。

## 前提

Issue が指した所(`label-mailbox.md` の原則4 の例示と 4.7.3 の表)は、#294 の X-6 と #316 で既に直っている。残る並びの正本は 3.5.5(`roles-responsibilities.md`)である。調査が見つけた実在の欠陥は、同ファイルの L841 と L882 の衝突である。

## 裁定

2委員が一致した点は、そのまま採る。割れた点(例示の列を分けるか)は、反対の委員の案 A′ を採る。

1. **L841 を L882 に揃える**(一致)。ADR-0078 決定2 は、併記を取り消せない操作の定義によらず保つと決めている。L882 が正で、L841 の「取り消せない操作に当たる場合に限り」が誤りである。直すときは「限り」を外すだけでなく、主語(「変更」と「縮小」)も L882 に合わせる。**既存の義務(ADR-0078 決定2)の是正であり、新しい義務の新設ではない**。この旨を記録に残す
2. **例示の列は分けない**(割れた点。A′ を採る)。3.5.5 の既存の表に、配備の統制を外す変更を統制の弱化の例として1行足す。列を分けない理由(併記の手続きは両者で同じであり、2つの概念の定義は 5.5.1 と 5.5.7 が持つ。表は例示であって閉じた列挙ではない)を、表と同じ所に1文で書く
3. **5.5.1 へ例示を足さない**(起案の案の一部を採らない)。例示の正本を2か所に作らない。配備の起動が取り消せない操作の側に当たることは、既存の 5.5.1 から導ける(調査 §#329 との関係)
4. **「両方に当たる操作は両方の経路で止める」は、既存の条項から導ける場合に限り、参照つきで書く**。導けなければ書かない(新しい義務になるため。書かなかった場合は、その旨を実装の記録に残す)
5. **新 ADR は立てない**(一致)。原則の意味を変えない。ADR-0038 と ADR-0078 は本文を変えず、ステータスの節に、当時の引用の並びの正本が 3.5.5 へ移ったことの案内を足す(`adr/index.md` の運用ルールが許す範囲で。許さなければ足さず、3.5.5 の側から ADR を指す)
6. **template に及ぶ項目は触らない**。調査の一覧(CLAUDE.md L36・L43、`claude-md-resident.json`、`handoff.md`、`generate-profile.mjs` L4286、`boundaries.md` L24)と、起案が足した「削除」を「データの削除」に直す件を、Issue のコメントに残す。Issue は開いたままにする
