# 意見書 委員02(現場)— #348 Q1・#340 Q2

2026-11-17。立場: 小さいチーム(1〜3名)・採用者の運用で回るか。入力: `council-00-agenda.md`、`research.md`。追加で読んだ: 第7章 7.3(`exception-escalation.md:26-65`)、5.4.6 の停止の表(`human-ai-boundary.md:262-290`)。実行はしていない(1名の体制の停止は research.md 2.5 節のとおり条文からの推論)。

## 0. 現場の立場の要点

1. **解く手段が「数字を書くこと」だけの停止は、根拠のない数字を生む。** 基準値は既定値なし・外部も支えない(research.md 3.1)。小さいチームが止まりを避けるために「20%」と書けば、機械は記入を確かめて通すが、保証は何も増えない。表示と実態が食い違う方向に倒れ、適合の主張の信頼を下げる。
2. **例外承認では受けられない。** 7.3 の対象は「ゲートの判定基準と、本標準の条項が本節を名指して定めた事項」に限る(:60)。5.4.6 の停止も 3.12.10 要求事項5 も 7.3 を名指していない。構成の条件を満たさない状態は未達・逸脱として扱う(:60)。自動の停止を解く経路も無い(ADR-0030)。つまり「止める」と決めると、採用者の逃げ道は**基準値を書くか、L1 へ降りるか**の2つだけになる。問い2への答えは「受けられない」であり、だから止めるなら設計の段階で慎重でなければならない。
3. **1名・2名の体制では、Q1 の増分が効く相手が狭い。** 1名はコア機能に関わる種別が第1区分で既に止まる。Q1 で増えるのは「コア機能に関わらない種別・理解保持者2名以上・変更30件以上・タスク30件未満または基準値未設定」の採用者だけである。**狭いのに、その採用者は最も真面目に L3 の条件を整えた者でもある。**
4. **Q2 は逆に、書かれていない帰結のほうが危ない。** 3.12.10 要求事項5 を文字どおり読むと準拠テンプレートの上で L3 を解禁できない(research.md 2.3)。これを明示すると、`start` 経由の自己修正で強制が実際に届いている採用者まで一斉に止まる。

## 1. Q1(#348)

### A-1 手戻り率の判定不能(母数不足)で止めるか

- **判定: 課さないと明記する**(止めない。表示する)
- 置き場所と文の案: 5.4.6 の :247 の直後に1文。「手戻り率の母数が最小標本数に満たない窓は、『発火しない』と表示し、第2区分の計測ができない範囲に数えません。差し戻し率の窓が判定不能のときだけ、停止の表の最終行によります」。停止の表は変えない
- 現場の根拠: 手戻り率の母数はタスク、差し戻し率の母数は変更である。増分が出るのは「変更30件以上・タスク30件未満」の窓だけ(research.md 2.4 B)。この形は小さいチームで普通に起きる。タスク管理を軽くして変更を直接積む運用、1タスクに多数の変更が付く運用が該当する。**母数の定義の違い(タスクか変更か)で L3 が落ちるのは、採用者から見て理由が見えない停止になる**。差し戻し率の側で十分に見ているチームが、別の母数の都合で止まる
- 落とす案: 「止める(読み A)」。理由: 統計は「発火させない」までしか支えず「止める」は支えない(research.md 3.1)。J3016 型の縮退の類推は、検知できない範囲に自律を置かないという原則を支えるが、手戻り率は引き下げの検知の一つで、第1区分と差し戻し率の検知が残る。母数の不足まで縮退に含めると、検知が一つ欠けただけで自律の全体を落とすことになる。**ただし現場の判断は、ここで品質監査・規格の両委員が「縮退は検知の一つの欠落でも起こるべき」と示した場合に覆りうる**。その場合も、せめて B の場合(タスク母数の定義)を直すことを求める
- 根拠水準: 暫定(現場の想定。小さいチームで B の形がどれだけ起きるかの実測は無い)

### A-2 基準値の未設定は「計測できない」に含まれるか

- **判定: 課さないと明記する**(含めない)
- 置き場所と文の案: 5.4.6 の同じ位置に1文。「基準値が未設定の手戻り率は、算出できていても引き下げを発火させません。この状態は適用の条件の欠落ではなく、『基準値未設定』として保証の開示に出します」。5.5.4「計測できない種別は登録しない」の説明に、手戻り率の基準値の未設定を含まないことを1句足す(入口と運用の食い違いの解消)
- 現場の根拠: 止めると全登録種別が基準値の記入まで止まる(research.md 2.4 A)。既定値を置かない決定(ADR-0129)と合わせると、**採用者は根拠なしに数字を書くことになる**。数字の書き手は登録者本人で、検査するのも同じ人である。書かせても機械が確かめるのは記入の有無まで(IMPL-0035 と同型)で、保証は増えない
- 落とす案: 「含める(止める)」。理由は上のとおり、信頼を増やさずに義務だけを増やす。**安さが理由ではない**。止めても実際の検知力が上がらないことが理由である
- 補足(採る): 「未設定」と「測らないと決めた」の区別。**様式の欄として採る**(条文は足さない)。`reworkBaseline` に「未決定 / 値 / 使わない(記名・理由つき)」を持たせ、表示に区別を出す。機械が確かめるのは欄の存在と値の形まで。内容の妥当性は manual/adopter と根拠水準マークで開示する。template への及び方: 構成の欄とその表示の分岐(本束では触らない。一覧に載せる)
- 根拠水準: 暫定(ゲーミングが起きるという予測は現場の想定で、実測は無い)

### A-3 基準値を定めることの義務の性格

- **判定: 課さないと明記する**(新しい義務として扱い、課さない)
- 現場の根拠: 「定めなければ使えない」は法的には代償でも、小さいチームには義務として働く。第4章 要求事項1 の「組織が定め、記録する」は既にあるが、これに違反しても停止はしなかった。ここで停止を結び付けるのは、記録の有無に実効性を持たせることで、**義務の強化にあたる**。強化なら重の審議の対象であり、本会議で採るなら信頼性の根拠(上の2点)が要る。現場の見るところ、その根拠は足りない
- 落とす案: 「代償であって義務ではない」と位置づける案。理由: 位置づけの言い換えで審議を軽く見せる形になる。採用者の損得は言い方で変わらない
- 根拠水準: 暫定

### A-4 止める場合の解く手段

- **判定: 課さないと明記する**(例外承認で停止を解く経路は置かない)。A-1・A-2 で止めないため、本争点の実害は出ない。仮に他の委員が「止める」を採った場合に備えて書く
- 現場の根拠: 7.3 の対象外(:60)と ADR-0030 の非対称から、例外承認では受けられない。**したがって「止める」を採るなら、解く手段は基準値の記入だけとなり、A-2 のゲーミングの問題が直撃する**。例外承認で受けるべきと主張する案は、自動の定義(実行を見送る裁量を持たない)と衝突するので採れない
- 落とす案: 「例外承認で受ける」。理由は上記の衝突
- 根拠水準: E2(条文の読み。7.3 の本文を確認した)

### A-5 止めない場合の #339(5.5.4 の登録の根拠の記録)

- **判定: 先送り**
- 足りない材料: 小さいチームで観点23(内部監査)が実際に走る率。1〜3名の体制では独立した監査者を置けず、第8章の事後監査切替に依ることが多い。観点23 が届く保証が無いこと(EV-0279)は現場でも当たる。**見直しの結論はここでは出さず、#339 に見直しの契機が成就したと記録する**(IMPL-0035 の note の条件の履行)
- 落とす案: 「見直さない(表示で足りる)」。理由: IMPL-0035 の note と EV-0279 が見直しを条件にしている。履行しないと、表示と実態が食い違う
- 根拠水準: 暫定

### A-6 中間案

- **判定: 採る**(A-1 と A-2 を分けて裁定し、いずれも「止めない」。ただし様式の欄で区別を出す)
- 落とす案: 「基準値未設定のみ止める」。理由: A-2 のとおり。「母数不足のみ止める」。理由: A-1 のとおり。「全部止める」。理由: 両方の理由が重なる
- 根拠水準: 暫定

## 2. Q2(#340)

### B-1 新設か IMPL-0834 への統合か

- **判定: 採る**(IMPL-0834 へ統合。新設しない)
- 現場の根拠: 台帳の3行(IMPL-0519・0279・0834)は同じ規定の別の面で、採用者は台帳を3行読んで1つの義務に組み直さねばならない。小さいチームほど台帳を読み解く人員が無い。統合して「登録の時点で、強制の手段の所在と範囲を照らす」の1行にする。#446 で扱う
- 落とす案: 「新設」。理由: IMPL-0834 と範囲が重なり、台帳が4行になる。読み手の負担が増える
- 根拠水準: 暫定

### B-2 求める記録の性格

- **判定: 採る**(所在の記入の有無を機械で確かめる。内容は確かめない)
- 置き場所と文の案: 条文は 3.12.10 要求事項5 の既存の文のまま。足すのは証跡の置き場だけ。「強制の手段の所在と、強制が届く範囲を D-0 へ書きます。範囲の外は、保証の開示に出します」。手順(テスト経路の限り方)は手引きへ
- 現場の根拠: 所在は1欄・1行で書ける。IMPL-0519 の note が既に求めているが検査が無いため、書かない採用者が出る。記入の有無なら決定可能で機械で閉じる(ADR-0129 の「確認の記名」と違い、自由な文の意味を問わない)。**空洞化(「CI」とだけ書く)は残るが、それは根拠水準マークと manual/adopter で開示する**。閉じ方の線引きはコアポリシーの方針どおり
- 落とす案: 「記入を求めず、IMPL-0519 の note のまま manual/adopter に残す」。理由: 検査の無い要請は、書かれていない義務と区別がつかない。「課さないと決めた」と「書かれていない」を読み手が区別できる状態に反する
- 根拠水準: 暫定(小さいチームが所在を実際に書けるかは未確認)

### B-3 求めた場合の対象

- **判定: 採る**(登録した変更種別の L3 を構成するとき)
- 現場の根拠: 準拠テンプレートが支える自律水準は登録した種別の L3 と、それ以外の L1 だけである(IMPL-0289)。L1 は全変更を人が確認するので、遮断の要件は意味を持たない。「全ての構成」と広げると、L1 の採用者にも欄の記入が及ぶ
- 落とす案: 「自律実行を解禁する全ての構成」。理由: 「自律実行」の語の範囲が条文上定まらず、L1 の小さいチームに不要な負担が及ぶ
- 根拠水準: E2(IMPL-0289 の note による)

### B-4 強制できる環境でない場合の扱い

- **判定: 採る**(登録を拒む。ただし拒む条件は**所在の欄が空、または「無し」のとき**に限る)
- 現場の根拠: 欄の有無は決定可能で、拒んでも小さいチームの費用は L1 に留まることだけである(research.md 6 節)。強制が実際に効くかは機械で確かめられないので、判定は人に残し、「効くことを機械が保証した」とは書かない
- 落とす案: 「表示のみ。解禁の判定は人」。理由: 欄が空のまま L3 に進める経路が残り、要求事項5 の「してはならない」を表示だけで受けることになる。「強制の有効性まで検査で拒む」案も落とす。決定可能でなく、検査が保証した体になる
- template への及び方(本束では触らない): 構成の欄、`autonomy.mjs` の登録の検査、試験

### B-5 準拠テンプレートの位置づけ

- **判定: 課さないと明記する**(「準拠テンプレートの上では L3 を解禁できない」とは書かない)
- 現場の根拠: 強制は `start` を呼んだ自己修正には届いている(IMPL-0272・delivered)。届かない範囲はロック外の反復と AI のレビューの往復である。**全否定の明示は、届いている部分まで否定し、採用者を一斉に L1 へ落とす**。代わりに、強制が届く範囲と届かない範囲を保証の開示に出す(B-2 の「範囲」)
- 落とす案: 「解禁できないことを明示する」。理由: 実態(届く部分がある)と表示が食い違う。表示と実態の食い違いは、巡の数に関わらず直す類の欠陥である
- 根拠水準: E2(IMPL-0272・0519・0279 の台帳の記述による)

### B-6 第8章・3.4.3(#352 の F-6)との関係

- **判定: 先送り**
- 足りない材料: 第8章の本文(切替の7条件)と F-6 の本文。research.md 9 節も未確認と書く。現場の見立てでは、極小規模の切替は L3 ではなく事後監査への切替で、Q2 の記録は L3 の登録に掛かるため直接は連動しない。ただし未確認であり、**断定しない**
- 落とす案: 「Q2 の結論を第8章の切替の前提へ反映する」。理由: 読んでいない本文に対して決められない
- 根拠水準: E0

## 3. 両件に共通

### C-1 安全の論点か

- **判定: 課さないと明記する**(CL 別の分岐は置かない)
- 現場の根拠: CL 別の分岐は新しい条項で、判定の負担と誤判定の余地を増やす。ADR-0039 により CL は案件ごと、リスク区分は変更ごとで、混ぜると条項の適用範囲の読みが割れる。Q1 は引き下げの検知の一つで、安全に直結しない。Q2 の遮断は予算の暴走・無限反復を止めるもので、3.12.10 要求事項5 が既に CL を問わずに書いている
- 落とす案: 「CL の高い案件にだけ止める・求める」。理由: 新条項と、案件の CL から変更ごとの適用の可否を導く誤読(ADR-0039 が禁じる)を招く
- 根拠水準: 暫定

### C-2 「採らないと決めたこと」の記録

- **判定: 採る**(ADR に残す)
- 残す項目: 手戻り率の母数不足で止めない・基準値未設定で止めない・例外承認で停止を解く経路を置かない(Q1)。準拠テンプレートの上で解禁できないと書かない・L1 の構成に所在の欄を求めない(Q2)。それぞれ理由つき

### C-3 閉じ方

- **判定: 採る**
- 機械で閉じる: 欄の存在、「無し」でないこと、値の形(Q2 の B-4、様式の欄)。manual/adopter で開示する: 所在の実効性、基準値の妥当性。根拠水準マークで開示する: 現場の想定に基づく部分

## 4. 必ず通す問い

1. **条文は結果と証跡までか。** Q1 は条文を1〜2文の明確化に留め、手順(窓の延ばし方・基準値の置き方)は手引きに残す。Q2 は証跡の置き場(所在と範囲を D-0 へ)までで、遮断の具体策は手引き。どちらも手順を条文に書かない
2. **例外承認で受けられないか。** 受けられない(上の 0 の 2、A-4)。7.3 は名指した事項だけを対象にする。新しい条項を足さずに受ける経路は無い。**だから、止める条項は一度置くと解く手段が狭く、慎重に扱う**
3. **破られたとき誰が何を失うか。** Q1: 利用者・事業が手戻り増加の早期検知を失う。ただし第1区分と差し戻し率は残る。細かく書くのは「発火しない」の表示(既にある)だけで足りる。Q2: 夜間の暴走による費用と無限反復。取り消せない操作ではなく、予算の上限(3.12.7)が事後で受ける。細かく書くのは強制の範囲の開示。**この2点を超える細則は、安全・取り消せない操作・適合の主張の信頼のいずれにも当たらないので書かない**

## 5. 条項を足す案について

- 足すもの: 5.4.6 の明確化2文(A-1・A-2)、5.5.4 の1句、3.12.10 の証跡の1文(B-2)
- 削れるもの: IMPL-0519・0279・0834 の3行を1行へ(B-1)。IMPL-0291 の `plan=scheduled` は本結論で閉じる。5.5.4 の入口と運用の二重の記述は、A-2 の1句で一致する
- 小さいチームでどう省けるか: 記入するのは所在の1欄と、基準値の「未決定 / 値 / 使わない」の1欄だけ。1名は第1区分で既に止まるので、実質の負担は2名以上の採用者に限る

## 7. 現場の最大の懸念(議長への申し送り)

- 他の委員が「止める」を採った場合、現場は**解く手段を基準値の記入だけにしないこと**(使わないと記名できる欄を併せて置くこと)を最低条件とする。さもないとゲーミングを促す条項になる
- 現場の判断が覆る条件: 小さいチームでも手戻り率の判定不能が実際に安全に及ぶ、という実測が出たとき
- この意見書の全体の根拠水準は暫定。小さいチームでの運用の実測は無い
