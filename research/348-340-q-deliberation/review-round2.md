## 2. 所見

### 中

**R2-1 手戻り率の記録を読めないときに止めることが、IMPL-0291 の note にしか無い。ADR-0158 は ADR-0129 決定3 の「読めないときは表示する」を維持すると宣言している**
- 所在: IMPL-0291 の note「手戻り率の記録を読めないときも、判定できないものとして止める(差し戻し率の履歴を読めないときと同じ。IMPL-0286)」。fix-round1.md の議長の裁定(L-2 を採る。Q1 の範囲)
- 食い違い: (1) ADR-0158 のステータスは「決定3 の残り(母数・分子・基準値の欄・表示)〜は維持します」と書く。ADR-0129 決定3(:57)の箇条は「基準値が未設定、または母数が最小標本数に満たないときは、止めずに『発火しない』と表示する。履歴を読めないときは『読めない』と表示する」で、後半は止めない扱いの一部として読める。ADR-0158 は後半に触れていない(ADR-0158 に「読めない」の語は無い)。(2) ADR-0158 決定2 は「『判定不能』の定義(窓の件数)は広げない」と書く。IMPL-0291 の note は「判定できないもの」の語で読めない場合を足しており、語は違うが、決定2 の読み手は止める原因が窓の件数と基準値の未設定の2つだけだと読む。(3) 5.4.6 の本文にも、読めない場合の停止の文は無い(差し戻し率の側も本文に無く IMPL-0286 にだけあるので、先例と同じ水準ではある)
- 裁定の中身(Q1 の範囲に入る)は妥当と見る。欠けているのは、裁定を ADR へ記録することである。降ろす束が IMPL-0291 の note だけを根拠に止める実装を入れると、ADR-0158 の「表示は維持」の宣言と逆の挙動を、記録の無いまま入れることになる
- 直し方の案: ADR-0158 決定1 に箇条を1つ足す。「手戻り率の記録を読めないときも、判定できないものとして止める。差し戻し率の履歴を読めないとき(IMPL-0286)と同じ扱いで、『判定不能』の語(窓の件数)は広げない。ADR-0129 決定3 の『読めないときは「読めない」と表示する』は、表示として維持する(止めない扱いだけを置き換える)」。ステータスの「決定3 の残り〜は維持」の後に「読めないときに止めない扱いも置き換える(決定1)」を足す
- 開示で閉じる案: 直さない場合は、IMPL-0291 の note の当該句に「(議長の裁定 2026-11-17。ADR には未記録)」を付ける。ただし ADR の宣言と note が逆を言う状態が残るため、上の直しを推す。編集の指摘の範囲(裁定は済み、記録の場所の欠け)で直せる

**R2-2 停止の表の新しい行(4点目が無い)の理由づけと、後から記録した4点目の内容の判定が欠ける**
- 所在: 5.4.6 の停止の表の「登録の根拠の4点目(5.5.4)が無い | 適用の条件の欠落 | 4点目を記録した時点」と、その直後の段落
- (a) 直後の段落は、適用の条件の欠落を「5.4.5 の後段は、計測できない種別を登録しないと定めています。計測できなくなった種別に L3 を置き続けることも、同じ理由で認めません」で理由づけ、基準値の未設定には別に1文を足している。4点目の欠けは計測の欠けではなく、この段落のどの文にも当たらない。表の行だけがあり、なぜ「引き下げ」でなく「適用の条件の欠落」なのかの説明が本文に無い(ADR-0158 決定5 の「登録日の無い種別は止める」と同じ型、は ADR にしか無い)
- (b) 5.5.4 の行は、登録の根拠の「内容は登録する者が登録の時に判定する(manual)」と書く。既に登録した種別へ4点目を後から書いて戻るとき、その記録は登録の時ではないため、内容を誰が判定するかが本文から決まらない。機械が確かめるのは記入の有無だけなので、「判定を待たずに戻る」と読むと、どの文字列でも、内容の判定を一度も経ずに L3 へ戻る。ADR-0158 決定4 の「記録の欠落が解けたことを記録から確かめる回復」は、有無の回復としては正しいが、内容の判定の欠けを開示していない。なお、記録を書き換える者については、直しで「導く元の記録」に登録の根拠を足したため、同じ段落の「検知の入力となる記録の変更を委任の範囲に含めない」が掛かる(AI の自己変更は塞がっている)
- 直し方の案: (a) 直後の段落に1文を足す。「登録の根拠の4点目が無い種別は、5.5.4 が登録しないと定めた状態です。登録が完了していない種別に L3 を置き続けないため、同じく適用の条件の欠落として扱います」。(b) 表の戻る条件を「登録する者が4点目を記名して記録した時点(内容は記録の時に登録する者が判定する。5.5.4)」とし、ADR-0158 決定4 の表の行も同じにする。5.5.4 の規定の当てはめで、新しい義務ではない(議長の M-7 の裁定の範囲)
- 開示で閉じる案: (b) を採らない場合は、ADR-0158 決定4 の表の後に「後から記録した4点目の内容は、登録の判定を経ない。内容の確かめは観点23 の内部監査(manual)に限る」と書き、採らなかったこと(戻る時点で登録の判定を要する型)を「採らなかった案」へ1行足す

**R2-3 5.4.6 の停止の節の登録簿が、新しい行(4点目の欠けによる停止)の降ろしを指さない**
