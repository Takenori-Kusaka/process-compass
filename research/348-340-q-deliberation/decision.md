## 2. Q1 の裁定と理由(現場・弁護の主張と、規格の主張の突き合わせ)

### 2.1 対立の核

- 現場(02)と弁護(05): 解く手段が「数を書くこと」だけの停止は、根拠の無い値の記入を促す。機械が確かめるのは記入の有無までで、保証は増えない。「発火しない」と正直に表示された状態より、見かけの検知が付いた状態の方が信頼を損なう
- 規格(04): ADR-0081 決定5 は判定不能での停止を比率を限らずに決め、「表示だけ」を名指して退けた。ADR-0129 決定3 は、その退けた案を手戻り率に当てている
- 起案(01)・品質監査(03): 入口(5.5.4)は計測を要件にし、運用は計測できなくても L3 が続く。同じ記録で適合とも不適合とも言えない

### 2.2 裁定: 止める

理由は次の4つ。多数であることは理由にしない。

1. **既存の決定の側が誤っているのではなく、ADR-0129 決定3 の1項が誤っている。** ADR-0081 決定5 は判定不能での停止を一般形で決め、「何もしない(表示だけ)」を採らなかった案に挙げた。ADR-0129 はステータスの表で決定5 の維持を宣言しつつ、決定3 で手戻り率を止めないとし、同じ ADR の中で停止を「決めていない」と重へ送った。採用済みの原則(ADR-0081)と、原則を決めないまま置いた実装の状態(ADR-0129 決定3 の1項)が食い違うときは、前者を正とする。逆にするなら ADR-0081 決定5 と 5.4.6 :247・:268・5.5.4 の入口を改める新しい原則が要るが、それを支える材料(統計・外部の実務・実測)は、会議体のどの委員も示していない
2. **「止めない」は、根拠の無い値よりも強い誘因を作る。** 現場・弁護の論は「止めると、数を書けば通る」である。これは正しい。ただし同じ物差しを「止めない」側にも当てると、止めない構成では**基準値を書かないことが最も得になる**。書けば基準を超えたときに止まりうる。書かなければ手戻り率は永久に発火せず、L3 は続く。止めない案は、手戻り率の検知を採用者が任意に外せる形にする。ADR-0081 は「手戻り率の行の削除」を課さないと決めた(分子を定義すれば計測できる)。止めない案は、行を残したまま、行を外す自由を採用者に渡す
3. **ゲーミングの跡が残るのは止める側だけである。** 止める案で緩い値を書けば、値・記録した日・決定した者・理由(IMPL-0517 で記名と理由を要する)と、決め方(本裁定の 2.4)が構成に残り、保証の開示に出る。内部監査(観点23)と出荷判定者が読める。止めない案で基準値を置かないことは、何の記名も要さない。信頼性の物差しで比べると、記名つきで開示される緩い値は、記名の無い不在より監査できる
4. **表示で受ける形は、5.4.6 が自動を求める理由と衝突する。** 5.4.6 は「監督の劣化は静かに進み、申告されない」から引き下げを自動にし、「点検する側が同じ劣化の当事者である構成では、非対称は成立しません」と書く。「発火しない」の表示を読んで L3 を止めるかを決めるのは、表示を読む人の点検である。弁護委員自身が、止めない案の信頼は「開示が読み手に届くか」に依ると認めた(05 の 8 節の2)

現場の「根拠の無い数字を書かせる」は、止めることへの反論としては退けるが、**指摘そのものは正しく、手当てを要する**。手当ては 2.4 に置く。

### 2.3 A-1 と A-2 を分けるか

分けて書き、どちらも止める。

- A-1(母数不足)は「判定不能」の定義(窓の件数)にそのまま当たる。ADR-0081 決定5 が直接に掛かる
- A-2(基準値の未設定)は「判定不能」の定義に入らない。語を広げると、既存の ADR・IMPL・試験の語が揺れる(品質監査の指摘)。そこで**別の状態として停止の表に1行を立てる**。根拠は 5.4.6「発火しない引き下げを、備えているものとして扱ってはなりません」と、5.5.4「検知条件を計測できること」である。基準値の無い手戻り率は、算出はできても「基準を超えた」という検知条件が成立しない
- 「基準値未設定のみ止める」「母数不足のみ止める」は、同じ「手戻り率が発火しない」状態のうち、止まるかを偶然で決める(起案の指摘)。採らない

### 2.4 止める場合の解き方と、根拠の無い値への手当て

解く手段は3つ。新しい経路は作らない。

| 手段 | 内容 | 戻り方 |
| --- | --- | --- |
| 判定可能な窓 | 窓の中のタスクが最小標本数に届く。届かなければ観測の窓を長くする(5.4.6。最小標本数は下げない) | 判定を待たずに戻る(ADR-0081 決定5・ADR-0030 の「適用の条件の欠落からの回復」) |
| 基準値の記録 | 第4章 要求事項1 の5事項を記録する。値は記録した日より後の評価から当てる(ADR-0129 決定3 の効力日) | 同上。基準を超えていれば、その評価で引き下げとして扱う |
| 登録の取り下げ | 種別を登録から外し、L1(協働)で扱う | 取り下げは厳しくする向きで、検知した時点で適用する(第8章の登録の表) |

**根拠の無い値への手当て(現場の最低条件への答え)**:

- 第4章 要求事項1 の「値の決め方」は、既定値のある閾値を前提に2択で書かれている。手戻り率の基準値には既定値が無い。この欠けを埋めるため、**既定値を持たない閾値の決め方に「実測前の組織の値」を加える**。実測前の値は、要求事項2 の置き換えの対象とする(2四半期の実測で置き換える)
- 実測前の値で解いた停止は、保証の開示と次の一手に「基準値は実測に基づかない(実測前の組織の値)」と出す。読み手は、検知が実測に支えられていないことを知る。これは現場が求めた「記名つきの開示」を、L3 を続ける欄ではなく、基準値の決め方の欄で与えるものである
- 止めている間も、手戻り率は算出し表示する(ADR-0129 決定3 の表示は変えない)。採用者は止まっている間に自分の値を観測し、実測から基準値を置ける。**止める案で実測から始める道が開くのは、止めている間も母数が溜まるときだけ**である。5.4.6 の母数の段落を手戻り率にも掛ける(4.4)
- 決め方を「実測から」と書いたのに、記録した日より前に判定可能な窓が一度も無い記録は、決定可能な食い違いである。準拠テンプレートでは「実測前」として表示する(template の分。8 節)

**採らない解き方**:

| 案 | 採らない理由 |
| --- | --- |
| 「使わない」と記名して L3 を続ける欄(現場の `reworkBaseline` の「使わない」) | 記名しても、手戻り率の検知の無い L3 が続く。5.5.4「計測できない種別は登録しない」に反する種別を、記名で登録に残す形になる。使わない自由は、登録しない(L1)ことで既に表せる(起案・規格) |
| 第7章の例外承認で停止を解く | 7.3 の対象はゲートの判定基準と 7.3 を名指した事項に限り、構成の条件は対象にしない(0 節)。停止は「自動」(実行を見送る裁量を持たない。ADR-0081 決定3)であり、承認で見送れば裁量を戻す。「例外承認で解けない」の文は足さない。7.3 の対象の限定と「自動」の定義から導かれるため |
| 既定値を置く | 根拠が無い(ADR-0129 課さないと決めたこと。外部も支えない。research 3.1)。置けば E0 の値が全採用者の既定になる |
| 移行の猶予(一定期間は止めない) | 期限つきの「表示だけ」であり、ADR-0081 が退けた案の期限つきの形である。基準値の記録は1件の記録で、止まった種別は記録で戻る |

### 2.5 所有者の方針の3つの問い(Q1)

1. **結果と証跡まで、手順は手引きへ**: 条文に書くのは「第2区分の窓が判定不能、または手戻り率の基準値が未設定の登録した種別へ L3 を適用しない」という結果と、戻る条件、基準値の決め方の記録(証跡)まで。窓の延ばし方・実測からの基準値の置き方は手引き(運用メトリクスと第4章の手引きの段落)に置く
2. **第7章の例外承認で受けられないか**: 受けられない(7.3 の対象外。0 節で本文を確かめた)。受けなくても、珍しい構成は既存の3つの出口(窓を長くする・実測前の値を記録して開示する・登録を取り下げる)で受けられる。新しい条項も経路も要らない
3. **破られたとき誰が何を失うか**: 止めないまま破られると、出荷の相手が、手戻りの増加の検知の無い L3 の成果物を受ける。L3 は CL0 の案件に限る(0 節)ので、人の安全には直接及ばない。響くのは**適合の主張の信頼**である。保証の開示は登録した種別を「L3(機械が常時監視)」と出すが、監視の一部が働いていない。だから停止の表の行までは細かく書く。CL ごとの書き分けや、基準値の妥当性の細則は書かない

## 3. Q2 の裁定と理由

### 3.1 B-1 統合

5委員とも統合。条項を新設しない。3.12.10 要求事項5 は既に「してはならない」と書いている。足りないのは降ろしと、確かめる場所である。降ろしは IMPL-0834(#446)に寄せる。

### 3.2 B-2 記録の性格: 採る(弁護委員の案は採らない)

- **置き場所は 5.5.4 の「登録の根拠の記録」の4点目**とする。IMPL-0519 の note が求める「D-0 へ書く」は、D-0 節12 の生成区間が構成から出す形で満たす(正本を構成の1か所にする)。3.12.10 要求事項4(G-1 の記録)へ置く規格委員の案は採らない。G-1 は案件の開始時の記録で、L3 を解禁する時点(登録)と一致しない。要求事項5 が問うのは解禁の時点の環境である
- 記録する事項: 3.12.10 の実行の単位(自己修正のループ、AI の確認側と作成側の往復)ごとに、停止条件を強制する手段の所在。その単位を使わない種別は「該当なし(理由)」と書く
- 機械が確かめるのは単位ごとの記入の有無まで。**手段が実際に停止を強制するかは確かめない。課さないと決めたものであり、書かれていないだけではない**(既存の3点と同じ型。ADR-0059 決定5・ADR-0081)
- 弁護委員の「記入の有無が埋まる=強制が効く、と読まれる」は正しい懸念である。手当ては、既存の3点と同じく「内容は機械で確かめていない」と表示すること(IMPL-0983 の表示の対象に4点目を含める)。懸念は記入を求めない理由にならない。求めない場合、IMPL-0519 の note の要請は検査も記録の場所も無いまま残り、「課さないと決めた」と「書かれていない」の区別がつかない(現場・品質監査の指摘)
- ADR-0129 が採らなかった「解禁の記録に、強制の範囲の理解の確認を足す」とは別物である。あちらは自由な文の記名(理解の確認)、こちらは場所・手段の名で、記入の有無が決定可能である。ADR-0129 の不採用は維持する

### 3.3 B-3・B-4・B-5

- B-3: 対象は登録した変更種別の L3。準拠テンプレートが支える自律は L3 と L1 だけ(ADR-0081 決定6)で、決定可能な照らしの時点は登録にしかない。L2 への引き上げ(5.4.5 の判定)にも要求事項5 は掛かるが、会議体は論じていない。本裁定は決めない(6 節 問い1)
- B-4: 4点目の記録が無い種別は登録しない(既存の「3点の記録が無い種別は登録しない」を「4点」にする)。既に登録された種別で4点目が無いものは、登録が完了していないものとして止める(ADR-0081 の「登録日の無い種別は登録が完了していないものとして止める」と同じ型)。強制の有効性で拒む案は、決定可能でないので採らない
- B-5: 「準拠テンプレートの上では L3 を解禁できない」とは書かない。実態と食い違う(`start` を呼んだ単位には強制が届く。IMPL-0272)。代わりに、附属書H の 3.12.10 の行と IMPL-0834 の note に「準拠テンプレートが強制するのは `start` を呼んだ自己修正の単位だけ。ロックの外の反復と AI の往復は、採用者が手段を備え、その所在を登録の根拠に書いたときに限り登録できる」と書く。品質監査・規格の「帰結を書く」と、起案・現場の「断定しない」の両方を満たす

### 3.4 所有者の方針の3つの問い(Q2)

1. 条文は結果(手段の所在の記録が無い種別を登録しない)と証跡(登録の根拠の4点目)まで。遮断の具体策(テストの実行の経路の限り方など)は手引きと採用者に置く(ADR-0129 決定4)
2. 例外承認では受けない(要求事項5 は構成の条件で、7.3 を名指していない)。珍しい構成(自作の実行基盤、外部のサービス)は、所在に書けば受けられる。使わない単位は「該当なし(理由)」で受ける。新しい経路は要らない
3. 破られると、夜間の暴走で予算を使い切る、AI が自分の修正を無期限に反復する。3.12.7 の総量の統制は事後にしか効かない。取り消せない操作ではないが、遮断の欠落であり費用が有界でない。細かく書くのは「記録の無い種別を登録しない」と「記入は有効性を意味しない」の2点まで

## 9. 採らないと決めたこと(ADR-0158 へ写す一覧)

- 手戻り率の判定不能・基準値の未設定で、登録した変更種別を止めないこと(ADR-0129 決定3 の1項。本 ADR で置き換える)
- 「判定不能」の定義を広げて基準値の未設定を含めること
- 「使わない」と記名して手戻り率の検知の無い L3 を続ける欄
- 手戻り率の基準値の既定値(ADR-0129 を維持)
- 移行の猶予
- 第7章の例外承認で停止を解く経路(7.3 の対象の限定と「自動」の定義による。文は足さない)
- CL ごとに停止・記録を分けること(L3 は CL0 に限る)
- 3.12.10 要求事項5 の新しい条項
- 強制の手段の所在を記入させないこと(IMPL-0519 の note を adopter のまま残すこと)
- 強制の有効性を機械で確かめて登録を拒むこと
- 強制の範囲の理解の確認の記名(ADR-0129 を維持)
- 「準拠テンプレートの上では L3 を解禁できない」と書くこと
