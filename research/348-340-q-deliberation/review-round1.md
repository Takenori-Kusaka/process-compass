## 2. 所見

### 中

**M-1 「2項に結論を出す」が、決定8(L2 は未決)と食い違う(表示と実態)**
- 所在: ADR-0158 のステータスの節「ADR-0129 の『重の審議へ送ったこと』の2項に、本 ADR が結論を出します」と、ADR-0129 のステータスの追記「『重の審議へ送ったこと』の2項へ結論を出しました」
- ADR-0129 の2項目は「自律実行を構成するとき、強制の手段の所在の記録を求めるか」で、L3 に限っていない。ADR-0158 決定8 と 14 節の裁定は、L2 を決めていない。2項目に出した結論は L3 の登録の分だけである
- 直し方の案: 両 ADR のステータスを「1項目に結論を出し、2項目は L3 の登録に限って結論を出した。L2 への引き上げは未決(決定8。#340 が受け皿)」へ改める。ADR-0158 の「見直しの契機」には既に L2 の審議がある

**M-2 ADR-0129 の「採用者に委ねる規定」の IMPL-0519 の行を、宣言せずに変えている(範囲の宣言)**
- ADR-0129 の表の IMPL-0519 の行は、採用者に「手段の所在を D-0 へ書く」ことを求める。ADR-0158 決定5 と IMPL-0519 の note は、これを「5.5.4 の登録の根拠に書く(D-0 節12 は構成から出す)」へ移した。ADR-0158 は「満たす」と書くが、記録の場所の変更であり、「1項だけを置き換える」の宣言の外にある
- さらに、「D-0 節12 を構成から出す」の降ろし先を追う IMPL が無い。IMPL-0519 の note は「(D-0 節12 は構成から出す。IMPL-0834)」と書くが、IMPL-0834 の note と T6 に D-0 節12 への出力は無い。T4 は手戻り率の表示だけを扱う。このままでは、D-0 で読めることを満たしたと主張する根拠が無い
- 直し方の案: (a) ADR-0158 のステータスに「ADR-0129『採用者に委ねる規定』の IMPL-0519 の行のうち、記録の場所(D-0)を登録の根拠へ移す」を置き換えの範囲として足す。(b) IMPL-0834 の note と T6 に「4点目を D-0 節12 へ出す」を足し、`undelivered` で追う。(b) を採らない場合は、IMPL-0519 の括弧の「IMPL-0834」を消す

**M-3 ADR-0129 のステータスの書き方が、運用ルール3・5 の語彙の形でない**
- `adr/index.md` の運用ルール3 は「一部置き換え(→ ADR-MMM の決定 n)」と、置き換えた決定の番号を求める。既存の例(ADR-0009・0017・0047・0054 など)は、状態の行に「一部置き換え(→ ADR-0063 の決定2): 〜」と書く。今回は承認待ちの段落の後に「(2026-11-17 追記)」を置き、語彙も後継の決定の番号も無い。`check-adr-links.mjs` は旧い側の語彙の欠けを検出しない(ヘッダに開示)ため、機械では落ちない
- ADR-0129 の「影響」の「基準値を置かない採用組織では、手戻り率は『発火しない』と表示され続ける」も、置き換えの後は実態と合わない。本文は書き換えられないので、ステータスで触れるしかない
- 直し方の案: 1行目を「採用(2026-11-12)。一部置き換え(→ ADR-0158 の決定1・決定2): 決定3 のうち『基準値が未設定、または母数が最小標本数に満たないときは、止めずに〜表示する』の1項を〜置き換えました(2026-11-17)。『影響』の『発火しない』と表示され続ける旨も、同じく改まります」の形にし、追記の段落と置き換える。M-2 の (a) を採るなら同じ行に足す

**M-4 IMPL-1003 の「実測前と出す」規則が、要求事項2 の「自組織の実測」と食い違う**
- 第4章 要求事項2 の置き換えの元は「2四半期の実測分布」で、「自組織の値」とある。この案件の窓に限っていない。企画承認(G-1)の時点で決める(要求事項1。IMPL-0977)なら、新しい案件の構成には先立つ窓が無い。そのため、組織の他の案件の実測から置いた値は、正しく「実測から」と記録しても、IMPL-1003 の規則で「実測前」と出される。採用者の記録と逆の表示を機械が出すことになる
- 直し方の案: IMPL-1003 の note を「『実測から』の記録で、この構成の窓に先立つ判定可能な窓が無いものは、その旨を併記する(記録の値を書き換えて表示しない)」へ改める。あるいは、決め方の記録に実測の出所(この案件の窓 / 組織の他の記録)を持たせる。T5 も同じく改める

**M-5 基準値の記録で戻る経路は、ADR-0081 が数え上げた2つに無い3つ目である。そのことを書いていない**
- ADR-0081 の突合の表(:135)は、「判定を経ずに戻る経路は2つある(判定不能の窓から判定可能な窓への回復、原因を特定できない事象の原因の特定)」と数え上げる。ADR-0158 決定4 は、基準値の記録を「ADR-0030 の『判定を経ずに戻る経路』の範囲に収まります」とだけ書く。数え上げを3つに増やしたことを書いていない
- 出典も違う。ADR-0030 は安全重要度の引き下げの ADR(`0030-criticality-reduction-by-design`)で、書いてあるのは「自動的に緩む経路は設けません」だけである。2つの経路は ADR-0081 の突合が定めた
- 性質は収まると判断する。原因の特定と同じく、記名した記録で欠落が解けたことを確かめる形であり、引き下げを戻すものではない(実行 D)。基準値を外して書き直しても、発火した引き下げは戻らない(`reworkBaselineInfo` は評価の日ごとの履歴を当て、登録より後の評価を全部たどる。autonomy.mjs:325-340)
- 直し方の案: 決定4 を「ADR-0081 が挙げた判定を経ずに戻る2つの経路に、基準値の記録を3つ目として加える。どれも、止めた理由である記録の欠落が解けたことを記録から確かめる回復で、ADR-0030 の『自動的に緩む経路』(判定と記録を経ずに統制を緩める経路)に当たらない」へ改める。出典を ADR-0081 にする

**M-6 ADR-0158 から ADR-0030 へのリンクが切れている**
- `/process-compass/adr/0030-autonomy-level-as-ladder-with-downgrade-preconditions/` に当たるファイルは無い。実在するのは `0030-criticality-reduction-by-design.md`。`lint:refs` は通った(本文のリンクの実在は検査の外と見られる)
- 直し方の案: M-5 の直しで ADR-0081 を引く形にする。ADR-0030 を残すなら、スラッグを `0030-criticality-reduction-by-design` に直す

**M-7 「4点目が欠けた登録済みの種別を止める」が、停止の表に無い**
- 5.5.4 の行と ADR-0158 決定5 は、既に登録した種別で4点目が欠けたものを「登録が完了していないものとして止める」と書く。5.4.6 の停止の表には、この行も、停止の性質(引き下げか、適用の条件の欠落か)も、戻る条件も無い。記録を書けば判定を経ずに戻るのか、登録の判定を要するのかが本文から決まらない。M-5 の経路の数え上げにも効く
- 参考: 先例の「登録日の無い種別」も表に無い。template は `記録`・`unmeasurable` として扱う。同じ型にするなら「適用の条件の欠落、記録した時点で戻る」が自然である
- 直し方の案: 停止の表に「登録の根拠の4点目が無い | 適用の条件の欠落 | 4点目を記録した時点」を足し、M-5 の数え上げに含める。あるいは「登録の判定を要する」と決めて書く。どちらにするかは議長が裁定する。同じ段落の「導く元の記録は、Sev1・Sev2 の記録、理解保持者の記録、窓の中の変更と判定記録です」にも、構成の基準値と登録の根拠を足す(L-4 と合わせる)

**M-8 IMPL-0834 が降りたとき、既存の登録がすべて止まる。その負担を ADR-0158 の影響に書いていない**
- 現在の登録の根拠には4点目の欄が無い(fixture の `basis` は detection・rollback・tests の3つ)。T6 が降りると、既存の採用者の登録した種別は、4点目を書くまで全部止まる。ADR-0158 の「影響」が新しい負担として挙げるのは、基準値を置かない構成の停止だけである。弁護委員の論点(採用者が先に失う負担を開示する)が半分しか満たされていない
- 直し方の案: ADR-0158「影響」の新しい負担に「準拠テンプレートが4点目を確かめるようになった時点で、4点目を書いていない登録済みの種別は止まる。使わない実行の単位は『該当なし(理由)』の1行で戻る」を足す。T7 の移行の注記にも同じ文を足す

**M-9 第8章の「登録できる種別は〜届き」が、5.5.4 より厳しい登録の前提に読める**
- 新しい段落の1文目「登録できる種別は、第2区分の窓が最小標本数に届き、手戻り率の基準値を記録し、強制の手段の所在を記録した種別です」は、窓が30件に届くまで登録できないと読める。2文目の「届かない間は登録した種別が止まり」と同じ段落の中で食い違う。5.5.4 が登録に求めるのは「計測できること」と4点の記録までで、窓の件数は停止(5.4.6)の側の条件である。裁定 6.2-8 の「新しい義務の語を使わない(帰結の説明)」にも反する

**L-6 附属書H 3.12.10 の新しい項目と次の項目の重なり**
- 新しい項目の後半「準拠テンプレートが強制するのは `start` を呼んだ自己修正の単位だけである」は、直後の既存の項目(「自己修正のループの強制は、`start` を呼んだ単位に限る」)と同じことを言う。直し方の案: 新しい項目の後半を「ロックの外の反復と AI の往復を使う種別を登録できるのは〜」だけにする
