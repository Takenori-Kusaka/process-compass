# 委員 03 意見書(品質監査。#348 Q1・#340 Q2)

2026-11-17。立場: 適合の主張を内部監査で確かめられるか、証跡が残るか。入力は `council-00-agenda.md` と `research.md`。他の委員の意見は見ていない。

## 0. 監査の物差し(先に置く)

- 適合の主張は、**第三者が記録だけで真偽を判定できる**ときにだけ成り立つ。判定に要るのは、決定可能な条件(値の存在・一致・件数)と、残る証跡(状態の表示・記入欄・台帳)である
- 条文が2通りに読める状態(読み A/B)は、それだけで監査上の欠陥である。同じ記録を見て監査員ごとに適合・不適合が割れる
- 「表示で開示する」は、**開示が出荷判定者に届くこと**までを確かめられて初めて統制になる。届く保証が無い開示は、統制と数えない(EV-0279 の差し替え条件と同じ見方)
- 根拠水準: 以下の判断は、実行で確かめた 2.4 節(L3 が止まらない)と条文の突合に基づく。外部は二次情報のみ(E0〜E1)。**安全に及ぶ実害の実証は無い**ので、暫定マークを付ける(各項に記す)

## 1. Q1(#348)

### A-1 手戻り率の判定不能(母数不足)で止めるか — **採る**

- 理由(監査): 5.4.6 :247・:268 は「第2区分」を単位に書く。5.5.4 の入口は「計測できない種別は登録しない」と書く。**登録の入口では計測を要件とし、運用中は計測できなくても L3 が続く**状態は、適合の主張として自己矛盾する。監査員は「登録時に計測できると言った種別が、運用で計測できないのに L3」を不適合とも適合とも言えない
- 判定は決定可能である(窓内のタスク数 < 最小標本数)。証跡は `autonomyState` の状態(判定不能の表示)で既に残る。**機械の検査で閉じる**(autonomy.mjs の `stop()` と同じ路線)
- 増分は小さい(変更30件以上かつタスク30件未満の窓だけ)。増分の小ささは採否の理由にしない。ただし「実害が小さい」ので、新しい義務の重さは軽い。別に、差し戻し率の側で止まる窓では何も変わらない
- 落とす案: 「止めない(停止の表は網羅)」。落とす理由は、表の欠落が当時の未実装の名残だと research 8 章が示し、条文の他の2箇所(:247・:268・5.5.4)と食い違うまま残る点。統計が「発火させない」までしか支えないという指摘は正しいが、**止めるのは統計でなく適用の条件(計測できない範囲に自律を置かない)**であり、根拠が違う
- 根拠水準: 暫定(J3016 の ODD の類推と SPC は二次情報)。見直し 2027-05

### A-2 基準値の未設定は「計測できない」に含まれるか — **含める。ただし「判定不能」の語は広げず、停止の表へ別の1行を立てる**

- 理由(監査): 基準値が無ければ、手戻り率の検知条件は**発火できない**。発火できない引き下げを備えたものとして L3 を適用する主張は、検知を備えるという適合の主張と整合しない。実行(2.4 の A)で L3 が止まらないことを確かめた=現状は主張が偽でも通る
- 「判定不能」の定義(窓の件数)を広げると、既存の ADR・IMPL・試験の語が揺れる。**語を広げず、別の状態(基準値未設定)として表に1行足す**。監査員が状態名で記録を引ける
- 落とす案: 「含めない。基準値を定めない自由」。落とす理由は、第4章 要求事項1 が閾値を組織が定め記録すると既に求めること、5.4.6 の表が「組織が定めた値」と書くこと。自由として残すなら、L3 を使わない自由(L1 で運用)が残る
- 落とす案: 既定値を置く。ADR-0129 の既定値なしの決定を変えない(外部も既定値を支えない)

### A-3 義務の性格 — **委任の使用の前提条件(代償)として書く。新しい義務とは書かない**

- 監査上は、義務か前提かで**不適合の所見の立て方**が変わる。義務なら「基準値を定めていない=不適合」。前提条件なら「基準値が無いのに L3 を使った=不適合」。後者が適切で、L1 運用の採用者に不適合を作らない
- ただし採用者が先に失う点は事実なので、**重の新しい義務として扱い、ADR に「採らないと決めたこと」を残す**(議長の裁定に委ねる点を明記)

### A-4 止める場合の解く手段 — **基準値の記入と窓の充足のみ。第7章の例外承認で解かない**

- 理由(監査): 自動の停止を例外承認で外すと、承認の記録が「停止を見送った」証跡になり、5.4.6 の「自動=見送る裁量を持たない」と衝突する。ADR-0030 の非対称を保つ
- 抜け道は新しい条項でなく、**基準値の記入または登録の取り下げ(L1 へ)**で受ける。通す問い2 への答えは「例外承認では受けない。既存の2つの出口で受ける」
- 例外承認の本文(7.3 の対象外の定め)の細部は未確認。**先送り事項**として残す(議長が確認する)

### A-5 止めない場合の #339 — 本意見は「止める」なので **見直しは不要**。ただし条件付き

- 止めることで、機械が確かめる記入の有無と実運用の状態が一致する。観点23 が内容まで届かない弱さ(EV-0279)は、基準値の「存在」を機械で閉じることで一部だけ補う。**算出の所在が実在するか**は閉じない。manual のまま、根拠水準マークで開示を続ける
- IMPL-0035 の再審議の条件(止めない場合)は発動しない。条件が外れたことを台帳に残す

### A-6 中間案 — **A-1 と A-2 を分けて裁定する。採る案は両方「止める」**

- 「基準値未設定のみ止める」案は落とす。母数不足で止めないと、同じ「計測できない」でも片方だけ L3 が続き、5.4.6 :268 の1文で説明できなくなる
- 「未設定を明示する欄(`reworkBaseline: none`)」案は、**採らない**。明示した「測らない」は、:268 により L3 不可なので止まる結果が同じ。区別する利益が監査上は小さく、欄の新設は様式の増加になる。ただし記名つきの開示が欲しいなら、第7章でなく D-0 の記入で足りる(先送りの余地)

### Q1 の証跡と閉じ方(通す問い 1・3)

- 条文に書く結果: 「手戻り率の窓が判定不能、または基準値が未設定の登録した種別へ、L3 を適用しない(L1 へ)」。回復は「差し戻し率の判定不能と同じ(判定可能への回復)」
- 残る証跡: 状態の表示(判定不能/基準値未設定)・L1 への降格の記録。**既存の表示と台帳で足りる。新しい様式は足さない**
- 機械: 値の存在と件数の比較(決定可能)。manual: 基準値の妥当性(未検証、暫定マーク)
- 破られたとき失う者: 出荷の相手(手戻りの増加が静かに進む)。取り消せない操作・安全には直接及ばない。**細かく書くのは停止の表の1行まで**。CL による出し分けは採らない(C-1)
- 削る既存条項: 5.5.4 と 5.4.6 :268 の二重記述は一致するので削らない(一致の確認で足りる)。IMPL-0291 は delivered へ移す(ただし試験の実行確認を前提。template は本束で触らない=及ぶ分は一覧)
- 小さいチーム: 1名は L1 運用が既定で影響なし。影響は L3 を使う採用者だけ。窓の延長(#349)を手引きへ

## 2. Q2(#340)

### B-1 新設か IMPL-0834 への統合か — **統合する(IMPL-0834 に寄せる)。新設しない**

- 理由(監査): 同じ規定(3.12.10 要求事項5)の台帳が3行に分かれたまま、新設で4行目が増えると、**適合の主張のどの行が真偽を決めるか**が不明になる。1つの主張に1つの証跡の組(所在の記入+強制の範囲)を対応させる
- 落とす案: 新設。落とす理由は台帳の重複と、Q2 の本体(所在の記録)が IMPL-0519 の note に既にあること。**足すのは条文の新設ではなく、既存の要請を確かめる検査の有無の整理**

### B-2 求める記録の性格 — **所在の記入の有無を機械で確かめる(IMPL-0035 型)。内容は manual と開示**

- 理由(監査): D-0 に「強制の手段の所在」が記入されている状態は、第三者が記録だけで確かめられる。記名・理解の確認(ADR-0129 が不採用)と違い、**場所・手段の名であり、存在を機械が見られる**
- ただし限界を本文に書く。**記入があることは強制が有効であることを意味しない**(IMPL-0035 と同型。EV マークで暫定開示)。この限界を書かないと、記入の有無が「強制している」という過大な主張に読まれる(適合の主張の信頼を損なう)
- 落とす案: 記入を求めない(manual/adopter のまま)。落とす理由は、IMPL-0519 の note が既に求めているのに、検査が無いために**求めていないのと同じ**になっている点。要請と検査の食い違いは監査で突かれる。求めるなら確かめられる形に、求めないなら note を消す。前者を採る

### B-3 求めた場合の対象 — **登録した変更種別の L3 を構成するとき**

- 理由(監査): 「自律実行を解禁する全ての構成」は範囲が語として定まっていない(research B-3)。範囲が曖昧だと、除外の主張も確かめられない。L3 の構成は台帳(登録の根拠)に残るので、対象を台帳の行で決定できる
- 落とす案: 全ての構成。落とす理由は範囲を機械が決定できないこと。3.12.10 の語の整備は別の編集の指摘へ回す

### B-4 強制できない環境の扱い — **登録の拒否は採らない。所在の記入が空なら L3 を構成として認めない、までを機械で閉じる**

- 理由(監査): 強制の有効性は決定可能でない。拒否を条件にすると、有効性を機械が判定したかのような過大な主張になる。決定可能なのは記入の存在だけ
- 落とす案: 強制の有効性まで検査して拒否する。決定不能で、通らない検査は形骸化する

### B-5 準拠テンプレートの位置づけ — **書く(準拠テンプレートの上では、ロックの外の反復の遮断は降りていないと明記)**

- 理由(監査): 現状、準拠テンプレートを使う採用者は、要求事項5 を満たしたと主張しやすい。実際は届く範囲が `start` 経由の自己修正までで、**主張が条文から導かれる帰結とずれたまま**になっている。IMPL-0834 は降りていない旨だけを表示し、帰結(自前の手段が要る)を書かない
- 「L3 を解禁できない」と断定する書き方は採らない。**「自前の手段の所在を D-0 に書いたときに限り解禁できる」**と書く(B-2 と整合)。断定は、採用者の側で手段を備えた場合を誤って否定する
- 書き場所: 附属書H の 3.12.10 の行(開示)と IMPL-0834 の note。条項の新設でなく開示の整理

### B-6 F-6(1名の体制と委任の停止) — **本審議の範囲外にする**

- 理由: F-6 は実行で確かめていない(research 2.5)。確かめていない帰結を条項に使わない。#352 の側で扱う

### Q2 の閉じ方(通す問い)

1. 条文は結果(所在の記入のある構成でだけ L3)と証跡(D-0 の記入)まで。強制の具体策は手引き(ADR-0129 が採用者へ委ねた)
2. 珍しい構成(自作の実行基盤・外部サービス)は、所在に書けば受けられる。例外承認は不要。7.3 は強制の要求事項に使えるか未確認(禁止事項の扱い)のため、使わない形で設計する
3. 破られたとき失う者: 利用者・事業(暴走による費用・無期限の反復)。3.12.7 の予算上限は事後統制どまり。**細かく書くのは「所在の記入が空の L3 を認めない」と「記入=有効の意味ではない」の限界の2点まで**
- 削る既存条項: IMPL-0834 と IMPL-0519 の重なりを解消(IMPL-0519 の note は IMPL-0834 に寄せる)。IMPL-0279 は別の対象(AI のレビューの往復)なので残す
- 小さいチーム: 自律実行を使わない選択(L1)の費用が低い。使うなら、所在の記入は数行。自作の手段が無いチームは L3 を使えないが、これは条文が既に求めていること
