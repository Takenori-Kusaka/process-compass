# 意見書 05(弁護): #348 Q1・#340 Q2

2026-11-17。委員 05。立場は弁護(課さない・別の形で受ける案を最も強く立てる)。判断軸は信頼性で、安さ・変更量は理由にしない。読んだもの: council-00-agenda.md、research.md、`exception-escalation.md` 7.3(:26-100)。

## 0. 結論(先に)

- **Q1: 止めない。ただし「課さないと明記する」。** 同時に、条文の読みの二重(5.4.6 :247・:268 と停止の表、5.5.4 の入口の記述)を編集で一本にそろえる。
- **Q2: 新設しない(課さないと明記する)。** 要求事項5 は既に条文にある。足りないのは新しい条項ではなく、降ろしの表示の整理(IMPL-0834 へ統合)である。
- **弁護の核**: 「止める/求める」は、記入や宣言で解ける形にした途端、**信頼を高めずに偽の安心を作る**。機械が確かめられるのは記入の有無までで、そこを関門にすると、中身のない値で関門を抜ける動機を生む(2 節)。

## 1. 必ず通す問い

1. **結果と証跡まで、手順は手引きへ**: 私の案が条文に足すのは「止めないと決めた」旨の1文と読みの整理だけ。証跡は既存(基準値の記録、「発火しない」「数えていない残り」の表示、IMPL の未達の表示)で足りる。手順(窓の延ばし方・基準値の置き方・実行基盤の強制手段)は手引きに既出で、追加しない。
2. **例外承認で受けられるか**: Q1 は例外承認の対象外。止めない案では受ける必要が無い(停止が無い)。止める案では、停止は自動で、例外承認で解くと「自動の見送り」になり ADR-0030 と衝突する(research 4 節 (2))。**Q2 は 7.3 の本文で確かめた**。7.3 の対象は「ゲートの判定基準と、本節を名指した事項」に限り、「席の兼務の禁止、文脈の分離、…などの構成の条件は対象にしない。構成の条件を満たさない状態は、未達・逸脱・列挙に無い離脱として扱う」(:60)。3.12.10 要求事項5 は構成の条件であり、例外承認では受けられないが、**既存の逸脱の扱い(第1章 1.10.2)で既に受けられる**。新しい条項は要らない。research が残した「7.3 の細部は未確認」は、本意見書で埋めた。
3. **破られたとき誰が何を失うか**: Q1・Q2 とも、失うのは出荷の相手(手戻りの検知・遮断)で、**開示は既にある**(「発火しない」、IMPL の未達の表示、附属書H の1行)。取り消せない操作や人の安全が直接かかるのは、CL の高い案件だけで、それは C-1 の別論点(後述)。ここを細かく書くのは安全に響く部分(CL1 以上)に限る。

## 2. 弁護の主張: 「止める」は信頼を上げず、偽の安心を作る

- **記入で解ける停止は、計測の代わりに数字の記入を促す。** 基準値は既定値なしの欄である(ADR-0129)。未設定で止めれば、全登録種別が基準値の記入まで L1 に落ちる。採用者が最も安く解く手は、根拠の無い値(例: 50%)を書くことである。すると台帳には「基準値あり」と出るが、実態は発火しない値になる。**「発火しない」と正直に表示された状態より、見かけの検知が付いた状態の方が信頼を損なう**。これは予測であり、実証は無い(根拠水準 E0)。
- **統計は止める理由を支えない。** research 3.1 の整理どおり、SPC の通常の態度は「標本が足りない間は管理限界を置かない・発火させない」で、「止める」は安全の論点である。DORA にも小チームの指針は無い(見つからなかったこと自体を E0 で開示)。
- **増分が小さい。** 判定不能の増分は B の場合(変更30件以上・タスク30件未満)だけ。差し戻し率で止まるチームには増分が無い(実行で確認、research 2.4 節)。小さい増分のために、全登録種別を巻き込む基準値未設定の停止を入れるのは、釣り合わない。J3016 の縮退の類推は、車両の話の援用であり(research 3.2)、本標準の L3 とは語義も違う(#347)。規格の根拠としては引けない。
- **既に残る検知は消えていない。** 第1区分と差し戻し率の検知は残る。手戻り率が静かなのは、三つ目の検知が働かないだけで、L3 全体の保証が外れるわけではない。ただし、そう言えるのは**開示が読み手に届くとき**に限る(5 節 A-5)。

## 3. Q1 の争点ごと

### A-1 手戻り率の判定不能(母数不足)で止めるか
- **判定: 課さないと明記する(止めない)。**
- 落とす案: 止める(読み A)。理由: 増分は B の場合に限られ、統計は「発火させない」までしか支えず、停止の表は網羅の形で ADR-0129 決定3 が既にこの読みで実装済み。信頼性の点では、止めても差し戻し率の側の保証は変わらない。
- 文の案(5.4.6 の停止の表の直後に1文): 「手戻り率の窓の判定不能・基準値の未設定は、適用の条件の欠落に当たらない。止めないと決めており、書き漏らしではない。『発火しない』と数えていない残りを表示する。」
- 根拠水準: E0〜E1(二次の統計の一般論。実証なし)。

### A-2 基準値の未設定は「計測できない」に含まれるか
- **判定: 含めない(課さないと明記する)。**
- 落とす案: 含める。理由: 算出はできている。「判定不能」の定義は窓の件数であり、基準値の未設定を含めるのは**条文を広げる読み**(research 2.1 節)。広げるなら新しい義務なので、重の審議の対象として個別に正当化が要り、その材料(実害の実績)は無い。
- 編集の案(編集の指摘として議長が直せる範囲): :247 の「判定不能」を「窓の件数が最小標本数に満たない状態」と明示し、基準値の未設定は別の状態であると書く。

### A-3 基準値を定めることの義務の性格
- **判定: 課さないと明記する。** 第4章 要求事項1 の既存の要請(閾値を組織が定め、記録する)は変えない。ただし、**満たさなくても止まらない**。「代償」と呼んでも、採用者から見れば先に失うものであり、実害は予測で示せていない。代償という言い方で義務を持ち込まない。
- 落とす案: 「使用の前提条件」として置く。理由: 義務と区別がつかず、2 節の偽の値を誘う。

### A-4 止める場合の解く手段
- 止めないので争点は消える。**念のため付す**: 仮に止めるなら、解く手段は基準値の記入と窓の充足のみで、例外承認では解けない(ADR-0030 の非対称)。これは、止める案が「記入で解く」だけの関門になることを示す補強の材料である。

### A-5 止めない場合の #339(5.5.4 の登録の根拠の記録)
- **判定: 採る(見直しの条件を履行する)。ただし範囲は本審議の外へ出す。**
- 内容: 5.5.4 の「計測できない種別は登録しない」は**登録の入口の判定**(manual)であり、運用中の継続の状態を止めに連動させない、と書き分ける。入口と運用の二重を、止めないことでそろえる(現状は食い違う: 登録できない種別が運用では止まらない)。
- 正直な弱点: 機械が確かめるのは記入の有無まで、観点23 が届く保証は無い(EV-0279)。止めない案の信頼は、**開示が読み手に届くか**に依る。ここを弱いまま残さないため、`/pit`・保証の開示の項目3 の「発火しない」「数えていない残り」を、適合の主張の文面に併記する既存の定めを、IMPL-0291 の note から指す。

### A-6 中間案
- **判定: 先送りでなく不採用。** 「基準値の未設定を明示する欄(`reworkBaseline: none`)」は、欄を足す構成の設計で、新しい様式の欄を増やす(template-fields の両方向の検査が付く)。未設定と「測らないと決めた」の区別は有用だが、区別して何が変わるかは「記名つきの開示」だけで、止めない案の下では表示の追加にとどまる。信頼性への寄与の実証が無いまま欄を足さない。再審議の条件(後述)に挙げる。
- 落とす案: 母数不足は止めない・基準値未設定のみ止める。理由: 2 節の偽の値の誘因が最も強い形になる。

## 4. Q2 の争点ごと

### B-1 新設か統合か
- **判定: 統合(新設しない=課さないと明記する)。** IMPL-0834・0519・0279 は3.12.10 要求事項5 の別の面で、台帳が3行に分かれている。IMPL-0834(#446)の降ろしに寄せ、IMPL-0519 の note の「手段の所在を D-0 へ書く」は、IMPL-0834 の中で「検査は無い」と開示する。
- 落とす案: 新設。理由: 要求事項5 は既に条文で、足すと二重になる。

### B-2 求める記録の性格
- **判定: 記入を求めない(manual/adopter のまま)。**
- 落とす案: 所在の記入の有無を機械で確かめる。理由: 所在が書かれても、強制が有効かは確かめられない(IMPL-0035 と同型)。ADR-0129 が「確認の記名」を機械で閉じないとして不採用にした理由は、所在の記入にも内容の側で当てはまる。**記入の有無が埋まる=強制が効く、と読まれるのが最も危うい**。manual と根拠水準マークで開示するほうが、読み手に何が確かめられていないかを正しく伝える。
- 注記: これは「何もしない」ではない。IMPL-0519 の note は採用者への要請として残り、未達として表示され続ける(消さない原則)。

### B-3 求めた場合の対象
- 求めないので争点は消える。範囲の線引きは IMPL-0834 の降ろしの中で #446 が決める(本審議で決めない。材料が足りない点は「先送り」ではなく担当 Issue がある)。

### B-4 強制できない環境の扱い
- **判定: 表示のみ。登録の拒否を機械の検査へ移さない。**
- 落とす案: 構成の登録を拒む。理由: 手段の所在は確かめられるが、強制の有効性は決定可能な条件でない(C-3 の方針: 機械の検査は決定可能な条件だけ)。拒む検査は、所在を書いた者を通し、書かない者を止めるだけで、強制の実効は何も確かめない。
- 受け方: 要求事項5 を満たさない状態は、7.3 の対象ではなく(:60)、**逸脱として扱われる**。適用の表明と適合の主張に件数を併記する既存の経路で、利用者は知る。

### B-5 準拠テンプレートの位置づけ
- **判定: 「テンプレートの上では L3 を解禁できない」と標準に書かない。**
- 理由: これは条文からの推論で、テンプレートの現状に依る(実行基盤の側の強制は採用者の持ち物)。標準の条項が特定の実装の現状を言い切ると、実装が変わったときに条項が誤りになる。実態の開示は IMPL-0834 の未達の表示と附属書H が担う。
- ただし開示の水準は上げる: 保証の開示に「3.12.10 要求事項5 は準拠テンプレートでは降りていない」が出るかを、突合で確かめる(research は未確認と明記)。出ないなら、それは編集の指摘として直す対象である。

### B-6 第8章・F-6 との関係
- **判定: 別の論点として扱う(本審議の範囲外)。** Q2 の結論(新設しない)は第8章の切替の前提を動かさないので、連動の修正は要らない。F-6 は #352 の側で扱う。

### C-2 「採らないと決めたこと」の記録

## 6. 根拠水準マーク案(EV)

- **対象**: 手戻り率の判定不能・基準値の未設定で L3 を止めない判断。3.12.10 要求事項5 の所在の記入を機械で確かめない判断。
- **根拠の水準**: E0(実証なし)。外部は二次情報のみ(SPC の一般論、J3016 の要約)で、DORA・J3016 の原文は未読。
- **差し替え条件**: (a) CL1 以上で、手戻り率の増加が検知されないまま L3 が続いた出荷後の不具合が1件でも観測されたとき。(b) 基準値に根拠のない値を置いて発火しない構成にした事例が観測された場合は、**止めない案ではなく、基準値の記録の水準を審議する**。(c) 規格(IEC 61508 の診断カバレッジ、J3016 の ODD)の原文を確かめ、診断が働いていないことを故障として扱う要求が開発プロセスに援用できると確かめたとき。(d) 手戻り率の算出が第三者に十分に使われ、誤発火率が観測できたとき。

## 8. 弁護が認める弱点(議長への注意)

1. 文言上は読み A が強い(research 2.1)。止めない案を採るには、:247・:268 の編集で読みを確定させる必要があり、**編集では済まない可能性**がある(意味が変わる)。議長は、これを意味を変える編集として重に含めるかを裁定してほしい。
2. 止めない案は、開示が読まれる前提に立つ。開示が適合の主張の文面に出る保証は、観点23 と EV-0279 の弱さに依る。ここは認める。
3. 外部の根拠は薄く、どの案も E0〜E1 である。私の案が信頼性で勝つという主張は、2 節の予測(偽の値の誘因)に依り、これも実証が無い。会議体が「止める」を採る場合は、記入で解ける停止が偽の値を誘わない仕組みを、別の委員が示してほしい。
