# #445 へ寄せるコメント(案。投稿はしていない)

#325(事前レビュー期間の検査と読み込みの記録)の審議の結果、次を #445 へ寄せる。

1. 3.10.2 は「期間を短縮できるのは第7章 7.4 のファストトラックを適用した場合に限る」と定める。短縮の下限(何営業日まで縮めてよいか)は、本標準はまだ定めていない(未決)と 3.10.2 に書き、根拠水準マーク EV-0281 で開示した。課さないと決めたのではない。下限を置くかは重の審議を要し、#325 では決めていない。
2. 短縮後の日程を台帳の行の必須欄にすること、下限の数値を置くこと、pre-review-closed を採用者の既定の必須チェックにすること(P2)は、採用者への新しい義務に当たる。**重の審議**(調査・5 委員の会議体)を要する。#325 では決めていない。
3. 順序: #325 の IMPL-0830(短縮をファストトラックの適用に限る照合)は、#445 の IMPL-0608〜0610(適用の期日・申請書・乱用の制約)が先に要る。台帳の行に、ファストトラックの適用の区分と短縮後の日程が読める欄が決まるまで、IMPL-0830 と #325 の T11 は降ろせない。
4. 採らなかった案: 3.10.2 の参照を第7章 7.3 へ差し替える(短縮を許す場面が広がる緩和になる)。
5. 第7章 7.4「後回しにできる対象」は限定列挙で、事前レビュー期間(3.10.2)を含まない。字義どおりでは、7.4 を適用しても期間は短縮できず、3.10.2 の経路が働かない可能性がある。7.4 に行を足すか 3.10.2 を直すかは、下限と同じ審議で決める(どちらも重)。#325 では決めていない。IMPL-0830 の着地点は7.4 の列挙に無く、限定列挙を追う IMPL-0567 が先に要る。ただし IMPL-0567 は禁止の行(G-4・G-5・認証・認可・データ保全)だけを追い、列挙に無い対象を短縮しないことは追わない。どちらの直しでも、マークの範囲を合わせて決める。
