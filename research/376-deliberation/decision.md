# 議長の裁定(#376 任免と緩める向きを同じ変化点に含むときの向きの優先)

入力: 議題 `council-00-agenda.md`、調査 `survey-376-1-internal.md`・`survey-376-3-probe.md`(追加の確認を含む)、意見 `council-01-drafter.md`(起案)・`council-02-field.md`(現場)・`council-03-qa-audit.md`(品質監査)・`council-04-standards.md`(規格)・`council-05-defender.md`(弁護)。外部調査 `survey-376-2-external.md` は裁定の時点で届いていない。届いたら突合し、裁定と食い違う点を本書の末尾へ追記する。

## 0. 骨格

単一値の向きは**要約**であり、記名の要件は**行ごと**に照らす。5 委員はこの構造で一致した。決定できる者は向きの値ではなく行ごとの照合で決まる(内部調査 §1.3)。#319 の X-6 が根拠とした「元の注記」は任免と発生の優先を述べたもので、緩める向きとの優先の根拠にならない(内部調査 §3)。Issue 本文の「ADR-0087 の決定5」は ADR-0088 決定5 の誤記である。

## R-1 向きの単一値 — 裁定: 案B(緩める向きを優先する)

- 1つの変化点が緩める行を1件でも含めば、要約の向きを「緩める」とする。優先の順は 緩める > 任免の決定 > 未達の発生 > 厳しくする > なし(今の導出。5 委員)
- 緩める行と任免の行を両方含むときは、表示を「緩める(任免を含む)」とする(現場・規格・品質監査)
- 単一値の向きを、記名の要件の根拠に使わない。要件は行ごとに照らす(起案・規格)。これを第5章「向きの扱い」へ書く
- 採らない: 案A(任免を優先)。緩める向きの変更が要約から消え、任免の記名で全体が決まったと誤読させる(5 委員)。案D(向きを集合で持つ)。行ごとの区分(R-4)と同じ事実を2か所に持ち、`SIGNED_DIRECTIONS` を引く帰属の照合の移行で取りこぼす危険がある(起案・弁護)。品質監査の委員の案D は、R-4 の行ごとの区分で目的を満たすため採らない

## R-2 記名の要件の積が空になる組 — 裁定: 積を緩めず、変化点を分ける規定と案内を置く

- 1つの変化点の記名者は、その変化点のすべての行(任免・緩める・名簿の表記の変更)の要件を満たす1人に限る。満たす者がいなければ受け付けない(今の挙動。品質監査・規格・弁護・現場)
- 満たす者がいない場合は変化点を分ける。分け方: 決定者その人を替える変化点と、組織上の任命権者が記名する変化点に、緩める行を入れない。緩める行は、新しい決定者が記名する後の変化点で決める。実行で、(a)(b) のどちらも分ければ通ることを確かめた(probe の追加の確認 1。弁護の委員の維持の条件を満たす)
- ADR-0088 決定5 の「同じ差分の中に緩める向きの行として出す。その変更の記名で決める」は維持する。代償措置の終了は未達を解く差分に出て、分けた後でもその差分の記名で決まる(probe 2)。決定5 が前提にした「記名者がその差分のすべての行を決められる」ことが成り立たない場合の扱いを、新しい ADR で補う
- 拒否の文言に、分け方の案内を足す(5 委員。今は案内が無い)
- p302 で通っていた (b) の場面が拒否されることは、回帰ではなく正しい強化と判定する(現場・品質監査・規格・弁護)。p302 は緩める行の要件を照らしていなかった
- 採らない:
  - 起案の委員の「決定者を替える変化点では、緩める行を変更前の決定者が決める」案。緩める行は変更後の構成で効く。決定の権限を離れる者に、その後の構成の緩和を決めさせることになる。外部の裏づけも無い
  - 混在の一律の拒否。S1 では任免と終了の行を入力として分けられない(現場)
  - 2名の記名(連名)。3.13.4 記録5 は単数で、根拠が無い
  - 任命権者に緩める権限を渡す案
  - 要件の和(どちらか一方の要件で足りる)とする案。統制の抜け道になる

## R-3 兼務の行 — 裁定: 緩める行として扱う今の分類を維持し、見つかった2点は後継の Issue で審議する

- 新しく生じる兼務の行を緩める行とし、決定できる者を D-0 表1 の決定者に限る今の扱いを維持する(5 委員)
- 実行で次の2点が見つかった(probe の追加の確認 2・3)
  1. 兼務を照合する鍵が席の組だけで人を含まない(generate-profile.mjs 227 行)。そのため、離脱(発生)で入った兼務は、後で別の人を置けるようになっても行が出ず、誰の決定にも掛からずに続く
  2. 決定者は、自分が当事者になる新しい兼務を自分の記名で決められる(3.13.3 の文言どおり。新任の決定者が自分の任命を確定してはならない規定と、形が似ている)
- どちらも本件の論点(向きの優先)の外にあり、兼務の禁止の規定(第3章 3.5)と小さい体制の扱い(1〜2名で決定者のほかに決められる者がいない)に及ぶ。調査と会議体を経ずに条項を置かない。後継の Issue #432 を起こした
- 採らない(本件では): 兼務の当事者が決定者のとき、変更前の決定者の記名を要する案(規格・現場)。後継の Issue で審議する

## R-4 記録と期待値 — 裁定

- 3.13.4 の記録に「変更の行ごとの種類(任免・緩める・名簿の表記の変更・厳しくする・未達の発生)」を加える。準拠テンプレートの `changeLog` の記録は、差分の行ごとに種類を残す。旧い記録には無くてよい(移行しない。無い記録は、種類の区分の無い記録として扱う)(5 委員)
- 記名者が満たした要件の根拠(資格)を行ごとに残す案(現場・品質監査)は採らない。資格は記録の時点の構成から導け、同じ事実を2か所に持つ。保証の開示と監査は構成の履歴から照らす
- matrix-sweep の mvp・growth の印(`#376`)を外し、期待の向きを「緩める」へ改める。`changed.by` には新しい ADR の決定1 を引く(ADR-0088 決定5 は引かない。決定5 は向きの優先を定めていない)
- (a)(b) を分けて通す場面と、分けずに拒否される場面(案内の文言を含む)を回帰スイートへ固定する
- ADR-0110 を新設する。ADR-0089 の状態の節に、#376 の印を ADR-0110 で解いた旨を足す
- EV: 分ければ通ることは、確かめた組((a)(b)、2名 cl0 の3行)にしか支えられない。EV-0228 で開示する
- IMPL: 3.13.3 の新しい要件(行ごとの照合と分け方)と 3.13.4 の行ごとの種類を、準拠テンプレートへ降ろす(IMPL-0444・0445)

- 兼務の照合の鍵が人を含まないことと、決定者が自分の兼務を決められること(R-3)。後継の Issue #432
- 外部調査の突合(末尾の節で済ませた)

## 採らない案(まとめ)

| 案 | 理由 |
| --- | --- |
| 任免を優先する(案A) | 緩める向きが要約から消える |
| 向きを集合で持つ(案D) | 行ごとの区分と重複する。帰属の照合の移行の危険 |
| 緩める行を変更前の決定者が決める | 権限を離れる者に、その後の構成の緩和を決めさせる |
| 混在の一律の拒否 | 任免と終了の行を入力として分けられない |
| 2名の記名・要件の和 | 根拠が無い。和は抜け道になる |
| 記名者の資格を行ごとに記録する | 構成の履歴から導ける。重複 |

## 外部調査との突合(裁定の後に届いた `survey-376-2-external.md`)

- NIST SP 800-53 Rev.5 CM-3・CM-4・CM-5(4)・AC-5 は、束ねた変更の承認の要件の合わせ方(最も厳しい要件・分割・和)を明文で定めず、組織に委ねる(転載で確認。原典 PDF は未読)。本標準が自ら決める事項であり、裁定と矛盾しない
- 業界の実装: Prow approve は、変更が触れたすべてのファイルについて OWNERS の承認者の承認を求める(触れた範囲すべての要件を満たすこと = 本裁定 R-2 の「すべての行の要件を満たす1人」と同じ側)。GitHub rulesets は食い違う定義に最も厳しい版を当てる。どちらも、要件を緩める合わせ方を採っていない
- 分割による迂回の禁止(FAR 13.003(c)(2))はある。本裁定の「分ける」は、要件を満たす者がいない場合に、各段をその段の要件を満たす者が記名する形であり、要件を下げる分割ではない。緩める行は分けた後も決定者の記名を要する
- ISO 27001 附属書A 5.2・5.3・8.32、ISO 20000-1、ISO 9001 6.3・8.5.6、ITIL 4 は原典を読めていない。EV-0228 の見直しで確かめる
- 裁定の変更: なし
