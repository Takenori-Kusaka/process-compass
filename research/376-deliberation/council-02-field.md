# #376 会議体 委員意見: 現場(採用組織の開発者・責任者)

- 日付: 2026-11-05
- 立場: 準拠テンプレートを使う採用組織の開発者・責任者。手数、拒否の文言の分かりやすさ、1〜2名の体制での詰み(誰も通せない変化点)を重視する
- 入力: `council-00-agenda.md`、`survey-376-1-internal.md`(以下「内部」)、`survey-376-3-probe.md`(以下「probe」)。`survey-376-2-external.md` は本稿の作成の時点で未着のため引いていない
- 判断軸: 信頼性。変更量の少なさは理由にしない
- 所在の表記: 標準 = `src/content/docs/phase4-process-design/roles-responsibilities.md`、生成 = `template/scripts/init/generate-profile.mjs`

## 現場から見た本件の核心

採用者が困るのは「向きのラベルが何と出るか」より、**変化点が通らず、どう直せば通るかが分からない**ことです。probe の (a)(b) は、1〜2名の体制で普通に起きる引き継ぎ(前任の離脱の後の任命、決定者の交代)で起きます。したがって本稿は R-2・R-3 を重く扱います。R-1 は、読み手(監査・品質保証部門、半年後の自分たち)が改訂履歴から「この変化点で何が緩んだか」を読めるかで判断します。

## R-1 向きの単一値の優先

### 推す案

**案B(loosen を優先)を単一値の規則として ADR に記録する。あわせて、表示のラベルは単一値だけに頼らず、R-4 の行ごとの区分から「緩める(任免を含む)」と出す。**

単一値 `direction` は loosen > appoint のまま据え置き、これを「決定」として初めて書き下します。

### 理由

1. **記名の可否は単一値で決まっていない**。照合は項目ごと(生成 2171 行 `deciderProblems`、5248〜5251 行)で、`SIGNED_DIRECTIONS = ['loosen','appoint']`(config.mjs 308 行)は両値を同じに扱う(内部 §1.3、probe まとめ表)。単一値が左右するのは**読み手の見え方**だけです。現場の読み手にとって重いのは緩める向きです。標準は緩める向きを重く扱う非対称を明記しています(標準 1973 行。5.4.5・5.4.6 と同じ非対称)
2. 改訂履歴の向きの欄が「任免の決定」だと、カバレッジの下限が 90 → 80 に下がった変化点(probe 確認1 の mvp・growth)が、要約からは**人の付け替えにしか見えません**。下限が下がったことは、後で不具合を振り返る人が最初に探す情報です
3. 今の導出(生成 2101〜2111 行)、poc 行の期待(印なし loosen)、規則の承認による上書き(生成 5421 行付近)、ADR-0088 決定5「同じ差分の中に緩める向きの行として出す」(ADR-0088 133 行)が、すべて同じ側にあります。B を決定として記録すれば、表示の5か所(内部 §1.3)の挙動を変えずに、根拠の無い状態(X-6 の指摘の核)を解けます
4. 任免を含むことは単一値から消えますが、`diff` の行、変化点の報告の節「席の責任者の任免・決定者の変更」、`appointerSigned` に残ります(内部 §4 案B)。消える情報は「要約の欄の1語」だけで、R-4 の行の区分で補えます

### 他の案を落とす理由

- **案A(appoint を優先)は採らない**。緩める向きが要約から消えます(内部 §4 案A)。さらに「任免の記名があれば緩める行も決まる」と読める表示になりますが、任免と緩める向きの要件は照合の時点も決定できる者の集合も違います(内部 §2.2 の表)。probe の S2a-iso・S3 b2 で、任免の要件だけを満たす記名が拒否されたことがその実例です。表示が誤った期待を生み、拒否されたときの混乱が大きくなります。現場にとって最も悪い組み合わせです
- **案D のうち「向きを集合で持つ」形は採らない**。`SIGNED_DIRECTIONS.includes(e.direction)` の3か所と表示の5か所を改め、旧い記録の移行が要ります(内部 §4 案D)。この費用が理由ではありません。**集合は、行ごとの区分(R-4)より情報が少ない**ためです。「loosen と appoint を含む」と分かっても、どの行が緩める行で誰が決定できたかは分かりません。区分を行に持たせれば、集合はそこから導けます。同じ目的に対して劣る表現を正本にしません
- **案D のうち「複合のラベル」の形は、表示の側でだけ採る**(推す案の後半)。単一値の正本は loosen のまま、表示は区分から組み立てます

### 条件と留保

- 複合のラベルの導出は R-4 の区分の記録が前提です。R-4 で区分を残さない結論になった場合、複合のラベルは `diff` の文字列から推すことになり、壊れやすいため、そのときは単一値 loosen の表示にとどめます
- 規則の承認による上書き(生成 5421 行付近)との整合は、probe で試していません(probe「試験していないこと」)。B の記録の前に、上書きの場面でも loosen > appoint が同じに成り立つかを試験で確かめる必要があります(未実証)
- 「読み手は要約の向きの欄から緩める向きを探す」は、現場の立場からの見込みで、採用者の観測はありません(未実証)。根拠水準のマークの対象です

## R-2 記名の要件の積が空になる組

### 推す案

**案C のうち「積が空のときだけ、分け方を具体に案内する」形を採る。混在そのものは拒否しない。加えて、積が空になる原因が代償措置の終了の行(ADR-0088 決定5)だけのときは、その行を「未決定のまま 90 を保つ」で通す経路を候補として会議体に諮る(条件付きで推す)。**

拒否は残します。誰も決定できる者のいない緩める行を、誰かの記名で通すことはしません。直すのは、拒否の後に採用者が**自力で通せる道筋を必ず持つ**ことです。

### 理由

1. **詰みは観測された**。(a) は任命権者でも新任の決定者でも拒否され(probe S2a・S2a-iso)、(b) は前任でも新任でも拒否された(probe S3 b2)。どちらも1〜2名の体制で普通に起きる引き継ぎです。ところが緩める行の拒否の文言には分ける案内が無く(probe「観測から加わった事実」1、生成 2238〜2241 行)、任命権者の記名では緩める行の拒否だけが出ます(probe S2a-iso の全文)。採用者は「任命権者でも決定者でもない」と言われ、**誰なら通せるのかが文言から導けません**。現場では、ここで構成を手で編集する、または AI に通し方を考えさせる誘惑が生じます(テンプレートの CLAUDE.md は手で編集しないと定めています)。統制を迂回させる圧力を生むこと自体が信頼性の欠陥です
2. **分ければ通ることは観測された**((a) は S2s-1 → S2s-2)。分けても代償措置の終了は未達を解く変化点の差分に出て、その変化点の記名で決まりました(probe まとめ表の最終行)。ADR-0088 決定5「同じ差分の中に…その変更の記名で決める。別の記名の儀式は要さない」(ADR-0088 133 行)と両立します。案内を足すことは、標準・ADR の要件を何も緩めません
3. 案内の中身は、拒否の側が既に持つ情報から作れます。照合は項目ごとに「誰なら決定できるか」を知っています(生成 2171〜2245 行)。案内に書くべきことは次の3点です
   - この変化点は、任免の行を決定できる者(例: 組織上の任命権者)と、緩める行を決定できる者(例: 変更後の決定者)が重ならないこと
   - 先に任免だけの変化点を、任免を決定できる者の記名で出すこと。その変化点では、緩める行を生む入力(独立レビュアへの別の人の任命、兼務を生む任命)を外すこと
   - 次の変化点を、新しい決定者の記名で出すこと
4. **代償措置の終了の保留(条件付き)**。(b) の S3 b2 は、p302 では下限 90 のまま 1人目の記名で通っていました(probe「p302 の版の S3」)。今の版で拒否される原因は、決定5 が加えた下限の行だけです。この行は「下限を下げる」決定で、下げないままにしておく側は厳しい状態です。積が空のとき、終了を未決定として 90 を保ったまま任免を通し、`/pit` に「代償措置の終了が未決定(決定できる者: …)」と出し続ければ、緩める決定を誰も無資格で下さず、採用者も詰みません。分ける手数を採用者に課すより、厳しい側に倒して決定を後へ送るほうが、現場の誤操作の余地が小さいと見ます

### 他の案を落とす理由

- **混在を一律に拒否する案(案C の強制)は採らない**。最も多い 1名 → 2名 の場面(probe 確認1 の S1、matrix-sweep の 2名 mvp・growth・poc)では、2人目を独立レビュアへ任命すること**そのもの**が未達を解き、同じ差分に終了の行を生みます。任免と緩める行は入力として分けられません(内部 §4 案C)。一律に拒否すると、今は1人目の記名で通っている最も普通の成長の場面が、誰にも通せなくなります。詰みを減らす目的と逆です
- **2名の記名を要する案は採らない**。`decidedBy` が1つのスキーマ、3.13.4 記録5「決定した自然人」(標準 2031 行。単数)、ADR-0106 の記名者ごとの帰属の裏づけを改める必要があります(内部 §4 案D)。費用ではなく、現場の手数と取り違えの面で劣ります。1つの変化点に2人の記名を同時に揃える調整は、分けて順に記名するより難しく、外部の任命権者が関わる (a) では特にそうです。また「どちらの記名がどの行を決めたか」を記録で区別する必要が生じ、分けた場合の「1変化点 = 1人の決定」より読み手の負担が大きくなります。分けて通る以上、同じ統制をより複雑な形で実現する理由がありません
- **今のまま拒否する案は採らない**。理由1 のとおり、文言から通し方が導けない拒否は、統制ではなく行き止まりです
- **任命権者に緩める行の決定を認める案は採らない**(議題に無いが、現場から出やすい要望として明記する)。任命権者は体制の外の人で(標準 1993 行)、緩める向きを決定できる者は対象の席の責任者か決定者に限られます(標準 1977 行)。詰みを解くために決定できる者を広げるのは、R-2 の目的に対して過大です

### 「p302 で通っていた場面が拒否される」ことの評価

**回帰ではなく、決定の新設に伴う正しい強化である。ただし、案内の欠落は回帰として扱う。**

- p302 で S3 b2 が通ったのは、緩める行がそもそも無かった(下限は 90 のまま下がらなかった)からです(probe「p302 の版の S3」)。今の版で同じ記名が拒否されるのは、下限を下げるという新しい決定に、決定できない者が記名したからで、向きの値の変化によるものではありません(probe「内部調査に無かった、実行で分かったこと」3)
- 一方で、採用者から見れば「先月まで通った引き継ぎが、理由の分からない拒否で通らなくなった」です。ADR-0088 決定5 の実装は、受け付けの可否を変える場面を持つことを記録していません。この点は、決定の新設の際に通し方を同時に示さなかった欠落であり、回帰の扱い(回帰スイートの場面として固定する)に値します

### 条件と留保

- **(b) を分けて通す手順は試験していない**(probe「試験していないこと」)。S3s-2 は分けても兼務の行で拒否されました。3段(決定者の交代だけ → 新しい決定者の記名で AI維持管理者を移す)で通る見込みは推測です(未実証)。案内を出す前に、この手順が通ることを回帰スイートの場面として確かめる必要があります。案内した手順で通らなければ、案内は拒否より悪い結果を生みます
- R-3 の結論によっては、(a)(b) の積が空になる場面の一部は解消します(兼務の行の決定できる者を変える場合)。R-2 の案内の文言は R-3 の結論の後に確定させます
- 「分ける手数より、終了の保留のほうが誤操作が少ない」は現場の見込みで、採用者の観測はありません(未実証)。保留の経路は ADR-0088 決定5「同じ差分の中に…その変更の記名で決める」に例外を足すことになるため、新しい ADR が要ります。保留が長く残ることによるオーバーヘッド(下限 90 のまま放置される)を防ぐため、`/pit` の注記と出荷の集約に出し続けることを条件とします
- 外部の確認者が独立レビュアの席に就く場面、`holderOnly` の緩める行との組は試験していません(probe「試験していないこと」)。積が空になる組はこのほかにもありうるため、案内は特定の組の列挙ではなく、照合の結果(各行の決定できる者の集合が重ならないこと)から一般に組み立てます

## R-3 兼務の行の扱い

### 推す案

**兼務が新しく生じる行を「緩める向き」に数えることは正しい。ただし、決定できる者を「変更後の決定者に限る」は改める。同じ変化点の任命で兼務が生じる場合、その兼務の行は任命と同じ者(変更前の決定者、前任が離脱済みなら組織上の任命権者)が決定する。少なくとも、兼務を負う本人には決定させない。**

### 理由

1. **緩める向きに数えることは標準と合う**。この行は「別の人を置ける体制で、同じ人が兼ねる決定である」と出ます(生成 1458 行)。人が減っていないのに統制を減らす選択は緩める向きです(標準 1977 行)。1〜2名で成立しない兼務禁止は列挙に無い離脱として記録し表示し続ける(標準 442 行)とされており、離脱を生む選択が決定であることとも合います。発生(記名なし)へ移す理由はありません(標準 1980 行は、発生を人が実際に減った場合に限る)
2. **今の決定できる者は、新任の決定者に自分の兼務を自分で決めさせる**。probe S2a では、事業決裁者と出荷判定者を兼ねることになる2人目(新任の決定者)だけが、その兼務の行を決定できました。S3s-2 でも、AI維持管理者と AI運用担当者を兼ねることになる2人目だけが決定できました(probe 確認3)。標準は「新任の決定者が、自分の任命を自分の記名で確定してはならない」と定めます(標準 1994 行)。誰がどの席を兼ねるかは任命の中身そのものであり、兼務の行だけを本人の記名で決めさせるのは、この規定の趣旨と逆向きです。拒否が(a)(b) の詰みを作るだけでなく、**仮に分けて通った場合も、本人が自分の兼務を決めた記録が残る**点が、現場から見た信頼性の欠陥です
3. 任命の決定者がこの行を決めれば、(a) の S2a と (b) の S3s-2 の拒否は、要件の積が空にならずに解けます。兼務を決めるのは、その兼務を負わせる任命をした者になり、記録の上でも「誰の判断でこの人に2つの席を持たせたか」が1人に定まります
4. 兼務の行の決定できる者が変更後の構成で照らされている理由は、生成の注記(5249〜5250 行)にも ADR にも見当たりませんでした。意図した選択か、緩める向きの照合(`allowedDeciders(config, …)`)を一律に変更後の構成へ当てた結果かは未確認です

### 他の案を落とす理由

- **兼務の行を緩める向きから外す(発生、または向きなし)案は採らない**。人が減っていないのに統制を減らす選択を記名なしで通すことになり、ADR-0055 が却下した「席の責任者の交代を、向きを持たない変更として記名なしで通す」(内部 §1.2、ADR-0055 採らなかった案)と同じ穴を開けます
- **今のまま(変更後の決定者に限る)は採らない**。理由2 のとおり、本人が自分の兼務を決める形を作ります。分ければ通るとしても、通った記録の中身が標準 1994 行の趣旨に反します
- **兼務の行を、変更後の決定者と任命の決定者のどちらでも決定できるとする案は採らない**。どちらでもよいとすると、新任の決定者が自分の兼務を決める道が残ります

### 条件と留保

- 本案は3.13.3 の「緩める向きの決定できる者」に、時点(変更前か変更後か)の定めを足すことになります。標準は今、時点を定めていません(標準 1977 行)。条項の改めになるため、調査・会議体・突合の手続を経た新しい ADR が要ります。本稿は現場の立場からの提案であり、採否は会議体の議論に委ねます
- 1名の体制(個人事業主等。標準 1994 行の例外)と初回の記入では、本人が決めるほかありません。この例外はそのまま残します
- 兼務の行のほかに、任命が生む緩める行(例: G-6 の「未達 → 適用しない」。probe 確認1 の poc 行)にも同じ論が当たるかは、本稿では検討しきれていません。G-6 の行の決定できる者は今は D-0 表1 の決定者で(probe 確認1)、S1 では前任と後任が同一人物のため問題が表に出ていません。決定者の交代と G-6 の行が同じ変化点に入る場面は試験していません(未実証)
- 代償措置の終了の行(下限)は、席の責任者の名義で決められる(AI維持管理者の席)ため、兼務の行と同じ扱いにはしません。R-2 の案内・保留で扱います

## R-4 記録と期待値

### 推す案

1. **`changeLog` に行ごとの区分を残す**。各行に、区分(任免・緩める・厳しくする・発生・名簿の表記)と、その行を決定できた者の集合(照合で使った値)を持たせる。単一値の `direction` は R-1 の規則で導いた要約として残す
2. **matrix-sweep の印は、R-1 の決定を記録した ADR を `changed.by` に引いて外す**。mvp・growth の期待を `向き loosen` へ改め、`knownFailure` の2件を消す。`changed.by` は「ADR-0088 決定5」ではなく新しい ADR を引く
3. **R-2・R-3 の場面を回帰スイートへ足す**。probe の S2a・S2a-iso・S2s・S3 b1・b2・b0・S3s を場面として固定し、拒否の文言に分ける案内が含まれることまで期待値に入れる
4. **新しい ADR を1本立て、R-1〜R-3 の決定と採らない案を記録する**。EV・IMPL は下記

### 理由

1. 区分が記録に無いと、R-1 の複合のラベルは `diff` の文字列から推すしかありません(内部 §1.3「どの行が任免でどの行が緩める向きかの区分は記録に残らない」)。また、R-2 のように拒否と受け付けが「どの行を誰が決定できたか」で決まる以上、後で記録を読む人(監査、次の担当者)が「この記名はどの行の決定として有効だったか」を確かめる手がかりが要ります。3.13.4 は区分を要求していません(標準 2025〜2032 行)が、要求していないことは残さない理由になりません。記録5「決定した自然人」を、どの決定についての自然人かと結べるのは区分だけです
2. 区分と決定できた者の集合を残すと、ADR-0106 の帰属の照合(material-attribution.mjs 562 行。今は `decidedBy` の帰属だけを照合し、席の要件は再照合しない。内部 §1.3)で、後から要件の再照合を足す道も開きます。今回の範囲で再照合を足すことは求めません

### EV・IMPL

- EV: R-1 の「読み手は要約の向きの欄から緩める向きを探す」、R-2 の「保留のほうが分けるより誤操作が少ない」、R-3 の「兼務の行を任命の決定者が決めるほうが記録の信頼性が高い」は、いずれも採用者の観測が無い判断です。採るものには根拠水準のマーク(ADR-0026)を付け、見直しの期日を置く。差し替えの観測の源は、採用者の変化点の記録(拒否の件数、分けた変化点の件数、保留の残存期間)とする
- IMPL: 「拒否の文言に、積が空のとき分け方を示す」「兼務の行の決定できる者」「changeLog の行の区分」は実行主体の挙動を制約するため、降ろし先 `config-change-log` 等(`src/data/impl-targets.yaml` に登録済みのものから選ぶ)へ実装マークを付ける。降りるまでは `state=undelivered` で表示し続ける

### 採らない案(R-4)

- **区分を残さず、`diff` の文字列と報告の節の見出しから後で読み取る案は採らない**。文字列の文言は版ごとに変わっており(probe「p302 の版での同じ場面」の文言の違い)、後から機械で区分を復元できる保証がありません
- **印を外さず見直し 2026-12 まで据え置く案は採らない**。印の根拠(X-6)の前提のうち「決定できる者が変わる挙動」は事実と合わないことが確かめられており(内部 §3 の突合の所見)、残すと誤った前提を期待値に保ち続けます
- **向きの値だけを改めて、R-2・R-3 の場面を足さない案は採らない**。本件で見つかった実害は向きの値ではなく詰みと文言です。値だけを直して閉じると、Issue の題に答えて現場の問題を残します
