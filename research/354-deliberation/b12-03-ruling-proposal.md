## 採らない案(記録)

| 案 | 理由 |
| --- | --- |
| IMPL-0986 を `issue=329` へ付け替える | #329 の裁定が T-1 を #354 へ寄せ、#329 に残すのは T-7 だけとした。寄せ戻しになり、#329 の閉じる条件を後から広げる。降ろし方(構成の欄)は ADR-0147 決定1 が採らなかった型で、降ろす見込みが無いまま scheduled を表示する |
| IMPL-0986・IMPL-0309 を #446 へ付け替える | 降ろす見込みが無い項目を予定として積む。先送りの表示 |
| ADR を起こさず `decision=ADR-0090`・`ADR-0083` を指す | implementation-marking.md は、採用者に委ねる理由と**求めること**を decision= の記録に書くと定める。ADR-0090 決定6 は資格情報の形を、ADR-0083 決定2 は経路を持たないことを書くが、名の数え方と再開の数え方を採用者に求めていない |
| 構成に配備の資格情報の欄を足す(#329 の T-1) | 記録の正本が2つになり、自己申告の値が実態の離脱を隠しうる(ADR-0147 決定1 と同じ) |
| ワークフローの YAML と env-check から (a) を推定して数える | 配備のジョブの特定が推定。(b)(c) は読めない。env-check の3項目を G-8 の判定に使わない決定(ADR-0090 決定6)と食い違う。部分の検出を数えたと表示すると、確かめていない条件を確かめたと読ませる |
| `/process-change` に種別 `resume` を足す | 終了の記録を覆せる操作が増え、ADR-0083 決定2・ADR-0068 決定3 の型に反する |
| 再開に代えて「新しい案件として始め直す」を案内する | 1.10.4 が塞ぐ数え直しの型そのもの |
| 記録の欠落の件数の数え方を実装の担当に選ばせる | 名を下げる式と併記の件数が別になりうる |
| 表明の文を機械が書く | 名義(ADR-0083 の「表明する者が述べる」) |
