## 所見

### 高-1 確認日の無い記録を「日付の書式」に入れ、離脱に数えない(表示と実態の食い違い)

- **所在**: `template/scripts/gate/org-assurance.mjs` の `continuityState`(`[why, kind] = ['確認日(YYYY-MM-DD)が無い', isFilledValue(rec) ? 'unresolved' : 'missing']`)。表示の側は ADR-0147 決定2 の(2)と「解けない」の一覧、IMPL-0521 と IMPL-1102 の note、`generate-profile.mjs` の構成書の注記
- **根拠**: 場面 O・P。欄に文字があれば、日付らしい語が無くても `unresolved`(書式)になる。「演習」だけ、「未確認」と書いた記録は、確認日が無いのに名を下げない。ADR-0147 決定2 は「確認日なし」を離脱に数えると書き、追認も「確認日なしは要求事項8 を欠く」とした。一方、L(欄が空)と O は同じ理由の文「確認日(YYYY-MM-DD)が無い」で逆の帰結になる。O・P の UNV は「数えなかった理由が書式・層1 の欠けのため」と出るが、括弧の理由は「確認日が無い」であり、出力の中でも食い違う。向きは離脱を見落とす側で、ADR が「受け取る者が気づけない」とした側である
- **直し方の案**: 「日付の書式」を決定可能な条件で定める。例として、欄に日付らしい語(`\d{4}[/.年-]\d{1,2}[/.月-]\d{1,2}` のうち YYYY-MM-DD でないもの、または実在しない日)がある場合だけ `unresolved` にし、それ以外(日付の語が無い)は `missing` にする。理由の文も2つに分ける(「確認日が YYYY-MM-DD の書式でない」と「確認日が無い」)。ADR-0147 決定2 の一覧と IMPL-1102 の note に同じ線を書く。試験に O・P を違反の入力として足す

### 中-1 過去の範囲で、開示の表と名が別の時点を読む

- **所在**: `aggregate-evidence.mjs` の `continuity`(4240 行。作業ツリーと `releaseDay`)と、`recCore`・`recPolicy`(範囲の終点のコミット)。出力は `assurance.continuity.core` と `claim`
- **根拠**: R1。`--to X` の集約で、開示の表は保持者 1 名を示し、名の側は離脱に数えない。ADR-0147 の採らない案の2行目は「同じ出力の中で、開示の表と名が食い違う状態が残る」ことを理由に退けた。直しは名の側だけを終点へ移したため、過去の範囲ではこの状態を作る。直す前は両方が作業ツリーを読み、食い違わなかった。先頭までの範囲(出荷の通常の経路)では食い違わない
- **直し方の案**: 開示の表の `core` も終点の記録で読む(`recCore` を開示へ使う)。直さない場合は、ADR-0147 の「影響」と IMPL-0521 の note に「開示の表(組織継続の側)は作業ツリーを読み、過去の範囲では名と別の時点を示す」と書く。あわせて「確かめていないこと」の行を、R1 で確かめた結果に改める
- **開示の案**: 直さないなら `:::caution[暫定 EV-NNNN / 見直し 2027-05]` を ADR-0147 決定2 の最後の行へ付け、過去の範囲の開示の表が作業ツリーを示すことを書く

### 低

- **低-1** 場面 T。同じ人を2行に書き、1行は数え、もう1行は書式で数えないとき、離脱の文に「数えなかった: 名簿 甲」と出る(数は正しく「数えた 1 名・書いた 1 名」)。`detail` の数えなかった名から、数えた名を除く。開示の案: 直さないなら、文の意味(行ごとの理由)を IMPL-0521 の note に1文で書く
- **低-2** 構成書の注記(`generate-profile.mjs` 3654 行)は、ADR 決定2 の「ただし、数えられるか決まらない名を足せば2名に届くときは数えない」を書かない。場面 S と Q で帰結が分かれる理由を、採用者が注記から読めない。ADR の文を1文で写す。開示の案: IMPL-0521 の note が既に線を書いているので、注記に「詳しい線は ADR-0147 決定2」と所在を足す
- **低-3** 終点が先頭でない範囲の試験が無い(ADR の「確かめていないこと」に記載どおり)。経路は R1〜R3 で正しく働いた。R1 と R2 を test-edition-end へ足し、ADR の「確かめていないこと」の1行目を外す。開示の案: 足さないなら、ADR の行を「実行で確かめた(2巡目)。試験は無い」に改める
- **低-4** 試験に、追認した離脱の側の L(確認日の欄が空)・M(周期超過)・N(本人)と、混ざった場面 Q・R が無い。今回は実行で合った。IMPL-0521 は `check=machine` なので、違反の入力として足す。開示の案: 足さないなら IMPL-0521 の note に「確認日なし・周期超過・本人は試験に無い」と書く
- **低-5** B の UNV の理由は「周期が空欄」と出て、層1 なしとは書かない(別の行で層1 なしは出る)。理由を「層1 なし(周期を読めない)」と書き分ける。開示は不要(別の行で読める)
- **低-6** 仮の番号 IMPL-1102 が、template の `aggregate-evidence.mjs` 5346 行の注釈にもある。push の前の付け直しで、本体の印・台帳・登録簿に加えて、この注釈も直す
