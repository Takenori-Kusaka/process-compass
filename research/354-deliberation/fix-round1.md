# Issue #354 項目1・3 独立の突合(1巡目)への対応

議長の裁定: 「読んだ版」には根拠にした版を付ける。目録で見た現行の版は別に書く。存在しない箇条番号を足さない。IEC 61508 は SRC-0649 に合わせる。

| 所見 | 対応 | 内容 |
| --- | --- | --- |
| 高-1 ISO 13849-1:2023 に 4.5.2 | 直した | `overview.md:435` を「ISO 13849-1」に戻し、4.5.2 は「2010 年・2017 年の解説(二次)が引く」箇条で、2023 年版ではないと書いた。2023 年版での箇条番号と既定の扱いは確かめていない旨を明記。代替案にあった「6.1.4」は、突合が見た iTeh の見本の目次に基づく未起票の確認で、出典カードが無いため本文へ足さなかった(存在しない根拠を足さない)。`survey-419-2-external.md:135` に版の誤りの注記を足した |
| 中-1 附属書F の版が現行の版 | 直した | 見出しの文を、根拠(版を特定しない解説と 2015 年版の解説)と現行の版(目録で確認)に書き分けた。ISO 13849-1 の行に「4.6 の記述は 2015 年版の解説」。IEC 62061・ISO 26262 は「表の記述の根拠の版は不明」と明記 |
| 中-2 IEC 61508 | 直した | `safety-verification.md` と `04-traceability.md` を「第2.0版(2010)、目録で確かめた(SRC-0649)、本文は読んでいない」に揃えた。04-traceability は、並べた版が根拠の版でなく目録の現行の版であることも明記 |
| 低-1 template の注釈 | 直した | `generate-profile.mjs`・`verify-gate-contract.mjs` の注釈を ADR-0083(第1章 1.10.2 の閉じた列挙、いまは D-1 の G-7 の兼務)に揃えた。コメントのみ。`node --check` と `verify-gate-contract.mjs` の実行で確認 |
| 低-2 ISO 8601 の括弧書き | 直した | 規定の表の行から括弧書きを外し、表の下の注へ移した。追補の有無は確かめていない旨と、要求を 2019 年版へ固定しない旨を書いた(Amd 1:2022 は記憶による未確認のため、名を挙げていない) |
| 低-3 ISO 26262 の改訂審議 | 直した | 「改訂の素案(ISO/DIS 26262-2)が審議中(SRC-0744)」を足した |
| 低-4 JSQC-Std のカード無し | 直さない(開示で閉じる) | カードを起こすには全文 PDF を読み直して付録Cを抜き書きする必要があり、本 Issue の範囲を超える。代わりに `assurance-case.md` に「出典カードは作っておらず、根拠の所在は調査メモの S3 にとどまる」と開示した。カード化は出典台帳の次の整備(既存の open Issue)へ寄せる |
| 低-5 iso.org の 403 | 直さない | 突合の判断のとおり、開示で閉じている。次の版の棚卸しで iso.org を再度試す |

## 編集の範囲

意味の追加はしていない。ISO 13849-1 の箇条番号は足すのでなく、版の誤りを外した。
