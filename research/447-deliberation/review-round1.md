## 所見1(高)頻度が空欄のときの「記録が無い」の表示が、本文と IMPL-1022 で食い違う

- 所在: `src/content/docs/phase4-process-design/human-ai-boundary.md:348-350`(本文の3つの箇条)と同 `:375`(IMPL-1022 の note)
- 根拠:
  - 本文は3つの場合を並列の箇条で書き、優先の順を置かない。「範囲に数える行が無いとき: 「AI を用いない実施の記録が無い」。範囲の名を併記する」は頻度の有無に依らない
  - IMPL-1022 の note: 「頻度が空欄・読めない値のときは IMPL-1021 の表示だけを出し、日付を比べない」。「だけを出し」は、頻度が空欄で記録も無い範囲について「記録が無い」を出さないと読める
  - 裁定 `decision.md` 1.3 の状態の表も行を排他の状態として並べており、2.1 の本文(箇条)と IMPL-NEW1 の note の間で同じ食い違いを裁定の段から持ち込んでいる
- 影響: 降ろし先(集約)は note を仕様として実装する。note のとおり降ろすと、頻度を定めず記録も付けていない範囲で「記録が無い」が出ず、本文が求める表示が減る。本標準が避けると書く向き(表示を減らす向き)の食い違いであり、規範どうしの矛盾に当たる
- 直し方の案: IMPL-1022 の note を「頻度が空欄・読めない値のときは、日付を比べず、頻度を過ぎたことの表示を出さない。記録が無いことの表示は頻度に依らず出す」に改める(本文と裁定 1.3 の「猶予なし」の趣旨に合う)。逆に本文へ優先の順を足す案は、表示を減らす向きなので採らない方がよい

## 所見2(中)「頻度を過ぎた」の境界が本文に無い

- 所在: `human-ai-boundary.md:350`、IMPL-1022(`:375`)
- 根拠: 本文は「最後の実施の日から頻度を過ぎたとき」とだけ書く。裁定 1.3 は「最後の実施の日に頻度を足した日が基準日より前」と式で書いたが、本文・note のどちらにも移っていない。template の `withinInterval` は `day <= end` を内とする(期限の日の当日は内)。月の加算は `Date.UTC(y, mo-1+n, d)` で、1月31日+1か月は3月3日になる
- 影響: 決定可能性の観点(機械の検査にする条件)。期限の当日と月末の加算で、標準を読んだ者と降ろし先とで判定が割れうる。止めない表示なので損失は開示に留まるが、machine にする前提の条件としては定義が欠ける
- 直し方の案: 本文の箇条を「最後の実施の日に頻度を足した日が、保証の開示を作る日より前のとき」に改める。月の加算で日が無い場合(月末)の扱いは、降ろし先に任せると IMPL-1022 の note に書くか、「その月の末日」と定める(新しい義務ではなく判定の定義)

## 所見3(中)実施者を並べて書いた行の数え方が決まらない

- 所在: `human-ai-boundary.md:344`(「複数の人が実施したときは実施者を並べて書きます」)と `:346`(「実施者が人の名簿にある行だけ」)、様式の注記 `deliverable-templates.md:510-511`
- 根拠: 並べる区切りが無い。並べた名の一部だけが名簿に無い、または AI の名義を含む行を数えるかが書かれていない(裁定 1.2 は「名簿に無い名の行は数えない」とだけ書く)
- 影響: 機械の検査にする条件のうち、名簿との一致が一意に決まらない
- 直し方の案: 「並べた名がすべて人の名簿にある行だけを数える。AI の名義を1つでも含む行は数えない」と書く(不利な側へ倒す。テンプレ11 の「表示は不利な側へ戻る」と同じ向き)。区切りは降ろし先の様式に任せると note に書く

## 所見4(中)読める値の列挙が template の読み取りと一致しない

- 所在: `deliverable-templates.md:1771`(テンプレ11 の行「期間の長さ(日・週・か月・年の数、四半期、半年)として読めない値は空欄と同じに扱い」)、IMPL-1020・1021
- 根拠: template の `parseInterval`(`template/scripts/gate/org-assurance.mjs:130-145`)は、列挙に無い「毎年」「年に1回」「毎月」「月に1回」も読む。一方「3か月に2回」は 3か月として読み、回数を捨てる。「週2回」「月2回」は null(読めない)になる。裁定 1.5 は「`parseInterval` は日・週・か月・年の数と四半期・半年を読む」とし、一致する前提で書いている
- 影響: 標準の列挙どおりなら「毎月」は「頻度を定めていない」と表示されるが、template は読んで日付を比べる。回数を伴う値(「3か月に2回」)は、標準の列挙では「3か月の数」として読めると解され、頻度の意味(2回)が落ちる。いずれも決定可能性の条件が標準と降ろし先で一致しない
- 直し方の案: 列挙を「(数を伴う日・週・か月・年、四半期、半年、毎月・毎年)」に揃えるか、列挙をやめ「1回あたりの期間の長さとして読めない値」と書き、例を note に置く。1期間に2回以上を求める値の扱い(期間を回数で割るか、読めない値とするか)を note に1句で決める
