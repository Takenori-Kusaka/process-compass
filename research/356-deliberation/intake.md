## 6. B の準備(重。ここで止める)

### 外部の調査の論点

1. 欠陥注入(fault seeding / defect seeding / error seeding)で、注入する者と見つける者が同じ場合の扱い。Mills の error seeding 以来の前提、IEEE 1028(レビュー)、ISO/IEC/IEEE 29119(テストの指標)、航空保安の TIP(Threat Image Projection)で、注入する者の独立を要件にしているか、測定値から除くか
2. 標識の可視性: TIP・フィッシングの演習・カオスエンジニアリング(GameDay)で、演習であることの印を受け手から隠す方法と、印を隠したまま流出を止める方法(印を受け手の見えない場所に置く設計の先例)
3. 小規模な体制で、外部の者に注入を委ねる実務(第三者のレビューの監査・ミステリーショッパー型)の例と、その記録の要件
4. 検出能力の低下を個人に結び付けずに権限を制限する先例(医療の外部精度管理の、施設単位と検査者単位の違い)
