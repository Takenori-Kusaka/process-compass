# #456 軽の審議 反対の委員の意見(2026-11-27)

立場: 裁定の案(案A+3a+論点4不採用)に反対する。突合は assurance-case.md と implementation-ledger.md(読むだけ)。

## 総評

方向(困りごと起点の投影を H に置く)には反対しない。反対するのは、案が掲げる「投影」「決定可能な検査」「表は実態と一致する」の3点が、下書きの表そのもので既に成り立っていないこと。決裁者の問いへの答えも、まだ出ていない。

## 論点ごと

1. **置き先A(H.3)**: 賛成。ただし「新しい要求を持たない投影」と言うなら、各行が引く条項・IMPL を正確に写せていることが前提になる。下の欠陥1〜2がその前提を崩す。
2. **失敗の型を外部から取らない**: 条件付き賛成。外部が構成原理を共有しないという調査は妥当。ただし採らない代わりに「品質保証部門が尋ねた困りごと」(1件のレビュー報告、起票者は同一人物)を行の出所にしている。単一事例が根拠なので EV(E0)では足りず、行が増える契機を EV-0058 に寄せるのは差し替え条件を水増しする。外部の型(slopsquatting、ASI09・ASI10)で表に無い行がどれかを「拾えない性質」の欄ではなく表の側で示すべき。
3. **止め方の区分の導出(§5)**: 反対。「決定可能」と称するが、導出の規則は台帳の列に依存するだけで、IMPL が当該の困りごとに対応するかは検査できない。下の欠陥1のとおり、対応の誤りは検査を通る。検査が保証するのは「台帳との表記の一致」だけで、決裁者が信じたいのは「止まる」こと。検査の通過が表の正しさの印として読まれる危険がある(H.11 の形骸化と同型)。さらに「実在だけ確かめる→人」への寄せは、機械が止めない点を過大な「人」と表示するのではなく、過小な「機械」と表示する逆の誤りの方が深刻。現行の導出に「合否に使わない」の区別が無い。
4. **審議中の表示**: 反対。規定の附属書に、結論の出ていない Issue 番号を書くと、規格の本文が運用上の課題管理に依存する。Issue が閉じても行が残り、検査(§5)は open かを見ない。採用者の版が違う時点で「審議中」の意味が定まらない。代案: 行の止め方は既存条項の範囲だけを書き、欠けは「止まらないこと」の列に事実として書く(例:「依存の実在・来歴を機械では確認しない」)。Issue 番号は書かない。
5. **論点4を採らない**: 部分的に反対。決裁者は「出荷をまたいだ推移」を見たいが、案は H.6 の項目番号を列に書くだけ。「どの値の、どの変化が崩れの兆しか」は答えていない。新様式を課さずに、H.6 の既存の値のうち困りごとごとの監視対象を1列で名指すところまでは、新しい義務なしにできる。

## 裁定の案の欠陥(台帳との突合)

1. **IMPL の誤引用**。行1「G-5 基準1〜8(全件)」の止め方に IMPL-0474 を「機械」と付けるが、IMPL-0474 は基準7(秘匿情報の検査が対象なしで通らない)の規定で、全件を機械で止める根拠ではない。IMPL-0682 は未応答のレビュアへの通知で、「確認待ちの上限で生成を止める」ではない。この2件は「機械」に分類されるため、導出規則を通っても、決裁者には人間の確認の限界を機械が止めると読める。表の最初の行でこの誤りなので、「各行を実装の段で1件ずつ確かめる」では足りず、確かめる基準を裁定に書くべき。
2. **投影が独自の回答になっている**。表の「止まらないこと」「担う主張」(「保守性を担う主張は無い」「C2 は基準の先行だけ」)は、各章のどこにも無い評価を含む。ADR-0056 決定9(独自の回答を書かない)に抵触しうる。これを書くなら、正本となる条項(H.2・H.11)の文言を引く形に限る。
3. **H.3 末尾「新しい検査を足さない」との整合**。案は「文書の整合の検査だから別」と読むが、同条は論証のために足さないと言っている。読みを裁定で明示するか、検査を足さずに lint:refs の既存の節番号検査と IMPL 実在の検査(check-recalibration-registry の前例)の拡張に留めるかを決めるべき。
4. **EV-0272・問25の追加**: 「問いは 24」を 25 にすると、EV-0272(24問の答えが投影)の水準の主張が変わる。新しい行の水準は「表が正しいか」の問いで E0。附属書D が問25 を引くと、D の想定問答が E0 の表に依存する。

## 決裁者の問いに答えているか

答えていない点: 「止まる」と「止まらない」の混在。11行のうち、機械だけで止まるのは2行程度。残りは人・未達・審議中・開示。決裁者が一目で知りたいのは「止まらない困りごとがいくつ残るか」だが、表は行を単位にして、1行内に区分が複数混在する(例: 機械+人+未達+審議中)。行を区分ごとに分けるか、行ごとに「最も弱い止め方」を1つ示す列が要る。

## 代案

- A の置き先は採る。ただし (a) IMPL の引用は台帳の記載範囲(どの基準・どの経路か)まで写す、(b) 審議中の Issue 番号を本文に書かない、(c) 行の最弱の区分を1列持つ、(d) 検査は IMPL の実在と区分の一致に限り、これが対応の正しさを保証しないことを表の注に書く、(e) 「担う主張」「止まらないこと」は各章の文言の引用に限る。
- 重へ上げる条件に該当するかは、(b) を採らず審議中を本文に書く場合に再検討を要する(規定に外部の課題の状態を結合する新しい形の義務)。

採らない案の記録: 「検査を通る=表が正しい」と読める表現、規定の本文への Issue 番号の記載。
