## 裁定の案の欠陥(行の誤り)

台帳(implementation-ledger.md)で裏を取った結果は次のとおり。

- **A. 区分の導出規則が台帳の意味と合わない(案 §5 (2))**。台帳の「検査の手段」は、規定の実装を誰が確かめるかであって、誰が止めるかではない。実例は次のとおり。
  - IMPL-0203・0205 は「機械が確かめる」だが、一覧を出すだけで「合否に使わない」。これを行3・行5・行8 で「機械」と書けば、止まると読まれる。
  - IMPL-0550 は一覧の出力を機械が作り、合否は判定しない。台帳上は「人が確かめる」である。
  - IMPL-1036 は週次実行が機械で、台帳は「人が確かめる」。

  台帳から導ける決定可能な条件は **「降りていない ⇔ 未達」だけ**である。「機械/人」の導出は決定可能に見えて意味を誤るので、機械の検査にしない。統制の閉じ方の原則(意味の判断は manual)に従う。止め方の区分は、次の3値を手で書く。
  - 機械が止める
  - 機械が示し人が止める
  - 人

  検査は、(1) IMPL の実在、(2) 未達と書いた升の IMPL が台帳で「降りていない」、(3) 台帳で「降りていない」IMPL を引く升に「未達」か「予定」がある、(4) 「審議中」に番号がある、の4つに絞る。
- **B. 行1 の IMPL-0474 は誤り**。IMPL-0474 は G-5 基準7(秘匿情報の検査を対象なしで通さない)である。「AI の作業量を人が確かめきれない」に当たらない。秘匿の行(行8)にだけ置く。
- **C. 行1 の IMPL-0682 が止め方を過大に書く**。台帳の IMPL-0682 は、未応答の指名が上限を超えたレビュアへ PR で**知らせる**だけである。「指名は外さない」とあり、新たな指名を止める制御1・2 の本体は実物で未確認である。行1 の「確認待ちの上限で生成を止める」は誤りである。「機械が示し人が止める(IMPL-0682。通知のみ)」とし、止まらないことの欄へ「上限での新規指名・生成の停止(IMPL-0682 は通知まで)」を書く。
- **D. 行4「なぜ」が #457 案と二重になる**。#457 案 §7 は、全変更で理由を記録し(5.5.1。テンプレートへの降ろしは未達)、設計上の選択は G-3 の判断記録で判定し、G-6 基準2・3.4.3 が「誰が確かめたか」を担う、とする。行4 の「G-6 基準3 だけ」では #457 の結論が出た後に書き直しになる。行4 は「審議中(#457。結論は research/457-deliberation/ruling-draft.md §7 の予定)」だけを書く。止め場所の欄は #457 の結論待ちとして空にし、先取りしない(重への上げ条件(b)を避ける)。
- **E. 行7 の「担う主張」欄に「保守性を担う主張は無い」と書くのは、投影ではなく独自の回答である**。#454 論点2 の結論を先取りする。欄は「審議中(#454)」だけにする。
- **F. 行9「止まらないこと」にも IMPL-0200・0507 がある**。止め場所の「5.8.6(実行前の拒否)」は IMPL-0198 の対象(Claude Code のファイルの道具の経路)に限る。Bash 経路は IMPL-0200 で未達である。区分の升に経路の限定を書く。
- **G. 行10(誤りの相関)の止め方「人(測定)」は H.4 の測定の記述を止めると読ませる**。止まらない(開示)ので、区分は「開示」にする。

## 代わりの案(修正点のまとめ)

1. 区分は3値の手書き(機械が止める / 機械が示し人が止める / 人)に、未達・開示・審議中を加える。導出の検査は「未達 ⇔ 降りていない」と実在だけにする。
2. 行1・4・7・10 を上記 B〜E・G のとおり直す。実装の段で、全行の IMPL を台帳の状態・文面と1件ずつ照らす(案 §4 の注記は、IMPL-0474・0550・0682 についてすでに誤りを示した)。
3. 「審議中」は、日付(`YYYY-MM-DD 時点`)と Issue 番号を持たせ、H の既存の「時点」表記の作法に合わせる。台帳の「予定 #452(見直し 2027-02)」と別の語になるので、ADR-0266 に「審議中は標準本文の欠け、予定は降ろしの欠け」と区別を1行書く。Issue の open 判定は検査しない(ネットワークに依る)。#454・#455・#457 の結論の実装の段に、行の更新を受け入れ条件として足す。
4. H.3 末尾「新しい検査を足さない」との整合は、新しい検査が文書間の整合の検査で、案件に掛からないとの起案の読みで足りる。ADR-0266 に明記する。
