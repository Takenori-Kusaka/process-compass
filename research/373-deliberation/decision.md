# 議長の裁定(#373 CL の判定と安全リスクアセスメントを、誰がどの段で確かめるか)

入力: 議題 `council-00-agenda.md`、調査 `survey-373-1-internal.md`・`survey-373-2-external.md`、意見 `council-01-drafter.md`(起案)・`council-02-field.md`(現場)・`council-03-qa-audit.md`(品質監査)・`council-04-standards.md`(規格)・`council-05-defender.md`(弁護)。

## 0. 骨格

5 委員とも欠陥を認めた。初回の CL の判定には記名も根拠も残らず、区分を下げる操作より軽い(弁護を含む)。外部の規格は、最も低い判定も確認の外に置かない(ISO 26262-2 表1 の QM 列の I3、FDA の Basic の記述と理由、EASA の開発の外での割り当て)。一方、全件に最も遠い段を課す形は、安全の範囲に入るかどうかの判定にまで I3 相当を課す規格が読めた範囲に無く(規格)、1〜9名の体制のほぼ全件で外部の確認者を要する(弁護)。そこで、記録と記名はすべての区分に課し、確認の段は**判定の結果から導かない入力**で決める。

Issue の参照の訂正: #318 の決定は ADR-0088、根拠水準は EV-0180。#357 の書き置きの IMPL は IMPL-0184・0344。

## R-1 CL の判定の確認 — 裁定

- **判定の記録**: すべての区分(CL0 を含む)で、CL の判定の記録を必須にする。記録に書くもの:
  - 判定者の記名(D-0 表1 の決定者)
  - 対策を入れる前の最悪の帰結
  - 1つ上の区分に当たらない理由
  - 附属書F F.2 の切り分けの回答

  (5 委員)
- **確認者**: 判定者と別の自然人が確かめる。段の下限は、判定で外れる1つ上の区分が評価者に求める段とする(CL0 → 段1、CL1 → 段2、CL2 → 段3。CL3 の判定は外れる区分が無いので段1)。低く判定しても、確認が下限より軽くなることはない(起案・現場・規格)
- **入力による引き上げ**: 判定の結果に依らない入力で、段を引き上げる(規格・品質監査。ISO 26262-2 表1 の HARA の行と同じ形)
  - F.2 Q1(物理的な危険源の制御)が「はい」の案件は、判定の結果に依らず段3
  - 規制業の候補に当たる案件は、少なくとも段2
- EV-0231: 段の割り当て(下限の導き方と、引き上げの入力)は類推にもとづき、本標準での実証が無い。見直し 2027-05
- 採らない:
  - (a) 全区分に最も遠い段を課す案。規格の裏づけの範囲を超え、小さい体制の全件で外部の確認者を要する
  - (b) 確認を求めない案。循環が残り、外部の規格のどれとも合わない
  - (c) CL0 にだけ求める案。CL1・CL2 の引き下げの経路が残る
  - IEC 62304 型の「判定しなければ最上位」の既定値。判定の記録を必須にすることで目的を果たし、既定値は初期化の詰みを生む
  - 品質監査の委員の「すべて段1 から始め、入力でだけ上げる」案。CL1・CL2 の判定で、外れる区分の要求より確認が軽くなる

## R-2 1〜2名の体制と、組織の外の確認者 — 裁定

- 確認を免除しない。チームの外の自然人を確認者にできる。2名の体制で、相手の1名を確認者に数えてよいのは段1 に限る(段は ADR-0088 の定義による)
- 確認者がいない場合: 判定の記録と記名(本人が書ける)の欠落は止める。確認の欠落(他の人の手が要る)は未達として表示し続け、出荷は G-8 の受容と開示で行える(ADR-0028・ADR-0030 と同じ扱い。現場・品質監査)
- ただし、F.2 Q1 が「はい」の案件で確認(段3)が欠けるときは、G-8 で受容しても出荷しない(品質監査)
- 理由の記述や AI の確認を、確認者の代わりにしない(規格)

## R-3 テンプレ9 — 裁定

- テンプレ9(AI エージェントの危害の評価)の要否は、第6章の CL に依らない4条件を正とする。軸E の表と規則データ(CL2 以上)の食い違いを、第6章に合わせて直す(5 委員)
- 様式に承認の欄を置く。確認者は作成者と別の自然人(段1)。段2・段3 は課さない(品質監査・規格・弁護)。CL2 以上では、安全性の評価者がテンプレ9 を読む(起案・現場)
- 製品の危害を下げた記録(区分の引き下げの根拠)は、テンプレ9 ではなく CL の判定の記録へ移す(起案・現場・規格)

## R-4 記録・機械の検査・ADR — 裁定

- 準拠テンプレートの初期化の回答 q-criticality は**仮の判定**とする。判定の記録と記名がそろうまで G-1 を開始しない。確認は R-2 のとおり扱う(規格・品質監査)
- 区分を下げる操作では、引き下げの根拠の記録が実在することを機械で確かめる(5 委員)
- 機械が確かめる範囲:
  - 判定の記録の欄、判定者の記名、確認者の記名(判定者と別の人であること、AI の名義でないこと)
  - 段2 以上の確認者の距離の機械の照合は、#357(組織上の距離を構成の欄で表す)へ渡し、IMPL を state=undelivered で付ける
- 「リスク区分(R)の判定に段を課さない」を、課さないと決めた事項として明記する。R は変更ごとに判定し(ADR-0039)、その確認は G-5・G-6 が担う(弁護・現場・規格)
- 附属書H(監査の観点)に、CL の判定の記録と確認の観点を足す。保証の開示に、判定の確認の段と未達の行を足す(起案・弁護)
- ADR-0113 を新設する(ADR-0112 は #374)。ADR-0088 の状態の節に、後継へ送った事項を閉じた旨を追記する
- EV-0231 を置く。IMPL を置く(判定の記録・確認・引き下げの根拠の実在は delivered、段2 以上の照合は undelivered)

## 採らない案(まとめ)

| 案 | 理由 |
| --- | --- |
| 全区分に最も遠い段 | 規格の裏づけの範囲を超える。小さい体制の全件で外部の確認者を要する |
| 確認を求めない | 低い判定で確認を逃れる循環が残る |
| CL0 にだけ求める | CL1・CL2 の引き下げの経路が残る |
| 判定しなければ最上位の既定値 | 記録の必須で足りる。初期化が詰む |
| 全件を段1 にして入力でだけ上げる | CL1・CL2 の判定の確認が、外れる区分の要求より軽くなる |
| テンプレ9 の確認に段2・段3 | テンプレ9 は製品の HARA ではない。製品の危害の根拠は CL の判定の記録へ移す |
| R の判定に段を課す | R は変更ごとで、確認は G-5・G-6 が担う |

## 実装の判断への裁定(2026-11-05、`implementation.md` の J-1・J-10・J-12)

- **J-1 確認者が欠けたときの出荷**: 実装の扱いを維持する。確認の欠落は未達であり、既存の「CL1 以上と規制業は未達のまま出荷しない」に乗る。R-2 の「G-8 の受容と開示で出荷できる」は、未達のまま出荷できる区分(CL0)についての記述である。3〜9名の CL1 の案件で段2 の確認者を置けなければ出荷できないことは、CL1 の案件に安全の確認を求める帰結として受け入れる。ADR-0113 に帰結として明記する
- **J-10 判定の記録の欠落の集約での扱い**: 実装を改める。旧い構成(ADR-0113 より前に G-1 を通過した構成)に限り、判定の記録の欠落を未達として表示する。それ以外の構成では、判定の記録と判定者の記名の欠落を、出荷の証跡の集約で欠落に数える。R-2 の「本人が書ける欠落は止める」による。G-1 の前の D-0 の検査だけでは、G-1 の後に記録を消す・書き換える経路が残る
- **J-12 判定者が現在の決定者でない記名**: 実装を改める。判定者の記名は、**記録が作られた時点**の D-0 表1 の決定者と照らす(ADR-0111 決定6 と同じ原則)。決定者の交代の後も、交代の前に正しく作られた記録は効力を保つ。記録の時点で決定者でなかった人の記名は拒否する。記録の時点を構成の履歴から導けない場合に限り、注意として出す

## 独立の突合への裁定(2026-11-05、`crosscheck.md`)

- **X-1・X-2・X-3(高・高・中)**: 旧い構成の境界と、判定者を照らす時点は、自己申告の日付ではなく、基底ブランチの履歴(記録を入れたコミットの時刻。ADR-0109 の検出の原則)から導く。旧い構成で記録を消すと出荷の止めが外れる経路(X-1)は、旧い構成でも CL1 以上・規制業・F.2 Q1「はい」の案件では、判定の記録の欠落を欠落に数えて塞ぐ。旧い構成の緩い扱いは、CL0 で F.2 Q1 が「いいえ」の案件の未達の表示に限る
- **X-4〜X-6・X-8・X-9(中)**: 実装の担当が直す。浅い取得で照合が効かない場合は、照合できなかったことを欠落として扱う(注意に落とさない)。同じ日の交代は、コミットの順で決める
- **X-7(J-6)**: R-3 の裁定どおり、テンプレ9 の要否は第6章の4条件を正とする。CL2 以上を4条件に依らず必須に残す判断は、裁定に無い強化であり、取り消す。CL2 以上の案件で安全性の評価者がテンプレ9 を読むこと(R-3)は、テンプレ9 が要る場合に限る
- **X-10**: 仮の判定(q-criticality)から最初の判定の記録へ移るときに、引き下げの根拠を求めない。最初の判定の記録は、すでに「1つ上の区分に当たらない理由」を持つ。引き下げの根拠を求めるのは、判定の記録が成立した後の区分の引き下げに限る
- X-11〜X-16(低): 実装の担当が直す

## 修正の帰結への裁定(2026-11-05)

- 節16(判定の記録)を持たない旧い構成は、CL0 でも週次の gate-entry と出荷で止まる(実装の担当の報告 4)。旧い構成を緩く扱う条件の F.2 Q1「いいえ」は、判定の記録が無ければ読めないためである。この帰結を受け入れる。判定の記録は本人が書ける欠落であり、R-2 の「本人が書ける欠落は止める」に合う。旧い構成への手当ては、急に止めないことではなく、止めた理由と次の一手(節16 を書く)を /pit と拒否の文で示すことにとどめる。ADR-0113 に帰結として明記する
