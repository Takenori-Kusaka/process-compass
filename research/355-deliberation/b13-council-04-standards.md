# #355 束 B13 会議体 委員4(規格): S0・標準品質・CL0 で F.2 の Q1 が「はい」の穴

- 日付: 2026-11-17。役割: 規格委員。読んだもの: `b13-intake.md`、`b13-research-external.md`、ADR-0159、ADR-0065(決定1・5)、`tailoring-guide.md` 軸B 前提表(L570〜)・軸E(L1099)、ADR-0088 の IMPL-0349 の記載。他の委員の文書は読んでいない。標準の本文・template は変えていない

## 1. 結論

- **推す: 案A(S0 の省略の前提に「F.2 の Q1 が『いいえ』」を足し、「はい」なら G-7 を適用に戻す)。ただし機構は「構成の食い違いを集約が欠落に数える」(IMPL-0349 型)に限り、導出(規則データ)には入れない**
- **落とす: 案B、案C1、案C2**
- 規格の観点の核心は2つ。(1) 外部に「探索・試作だから人身への危害の検証の席を外す」を支える規範は、読んだ範囲に無い。(2) 本標準の内側では、これは**新しい記録の義務ではなく、既にある義務(F.7)の判定席の欠落の修復**である。ADR-0159 決定4 が「新しい義務ではない」と書いた論理の延長で閉じる

## 2. 外部の規格・実務との整合

規格として言えること: 軽重を段で変える規範(FDA の二段、J3018 の段階的試験)はある。「軽い」の側でも**別の者が判定する**。案A は軽重を G-7 の適用有無でなく、既存の「Q1 が『はい』」(F.2)に預けるので、この構図と同型である。

**言えないこと(未読の開示)**: IEC 61508、ISO 13849-1、ISO 26262、IEC 62304 の本文が試作・探索を適用外にするか。外部の調査は読めていない。したがって「規格が探索段にも G-7 相当を要求する」とは書かない。書けるのは「免除を支える規範が読んだ範囲に無い」までである。この否定の主張は根拠水準マークで開示する(第6節)。

## 3. 既存の ADR・語彙との整合

### 3.1 案A は ADR-0065・ADR-0159 と矛盾しない。ただし ADR-0065 決定1 を一部置き換える

- ADR-0065 決定1 は前提を3つとし、前提1・2 は「機械では確かめない」とした。案A は前提4 を足す。前提4 だけは機械で確かめる(F.2 の Q1 は D-0 表10 の機械が読める値)。**前提1・2 を機械で確かめない決定は変えない**。前提4 を機械にするのは、決定可能な条件(値の一致)だけを機械にする統制の閉じ方の方針と合う
- 先例は2つある。IMPL-0109・IMPL-0345(CL1 以上は S0 でも G-6・G-7 を適用。規則 r-e-cl1)は「危害の深刻度は体制・ステージで下がらない」を理由に S0 の省略を取り消した。案A は同じ理由を、CL の記録でなく F.2 の回答に当てる。IMPL-0349(未適用の厳格化の食い違いを集約の欠落に数え、構成は書き換えない)が機構の先例
- ADR-0065 の本体の決定(CL1 以上は S0 でも適用)と同じ向きで、新ADR で「決定1 に前提4 を足す」一部置き換えを記録する。原則の反転ではなく、省略の成立範囲を狭める側の追補である

### 3.2 ADR-0159 決定4(CL から F.2 を導かない)との関係

- 決定4 の禁止は「CL で F.2 の判断を置き換える」向きである。案A は F.2 の回答からゲートの状態を導く逆向きで、CL の判定を触らない。ADR-0039 の「別の軸の判定で置き換えない」に反しない。受付の読みに同意する
- **ただし導出の入力に F.2 を足してはならない**。ADR-0159 の採らない案(判定記録に附属書F の適用の欄を足す)と同じ理由で、2か所に同じ判断が書かれると食い違う。規則データ(`rules-business-phase.yaml`)に F.2 の条件を持たせず、集約の側だけで突き合わせる

### 3.3 受付の論点(i) `CONDITIONS` を拡げるか

- 反対。条件の語を拡げると、導出が D-0 の自由記述に依存し、同じ入力から同じ構成を導くというテーラリングの原則(ADR-0065 決定1 の理由)が崩れる。升は導出結果だけを書き、前提4 は前提表と軸E に置く。`check-stage-table` を変えない。この点は議長の裁定に委ねるが、規格の側から見て、導出と判定の記録の二重化は避けるべきである

### 3.4 7.3 例外承認で受けられないか(3問の(2))

- 受付の結論に同意する。席が無い判定の例外は存在しない。ADR-0153 の対象の限定に反する。戻した後の個別の基準7 の項目は7.3 で受けられ、これは ADR-0159 決定4 のとおり
- 補足: S0 の採用者が「速さの代償として Q1 『はい』の PoC を G-7 なしで出したい」場合の逃げ道は、**構成の変更(F.2 の回答を直す)ではなく**、基準7 を戻した後で7.3 にて個々に受ける、の順になる。F.2 の回答を軽くして逃げる誘因は残る(第5節の異議)
