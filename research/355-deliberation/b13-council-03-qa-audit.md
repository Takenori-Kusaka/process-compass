## 2. 各案で残る証跡が、適合の主張と安全を支えるか

### 案A

- 残る証跡: (a) D-0 表10 の F.2 の回答(人の判定)、(b) F.7 の記録(作成者)、(c) 判定記録テンプレ4 の基準7 の行(出荷判定者。記録と基準の突合)、(d) 集約の「Q1 が『はい』かつ G-7 が省略」の欠落(機械)
- 支えるもの: 「基準7 を判定した記録」。事後に F.7 を作っても、出荷の時点の判定は作れない(受付 3問(3))。G-7 を戻せば、判定を出荷の前提にする既存の仕組み(結果の欄が空の記録は通過に数えない。`gate-criteria.md` L364)がそのまま効く
- 支えないもの(開示が要る): (i) F.2 の Q1 の答え自体が正しいか(下の 3.3)、(ii) F.7 の中身の妥当性、(iii) 出荷判定者が S0 の小さいチームで作成者と別の人か。ADR-0159 影響 L70 は「独立した確認者は、本 ADR のどの決定も求めない」と書いている。**F.7 に「独立した評価」の項目があるのは、作成者の記録に独立の証跡を求めるためで、G-7 の席の独立ではない。ここを混同した文を書かない**
- 近い先例との整合: F3(非重大リスクでも IRB が「軽い」を判定)、F6(実験の主体に段階・記録・書面。免除なし)、F8(独立した安全機能の欠落が実証段階の人身事故に直結)。速度の損失は Q1「はい」の案件だけに限られる

### 案B

- 残る証跡: 判定記録に「段3 の確認者が F.7 を確かめた」の行
- 監査人が受け付けない理由:
  1. 段3 の確認者は、CL の区分の確認者で、案件の初めに1回置かれる席である(`tailoring-guide.md:1060`・`1073`)。出荷ごとに、出荷される版の F.7 を見る務めを足すと、席の務めの意味が変わる
  2. 独立性の証跡が無い。ADR・suite が、同一人物の承認を記録つきで受け付けている(メモリ: suite の fixture)。確認者=作成者=承認者の3役が1人の構成で、「別の者が見た」と述べられない。SRC-0677・SRC-0678 の三段(人・部門・組織)で言えば、案B は最も弱い「人」の段にも届かない可能性がある
  3. 先例(F3・F6)が共通して持つのは「開発の主体と別の者が判定する」点で、案B はこの共通点を保証しない
  4. G-7 基準7 と同じ判定を、別の席・別の記録様式で重ねる。同じ基準が2か所で判定され、一方が省かれる構成が生じる。これは ADR-0159 が「同じ判断を2か所に書かせると食い違う」として採らなかった理由と同型
  5. 機械が見られる範囲も増えない(確認者の行の有無は見られるが、確かめた事実は manual)。一方で template の変更は案A より大きい(受付 5)。**これは理由に使わない。1〜4 だけで落とす**

## 3. 機械で閉じる条件と manual の線引き

### 3.1 機械にしてよい(決定可能)

- 条件: 「D-0 表10 の F.2 の Q1 の値が『はい』」かつ「構成の G-7 の状態が省略」。値の一致であり、`f2Q1Of` の構文読みで決まる。違反と適合の対の試験を添えて machine にする
- 構成を書き換えない型は IMPL-0349 に先例がある。構成を書き換える側は人(/process-change)。機械は欠落に数えるだけ

### 3.2 条件1: 欠落の解消の経路を先に確かめる(異議)

受付の案Aの機械は、「構成の G-7 が省略」を欠落に数え、構成の変更で戻すまで止める。ところが導出(エンジン)は F.2 の回答を入力に持たない(受付 1.3)ので、規則による再導出は S0・標準・CL0 で常に「省略」を返す。IMPL-0349 の `pendingTightenings` は「再導出と構成の差」を扱うが、**構成が導出より厳しい(G-7 を適用)場合の扱い**は本件で確かめていない。次のどれかが起きると、案Aの欠落が解消不能になるか、手で戻した構成が別の検査で緩和・逸脱として扱われる。

- 構成の g7 を「適用」へ手で変えると、導出との差として別の欠落や警告が出る
- /process-change が導出の値へ構成を戻す

したがって、**案Aを採るなら template の項目の最初に、「S0・標準・CL0・Q1 はい」の構成を通しで作り、g7 を適用へ変えた構成が集約・`/pit`・テーラリングの検査をすべて通ることを、違反と適合の対で固定する**。通らないなら、導出の入力に F.2 の Q1 を足す案(受付が避けた複製)か、構成の上書きの語(`CONDITIONS`)を足す案を、議長が改めて裁定する。実行での確認が済むまで、この点は「通る」と書かない。

### 3.3 条件2: manual と開示の線引き

| 項目 | 閉じ方 | 理由 |
| --- | --- | --- |
| Q1 と G-7 の状態の一致 | machine | 値の一致 |
| Q1 の欄が空・読めない | machine(欠落に数える。fail-closed) | 構文。既存の D-0 の検査が既に数えるならそちらに従い、数えないなら本件で数える。要確認 |
| F.2 の Q1 の答えが正しいか | manual(段3 の確認者が D-0 で確かめる。既存) | 意味の判断。機械は閉じない。**「いいえ」と書けば S0 のまま通れる抜け道が残る**と、根拠水準マークで開示する |
| F.7 の中身の妥当性 | manual(出荷判定者) | ADR-0159 決定4。adopter にしない |
| G-7 判定者が作成者と別か | adopter ではなく、開示のみ | 本束で課さない。課すなら別の審議(新しい義務) |

「いいえ」への書き換えを機械で止めようとしない(自由な文の意味は機械で閉じない。コアポリシーの統制の閉じ方)。代わりに、Q1 の答えが変わった履歴(D-0 の版の差)を、出荷判定者が基準7 の判定で見ることを手引きに書く(手引き。条文には置かない)。

## 8. 異議(議長へ)

1. 3.2 を実行で確かめるまで、案A を「通る」とは書かない。確かめられないなら、導出の入力を足す案を再び審議に載せる
2. 案A は G-7 判定者の独立を保証しない。この点を「課さないと決めた」として明記し、F.7 の「独立した評価」の項目が担う範囲と混同しない
3. CL 区分表の隙間(受付 1.4。軽い人身への危害の行が無い)は、案A の採否と無関係に成り立つので、本審議から切り離すのに異議はない。ただし、案A が CL0 の隙間の穴埋めに見えないよう、条文は F.2 から直接書く
