## 2. 採る案と理由(所有者の方針の3問)

**採る: 案A′**。S0 の省略の前提に「附属書F F.2 の Q1 が『いいえ』」を足し、「はい」の案件は S0・標準・CL0 でも G-7 を適用して基準7 で F.7 の記録を判定する。導出の入力に Q1 の写しを持たせ、写しと D-0 表10 の食い違いを機械が値で確かめる。

1. **条文は結果と証跡まで**: 結果は「Q1 が『はい』の案件は、F.7 の記録を、作成者と別の席(出荷判定者)が基準7 で判定してから出荷する」の1文。証跡は D-0 表10・F.7・判定記録(テンプレ4)。どれも既にある。手順(誰が何日で突合するか)は `gates/G-7.md` の手引きに置く。条文に足すのは前提4 と、軸E の升の文の直しだけである
2. **第7章の例外承認で受けられないか**: 受けられない(全委員と同意見)。S0 では G-7 自体が無く、外す判定基準が存在しない。7.3 の対象の限定(ADR-0153 決定1)と食い違う。席を戻した後の個々の基準7 の項目は 7.3 で受けられる(ADR-0159 決定4)。新しい条項は足さない
3. **破られたとき誰が何を失うか**: 実験参加者の身体の安全(取り消せない)、採用者の安全配慮の備えと準拠の主張の根拠、本標準の「決められた場所では必ず人が触る」。直す側の費用は、Q1「はい」の S0 案件が G-7 の判定(記録の突合)を待つ時間で、取り消せる。非対称である

**統制の閉じ方**:

| 条件 | 閉じ方 | 理由 |
| --- | --- | --- |
| 構成の回答(Q1 の写し)が「はい」なら S0 の G-7 を適用 | machine(導出の規則。エンジンの試験) | 列挙値からの導出。決定可能 |
| 写し「いいえ」× D-0 表10「はい」 | machine(記載の欠落。出荷を止める) | 値の一致。`f2Q1Of` の構文読み |
| 写し「はい」× D-0 表10「いいえ」 | machine(注意。止めない) | 統制が厳しい側に倒れている(q-criticality と同じ扱い) |
| D-0 表10 の Q1 の答えそのものが正しいか(「いいえ」の誤答) | manual(判定者と別の自然人の確認。既存の F.2 L72)。根拠水準マークで開示 | 自由な文の意味。機械で閉じない(異議 (iii)) |
| F.7 の中身の妥当性 | manual(出荷判定者。ADR-0159 決定4) | 同上 |
| G-7 の判定者が作成者と別か | 課さない(本束で新しい義務にしない)。開示のみ | ADR-0159 影響の「独立の確認者はどの決定も求めない」を維持 |

**委員の大勢の「導出に F.2 を入れない」を退ける理由**: 委員の懸念は ADR-0159 の採らない案(判定記録に附属書F の適用の欄を足す)と同じ「2か所に書くと食い違う」だった。この採らない案の欄には、食い違いを見る機械が無かった。案A′ の写しは、q-criticality と D-0 節16 の先例(`cl-judgment.mjs` L272〜281)、ADR-0065 決定5(回答と名簿の食い違いをどちらの向きも検出する)と同じ型である。食い違いは機械が値で検出する。規格委員の「導出が D-0 の自由記述に依存する」の懸念にも当たらない。導出が読むのは列挙値の回答で、D-0 は読まない。品質監査の委員が 3.2 で求めた「通らないなら導出の入力を足す案を改めて裁定する」の条件に当たる。

## 4. ADR の要否: 要る(ADR-0171)

- **題**: ADR-0171: S0 の省略の前提に附属書F F.2 の Q1 を足す — 「はい」の案件は G-7 を適用し、導出は Q1 の写しを入力に持つ
- **ステータス**: 採用(日付は実装の日)。ADR-0065 決定1 を一部置き換える(前提を4つにする)。ADR-0159「影響」の未決(S0 で G-7 を戻すか)を決める。ADR-0065・ADR-0159 の本文は書き換えない。重の審議の結論(#355 束 B13、`research/355-deliberation/b13-decision.md`)
- **文脈**: S0・標準・CL0 は G-7 を省略する。軸E の升は Q1「はい」なら F.7 の記録を要すると書くが、判定する席が無い。集約の基準7 は not-checked で、G-8 は技術品質を判定しない。F.7 が無いまま、人身への危害を生じうる制御を持つ成果物が実験参加者へ出る。導出は F.2 を入力に持たず、構成の G-7 を導出より厳しくする正規の経路も無い(実行で確かめた)
- **決定**
  1. S0 の省略の前提に、前提4「D-0 表10 の附属書F F.2 の Q1 が『いいえ』」を足す。Q1 が「はい」の案件は、S0・標準・CL0 でも G-7 を適用し、基準7 で F.7 の記録を判定する
  2. 導出の入力に Q1 の写し(初期化の回答。仮の答え)を足す。正本は D-0 表10。写しが「いいえ」で正本が「はい」なら記載の欠落にして出荷を止める。逆向きは注意にとどめる。q-criticality と D-0 節16 の関係と同じ型
  3. G-6 は戻さない(ADR-0065 決定4 を維持)。G-6 を省略して G-7 を適用する構成の独立確認の欠落は、「G-6 が未達の体制」と同じに扱う(第4章 G-7 基準5 の表)
  4. CL は F.2 から導かない(ADR-0159 決定4)。F.2 の写しが変えるのはゲートの状態だけ
  5. 課さないと決めたこと: (a) G-7 の判定者の作成者からの独立 (b) Q1 の答えの正しさの機械での検証 (c) CL の F.2 による引き上げ (d) 部分の G-7 (e) G-6 の復帰 (f) 案件より細かい出荷単位での絞り込み (g) 7.3 への新しい条項
- **結果**: Q1「はい」の S0 案件は G-7 の記録(引き継ぎ文書・負債台帳・判定記録・欠陥の台帳)と判定を負う。速度の損失は取り消せる。Q1 を「いいえ」と書く抜け道は残り、manual の統制として開示する。前提1・2 を機械で確かめない決定(ADR-0065 決定1)は変えない。機械が確かめる前提は 3 と 4(値の一致)だけである。準拠テンプレートの実装は #448 で降ろす(未達の表示を続ける)
- **採らなかった案(要旨)**: 3 の表のとおり。特に「導出に入れず集約だけが止める」は、解く正規の経路が無く偽りを誘うため採らない、と書く
- **見直しの契機**: EV(前提4)の見直し日。Q1 を後から「はい」へ直した案件、直す前に出荷した案件の発生。外部の調査の穴(4規格の試作の扱い、使用者側の労働安全の法 F10)が埋まったとき
