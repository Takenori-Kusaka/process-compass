## 3. 所有者の方針の3問

### (1) 条文は結果と証跡まで

- 求める結果は1つに書ける: **「F.2 の Q1 が「はい」の案件は、F.7 の記録を、作成した者と別の席が判定してから出荷する」**。G-7 を戻すか、別の席に置くかは手段である
- 証跡は既に在る置き場で足りる: D-0 表10 の F.2 の回答(機械が読める。`f2Q1Of`)、F.7 の記録(様式は #448 の IMPL-0933)、判定記録(テンプレ4)。新しい置き場は要らない
- 機械で閉じられるのは「表10 の Q1 が『はい』かつ構成の G-7 が省略」の一致だけ(値の一致。決定可能)。F.7 の中身の妥当性は manual のまま

### (2) 第7章の例外承認で受けられないか

- **受けられない**。7.3 の対象はゲートの判定基準と、条項が 7.3 を名指した事項である(ADR-0153 決定1 の前提)。S0 では G-7 そのものが無く、外す判定基準が存在しない。例外承認はゲートの未達も解かない(7.3。IMPL-0603)
- G-7 を戻した後なら、基準7 を満たさない個々の項目は 7.3 で受けられる(ADR-0159 決定4、ADR-0153。基準7 は 7.4 の禁止の対象に入っていない)。**7.3 は、席を戻した後の逃げ道としては働くが、席の無さは埋めない**
- 「S0 で Q1『はい』の出荷は、基準7 を例外承認する行を要する」とする読みは、存在しない判定の例外を作ることになり、7.3 の対象の限定(ADR-0153)と食い違う

### (3) 破られたとき誰が何を失うか

| 誰が | 何を失うか | 取り消せるか |
| --- | --- | --- |
| 実験参加者・社内の利用者(S0 の露出の範囲) | 身体の安全 | 取り消せない(`tailoring-guide.md` の「設計で下げられない危害」) |
| 採用者 | 安全配慮・製造物の責任への備え(検証の記録が無い)。本標準に準拠したと述べた根拠 | 事後に記録を作っても、出荷の時点の判定は作れない |
| 本標準 | 「決められた場所では必ず人が触る」の主張。軸E の升の「要する」が判定されない義務になる | — |
| 案を採った場合に S0 の採用者が失うもの | Q1「はい」の PoC だけ、G-7 の判定(記録の突合。3営業日)の時間 | 取り消せる(速度) |

非対称である。直す側の費用は速度で回復でき、直さない側の損失は回復できない。

## 4. 会議体に掛ける案

### 案A(受付の推奨): S0 の省略の前提に「F.2 の Q1 が『いいえ』」を足し、「はい」なら G-7 を適用に戻す。集約が構成の食い違いを欠落に数える

- 条文: 軸B「S0 の省略が成立する前提」の表へ前提4「D-0 表10 の F.2 の Q1 が『いいえ』」を足す。軸E L1099 の升は「G-7 を適用する構成では」を外し、「Q1 が『はい』の案件は G-7 を適用し、基準7 で判定する」にする
- 機械: 集約が「D-0 表10 の Q1 が『はい』かつ構成の G-7 が省略」を記載の欠落に数え、構成の変更(/process-change)で G-7 を戻すまで出荷させない。先例は IMPL-0349(CL1 以上で G-6・G-7 が規則より緩いまま残る構成を欠落に数える。構成は書き換えない)。決定可能な値の一致なので machine にできる
- 導出の入力は増やさない。F.2 の回答は D-0 にあり、質問へ複製すると2か所で食い違う(ADR-0159 の採らない案「判定記録に附属書F の適用の欄を足す」と同じ理由)
- 論点: (i) 軸B の升の括弧に F.2 を書くと `check-stage-table` が落ちる(1.3)。升は導出の結果だけを書き、F.2 の条件は前提の表と軸E に置くか、`CONDITIONS` に導出の外の条件の型を足すか (ii) ADR-0065 決定1 を一部置き換える新 ADR が要る (iii) CL0 の判定に F.2 の答えで G-7 を戻すことが、ADR-0159 決定4「CL から F.2 を導かない」の逆向き(F.2 からゲートの状態を導く)として許されるか。受付の読みでは、CL を置き換えず、ゲートの状態だけに効くので許される

### 案B(対立案): G-7 は戻さず、F.7 の記録の判定を、既に段3 を求められている判定の確認者に負わせる

- 条文: Q1 が「はい」の案件では、段3 の確認者が出荷の前に F.7 の記録を確かめ、確かめた記録を判定記録に残す
- 長所: S0 の速度を保つ。段3 の確認者は既に在る(`tailoring-guide.md:1060`・`1073`)
- 短所(受付の見立て): 段3 の確認者の務めは判定の**区分**の確認で、案件の初めに1回である。出荷ごとの検証記録の判定は別の務めで、席の新設に等しい。G-7 の判定者の席と型(記録の突合・期限・差し戻し)を別名で作り直すことになる。会議体で弁護の委員に持たせる
