# #355 束3 独立の突合 1巡目の所見への議長の裁定(直しの指示)

日付 2026-11-15。所見は `b3-review-round1.md`。高 3・中 4・低 5 を、次のとおり扱う。

## R1-01(高): 第3の形で直す。(a) も (b) も、そのままは採らない

- **採らない (a)**: 範囲で spec.md が変わった機能を、変更したファイルだけを根拠に G-7 基準5 の欠落へ足す案。判定を受ける前の下書きの機能仕様(新しい機能の spec.md を既定ブランチへ入れ、G-2・G-4 を待つ状態)が出荷の範囲に在るだけで、出荷が止まる。基準5 の対象を広げることは、この束の審議の範囲を超える(採る審議は重)
- **採る形**: 再確認の式の中で、通過の記録の扱いを次へ改める
  1. 効いている G-4 の通過のうち、版を読めたものの1件でも先端と一致 → 一致(現行のまま)
  2. 一致する効いている通過が無く、**その機能に版を読めた G-4 の通過の記録が1件でも在り(効いているか、後の差し戻しで打ち消されたかを問わない)、そのすべてが先端と一致しない** → 不一致(欠落)。確定した版が在り、先端はそこから変わっていて、変更後の版を対象とする効いている通過が無いことが、値で決まるため(場面 D が欠落になる)
  3. 打ち消された通過の版が先端と一致し、効いている通過に一致が無い → 未確認。理由は「先端の版の通過が、後の差し戻しで打ち消されている(または判定日時が空で前後が決まらない)」
  4. その機能に G-4 の通過の記録が1件も無い → 未確認。理由の文を実態へ直す:「この機能を対象とする G-4 の通過の記録が無い。コミットまたは PR のトレーラ Spec がこの機能を指す場合に限り、G-7 基準5 が欠落に数える。指さない場合、機械は欠落にしない」
  5. 判定する席の責任者でない者の通過(`judgeOk=false`)と `headMatch` が偽の写しは、通過の記録に数えない(2 の「通過の記録」に入れない。現行の扱いのまま未確認)
- ADR-0136(まだ採用の前。本文を直してよい)・IMPL-0241 の note・`gate-criteria.md`・`spec-recheck.mjs` の理由の文を、上の形へ揃える。「基準5 の欠落がそのまま当たる」の文は削る
