## 1. 所見

### F-01 高 IMPL-0667 実物の様式の判定記録を 1 件も数えない

- **所在**: `template/scripts/gate/judgement-records.mjs` の `reachRecordOf`(`cellOf(String(text ?? ''), '判定')`)
- **事実**: `cellOf` は欄名の前方一致で最初の行を返す。様式 04 は冒頭の表に `| 判定者 |` があり、これが `| 判定 |` より先に当たる。判定の語が読めず、全件が「読めない記録」になる
  - `probe-unit.mjs` P1: 様式の配置で乙の継続 4 件 → `verdict: null`、`total: 0`、`gaps: 0`、`unreadable: 4`
  - 対照: 判定者と判定日時の行を除くと `total: 4`、`gaps: 1`
  - `probe-e2e.mjs` E3(実物の集約): 4 件目の継続で欠落 0 件。表示は「乙・丙の継続・保留を 0 回と数えた。未確認 4 件」
- **影響**: `delivered / machine` の表示に反し、3 回を超える継続・保留が止まらない。試験は判定者の行を持たない入力だけを渡すので通る
- **直し方の案**: 欄名の完全一致で読む(集約の `rowValue(text, '判定')` と同じ)。様式 04 の全体を入力にする対の試験を足す

### F-02 高 IMPL-0738 「未達の種類を問わず」が実装されていない(0755 との組み合わせ)

- **所在**: `template/scripts/gate/config.mjs` の `unmetShipBlockers`、`aggregate-evidence.mjs` の `unmet.push({ gate: 'g2', ...})`
- **事実**: `unmetShipBlockers` が見るのは `config.unmet` と導き直した G-3 だけである。様式 08 の「置かない」が生む G-2 の未達は、集約の表示用の配列にだけ入る

  - 暫定任命の併記の未達(IMPL-0638)も「未達」と表示して止めない。CL1 以上で 0738 の note と食い違う
- **影響**: マークの note・条文・ADR-0218 決定1 の「未達の種類を問わず」と実態が食い違う
- **直し方の案**: F-08 の決定の後に、止める未達の範囲を列挙して 1 か所で導く。0638 を止めない扱いに残すなら、その理由を ADR に書く

### F-03 高 IMPL-0523 通常の置き場の G-3 を読まず、誤って止め、書き換えも見逃す

### F-08 高 IMPL-0738 体制に由来しない未達へ広げる部分は新しい義務である(所有者へ上げる)

重の裁定 15 節 1 の問いへの結論である。

**人の確認の未達については既存の条文の読みと認める。G-3 のような体制に由来しない未達へ広げる部分は、新しい義務である。**

| 根拠 | 内容 |
| --- | --- |
| 表の置かれた文脈 | 直前の文は「体制の縮小を緩める向きの決定として扱わない…人が抜けた時点で、統制は既に成立していません」で、再テーラリングの節にある |
| 変更前の表の行 | `出荷しない。軸E「人員が足りない場合」の選択肢による`。解く道が人員の選択肢だけで、スタックの未確定を解けない |
| 引用の先例 | ADR-0055(149 行)は体制の変化点、ADR-0088(91 行)は評価者の段の未達である。いずれも人の確認に関わる。第3章・第5章の引用も体制の縮小の文脈にある |
| 条文を書き換えた事実 | 本束は表の行へ「未達の種類を問わず」を足し、R1 の行に「CL0 で規制業でない案件」の限定も足した |
| 本束自身の記述 | ADR-0218 決定3 と IMPL-0738 の note は「本標準が足す」と書く |
| 採用者への影響 | CL1 以上・規制業でスタック未確定のまま出荷していた案件が止まる。猶予は採らないと決めている |

裁定の理由 2 は「人員由来に限る読みは他の条文と合わない」とするが、挙げられた 2 つの未達(判定の確認、独立した安全性の評価)はどちらも人の確認の未達である。人員の数に限らない根拠にはなるが、G-3 まで及ぶ根拠にはならない。

**所有者に決めてもらう点**: 体制に由来しない未達(現在は G-3)でも CL1 以上・規制業の出荷を止めるか。止めるなら、新しい義務として ADR-0218 に明記し、既存の案件の扱いを決める。
