- 欠け: 全 PR(または承認のあった PR)で時間/規模の比を継続計測し、傾向を見る。
- 決定可能性: 算出は決定可能だが、**時間の入力の妥当性が乏しい**(作成から承認までの時計時間は、レビューの実時間を表さない。夜間・休日で膨らむ)。比の値の意味は決定可能でない。標準は rubber stamp の検知に使う(ゲートの健全性の計測)ので、傾向の表示にとどまる。
- 候補: (a) 全 PR で分布(中央値・下位の四分位)を出す所見(合否に使わない)。時計時間の近似の旨を同じ行に開示(根拠水準マーク)。(b) 計測の手段は品質保証の機能が四半期に手で集める(今の note のまま)と、ADR に記録して adopter。(c) IMPL-0136 と同じ関数で束ねる。

## 4. 横断の所見

1. 降ろせる規定の多くは「記録の存在・欄の非空」までが決定可能で、内容の妥当性は閉じない。標準の基準の文言(「完備」「欠落 0 件」)は内容の完備を含むため、実装が標準より弱い部分を note と README の基準表で開示する必要がある(現状の 'partial' 表示はそうなっている)。
2. 0042・0044・0046 は、機械が結合するための**新しい記入の義務**(台帳の対象欄、記録の置き場)を要する。採用者への新しい義務に当たるので重の候補。
3. 0048 は実装が在り、実機の確認だけが欠ける。undelivered の理由が「降りていない」ではなく「確かめていない」であり、表示の食い違い(「高」になりうる)。
4. 0023 も検出と警告は在り、残るのは「つなぐ」の定義。
5. 0132 は check-decisions.mjs の注記で未実装が確認できた(note は正しい)。
