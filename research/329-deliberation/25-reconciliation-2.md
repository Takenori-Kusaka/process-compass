## 新たな所見

### N-1(中) ADR-0141 決定8 の見出しと frontmatter の description が、限定の前の文のまま

- 所在: `adr/0141-...md:73`(「### 8. PR を経ない起動の結果を、G-5 の通過に数えない」)、同 :3 の description(「PR を経ない起動の結果を G-5 の通過に数えません」)
- 根拠: 決定8 の本文は「PR を経る変更の G-5 の通過に数えるのは…」へ限られ、PR を経ないコミットの G-5(push を契機とする実行。これも字義どおりには PR を経ない起動)を対象外とした。見出しと description は限定を持たず、H-1 と同じ読み違いを要約の側に残す。description はサイドバーと一覧に出る。規範の条文(第4章 837 行)は正しいため、表示と実態の食い違いの「高」には当てない
- 開示・閉じ方の案: 意味を変えない文言の食い違いなので、編集の指摘(ed)として議長が直すのが妥当。見出しを「### 8. PR を経る変更で、PR を経ない起動の結果を G-5 の通過に数えない」、description の該当の文を「PR を経る変更では、PR を経ない起動の結果を G-5 の通過に数えません」とする。ADR-0141 は未公開なので当日の訂正の扱いに収まる。直さない場合は、決定8 の本文の冒頭に「見出しの限定は本文による」と書くほか、閉じる手段が無い(根拠水準マークの対象ではない)

### N-2(ed) EV-0137 への補いの文が、マークの書式の位置に無い

- 所在: `ci-gates.md:1025-1028`(EV-0137 の block)
- 根拠: 補いの文「区分の語は、ADR-0141 で列挙に無い離脱へ改めました。」が、**対象** と **根拠の水準** の行の間にある。`evidence-marking.md:57` は補足を「空行を挟んで記載する」(差し替え条件の後)とする。後ろに空行が無いため、描画では補いの文と「根拠の水準」が1つの段落に連なる。lint は通るが、書式の正本と食い違う。台帳(`evidence-ledger.md`)の EV-0137 の対象は「未達とすること」のまま出て、補いは台帳に届かない
