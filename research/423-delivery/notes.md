# #423 PR を経ないコミットへの区分の下限の規則と判断記録の要否の規則の照合(降ろすだけの対応)

## 振り分け

条項の新設・改廃は要しない。第3章 3.8.1 の要求事項2・6 と第2章 2.6 の要求事項2・6 は「変更」に掛かり、PR を経ないコミットを除いていない。PR を経ないコミットは、標準がトレーラ `Risk`・`Verification` で扱う正規の経路である(pr-workflow.md、git-strategy.md)。実行層が PR だけを照合していたのは降ろし漏れで、準拠テンプレートへ降ろすだけの対応とした。

## 既存の決定との突合

- 規則は当該コミットの直前の構成から読む。委任の規則の照合(aggregate-evidence.mjs の委任の識別。コミット自身が足した規則で自らを範囲へ入れない)と、PR の検査が基底ブランチから読む扱い(ADR-0078)と同じ向き
- PR を経ないコミットの欠落の扱い(トレーラ Risk・Verification の欠落を記載の欠落にし、成立済みのコミットは書き換えず判定記録の「対象」で補う)に揃えた。区分は判定記録の「変更のリスク区分」で補った値にも下限を当てる
- 2.6 の S0 の扱い(ADR-0101 決定3)に揃え、S0 では欠落にせず品質レポートに注意を出す。ステージ不明は欠落にする側に倒す(stageOf が null)
- 申告で外す経路は置かない(ADR-0101 決定3)
- 3.8.1 の要求事項6(規則と製品のコードの同時変更)・2.6 の要求事項6 も、PR の検査と同じく欠落にする

## 範囲の外として記録すること

- R1・R2 の確定者の記名(3.8.1 の要求事項3)は、PR を経ないコミットについては判定記録の件数として開示するだけで、コミットごとに欠落にしない。本件では変えていない(IMPL-0391 の note に書いた)
