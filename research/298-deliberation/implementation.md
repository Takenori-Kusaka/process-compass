## 5. 裁定と食い違った点

1. **1.2 の「採用組織が定めます」**: 裁定の文の案は「本標準が定めない事項(…)は、採用組織が定めます」だった。主語が採用組織の平叙の動詞文は、第1章 1.7.1 で要求として読まれ、採用組織に反復の周期などを定める義務を課す。このため「本標準は、…を定めず、採用組織に委ねます」と主語を本標準にした。裁定 6 章の突合(1.2 の段落が要求に読まれないか)に従った直し
2. **2.2 の 1 文の主語**: 裁定の案は「AI協調ループは、…を規定しません」。同じ理由で「本標準は、AI協調ループについて、…を規定しません」とし、規定するもの(工程・判定者・判定基準)を 1 文足した
3. **1.4 の「第8章の調整で設けたもの」**: 第8章は会議体を「設置ではなく対応づけ」で扱う。「設けたもの」だけでは、既存の場へ対応づけた会議体が定義から外れる。「対応づけたもの、または設置したもの」とした
4. **1.2 に EV を付けていない**: 裁定は 1.2 の段落に EV を求めていない。「主張しない」は決定であり、実証を欠く値・前提を述べていないため付けていない。主張しない理由(併用した案件の記録を確かめていない)は本文に書いた
5. **H.8 の行の数**: 品質保証の委員の案は「使ってはならない」3 行だった。裁定 5 章の 4 表現を 1 行にまとめ、イベントでの判定(委員の案の 3 行目)は足していない。裁定がこの行を挙げておらず、工程ゲートの判定の成立は第4章が既に定めるため
6. **A.7 の接点の 3 つ目**: 裁定は「本標準は、併用した開発がスクラムであるかを判定しない」とだけ書く。ガイドの End Note の 2 文(不変性と、一部の実装はスクラムではない)を逐語で引いて、この表明の根拠にした
7. **出典台帳の再生成の副作用**: SRC-0640 を足した後の `npm run sources:index` が、#309 の出典(SRC-0634〜0639)についての生成物の更新も含めた。以前の作業で再生成されていなかったもので、生成物なのでそのまま含めた
8. **第8章 EV-0148 の Scrum Guide**: 裁定 M-7 は「本文と規定の附属書には手法の固有名を出さない」とする。第8章(本文)の EV-0148(#296 で付与)は、根拠水準のマークの補足の中で Scrum Guide(2020)を出典として名指ししている。マークは第1章 1.7.2 で説明であり、関係の主張ではないため変えていない
