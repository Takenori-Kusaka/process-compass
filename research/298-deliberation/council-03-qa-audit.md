## 1. 立場と全体の見立て

1. **監査人にとって最も危険なのは「書かれていないこと」ではなく、本文が黙示に関係を主張していることである**。現状、本文は関係を一言も主張していないのに、(a) 附属書A A.1 が「有効な形」と断定し、A.3 が「実証済みの部品」と書き、(b) フェーズ6 が「スプリントごと」を要求の周期にし、(c) 2.10 の「設けません」が禁止として読める。監査では (a) は根拠の無い有効性の主張、(b) はスクラムの前提、(c) はスクラムのイベントの禁止として、互いに矛盾した 3 通りに読まれる。**節を足す前に、この 3 つを直さなければ、どの案を採っても矛盾が残る**
2. **「併用できる」は、本標準が確かめる手段を持たない主張である**。併用した開発が「スクラムである」かはスクラムガイドの著者側の解釈(End Note の immutable)で決まり、併用の効果は実証が無い(HELENA は自己評価で効果量小、Cooper は知覚ベース)。監査で根拠を問われたとき、出せる証跡が無い。**主張しないと明記する(C)を核にする**
3. **対応表(A)は、本プロジェクト自身がすでに一度誤った**。#267 への回答は「附属書A で対応づける語」と書いたが附属書A にその語は無く、「完成の定義 = ゲートごとの判定基準」という対応は、開発者の自己判定(完成の定義)と、開発ラインの外の記名の単独判定(G-7)を同じものとして読ませる。**対応表は記録と実態の食い違いを生む装置として働く**(E2、自己の観察 1 件)
4. **記録と実態が食い違う経路は、新しい禁止ではなく、既存の規定の所在を引くことで塞ぐ**。ゲートは単独判定・記録が成立要件(第4章)なので、イベントでの合意・完成の定義の充足・ボードの「完了」はゲートの判定に数えないと、本標準を主語にして表明する。対外の書き方は附属書H H.8(規定)へ行を足す
5. **起票者の前提「読者の既知と接続する説明は要る」は、正本で「関係を主張しない」と書くことで満たせる**。派生物が書けるのは「本標準は開発の方式を限定せず、反復手法との関係を主張しない。ゲートの判定はイベントで代えない」までであり、それ以上(対応・併用の推奨)を派生物に書かせない根拠も同じ文が与える

## 3. 論点ごとの詳細

### M-1 書く型

**判定: 主張しないと明記する(C)を核に、記録の食い違いの経路の所在の表明・対外表現・既存の由来の主張の是正を組にする。対応表(A)は作らないと明記する。**

採る案の文(本文。置き場は M-2):

> 本標準は、開発の方式(反復型か計画駆動か)と、採用する開発手法によって、適用対象を限定しません。
>
> 本標準は、既存の開発手法(スクラムその他の反復型の手法を含む)の採用を求めず、禁じません。本標準は、それらの手法との併用の可否と効果、手法の構成要素と本標準の規定との対応、および併用した開発がその手法の定義を満たすことを、主張しません。確かめていないためです。
>
> 本標準は、他の手法のイベントでの合意、完成の定義の充足、作業項目の状態の変更を、ゲートの判定として数えません。ゲートの判定は単独の判定者が行い、判定記録の作成をもって成立します(第4章「判定の成立」)。

- 3 段落とも主語は「本標準」で、1.7.2 により説明(表明)として読まれ、要求事項を増やさない。3 段落目は新しい禁止ではなく、第4章 L50(判定会議を開かない)と「判定の成立」(記録が成立要件)の帰結を、手法を使う読者の側から引き直したものである
- 根拠水準: 主張しないことそのものは決定であり E を要しないが、理由(「確かめていない」)を開示するため `:::caution[暫定 EV-0149 / 見直し 2027-10]`(E0)を付ける。**対象**: 既存の反復手法との併用の可否・効果を本標準が確かめていないこと。**差し替え条件**: 本標準を適用した案件のうち、反復手法のイベントと本標準のゲートを同時に運用し、判定記録とイベントの記録を突合できたものが 2 件以上観測された時点で、併用の条件を書くかを再審議する

選ばなかった案:

- **A(手法との対応表)**: 落とす。(1) H.10 が「確かめていない範囲を覆う対応表は作らない」を既に決めている。同じ理由がそのまま当たる。(2) 本プロジェクトの一度の対応づけ(#267 回答)は、所在の誤りと意味の誤り(自己判定の完成の定義と記名の単独判定を同一視)を同時に生んだ(E2、自己の観察)。(3) スクラムガイドは immutable を謳い、対応の誤りは「スクラムではない」と相手側から否定されうる。本標準はその判定権を持たない。(4) ADR-0017 決定5 の「比較の公平性」の懸念。対応表を作らないことは、**「作らないと決めた」と A.7 に書く**(H.10 末尾と同じ型)
- **B(併用の条件を規範として本文に置く)**: 落とす。(1) 「〜を併用する組織は〜しなければならない」は、適用範囲を手法名で切る規範になり、自己申告の手法名で条項の適用が変わる。監査では「スクラムと名乗らなければ掛からない」条項になる(ADR-0044 決定4 の論法と同型)。(2) 条件を書けば「条件を満たせば併用できる」の黙示の主張が生じ、C と両立しない。(3) 条件の中身(イベントでゲートを代えない)は既存の第4章で既に効いており、重ねると 1.7「同じ事項の規定は1か所」に反する。B の保護の中身は、C の 3 段落目(所在の表明)で取り込む
- **B を附属書A に説明として置く**: 一部を採る(A.7 の事実の記述)。「条件」の形にはしない。条件の形は参考の附属書でも適合の目安として読まれる
- **D 単独**: 落とす。受入条件を満たさない。派生物が書けない状態(#298 の契機)を固定する
- **C 単独(既存の記述を直さない)**: 落とす。1 章で方法中立を表明しても、A.1・A.3 の断定、フェーズ6 の「スプリントごと」、2.10 の禁止の読みが残り、本文が自分と矛盾する(1. 見立て 1)

### M-2 置き場

**判定: 採る。第1章 1.2 の表と「適用外の領域が存在する場合は…」の段落の後へ、M-1 の 3 段落を置く。附属書A に A.7 を新設する。対外表現は附属書H H.8。**

- 1.2 を選ぶ理由: 「方式で限定しない」は 1.2 の表に方式の区分が無いことの帰結であり、適用範囲の節が正本の所在になる。監査人は適用範囲を最初に読む

### M-3 併用を書くなら何を書くか

**判定: 併用の条件は書かない(主張しないと明記する)。附属書A A.7 に次の事実だけを、出典の版と取得日を固定して書く。**

## 4. 他の委員に問いたいこと
