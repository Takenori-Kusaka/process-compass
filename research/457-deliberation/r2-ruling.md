# #457 再審議の裁定(議長 2026-11-27)

- 重さ: 重(論点2 が ADR の原則の変更に当たるため)。5 委員(起案・現場・品質監査・規格・弁護)の結論は、論点1〜3 で一致した。割れたのは K8 の表示(`未達` か `開示`)だけ
- 裁定の本体は `r2-ruling-draft.md` の §1〜§7 を採る。本書は、議長が最終に決めた点と、裁定の案からの変更だけを書く

## 1. 裁定の要旨

| 論点 | 裁定 |
| --- | --- |
| 1 一続きの追跡 | 条項も様式も足さない。**PR の本文を追跡の面**とし、既存の記録(トレーラ `Spec` → 機能仕様・受入基準・タスク、G-6 基準6 の検証の記録、5.5.1 の理由の記録、指示資産の版、実行の識別子)を1本で辿る道筋を、手引きと H.3 に置く。答えの中心を、機械の記録(モデルの版)から追跡へ移す |
| K7 理由の記録先 | 理由の記録先を、取り込みの方式に依らず変更から辿れる所とし、PR の本文を既定にする。手引きと IMPL-1052 の note を直す |
| K8 途中のコミットのトレーラ | `未達`。新しい実装マーク(undelivered)で表示する。直すのは template の変更で、束 D1 へ回す |
| 2 調査の範囲 | 広げない(ADR-0267 を保つ)。調査の結果は既存の器(2.6 の判断記録、Spec の前提、5.5.1 の根拠の所在)へ寄せる。調査が作業そのものである場合は、その成果物を成果物として扱う。全件の調査の記録と、実行の記録の保持の義務は採らない |
| 3 モデルの版 | 記録は保つ。説明・再現・正しさの証跡ではないと明記し、構成管理の記録(影響範囲の特定・変化点・供給者の管理・検出率の測定の有効性・宣言と実態のずれの検出)として位置づけ直す。記録をやめる案は、安全関連部の要求に当たるので採らない |

## 2. 議長が決めた点

1. **前提の訂正を受ける**。議長は「スカッシュの実例が無い」と指示したが、誤りだった。#361 の試行(2026-11-26。C-27・D-8)が、スカッシュの2つの設定を観測している。K7(理由を途中のコミットのメッセージへ書くと、設定B では既定ブランチに残らない)は、観測済みの形として扱う(E2)。K8(`Agent-Run`・`Agent-Assets`・AI の `Co-Authored-By` が残るか)は観測していない。根拠水準マークで開示し、観測は #361 へ寄せる
2. **K8 の表示は `未達`**。`開示` は H.3 では「本標準が統制を置かず、主張しない」の意味である。5.8.2 は変更ごとの生成の条件を求めており、統制は置かれている。降りていないだけなので、ADR-0028 により `未達`
3. **新しい実装マークの target は `evidence-aggregation`、`issue=457`**。運ぶ手段(PR の本文へ写す・ホスティングから読む)は束 D1 で決める。D-8(設定B では GitHub が本文の後に段落を足す)が「PR の本文の末尾へ写す」形を損なうので、手段を本束で決めない
4. **H.5 問11 の並べ替えは、本束で行う**。裁定の案は #465 の push の後へ回したが、同じ作業ツリーで #465 の直しの後に直列で実装するので、分ける理由が無い
5. **5.8.2 の条文は変えない**。5.8.2 は、版を説明の証跡と書いていない。読み方は ADR-0270 に置く
6. **`pr-workflow.md` の「スカッシュの後に残すトレーラ」の列挙の直しを、本束に含める**
7. **ADR は2つ**。ADR-0269(論点1・2。ADR-0267 を置き換えずに補う)、ADR-0270(論点3。ADR-0012 決定3 の理由を一部置き換える)。採用済みの ADR の本文は書き換えない。ADR-0012 の側は、ステータスの欄の表示だけを慣行に従って足す

## 3. 所有者の意見との対照

| 所有者の意見 | 裁定 |
| --- | --- |
| すべての記録を取るのではない | 採る。会話の全文の保存・全件の調査の記録・実行の記録の保持を義務にしない |
| チケットのように、目的・ゴール・ステップ・インプットを追う | 採る。既存の記録を、PR の本文を面にして1本で辿れるようにする |
| 何を調査したかを追う | **一部だけ採る**。調査の結果は既存の器へ寄せる。調査の過程の全件の記録は採らない。理由: 作成側の主張にとどまり、事後の作文になりやすく、求める規格が読めた範囲に無い |
| モデルの版を証跡にする価値は無い | 説明の証跡としては採る(外す)。記録そのものは保つ。影響範囲の特定と変化点の管理に要り、やめると安全関連部の要求に穴が開く |
