**H-1 入力の分離の参照先と、人の判定者への適用が実態と食い違う**

- 所在: `human-ai-boundary.md` 5.5.1 の理由の記録の箇条の3項目め(「入力の分離は第3章 3.5.4 による」)、ADR-0267 決定3(「読む順序は、第3章 3.5.4 の入力の分離による」)。元は `ruling.md` §1.3(「読む順序は G-6 の手順(判断の前に作成側の主張を読まない)が既に担う」)と §1.5(「抜き取りの判定者は自分の判断の後に読む(入力の分離)」)
- 根拠:
  - 3.5.4 は語の定義の節で、要求事項は 3.5.3「入力の分離(適用: 確認側の担い手に AI を置く場合)」にある(`roles-responsibilities.md` L673。IMPL-0021 の note も「入力の分離(3.5.3)」)
  - 人のレビュアについて、附属書C「入力の分離」は「作成側の説明文を後に読む順序は、人のレビュアには課さない」と書く(`review-guide.md` 「入力の分離」の箇条の2項目め)。G-6 の判定者と事後の抜き取りの判定者は自然人である。ADR の決定3 と裁定 §1.5 が言う「読む順序」の統制は、人の判定者には課されていない
  - 「数えない」そのものは manual の統制として成り立つが、ADR は止められない読む順序を、既にある統制として示している。裁定 §1.3 が「止められない統制を書くと、表示と実態が食い違う」として退けた形と同じ食い違いが、参照の側に残った
- 直し方: 5.5.1 の参照を「確認側の担い手に AI を置く場合の入力の分離は第3章 3.5.3 による。人の判定者には読む順序を課さず、附属書C『入力の分離』の勧めによる」の趣旨へ改める。ADR-0267 決定3 も同じく改め、人の判定者では「数えない」が判定者の manual の扱いだけで閉じることを書く。H.3 行4 の開示にも「人の判定者が理由を先に読むことは止めない」を足す(EV-0061 の範囲と揃える)

**H-2 H.3 行4 の未達の説明が IMPL-1051 の実態と食い違う**

- 所在: 5.5.1 の EV-0358 の本文(附属書IV 2(b)・42010)、5.5.1 の非課の段落(EU AI Act 第12条)、ADR-0267 のコンテキスト。`research/sources/` には SRC-0769 だけが足された
- 根拠: 裁定 §4.3 は「実装の担当は、新しい出典を出典台帳へ SRC として登録し」と指示した。既存の SRC-0087〜0089・0299・0489 は第14条・分類の指針などで、第11条・第12条・附属書IV、42010 の目次を収めていない(題目で確認)。`impl.md` に登録しなかった旨と理由の記録も無い。「調べた範囲に見つからない」の主張を、後から読む者が辿れない

**M-2 SRC-0769 の対象と、本標準が引く主張の間の隔たりを本文で開示していない**

- 所在: 5.5.1 の EV-0358 の本文「AI が書く理由は、実際の生成の原因と一致しないことがあります(arXiv:2505.05410。要旨)」、ADR-0267 のコンテキスト(「SRC-0769。要旨のみ」)
- 根拠: 要旨だけを読んだことは両方で開示されている(この点は可)。しかし SRC-0769 の summary 自身が「思考の連鎖と、変更の記録に書く理由は同じ対象ではない」と書く。研究は、手掛かりを使った推論の言語化の割合で、変更の記録の理由を測っていない。本文はこの転用を書かずに、理由を主張として扱う根拠にしている。読み手は直接の実証と読みうる
- 直し方: EV-0358 の本文と ADR に「推論モデルの思考の連鎖についての研究で、変更の記録に書く理由を直接測ったものではない(転用)」を足す。E0 の水準は変えない

**L-1 IMPL-1050 の check を裁定と変えた理由が、議長の記録に無い**

- 所在: `human-ai-boundary.md` の IMPL-1050(`check=manual`)。裁定 §4.5 は `check=presence`
- 根拠: 未達の間は検査する行が無いので manual は誠実な表示で、変えたこと自体は妥当と読む。しかし変更は `impl.md` にだけあり、裁定の指示と食い違ったまま。note は「presence の検査は語の存在だけを確かめ…(manual)」と、presence と manual を同じ文で書き、どちらの状態の説明か読みにくい。実装台帳の「検査のスクリプト」の列は `check-process-rules` を示すが、今はこの規定を確かめない(列の意味は降ろし先の既定の検査で、全体の仕様に依る)
- 直し方: 議長が裁定の補記で「未達の間は manual、束 D1 で presence(単位: 行)へ移す」と記録する。note は「現在は manual(降りていない)。束 D1 で行を置いた時点で check=presence(単位: 行)へ移す。presence は語の存在だけを確かめる」と時点で分ける

**L-2 EV-0358 に見直しの担い手と、測定の義務を課さない旨が無い**

- 所在: 5.5.1 の EV-0358
- 根拠: 裁定 §2.3 は見直しの担い手(保守者。材料は採用組織の報告と pit-wall・通し実行の数え上げ)と「採用者へ測定の義務は課さない」を設計に含めた。マークの書式上は必須でないが、差し替え条件が「採用組織の変更の記録で…」と始まるため、採用者の測定の義務と読まれうる。裁定 §1.10 で測定の割り当てを退けたこととの区別が本文から読めない
- 直し方: マークの本文に「材料は採用組織からの報告と、評価基盤・通し実行の記録の数え上げ。採用者へ測定の義務は課さない」を一文足す

**L-3 判断記録が理由の記録を兼ねるときと、G-6 基準3 の関係**

- 所在: 5.5.1 の箇条「設計上の選択は、本節の理由の記録で代えない」、ADR-0267 決定5(「判断記録が作業上の選択の理由の記録を兼ねてもよい」)
- 根拠: 「兼ねてもよい」は ADR にだけあり、5.5.1 には無い。兼ねた記録は G-6 基準3 では添付の確認の対象(判定の根拠)になる。5.5.1 の「G-6 の判定の根拠に数えない」と並べると、同じ記録が数えられるのか読み手が迷う。基準3 は記録の存在を、基準6 は検証の理由を見る(裁定 §3 の「別物」)が、本文はその区別を書かない
- 直し方: 5.5.1 に「判断記録が兼ねてもよい。そのとき G-6 基準3 が確かめるのは設計意図の記録の存在で、作業上の選択の理由の中身ではない」の趣旨を足すか、採らないなら裁定に記録する
