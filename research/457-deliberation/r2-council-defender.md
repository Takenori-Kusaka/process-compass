# #457 再審議 会議体: 弁護委員の意見(2026-11-27)

立場: 所有者の意見をもっとも強い形で弁護し、そのうえで弁護しきれない点を認める。所有者の意見は決定ではなく審議の入力であり、弁護は採用の勧めではない。

確かめたこと: `r2-intake.md`・`r2-options.md`・`r2-external.md`・ADR-0267 の本文と、前回の弁護委員の意見を読んだ。本文(`human-ai-boundary.md` 等)の行は、r2-intake の引用を信じた。私は本文の行を読み直していない。外部の規格は r2-external のとおり二次資料止まりで、規格の本文は誰も読んでいない。「推測」と書いた箇所は、読んだ根拠が無い。

## 0. 先に: 受付案は所有者の意見を薄めているか

所有者の意見は2つの主張に分かれる。受付案はそれぞれ別の扱いを受けている。

| 主張 | 受付案の扱い | 薄まっているか |
| --- | --- | --- |
| (甲)ブラックボックス化への答えは全記録ではなく、目的・ゴール・調査・ステップ・インプットの追跡である | 1-B(結ぶ)+ 2-A(調査は広げない) | **「調査」の部分だけ薄まっている**。追跡の他の5要素は既存の記録で結べるが、調査は結べない(K4)。2-A は「所有者の意見の核の1要素を採らない」と同義で、その旨を記録するだけに止まる |
| (乙)モデルの版そのものを証跡にする価値は無い | 3-A(記録は保つ。説明の証跡から外す) | **「証跡」の否定は受け入れられている**。薄まっていない。3-A が退けるのは「記録をやめる」ことで、これは所有者の字句(証跡にする価値)を超えた読みである |

つまり3-A は乙を実質的に採っている。薄いのは2-A である。ただし、弁護委員として強い主張をすると、2-A の「広げない」は理由づけが弱い。r2-options の根拠は「判断に効いた調査は所在として残る」だが、K4 は「変更の単位の調査を残す記録が無い」とも書いている。両方が r2-intake に並んでいる。**どちらが実態かを、実行で確かめた形跡が無い**。

## 論点1: 一続きの追跡

### 採る案: 1-B を強めた形(新しい案 1-E)。条項は足さない

受付の1-B は、手引きに「辿る順序」を書き、K1 を開示し、K7・K8 を直す。これに次を足す。

1. **PR の本文を追跡の頭に据える**(1-B の1にない主張)。理由は K7・K8 から導ける。スカッシュのマージで既定ブランチへ残るのは、PR の本文(スカッシュのメッセージ)だけである。目的(変更の概要)・検証の記録・理由・トレーラは、PR の本文に居るときだけ、後から辿る者の手元に残る。「チケットのように読める」を所有者が求めるなら、本標準の既存の記録の中で最もチケットに近いのは PR の本文であり、これを頭にするのが筋である。新しい様式ではなく、既にある様式(template のPR 様式の「変更の概要」「検証方法と結果」、トレーラの節)の**位置づけ**を変えるだけで済む(確かめたこと: r2-intake §1 の表、K7・K8)
2. **K8 の直し方は (a) を採る**: テンプレートが PR の本文へ、PR 内のコミットの `Agent-Run`・`Agent-Assets`・`Co-Authored-By` を写す。決定可能な条件(値の一致)で機械の検査にできる。(b) の「スカッシュの設定変更」は、PR の本文を末尾の段落で読む既存の検査と衝突すると r2-options が書いており、採らない。ただし (a) は実行での確認が要る(推測: 写し漏れ・形式の違いで検査が偽の失敗を出す可能性)
3. **K8 が直るまで、H.3 の「最も弱い止め方」へ `未達` を出す**。ADR-0028 の原則どおり。標準が自ら「機械が示し人が止める」と表示しつつ、既定の運用で欠ける状態を放置するのは、表示と実態の食い違いであり、巡の数に関わらず直す類の「高」に当たりうる
4. **K3 は様式の注記に止める**(条文にしない)。検証の記録が受入基準を識別子で引く形を、template の PR 様式の欄の注記で勧める。理由: 1-C は G-6 の差し戻しの理由を増やし、FND-0020 の「提出のための作業」へ寄る。識別子の存在は決定可能だが、整合(その検証が本当にその基準を満たすか)は決定できない。Automotive SPICE の注記(リンクの存在は整合を意味しない、FND-0237)が、機械の検査を条文の根拠にすることへの歯止めになる
5. **H.3 は2行のまま、「止める場所」の列を鎖の言葉で書き換える**。行の区分(何をしたか=機械の記録、なぜ=人の記録)は、「最も弱い止め方」の導出(ADR-0266 決定5)に使われる。1行に寄せると導出が粗くなる(r2-options 自身の指摘)。所有者の「一続き」は、列の文と手引きの順序で満たせる

### 退ける案

- **1-A**: K7・K8 を直さないので、標準が勧めた記録が既定で失われる。追跡を主張しないので欠陥と判定できない。却下
- **1-C(条文化)**: K3 の識別子を条文にすると、新しい義務と形式の差し戻しが増える。ただし**退けるのは今回であって、永久ではない**。K3 の違反が実行で多発するなら再検討する条件を、ADR に書く
- **1-D(チケット様式の新設)**: 既存の記録と内容が重なる。ステップの欄は5.8.6 要求事項8(AI に操作の要約を生成させない)と衝突する。**所有者の字句の「チケット」は、この意味(新しい様式)では採らない**

### 残る懸念

- 手引きの順序は manual で、守られたかを機械は確かめない。「辿れる」と名乗れるのは、識別子で結ばれた範囲に限る。結ばれていない範囲(K1: Issue 番号・`setup`、K5・K6)を、同じ場所に開示することを前提にする
- K1 の範囲が広いと、「チケットのように辿れる」と書いた文が、文書・設定の変更では偽になる。範囲を狭く書く(製品のコードの変更に限る)必要がある。どこまで書くかは議長の裁定

## 論点2: 「何を調査したか」を残す範囲

### 採る案: 2-C を基本に、2-A の「条項を広げない」を保つ。ただし 2-A の理由づけを改める

受付は2-A(広げない)を推す。理由の中心は「効かなかった調査を残しても、読む者の要る情報は増えない」である。これは**半分しか成り立たない**。効かなかった調査(退けた案)を後から知る価値は、同じ調査のやり直しを避けることにある。外部の調査は、この価値を測った研究が無いと書く([未])。「増えない」は推測である。

とはいえ、広げる側の根拠も弱い。外部の調査によれば、「何を調べたか」を変更ごとに求める規格は見つからなかった。AI の自己申告は実際の作業と一致しない(忠実さ 20% 未満、arXiv:2505.05410、要旨のみ)か、捏造しうる(FND-0228)。作成側の説明は、レビューの判定を歪める(FND-0147)。ADR-0267 が採らなかった案と同じ欠点が、ここでも成り立つ。

したがって:

1. **条項は広げない**。5.5.1 の範囲(退けた案がある選択・外部の制約に従った選択)を保つ
2. ただし2-A の「調査は残さない」という言い方は採らない。**「調査は、判断を変えたときは既存の器に残す」(2-C)** と、手引きと template の PR 様式の注記に書く。器は、設計上の選択=判断記録の代替案、確かめていない言明=前提の台帳、作業上の選択=5.5.1 の所在。新しい欄を作らない
3. **「調査を変更ごとの全件で残さない」と決めた旨を ADR に明記する**。r2-options のとおり、却下は成果であり、「書かれていない」と「課さないと決めた」を区別できる状態を保つ
4. **残した調査は、作成側の主張であり、判定の入力に数えない**旨を、5.5.1 の理由と同じ行に置く(ADR-0267 の既存の扱いを調査にも延ばす)

### 退ける案と、弁護しきれない点

- **2-B(全変更で調査の欄)**: 退ける。ADR-0072・FND-0147・FND-0228
- **2-D(実行の記録の保持を標準の要求にする)**: **所有者の意見をもっとも強く実現する案はこれである**。「何を調べたか」を AI の申告でなく実行の事実で残せる。FND-0228 の捏造の経路を避け、K5・K6 も閉じる。弁護委員として、これを最も強い形の主張として示す。ただし**採らない**。理由: 会話の全文に秘密・個人情報を含みうる(ADR-0267 決定6)。保管の費用。読む者はインシデント・監査に限られる。実行基盤ごとの差。そして採用者への新しい義務であり、これは重の議題で、所有者の意見は「全記録ではなく」と言っている。**2-D は所有者の第一の字句(全記録ではなく)と矛盾する**。弁護の対象としても、所有者の意見の中で2つの主張が衝突している点は認める
- 中間の形(推測、実行で確かめていない): 保持は採用者に委ねたまま、実行の記録の**所在の宣言**(どこに何日保つか)だけを D-0 の担い手の宣言に足す。これなら全記録の義務ではなく、「引ける所がある」ことが保証される。ただし、新しい欄を足す案であり、「細かい定義を増やさない」と緊張する。議長が r2-options に無い案として検討する価値はあるが、私は推さない(宣言の欄が形骸化しない保証が無い)

### 残る懸念

- AI が「読まずに書いた」場合を、記録から見分けられない。ADR-0267 の限界がそのまま残る
- 調査の記録を既存の器へ寄せる(2-C)のは手引きで、器の選び方を誤ると散る。「後から調査をやり直す費用」を減らしたいという所有者の動機に、manual の手引きで答える限界がある

## 論点3: モデルの版の位置づけ

### 採る案: 3-A + 3-D。ただし受付の3-A に次を足す

受付の3-A は、H.3 の行から生成の条件を外し、ADR-0012 決定3 の「再現」を新しい ADR で置き換える。これに賛成する。所有者の「証跡にする価値は無い」を、説明の証跡としては**全面的に採る**ことになる。外部の調査も、版を説明の証跡にする規格を、開発の道具としての AI には見つけていない。版を取る規格(IEC 62304 の SOUP、ISO 26262-8 のツール、FDA PCCP、SR 11-7、ML-BOM)の目的は、構成管理・変更管理・影響範囲の特定である。

足す点:

1. **「証跡ではない」を ADR と 5.8.2 に直接書く**: 「版の記録は、影響範囲の特定と、宣言と実態のずれの検出のためのものであり、ブラックボックス化の説明にも、正しさの根拠にも、再現にもならない」。5.8.2 は既に「再現のためではない」「正しさの根拠は検証の記録」と書いている(L1158〜1165)ので、ADR-0012 決定3 の理由文だけが食い違う。これを解く
2. **H.3 の行から、項目7(宣言した担い手と共著者の不一致)の証拠も外す**。r2-options の3-A の1に含まれる。「何をしたか」の証拠ではなく、変化点のずれの検出だから
3. **E0 の開示を、問11・問22 に加えて 5.8.2 の本文の近くにも置く**。影響範囲の絞り込みに使えた実績が無いこと(問11・問22 が E0 と開示済み)を、位置づけ直した文の隣で見えるようにする。見直しの条件(インシデントが起きて版で絞れたか、絞れなかったか)を `見直し YYYY-MM` と一緒に置く
4. **K8 の修正(論点1 の (a))を、3-D として先にやる**。「記録しているが既定の運用で落ちる」記録は、影響範囲の特定の役も果たせない。残すと決めた以上、欠けない記録にする

### 退ける案と、弁護しきれない点

- **3-B(記録をやめる)**: **弁護しきれない**。所有者の意見をもっとも強く実現する案だが、(1) safety-verification 要求2(安全関連部の構成管理)が根拠を失う。安全に当たり、ADR の原則の変更・安全という重の中でもさらに別の議題になる。(2) 宣言と実態のずれの機械の検出(3.13.5)が申告だけになる。FND-0059(E2)は、指定と実際が違った事例を記録している。(3) インシデントで点検の範囲が出荷済みの全変更になる。所有者の「価値は無い」を、「証跡としての価値は無い」まで読む限り弁護できるが、「記録そのものに価値が無い」とは読めない。後者は事実として支えられない
- **3-C(期間の記録で代える)**: 弱い形なら弁護できる。変更ごとのトレーラ(K8 で落ちる)に依らず、影響範囲を粗く保つ。しかし、宣言と実態がずれたとき(FND-0059)、期間の記録は実態を表さない。並行の実行で複数のモデルが動く構成では、期間で一意に決まらない。**3-A の補助として、期間の記録を併用する形(推測、実行で確かめていない)は考えられる**が、新しい欄を増やすので推さない

### 残る懸念

- 版の識別子が固定の挙動を指さない(別名・非決定性)ため、影響範囲の特定の役も限られる。外部の調査は、提供者・世代によって異なり、一律には言えないと述べる。この限界を開示しないと、「版を残している」ことが保証の水増しに読まれる
- 「実際に動いたモデル」を記録する(OpenTelemetry の `response.model` 型)のか、「指定したモデル」を記録するのかを、`Co-Authored-By` が区別するか未確認(推測: 指定側だけの場合、FND-0059 の事例を検出できない)。3.13.5 の検出の入力が実態を表すかは、実行で確かめる必要がある

## 第7章の例外承認で受けられないか

受けられない。7.3 は満たさない基準を進める手続で、本件の論点(追跡・調査・版)は、新しい義務を課すかどうかの問題である。義務が書かれていなければ逸脱の対象にならず、例外承認で「書かれていない義務」を埋めることはできない。前回の弁護委員の意見と同じ結論を採る(私は前回の記録を読んだだけで、7.3 の本文を読み直していない)。

## 破られたとき誰が何を失うか

| 破られること | 失う者 | 失うもの |
| --- | --- | --- |
| K7・K8 を直さず、既定のスカッシュで理由・トレーラが落ちる | 保守・インシデント対応・内部監査の担い手 | 書いたはずの理由と、生成の条件。書いた者は失わない(書いたつもりのまま) |

記名欄は、どの案でも足さない。

## 議長への勧め

1. 論点1 は 1-B を強めた形(PR の本文を頭にする。K8 は (a) で直す。K8 が直るまで `未達` で表示する)。K7・K8 は本件の範囲で直す。D1 で IMPL-1052 を降ろす前に要る
2. 論点2 は条項を広げない(2-A の結論)。ただし根拠を「効かない調査は要らない」(推測)から、「全件の調査の記録は、作成側の主張にとどまり、判定に数えられず、規格にも無い」に改める。2-C の手引きを添える。2-D を採らない旨と、その理由(所有者の「全記録ではなく」と矛盾すること)を ADR に明記する
3. 論点3 は 3-A + 3-D。「証跡ではない」を ADR に直接書く。E0 と見直しの条件を置く。3-B・3-C は退ける
4. 所有者の意見の「証跡にする価値は無い」は、説明の証跡としては採り、構成管理の識別子としては採らない。この区別を所有者へ返す文面に明記する
5. 重へ上げる必要のある点: 2-D(新しい義務)と3-B(安全)を採る場合のみ。上の勧めは、どちらも採らない
6. 議長が裁定すべき残り: H.3 を2行のまま書き換えるか(私は2行のまま)。K1 の開示の範囲。ADR は 0269(追跡・調査)と 0270(版の目的)に分けるか、1つにまとめるか(私は分ける: 版の目的は ADR-0012 の置き換えで、論点が違う)

## 弁護しきれなかった点(正直な一覧)

- 所有者の意見の中で、「全記録ではなく」と「調査・ステップ・インプットを追う」は、緊張している。後者を機械の記録で満たすと(2-D)前者に反し、自己申告で満たすと(2-B・1-D)FND-0228・FND-0147 に反する。両立する形は、既存の記録を結ぶこと(1-B)だけで、「調査」の要素は結べない部分が残る
- 受付案の2-A の理由づけ(効かない調査は価値が無い)は、実測がない推測である。結論は支持するが、理由は改める
- 追跡が後からの説明を改善した効果の測定は無い。1-B も E0 のマークが要る
- 弁護の限界として、規格の本文を誰も読んでいない。外部の調査の「規格に無い」は、「読めた範囲に無い」である
