## 高

### H-1 IMPL-0118 の note と ADR-0127 決定5 の帰結は「G-6 が未達の体制では、範囲に触れた件数を開示する」と書くが、その件数を出す処理は無い(表示と実態の食い違い)

- 所在: 表示は `exception-escalation.md:685` の IMPL-0118 の note(「G-6 が未達の体制では、範囲に触れた件数を開示するだけで数えない扱いにしない」)と、`adr/0127-…md` 決定5 の帰結(「範囲に触れた件数を開示するだけで」)。実態は template `aggregate-evidence.mjs:1741`(`g6AppliedStructure ? restrictionHit(...) : { hit: false, restrictions: [] }`)。`restrictionHit` を呼ぶのはここだけ
- 食い違い: G-6 が未達の体制では範囲を照らさない。そのため範囲に触れた変更は数えられず、どこにも出ない。保証の開示の行(`aggregate-evidence.mjs:5517`)は、解除されていない制限があると「範囲に触れ、独立レビュア2名に満たず数えなかった変更 0 件」と出す。読み手は「範囲に触れた変更は無い/すべて満たした」と読む。note が言う「範囲に触れた件数の開示」は実装に無い。IMPL-0118 は `state=delivered check=machine` のまま
- 直し方(どちらか):
  1. 実態を note に合わせる。G-6 が未達の体制でも `restrictionHit` を呼んで「範囲に触れた変更」の件数だけを数え、項目1 の行に「G-6 未達の体制のため照らしただけで、数えない扱いにしていない」と出す。数えない扱いは変えないので、裁定5 の範囲を超えない。試験を1件足す
  2. note と ADR の帰結を実態に合わせる。「G-6 が未達の体制では範囲を照らさず、件数も出さない。行の『数えなかった変更』は 0 と出る」と書き、行の文にも「G-6 を適用する体制に限る」を足す
- 推奨: 1。2 を採る場合も、行の文の「0 件」が誤読されないよう、行の文の直しは要る
