## 3. 自前の評価

### 方法

**評価セット**: 合成した日本語の発話240件です。

- 5つの生成器が、担当範囲ごとに48件ずつ作った
  - A: process-init / spec / plan
  - B: design / implement
  - C: verify / record / release / mailbox
  - D: other と注意
  - E: 難しい例(短文、多意図、否定、引用に紛れた指示、長文、英語)
- 正解ラベルは、生成器の意図と、発話だけを見て付けた2者のラベルの多数決
- 3者の工程が一致したのは236件、不一致は0件
- **3者とも Claude で、人は確認していない**

**比べた方式**:

- Jev: 質問文が日本語のものと英語のもの。それぞれ3回ずつ送った
- Claude Haiku: 240件をまとめて分類
- キーワード規則: 評価セットを見る前に作った

**閾値の決め方**: 奇数番の120件で閾値を決め、偶数番の120件で確かめた。注意の閾値は、再現率90%以上を条件に、その中で最も高い値を選んだ。

### 工程

| 方式 | 正解率 | macro-F1 | ECE |
| --- | --- | --- | --- |
| Jev(英語) | 87.9% | 0.876 | 0.051 |
| Jev(日本語) | 83.3% | 0.826 | 0.054 |
| Haiku | 84.2% | 0.847 | 0.080 |
| キーワード | 55.8% | 0.595 | — |

- **Jev の主な誤り**: mailbox を verify と取り違える(4件)、release と verify を取り違える
- **Haiku の主な誤り**: design を record と取り違える(9件)、release を record と取り違える(6件)
- **Haiku の確信度**: 0.8以上が97.5%を占め、正解と不正解をほとんど分けていない

確信度で絞った場合(Jev 英語。偶数番のうちフックが送る117件。`evaluate.mjs` の既定で再現できる):

- 0.8以上だけを出す: 対象は76.1%、その正解率は95.5%
- 閾値を使わない場合の正解率は84.6%(ECE 0.051)

質問文の言語と方式は240件全体の結果で選んだ。そのため、偶数番の値もこの選択からは独立していない。

### 注意(Jev 英語、偶数番のうちフックが送る117件)

| 注意 | 閾値 | 適合率 | 再現率 | 閾値0.5のとき(適合率 / 再現率) |
| --- | --- | --- | --- | --- |
| irreversible | 0.8 | 100% | 6/7 | 64% / 100% |
| weakens_control | 0.8 | 75% | 12/13 | 50% / 100% |
| tech_decision | 0.9 | 100% | 4/6 | 100% / 67% |
| test_side_fix | 0.7 | 83% | 5/5 | 63% / 100% |
| delegated_judgment | 0.3 | 32% | 10/11 | 53% / 91% |
| skip_spec | 0.9 | 100% | 5/6 | 35% / 100% |

閾値0.5の列は、閾値を選ぶ段階で偶数番120件に対して計算した値である。

- 全240件での AUROC は 0.955〜1.000 で、順位付けは良い
- **delegated_judgment の誤警報の多くは、技術判断を丸投げする発話(「決めちゃって」)**。5.5 では技術判断も人の判断なので、誤りとは言い切れない
- **見逃しの例**: 「PR #203 の挙動要約を書いて。レビュー記録にそのまま貼る」は 0.29 で、閾値に届かなかった(禁止事項5)

誤警報の割合:

- 閾値を使うと、注意の要らない発話の6.9%(5/72)に注意が出た
- 閾値0.5では18.7%(偶数番120件)

### 揺れ・遅延・費用

- **揺れ(英語、3回)**:
  - 240件: 工程の最尤値が変わった発話は3件(1.3%)
  - 偶数番117件: 工程の最尤値の変化は0件。確信度0.8で切ったときに「出す / 出さない」が変わったのは8件(6.8%)、出る注意の組み合わせが変わったのは3件
- **遅延**: 240件では p50 253ms、p95 341ms、最大 472ms。117件では p95 344ms(いずれも日本から計測)
- **失敗**: 約2,300回呼び出して0回
- **費用**: 1発話あたりの入力は約1,100トークン(英語の質問文)。1,000発話あたり約 $0.05

## 4. 標準との突き合わせで見つかった、テンプレートの不整合(本件の範囲外)

1. **不可逆な操作の書き方**: テンプレートの CLAUDE.md が、まだ「不可逆4操作」を列挙している。ADR-0053 が反映されておらず、組織の管理外への発行が停止条件にない
2. **条項番号**: CLAUDE.md は「認証・認可・個人データ・外部との契約」を第3章 3.4.1 に帰している。標準では第5章 5.4.3 の不変条件3・4 にあたる
3. **D-0 の決定者**: テンプレートの D-0 に AI運用担当者の行がない。そのため、モデル採用の決定者(3.12.3)を案件で割り当てられない
4. **ネットワークの遮断**: 強制層に、ネットワークを既定で拒否する設定がない。2026-09-23 時点で ask にあるのは `wget` だけで、node の fetch は確認なしで外部へ送信できる
