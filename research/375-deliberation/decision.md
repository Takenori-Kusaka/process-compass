# 議長の裁定(#375 名簿へ足すのと同じ変化点で任命すると記名が拒否される)

入力: 議題 `council-00-agenda.md`、調査 `survey-375-1-internal.md`・`survey-375-2-external.md`・`survey-375-3-probe.md`、意見 `council-01-drafter.md`(起案)・`council-02-field.md`(現場)・`council-03-qa-audit.md`(品質監査)・`council-04-standards.md`(規格)・`council-05-defender.md`(弁護)。

## 0. 骨格

5 委員とも案(a) を推した。弁護の委員も、今の挙動を意図した決定として守る根拠を見つけられなかった(標準・ADR-0079 決定7・#296 の会議体に記述が無い。ADR-0106 決定4 は同じ変更で足した材料を認めている)。外部の規格と実務が求めるのは確認と付与の**論理の前後**であり、取引を分けることではない(21 CFR 11.100(b)、NIST SP 800-63A-4、800-53 IA-12(1)・AC-2 c、Entra・Okta)。CODEOWNERS と RBAC が変更前の状態で判定する先例は、**記名者の権限**についてのもので、付与される者の前提条件には当たらない(規格の委員)。

## R-1 同じ変化点での確認と使用 — 裁定: 案(a)。回帰として直し、解釈を ADR で確定させる

- 名簿へ足すのと同じ変化点で、本人以外が記名した氏名の確認を、その変化点の任命・記名の判定に数える
- 確認と使用の前後は、論理の順序で足りる。確認の記名の要件を先に照らし、満たした確認だけを、その変化点の判定に数える(起案)
- 分類: 回帰である(4af67c5 の付記が評価の時点を定めずに検査の結果を変えた)。標準が前後を定めていなかったため、解釈を確定させる ADR-0111 を起こす
- 採らない:
  - 案(b) 前の変化点での確認を要求する。独立も効力の前後の保証も増えない(probe 3: 帰属の検査は同じ PR の2件を同じ PR で照合する)。委任の席では手順そのものが成り立たない(probe)。1〜2名の体制が2人目を迎える変化点で手数が倍になる
  - 案(d) 同じ変化点なら確認と任命に別の記名者を求める。標準に2つの記名を求める定めが無く、小さい体制で止まる
  - 案(e) 名簿の追加と確認の旗を同じ変化点で拒否する。確認の手順そのものが成り立たない
  - a1(L5058 だけを直す)。`nameOverrides` と [上書き] の表示が食い違ったまま残る(probe)

## R-2 評価の時点を揃える範囲 — 裁定: 2つの類を分ける原則と、検査ごとの表を ADR に置く

- 原則(規格・弁護・現場・起案):
  - 類A **付与される者の前提条件**(氏名の確認の効力、席の責任者・委任の席の責任者・適合性確認の承認者に置かれる人の名義)は、この変化点の記録を足した後の構成で照らす
  - 類B **記名・承認する者の資格**(変化点の記名者、確認の記名者、任免の決定者)は、変化点の前の構成で照らす。したがって、この変化点で名簿へ足した人が、同じ変化点で他の人の氏名を確認しても数えない(規格の委員の条件。実行での確認は実装の試験で行う)
- 一般原則案(f)「すべてを記録を足した後の構成で照らす」は採らない。類B を後の構成で照らすと、同じ変化点で足した者が自分たちの資格を作れる(弁護)
- 評価と書き出し(`changeLog` の `nameOverrides`、[上書き] の表示)は、同じ記録の1回の生成から作る(弁護 C1・品質監査)
- 表(実装で行番号を確定させる): `namingProblems`(L5058)・`nameOverrides`(L5345)・[上書き] の行(L5454)・適合性確認の承認者に置かれる人の名義(L5072〜5076)・`clampSeats` の席の責任者の名義 = 類A。記名の検査(L5216〜5232)・確認の記名者の資格(`confirmedNames`)・任免の決定者・規則の決定者と承認者の資格 = 類B
- `namingProblems` の中で類A と類B が混じっている箇所は、呼び出しを分けて解く(弁護 C5)
- 拒否の文(config.mjs L514〜517)を原因ごとに分け、同じ変化点で確認できる旨と、記名者の要件を案内する(現場・弁護)

## R-3 委任の席(`clampSeats`) — 裁定: 回帰として本件で直す

- `clampSeats` の ctx(L700)へ `changeLog` を渡す。席の責任者の名義の確認は類A として、この変化点の記録を足した後の構成で照らす。同じ ctx を受ける名義の検査(規則の決定者・承認者の資格、config.mjs L1292・L1378 付近)は類B として、前の構成のままにする(規格・弁護)
- 委任の席が記名なしに自動で緩まないことを試験で確かめる(品質監査)

## R-4 記録・開示・ADR — 裁定

- 同じ変化点で確認して使ったことを区別する欄は足さない。確認(`nameConfirmations`)・記名者・任命の差分は1件の記録に並び、記録から読める。課さないと決めた旨を ADR に書く(5 委員)
- 変化点を分けることを求めない旨を、G-6 の氏名の確認の規定へ1文で書く(起案)
- 帰属(ADR-0106)は時間の前後を保証しない。確認と使用は同じ PR で同時に裏づけられる。この旨を ADR に書く(品質監査・弁護)
- ADR-0111 を新設し、ADR-0079 決定7 を補う(置き換えない)。ADR-0079 の状態の節に補った旨を足す
- EV-0229: 類B を前の構成で照らすことで、同じ変化点での自己作成の資格が塞がるという判断は、試作と試験の場面にしか支えられない。見直し 2027-05
- IMPL: IMPL-0266(氏名の確認の注記)の規定を改める。新しい IMPL-0446(評価の時点の2類)を置く
- 回帰スイートの印(根の場面の #375 と、連鎖の2場面の dependsOn)を外す。期待値は p302 と同じ(反映)なので `changed` は要らない。外す根拠として ADR-0111 を引く。拒否されたままの経路(本人・AI の名義・名簿に無い人・記名なし・AI 名どうしの相互の確認・同じ変化点で足した人による確認)を場面で固定する

## 採らない案(まとめ)

| 案 | 理由 |
| --- | --- |
| (b) 前の変化点での確認を要求 | 独立も前後の保証も増えず、委任の席で成り立たない |
| (d) 確認と任命に別の記名者 | 根拠が無く、小さい体制で止まる |
| (e) 名簿の追加と確認を同じ変化点で拒否 | 確認の手順が成り立たない |
| (f) すべてを後の構成で照らす | 同じ変化点で足した者が資格を作れる |
| a1 の範囲だけの修正 | 記録と表示が食い違う |
| 同じ変化点での確認を区別する欄 | 1件の記録から読める。重複 |

## 追加の裁定(独立の突合 X-1〜X-3 を受けて、2026-11-05)

突合(`crosscheck.md`)は、実装が裁定に無い例外(前の名簿に体制の内の人がいなければ、類B を外す)を足したこと、その例外が理由とした「1名の体制の扱い」が保たれていないことを示した。議長が次のとおり裁定する。

- **AR-1 例外の範囲(X-2)**: 類B の例外は、3.13.3 の「初回の記入」(どの席にも責任者が記入されたことのない状態から全席を記入する変化点)に限る。「前の名簿の体制の内が0名」では広すぎる(外部の人だけが前の名簿にいる初回でない変化点で、同じ変化点で足した人の確認が数えられた)。標準 G-6・D-0 表5・accountable.md の3か所を同じ条件の書き方に揃える
- **AR-2 1名から2名へ移る変化点の詰み(X-1)**: AI を示す語を含む氏名の本人1名の体制に2人目を足す変化点は、今は本人の記名でも2人目の記名でも拒否され、外部の人を先に置く迂回しか無い。1つの変化点の記名者は1人で、確認の記名者はその変化点の記名者であるため、同じ変化点で2人目が本人の氏名を確認する形は構造上成り立たない。そこで次のとおりとする
  - 名簿の体制の内が1名から2名以上へ移る変化点では、前の名簿で効いていた本人の自己申告の確認を、その変化点では**確認待ち**として受け付ける(名簿へ足すこと自体を拒否しない)
  - 確認待ちの氏名は、契約検査と出荷の証跡の集約で、記録の無い確認と同じく欠落として扱う。したがって、本人以外の人(2人目以降)が記名する後の変化点で確認するまで、マージも出荷もできない。2つの変化点を同じ PR に入れてよい
  - `/process-change` と拒否・注意の文は、確認待ちの氏名と、次の変化点で本人以外が確認する手順を案内する
  - 採らない: 同じ変化点で足した人の確認を、移行の場合に限り数える案(記名者が1人で、構造上成り立たない)。確認待ちを欠落に数えない案(2名以上の名簿で、本人の自己申告だけの氏名が効いたまま残る)
- **AR-3 試験(X-3)**: 初回の記入の例外の側、AR-1 の境界(外部の人だけが前の名簿にいる初回でない変化点では数えない)、AR-2 の確認待ちの経路(足す変化点は通る・確認待ちのままでは契約検査が落ちる・次の変化点で本人以外が確認すれば通る)を、試験と回帰の場面へ固定する
- X-4〜X-6(低)は実装の担当が直す。ADR-0111 の表の記述を事実に合わせる、アカウント名の確認が類B の対象外である旨を明記する、空振りの試験を直す
- EV-0229 の範囲に AR-2 の確認待ちの扱いを含める
