### M-1(中) IMPL-0278 の note が、足した説明の段落と食い違う
- 所在: `tailoring-guide.md` 軸A の人数の段落の後(新しい段落)と、IMPL-0278(`state=undelivered`)の note
- 根拠: 新しい段落は「規模の規則は、設問の回答から導きます。名簿の人数から直接は導きません」を本標準の説明として述べる。一方 IMPL-0278 の note は「軸A の人数を、表5 の人で数えること。準拠テンプレートは規模の規則を設問の回答から導き、名簿の人数から直接は導かない」と、同じ挙動を降りていない差として書く。台帳は、本文が意図と述べた挙動を未達と表示する。降りていないのは、名簿が空のとき(3名以上の回答)の検出だけである(新しい段落の「名簿を書いた後は」も同じ範囲を示す)

- 直しの案: IMPL-0278 の note を「3名以上の回答で名簿の体制の内が空の場合に、回答と人数の食い違いを検出すること。規模の規則を回答から導き名簿から直接は導かないことは意図である(#351 の裁定、第8章の説明の段落)。…(以下の確かめる者は保つ)」へ改める。state=undelivered、issue=351 は保つ。`npm run impl:write` が要る
