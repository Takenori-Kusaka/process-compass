# 束 B25 K-4 反対委員の意見書(軽)

- 立場: 調査の案1(本文に「関わる」の定義と扱いを足す)を落とす側。実物は条文とコードを読んだ。template のコードは実行していない(調査の 1.3 の実行結果は未検証のまま借りる)
- 結論: **案1 に反対。対案(案2 の改良)に条件つきで同意**。案1 の段落の第3文「関わらないことを記録で示していない種別は、関わるものとして扱います」は、採用者への新しい義務に当たると読む。入れるなら軽では閉じず、所有者へ上げる

## 1. 反証

### 1.1 「答えは既にある」は、問いの半分にだけ当たる

- 問い(1名の体制で、委任の停止は第8章のどの種別を止めるか)への答えは `tailoring-guide.md:343`「コア機能に関わる登録した変更種別も止まり続けます」で足りる。ここは調査のとおり
- ただし「関わる」の中身は本文のどこにも無い。`human-ai-boundary.md:197` は「該当**機能**を L1 へ引き下げる」、`:310` は種別の単位の停止。機能から種別への写像は template の `templates/05-handover.md:22` にだけある。したがって「答えは既にある」は **止まる単位の答え**であって、**どの種別が関わるかの答え**ではない。調査の 2 節 a と b は分けて読むべきで、a は済み、b は残る
- 「委任」の他の意味は、調査の 1.4 を実物で確かめて成り立った。`human-ai-boundary.md:657` の独立レビュアの席の「委任の宣言」は 5.5.4 の内側の宣言で、別の範囲ではない。兼務(3.5)は委任と呼ばれていない。語の多義による食い違いは見つからなかった

### 1.2 案1 の第3文は読みを狭める。ADR の決定にも条文にも根拠が無い

- 根拠の無さを行で示す。「示していなければ関わる」の既定(空欄=すべて)が書かれているのは template だけ(`templates/05-handover.md:22`、`org-assurance.mjs:804`〜`:821`)。標準側にも ADR にも無い
- 近い文は ADR-0081 の影響欄 `adr/0081-…md:144`(調査は :142〜:143 と引いているが、実物は :144)。書かれているのは「引き継ぎ文書に関わる登録した変更種別の列を**足す**」と「台帳と引き継ぎ文書が**無い**構成では委任がすべて止まる」まで。列が**ある**が空欄、あるいは列の**無い**行の扱いは、ADR は決めていない。止まる範囲が文書の不在と同じ向きだから既定もすべてだ、というのは類推であって決定ではない
- 現行の本文は、`:197` の「該当機能」を採用者がどう種別へ落とすかを開いたままにしている。第3文はこれを閉じ、閉じ方は「記録を作らない限りすべて止まる」である。止まりたくない採用者は「なし」の記録を作らなければならない。**記録を作る動機が、止まるという不利益で与えられる**。これは義務の語を使わない義務である
- ADR-0158 決定7(`adr/0158-…md` の「7. 第8章の切替への帰結」)は「新しい義務の語は使わない」と決めた。帰結の説明に留めると決めた範囲を、第3文は越える。調査 4 節 (iii)「5.4.5 後段と同じ向き」は、5.4.5 が**登録の可否**(計測できない種別は登録しない)の話で、**記録の既定値**の話ではないため、類推として足りない
- 判定: **新しい義務に当たる**。ADR-0081 決定4・6 の変更にまで当たるかは、決定6 の本文を私は読めていない。当たる可能性が否定できない以上、議長は軽で裁定せず、所有者へ上げるのが決まりに沿う(軽で2委員が割れ、割れた点が新しい義務に当たる場合は重へ)

### 1.3 本文の段落は、定義の増加で、破られた損失が小さい

- 案1 の段落は、5.5.7 の機械の規則、5.5.4 条件5、既定の倒し方の3つを1段落に持ち込む。3問の(3)に照らすと、破られたとき失うものは、調査自身の 3 問で「安全ではない。CL0・R3 に限る。取り消しは条件4」と書かれている。**安全・取り消せない操作・適合の主張の信頼のどれにも当たらない**。さらに 1名の体制は適合を主張しない(`roles-responsibilities.md:296`、調査 F7)ため、最も大きな読み手(1名)に対しては主張の信頼も失われない
- よって細かく書く対象ではない。調査が根拠にする「template を使わない採用者が手掛かりを持たない」は、手引きの欠けであって条文の欠けではない
- 「正本の逆転」(案2 を退けた理由)は誇張。`template/` は標準の部分集合であり(ADR-0040)、template が標準より**細かい**定めを持つのは仕様どおり。逆転ではなく、template が先に進んでいる状態だ。ただし、それを標準側が知らないままなのは、手引きとして開示すべき(下の対案)

### 1.4 場面 F(登録外の ID)は仕様ではなく、template の不整合

- 標準は「関わる」の写像を定めていない(1.2)。したがって「登録外の ID が何も止めない」は**標準に対する欠陥ではない**。template の入力検証の欠けである
- ただし template の中では向きが食い違う。列の欠け・空欄・節2 欠落・行なしは、すべて止まる側(`autonomy.mjs:307`〜`:310`、`org-assurance.mjs:804`〜`:821`)。登録外の ID だけが止まらない側に倒れる。書き誤りで止まるべき種別が止まらないのは、同じ層の既定(止める側)に反する
- 調査の推す「表示する。止めない」は、止まらないことを表示の下に隠す。表示が無い・見落とされる場合は、表示と実態の食い違い(最も重い欠陥の類)にはならないが、止めるべき停止が欠ける。決定可能な条件(ID が登録の一覧に有るか)なので、止める側に倒すことが機械の検査の原則と整合する。反論(書き誤り1つで全種別が止まり所在が見えにくい)は、止める理由の表示を併せれば解ける。私は「止める+理由を表示」を推す。これは template の動作の整合であり、標準の条項の追加ではない

## 2. 対案(案2' 本文は直さない。参照の整理と template の試験・検証だけ)

1. **本文の段落(案1)は入れない**。`human-ai-boundary.md` に定義を足さない。新しい IMPL も足さない
2. 第8章 `tailoring-guide.md:343` は変えない。調査の言う「括弧の参照の編集」は、実質を変えないので議長が編集として直してよい(軽の編集の指摘の扱い)。直すなら参照先を既存の語のまま(5.4.6 の停止の表の行)にとどめ、「関わる種別の定め」という、本文に無い定めを指す語を入れない(存在しない定めへの参照は、それ自体が表示と実態の食い違いになる)
3. T8 を template に降ろす: 2種別を同じ構成に並べ、関わる=種別1 のとき種別1 だけが止まる、「なし」のとき両方止まらない、空欄のとき両方止まる。これは**既にある文(`:343` とテンプレート様式 `05-handover.md:22`)の実行での固定**であり、条項を足さない
4. 場面 F: ID が登録の一覧に無い行を、止める側に倒す。理由を出力に表示する(決定可能)。template の変更に留まり、標準の本文は動かさない
5. 標準側への開示: 「関わる」の写像が本文に無いことを、根拠水準のマークで開示する(`:::caution[暫定 EV-NNNN / 見直し YYYY-MM]`。内容: 「関わる登録した変更種別の定義は本文に無く、準拠テンプレートの様式だけが空欄をすべてとして扱う。単一の実装にしか支えられない」)。これは ADR-0026 の用途(未検証・単一事例)にそのまま合う。**「書かれていない」と「課さないと決めた」の区別**(コアポリシー)も、これで読み手に残る
6. 定義を本文へ足す判断は、観測が出てからにする。契機: 採用者が template を使わずに「関わる」を狭く読み、保持者1名の機能に触れうる種別を L3 で回した記録が出たとき。または所有者が新しい義務と承知のうえで入れると決めたとき

## 3. 3問への答え(対案について)

1. 満たすべき結果と証跡: 結果は「保持者1名以下の機能に関わる種別は止まる」(`:343` と `:310` で既にある)。証跡は台帳の節2 と、委任の判定の出力。手順(写像の作り方)は手引き(様式)に置き、条文に足さない
2. 例外承認で受けられるか: 珍しい構成(関わるかの判断が割れる種別)は、新しい条項を足さずに**止める側に倒れる**ことで安全が保たれ、止めたくなければ「なし」を記録する。ただし 5.4.6 の停止は「実行を見送る裁量を持たない」(`:190`)ため、第7章の例外承認で停止を外せない。案1 と対案のどちらも、例外承認は使わない。ここは調査に同意する
3. 破られたとき誰が何を失うか: 関わる種別を狭く読む採用者が、保持者1名の機能に触れうる種別を L3 で回す。失うのはその採用者の事後監査の信頼で、CL0・R3 に限り、条件4 で取り消せる。適合の主張の信頼は、1名の体制では主張自体が無い(`roles-responsibilities.md:296`)。2名以上の体制では節2 の記録が出荷判定者に見える。この損失の大きさは、本文の段落と新しい義務を正当化しない
