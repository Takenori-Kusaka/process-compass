# 束 B25 — K-4 の議長の裁定(2026-11-19。軽)

問い(#446 のコメント 2026-11-17、束 B17 が #340 から寄せた): 1名の体制で、ADR-0081 の委任の停止(理解保持者が1名以下)が、第8章の委任のどの種別を止めるか。

記録: 調査 `10-k4-research.md`、起案 `21-k4-proposer.md`、反対 `21-k4-opponent.md`。外部の調査は行っていない(規格の引用を要さない)。

## 1. 2委員が一致した点(そのまま採る)

- 止まる単位の答えは本文に既にある。`tailoring-guide.md` 第8章(ADR-0158 決定7)「1名の体制では、コア機能に関わる登録した変更種別が止まり続ける」。止まるのは 5.5.4 の委任(登録した変更種別)だけで、兼務(3.5)は止まらない。「委任」の語に他の意味による食い違いは無い
- 欠けているのは、どの種別が「関わる」かの写像が本文に無く、template の様式 `templates/05-handover.md` の節2 と `org-assurance.mjs` だけが持つこと(空欄・列の欠けはすべて止まる側)
- 第7章の例外承認では受けない。停止は裁量を持たない自動の措置である(5.4.6)
- 破られたときの損失は、採用者の事後監査の信頼に留まる(CL0・R3 に限る。取り消しは条件4)。安全・取り消せない操作には当たらない。1名の体制は適合を主張しない
- template に、2種別を並べた試験を足す(関わる種別だけが止まる/「なし」は止まらない/空欄は両方が止まる)。既にある文の実行での固定で、条項を足さない

## 2. 割れた点と裁定

割れた点: 本文へ「関わらないことを記録で示していない種別は、関わるものとして扱う」と書くか。起案は「既存の停止の範囲の曖昧さの解消で、新しい義務ではない」、反対は「止まりたくない採用者に『なし』の記録を作らせる。義務の語を使わない義務で、ADR-0158 決定7(新しい義務の語は使わない)の範囲を越える疑いがある」。

裁定:

- **本文に段落を足さない(案1 を採らない)**。割れた点は、採用者への新しい義務に当たるかどうかそのもので、議長が軽で入れると決めてよい点ではない(指揮役の指示: 新しい義務に当たると分かったら裁定しない)。入れない側は新しい義務を課さないため、議長の裁定で閉じられる。入れるかどうかは所有者へ問う(§4)。所有者が入れると決めたら、起案の文の案(`21-k4-proposer.md`「文の案」)を基に別の審議で扱う
- **写像が本文に無いことを、根拠水準マークで開示する**。所在は `tailoring-guide.md` 第8章の当該の文の直後。内容: 関わる登録した変更種別の対応は本文で定めていない。準拠テンプレートの運用引き継ぎ文書の節2 が、機能ごとの記録と、記録の無い場合にすべての種別を止める扱いを持つ。単一の実装にしか支えられない。差し替え条件: 準拠テンプレートを使わない採用者の運用の記録が得られたとき、または所有者が本文への定義の追加を決めたとき。「書かれていない」と「課さないと決めた」を読み手が区別できるようにする
- **登録外の ID(template)は、止める側へ倒し、理由を表示する**(反対の案)。運用引き継ぎ文書の節2 の「関わる登録した変更種別」に、登録の一覧に無い ID を書いた行は、その機能について空欄と同じ扱い(すべての種別を止める)にし、どの行のどの ID が登録に無いかを出力に出す。決定可能な条件(ID が登録の一覧に在るか)である。同じ層の既定(列の欠け・空欄・行なし)が止める側で、ここだけが止まらない側へ倒れるのは不整合で、書き誤りで止まるべき種別が黙って止まらない。取り込みの後に止まる採用者がいるため、CHANGELOG と移行の注意に書く
- 第8章の括弧の参照の編集は行わない(本文に無い定めを指す語を入れない)
- 新しい実装マークは足さない。2種別の試験は、既にある停止のマーク(理解保持者数による種別の停止)の試験へ場面として足す。登録外の ID の扱いは、同じマークの note に1句を足す

採らない案:

| 案 | 理由 | 再検討の契機 |
| --- | --- | --- |
| 案1(本文に「関わる」の定義と既定の段落) | 新しい義務に当たるかで2委員が割れた。損失は安全・取り消せない操作・適合の主張に当たらず、細かく書く対象でない | 所有者が入れると決めたとき。template を使わない採用者が狭く読んで L3 を回した記録が出たとき |
| 案1 から既定の文だけを外した段落 | 定義だけが残り、実行を決めない文になる。template との食い違いを本文に作る | — |
| 案3(1名の体制では全種別を止める) | ADR-0158 決定7 の変更に当たる(重) | — |
| 案4(対応表を必須の記録にする) | 新しい義務 | — |
| 登録外の ID を表示に留める(調査・起案) | 同じ層の既定と向きが逆になる | 登録外の ID を許す正当な運用が出たとき |

## 3. 実装と突合

- 新しい根拠水準マークの番号は push の直前に付け直す。`npm run evidence:write`

## 4. 所有者への問い(指揮役へ上げる。回答を待たずに §2 で進める)

本文(5.4.6 か第8章)へ「関わらないことを記録で示していない種別は、関わるものとして扱う」と書くか。書くと、準拠テンプレートを使わない採用者にも止まる側の既定が及び、止まりたくない採用者は「なし」の記録を作ることになる。議長は書かない案で進め、欠けを根拠水準マークで開示する。書くと決める場合は、#446 とは別に審議する(#446 を閉じる条件には含めない)。
