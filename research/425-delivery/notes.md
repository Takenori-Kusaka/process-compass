# #425 準拠テンプレートが案内する道具(graft)の外部送信(降ろすだけの対応)

## 振り分け

条項の新設・改廃は要しない。組織の管理外への送信は、第5章 5.8.6 の要求事項1(許可していない外部への通信の拒否)、5.5.1 の取り消せない操作(外部への発行)、ADR-0053 決定4(既定を拒否に置く構造)、ADR-0103 決定2(送信を始める設定の有効化は人の決裁)で既に扱われている。準拠テンプレートが、利用統計を既定で送る道具をそのまま案内していた(SKILL.md は「止めるなら」と任意の手順として書いていた)ので、既定を止める側へ直す。

## 確かめた事実(`survey-graft-telemetry.md`)

- graft 0.12.1 は、利用統計を既定で送る(opt-out)。送るのは許可リストの項目(版・OS・乱数の端末 ID と repo ID・件数のバケット・コマンド名)で、コード・パス・シンボルは含まない。送信元の IP は受信側に届く
- `build --deep` はファイルのパスとソースの本文を、`blast --name` はパスとシンボル名を、設定した LLM の提供者へ送る
- DO_NOT_TRACK と CI の環境変数で利用統計は止まる。`telemetry disable` は OS のユーザーのホーム単位
- 1 日 1 回の更新の確認(npm レジストリ)は 0.12.1 では止められない(上流で修正済み・未リリース)

## 決めたこと(準拠テンプレート)

- 構成の生成が `.claude/settings.json` の `env` に `DO_NOT_TRACK=1` を置く。採用者が値を変えた場合は残す(送ると決めるのは組織。強制層の変更として AI維持管理者が承認する)
- ソースとパスを送る 2 つのコマンドを deny に置く。ステージと guard.enabled に依らない
- 更新の確認は止められないことを SKILL.md に開示し、ネットワークの既定の拒否(IMPL-0200、未達)で扱うとした。止める手段の無いものを止めたとは書かない
- graft をテンプレートから外すことは本件で決めない(コードの探索の道具の採否は 3.11.2 の AI維持管理者の判断。外す理由になる事実は、利用統計の既定と更新の確認であり、前者は止めた)

## 突合

- ADR-0103 決定2 は推定による注意の喚起の規定だが、組織の管理外への送信を既定で止める向きは同じで、矛盾しない。ADR-0103 の会議体はこの道具を先例にしていない
- deny は前方一致で、フラグの順序を変えた形(`build . --deep` など)は止まらない。指示文(SKILL.md)と併せて扱う
