## #140 で確定した設計（後続で覆さないこと）

| 事項 | 決定 |
|---|---|
| スコープの単位 | 事業ステージ。SG の「継続」判定と同時に次ステージ分を確定する。専用の場を設けない |
| スコープ3層 | SC-M 確約範囲（容量の60%以内）/ SC-P 計画範囲 / SC-B 調整枠（20%程度）|
| 規模の合意 | 工数の絶対値でなく実測スループット（完了件数）に対する件数。実測がなければ SC-M を置かない |
| 進捗の観測 | 到達＝進捗率（遅行）、停滞＝作業単位の滞留期間（先行）。自己申告の完了率は使わない |
| 通常運転と例外の境界 | **SC-M を動かすときだけ例外**。SC-P・SC-B の増減は価値責任者の単独判定 |
| 期日不足時の順序 | 範囲を削る → 期日を動かす → 基準を下げる（7.3 の例外承認） |
| 範囲内外の判定（#131） | **人が判定し、機械は記入の有無だけを検査**。G-4 判定基準5 |
| 差し引き | G-4 に記載事項1つ追加、7.6 のスコープ発火条件を SC-M 限定へ縮小（報告は純減） |
| 記号の衝突解消 | 受入基準 `AC-n` → `CR-n` へ改称（ADR-0018 の AC-0/1/2 と衝突していた） |
